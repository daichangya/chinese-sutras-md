# 發菩提心戒 · 第一卷

> 石經寺主講經律沙門志仙記

---

## 1

夫菩提心戒者為修六度万行之泉源是證三身佛果菩提之根本功最甚深理難思議是以三世諸佛同說三世菩薩同學故經云戒如明日月亦如瓔珞珠微塵菩薩眾由是成正覺。

念三寶六師佛菩薩念梵釋四王金剛天

將釋戒文分為八段第一奉請賢聖第二想陳妙供第三懺悔罪第四受三歸依戒第五翻邪歸正第六正受菩提心戒第七遣相第八普皆迴向八段不同。𠍴

且初第一奉請賢聖

人各整衣跪合掌聞舉弟子某甲等處隨言後說䠒

三說念無盡三寶願降臨

第二想陳妙供

三說念供養無盡諸三寶

第三懺悔罪𠍴

念普賢菩薩懺悔師

第四受三歸依戒

三說念誓受如来三歸依戒

第五翻邪歸正

念歸命無盡佛法僧

第六正受菩提心戒

三說念戒清涼菩薩摩訶薩

第七遣相

三說念遠離一切諸性相

第八普皆迴向

三說念皆共速成無上覺

始從此座一剎那間生在佛家終至後身三僧祇內得名佛子此心若在万德咸歸此心若失万德皆喪是故應當善好護持。

上来普為四眾發菩提心已竟齊念摩訶般若。

弟子某甲等稽首皈命禮遍虛空法界 /
十方諸如来瑜伽揔持教諸大菩薩眾 /
及禮菩提心能滿福智聚令得無上覺 /
是故志心禮

弟子某甲等十方一切剎所有諸供養 /
花鬘塗香等飲食幢幡盖誠心普奉獻 /
諸佛諸法藏諸大菩薩眾及諸賢聖等 /
我今志心禮

弟子某甲等從無始来輪迴生死 /
乃至今日所造眾罪無量無邊 /
不自覺知自作教他見作隨喜 /
我今懺悔不復更造唯願諸佛 /
慈悲攝受令我罪障速得消滅 /

弟子某甲等稽首投誠菩提道場 /
歸依如来無上三身歸依方廣 /
大乘法藏歸依僧伽諸菩薩眾 /

弟子某甲等歸依佛竟歸依法竟 /
歸依僧竟従今已往乃至成佛 /
更不歸依二乘外道惟願諸佛 /
慈悲攝受

弟子某甲等
仰啟盡十方無量無邊界一切佛菩薩 /
従今日已往乃至成正覺誓發菩提心 /

有情無邊誓願度福智無邊誓願集 /
佛法無邊誓願學如来無邊誓願侍 /
無上菩提誓願成

弟子某甲等今所發覺心 /
遠離諸性相蘊處及界等能取所取執 /
諸法悉無我平等如虛空自心本不生 /
空性圓寂故如諸佛菩薩發大菩提心 /
我亦如是發是故志心禮 /

願以此功德普及於一切 /
我等與眾生皆共成佛道 /

石經寺主講經律沙門乹統八年十月十五日記志仙
