# 华严经疏注 · 第120卷

> 唐 澄观述　宋 净源录疏注经

---

归命十方极三际，尘刹圆明调御师， /
法界功德大悲云，毗卢遮那大智海。 /
所住甚深真法性，所流圆满修多罗， /
一一尘方佛会中，普贤文殊诸大士。 /
我今欲以一毛智，测量无边法界空， /
愿承三宝同体慈，句句冥符诸佛意。 /
俾令法眼常无缺，尽众生界如普贤， /
回兹胜善洽群生，速证菩提常乐果。 /

## 120

△三、明因深广，因深则果厚故。文分为三：初、问答审见。

尔时普贤菩萨摩诃萨唯是如来之所能知。至

△二、显因深远，三：初、别明求菩提行，二：初、顺显所行。

普贤告言善男子修行佛法护持正教。至

△二、离过成德。

善男子！我于尔所劫海中助道之法大菩提心。至

△二、通明悲智行。

善男子！我庄严佛土劫海可尽，此无有尽。至

△二、别明求法行，二：初、反显无不能舍。

善男子！我法海中一切所有而求得者。至

一文尚无所不舍，况全部耶？以一文即一切之一，如海一滴故。

△二、显求所为结说无尽。

善男子！我所求法佛刹微尘数劫海说不可尽。至

△三、结因成果，二：初、结因，文有十句。

是故，善男子！我以如是助道大志乐力修功德力。至

上四缘因。

如实思惟，一切法力，智慧眼力。

此二，了因。

佛威神力、大慈悲力、净神通力、善知识力故。

后四通于缘了，以有成果之功，故皆云力也。

△二、成果。

得此究竟，三世平等，清净法身。

由了因故，得法身果。

复得清净无上色身。

由缘因故，得色身果。

超诸世间随诸众生令其见者靡不欣乐。至

△四、观用无涯，三：初、举益劝观，三：初、标。

善男子！汝且观我如是色身。

△二、释，二：初、明难见闻。

我此色身无边劫海千亿那由他劫难见难闻。至

△二、见闻皆益，三：初、不退菩提益。

善男子！若有众生见闻我者皆亦如是。至

△二、善根成熟益。

或有众生一日一夜或生欢喜皆得成熟。至

△三、总结多门，皆不退成熟。

善男子！我以如是等三藐三菩提得不退转。至

上多门皆不退，下种种皆成熟。

善男子！若有众生必得生我清净身中。至

净刹可生，身云何生？此有二义：一、约法性身、刹，与刹为体，名清净刹；与身为体，名清净身。从能依有殊，欲显所依体一，故言生身。二、约相用，净刹是所依之刹，净身则身内之刹。欲显身土互融，故言生净身耳。

△三、总结。

善男子！汝应观我此清净身。

△三、观见奇特，三：初、见毛内含三世间。

尔时善财童子观普贤如是等事各各不同。至

△二、见普贤身徧诸刹中出生大用。

又见普贤于一一世界海中多罗三藐三菩提。至

△三、自见己身等普贤化。

时善财童子又见自身诸世界中教化众生。至

△三、校量显胜，三：初、校量善根。

又善财童子亲近佛刹筭数譬喻亦不能及。至

△二、校量所入刹海。

是善财童子从初发心，一切毛孔悉亦如是。至

△三、双结上二超胜之相，二：初、别明横竖深广。

善财童子于普贤菩萨毛孔刹中。

于中有三世间。

行一步，过不可说不可说佛刹微尘数世界。

显横广。

如是而行，尽未来劫。

明竖穷。

犹不能知。

显其深远。

一毛孔中刹海次第刹海藏。

藏约包含。

刹海差别，刹海普入。

普入约广徧。

刹海成，刹海坏，刹海庄严所有边际。

上器世间，下智正觉世间。

亦不能知佛海次第集菩萨众海散所有边际。至

后众生世间。

亦不能知入众生界如是等海所有边际。至

△二、总结平等周徧。

善财童子于普贤菩萨不于此刹没，于彼刹现。至

不于此没彼现者，以没现相如法性故，以彼此相相即故也。

念念周徧无边刹海令向阿耨多罗三藐三菩提。至

△二、位满齐佛。

当是之时善财童子得普贤菩萨诸行愿海。至

上句明自得，余皆等上。

与普贤等。

等因圆。

与诸佛等。

等果满。此下别显等相。

一身充满一切世界解脱自在悉皆同等。至

此即义。当觉因位既满，更无所修，故但说等，不辨更求。此则一生顿成，行布亦足，非唯但约理观初后圆融。

△二、闻佛胜德难思。前长行但显因圆，此偈颂方陈果用，非颂前文。然有二意：一、对普贤。普贤意云：上来见我难思之德，尚是因位。今示汝果，尤更甚深。二、对善财。善财等佛，但是因圆。以果海离言，故不说成佛。今寄现佛之德，以显善财得果之相。故长行偈文，因果绮互。文中有三：初、有四颂，标举佛德，诫听许说。

尔时，普贤菩萨摩诃萨即说颂言。

汝等应除诸惑垢未曾分别起想念。至

△二、长行，举众渴仰欲闻。

尔时诸菩萨闻此说已作是念已深生渴仰。至

△三、广陈德相，令众求满，二：初、长行重诫，许说分齐。

尔时普贤菩萨今我欲说佛功德海一滴之相。至

△二、偈颂广显佛德难思。九十五偈，分之为二：初、九十三偈别叹佛德。于中，前八十偈法说，后十三偈喻明。然通赞毗卢遮那十身圆满二十一种殊胜功德，实即应分二十一段，且为十九，后三合故。初有二偈，即于所知一向无障碍转功德。

即说颂言：佛智广大同虚空念念示现无边事。至

谓佛无障碍智，于一切事品类差别无着无碍故。

△二、有一偈，明于有无无二相，真如最清净，能入功德。

随众生心种种行而佛本来无动念。至

谓了真如无二，故无动念。

△三、有三偈，即无功用佛事，不息休功德。

或有处处见佛坐心不净故不闻者。至

谓住佛无住处，作佛事不休息，故云或见等。

△四、有十五偈，即于法身中所依意乐作事无差别功德。谓由诸佛所依智同，益众生意乐同，报化作用同。故前经云得佛平等，亦同《摄论》四种意趣中平等意趣。故此广列诸佛皆互相徧。此释已妙。今更以文理证此诸佛皆遮那之身。谓此文言此三千界阿閦在中，阿閦如来本在东方，今云在此，明不异此。又无量寿佛、月觉如来皆徧十方，岂容隔此？又皆言或见，则知一佛随见不同。若言别赞余佛，直言阿閦在此，何成赞德？况华藏刹海皆遮那化境，无量寿等未出刹种之中，岂非是此佛耶？《法华》、《央堀》并说十方分身，故知法藏别缘十六王子皆方便说。以理推之，皆是如来海印所现，何缘不说自所现佛而说他耶？故知贤首佛等皆本师矣。

然此段文亦兼显第十七随其胜解示现差别佛土功德。文中有三：初八偈，主伴严土摄生同。

或见清净大菩萨说法除灭众生翳。至

△二、有四颂，明微细含容转法同。

一一毛端不可说毗卢遮那转法轮。至

△三、有三偈，总摄多门，结前生后。

或见世界不清净我说少分汝当听。至

△五、有三偈，即修一切障对治功德。

或见释迦成佛道随众生心皆示现。至

谓一切时常修觉慧，治六蔽等故。既云已经多劫，则不定始成。

△六、有三偈，即降伏一切外道功德。

或见究竟波罗蜜犹如幻师现众像。至

初二即教证二道，后一现所摧同类之身。

△七、即生在世间，不为世法所碍功德。于中有四：初、八相现世无碍。

或现兜率始降神或见正修诸妙行。至

△次三，处天宫殿无碍。

或见如来清净月莫不于中现其像。至

△次六，随世巧化无碍。

于彼然灯世尊所如是展转陪过此。至

△四、有二偈，结叹。无碍之智，能徧随机。

佛智通达净无碍随众生心皆示现。至

△八、安立正法功德。于中亦四：初、明立三乘法轮。

如来住于无上道不使众生有惊怖。至

末句之中，兼显业用。

△二、明立六度道品对治法。

如来普演广大音无量方便诸法门。至

△三、明一音随类闻法不同乃至无量。

龙神八部人非人悉是如来方便力。至

△四、有四偈，明平等语业而应一切。

涅槃寂静未曾异普照世界除烦恼。至

△九、有三偈，明其授记功德。

具足清净功德智随所应化示佛道。至

记别过未如现在，故云悉明见。

△十、有四偈，明示现受用变化身功德。

究竟虚空十方界现斯苦行摧异道。至

△十一、有二偈，明断一切疑功德。

或持彼戒为世师方便皆令住佛道。至

谓于一切境善决定故，能断他疑。

△十二、令入种种行功德。

或现上服以严身然后舍去无知者。至

谓徧了一切有情性行，随根令八故。

△十三、有一偈，即当来生妙智功德。

如来无碍智所见种种教化令成就。至

谓佛知久远故。

△十四、有五偈，随其胜解示现功德。

譬如幻师善幻术靡不于中现其影。至

谓随解现身故。

△十五、有三偈，即无量所依调伏有情加行功德。

譬如净日放千光普使除灭三毒火。至

意云：佛智为无量菩萨，谓伏众生加行之所依故。

△十六、有二偈，明平等法身波罗蜜多成满功德。

如来清净妙法身当于佛体如是观。至

然同《摄论》法身具五种相：初句白法为相，以是极果圆满自在故；次二句不思议相；次一是无二相；次一无依相；次句常住相。次句二喻者，空喻、无依梦喻，非有无二相。余不可喻，或略不喻。𦘕

△十七、有一偈，明随胜解示现差别佛土功德。

三界有无一切法无有依空而住者。至

既随解而现，故不可喻。此偈亦总拂前喻，如山林等必不依空，有等必然不能喻佛。

△十八、一偈，明三种佛身方处无分限功德。

大海摩尼无量色随应而现无所住。至

△十九、有一偈，摄三种功德。

虚空真如及实际可以显示于如来。至

同法性等即穷生死际，常现利乐一切有情功德；等虚空即无尽功德；等实际即究竟功德，以不如实际之际穷未来际故。

△二、有二偈，结德无尽，劝信勿疑，亦是别显无尽功德。虽是总结，即当别文。初一结德。

刹尘心念可数知无能尽说佛功德。至

△后一，劝信。

若有闻斯功德海慎勿于此怀疑念。至

古德亦有将此二偈为一部流通，已如前说。

△四、谦赞回向。

法性深广难思议普令含识证菩提。至
