# 十二礼 · 第一卷

> 龙树菩萨造　禅那崛多别译

## 1

至心归命礼西方阿弥陀佛！

稽首天人所恭敬，阿弥陀仙两足尊， /
在彼微妙安乐国，无量佛子众围绕。 /

金色身净如山王，奢摩佗行如象步， /
两目净若青莲华，故我顶礼弥陀佛。 /

面善圆净如满月，威光犹如千日月， /
声如天鼓俱翅罗，故我顶礼弥陀佛。 /

观音顶戴冠中住，种种妙相宝庄严， /
能伏外道魔憍慢，故我顶礼弥陀佛。 /

无比无垢广清净，众德皎洁如虚空， /
所作利益得自在，故我顶礼弥陀佛。 /

十方名闻菩萨众，无量诸魔常赞叹， /
为诸众生愿力住，故我顶礼弥陀佛。 /

金底宝间池生华，善根所成妙高座， /
于彼座上如山王，故我顶礼弥陀佛。 /

十方所来诸佛子，显现神通至安乐， /
瞻仰尊颜常恭敬，故我顶礼弥陀佛。 /

诸有无常无我等，亦如水月电影露， /
为众说法无名字，故我顶礼弥陀佛。 /

彼尊无量方便境，无有诸趣恶知识， /
往生不退至菩提，故我顶礼弥陀佛。 /

彼尊佛刹无恶名，亦无女人恶道怖， /
众人至心敬彼尊，故我顶礼弥陀佛。 /

我说彼尊功德事，众善无边如海水， /
所获善根清净者，回施众生生彼国。 /

---

## 校异

。此十二礼文，出在迦才《净土论》，今刻依之。又往生礼赞中夜偈亦用此文，但每偈首有「南无至心归命礼西方阿弥陀佛」十三字，又每偈「弥陀佛」竝作「弥陀尊」（《集诸经礼忏仪》第三及《往生要集》上所引亦作「弥陀佛」）又第七偈「妙高座」作「妙台座」，又第十、第十一两偈前后易位，此为异耳
