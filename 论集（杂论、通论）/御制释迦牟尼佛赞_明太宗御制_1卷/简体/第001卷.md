# 御制释迦牟尼佛赞 · 第一卷

> 明 太宗御制

---

如来胜相徧十方具足万行显微妙顶髻圆光无不照无量无碍性恒存譬如大海纳百川 /
一滴徧涵诸水味又如海水起诸泡一泡中含一海体须弥微尘纳芥子一毫徧摄于大千 /
大威大智大神通甚深甚广甚方便能立最胜之大法演说无量最上乘犹如大风吹海波 /
散作甘雨徧世界一点沾满于尘刹令溥清净悉清凉法云大周于十方妙具种种之胜色 /
普护众生无露迹如八宝盖胜吉祥有如雷音海潮音远震十方无所碍世人有耳悉能听 /
由闻以入观一同咸悟圆觉及妙觉善巧方便出世间征心演法显真如五阴六入亦如是 /
一心万行之本源真心自性恒冥寂领者由凡而入圣解者超断以除缘以证信心为实心 /
以寂静境为真境以大智海为性海以慧妙国为住持以法身而体色身以无相而摄有相 /
智身光明如日月照临随现于世间众生心性亦如是一切与佛无分别若能断除诸障垢 /
自然获此智慧心令彼凡夫悉解脱如渴饮水成醍醐若能精进无退转坚固心等金刚山 /
诸善男子善女人及诸声闻与缘觉闻是真谛诵赞叹欢喜乐受作思惟无量无边消劫尘 /
口变无等甘露味如是功德不思议庸愚俱至妙菩提随缘感应无不周愿使众生皆成佛 /
