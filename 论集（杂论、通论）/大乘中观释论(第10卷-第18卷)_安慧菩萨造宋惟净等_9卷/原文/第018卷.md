# 大乘中觀釋論(第10卷-第18卷) · 第十八卷

> 安慧菩薩造  宋 惟淨等譯

---

能見及所見見者等各異 /
彼更互相望一切皆無合 /

如是染染者及彼所染法 /
瞋等餘煩惱餘處三無合 /

異共異有合彼見等諸法 /
異性無所有故不可說合 /

非唯見等法異性無所有 /

餘諸法皆同無異性可得 /

異因異有異異離異無異 /
若法從因出彼無異可得 /

若異異於異離異無所得 /
彼異不異異離異無有異 /

異中無異性不異中亦無 /
無有異性故即無彼此異 /

一法不自合異法亦不合 /

合法及合時合者悉皆無 /

從因緣和合諸法即無生 /

若從因緣生即自性有作 /

自性名作法云何當可得 /
自性無虛假離佗法所成 /

若法無自性云何見佗性 /
自性於佗性亦名為佗性 /

離自性佗性復云何有法 /
若有自佗性即諸法得成 /

有法若不成無法亦不成 /
有壞名為無世人說無體 /

若見自佗性或有體無體 /
彼則不能見如來真實義 /

世尊已成就離有亦離無 /
教授迦旃延應離有無二 /

若自性佗性或有體無體 /
自體有異性法即不可得 /

從識種子生成三有境界 /
見境界無我三有種子滅 /

若見彼異性非諸法有體 /
云何自體無異性當可得 /

言有即著常言無即斷見 /
是故有無性智者無依著 /

若法有自性非無即是常 /
先有而今無此還成斷見 /

諸行若輪轉常即無徃來 /
無常無徃來眾生亦同等 /

汝今且觀如是人諸根圓具及所行 /
又若說彼有多聞或為惡獸所食噉 /
恣佗所食為所棄過去佗身彼即無 /
不還後世無怖心應知此身唯行聚 /

人若有徃來於蘊處界中 /
五種推求無誰受徃來者 /

能取及所取無諸有徃來 /
無有即無取何有徃來者 /

彼諸行無滅此云何可有 /
眾生亦無滅復云何可有 /

諸行生滅法無縛亦無解 /
縛解若有作即縛解不生 /

若因取名縛有取即不縛 /
無取亦不縛何分位可縛 /

有眾生可縛彼縛即有體 /
縛法彼若無如調達所縛 /

若先有其縛彼縛能縛身 /
今既無所縛如去來品說 /

已縛即不縛未縛亦不縛 /
離已縛未縛縛時亦不縛 /

已縛即不解未縛亦不解 /
若縛中有解縛解即同時 /

若我滅無取我得涅槃者 /
此或有彼執還成執於取 /

不應捨生死不應立涅槃 /
有無皆成謗此說非道理 /

自能降伏心復能攝受佗 /
即有慈愛心此說降伏體 /

思及思所生大仙所說業 /
彼業有多種次第而分別 /

彼所說思者此即是意業 /
從思所生者所謂身語業 /

受用故生福施受用福生 /
非福亦復然此名受用義 /
并思為七種了知諸業法 /
身語表無表遠離不遠離 /

業住至果熟彼業即是常 /
若滅即成無云何有果生 /

若芽等相續芽等復生餘 /
種先而果後不斷亦不常 /
若不先植種果生即不能 /
因隨果法中從芽等相續 /

若心有相續心法即現轉 /
果若離於心無相續可轉 /
從心有相續從相續有果 /
業先而果後不斷亦不常 /

求法方便者是十白業道 /
此世及佗世得五欲勝果 /

若如汝所說次第而分別 /
彼有過失生其過多復大 /

今我復說此順正理分別 /
諸佛及緣覺聲聞等讚說 /
不失如契書業如所負財 /
界分別有四皆自性無記 /

見道所不斷至修道乃斷 /
是故不失法能持於業果 /

若見苦時斷彼即有過失 /
有相似業故斷即壞於業 /

一切相似法諸業有繫屬 /
諸界一法生一業一法起 /

所有二種業現非無常性 /
住至度果已如是還復生 /
或至命終滅或至度果滅 /
此無漏分別彼相亦無漏 /

雖空亦不斷生死亦不常 /
業果報不失此法佛所說 /

諸業本不生非伺察可得 /
業力心相續業果二俱壞 /

若業本不生業云何有壞 /
若其有所生彼云何不壞 /

若法有自體有業而可住 /
二世受報已彼業還復在 /

此諸業煩惱業因煩惱成 /
彼煩惱無實業云何有實 /

若說業煩惱以為身因者 /
業煩惱自空身因復何有 /

眾生無明覆愛結所縈纏 /
作作者受者不一亦不異 /

業不從緣生不從非緣生 /
見有業相違是故無作者 /

無作者作業何有業生果 /
既無實有業受者當何有 /

如佛神力化化成具足相 /
是化復起化初化名化者 /
諸法如化相作作者無作 /
說作者等體皆云何可有 /

諸法無有體如乾闥婆城 /
煩惱業及身作者果亦然 /

蘊中若有我有即生滅分 /

若異蘊有我有即非蘊相 /

若或無有我我所當何有 /
無我無我所我我所即滅 /

諸業煩惱盡即名為解脫 /
而彼業煩惱從分別中生 /
一法如是故餘法亦復然 /
無定意分別無定故差別 /

此所說想法想即心境界 /
無生亦無滅如涅槃法性 /

一切實不實

非實非不實

亦實亦不實此即諸佛教 /

若佗信寂靜無戲論所戲 /
無異無分別此即真實相 /

若法從緣有而不即是因 /
亦不異於因故非常非斷 /

無一義多義不斷亦不常 /
此諸佛世尊正法甘露句 /

正覺不出世聲聞復滅盡 /
彼緣覺正智從於猒離生 /

若現在未來因過去時者 /
彼現在未來過去時已有 /

若現在未來過去時中無 /
彼現在未來因何而可有 /

現在及未來若不因過去 /
即無彼二時不因過去故 /

若因過去時或不因過去 /

此如前所說上中下等法 /
應知無一異亦無次第轉 /

時不住無取時住亦無有 /
離時何有體異體亦無時 /

若謂眾因緣和合生果者 /
和合中有果何湏和合生 /

若謂眾因緣和合生果者 /
和合中無果云何和合生 /

若謂眾因緣和合有果者 /
和合中無取何有果可取 /

若謂眾因緣和合無果者 /
是即彼因緣與非因緣同 /

因若未與果是因先滅者 /
因滅而果生果起即無因 /

若因緣和合如是果同生 /
能生及所生亦如燈與光 /

亦非先有果然後方和合 /
生已還復生即墮一時過 /

若先無和合而有果生者 /
是即離因緣乃成無因果 /

法滅即是無壞法無別體 /
是即前生因而墮重生過 /

因生果已滅而復何有滅 /
又若因住果離果何有住 /

無彼過去因與過去果合 /
亦無未生果與已生因合 /

亦無未生因與已生果合 /
已生即不見有和合可得 /

若法無和合因何能生果 /
若法有和合因何能生果 /

因果若是空云何能生果 /
因果若不空云何能生果 /

不空即不生不空即不滅 /
以得不空故不生亦不滅 /

空即云何生空亦云何滅 /
以空故不生以空故不滅 /

因果若一性即無法可生 /
因果若異性亦無法可生 /

果自體若有因即何能生 /
果自體若無因亦何能生 /

亦非因緣成亦非自體有 /
又非和合生此何能生果 /

若因緣和合所作得成者 /
果若無集因即因緣不合 /

離成無有壞離壞亦無成 /
共成無有壞共壞亦無成 /

壞法亦如成無共離道理 /
成法亦如壞無共離道理 /

離壞若有成云何當可得 /
法體無常徧無處而不有 /

若離成有壞云何當可得 /
亦如生與死非同時而有 /

若二互共成彼二互無有 /
成壞二無故云何有成就 /

盡即無有成不盡亦無成 /
盡即無有壞不盡亦無壞 /

彼成壞二法非空故可有 /
又成壞二法非不空可有 /

此成壞二法非一性可有 /
此成壞二法亦非異性有 /

有體不生體無體不生體 /
體不生無體有無體不生 /

法不從自生云何從佗生 /
自佗既不生如所生亦然 /

滅已不復生因即墮於斷 /
若生滅相續故因果有體 /

若法住自體無法有分位 /
至涅盤時斷即諸法斷滅 /

死有若已滅取初有不然 /
死有若未滅取初有不然 /

若初有滅時而死有生者 /
滅時是一有生時是異有 /

亦無法滅時與生時和合 /
是即同所依此滅彼蘊生 /

如是此三時有相續不然 /
若無彼三時云何有相續 /
有相續若無云何有成壞 /
若無彼成壞法云何可成 /

即蘊無如來

異蘊無如來

如來無諸蘊

何處有如來

若無有自體云何有佗體 /
彼佗體既無何有人等相 /

若法因佗有彼無體可生 /
無體故無性云何有如來 /

若無有自體云何有佗體 /
離自體佗體何處有如來 /

何名未取蘊自體無別體 /
異蘊亦無取何得有如來 /

無一性異性五種求亦無 /
云何所取中施設有如來 /

此如是所取自性無所有 /
若無有自性云何有佗性 /

法無自體故能取所取空 /
及一切種空空何有如來 /

空即不可說不空亦不有 /
俱不俱亦然假施設故說 /

若不依俗諦即不說勝義 /
若不依勝義即不說涅盤 /

若法有自性見空即無益 /
諸見分別縛今此悉遮遣 /

寂滅中何有常無常等四 /
寂滅中何有邊無邊等四 /

佛種本無性一異不可說 /
不可說即無何施設可有 /

顛倒分別習無執中生執 /
若如來本無即無分別因 /

如來自體空思惟不可有 /
云何謂如來滅後有與無 /

佛已過戲論能破諸戲論 /
戲論所覆者彼不見如來 /

若以色見我以音聲求我 /
是人行邪道不能見如來 /

彼如來自體即世閒自體 /
如來體不成世間亦無體 /

寂滅中何有常無常等四 /
寂滅中何有邊無邊等四 /

因分別故起說彼貪瞋癡 /
善不善顛倒此等從緣有 /

若善不善倒從緣生貪等 /
以煩惱無性故煩惱無實 /

汝意若離我謂有諸煩惱 /
從因緣有者此煩惱悉遮 /

有身見煩惱染者亦不有 /
五種求悉無諸蘊亦不有 /

善不善顛倒彼皆無自體 /
顛倒名虛妄觀如來品說 /

善不善等法當云何可得 /
如乾闥婆城如燄亦如夢 /

若不因不善善即無施設 /
以因不善故善亦無所有 /

若不因於善不善無施設 /
以因於善故不善無所有 /

此若無有善當云何有貪 /
又若無不善云何當有瞋 /

若無常謂常此執顛倒者 /
空中無無常何有顛倒執 /

若無常謂常此執顛倒者 /
無常若成執空何非顛倒 /

能執業用境此等目性空 /
皆是寂滅相是故無有執 /

執性無有故何言邪與正 /
計無常等法而成於顛倒 /

無未生顛倒及已生顛倒 /
亦非顛倒時有顛倒生起 /

未生當云何有顛倒可得 /
顛倒若不生何處有顛倒 /

若常樂我淨此四是有者 /
彼常樂我淨是即非顛倒 /

若常樂我淨此四是無者 /
彼無常苦等是即應不有 /

若顛倒法滅如是無明滅 /
以無明滅故諸行等亦滅 /

有何法可斷此中云何斷 /
若實有自性自體無繫屬 /

若煩惱無實無故何名斷 /
離有體無體有何法可斷 /

若一切法空無生亦無滅 /
以無生滅故四聖諦亦無 /

若知及若斷修證等作用 /
如是四聖諦無體即不有 /

四聖諦若無即無四聖果 /
苦等諦若無亦無向果者 /

若無八聖人是即無僧寶 /
若無四聖諦亦即無法寶 /

若無法僧寶云何當有佛 /
若如汝所說是即破三寶 /

若因果體空即無法非法 /
世俗諸所行亦破一切法 /

諸法無自體有執非道理 /
此中佛所說空故有行相 /

諸佛依二諦為眾生說法 /
一是世俗諦二是勝義諦 /

若人不了知二諦差別法 /
彼不解真實甚深佛法義 /

若不依世俗即不說勝義 /
不得勝義故即不證涅槃 /

呪師法不成不善攝蛇毒 /
惡見壞於空其義亦如是 /

故諸佛世尊不欲為說法 /
眾生不能解以法為非法 /
於甚深空義而實不能入 /
以如是因故不壞復云何 /

汝謂我著空不空亦不有 /
以空不有故不應生毀責 /

以有空義故一切法得成 /
若不有空者一切法不成 /

汝今自有過而返謂我有 /
譬如乘馬人自忘其所乘 /

汝若見諸法皆有自體者 /
法若非因緣還成汝自見 /

因果有定性作作者亦然 /
乃至生滅等汝悉破果法 /

若從因緣生諸法即無體 /
緣亦是假名非一異可有 /

若不從緣生無少法可有 /
由從緣生故彼皆如幻士 /

若一切不空無生亦無滅 /
以無生滅故四聖諦亦無 /

若不從緣生云何當有苦 /
無常是苦義彼體無所有 /

苦體若不有云何當有集 /
是故若無集此即破於空 /

苦若有定性自性無所作 /
自體若有著此即破於滅 /

道若有定性修即不可得 /
道若是可修定性無所有 /

若彼苦與集及滅無所有 /
而滅苦道諦云何當可得 /

若苦法不生滅法云何有 /
苦自體無知彼法復云何 /

苦法不知故餘斷及作證 /
修習亦復無即無四聖諦 /

若無四聖諦即無有法寶 /
以無法僧故云何當有佛 /

不以菩提緣佛墮無緣過 /
不以佛為緣菩提還成過 /

若佛有自體無菩提可成 /
無菩薩修行亦無得果者 /

不空何所作自體所作無 /
法非法亦無果亦無所有 /

因法非法故是即有其果 /
法非法若生不空何有果 /

汝亦破世間一切所行相 /
以破空義故復壞於緣生 /

若破於空義即無法可作 /
此何能發起無作有作者 /

世閒眾物類老少等變異 /
若自體不滅有定性為常 /

若見緣生義見非見相應 /
即能見苦集滅道諦亦然 /

若一切法空無生亦無滅 /
無斷無所證云何成涅槃 /

若一切不空無生亦無滅 /
無斷無所證云何成涅槃 /

無退亦無得不斷亦不常 /
不滅亦不生此說為涅槃 /

若涅槃有體即墮老死相 /
涅槃非老死而無老死法 /

若涅槃有體涅槃即有為 /
此乃無有法而是無為者 /

若涅槃有體云何名無取 /
若法體是有何法無取邪 /

若涅槃有體無體當何有 /
涅槃有體故無無體可成 /

若涅槃無體云何名無取 /
非無體可有涅槃即無取 /

有體有生死即有往來相 /
因彼無取故即說為涅槃 /

佛大師所說斷有及非有 /
勝義無無體此即成涅槃 /

若有無二法共成涅槃者 /
彼有無二法解脫性不成 /

涅槃有無成云何得無取 /
而彼有無相二因取故成 /

若有無二法共成涅槃者 /
涅槃是無為有無是有為 /

若有無二法共成涅槃者 /
彼二非一處如明暗不俱 /

非非有非無而成於涅槃 /
彼有無二法無能成所成 /

若非有非無而成涅槃者 /
此有何可說亦有何可取 /

如來涅槃後不說有與無 /
俱有及俱非如來悉不說 /

非生死涅槃有少法差別 /
涅槃與生死亦無少差別 /

實際涅槃際空際生死際 /
非彼二中閒有毫釐差別 /

依止於涅槃先際及後際 /
說常等邊等有無等諸見 /

若諸法皆空何有邊無邊 /
亦有亦無邊非有非無邊 /

何一性異性何有常無常 /
亦常亦無常非常非無常 /

諸所得皆寂遠離諸嬈惱 /
無我無所成諸法無所得 /

眾生無明覆後復起三行 /
由三行造業生人等諸趣 /

以行為因故而取著於識 /
由著彼識故增長於名色 /

由名色增故而生於六處 /
六處隨起觸所生如次說 /

因眼及與色與名色為緣 /
如是法和合是故識生起 /

由眼色識三故能生於觸 /
從觸復起受此受相三種 /

因受起於愛以受故愛生 /
從愛生於取所取有四種 /

因取故有有謂取者有故 /
若無取解脫是故無彼有 /

有者謂五蘊從蘊故起生 /
生故有老死及憂悲苦等 /

諸憂悲苦惱皆從生所起 /
如是即唯有一大苦蘊生 /

此無明及行為生死根本 /
智者於無明而不見有體 /

若無明息滅諸行亦復滅 /
無明行滅故智者如是修 /

滅法對治生即真實所轉 /
此一大苦蘊如是苦皆滅 /

## 觀諸見品第二十七

復有人言勝義諦中有眾生相續是見處故此非不有相續所起是故今此自體相續皆如夢等。

論者言如汝所說有其相續是見處者此非道理如下頌言。

釋曰今此如是即起世閒常等諸見謂世閒常世閒無常亦常亦無常非常非無常如是諸見因見世蘊依過去起今此所說過去世者名為先際。

次下頌言。

釋曰於未來世為有起邪為無起邪亦有亦無非有非無邪如是即起邊等諸見謂世閒有邊世閒無邊亦有邊亦無邊非有邊非無邊如是諸見因見世蘊依未來起此說未來名為後際。

論者言此言有者非勝義諦謂勝義諦中諸見皆空復云何有故下頌文證成此義。

釋曰何所以邪此中所言謂過去世即非今世以無勤力而可成故又時世別故別業生故如數論師言彼過去世即今世者此非道理汝宗大諦神我過去世者非今世有何以故無差別故若無差別即因果不異是義不成一切因喻而悉無體諸所成法時非時處因相不住亦非同時而有所成是義顯明又復此中二法不和合故若言因果無別異者即自體中而有遮遣云何體中故遮異性而言不異此復云何若自體中有所遮遣如是應有樂苦癡性所成和合若尒應汝最初本所成法即是樂苦癡性無別何以故性無別故若樂苦癡無別異者汝最初諦何故所成而各異邪又復何故汝宗樂等及大諦等神我等中諸根大種各有自體彼大諦等各各有果既容別異如是即應果起果成是義亦容互相長養故知樂等及大諦等各有自體以彼樂等有因和合故且非同時所成法中何等有因何等無因如是知者所作如理若汝意謂樂等法中諸樂等因此有異者彼樂等果亦即有異故非因果二法無別若無別者即彼如是所起之果而無道理何以故因果無異故又差別諸因自體若一即差別果自體不成以果所成諸差別法有多種體一果不生故云何汝宗彼薩埵等自性互相於果法中能建立邪為離互相長養性故何以故而彼互相長養法中無所生故此中云何如前所說大諦等法如是長養即有次第若一種法一種功用離自力能而亦互相不得成故以互長養彼無體故若尒即應如是同生我及大等於是時中生成果義諸長養等如前所說悉無體故如是樂等及彼地等次第同生俱無長養又復如前彼地等法及薩埵等緫集諸體同一住持有所行故同時成辦故若尒即是地等諸法互相長養乃至決定所作事用於和合中不有和合所成之義謂彼無體故長養亦無體若離長養所成果法不能建立由如是故若如所說悉不能立如汝所說薩埵之言與彼囉闍怛摩二法開示所行乃有相違何以故謂薩埵功用不能長養彼二法故決定所行皆不有故若囉闍摩開示所行二法決定而不有者如是果起果成於自體中皆悉遮遣異法和合於自體中悉亦遮遣而不成故如是即應樂苦癡果亦無別異何以故樂苦癡果說有異故如是亦應大諦神我果體有過謂以樂苦癡法因果無異如是因果二法無體豈得和合若法一處無別異者即如是處決定所作而無因果不有異性故此乃因義不成一切事用一切所成此有何義是中云何薩埵自體有其事用及一切果又復何名有一切事一切自體如是有者即是有因及有果法若謂因果是一體者諸有縛因即是解因如是有智即是無智如是起相即是坐相如是善趣因即是惡趣因由如是故是即無彼因果可見又復亦應無縛無解此等皆如諸處廣說即於如來阿含等中一切無體又此色依分位大無義利是故一切事用一切所成悉不和合亦無一切事用一切果體各別決定因果二法和合相續於諸事用果體亦無所證由是因故因果差別無異相續而可起故所言一切者此說即是詮表之義於詮表中亦非無異而有所成若或各別決定境界諸根作用皆寂止者汝宗大諦神我等法亦應不定無因果體故時處因相皆無果利悉已遮故於一切事一切所成徧一切處若或有者此復何義亦非同時有法所成是義顯明若復異體不有果者即一切事用悉無所得此義既明前所遮遣悉非道理。

或有人言身雖有異而我是一以有我故過去世中有我可得此說畢竟如是決定取差別故此說有取是故有我別異所成。

論者言取有別者此無差別何以故或謂決定異取有我者下頌遣言。

釋曰亦非有蘊既變壞已我復有成所言有者謂成就義由取故有我以有我故即有我所此即二種分別建立第三分別而復無體彼法體者取不即我謂積集故如外物體亦非別異諸有法體所作壞已而復有來何以故若取有所得云何有其作者作業二法差別是故無因有我可得此中如是廣說證成亦非無我但為遮遣我故乃說無我。

復次頌言。

釋曰如佛所言我若無體即於苦樂悉得捨離由是乃於善趣解脫今此遮遣我語取故。

復次頌言。

釋曰何故不可得邪謂所取中無能取義離差別相故若離能取亦無所取謂以離取無異取故。

復次頌言。

復次頌言。

釋曰今此證成復何義邪。

次下頌言。

釋曰若離於此有異可成即離於彼亦異可成何以故若此世異彼有所起者即彼如是有生無死謂前世有死此世有生前若無死此亦無生以前世死是此世生。

復有人言或別異法有別異性彼法雖壞相續得成。

論者言先世我體若已斷者與此相違何以故諸業壞故又此人造因彼人受果造因者異受果者異此如是等皆有過失。

復次頌言。

釋曰若異作異受此非道理何所以邪下頌荅言。

釋曰謂由先有所積集故。

復次頌言。

釋曰如其所說審諦觀察乃以多種開示其義今此遮遣依止未來而起諸見未來有我或無我邪如是諸見皆同過去然後一性異性俱不俱等此中皆止此復云何故下頌言。

釋曰如是有法此即不生以天有故所以者何若法有生即無其常是故未來世中不見有我亦不見無我此俱有過。

復次頌言。

釋曰若人身生即天身壞此云何有以異性故如提婆達多與演若達多二蘊各異於異性中即不見有相續可得。

復有人言亦有天身亦有人身。

故頌遣言。

釋曰若如是有亦天亦人者彼有過失是即半身有所成故。

復有人言此中非常非無常是可有邪。

故頌遣言。

釋曰今此遮遣所說成義此中意者即彼如是轉復難解何以故若天界人界何有所來若天若人亦復有其何趣可去若或有其天等同分我即無始而乃有常非有一法來去可成所有眾生及補特伽羅如前所說悉已遮止是故此中所說亦無常法可得以非道理故無有常故又復常法無對待因故是故無常不能有成又復離彼常無常法復有何法而得起邪。

復次頌言。

復次頌言。

釋曰言有邊者譬如世閒焚燒種子不復有其相續和合是故亦無後世可有言無邊者亦無種類所作果故是故邊無邊二而悉不有。

復次頌言。

釋曰此復云何若先蘊已壞不因是蘊後蘊復生此即說為世閒有邊謂諸蘊已滅無和合故若先蘊不壞亦不因是蘊後蘊不生此即說為世閒無邊謂以先蘊一切分位二俱不見是故世閒有邊無邊此皆不有。

復次頌言。

釋曰若我是一亦不可得此復云何。

故頌遣言。

釋曰壞及不壞各一分者皆非道理。

此中意者若言二分亦悉止遣。

復有人言非有邊非無邊應可有邪。

故頌荅言。

釋曰此中何故湏止遣邪謂若有所得即有過失其或無者又復云何如是若有決定所得此即離於中論所說若或無所得者云何於彼實不實法中有遮遣邪若汝所樂乃至眾生有所得者即非中論所說有相違故由此應知世俗諦中即有所得勝義諦中一切遮遣雖言無所得於佗所得亦容有成非悉遮遣謂於和合有相違故若尒即於比量而不相違但於勝義諦分各別遮遣有所得故世俗法中非離所作謂與世俗一向義邊諸緣生法不相違故若謂定實有所得者亦非道理何以故見量相違故此中應問若尒於有分中豈不相違荅見量無所得故此無過失是故應知諸言自者皆見量攝此即是為不顛倒說此復云何能了知邪謂於二中若了不二即無虛誑若於見量比量法中了達見量比量之義是為正說於諸分位中若微細若廣多一切義門得決定見量者彼見量智於一切因及彼一切世俗法中無不了達然於一切以見量所證皆如夢幻如乾闥婆城等若於一切不如實義中皆非見量此說正理若於形顯色等所取相中先所慣習諸思念事於夢所見此等皆如盲人觀色由此應知世閒一切此彼所取皆如夢中昔慣習事及睡眠人慣習思念有何差別但從徃昔習念而有沉於夢寐覺已即無世閒一切悉無所得於見生中有所得相起分別者皆如夢等若於夢中所見色像此亦非無又過去生中已起別異一切色像與見生中夢中起者而各有異不和合故如三摩地所生大種所成三摩地境界此相似者形顯色等所成亦然是故一切境界無實皆是夢中意識所起此即比量之名如比量義而不相違此如是等廣說證成如來決定一切所說無不和合是故世俗勝義一切所說於彼世俗勝義諦中俱不相違今此應知諸見不生下頌所說如是證成。

釋曰此中亦無諸見所起一切境界作者作業此等諸法皆是無生如是一切種種分別所生諸見起多種苦及多種類若能了知無種類已普徧世閒起大悲心皆如親友緫結頌曰。

過去世有我或無我等四 /
是我等諸見依過去世起 /

又於未來世我不見有起 /

彼過去世我非今世可有 /

若或離於取復何有我邪 /
又復離於取無處有所作 /

取不即是我此義已證成 /
我謂自主宰他主宰何有 /

若復異於取我亦不可得 /
能取所取取此皆無異取 /

如所說正理我不即是取 /
我不異於取亦不決定無 /

過去世有我非今世可得 /
過去世無我亦非今可得 /

今世過去世無別異可得 /
若此有別異見世緣不成 /

若先世造業後世當受果 /
此若無所生是中有過失 /

我本造作成無體亦如瓶 /
煩惱業因空所生無因故 /

過去起是見我為有為無 /
此二俱不俱是皆無所有 /

若天即是人天有乃為常 /
此有即不生天有是常故 /

若天與人異異即成無常 /
天與人異故相續無所有 /

若天是一分人亦是一分 /
即常無常二成一處不然 /

若常與無常是二可成者 /
非常非無常隨所欲應成 /

依先際所起常等四見無 /
後邊等四見伺察亦皆無 /

若世閒有邊云何有後世 /
若世閒無邊云何有後世 /

此諸蘊相續如世然燈燄 /
以是故世閒邊無邊不然 /

若一分有邊若一分無邊 /
邊無邊共有世閒非道理 /

云何一取者一分是有壞 /
云何一所取一分是不壞 /

若有邊無邊是二可成者 /
非有非無邊隨所欲應成 /

當知一切法常等皆空性 /
何人以何緣何處生是見 /

佛為世閒斷諸見宣說一切微妙法 /
起悲愍心利眾生稽首瞿曇大聖主 /

甲辰歲高麗國大藏都監奉彫造𠡠
