# 成就梦想法 · 第一卷

> 唐 不空述

## 1

我今披见秘藏要文，有成就梦想法，为末世众生故，说是次第仪则。于净室中作一方坛，随意大小，其坛中办备供物，谓香花、油灯、饮食、菓子、苏蜜、欢喜团等，如是种种不可具说，随时取新者用之。

次说劝请法曰：

次说大钩召呪曰：内缚右风招之

归命恶萨缚怛罗钵罗底贺帝怛他誐党矩奢地淅哩也钵哩布罗迦耶娑婆贺。󰂛引

若有众生诵此呪时，一切圣众、天龙、鬼神皆随喜来诣。

复次，说成就好梦法，礼北方而作是念言：

复次说真言曰：

唵，阿，味，罗吽，佉，左。引引入恶声引引𠸪

若有众生得见好梦不得成就者，由此教法念文殊师利菩萨及妙幢菩萨等，若卧时诵一百八遍，常得好梦能知善恶之事。若有人得吉梦欲成就者，加持饮食七遍，食者不久得成就，唯除思梦忙想来梦也。

复次，谁思除灭恶梦法，礼北斗方而作是念言：

复次说真言曰：

唵，瑟置哩，迦攞噜，跛吽欠，萨婆呵。二合二合

若有善男子、善女人等，得见恶梦不祥出现者，以命木作人形，书彼那么加持七遍，三日终竟，彼人形置山野及大河边，不祥消灭，心神安乐。若有人常得吉梦，如是不修行者，不得久成就，乃至消灭。虽见恶梦，如是修行者，不应还成吉事。又取白线作索，呪二十一结系身，出入三度，恶梦不应。

复次，说供养真言曰：金刚合掌二风宝形

唵阿谟佉。布惹么柅。跛纳么。婆曰。怛他蘖多。尾路枳帝。三满多。钵罗萨罗。吽。𭭳

若有众生诵此真言，供养三宝时，流出无量供养云海，供养一切圣众。

复次，说施食呪曰：右手以空摩火甲三两反，余三指直之，又空风弹指作声，一诵一弹七返

囊莫萨缚。怛他蘖哆。缚噜枳帝。唵。三婆罗。三婆罗吽。

若有人以此呪加持饮食，施与一切天、龙、药叉、罗刹娑等，山王、海王、河王、大树王，一切诸鬼神等，各各皆得摩伽陀国所用斗七七斛食，皆悉饱满。

次发遣颂曰：

我今劝请佛眼尊，文殊玅幢诸眷属， /
北斗七曜九执等，二十八宿十二宫。 /
十二天王二六神，诸龙药叉罗刹等， /
山王河王大树王，所有十方大善神， /
不越劝请净心力，降临影向受玅具。 /
护持某甲除不祥，成就好梦与诸愿。 /

我今归依佛法僧，文殊玅幢北斗星， /
十二天王诸星宿，知见吉梦成所愿。 /

我今归依佛法僧，文殊玅幢北斗星， /
十二天王诸星宿，愿除恶梦得善事。 /

唯愿圣众，并诸眷属，加持某甲， /
还归大宫。

保延六年正月十八日书写之移点了。

嘉禄元年六月三日，奉随日光房僧都御房于堀川坛所奉受了，圆俊记之。

文永元年六月二十八日，奉写之繁承记。

同七月十一日，奉从修月房僧都御房奉受云了。繁承。
