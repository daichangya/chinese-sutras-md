# 律苑事規 · 第十卷

> 元 省悟編述　嗣良參訂

---

降伏魔力怨除結盡無餘露地擊犍稚 /
比丘聞當集諸欲聞法人度流生死海 /
聞此妙響音盡當雲集此 /

持戒清淨如滿月身口皎潔無瑕穢 /
大眾和合無違諍爾乃可得同結界 /

散花莊嚴淨光明莊嚴寶花以為帳 /
散眾寶花遍十方供養一切諸如來 /

戒香定香解脫香光明雲臺遍法界 /
供艱一切無量佛見聞普薰證寂滅 /

諸佛出世第一快聞法奉行安穩快 /
大眾和合寂滅快眾生離苦安樂快 /

流轉三界中恩愛不能脫棄恩入無為 /
真實報恩者

善哉大丈夫能了世無常捨俗趣泥洹 /
希有難思議

歸依大世尊能度三有苦亦願諸眾生 /
普入無為樂

毀形守志節割愛無所親棄家弘聖道 /
願度一切人出度人經

大哉解脫服無相福田衣披奉如戒行 /
廣度諸眾生

遇哉值佛者何人誰不喜福願與時會 /
我今獲法利

八功德水淨諸塵盥掌去垢心無染 /
執持禁戒無缺犯一切眾生亦如是 /

香湯熏沐澡諸垢法身具足五分充 /
般若圓照解脫滿群生同會法界融 /

羅漢聖僧眾凡夫眾和合香湯浴淨籌 /
布薩度眾生

金剛無礙解脫籌難得難遇如今果 /
我今頂戴歡喜受一切眾生亦如是 /

具足清淨受此籌具足清淨還此籌 /
堅固喜捨無缺犯一切眾生亦如是 /

清淨如滿月清淨得布薩身口業清淨 /
爾乃應布薩

稽首禮諸佛及法比丘僧今演毗尼法 /
令正法久住優波離為首及餘身證者 /
令說戒要義諸賢咸共听 /

一切恭敬自歸依佛當願眾生 / 打引眾拜
體解大道發無上心 / 引一下眾起立槌一下云

自歸依法當願眾生深入經藏打引眾拜 /
智惠如海自歸依僧打引眾立槌一下云打引眾拜 /

當願眾生統理大眾上來布薩無限勝因 /
散沾法界和南聖眾 / 引二下

瑤光貫月赤光高仙侶排空奏玉簫 /
梵壽如來添祿筭九天王母進幡桃 /

聖誕今朝瑞氣多歡呼萬歲滿山河 /
大恩大德充天地鳶自翔雲魚躍波 /

一月在天影涵眾水一佛出世各坐一花 /
白毫舒而三界明甘露洒而四生潤 /

我今灌沐諸如來淨智莊嚴功德聚 /
五濁眾生令離垢同證如來淨法身 /

淨法界身本無出沒大悲願力示有去來 /

法正為初二法時三聰四覆五光隨 /
六雲洪七八智首九祖南山皆聖師 /

日亦然兮夜亦然睡時宜後起宜先 /
殿堂禮誦候開靜動止回施向左肩 / 一

晨朝洗面莫猖狂盥漱低頭少使湯 /
頭若痒時須待浴手巾乾淨不相妨 / 二

寫字吟詩遣睡魔不須將此當嘍囉 /
南山教觀多玄旨好把工夫去琢磨 / 三

寂靜身心展鉢時出宜先筯入先匙 /
食巾収摺須臨後左右和南禮莫虧 / 四

粥了和南齋了茶說文習讀莫喧譁 /
出堂入戶清規合要見叢林有作家 / 五

說恣差僧行事時從規自合具威儀 /
近來一輩無羞恥直裰中間小袖兒 / 六

誦文鬮出不尋常莫教無聲靜法堂 /
賞物雖無猶自可僧前罰拜最難當 / 七

脫著衣衫貴整齊掩門須緩放籌仾 /
密持呪語輕彈指淨讀常將右手提 / 八

入浴披衫貴靖恭需湯擊板合從容 /
不應脚布安槽上双脚如何著桶中 / 九

負笈尋師號學人業精名遂在乎勤 /
秋堂雨後凉生夜誰解明燈照祖父 / 十

## No. 1113-D

古人云業精于勤荒于嬉今之人少有自勤非策而勤之則不能精于業也古來學肆春秋長講令止於夏中以了故事制後三日祈禱畢四日齋前住持啟講又三日首座宜啟晚講五日初去便乃習讀掛習講牌於法堂每至參前上殿後住持令行者打靜鐘三下至昏黃時學子提灯至法堂而與科目者各宜努刀西堂耆舊亦當與席作成叢林也直日侍者送引子與維那唱二火後住持至法堂就座維那鳴引二下使眾寂然無聲喝三後維那鳴引二下直日侍者至維那前問訊取覆講盛鬮合子安住持机上住持問訊了開鬮合住持信手混括一鬮付與直日展開呈住持了高聲喝云却將拈出之鬮以示覆人了仍入鬮合中還置維那前而堂司行者將燭二條置覆講人前卓上覆人却覆本日住持所講之文不可覆以次人講預宜研精覃思說驚人語使眾悚听而荒怠者寧不知愧覆畢維那鳴引二下直日再至維那前取引科鬮合至住持前。有處堂賓二司每夜輪行湯茶某甲侍者覆講有處併將引科策文二鬮一道拈定對眾白之次第而出
