# 经分别(第5卷-第15卷) · 第十五卷

> 通妙译

---

归命彼世尊应供等正觉 /

当言善爱语切勿语不善 /
为言爱语者牛即曳重载 /
彼亦得财宝由此皆欢喜 /

妄语．骂．离间句．宿之二种 /
除有智者外实有．粗罪．掘 /

草木与异语讥嫌并出时 /
彼之二戒者先来及拖出 /
脱脚床坐卧门窗有虫水 /

心高无放逸智慧学圣人 /
常念心寂静苦恼不复存 /

不选任．日没尼处．利与衣 /
缝衣及公路船．取食．独十 /

施食．别众．数饼．足食有二 /
非时．蓄藏．乳杨枝此十事 /

饼．语．跋难陀等三以及个别特信家 /
摩诃男与波斯匿军．射此等以为十 /

饮酒与指．水轻侮．恐怖．火 /
沐浴及坏色不还与．藏之 /

故意杀．虫及发诤覆藏粗罪．未二十 /
贼队．豫约．阿利咤被举．骞荼十学处 /

如法．诽谤与无知打．举手以及无根 /
故意．屏听与不平同意．沓婆并转施 /

王．宝物．同住针筒与卧床 /
绵．坐具．疥疮雨衣及佛衣 /

不知圣典义此教咒文者 /
不法学习者俱是不见法 /

我为嗜好肉味香来食王之美味饭 /
为食不说我之法〔但知我〕法圣者赞 /

如此可耻婆罗门为彼之财与名利 /
〔于是现世〕不法行此为〔来世〕堕狱因 /
离去矣大婆罗门他有情亦以煮食 /
汝之行此不法行〔汝〕勿碎如碎石瓶 /

归命彼世尊应供等正觉 /

所得应满足过欲实为恶 /
以捉白鸟王汝等黄金失 /

## （二）

诸大姊！今诵出此七灭诤法。

每诤论生起为止静而灭除之——

诸大姊！七灭诤法已诵竟。于此，我今……知解。

诸大姊！已诵出因缘、已诵出八波罗夷法、已诵出十七僧残法、已诵出三十舍堕法、已诵出百六十六波逸提法、已诵出八提舍尼法、已诵出众学法、已诵出七灭诤法。凡是已收入佛之戒经，正确含摄于戒经者，尽于每半月诵出，由此一切和合、欢喜、无诤而修学之。

应与现前毘尼、

应与忆念毘尼、

应与不痴毘尼、

应作自言治、

多人语、

觅罪相、

如草覆地。
