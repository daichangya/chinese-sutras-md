## 因缘心论颂

〔题解〕

《因缘心论颂》，印度大乘佛教中观学派典籍，龙树撰，一卷。

本文献作者龙树，又译龙猛，是大乘佛教鼻祖，印度大乘佛教中观学派的创始人，有第二佛陀之称。生存年代约公元150年～250年。龙树著述颇丰，有「千部论主」之称。其代表作是《中论》、《十二门论》、《大毗婆沙论》、《大智度论》等，《因缘心论颂》也是其重要著作之一。是研究龙树及其大乘中观学说的重要资料。

本文献全文共140字，篇幅虽短，立论精要。以颂文的形式论述了佛教的基本理论「缘起论」，以及作者站在大乘空宗的立场上对缘起论的新的阐释。本文献未为我国历代大藏经所收，近代在敦煌发现后，被收录于《大正藏》第三十二卷第一六五四部。但由于仅用了两个本子（斯1358号和斯2462号），且错讹较多，因此有必要进行重新整理。同时，为了尽可能地避免错误，整理者将《因缘心论颂》、《因缘心论释》和《因缘心释论开决记》三篇文献作了仔细地对勘，具体情况随文说明。

整理本的底、校本情况如下：

底本：中国北京图书馆藏北7257（海17）号。

校本：甲本，中国北京图书馆藏北7255（官68）号。

乙本，斯1358号。

丙本，伯4645号。

丁本，斯250号。

戊本，斯4235号。

己本，北469（雨55）号。

差别十二支，能仁说缘生， /
于烦恼业苦，三中俱摄尽。 /
初八九烦恼，二及十是业， /
余七皆是苦，十二唯三摄。 /
从三生于二，从二生于七， /
七复生于三，此有轮数转。 /
诸趣唯因果，此中无众生，
唯从于空法，还生于空法。 /
诵灯镜及印，火精种梅声， /
诸蕴相续结，不移智应察。 /
于甚微细事，若有见断者， /
彼不善因缘，未见缘生义。 /
此中无可遣，亦无少安立， /
于真以观真，见真而解脱。 /
