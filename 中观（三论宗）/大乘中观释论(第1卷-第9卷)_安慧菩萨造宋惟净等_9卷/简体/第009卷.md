# 大乘中观释论(第1卷-第9卷) · 第九卷

> 安慧菩萨造  宋 惟净等译

「不灭亦不生，不断亦不常等。」 /

「我稽首礼佛，诸说中第一。」 /

「诸法不自生。」

「亦不从他生。」

「共生亦无性。」

「亦不无因生。」

「如诸法自性，不在于缘中。」 /

「以无自性故，他性亦复无。」 /

「亦非缘生果。」

「果不从缘有，有无果生止； /
若说生法时，无依无所生。」 /

「果不从缘生，此果缘中生。」 /

「果若别异解，无道理可依； /
若一法作成，果体不可立。」 /

「非无缘有果，无缘果亦无； /
如是世俗中，常性不可得。」 /

「非有亦非无，缘义和合尔。」 /

「诸法无自性，非有亦非无。」 /

「于此无缘法，云何有缘缘？」 /

「若法未生时，即不应有灭。 /
灭法何能缘？故无次第缘。」 /

「诸法无自性，非有亦非无； /
此有彼法起，如是无所有。」 /

「若谓缘无果，果从缘中出； /
是果何不从，非缘中而出？」 /

「若果从缘生。」

「是缘无自性。」

「从无自性生，何得从缘生？」 /

「如衣因所成，能成因别异； /
成法若自无，别异因何有？」 /

「果不从缘生，不从非缘生， /
以果无有故，缘非缘亦无。」 /

「已去无有去。」

「未去亦无去。」

「离已去未去，去时亦无去。」 /

「动处则有去，此中有去时。」 /

「非已去未去。」

「是故去时去。」

「云何于去时，而当有去法？ /
以离于去法，去时不可得。」 /

「若去时有去，则有二种去： /
一谓有去时，二谓去时去。」 /

「若有二去法，即有二去者。」 /

「以离于去者，去法不可得。」 /

「若离于去者，去法不可得。」 /

「去者即不去。」

「不去者不去。」

「离去不去者，无第三去者。」 /

「若言去者去，云何有此义？」 /

「若离于去法，去者不可得。」 /

「去法若欲去，非无去者去。」 /

「已去中无发。」

「未去中无发。」

「离已去未去，去时中无发。」 /

「去未去去时，云何有分别？」 /

「去者即不住。」

「不去者不住。」

「离去不去者，何有第三住？」 /

「去者若当住，云何有此义？ /
以离于去法，去者不可得。」 /

「去未去去时，止息诸分别。」 /

「所有行止法，皆同去义说。」 /

「去法即去者，是事则不然。」 /

「若谓于去法，即为是去者； /
作者及作业，即一性可立。」 /

「去法异去者，是事亦不然。」 /

「因去知去者，不能用是去。」 /

「先无有去法，故无去者去。」 /

「因去知去者，不能用异去； /
于一去者中，不有二去故。」 /

「若实有去法，去者不用三； /
不实有去法，去者不用三。」 /

「去法有不有，去者不用三。」 /

「是故去去者、所去处皆无。」 /

「见闻及嗅尝，触知等六根， /
此见等六根，说能取诸境。」 /

「是眼即不能，自见于己体。」 /

「若不能自见，云何能见他？」 /

「火喻即不能，成于眼见法。」 /

「去未去去时，前已答是事。」 /

「见若未见时，即不名为见。」 /

「若言能所见，此云何和合？」 /

「能见亦不见，见法无性故。」 /

「所见亦不见，见法离性故。」 /

「离见不离见，见者不可得。」 /

「以无见者故，云何有所见？」 /

「见可见无故，识等四法无。」 /

「四取等诸缘，云何当得有？」 /

「闻嗅味触知，如是等诸根， /
而悉同于上，眼见法中说。」 /

「若离于色因，色即不可得。」 /

「离色因有色，色则堕无因； /
无因无有义，何法无因立？」 /

「若复离于色，有其色因者， /
即是无果因；无果因何立？」 /

「若已有色者，色因无所起； /
若无有色者，亦不用色因。」 /

「无因而有色，是事亦不然。」 /

「是故于色中，离有无分别。」 /

「果若似于因，此说即不然。」 /

「果若不似因，是事亦不然。」 /

「所有受心想，诸行一切种， /
及余一切法，皆同色法说。」 /

「彼一切诸法，皆同色法说； /
若诤论安立，随所起即空。」 /

「一切不离空，一切得成就。」 /

「若见一物性，一切法亦然； /
若解一法空，一切皆空故。 /
言说有所得，诸所作皆空； /
一切无所得，一切皆成就。」 /

「空相未有时，先无彼虚空。」 /

「云何无相中，彼有相可得？」 /

「无实相无体，云何相可转？」 /

「于无相法中，相则无所相。」 /

「离有相无相，无异处可转。」 /

「所相既无体，能相亦不立。」 /

「能相无有故，亦无有所相。」 /

「是故无能相，亦无有所相。」 /

「离所相能相，亦无有别相。」 /

「若使无有有，云何当有无？」 /

「有无既已无，谁为知解者？」 /

「非有体无体，无能相所相。」 /

「遣有言无性，亦不取无性； /
如说青非青，不欲成其白。」 /

「见有性无性，彼即少智慧； /
无真实微妙，圣慧眼开生。 /
虽观于诸性，当寂止诸见； /
此即胜义谛，远离一切见。」 /

「若先有染者，后有其染法； /
云何离染法，而有染者生？」 /

「有染者复染，云何当可得？」 /

「若有若无染，染者亦复然。」 /

「染者先有染，离染者染成。」 /

「有染复染者，亦云何当得？」 /

「如是若同生，亦复非道理； /
染法染者二，此当云何用？」 /

「彼染法染者，非一性有合。」 /

「异性若有合，云何当可得？」 /

「若一性可合，离伴亦应合。」 /

「异性若有合，离伴亦应合。」 /

「若异性有合，染染者何用？」 /

「若染染者二，各各自体成； /
是二若有合，前亦应得合。」 /

「异相不成合，汝欲求成合； /
合相若已成，复欲成其异。」 /

「如是染染者，非合不合成； /
诸法亦如染，非合不合成。」 /

「若生是有为，即应有三相。」 /

「若生是无为，不作有为相。」 /

「生等三法离，即无相业用。」 /

「住何有灭相？无常何有住？ /
若先有住法，后不复应有。 /
若常有无常，有住不有常； /
或先有其常，后即不有常。 /
无常与住同，若有其体者， /
有常即邪妄，或有住亦妄。」 /

「不于一时中，生住灭和合。」 /

「生住灭诸相，别有有为相； /
有即是无穷，无即非有为。」 /

「生生之所生，唯生于本生； /
本生之所生，复生于生生。」 /

「若谓是生生，能生于本生； /
生生从本生，何能生本生？」 /

「若谓是本生，能生于生生； /
本生从彼生，何能生生生？」 /

「若谓生生时，能生本生者； /
生生若未生，何能生本生？」 /

「如灯能自照，亦能照于他； /
彼生法亦然，自生复生他。」 /

「灯中自无暗，住处亦无暗， /
破暗乃名照，无暗即无照。」 /

「无少处可照，是灯何能照？ /
生亦无少分，生法可成就。」 /

「云何灯生时，而能破于暗？ /
彼灯初生时，不能及于暗。」 /

「灯若不到暗，而能破暗者； /
灯在于此间，应破一切暗。」 /

「若灯能自照，亦能照他者； /
暗亦于自他，暗蔽定无疑。」 /

「生法若未生，自体不能生。」 /

「生法若已生，生已复何生？」 /

「非已生未生，生时亦不生。」 /

「去未去去时，前品此已说。」 /

「若生时有生，彼生相已破。」 /

「云何生时生，而说为缘起？」 /

「若法众缘生，彼自性寂灭。」 /

「是故生时生，如是皆寂灭。」 /

「若法未生时，如瓶等何有？ /
缘法假和合，生已复何生？」 /

「若生时有生，是即有所生？ /
诸生性如幻，此生复谁生？」 /

「若生已复生，是生即无穷。」 /

「若无生而生，法皆如是生。」 /

「有法不应生，无亦非道理； /
有无俱不然，前品此已说。」 /

「若灭时有生，无体而可得。」 /

「若法不灭时，彼体不可得。」 /

「未住体不住，住不住相违； /
住住时不住，此复何有住？」 /

「若灭时有住，彼无体可得； /
住灭二相违，住位中无灭。」 /

「诸法于常时，皆有老死相。」 /

「而有何等法，离老死有住？」 /

「住不自相住，异住非道理； /
如生不自生，亦不从他生。」 /

「此住若未住，住体云何立？ /
此住若已住，复何住可成？ /
若已住更住，此住即无穷； /
若或无住住，法皆如是住。」 /

「已灭法不灭，未灭法灭空。」 /

「彼灭时亦然，无生何有灭？」 /

「此分位定住，先分位显明。」 /

「异分位定住，先分位已灭。」 /

「如彼一切法，生相不可得； /
即此一切法，灭亦不可得。」 /

「若法是有者，灭即不可得； /
不可于一处，有有无二性。」 /

「无法即无果，灭亦不可得； /
如无第二头，不可言其断。」 /

「法不自体灭，他体亦不灭； /
如生不自生，他体亦不生。 /
此灭若未灭，自体可能灭； /
此灭若已灭，灭已复何灭？ /
是灭若有异，灭即是无穷； /
灭若无所灭，法皆如是灭。」 /

「生住灭不成，即无有为法； /
有为法不成，何得有无为？」 /

「如梦亦如幻，如干闼婆城， /
所说生住灭，其相亦如是。」 /

「老亦不离老，老时无所有； /
此性老不成，异性亦如是。 /
是故一法中，老即不可得； /
老老而无老，非自体他体。 /
此老不自老，一切老亦然， /
老若有别异，老即是无穷。 /
解脱出离道，自具足亦然， /
若法离自相，果亦不可得。」 /

「已脱不可说，未脱不可说， /
脱未脱无说，脱时亦无说。 /
此解脱若异，解脱即无穷； /
若无脱而脱，皆如是解脱。」 /

「色法如聚沫，受即如浮泡， /
想同阳焰生，行如芭蕉相， /
识如彼幻法，显示所立法， /
如梦如影像，亦同于响应。」 /

「应修善法行，勿修恶法行； /
修善法行人，二世安乐寂。」 /

「作者若有实，亦不作实业。」 /

「实所作无故，无所作差别。」 /

「有业无作者。」

「无实所作故。」

「有作者无业。」

「作者亦无实。」

「若实有作者，亦实有作业； /
作者及作业，二俱堕无因。」 /

「若有果无因，因即非道理。」 /

「作作者无体，作用不和合。」 /

「若无法非法，所作等无体。」 /

「法非法无故，从生果亦无。」 /

「无果无解脱，亦无生天道； /
非唯生天道，解脱道亦无。」 /

「作者实不实，亦不作二业； /
有无互相违，一处即无二。」 /

「作作者作用，所作实非实； /
着即生过失，此因如先说。」 /

「所作实不实，亦实亦不实； /
作者及作业，此因如先说。 /
作者诸所作，非实非不实； /
应知业亦然，此因如先说。 /
实所作即无，不实又无因； /
有无互相违，一处何有二？」 /

「因作者有业，因业有作者。」 /

「世俗遣异性，我见成就相。」 /

「若胜义谛中，有作者作业； /
彼能取所取，此亦应遮遣。 /
作者作业等，此义如是故； /
余法自及他，相因义应观。」 /

「眼耳等诸根，受等心所法； /
彼所取若成，有取者先住。」 /

「若无彼先住，何有眼耳等？」 /

「以是故当知，先已有法住。」 /

「眼耳等诸根，受等心所法， /
有法先住者，以何可了知？」 /

「若离眼等根，有法先住者。」 /

「应离眼耳根，有见等无疑。」 /

「一切眼等根，实无法先住。」 /

「眼等根所取，异相复异种。」 /

「若眼等诸根，无法先住者； /
彼眼等诸根，当云何先有？」 /

「若见即闻者，闻者即受者； /
一一有先住，如是非道理。」 /

「若见闻各异，受者亦复异； /
见时若能闻，即成多我体。」 /

「眼耳等诸根，受等心所法， /
彼从诸大生，彼大无先住。」 /

「眼耳等诸根，受等心所法， /
若无先住者，眼等亦应无。」 /

「彼眼等先无，今后亦复无， /
以三时无故，有性皆息灭。」 /

## 9

复次颂言：

释曰：遣一性故。

释曰：薪火二法遣异性故。

释曰：总遣异性故。此中薪火二法，一性异性俱不可见，如瓶非木。又如水中莲花，异性不成故。是故胜义谛中薪火二法非相因有，而彼二法毕竟空故。

复次颂言：

释曰：一性异性互相因待次第不成。复次颂言：

释曰：彼能取所取非作者作业一性可着，亦非异性所取，离亦不生。若异性所取，即互不到，不到即不烧，不烧即不灭，不灭即是常。若法常住，彼即互相因待不成。若成不成，二法相因毕竟无体。若人计火从余方来，有其能取及所取者，此义不成。故下颂言：

释曰：彼瓶衣等因果二法，同生不同生、能相所相，彼等所成，如非泥团即是其瓶，彼瓶果法有作用故。亦非异瓶别有果法作用所成，非彼二法互相因待，若成不成相因无体。此如是故，余处随应所说亦然。若胜义谛中无一异性，是故不应取着。

「若火即是薪，作作者一性。」 /

「若薪异于火，离薪应有火。」 /

「异即应常然，火不因薪故； /
薪即复无功，此业用相违。」 /

「火若常然者，然火功相违； /
此如先所说，离薪别有火。」 /

「不到即不烧。」

「不烧即不灭。」

「不灭即常住。」

「若异薪有火，即薪能到火； /
如此人至彼，彼人至此人。」 /

「若异薪有火，欲令薪到火； /
彼二互相离，薪火何能到？」 /

「若因薪有火，亦因火有薪。」 /

「二何法先成，薪火相因有。」 /

「若因薪有火，火即成复成。」 /

「亦非不有薪，而有火可得。」 /

「若法有因待，是法还成待。」 /

「二法无所成，已成云何待？」 /

「若未成有待，未成当何待？」 /

「若因待有成，自待非道理。」 /

「二因成无体，无不因薪火。」 /

「因薪火亦无。」

「因火亦无薪。」

「火不余处来。」

「薪中亦无火。」

「余法亦复然，如去来品说。」 /

「即薪而无火。」

「异薪亦无火。」

「火中亦无薪，薪中亦无火。」 /

「余诸法皆同。」

「及彼瓶衣等。」

「非受非不受，异复云何有？ /
如能取所取，诸所说亦然。」 /

「若人执有我，诸法有实性， /
各各差别说，彼不解佛法。」 /

## 观生死品第十一

复有人言：胜义谛中亦有生死。何以故？如佛所言：「生死长远，众生愚迷不知正法。我欲令彼如理修行得尽生死，乃作是言：『汝诸苾刍，应如是学。』」以此证知胜义谛中有其生死。

论者言：如佛所说，皆是方便世俗施设，非胜义谛，亦非不有生死而说。长时有法可尽，彼生死者众生所受。若如理修行，即能尽彼生死有性。此中先说薪火二法能取所取彼等次第，此非道理。

复次颂言：

释曰：此义云何？所言生死者即是无际，无际即无始。今此义者，无最上、无先际，故言无际。又非有彼先际，故名无际。故下颂言：

释曰：先后义无体，无自性故，如兔角等，应如是见。由如是故，中亦不可得说，非不有故，如兔角等。

复次颂言：

释曰：生死无自性，彼云何有？故下颂言：

释曰：此中应问：如所表示无先后共，即次第不生，而何有众生受生老死？又云何修行尽生死有性？此即不成。故颂答言：

释曰：若不离老死而有生者、应不离老而有死邪？故下颂言：

释曰：若或异法有所成者，譬如牛马，异体应可同生。云何生不有死？又何不死有生？若生老死先有体者，即彼本来有其生死。

复次颂言：

释曰：无因即无所依，无依即无生，无生即无相续有性。

复次颂言：

释曰：此义云何？若言生时有其死者，以彼生灭二法无同时性。又复无因二俱不生，彼无性故。若或同生，又生老死无相待因性。

复次颂言：

释曰：胜义谛中戏论不生故。

复次颂言：

释曰：能知所知等一切法，先后共次第皆不和合。若先有果后有其因，果即无因，此即因有相违。若先有因后无果者，即因果不和合。若因果二法同时有者，如是决定彼因果性亦复无体。若已生若未生，二法相因俱无体故。能相所相，所说亦然。

复次颂言：

「大牟尼所说，生死无先际。」 /

「今此如是说，无先亦无后。」 /

「若无有先后，中复云何有？」 /

「是故此中无，先后共次第。」 /

「若使先有生，后有老死者， /
不老死有生。」

「后老死非理。」

「若使后有生，先有老死者； /
彼所有老死，无生即无因。」 /

「无此生老死，亦无有先后； /
老死亦复然，亦应与生共。」 /

「若不生即无，先后共次第； /
云何戏论言，有生老死合？」 /

「若诸法因果，能相及所相， /
所受及受者，真实义如是。」 /

「非但说生死，先际不可得； /
诸法亦复然，先际不可得。」 /

## 观苦品第十二

复有人言：胜义谛中有彼诸蕴苦所成性。如佛所言：略说五取蕴，由苦所得故。

论者言：此等所说皆世俗谛，非胜义谛。何以故？此苦果故。此苦果者，多种分别。

复次颂言：

释曰：有一类人欲令此苦各别系属。故下颂言：

复次颂言：

释曰：若自作者，而彼诸法皆自体所成，非同生性故。若离自体，即无对待因性。亦非同生可有，故下颂言：

释曰：缘所成故。此中若法缘所成性，即无自作，此遣法自相。又复亦非他作道理。

复次颂言：

释曰：今此五蕴与未来五蕴诸有所作，非此二法互有他性。何以故？灭与未生二无性故。此中亦非苦能作苦，自作他作云何可成？

复次颂言：

释曰：若复离蕴无所施设，彼复云何有苦可作？

复次颂言：

释曰：此非离苦而复有苦，苦无异故。

复次颂言：

复次颂言：

释曰：或有人言：若人自作苦，即非他所成，应有他作邪？对此异意，故下颂言：

释曰：今此如是，非有所作，亦非有苦。若以彼苦自作苦者，即自所作，道理相违。是故此说以无有人何有他作？彼无性故。若复他无自体，是中云何他能作苦？若人自体不生，即无所有。他体不生，即无他作，是故无有他能作苦。若或自他二法共作苦者，亦非道理。

复次颂言：

如有颂言：

释曰：胜义谛中苦无体故。

复次颂言：

释曰：此复云何？色等亦然。故下颂言：

释曰：色非自体作故。彼能作所作，若有若无，皆非所作。若有能作，即所作无体。无即非能作，云何无中计有我作？此即著于能作。亦非他法成已复成色法作用，是中亦非他性可成。今此所说，若从缘生，彼即无有异法可得，亦非自他缘法不生，又一切法非无因故。由是胜义谛中色等诸法体不可得。

「自作及他作，共作无因作。」 /

「彼等于诸果，所作非道理。」 /

「苦若自作者，即不从缘成。」 /

「以有此蕴故，有未来五蕴。」 /

「若有此五蕴，与未来蕴异； /
于此彼蕴中，应有他作苦。」 /

「若人自作苦，离苦何有人？ /
云何自作中，离人而有苦？」 /

「若苦他人成，授与此人者； /
他亦名自作，离苦何有苦？」 /

「若他人作苦，离他何有苦？ /
亦非有作已，他能授于此。」 /

「自作若不成，复何有他作？ /
若他人作苦，即亦名自作。」 /

「苦不名自作，亦非他人作， /
是故所作中，离苦人无体。」 /

「若有自他作，即有共作苦； /
今无自他共，无因亦非理。」 /

「他相若自作，他相此无因； /
此若有自因，何有无因作？」 /

「非但说于苦，四种俱不有。」 /

「外诸法皆同，四种俱不有。」 /

## 观行品第十三

前品所说破色等蕴，此即亦有对治相违。何以故？如佛所言：「诸苾刍！汝等应当如实了知色是无常，乃至识法亦是无常。」以此文证，有色等蕴。

论者言：此世俗谛增上所说，非胜义谛。故有颂言：

释曰：此虚妄者，是邪智境界。愚人不实，于虚诳法无分位中计色有性。

复次颂言：

释曰：此即无所得相违。故下颂言：

释曰：无所有故，譬如兔角，虚妄之法而不和合。是故虚妄法者，虽有所说皆是虚妄。故佛世尊广为开示，普尽一切若根若随烦恼、所知二障等法皆悉是空，使令除断，即彼空性离二边故。此中所说诸虚妄法，决定皆是世俗谛有。若虚妄法，于胜义谛中如干闼婆城。又或虚妄法者，虽复所说，是中亦非妄法可有，故佛世尊诸有所说悉无相违。若言诸法不有，即是证成自性空义，遣妄执故。

复次颂言：

释曰：若见有法变异之性，彼即无我。无我即无常，无常即不有。如是所说，是为虚妄。此法如是。故下颂言：

释曰：虽说诸法皆空，即彼诸法犹如空花，亦非有彼无自性法，又或无所成故。

复次颂言：

释曰：若法有异，自性亦异。若彼诸法无自性者，即不和合。是故若见诸法各各自性有别异者，云何不说此为虚妄？故下颂言：

释曰：若其无者，即无法可有异性和合。计有性者，即堕过失。此复云何？

复次颂言：

释曰：若后异者，譬如老作老相，此即自比量相违。

或有人言：若不离自体有法可异者，乳应即成酪。若尔，即有因一向过失。

复次颂言：

释曰：亦非离彼滋味气势报体等法乳即成酪，以缘性故。又复亦非异乳有酪，此即于第二时有一向过失。故下颂言：

释曰：亦非异乳有酪可得，此即不堕一向过失。是故无有异法可见，有即虚妄。何以故？自性空故。胜义谛中亦无少分不空之法，对待空法而有所成。

复次颂言：

释曰：因不成故，此中非有空法可说。今此如是证成世尊所说空义。如其所说，此复云何？故下颂言：

释曰：此即遣诸空执。诸佛世尊所说无疑，何况有异？若欲有其空者，此乃于法自性有所取着。此中亦非有性可取，应当舍离。若或于空有所取者，此即边执。彼有执者无异方便，应知此等佛所不化。

「若彼虚妄法，是世俗有为； /
无妄涅槃法，即是胜义谛。」 /

「彼虚妄法者，诸行妄取故。」 /

「即彼虚妄法，是中何所取？」 /

「诸法无自性，见有异性故。」 /

「无性法亦无，一切法空故。」 /

「若法无自性，法云何有异？」 /

「若法有自性，亦复何有异？」 /

「若诸法即异，无异法可有； /
现住法若异，后变异不成。」 /

「若法即有异，乳应即成酪。」 /

「若或异于乳，云何得成酪？」 /

「若有不空法，即应有空法； /
无少不空法，何得有其空？」 /

「遣有故说空，令出离诸见； /
若或见有空，诸佛所不化。」 /
