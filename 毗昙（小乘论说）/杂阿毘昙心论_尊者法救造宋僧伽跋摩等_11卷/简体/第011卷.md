# 杂阿毘昙心论 · 第十一卷

> 尊者法救造  宋 僧伽跋摩等译

---

古昔诸大师，于诸甚深法， /
多闻见圣迹，已说一切义。 /
精勤方便求，未曾得异分， /
阿毘昙心论，多闻者已说。 /
或有极总略，或复广无量， /
如是种种说，不顺修多罗。 /
光显善随顺，唯此论为最， /
无依虚空论，智者尚不了。 /
极略难解知，极广令智退， /
我今处中说，广说义庄严。 /

敬礼尊法胜，所说我顶受， /
我达摩多罗，说彼未曾说。 /
弟子咸劝请，毘昙毘婆沙， /
专精思惟义，贤众所应学， /
正要易解了，离恼济群生。 /

顶礼前最胜，离恼安教尊， /
所说悉具足，罗汉见真谛。 /

牟尼尊悉知，法聚二种相， /
亦为他显现，我今说少分。 /

一切有漏行，离我乐常净， /
不见有漏故，计我等妄受。 /

若增诸烦恼，是圣说有漏， /
以彼漏名故，惠者说烦恼。 /

以彼漏名故，惠者说烦恼。 /

亦名为烦恼，受阴及与诤， /
烦受诤起故，是诸贤圣说。 /

若行离烦恼，亦解脱诸漏， /
此及前受阴，是阴圣所说。 /

所谓色受阴，想行及与识， /
是五阴次第，麁细随顺说。 /

十种谓色入，及无作假色， /
是分别色阴，牟尼之所说。 /

所名为识阴，此即是意入， /
于十八界中，亦复说七种。 /

余则有三阴，无作三无为， /
是则说法入，亦复说法界。 /

轮转于生死，当知二诤根， /
是故别受想，建立二种阴。 /

五阴虽是行，而一受行名， /
有为法多故，说行阴非余。 /

广说诸法阴，其数有八万， /
戒等及余阴，悉是五阴摄。 /

法阴谓经论，如是一一说， /
及诸对治行，悉名法阴数。 /

所谓眼耳鼻，舌身及与意， /
色声香味触，余则说法入。 /

虽于一身中，所作事各异， /
依缘自性故，十二种分别。 /

虽有众多色，但说一色入， /
当知一色入，三眼境界故。 /

彼一切诸法，虽尽是法入， /
法中众多故，一法入非余。 /

彼十一切入，八入二四入， /
及五解脱入，皆悉十二摄。 /

界种说十七，或说为十二， /
境界依者依，分别十八种。 /

境界依者依，分别十八种。 /

二眼说一界，以二一自故， /
耳鼻亦如是，二共说一界， /
为令身端严，彼皆不一一。 /

若有诸余界，世尊契经说， /
各随其自性，悉入十八界。 /

界说一切法，彼即十二入， /
除三无为法，余则说五阴。 /

牟尼观众生，欲解根不同， /
性行愚差别，故说阴界入。 /

聚积是阴义，输门义说入， /
种性义说界，是三种差别。 /

境界依者依，度量法所应， /
是故界入阴，不增亦不减。 /

界中一可见，又说一切界， /
无记谓八种，余则善不善。 /

一切皆当死，是论一向记， /
一切死复生，是名分别论， /
若问生殊胜，是名诘问论， /
众生五阴异，是名止记论。 /

十二界有对，一界说少分， /
十界七有对，一少分亦然， /
说境界有对，障碍及与缘。 /

说境界有对，障碍及与缘。 /

有漏有十五，余二三三有， /
欲有中有四，十一在二有。 /

有觉有观五，三行三余无， /
有缘当知七，法入说少分。 /

九不受余二，为无为共一， /
一向是有为，当知十七界。 /

有罪及有报，染污及隐没， /
修习则有十，一界中有见， /
亦说有心法，一界是见性。 /

自分眼见色，非彼眼识见， /
非慧非和合，不见障色故。 /

极微数有十，九界四大造， /
二界说少分，内界说十二， /
此即是根性，一界中有根。 /

分余分十七，一界说有分， /
十七界堕世，一少分三业。 /

非学非无学，当知十五界， /
彼悉修道断，余界俱三种， /
于彼三界中，说持戒犯戒。 /

十七说有上，一界说二种， /
果有果十七，一三觉所说。 /

三界三种缘，一依亦复然， /
五一或分别，余缘唯说一。 /

若眼随生见，耳界随生闻， /
三界随生觉，意界随生识。 /

境界唯无记，觉心于中转， /
随生三种识，是则名为觉。 /

二境不近受，远近境界一， /
余一向近受，依及境界等。 /

二界说不定，一界境亦然， /
五界依或俱，一界依说远。 /

十一界有二，六三一四种， /
事及长养报，刹那与依种。 /

生身眼色界，自地及他地， /
若彼眼识生，自他地亦然。 /

耳界如前说，鼻舌界自地， /
身触即地说，意识则众多。 /

若彼得眼界，或彼所依识， /
二俱得不得，亦色及与舍。 /

色界二识识，乃至触亦然， /
诸余十三界，一向意识缘。 /

思惟识三种，是意欲有中， /
色无色分别，一种谓余界。 /

诸法离他性，各自住己性， /
故说一切法，自性之所摄。 /

界中说一界，阴入亦复然， /
如是阴入界，则摄一切法。 /

至竟无能生，用离等侣故， /
一切众缘力，诸法乃得生。 /

一切众缘力，诸法乃得生。 /

若彼心起时，是心必有俱， /
诸心法等聚，及不相应行。 /

想欲及触慧，念思与解脱， /
忆定及与受，此说心等聚。 /

一切心生时，是生圣所说， /
同共一缘行，亦复常相应。 /

诸根有惭愧，信猗不放逸， /
不害精进舍，一切善心俱。 /

邪解不正忆，不顺智失念， /
不信懈怠乱，无明掉放逸。 /

烦恼大地十，一切秽污心， /
无惭及无愧，说不善大地。 /

无惭及无愧，说不善大地。 /

忿恨诳悭嫉，恼谄覆高害， /
如此诸烦恼，说为小大地。 /

不善心品中，心法二十一， /
欲三见一减，二见除三种。 /

欲善二十二，不共有二十， /
无记说十二，悔眠俱即增。 /

初禅离不善，余知如欲有， /
禅中间除觉，于上观亦然。 /

极微在四根，十种应当知， /
身根九余八，谓是有香地。 /

一切有为法，生住及异灭， /
此亦有四相，展转更相为。 /

当知前四相，相各为八法， /
随相亦应知，相相唯相一。 /

异性相说远，处所时亦然， /
戒种及大地，诸识性分别。 /

所作共自分，一切相应报， /
从是六种因，转生有为法。 /

相似不相似，各除其自性， /
一切是作因，生时无障故。 /

一起性有依，亦复说无依， /
当知共有因，展转为因果。 /

前生与后生，亦说彼未生， /
自地相似因，或说于他地。 /

秽污有九种，展转更相因， /
谓受生所得，方便生非下。 /

善等自分因，受果而不与， /
或与而不受，或俱不俱说。 /

苦集于自地，疑见及无明， /
说一切遍因，诸烦恼前起。 /

谓同一行法，一依亦一时， /
及一境界转，是说相应因。 /

不善善有漏，三世之所摄， /
以彼有报故，说名为报因。 /

五中世受果，亦说二与果， /
已尽与果一，二因当分别。 /

作因一切法，二因说二世， /
余三说三世，增依报功果。 /

报生心心法，及与诸烦恼， /
悉从五因生，是义应当知。 /

若彼不相应，诸余相应法， /
除其初无漏，是从四因生。 /

谓余不相应，自分当知三， /
及诸余相应，初生无漏法。 /

于中不相应，是从于二因， /
若从一因生，当知必无有。 /

次第亦缘缘，增上及与因， /
法从四缘生，世尊之所说。 /

除罗汉后心，诸余心心法， /
常有行已生，是说次第缘。 /

或法心次第，非彼心无间， /
无间非次第，俱不俱当知。 /

境界于一切，心及诸心法， /
是故一切法，说名为缘缘。 /

若彼所作因，此即增上缘， /
所谓因缘者，当知余因说。 /

心及诸心法，是从四缘生， /
二正受从三，谓余说于二。 /

分齐有三种，名色及与时， /
初分说一字，极微刹那余。 /

七微成阿耨，七耨成铜尘， /
水兔羊毛尘，当知从七起。 /

贪欲瞋恚慢，过去或缘起， /
未来说一切，余二世尽缚。 /

烦恼次第起，自地于自地， /
上地亦生下，当知随次生。 /

有扼漂流取，泄漏与结缚， /
以是义故说，扼流取漏缚。 /

数有二十九，亦说二十八， /
三十六十五，欲等扼流性。 /

谓前三十四，次种说三十， /
第三者说六，第四三十八。 /

说彼欲漏性，当知四十一， /
有漏五十二，无明漏十五。 /

无知故犹预，犹预故邪见， /
因此邪见故，转生诸身见。 /

从是起边见，戒取戒想取， /
于彼决定已，次第生见取。 /

自见则生欲，他见则起恚， /
自见举名慢，从使转生缠。 /

无惭与无愧，睡悔悭嫉掉， /
眠忿及与覆，是上烦恼缠。 /

无愧睡与眠，此三无明依， /
掉悭及无惭，是从贪欲生。 /

覆缠二使依，悔则因犹豫， /
忿嫉瞋恚依，明智之所说。 /

所谓烦恼垢，害恨瞋恚依， /
诳高依贪欲，是义应当知。 /

所谓五邪见，谄依由是生， /
说依见取果，是恼应当知。 /

一切烦恼俱，说睡及与掉， /
无惭不善俱，无愧亦复然。 /

悔在于意苦，修道之所断， /
眠唯在欲意，余各自建立。 /

所谓悭与嫉，独立离于二， /
是故此二缠，立于九结中。 /

诸使在三界，尽舍根相应， /
随地诸根使，相应至色有。 /

邪见及无明，欲界中乐苦， /
瞋恚疑唯苦，谓余一向乐。 /

谓勋二相应，见断唯应意， /
欲界诸烦恼，说诸根相应。 /

贪欲瞋恚痴，当知六识俱， /
谓欲随道断，上地随所得。 /

无色界一切，非事慢意地， /
当知彼七使，自性果及人。 /

一时断烦恼，正智之所说， /
如此诸解脱，亦非一时得。 /

谓彼缘中觉，及说彼缘断， /
亦说得对治，又复彼缘灭。 /

欲界中解脱，圣说四断知， /
离色无色界，当知五断知。 /

苦集烦恼尽，总说一断知， /
灭道断各一，如欲上亦三。 /

修道断当知，界界断说一， /
三断是智果，余则说忍果。 /

初地说一切，禅五亦复八， /
无色说一果，眷属果亦然。 /

世俗道果二，圣九法智三， /
未知智说二，彼品果六五。 /

或有诸圣人，未成就断知， /
或成一二三，四五及与六。 /

舍一二五六，如舍得亦然， /
得果及度界，二处断知集。 /

谓彼二因灭，离系及度界， /
得于无漏得，及缺第一有。 /

好境俱不俱，彼二种爱生， /
恶境二亦然，一则谓为舍。 /

谓使烦恼心，障碍不违净， /
妙善心可得，非不相应使。 /

初则名始业，次则已习行， /
思惟已度者，当知第三种。 /

若此烦恼怖，远离诸贤圣， /
如实正具足，方便应善听。 /

始于自身分，系缚心令定， /
欲缚于识足，为尽智慧怨。 /

是方便于身，真实相决定， /
诸受及自心，法亦如是观。 /

三种说念处，自性及与共， /
亦说名为缘，闻等慧亦然。 /

入法中总观，得法真实相， /
此四是无常，空无我非乐。 /

从是名为煖，于法觉而生， /
十六行等起，观察四圣谛。 /

是法增长已，生顶及于忍， /
得世第一法，依于一刹那。 /

下苦有四行，说摄依六地， /
忍法亦如是，谓余或依七。 /

世间第一法，次生苦法忍， /
忍次生于智，俱观于下苦。 /

谓色无色苦，集灭道亦然， /
此法无间等，说是十六心。 /

随法行利根，此在十五意， /
随信行钝见，当知亦在中。 /

随信随法行，若具烦恼缚， /
乃至五种断，当知向始果。 /

六断乃至八，是向第二果， /
离欲至八地，是则第三向。 /

若至十六心，是名住于果， /
软见信解脱，利见名见到。 /

非事诸烦恼，谓彼一切尽， /
乃至未进行，是名须陀洹。 /

未尽修道种，受生生死七， /
当知彼所说，极满须陀洹。 /

若断三四种，成就彼对治， /
余二生三生，是说名家家。 /

六品烦恼断，见道断一切， /
是说斯陀含，谓彼未进行。 /

若七八品断，成就对治根， /
余则受一生，是名一种子。 /

九品尽不还，当知有多种， /
或五及七八，或复说众多。 /

十五有二十，三十与八十， /
九十百二十，及三百六十， /
四百八十种，千四百四十， /
如是广略说，摄受阿那含。 /
根地及种性，处所广建立， /
随彼烦恼断，今当次第说。 /

一三四与六，十六及十八， /
谓说二十四，复说三十六， /
七十有二种，九十有六种， /
二百一十六，二百八十八， /
六百四十八，八百六十四， /
又复说二千，五百九十二。 /

利根软烦恼，住于一种业， /
是中般涅槃，分别六种性。 /

精进勤方便，修习速进道， /
是生般涅槃，彼亦有二说。 /

第三勤方便，离于速进道， /
第四不勤求，三俱说六种。 /

超半超处处，是名为上流， /
此亦六种性，当知进不进。 /

谓生根烦恼，是说有三种， /
不生亦复然，及二上流一。 /

如是九烦恼，在于上八地， /
谓彼双道灭，世尊之所说。 /

有垢无垢道，俱能离八地， /
住彼说身证，谓得灭正受。 /

金刚喻定次，必生于尽智， /
生意我生尽，应供离诸漏。 /

阿罗汉六种，随信行生五， /
彼得于二智，当知时解脱。 /

不动法利根，是不时解脱， /
彼得于三智，自解脱成就。 /

慧解脱当知，不得灭尽定， /
若得灭尽定，当知俱解脱。 /

诸根说九种，亦说九种人， /
七种诸声闻，缘觉及如来。 /

软中最软根，是为初种人， /
乃至增上上，第九人当知。 /

谓以学种性，得彼无学果， /
或即彼种性，或进不退转。 /

所谓三四五，六七次第增， /
是诸退法等，说五罗汉等。 /

谓随信行法，若随法行法， /
及与见谛道，是尽同一相。 /

于中诸根法，是名未知根， /
谓余有学法，佛说已知根。 /

当知无学法，是说无知根， /
得果舍前道，无碍智所说。 /

方便及诸根，正受解脱俱， /
当知贤圣七，事则说有六。 /

一三五十五，及与七十三， /
谓根种性道，离烦恼当知， /
三倍次五倍，十五及九倍， /
如是众多种，唯说随信行。 /

以有五事故，说有八人名， /
先后事各一，中间则有三。 /

已尽为解脱，得依于一果， /
不秽污第九，灭尽应当说。 /

无着相似名，彼能获不动， /
信解脱种性，升进亦增道。 /

或有学果满，或根或正受， /
或复三俱满，无学二亦然。 /

建立功德恶，渐渐见真谛， /
无碍道力得，有为无为果。 /

谓三无间等，缘事见无间， /
当知有三种，或二亦复一。 /

若智性能了，明照一切有， /
有无有涅槃，彼诸相今说。 /

三智佛所说，最上第一觉， /
谓法智比智，及世俗等智。 /

苦集及灭道，二智从谛生， /
是名与四智，牟尼随谛说。 /

若智观他心，是从三中说， /
尽无生智二，境界在四门。 /

对治及方便，自性行行缘， /
已作因长养，是故说十智。 /

九智唯说善，一智三分别， /
一见二非见，余则有二种。 /

学与无学六，二智说无学， /
非学无学一，当知一三种。 /

八智性不断，二知二种说， /
有漏无漏一，一则说有漏。 /

四智有为缘，有常缘则一， /
五智二境界，明智之所说。 /

法智应当知，是从六地起， /
比智则九地，他心智在禅。 /

等智应当知，在于十一地， /
谓彼诸余智，品品如前说。 /

若说诸念处，一智当知后， /
三则说一智，余四明智说。 /

一智欲界依，二界依有一， /
二智三界依，余六一或三。 /

名则十六行，事或说十六， /
离于十六行，除暗非无漏。 /

二智十六行，法智及比智， /
如是行或非，是说为等智。 /

四智有四行，决定行所说， /
若智知他心，如是行或非。 /

尽智无生智，离空无我行， /
说有十四行，谓近于等故。 /

谓慧行能行，亦为他所行， /
余有依二种，无依他所行。 /

谓初无漏心，或有成就一， /
二或成就三，四时各增一。 /

若得修于智，谓在圣见道， /
即彼当来修，诸忍亦如是。 /

于彼三心中，得修于等智， /
当知最后心，或修七或六。 /

于彼上修道，十七无漏心， /
当知修于七，增益根或六。 /

得不还果时，及离上七地， /
勋修诸神通，解脱修习八。 /

此诸无碍道，及灭第一有， /
即彼八解脱，当知修于七。 /

第一有离欲，无碍道修六， /
上乘应当知，修习于下地。 /

无学初心中，修于一切地， /
无学相似修，或苦习比智。 /

尽智心俱修，善有漏功德， /
九地至一地，次第修亦减。 /

诸忍则非智，尽无生非见， /
余一切圣慧，当知三种性。 /

若善有漏智，在意则是见， /
烦恼见是智，此及余说慧。 /

法智及比智，观察于九智， /
因智及果智，境界于二智。 /

道智缘九智，解脱智无缘， /
余一切境界，决定智所说。 /

谓彼灭及道，法智之所行， /
是三界对治，非欲界比智。 /

神足天眼耳，是说一等智， /
或六智宿命，五说他心智。 /

处非处智力，及第一无畏， /
此是佛十智，余此中差别。 /

净业有爱果，不净果不爱， /
此说为是处，异则说非处， /
应当如是知，是处非处力。 /

彼十智自性，在于十一地， /
决定说如来，谓阎浮提依。 /

第二力八智，于彼事业转， /
及法受烦恼，余则如前说。 /

诸禅及背舍，正受三摩提， /
第三力回转，九智余如前。 /

于上下诸根，第四力回转， /
第五说解力，第六于界缘。 /

于彼种种趣，第七力回转， /
当知已说四，余皆如前说。 /

知宿命有行，是说第八力， /
谓禅有烦恼，余则如前说。 /

第九力当知，远离于所缘， /
命终及受生，行于众生数。 /

第十力十智，或六一切地， /
示现力明通，余皆如前说。 /

初则如初力，第二如第十， /
余二如二七，是名无畏安。 /

第四禅有垢，无诤三方依， /
缘欲未生恼，依不动智慧。 /

所谓妙愿智，远离彼境界， /
于彼最后得，六智自在性。 /

义辩漏无漏，在于一切地， /
佛说为方便，余则如前说。 /

所谓为应辩，境界道及说， /
因明论方便，或三余如前。 /

法辩缘施设，在于五地中， /
以数为方便，余如无诤说。 /

声明论方便，是则为辞辩， /
境界于言说，二地余如前。 /

智依于诸定，安不动而转， /
是故当思定，勤求见真实。 /

决定说四禅，及与无色定， /
是中一一说，味净及无漏。 /

善有漏是净，无漏离炽然， /
味则爱相应，最上无无漏。 /

净者有四分，退分及住分， /
胜进决定分，随顺诸功德。 /

五支有觉观，亦复有三受， /
种种及四心，是说为初禅。 /

第二有四支，种种及二受， /
第三说五支，此禅亦二受。 /

离息入息出，第四有四枝， /
枝者谓说善，随事如先说。 /

禅支名十八，事则有十一， /
无色无有支，禅眷属亦然。 /

有觉亦有观，是说未来禅， /
禅中间有观，明智之所说。 /

未来或二种，谓离味相应， /
禅中间三种，亦俱说一受。 /

三摩提与通，无量一切处， /
胜处及诸智，背舍于中起。 /

二无量无恚，最后说无贪， /
第三说喜根，谓彼欲界依。 /

乐苦喜众生，众生无余想， /
随其所应转，无量众生缘。 /

胜处说有八，前三色背舍， /
及八一切处，无贪善根性。 /

若说彼眷属，是则五阴性， /
此说三方依，境界欲界色。 /

背舍中最后，心不相应行， /
是说二界依，先从欲界起。 /

余则四阴性，说彼三界依， /
或无色境界，及以无漏缘。 /

当知或有说，成就四无量， /
或复成就三，减者则不然。 /

或一乃至八，成就于背舍， /
或四亦复八，成就于胜处。 /

或一亦复二，八九及与十， /
当知彼修行，成就一切处。 /

五通在四禅，根本非余地， /
诸智如前说，三无量或六。 /

彼前四胜处，及与喜无量， /
亦初二背舍，在于初二禅。 /

余有四胜处，及与一背舍， /
亦八一切处，说在最上禅。 /

余即名背舍，二一切亦然， /
灭尽最在后，余无漏九地。 /

三背舍当知，有漏及无漏， /
定智通已说，其余悉有漏。 /

谓彼性背舍，能胜所缘处， /
无暗普周满，名如所度说。 /

未离欲当知，成就味相应， /
离下未至上，成就净诸定。 /

住上应当知，成就下无漏， /
方便生功德，当知非离欲。 /

根本净初禅，是亦同一缚， /
不能断烦恼，无量亦复然。 /

当知五背舍，及与八胜处， /
亦十一切处，不能断烦恼。 /

所谓无漏定，一一七种因， /
味相应因一，谓彼净亦然。 /

无漏禅无色，逆顺超次第， /
次第生六种，七八九与十。 /

从六至十一，谓净次第生， /
次生二至十，味相应非三。 /

净与无漏禅，缘于一切地， /
自地有漏法，味相应所缘。 /

无色则不缘，下地有漏种， /
谓根本善有，秽污如味禅。 /

谓色界有余，无量诸功德， /
是则缘欲界，最胜之所说。 /

若能勋诸禅，是依第四禅， /
三地爱尽故，净居唯果实。 /

或有念正受，或畏诸烦恼， /
或复乐受生，是各随义说。 /

离欲及受生，而得于净禅， /
秽污退及生，无漏唯离欲。 /

无漏除烦恼，及正受中间， /
一切定中间，相应于舍根。 /

随识现在前，上地则成就， /
舍则不成就，心力羸劣故。 /

受生及离欲，得是诸化心， /
二三及与四，亦五一时得。 /

或有二三四，五七及与九， /
增三或亦五，如是成化心。 /

一切智所说，修多罗妙义， /
我今当少说，修行宜善听。 /

惠施持净戒，是各有四种， /
修禅则有二，说名为功德。 /

无贪相应思，俱起同一果， /
众具处所生，此则是施性。 /

所谓自摄受，亦复摄受他， /
或有二俱摄，或二俱不摄。 /

若未离欲者，供养于支提， /
及凡夫离欲，是名自安施。 /

离欲非凡夫，除其现法果， /
施与诸众生，是名为摄他。 /

未离欲界欲，已离欲凡夫， /
施与诸众生，当知二俱摄。 /

离欲非凡夫，除其现法果， /
供养于支提，是则俱不摄。 /

或有为摄他，供养于支提， /
无量众见闻，皆生随喜心。 /

谓彼希望等，七种施非上， /
第八庄严心，是名最胜施。 /

寿色力安乐，辩才等五种， /
施报百千等，施主之所获。 /

慈无诤灭定，见道及无学， /
从彼正受起，施者得即果。 /

父母若病人，及与说法师， /
近佛诸菩萨，施者得大果。 /

善说诸经法，远离诸颠倒， /
不谤于牟尼，是说为法施。 /

以离等受说，安慰诸恐惧， /
是名无畏施，能坏贫穷怖。 /

普于群生类，等受戒律仪， /
功德流增广，是则为大施。 /

欲界及禅生，无漏戒律仪， /
断律仪从二，是说律仪种。 /

或以希望受，或以恐怖持， /
有顺菩提支，及与清净戒。 /

根本眷属净，不为觉所坏， /
摄受于正念，随顺般涅槃。 /

禅无色无量，得修及习修， /
不净安般念，二修义亦然。 /

二十说欲界，色界或十六， /
无色界有四，处所次第说。 /

善趣在欲界，及色界三地， /
无色三亦然，是说为识住。 /

第一有无想，是说众生居， /
谓有漏四阴，是说四识住。 /

烦恼及业事，彼随次第生， /
当知是有支，众生一切生。 /

此诸分建立，谓众生受生， /
过二及未生，中间说于八。 /

三有支烦恼，二业事则七， /
七名前有支，五则说后分。 /

前支五说果，余二则为因， /
后支三说因，余二则为果。 /

前痴后爱取，行有合亦然， /
名色入触受，是说同老死， /
谓初受身识，是则未来生。 /

烦恼起烦业，彼业转生事， /
事亦生于事，亦复生烦恼。 /

谓彼相续转，刹那与连缚， /
及前谓分段，此则说缘起。 /

生摄一切趣，非趣摄于生， /
谓生中阴增，当知非趣摄。 /

所谓四大种，及诸有漏识， /
亦色中间相，此界说生本。 /

谓性果诸行，有漏是说苦， /
因性则为集，灭谛众苦尽。 /

若无漏诸行，是说为道谛， /
此二因缘故，麁细次第现。 /

圣果事有六，最胜在九地， /
第三在六地，二种依未来。 /

随信行行法，离烦恼迟相， /
随法行行法，离烦恼速相。 /

根本禅地中，当知是乐道， /
减及难得故，当知是说苦。 /

佛及声闻法，解脱亦余因， /
清净无垢信，圣戒谓决定。 /

初禅若有善，说名现法乐， /
谓得生死智，是说名知见。 /

当知分别慧，方便生功德， /
金刚喻四禅，是名为漏尽。 /

善有为诸法，方便之所起， /
佛说如意足，是亦说正断。 /

此说四念处，四圣种亦然， /
如其增上生，是皆随名说。 /

净信精进念，智慧及喜猗， /
觉品相应舍，思戒三摩提。 /

处方便自在，软及利亦然， /
见道亦修道，故说三十七。 /

二禅三十六，未来亦复然， /
三四及中间，是悉三十五。 /

初禅说一切，无色三十二， /
最上二十二，欲界亦复然。 /

诸食中抟食，欲界说三入， /
识食思及触，是食说有漏。 /

无愿有十行，二行是空定， /
四行说无相，是说为正行。 /

谓彼四颠倒，当知见苦断， /
三见自性增，见实者分别。 /

诽谤于真实，此见是邪见， /
不实而妄置，是二见及智。 /

非因而见因，是说为戒取， /
若摄受边见，依断灭有常。 /

诽谤及妄置，因见及二边， /
于此诸事转，或见彼则断。 /

谓眼等四根，身根有三种， /
意根及与命，是根生死依。 /

增上是根义，五根说四种， /
当知余四根，各有二增上。 /

受或烦恼分，信等依清净， /
九根若无漏，此三依于道。 /

欲界四善八，色种根有七， /
心法则有十，一心三根二。 /

于此诸根中，一及十有报， /
十二中是报，命根唯是报。 /

二或六七八，最初生时得， /
当知欲界报，色六无色一。 /

舍四八与九，或复舍于十， /
渐终及顿没，善舍各增五。 /

二断无断四，六根则二种， /
三无漏不断，余则修道断。 /

或成就三四，五七及与八， /
十一与十三，是说定成就。 /

九根得初果，或获二沙门， /
谓以十一根，究竟第四果。 /

若取诸根义，五种心境界， /
若取一切法，是则说意识。 /

欲色界诸阴，无色与无漏， /
有依无依八，及彼二无为。 /

五法应当知，法智之境界， /
比智七为缘，他心境界三。 /

有漏当知十，因果智有六， /
解脱一道二，余二境界九。 /

自地诸烦恼，定使于自地， /
自种一切遍，随使于彼种。 /

若定三界法，三界使所使， /
二界生当知，一界亦复然。 /

此经牟尼说，其性已分别， /
识知及诸使，当知是三门。 /

已分别诸法，一一定相续， /
于上众杂义，是今当略说。 /

有缘亦相应，有行及有依， /
心及诸心法，是同一义说。 /

从缘生亦因，有因亦有为， /
说处及与道，有果应当知。 /

有罪亦隐没，秽污下贱黑， /
善有为说习，亦复说名修。 /

无想二正受，亦众生种类， /
句味与名身，命根与法得。 /

谓彼凡夫性，及诸法四相， /
非色不相应，说是有为行。 /

二善五种三，当知七无记， /
二在于色中，一在无色地。 /

二界说有三，余在于三界， /
有漏无漏五，余则尽有漏。 /

初无漏心中，当知舍不得， /
凡夫流诸界，离欲时灭尽。 /

烦恼断离系，是名为数灭， /
无诸障阂相，是说为虚空。 /

依于诸缘法，有依及境界， /
不具则不生，此灭非是明。 /

前因相似增，或俱依倚生， /
二因及一缘，一向已生说。 /

报谓众生数，有为解脱果， /
有缘说俱行，谓于他相转。 /

有为解脱果，一切有为法， /
说果有因生，故及数缘灭。 /

普因无方处，生时心解脱， /
烦恼在道心，乃至灭时舍。 /

有爱有五种，无有唯一相， /
爱事余烦恼，灭尽是三界。 /

若得九种法，当知秽污心， /
善心得六种，无记即无记。 /

道品有六法，当知是根性， /
诸法若相应，是说为他性。 /

缘中得解脱，大仙之所说， /
亦有断而缚，见道及修道。 /

二解于三谛，四由见正道， /
而得不坏净，修习于二世。 /

一切诸心法，说与心俱转， /
亦此心诸相，余相及所作。 /

断法谓有漏，知者亦无垢， /
灭未来说远，余则说于近。 /

所谓无间业，及诸无漏道， /
慧说名为定，见处谓有漏。 /

说有十九根，谓成就极多， /
极少成就八，晓了根所说。 /

增语及有对，明无明处中，以多名故说增语 /
所谓得果者，是则双道事。 /

若智在苦因，及忍说为厌， /
能离贪欲故，说四为离欲。 /

罗汉住报生，及与威仪心， /
随顺心灭故，趣向般涅槃。 /

生有及坏有，本有亦复中， /
当知二刹那，一染三有二。 /

若离欲界欲，越度第一有， /
及与起忍法，极为业障碍。 /

当知有五种，自性及与因， /
系缚若摄受，一切境界事。 /

说阴即为事，界入事亦然， /
及与世刹那，是名五种事。 /

育多婆提说，安立及方便， /
亦说和合修，是名为四果。 /

运身及意解，意念自在通， /
意念唯如来，当知二则共。 /

入色无色界，亦复增益根， /
及与贤圣退，生中间定无。 /

劫减佛兴世，增时转轮王， /
二时辟支佛，如是应当知。 /

若彼诸法生，二得共俱起， /
二得俱生者，当知有得得。 /

诸得有十五，得于苦法忍， /
其余见增道，当知一一减。 /

若于彼地中，断及坏对治， /
即摄解脱得，法智比智品。 /

与道俱起得，俱起而非因， /
道亦非彼因，后起或有无。 /

空行有垢住，是说为空空， /
说无学境界，在于十一地。 /

行于无常行，是无愿无愿， /
俱在于不动，欲界余如前。 /

谓无相无相，彼行于寂止， /
行于无记灭，余则如前说。 /

超越三摩提，上下至第三， /
及不念思惟，于缘超亦然。 /

佛语善无记，如彼初心转， /
究竟亦复然，无记或清净。 /

声闻则不定，究竟及与转， /
说时不退减，唯是佛世尊。 /

诸入中有四，可烧亦能烧， /
可称亦能称，断能断无惑。 /

地谓色形处，坚相说地界， /
余二亦二种，风即风或异。 /

福分说一种，及与解脱分， /
于福决定分，第四离诸漏。 /

当知布施等，能转于恶趣， /
必定与忍俱，施等同或异。 /

离欲及退时，受生亦命终， /
断善及相续，当知是意识。 /

谓一切众生，悉住于舍受， /
命终及受生，以不捷疾故。 /

虽已说多法，决定众杂义， /
于彼无量处，当复择其要。 /
牟尼说见道，疾故名法轮， /
或说学八支，转至于他心。 /

佛说具足道，广大名梵轮， /
齐辐辋具足，对治非梵行。 /

谓优波婆素，受时他二说， /
具足一日夜，离严饰威仪。 /

尸罗支有四，不放逸支一， /
余则是持支，斋支慧所说。 /

具律优婆塞，比丘律仪一， /
以彼缺减义，牟尼说少分。 /

二律仪妙行：业道初解脱： /
说业及尸罗：如是七种名。 /

成就身非业，或说业非身， /
或有身业俱，或亦不俱说。 /

谓入不正知，及住与出胎， /
乃至入正知，住出亦复然。 /

初者不净业，亦复不求智， /
中二各成一，第四俱成就。 /

住于初果者，一种不净业， /
而不堕恶趣，业不具足故。 /

四食在欲界，四生趣亦然， /
三食上二界，抟食彼则无。 /

于彼饿鬼趣，意思食为增， /
及与诸卵生，三无色亦然。 /

胎生抟食增，谓彼人趣中， /
地狱识食增，第一有亦然。 /

欲天如人趣，色界触食增， /
及与畜生趣，湿生亦复然。 /

归依彼诸佛，所得无学法， /
涅槃无上法，僧学无学法。 /

缘觉菩萨道，及与三真谛， /
于彼无垢信，是法不坏净。 /

随生清净戒，佛僧如归说， /
此事有二种，说有四种名。 /

所谓沙门果，无为亦有为， /
有为学果三，无学果第四。 /

八十九圣人，沙门无为果， /
亦说于有为，一切沙门道。 /

虽知一切空，而非知一切， /
除其共相应，自性亦复然。 /

所谓断对治，坏持及远分， /
此四应当知，是名对治种。 /

初得若习行，对治及断修， /
当知此四种，是名为修义。 /

烦恼通三界，若见断二种， /
二断则三种，俱见道前行。 /

若欲界烦恼，五行有二种， /
彼修齐限故，说修道前行。 /

次第缘所作，说彼法生时， /
缘缘所作业，彼法灭时说。 /

三因所作业，谓彼法生时， /
二因之所作，当知灭时说。 /

一切众生类，心起住灭等， /
贪欲等相应，不相应亦然。 /

欲界中有四，色无色各三， /
亦学无学心，说此次第生。 /

欲界善生九，亦复从八起， /
二秽污生四，亦从十心生。 /

无记次生七，亦复从五起， /
色界善十一，亦从九心生。 /

色界秽污六，亦从八心起， /
无记次生六，从三次第生。 /

无色善生九，亦从六心起， /
秽污心生七，彼亦从七生。 /

无记心生六，亦复从三起， /
学心生于五，亦从四心生。 /

无学心生四，亦从五心生， /
已说十二心，二十应当说。 /

二善二秽污，报生及威仪， /
工巧诸禅果，欲界中八心。 /

除不善工巧，余则在色界， /
离禅果威仪，余四在无色。 /

学与无学心，此则为二十， /
彼心次第生，各随其义说。 /

欲方便生十，亦从八心起， /
生得次生九，亦从十一生。 /

二秽污生七，亦从十四起， /
报生威仪八，是亦从七生。 /

工巧心生六，亦复从七起， /
变化心生二，亦即从二生。 /

色方便十二，是亦从十起， /
生得次生八，亦从五心生。 /

色秽污生九，亦从十一起， /
威仪心生七，从五次第生。 /

当知色报生，亦如威仪说， /
谓彼诸禅果，当知如欲界。 /

无色初生七，是亦从六生， /
生得亦生七，当知从四起。 /

秽污生八心，是从十心起， /
报心生于六，是亦从四生。 /

学心次生六，从四次第起， /
无学心生五，是亦从五生。 /

经律阿毘昙，是名俗正法， /
三十七觉品，是说第一义。 /

五十二及余，亦复说八十， /
或有说十三，是金刚三昧。 /

三通则说善，余二是无记， /
当知依欲色，世尊说慧性。 /

当知彼诸根，慧者善分别， /
名有二十二，事则说十七。 /

若事分别时，舍名则说等， /
分别无所舍，是则第一义。 /

界趣地必定，中阴五无碍， /
说名为香食，求有乘意行。 /

七日或七七，乃至彼和合， /
或裸形食香，诸根悉具足。 /

随行量不定，或有见不见， /
入则从生门，或生颠倒想。 /

知者一切法，识明亦复然， /
知及意识明，彼各随事说。 /

刀兵病饥馑，说名中劫过， /
除地余三种，说名大劫过。 /

七火次第过，然后一水灾， /
七七火七水，复七火后风。 /

错乱本业报，恐怖及伤害， /
若彼解支节，圣说水火风。 /

退法有三种，得未得习行， /
或一人一退，未得退说二， /
谓彼习行退，三圣俱亦然。 /

诸天则不退，果退终不死， /
亦不造彼业，住果所不为。 /

若修诸相好，方便起彼业， /
从是转增进，说名为菩萨。 /

一种异分别，或有说相异， /
或说分分异，或复说异异。 /

次第无间等，智谛异相故， /
见瓶不见衣，是故彼亦然。 /

当知有中阴，世尊之所说， /
譬如村间道，彼则有俱过。 /

当知一切有，非有一切相， /
一切无一切，无有他相法。 /

一切世悉有，不违其所应， /
牟尼之所说，声闻僧无佛。 /

设令广章句，群生大恐怖， /
无胜甚深相，我今但略说。 /

古昔诸大师，演说无量义， /
我今随所解，分别说少分。 /

决定知此论，章句微妙义， /
于彼智慧众，勇猛无所畏。 /

我今增益论，其心无所贪， /
为令智者乐，疾得寂灭乐。 /

## 011

问：知法、识法、明法，此云何？答：

彼苦智知苦，乃至道智知道，无漏智分段缘故。善等智者亦知苦，乃至虚空数非数灭，普缘一切法故。识者亦识一切法，彼眼识识色，乃至身识识触，摄受自相故。意识识眼色眼识，如是一切普缘故。明者亦明一切法，随其事。彼苦忍苦智明苦，乃至道忍道智明道，分段缘故。善有漏慧亦明苦乃至虚空非数灭。问：劫云何过？答：

刀兵病饥馑说名中劫过者，三种中劫过，谓刀兵、病疫、饥馑。刀兵劫者，谓乃至人寿十岁时，贪麁恶境界，行诸邪法，各住害心，手执草木皆成刀剑，更相杀害。如是经七日，刀兵中劫过。疾疫劫者，亦寿十岁时，多诸疾病，无有医师方药瞻病，薄福德故，遇病辄死。如是经七月七日，疾疫中劫过。饥馑劫者，亦寿十岁时，饥渴增上体极羸劣，普天亢旱种殖不收数米而食，煎煮人骨以饮其汁。如是经七年七月七日，饥馑中劫过。如是说者，若于今世一日一夜持不杀戒，终不生彼刀兵劫中。一呵黎勒果施僧福田，终不生彼疾疫劫中。若以一食施僧福田，终不生彼饥馑劫中。此阎浮提恶劫互起，余方则少有相似。如此间刀兵劫起，彼唯瞋恚增上。如此间疾疫劫起，彼唯羸劣少力。如此间饥馑劫起，彼唯增饥渴。问：云何大劫过？答：除地余三种，是名大劫过。三大种说大劫过，谓火、水、风，非地种。何以故？不利故。利者坏大劫。复次地种坏劫者，坏劫应至第四禅，而未曾至第四禅。问：何故坏劫不至第四禅？答：净居天故。彼无上地生，即彼般涅槃故。亦不下生，下地非数灭故。若彼住经坏劫者亦不然，增上福力生彼处故，内扰乱非分故。若彼地内有扰乱者，则外有灾患。彼初禅内有觉观火扰乱，故外为火灾所烧。第二禅内有喜水扰乱，故外为水灾所漂。第三禅内有出入息风扰乱，故外为风灾所坏。问：第四禅未曾有扰乱者，何得不常？答：刹那无常所坏故。如是说者，第四禅地不定相续，随彼天生宫殿俱起，若天命终彼亦俱没。问：何等劫尽最初？答：

七火次第起者，谓最初火劫起。如是说言，若火劫将起，尔时人寿八万岁，地狱命终者不复还生，当知劫尽。乃至地狱无有一众生住，是名地狱劫尽。如地狱劫尽，畜生、饿鬼亦如是。若畜生于人有用者与人俱尽。是时阎浮提唯有一人，无有教者能入初禅，从初禅起已举声唱言：离生喜乐甚为快乐。如是音声展转相告遍阎浮提。诸余众生亦无师教悉入初禅，乃至阎浮提无一众生住，是名阎浮提劫尽。唯除欝单曰。欲界一切善趣亦复如是。欝单曰命终无得禅者，离欲非分故。又于彼时初禅一众生无有教者而入第二禅，从禅起已举声唱言：定生喜乐甚为快乐。如是音声遍至梵天。余诸众生亦复如是。乃至初禅无一众生住，是名众生世劫尽。是时世界久远虚空，乃至七日出。问曰：从何处出？答：有说劫成时由乾陀山后有七日轮住，从彼而出。有说一日分为七分。复有说一日七倍热。复有说从无间地狱火出。如是说者，众生业力故，增上果器世界起。彼业尽如是扰乱生，乃至梵天烧然如是。七火次第过然后一水灾者，七火灾过已然后一水灾，乃至坏第二禅。问：水从何处起？答：有说从第三禅际雨热灰水。复有说水轮涌出。扰乱起如前说。七七火七水者，七火灾次第过然后一水灾，如是七七火灾一七水灾。复七火后风者，复七火灾过然后一风灾，水灾风灾从火灾次第起。此则善说。是遍净天六十四劫寿也。水灾所漂乃至第二禅，风灾所坏乃至第三禅，百亿四天下一时俱坏。十九中劫世间空，一中劫器世界坏，一中劫器世界成，十九中劫渐次第住。若处最初空，是处最后住；若处最后空，是处最前住。问：云何心乱？答：

错乱本业报怖畏及伤害者，四因缘心乱，谓四大错乱、本业报、恐怖及伤害身。四大错乱者，饮食不适故四大错乱，四大错乱故令彼心乱。本业报者，本造心乱，业报已熟。问：何者是？答：好传衰祸令他愁苦。或复骂言：汝痴狂心乱。驱迫众生令堕崄处，焚烧山泽强与人酒，或以妄想倒说佛语。如是比业，得心乱果。恐怖者，见非人形来惊畏，恐怖故彼心则乱。伤害身者，为非人所打故。彼以不净污大众会处及佛僧塔，故彼处非人瞋即打，故彼则心乱。此说凡夫人。圣人无本业行报心乱。若先种定报业者，先受报已然后超升离生。若种不定报业者，若超胜离生彼业则灭。心乱者在欲界，彼地狱不心乱，常乱故。畜生饿鬼及人则心乱，除欝单曰。欲界天亦有心乱。问：何等圣人心乱？答：须陀洹、斯陀含、阿那含、阿罗汉、辟支佛，唯佛心不乱、声不坏、发不白、面不皱、不渐般涅槃。

世尊扰乱业久已灭尽，行妙行故。乱者意识非五识心，不分别故。有漏心乱非无漏，真实行故。是故若说心狂乱是散乱耶。作四句。初句，谓狂者善有漏心、不隐没无记心。第二句，谓自相住者秽污心。第三句，谓狂者秽污心。第四句，谓自相住善心及不隐没无记心。问：何等大能解支节耶？答：若能解支节圣说水火风。三大能解支节非地大，不利故。火大解支节者，谓命终时火大增遍烧筋，烧筋已节节解，节节解已不久命终。水大解支节者，谓节节解时先令筋烂，筋烂已余如前说。风大解支节者，令筋碎，筋碎已余如前说。支节解已，不过日夜命终，四大错乱故。地狱无解支节，支节常解故，业报故不死。畜生、饿鬼及三方解支节，除欝单曰，无罪业故。天亦如是。凡夫圣人解支节，唯除佛。罪报者解支节，佛无罪报故。已说解支节，退今当说。

退法有三种，得退、未得退、习行退。得退者，所得功德遇退因缘则退。未得退者，应得功德放逸故不得。习行退者，已得功德，有因缘故不得习行。问：何等人何事退？答：或一人一退。若得退者是钝根声闻非利根，利根者三昧力故，是故说。或云何知有得退？答：以说二种阿罗汉故，谓退法、不退法。若言道退果不退者，不然。何以故？断得与道合故，得者道谛摄，是故道退非断者，不然。若言离烦恼种云何生者，应说如初无漏心无前因而生，彼亦如是。复次有自分因分故，从无际生死烦恼自分因分生。言烦恼于三处起非说者，不然。何以故？为起烦恼具满故说众生起。烦恼具有三因缘，谓因力、境界力、方便力。彼欲爱使未断未知是因力，欲爱缠所着法是境界力，彼不正思惟是方便力。是彼说意。若从彼说不正思惟者，前不正思惟非分则不起。若有前不正思惟，此则无穷。又复善无记心至竟不生，若不生者解脱亦非分，烧诸烦恼不应还生。如火烧木为灰，至竟为灰不复为木。如是阿罗汉以智火烧烦恼薪，不应复为烦恼。彼不应如是。何以故？譬不合故。云何如烧薪有灰？若如是，阿罗汉烦恼有余如灰耶？若有余者非阿罗汉，有烦恼故。若无者，不如上譬。然非彼圣道如火烧薪，但圣道起断烦恼得解脱得作证。彼若离圣道亦舍解脱得，系得还起。如诸退相违经说，当知说不时解脱故。未得退说二者，若彼未得退者，谓声闻、辟支佛，非佛，住一切最胜根故。声闻者不得佛、辟支佛胜根，辟支佛不得佛胜根，是故有未得退。略说一切众生若修行皆应得圣慧眼，若不修行入名色者是为未得退。问：云何知有未得退？答：信佛说故。如世尊说：诸天及世人退于智慧者，染著于名色，不见圣谛故。谓彼习行退三圣俱亦然者，若习行退者，谓声闻、辟支佛、如来三圣悉有，以中间诸因缘故，所得功德不能常现在前。问：云何知有习行退？答：说心心法退故。如世尊说：于此四种心心法得现法安乐住，我说彼一一退。如修多罗广说。又复说，不动意解脱身作证成就游者，彼不退。以是故知世尊亦有习行退，是故说。世尊多游未至，非根本地。何以故？近欲界故。虽不动意解脱有习行退，然彼成就得修故，彼一切现在时得常随转，彼心心法者现在修，谓不现在前者名为退。习行退最多者谓世尊。何以故？功德无边故。如转轮圣王广受境界。又说摄他故名不动，自摄故名心心法。世尊多摄他、少自摄，如是世尊大悲大舍。问：何处不退？答：断者无碍知者解脱若不正思惟相续无穷则余念不得生也

诸天则不退者，诸天不退，以利根天得果故，利根者则不退。若钝根人得果然后生天亦不退，无生故。圣人无生不退，此前已说，退具非分故。世尊说五退具，多事业等。五退法彼天则无，是故不退，以天不退故。当知退者必人中，以退具可得故。果退终不死者，果退者终不死，要还得果。何以故？下地生非数灭故，非数灭法终不更现在前，不生法故。以果所摄道决定及决定究竟故，以果道苏息处故，彼人得苏息。又果处善自护故，以果处具三因缘及五因缘故，前已说。彼三果退非须陀洹果，见道断烦恼非对治事故，见道断烦恼依我处转而无有我。修道断烦恼是对事，修道断烦恼净处转，彼有净想不净想。彼思惟诸行不净，得离欲净思惟，于见不净退。无有法我我所思惟，于非我见退。复次须陀洹果方便广前施戒修等向解脱，如是比。又须陀洹果见道得故无有见道退，速道故、利故、非想非非想处对治故。若阿罗汉果退至须陀洹果，当知退三果，彼对治烦恼得成就故，亦不造诸业如彼住于果者。若得果人所不为，彼退果人亦不作。何以故？得不作律仪故、圣道已灭恶行故，如曾服药。复次希望具足故，彼人希望灭果，对治恶行故。问：齐何当言菩萨？答：

若有众生，以一食施，起决定心，发无畏言：我当作佛。能起相报增长彼业，齐是名菩萨，以能从此作相似相续业故。若不如是，但有空名。菩萨虽有初起不退心，是则菩提决定非趣决定。谓造相报业已，是则俱决定。是故齐相报业为名。以彼离四因缘故，谓离恶趣、离非男、离卑姓、离不具根。得一因缘，谓生性识宿命。以生识宿命故，闻即受持。眷属信受，离众生过，度三阿僧祇劫，于百劫中种相报业，除释迦牟尼。释迦牟尼菩萨精进故，除九劫，余九十一劫。有说二三阿僧祇非劫阿僧祇，谓劫阿僧祇、生阿僧祇、善行阿僧祇。问：相报业为何等性？答：身业口业增上意业。又是思慧，性非闻慧。以劣故，非修慧。欲界不定故，阎浮提种非余方。男子非女人，佛出世非不出世，见佛非不见佛，缘造业非缘余。有说一思愿种三十二相业，后种种业满。又复说一定心一行一缘，众多思愿现在前，有愿足下安平住果，有愿乃至肉髻，彼一一相百福眷属。福量者，有说一转轮圣王福，是名一福量。又复说一帝释福。有说劫成时一切众生业增上器世界生，是名福量。有说除近佛地菩萨，诸余众生福乐自在业，是名一福量。佛无学法是菩提，谓尽智、无生智，萨埵求此智故名菩提。萨埵得此菩提，觉一切法，故名为佛。虽相报业后得转轮圣王，而圣王相者当知是余业报。问：几种萨婆多？答：趣应言到，与趣同名

此四种萨婆多，一种异分别者，彼说诸法随世转时，分异非事异。如乳变为酪舍味力饶益不舍色，如金银器破已更作余器，舍形不舍色。法从未来至现在亦如是。当知此是转变萨婆多。相异者，过去法与过去相合，不离未来现在相。如人着一色非不着余，彼亦如是。此说有过，若过去诸法不离未来现在相者，竟何所成亦成合义？若尔者，则世乱。如人着一色，于一色爱着，亦行亦成就，于余成就而不行，是故彼说世乱。譬亦相违。分分异者，说诸法随世转时，分分异非事异。此则不乱建立世。何以故？业别故。谓法未作业说未来，作业说现在，作业已说过去。彼异者，彼说诸法随世转时，前后相待，非事异亦非分异。如一女人亦名女亦名母，前后相待故。谓观女则知母、观母则知女，此最乱建立世。彼说过去世一刹那有三世，说言观前起相名未来，观后起相名现在。问：诸师说谛无间等各各异。萨婆多及婆蹉部说次第谛无间等，昙无得等说一无间等。何者为实？答：今当以五支如实说。五支者，一曰宗、二曰因、三曰譬、四曰合、五曰结，六曰义如下偈说

修行者先苦无间等，后乃至道。问：何故？答：智谛异相故。苦集灭道智各异相，行别故。若行是苦智，此行非余智。若不尔者，无四智建立。谛亦异相，彼逼迫是苦相、生起是集相、寂灭是灭相、出离是道相。非不异智异相谛一无间等。譬如见瓶时不见衣，以瓶衣异相故。以异相故，见瓶不见衣、见衣不见瓶。彼亦如是，于异相谛见苦时不见余，如是一切。是故次第无间等。说一无间等者，彼说于谛一无间等。何以故？信圣贤故。如世尊说：比丘于苦无疑、集亦无疑、灭道亦如是。如灯俱作四事、热器、烧炷、油尽、破暗。如是一智知苦乃至修道，是故一无间等。彼说智谛异相者，不然，一相故。一切慧一智相，于一切法境界作无我行。如世尊说：一切法无我，智慧者能见。彼厌于苦时，是即道清净。谛相亦如是说。瓶衣异相者，此亦不然。何以故？自相无间等，非分故。共相境界无间等，非自相，谓色等五阴坏相。共境界智一无间等，若异者则自生过。次第无间者言：汝言贤圣说者，此则密语，此说有余义。如世尊说：若苦无疑，于一切无疑。为彼疑行故说。若彼苦无间等生，彼疑至竟不行，非数灭故。为除有余说，故世尊说。给孤独修多罗如是说言：长者！于四圣谛次第无间等。如是广说。所说如灯者，灯有多性多业过，我不取灯事。若分别时灯舍自名，前已说。彼明色入摄，力能破暗，彼热触入摄，能作余事。若不尔者，坏决定义。慧不如是，若言同者则有过，若言一相者此亦不然，行别故。无常行智异，苦空无我等行智亦各异，如是比。若不尔者，无解脱门。不坏行是解脱门。如汝说缘一切法作无我行，以顿观一切法故。此则不定思惟分。定思惟行各别谛缘，是故不应说彼厌于苦时是即道清净，不可以厌行缘于灭道，灭道是可乐事故。一切缘者不通一切，相违故。以无我行不即行，此无我行故、自性不自观故。亦无二决定性，亦不观相应共一行一缘故，亦不观共有共，一果一决定故。又说一切行无常者亦非无常行，作灭无间等，灭者常故。当知彼行远，以向真谛故说。如所说观此众生长夜成就身口意恶行。言此众生即是地狱及余恶趣，实非此人即是地狱，以向地狱故说。彼亦如是。又复是空无间等者，则非无愿无相，彼一切法境界非分故。莫言有过，是故一切法无我行是不定思惟。定思惟者有漏缘，若不尔者解脱门减。若言自相无间等非分者，不然。何以故？以观故。是自相共相，谓逼迫相是苦相，观三谛故是自相，观阴故是共相。如是一切，当知皆以观故说自相共相。言不尔者，不然。何以故？以不坏观故，前已说。前说中阴后当说，今当说。问：为有中阴、为无？答：坏相即无常相杂观名为坏三脱，异观故不坏

此说有中阴。何以故？世尊所说故。如世尊说：七士夫趣有中般涅槃。若无中阴者，则无中般涅槃。若言有中夭从彼般涅槃者，不然，天趣中不说故。世尊修多罗说：四天王天乃至非想非非想处，不说有中夭。余亦有过。若说生般涅槃，复有名生天耶？如是一切。阿那含亦应如是说过。是故彼是妄想说。若言寿命中间般涅槃者，不然，除欝单曰及后边菩萨，多有众生不尽寿而死，此皆是中般涅槃耶？是故此皆有过。问：此云何？答：譬如村间道。如从一村至一村，如是死阴生阴，从死阴趣生阴亦如是。如《阿湿波罗延经》说：若彼处来，如是广说。若无中阴者则无去来，是故应有中阴。若言为除有余说修多罗，故世尊说修多罗及偈言。五无间罪作已，次第生无间地狱中。又复为梵志说偈言：少为老病漂，到于阎王所，梵志无住处，亦无有资粮。是故无中阴者此不然。何以故？业趣无间，故说修多罗及偈，谓作无间业已必先受无间报，然后受余业报，亦必生地狱趣中非余趣。如汝所解，世尊说修多罗，五无间业作已，次第生地狱中。为要五无间生地狱中？为二三四耶？为更余罪生地狱中耶？当知此经及偈意。

若言如影者，如月极远，影现水中，非彼月来至水中。如是死阴生阴如影，众生生，何用中阴为者，此亦不然。何以故？彼则有俱过。月及水俱，死阴生阴不俱，是故有过。眼识足下身，识譬亦如是。若先取生阴而舍死阴，如折楼虫者，不然。何以故？趣不别及二识合过故。是故说有中阴，如所说四种萨婆多。问：为有一切有、为无？答：

此有是萨婆多所立。一切者，谓十二入。彼诸入有自相非余，一切相所作别故。作业别，前已说。一切无一切者，谓学法中有学法无无学法，无学法中有无学法亦无学法。如空中亦无有迹，如是比。问：此说有，云何无有？答：无有他相法。如眼相是眼入，无余入相，相别故。以是故说一切法不杂。

有三世萨婆多，此萨婆多所立。问：何故？答：现在世者，观过去未来故施设，若无过去未来者，则无现在世。现在世无者，亦无有为法，是故有三世。莫言有咎。若言久远是过去、当有是未来，非是有，唯有现在者，此不然。何以故？有业报故。世尊说：有业有报。非是业、报俱现在。若业现在，当知报在未来。若报现在，当知业已过去。若言俗数说者，亦说作者不可得。若言俗数说有业有报者，此亦不然。世尊亦说作者不可得。此亦俗数说耶？神口所说第一义空修多罗，而汝妄想说此有故彼有，如是比。当知如汝说，久远是过去、当有是未来，非是有，唯现在是有者，莫作是说。我亦能说现在者于既往是未来，于当有是过去。此非智者说。如所说若无信等五根，我说是凡夫辈。若学人缠所缠，信等五根不现在前，道与烦恼不俱故。是故应知有过去未来。若异者，圣人应是凡夫。若言得随生，此亦不然。无法得非分故。依处非分故。声闻僧无佛者。声闻僧不摄佛。何以故？三宝不减故。若世尊声闻所摄，应有三宝非三佛，无别体故。归依及不坏净念等亦如是。莫言有过，是故声闻僧不摄佛。如世尊修多罗说：憍昙弥！施僧亦是供养我。当知是说比丘僧、圣僧、福田僧，世尊者彼三僧所摄，破烦恼故、圣故、第一义福田故，非声闻僧自觉故。

若广说者众生怖畏，是故我今不广说。章句深达，阿毘昙明净智慧所解，诸论音声妙义于此略说。

我今于尊者法胜所说中，以少智慧思量撰集造立章句，将以申述助宣遗法，非欲憍慢求名称故。如彼所说，若生诸烦恼是圣说。有漏灭道亦生烦恼，而非有漏增，烦恼非分故。无漏缘烦恼灭而不增，前已说。是故我说增也。无漏缘软中上不增者，不然，依增故。

于此论章句义味，能决定知、善分别说者，于诸智慧众中心无怯畏，善解法相故。

经本至略，义说深广，难可受持。如虚空论，难可了知，前已说。是故增益论本，随顺修多罗义，令易了知。以知义故，烦恼则断。
