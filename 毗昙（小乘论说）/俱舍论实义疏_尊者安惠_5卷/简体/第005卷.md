# 俱舍论实义疏 · 第五卷

> 尊者安惠造

稽首薄伽众德山，稽首达磨大智海， /
稽首僧伽和合众，掣斯论主及吾师。 /
我将萤耀助阳光，随力弘宣对法藏， /
为利群生法久住，愿以威神见护持。 /

智断及利他，方便期造论， /
立名对法藏，惣七义应知。 /

彼人解脱种，我观极微细， /
犹如诸矿中，真金隐兹住。 /

回施之福及利己，自修回施二福德， /
复因利乐诸有情。如上众多福智聚， /
果证非他遂自得，行愿福及回施福， /
自他俱利不唐捐。

乳母甘饍用资身，为子获安非为己， /
佛修福智趣菩提，本为利生非为自。 /

时雨虽普降，无种芽不生， /
佛虽化世间，缘阙不得果。 /

善知识者谁？谓佛令生智， /
离放逸恶行，违此即舍离。 /

若离择法定无余，能灭诸惑胜方便， /
由惑世间漂有海，因此德佛说对法。 /

苾刍意寂静，于事得永断， /
能尽生死际，更不受后有。 /

诸佛出现乐，演说正法乐， /
僧众和合乐，同修勇进乐。 /

乱心无心等，随流净不净， /
大种所造性，由此说无表。 /

初阙相续及假是，无心随流表相杂， /
重置等言不简别，故此说中有六失。 /

作等余心等，及无心有记， /
无对所造性，是名无表色。 /

地谓显形色，随世想立名， /
水火亦复然，风即界亦尔。 /

趣求诸欲人，常起于希望， /
诸欲若不遂，恼坏如箭中。 / 说六识

受领纳随触，想取像为体， /
四余名行蕴，如是受等三， /
及无表无为，名法处法界。 /

三蕴与无表，及三种无为， /
此法处所摄，法界亦如是。 /

识为各了别，此即名意处， /
及七界应知，六识转为意。 /

惣摄一切法，由一蕴处界， /
摄自性非余，以离他性故。 /

如鱼处泥中，跃水令浑浊， /
无明中倒想，污患亦复然。 /

牟尼说法蕴，数有八十千， /
彼体语或名，此必行蕴摄。 /

空界谓窍隟，传说是明暗， /
识界有漏识，有情生所依。 /

一有见谓色，十有色有对， /
此八除色声，无记得三种。 /
五无分别，由计度随念， /
以意地散惠，意诸念为体。 /

内五有熟养，声无异熟生， /
八无碍等流，亦异熟生性， /
余三实唯法，刹那唯后三。 /

眼法界一分，八种说名见， /
五识俱生惠，非见不度故。 /
眼见色同分，非彼能依识， /
传说不能观，被障诸色故。 /

眼不下于身，色识非上眼， /
色于识一切，二于身亦然。 /
如眼耳亦然，次三皆自地， /
身识自下地，意不定应知。 /

## 分别根品第二之一论卷第三

颂曰：

论曰：眼等五根至闻声别故。颂云：

颂曰：

若男入胎，于母生爱、于父生恚。若女入胎，于父生爱、于母生恚。由如故知能续后有，皆是染心。是以意根于续后有。

经云：父母精血入胎者，识所摄持方能成就羯剌蓝也。

释曰：此显身语随心转义。如契经言：心能导世间，心能遍摄受，如是心一法，皆自在随行。颂曰：

论颂云：

颂曰：

言最后三根定是无漏，除此三根之外不通无漏。契经言：尔时世尊成正觉已，作是思惟：我所证法甚深微妙，难见难解、不可思议，非寻思境，是智者所知，非凡愚所及。斯诸众生久习邪教，爱着诸有，诸见所惑乱故不能解了。以不了故不能信受，及生娆恼。我所言说无所利益，唐没劬劳。不如寂法受解脱乐。作是念已默然而住。尔时娑婆世界主大梵天王知佛世尊作如是念，即自思惟：此世界中诸众生等多所失坏。今佛世尊证无上法，深广微妙虑诸众生不能信受，遂处闲寂受现法乐。我应诣彼劝请世尊转妙法轮。作是念已，譬如壮士屈申臂顷，从梵宫没，至于佛所。顶礼佛足，遶三匝已，却住一面，合掌恭敬而白佛言：世尊！此世界中诸众生等久习异教，见惑萦缠，流转生死，无所归依、无所救护。世尊旷劫为诸众生修行引，今者得成无上正觉证无上法，出现于世如优昙花。不为有情随机演说，处于闲寂静默而住。唯愿世尊降大悲心哀愍世间，为诸有情说正法要。有诸众生诸结微薄，机宜成熟、利根易化，不闻法故自然损减失大法利。唯愿世尊为诸众生开甘露门、说微妙法，令诸有情利益安乐。尔时大梵天王劝请世尊而说偈言：󰢷

尔时世尊闻梵天王劝请偈已，起大悲心，即以道眼观诸有情，或有钝根执着诸有，或有中根少厌生死，或有利根而不放逸。如是世尊观诸世间一切有情，处在世间或生或长，根有利钝，或有易化得道。如实知已，受梵王请，许转法轮，而说偈言：

颂曰：

论：唯一命根定是异熟。释曰：无一命根非是异熟。颂曰：

等世间有情所余福业，咸发愿言：愿我长寿。亦不愿言：愿我住寿至于百年或住九十八十年等。或有尊人及亲友等恒祝之言：愿汝长寿。亦不定言尔所时等。以此洲人所作诸业，与贪心俱，作是愿。契经中说：苾刍当知，毘婆尸佛时人寿八万岁，乃至迦叶波佛时人寿二万岁。我今出世，人寿百岁。少出多减等。寿若无定限者，世尊何故作如是说？劫初诸根大种殊胜，寿即延长。今时渐劣，故寿难至于十岁。福尽即死，不因命也。修故塔寺能延其寿。颂曰：

传说五于四，四根于二种， /
五八染净中，各别为增上。 /

譬如明眼人，能避现险难， /
世有聪明者，能离当苦惠。 /
多闻能知法，多闻能离罪， /
多闻舍无义，多闻得涅槃。 /

身由食住，命托食存，食已令心， /
适悦安泰。

了自境增上，惣立于六根， /
从身立二根，女男情增上。 /
于同住杂住，清净增上， /
应知命五受，信等立为根。 /
未当知已知，具知根亦尔， /
于得后后道，涅槃等增上。 /

身不悦名苦，即此悦名乐， /
及三定心悦，余处此名喜， /
心不悦名忧，中舍二无别， /
见修无学道，依九立三根。 /

唯无漏后三，有色命忧苦， /
常知唯有漏，通二余九根。 /

世尊出现为优昙，旷劫难逢今一遇， /
普为有情获法利，唯愿广开甘露门。 /

大梵天王善谛听，我所得法甚微妙， /
今为汝等广开演，令于长夜获安乐。 /

命唯是异熟，忧及后八非， /
色意余四受，一一皆通二。 /

北洲定千年，西东半日减， /
此洲寿不定，后十初叵量。 /

梵行妙成立，圣道已善修， /
寿尽时欢喜，犹如舍众病。 /
