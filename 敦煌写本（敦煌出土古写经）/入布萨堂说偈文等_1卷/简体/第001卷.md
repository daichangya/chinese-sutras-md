# 入布萨堂说偈文等 · 第一卷

---

持戒清净如满月身口皎洁无瑕秽 /
清净和合无违诤尔乃可得同布萨 /

八功德水净诸尘灌掌去垢心无染 /
奉持禁戒无缺犯一切众生悉如是 /

罗汉圣僧集凡夫众和合 /
香汤浴净布萨度众生 /

香水勋沐澡诸垢法身具足五分充 /
般若圆照解脱满群生同会法界融 /

戒香定香解脱香光明云台遍世界 /
供养十方无量佛见闻普勋证寂灭 /

金刚无碍解脱筹难□□□□□菓 /
我今欢喜顶戴受一切众生悉如是 /

具足清净受此筹具足清净还此筹 /
坚持禁戒无缺犯一切众生悉如是 /

清净如满月清净应布萨 /
身口业清净尔乃同布萨 /

诸佛出世第一快闻法奉行欢喜快 /
大众和合寂灭快众生离苦安乐快 /
