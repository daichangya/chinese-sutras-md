緣縛於自地，上地亦復然。 /

謂彼諸餘使，當知緣自種， /
緣使自境界，一切所依品。 /

若使無漏緣，他地緣煩惱， /
自品相應使，境界解脫故。 /

彼使身見者，見苦所斷種， /
見集一切遍，見苦餘亦然。 /

如苦集亦爾，滅道有漏緣， /
盡使於自種，修道斷亦然。 /

見苦使自品，緣使及相應， /
見相應無明，緣使餘亦然。 /

若滅境界見，彼俱生無明， /
諸一切遍使，有漏緣相違。 /

彼使與微入，隨入亦隨逐， /
是從三事起，當知不斷等。 /

身見受邊見，彼相應無明， /
欲界中無記，色無色一切。 /

貪欲瞋恚慢，過去或緣起， /
未來說一切，餘二世盡縛。 /

煩惱次第起，自地於自地， /
上地亦生下，當知隨次生。 /

有扼漂流取，泄漏與結縛， /
以是義故說，扼流取漏縛。 /

數有二十九，亦說二十八， /
三十六十五，欲等扼流性。 /

謂前三十四，次種說三十， /
第三者說六，第四三十八。 /

說彼欲漏性，當知四十一， /
有漏五十二，無明漏十五。 /

無知故猶預，猶預故邪見， /
因此邪見故，轉生諸身見。 /

從是起邊見，戒取戒想取， /
於彼決定已，次第生見取。 /

自見則生欲，他見則起恚， /
自見舉名慢，從使轉生纏。 /

無慚與無愧，睡悔慳嫉掉， /
眠忿及與覆，是上煩惱纏。 /

無愧睡與眠，此三無明依， /
掉慳及無慚，是從貪欲生。 /

覆纏二使依，悔則因猶豫， /
忿嫉瞋恚依，明智之所說。 /

所謂煩惱垢，害恨瞋恚依， /
誑高依貪欲，是義應當知。 /

所謂五邪見，諂依由是生， /
說依見取果，是惱應當知。 /

一切煩惱俱，說睡及與掉， /
無慚不善俱，無愧亦復然。 /

悔在於意苦，修道之所斷， /
眠唯在欲意，餘各自建立。 /

所謂慳與嫉，獨立離於二， /
是故此二纏，立於九結中。 /

諸使在三界，盡捨根相應， /
隨地諸根使，相應至色有。 /

邪見及無明，欲界中樂苦， /
瞋恚疑唯苦，謂餘一向樂。 /

謂勳二相應，見斷唯應意， /
欲界諸煩惱，說諸根相應。 /

貪欲瞋恚癡，當知六識俱， /
謂欲隨道斷，上地隨所得。 /

無色界一切，非事慢意地， /
當知彼七使，自性果及人。 /

一時斷煩惱，正智之所說， /
如此諸解脫，亦非一時得。 /

謂彼緣中覺，及說彼緣斷， /
亦說得對治，又復彼緣滅。 /

欲界中解脫，聖說四斷知， /
離色無色界，當知五斷知。 /

苦集煩惱盡，總說一斷知， /
滅道斷各一，如欲上亦三。 /

修道斷當知，界界斷說一， /
三斷是智果，餘則說忍果。 /

初地說一切，禪五亦復八， /
無色說一果，眷屬果亦然。 /

世俗道果二，聖九法智三， /
未知智說二，彼品果六五。 /

或有諸聖人，未成就斷知， /
或成一二三，四五及與六。 /

捨一二五六，如捨得亦然， /
得果及度界，二處斷知集。 /

謂彼二因滅，離繫及度界， /
得於無漏得，及缺第一有。 /

好境俱不俱，彼二種愛生， /
惡境二亦然，一則謂為捨。 /

謂使煩惱心，障礙不違淨， /
妙善心可得，非不相應使。 /

初則名始業，次則已習行， /
思惟已度者，當知第三種。 /

若此煩惱怖，遠離諸賢聖， /
如實正具足，方便應善聽。 /

始於自身分，繫縛心令定， /
欲縛於識足，為盡智慧怨。 /

是方便於身，真實相決定， /
諸受及自心，法亦如是觀。 /

三種說念處，自性及與共， /
亦說名為緣，聞等慧亦然。 /

入法中總觀，得法真實相， /
此四是無常，空無我非樂。 /

從是名為煖，於法覺而生， /
十六行等起，觀察四聖諦。 /

是法增長已，生頂及於忍， /
得世第一法，依於一剎那。 /

下苦有四行，說攝依六地， /
忍法亦如是，謂餘或依七。 /

世間第一法，次生苦法忍， /
忍次生於智，俱觀於下苦。 /

謂色無色苦，集滅道亦然， /
此法無間等，說是十六心。 /

隨法行利根，此在十五意， /
隨信行鈍見，當知亦在中。 /

隨信隨法行，若具煩惱縛， /
乃至五種斷，當知向始果。 /

六斷乃至八，是向第二果， /
離欲至八地，是則第三向。 /

若至十六心，是名住於果， /
軟見信解脫，利見名見到。 /

非事諸煩惱，謂彼一切盡， /
乃至未進行，是名須陀洹。 /

未盡修道種，受生生死七， /
當知彼所說，極滿須陀洹。 /

若斷三四種，成就彼對治， /
餘二生三生，是說名家家。 /

六品煩惱斷，見道斷一切， /
是說斯陀含，謂彼未進行。 /

若七八品斷，成就對治根， /
餘則受一生，是名一種子。 /

九品盡不還，當知有多種， /
或五及七八，或復說眾多。 /

十五有二十，三十與八十， /
九十百二十，及三百六十， /
四百八十種，千四百四十， /
如是廣略說，攝受阿那含。 /
根地及種性，處所廣建立， /
隨彼煩惱斷，今當次第說。 /

一三四與六，十六及十八， /
謂說二十四，復說三十六， /
七十有二種，九十有六種， /
二百一十六，二百八十八， /
六百四十八，八百六十四， /
又復說二千，五百九十二。 /

利根軟煩惱，住於一種業， /
是中般涅槃，分別六種性。 /

精進勤方便，修習速進道， /
是生般涅槃，彼亦有二說。 /

第三勤方便，離於速進道， /
第四不勤求，三俱說六種。 /

超半超處處，是名為上流， /
此亦六種性，當知進不進。 /

謂生根煩惱，是說有三種， /
不生亦復然，及二上流一。 /

如是九煩惱，在於上八地， /
謂彼雙道滅，世尊之所說。 /

有垢無垢道，俱能離八地， /
住彼說身證，謂得滅正受。 /

金剛喻定次，必生於盡智， /
生意我生盡，應供離諸漏。 /

阿羅漢六種，隨信行生五， /
彼得於二智，當知時解脫。 /

不動法利根，是不時解脫， /
彼得於三智，自解脫成就。 /

慧解脫當知，不得滅盡定， /
若得滅盡定，當知俱解脫。 /

諸根說九種，亦說九種人， /
七種諸聲聞，緣覺及如來。 /

軟中最軟根，是為初種人， /
乃至增上上，第九人當知。 /

謂以學種性，得彼無學果， /
或即彼種性，或進不退轉。 /

所謂三四五，六七次第增， /
是諸退法等，說五羅漢等。 /

謂隨信行法，若隨法行法， /
及與見諦道，是盡同一相。 /

於中諸根法，是名未知根， /
謂餘有學法，佛說已知根。 /

當知無學法，是說無知根， /
得果捨前道，無礙智所說。 /

方便及諸根，正受解脫俱， /
當知賢聖七，事則說有六。 /

一三五十五，及與七十三， /
謂根種性道，離煩惱當知， /
三倍次五倍，十五及九倍， /
如是眾多種，唯說隨信行。 /

以有五事故，說有八人名， /
先後事各一，中間則有三。 /

已盡為解脫，得依於一果， /
不穢污第九，滅盡應當說。 /

無著相似名，彼能獲不動， /
信解脫種性，昇進亦增道。 /

或有學果滿，或根或正受， /
或復三俱滿，無學二亦然。 /

建立功德惡，漸漸見真諦， /
無礙道力得，有為無為果。 /

謂三無間等，緣事見無間， /
當知有三種，或二亦復一。 /

若智性能了，明照一切有， /
有無有涅槃，彼諸相今說。 /

三智佛所說，最上第一覺， /
謂法智比智，及世俗等智。 /

苦集及滅道，二智從諦生， /
是名與四智，牟尼隨諦說。 /

若智觀他心，是從三中說， /
盡無生智二，境界在四門。 /

對治及方便，自性行行緣， /
已作因長養，是故說十智。 /

九智唯說善，一智三分別， /
一見二非見，餘則有二種。 /

學與無學六，二智說無學， /
非學無學一，當知一三種。 /

八智性不斷，二知二種說， /
有漏無漏一，一則說有漏。 /

四智有為緣，有常緣則一， /
五智二境界，明智之所說。 /

法智應當知，是從六地起， /
比智則九地，他心智在禪。 /

等智應當知，在於十一地， /
謂彼諸餘智，品品如前說。 /

若說諸念處，一智當知後， /
三則說一智，餘四明智說。 /

一智欲界依，二界依有一， /
二智三界依，餘六一或三。 /

名則十六行，事或說十六， /
離於十六行，除闇非無漏。 /

二智十六行，法智及比智， /
如是行或非，是說為等智。 /

四智有四行，決定行所說， /
若智知他心，如是行或非。 /

盡智無生智，離空無我行， /
說有十四行，謂近於等故。 /

謂慧行能行，亦為他所行， /
餘有依二種，無依他所行。 /

謂初無漏心，或有成就一， /
二或成就三，四時各增一。 /

若得修於智，謂在聖見道， /
即彼當來修，諸忍亦如是。 /

於彼三心中，得修於等智， /
當知最後心，或修七或六。 /

於彼上修道，十七無漏心， /
當知修於七，增益根或六。 /

得不還果時，及離上七地， /
勳修諸神通，解脫修習八。 /

此諸無礙道，及滅第一有， /
即彼八解脫，當知修於七。 /

第一有離欲，無礙道修六， /
上乘應當知，修習於下地。 /

無學初心中，修於一切地， /
無學相似修，或苦習比智。 /

盡智心俱修，善有漏功德， /
九地至一地，次第修亦減。 /

諸忍則非智，盡無生非見， /
餘一切聖慧，當知三種性。 /

若善有漏智，在意則是見， /
煩惱見是智，此及餘說慧。 /

法智及比智，觀察於九智， /
因智及果智，境界於二智。 /

道智緣九智，解脫智無緣， /
餘一切境界，決定智所說。 /

謂彼滅及道，法智之所行， /
是三界對治，非欲界比智。 /

神足天眼耳，是說一等智， /
或六智宿命，五說他心智。 /

處非處智力，及第一無畏， /
此是佛十智，餘此中差別。 /

淨業有愛果，不淨果不愛， /
此說為是處，異則說非處， /
應當如是知，是處非處力。 /

彼十智自性，在於十一地， /
決定說如來，謂閻浮提依。 /

第二力八智，於彼事業轉， /
及法受煩惱，餘則如前說。 /

諸禪及背捨，正受三摩提， /
第三力迴轉，九智餘如前。 /

於上下諸根，第四力迴轉， /
第五說解力，第六於界緣。 /

於彼種種趣，第七力迴轉， /
當知已說四，餘皆如前說。 /

知宿命有行，是說第八力， /
謂禪有煩惱，餘則如前說。 /

第九力當知，遠離於所緣， /
命終及受生，行於眾生數。 /

第十力十智，或六一切地， /
示現力明通，餘皆如前說。 /

初則如初力，第二如第十， /
餘二如二七，是名無畏安。 /

第四禪有垢，無諍三方依， /
緣欲未生惱，依不動智慧。 /

所謂妙願智，遠離彼境界， /
於彼最後得，六智自在性。 /

義辯漏無漏，在於一切地， /
佛說為方便，餘則如前說。 /

所謂為應辯，境界道及說， /
因明論方便，或三餘如前。 /

法辯緣施設，在於五地中， /
以數為方便，餘如無諍說。 /

聲明論方便，是則為辭辯， /
境界於言說，二地餘如前。 /

智依於諸定，安不動而轉， /
是故當思定，勤求見真實。 /

決定說四禪，及與無色定， /
是中一一說，味淨及無漏。 /

善有漏是淨，無漏離熾然， /
味則愛相應，最上無無漏。 /

淨者有四分，退分及住分， /
勝進決定分，隨順諸功德。 /

五支有覺觀，亦復有三受， /
種種及四心，是說為初禪。 /

第二有四支，種種及二受， /
第三說五支，此禪亦二受。 /

離息入息出，第四有四枝， /
枝者謂說善，隨事如先說。 /

禪支名十八，事則有十一， /
無色無有支，禪眷屬亦然。 /

有覺亦有觀，是說未來禪， /
禪中間有觀，明智之所說。 /

未來或二種，謂離味相應， /
禪中間三種，亦俱說一受。 /

三摩提與通，無量一切處， /
勝處及諸智，背捨於中起。 /

二無量無恚，最後說無貪， /
第三說喜根，謂彼欲界依。 /

樂苦喜眾生，眾生無餘想， /
隨其所應轉，無量眾生緣。 /

勝處說有八，前三色背捨， /
及八一切處，無貪善根性。 /

若說彼眷屬，是則五陰性， /
此說三方依，境界欲界色。 /

背捨中最後，心不相應行， /
是說二界依，先從欲界起。 /

餘則四陰性，說彼三界依， /
或無色境界，及以無漏緣。 /

當知或有說，成就四無量， /
或復成就三，減者則不然。 /

或一乃至八，成就於背捨， /
或四亦復八，成就於勝處。 /

或一亦復二，八九及與十， /
當知彼修行，成就一切處。 /

五通在四禪，根本非餘地， /
諸智如前說，三無量或六。 /

彼前四勝處，及與喜無量， /
亦初二背捨，在於初二禪。 /

餘有四勝處，及與一背捨， /
亦八一切處，說在最上禪。 /

餘即名背捨，二一切亦然， /
滅盡最在後，餘無漏九地。 /

三背捨當知，有漏及無漏， /
定智通已說，其餘悉有漏。 /

謂彼性背捨，能勝所緣處， /
無闇普周滿，名如所度說。 /

未離欲當知，成就味相應， /
離下未至上，成就淨諸定。 /

住上應當知，成就下無漏， /
方便生功德，當知非離欲。 /

根本淨初禪，是亦同一縛， /
不能斷煩惱，無量亦復然。 /

當知五背捨，及與八勝處， /
亦十一切處，不能斷煩惱。 /

所謂無漏定，一一七種因， /
味相應因一，謂彼淨亦然。 /

無漏禪無色，逆順超次第， /
次第生六種，七八九與十。 /

從六至十一，謂淨次第生， /
次生二至十，味相應非三。 /

淨與無漏禪，緣於一切地， /
自地有漏法，味相應所緣。 /

無色則不緣，下地有漏種， /
謂根本善有，穢污如味禪。 /

謂色界有餘，無量諸功德， /
是則緣欲界，最勝之所說。 /

若能勳諸禪，是依第四禪， /
三地愛盡故，淨居唯果實。 /

或有念正受，或畏諸煩惱， /
或復樂受生，是各隨義說。 /

離欲及受生，而得於淨禪， /
穢污退及生，無漏唯離欲。 /

無漏除煩惱，及正受中間， /
一切定中間，相應於捨根。 /

隨識現在前，上地則成就， /
捨則不成就，心力羸劣故。 /

受生及離欲，得是諸化心， /
二三及與四，亦五一時得。 /

或有二三四，五七及與九， /
增三或亦五，如是成化心。 /

一切智所說，修多羅妙義， /
我今當少說，修行宜善聽。 /

惠施持淨戒，是各有四種， /
修禪則有二，說名為功德。 /

無貪相應思，俱起同一果， /
眾具處所生，此則是施性。 /

所謂自攝受，亦復攝受他， /
或有二俱攝，或二俱不攝。 /

若未離欲者，供養於支提， /
及凡夫離欲，是名自安施。 /

離欲非凡夫，除其現法果， /
施與諸眾生，是名為攝他。 /

未離欲界欲，已離欲凡夫， /
施與諸眾生，當知二俱攝。 /

離欲非凡夫，除其現法果， /
供養於支提，是則俱不攝。 /

或有為攝他，供養於支提， /
無量眾見聞，皆生隨喜心。 /

謂彼希望等，七種施非上， /
第八莊嚴心，是名最勝施。 /

壽色力安樂，辯才等五種， /
施報百千等，施主之所獲。 /

慈無諍滅定，見道及無學， /
從彼正受起，施者得即果。 /

父母若病人，及與說法師， /
近佛諸菩薩，施者得大果。 /

善說諸經法，遠離諸顛倒， /
不謗於牟尼，是說為法施。 /

以離等受說，安慰諸恐懼， /
是名無畏施，能壞貧窮怖。 /

普於群生類，等受戒律儀， /
功德流增廣，是則為大施。 /

欲界及禪生，無漏戒律儀， /
斷律儀從二，是說律儀種。 /

或以希望受，或以恐怖持， /
有順菩提支，及與清淨戒。 /

根本眷屬淨，不為覺所壞， /
攝受於正念，隨順般涅槃。 /

禪無色無量，得修及習修， /
不淨安般念，二修義亦然。 /

二十說欲界，色界或十六， /
無色界有四，處所次第說。 /

善趣在欲界，及色界三地， /
無色三亦然，是說為識住。 /

第一有無想，是說眾生居， /
謂有漏四陰，是說四識住。 /

煩惱及業事，彼隨次第生， /
當知是有支，眾生一切生。 /

此諸分建立，謂眾生受生， /
過二及未生，中間說於八。 /

三有支煩惱，二業事則七， /
七名前有支，五則說後分。 /

前支五說果，餘二則為因， /
後支三說因，餘二則為果。 /

前癡後愛取，行有合亦然， /
名色入觸受，是說同老死， /
謂初受身識，是則未來生。 /

煩惱起煩業，彼業轉生事， /
事亦生於事，亦復生煩惱。 /

謂彼相續轉，剎那與連縛， /
及前謂分段，此則說緣起。 /

生攝一切趣，非趣攝於生， /
謂生中陰增，當知非趣攝。 /

所謂四大種，及諸有漏識， /
亦色中間相，此界說生本。 /

謂性果諸行，有漏是說苦， /
因性則為集，滅諦眾苦盡。 /

若無漏諸行，是說為道諦， /
此二因緣故，麁細次第現。 /

聖果事有六，最勝在九地， /
第三在六地，二種依未來。 /

隨信行行法，離煩惱遲相， /
隨法行行法，離煩惱速相。 /

根本禪地中，當知是樂道， /
減及難得故，當知是說苦。 /

佛及聲聞法，解脫亦餘因， /
清淨無垢信，聖戒謂決定。 /

初禪若有善，說名現法樂， /
謂得生死智，是說名知見。 /

當知分別慧，方便生功德， /
金剛喻四禪，是名為漏盡。 /

善有為諸法，方便之所起， /
佛說如意足，是亦說正斷。 /

此說四念處，四聖種亦然， /
如其增上生，是皆隨名說。 /

淨信精進念，智慧及喜猗， /
覺品相應捨，思戒三摩提。 /

處方便自在，軟及利亦然， /
見道亦修道，故說三十七。 /

二禪三十六，未來亦復然， /
三四及中間，是悉三十五。 /

初禪說一切，無色三十二， /
最上二十二，欲界亦復然。 /

諸食中摶食，欲界說三入， /
識食思及觸，是食說有漏。 /

無願有十行，二行是空定， /
四行說無相，是說為正行。 /

謂彼四顛倒，當知見苦斷， /
三見自性增，見實者分別。 /

誹謗於真實，此見是邪見， /
不實而妄置，是二見及智。 /

非因而見因，是說為戒取， /
若攝受邊見，依斷滅有常。 /

誹謗及妄置，因見及二邊， /
於此諸事轉，或見彼則斷。 /

謂眼等四根，身根有三種， /
意根及與命，是根生死依。 /

增上是根義，五根說四種， /
當知餘四根，各有二增上。 /

受或煩惱分，信等依清淨， /
九根若無漏，此三依於道。 /

欲界四善八，色種根有七， /
心法則有十，一心三根二。 /

於此諸根中，一及十有報， /
十二中是報，命根唯是報。 /

二或六七八，最初生時得， /
當知欲界報，色六無色一。 /

捨四八與九，或復捨於十， /
漸終及頓沒，善捨各增五。 /

二斷無斷四，六根則二種， /
三無漏不斷，餘則修道斷。 /

或成就三四，五七及與八， /
十一與十三，是說定成就。 /

九根得初果，或獲二沙門， /
謂以十一根，究竟第四果。 /

若取諸根義，五種心境界， /
若取一切法，是則說意識。 /

欲色界諸陰，無色與無漏， /
有依無依八，及彼二無為。 /

五法應當知，法智之境界， /
比智七為緣，他心境界三。 /

有漏當知十，因果智有六， /
解脫一道二，餘二境界九。 /

自地諸煩惱，定使於自地， /
自種一切遍，隨使於彼種。 /

若定三界法，三界使所使， /
二界生當知，一界亦復然。 /

此經牟尼說，其性已分別， /
識知及諸使，當知是三門。 /

已分別諸法，一一定相續， /
於上眾雜義，是今當略說。 /

有緣亦相應，有行及有依， /
心及諸心法，是同一義說。 /

從緣生亦因，有因亦有為， /
說處及與道，有果應當知。 /

有罪亦隱沒，穢污下賤黑， /
善有為說習，亦復說名修。 /

無想二正受，亦眾生種類， /
句味與名身，命根與法得。 /

謂彼凡夫性，及諸法四相， /
非色不相應，說是有為行。 /

二善五種三，當知七無記， /
二在於色中，一在無色地。 /

二界說有三，餘在於三界， /
有漏無漏五，餘則盡有漏。 /

初無漏心中，當知捨不得， /
凡夫流諸界，離欲時滅盡。 /

煩惱斷離繫，是名為數滅， /
無諸障閡相，是說為虛空。 /

依於諸緣法，有依及境界， /
不具則不生，此滅非是明。 /

前因相似增，或俱依倚生， /
二因及一緣，一向已生說。 /

報謂眾生數，有為解脫果， /
有緣說俱行，謂於他相轉。 /

有為解脫果，一切有為法， /
說果有因生，故及數緣滅。 /

普因無方處，生時心解脫， /
煩惱在道心，乃至滅時捨。 /

有愛有五種，無有唯一相， /
愛事餘煩惱，滅盡是三界。 /

若得九種法，當知穢污心， /
善心得六種，無記即無記。 /

道品有六法，當知是根性， /
諸法若相應，是說為他性。 /

緣中得解脫，大仙之所說， /
亦有斷而縛，見道及修道。 /

二解於三諦，四由見正道， /
而得不壞淨，修習於二世。 /

一切諸心法，說與心俱轉， /
亦此心諸相，餘相及所作。 /

斷法謂有漏，知者亦無垢， /
滅未來說遠，餘則說於近。 /

所謂無間業，及諸無漏道， /
慧說名為定，見處謂有漏。 /

說有十九根，謂成就極多， /
極少成就八，曉了根所說。 /

增語及有對，明無明處中，以多名故說增語 /
所謂得果者，是則雙道事。 /

若智在苦因，及忍說為厭， /
能離貪欲故，說四為離欲。 /

羅漢住報生，及與威儀心， /
隨順心滅故，趣向般涅槃。 /

生有及壞有，本有亦復中， /
當知二剎那，一染三有二。 /

若離欲界欲，越度第一有， /
及與起忍法，極為業障礙。 /

當知有五種，自性及與因， /
繫縛若攝受，一切境界事。 /

說陰即為事，界入事亦然， /
及與世剎那，是名五種事。 /

育多婆提說，安立及方便， /
亦說和合修，是名為四果。 /

運身及意解，意念自在通， /
意念唯如來，當知二則共。 /

入色無色界，亦復增益根， /
及與賢聖退，生中間定無。 /

劫減佛興世，增時轉輪王， /
二時辟支佛，如是應當知。 /

若彼諸法生，二得共俱起， /
二得俱生者，當知有得得。 /

諸得有十五，得於苦法忍， /
其餘見增道，當知一一減。 /

若於彼地中，斷及壞對治， /
即攝解脫得，法智比智品。 /

與道俱起得，俱起而非因， /
道亦非彼因，後起或有無。 /

空行有垢住，是說為空空， /
說無學境界，在於十一地。 /

行於無常行，是無願無願， /
俱在於不動，欲界餘如前。 /

謂無相無相，彼行於寂止， /
行於無記滅，餘則如前說。 /

超越三摩提，上下至第三， /
及不念思惟，於緣超亦然。 /

佛語善無記，如彼初心轉， /
究竟亦復然，無記或清淨。 /

聲聞則不定，究竟及與轉， /
說時不退減，唯是佛世尊。 /

諸入中有四，可燒亦能燒， /
可稱亦能稱，斷能斷無惑。 /

地謂色形處，堅相說地界， /
餘二亦二種，風即風或異。 /

福分說一種，及與解脫分， /
於福決定分，第四離諸漏。 /

當知布施等，能轉於惡趣， /
必定與忍俱，施等同或異。 /

離欲及退時，受生亦命終， /
斷善及相續，當知是意識。 /

謂一切眾生，悉住於捨受， /
命終及受生，以不捷疾故。 /

雖已說多法，決定眾雜義， /
於彼無量處，當復擇其要。 /
牟尼說見道，疾故名法輪， /
或說學八支，轉至於他心。 /

佛說具足道，廣大名梵輪， /
齊輻輞具足，對治非梵行。 /

謂優波婆素，受時他二說， /
具足一日夜，離嚴飾威儀。 /

尸羅支有四，不放逸支一， /
餘則是持支，齋支慧所說。 /

具律優婆塞，比丘律儀一， /
以彼缺減義，牟尼說少分。 /

二律儀妙行：業道初解脫： /
說業及尸羅：如是七種名。 /

成就身非業，或說業非身， /
或有身業俱，或亦不俱說。 /

謂入不正知，及住與出胎， /
乃至入正知，住出亦復然。 /

初者不淨業，亦復不求智， /
中二各成一，第四俱成就。 /

住於初果者，一種不淨業， /
而不墮惡趣，業不具足故。 /

四食在欲界，四生趣亦然， /
三食上二界，摶食彼則無。 /

於彼餓鬼趣，意思食為增， /
及與諸卵生，三無色亦然。 /

胎生摶食增，謂彼人趣中， /
地獄識食增，第一有亦然。 /

欲天如人趣，色界觸食增， /
及與畜生趣，濕生亦復然。 /

歸依彼諸佛，所得無學法， /
涅槃無上法，僧學無學法。 /

緣覺菩薩道，及與三真諦， /
於彼無垢信，是法不壞淨。 /

隨生清淨戒，佛僧如歸說， /
此事有二種，說有四種名。 /

所謂沙門果，無為亦有為， /
有為學果三，無學果第四。 /

八十九聖人，沙門無為果， /
亦說於有為，一切沙門道。 /

雖知一切空，而非知一切， /
除其共相應，自性亦復然。 /

所謂斷對治，壞持及遠分， /
此四應當知，是名對治種。 /

初得若習行，對治及斷修， /
當知此四種，是名為修義。 /

煩惱通三界，若見斷二種， /
二斷則三種，俱見道前行。 /

若欲界煩惱，五行有二種， /
彼修齊限故，說修道前行。 /

次第緣所作，說彼法生時， /
緣緣所作業，彼法滅時說。 /

三因所作業，謂彼法生時， /
二因之所作，當知滅時說。 /

一切眾生類，心起住滅等， /
貪欲等相應，不相應亦然。 /

欲界中有四，色無色各三， /
亦學無學心，說此次第生。 /

欲界善生九，亦復從八起， /
二穢污生四，亦從十心生。 /

無記次生七，亦復從五起， /
色界善十一，亦從九心生。 /

色界穢污六，亦從八心起， /
無記次生六，從三次第生。 /

無色善生九，亦從六心起， /
穢污心生七，彼亦從七生。 /

無記心生六，亦復從三起， /
學心生於五，亦從四心生。 /

無學心生四，亦從五心生， /
已說十二心，二十應當說。 /

二善二穢污，報生及威儀， /
工巧諸禪果，欲界中八心。 /

除不善工巧，餘則在色界， /
離禪果威儀，餘四在無色。 /

學與無學心，此則為二十， /
彼心次第生，各隨其義說。 /

欲方便生十，亦從八心起， /
生得次生九，亦從十一生。 /

二穢污生七，亦從十四起， /
報生威儀八，是亦從七生。 /

工巧心生六，亦復從七起， /
變化心生二，亦即從二生。 /

色方便十二，是亦從十起， /
生得次生八，亦從五心生。 /

色穢污生九，亦從十一起， /
威儀心生七，從五次第生。 /

當知色報生，亦如威儀說， /
謂彼諸禪果，當知如欲界。 /

無色初生七，是亦從六生， /
生得亦生七，當知從四起。 /

穢污生八心，是從十心起， /
報心生於六，是亦從四生。 /

學心次生六，從四次第起， /
無學心生五，是亦從五生。 /

經律阿毘曇，是名俗正法， /
三十七覺品，是說第一義。 /

五十二及餘，亦復說八十， /
或有說十三，是金剛三昧。 /

三通則說善，餘二是無記， /
當知依欲色，世尊說慧性。 /

當知彼諸根，慧者善分別， /
名有二十二，事則說十七。 /

若事分別時，捨名則說等， /
分別無所捨，是則第一義。 /

界趣地必定，中陰五無礙， /
說名為香食，求有乘意行。 /

七日或七七，乃至彼和合， /
或裸形食香，諸根悉具足。 /

隨行量不定，或有見不見， /
入則從生門，或生顛倒想。 /

知者一切法，識明亦復然， /
知及意識明，彼各隨事說。 /

刀兵病饑饉，說名中劫過， /
除地餘三種，說名大劫過。 /

七火次第過，然後一水災， /
七七火七水，復七火後風。 /

錯亂本業報，恐怖及傷害， /
若彼解支節，聖說水火風。 /

退法有三種，得未得習行， /
或一人一退，未得退說二， /
謂彼習行退，三聖俱亦然。 /

諸天則不退，果退終不死， /
亦不造彼業，住果所不為。 /

若修諸相好，方便起彼業， /
從是轉增進，說名為菩薩。 /

一種異分別，或有說相異， /
或說分分異，或復說異異。 /

次第無間等，智諦異相故， /
見瓶不見衣，是故彼亦然。 /

當知有中陰，世尊之所說， /
譬如村間道，彼則有俱過。 /

當知一切有，非有一切相， /
一切無一切，無有他相法。 /

一切世悉有，不違其所應， /
牟尼之所說，聲聞僧無佛。 /

設令廣章句，群生大恐怖， /
無勝甚深相，我今但略說。 /

古昔諸大師，演說無量義， /
我今隨所解，分別說少分。 /

決定知此論，章句微妙義， /
於彼智慧眾，勇猛無所畏。 /

我今增益論，其心無所貪， /
為令智者樂，疾得寂滅樂。 /

## 011

問：知法、識法、明法，此云何？答：

彼苦智知苦，乃至道智知道，無漏智分段緣故。善等智者亦知苦，乃至虛空數非數滅，普緣一切法故。識者亦識一切法，彼眼識識色，乃至身識識觸，攝受自相故。意識識眼色眼識，如是一切普緣故。明者亦明一切法，隨其事。彼苦忍苦智明苦，乃至道忍道智明道，分段緣故。善有漏慧亦明苦乃至虛空非數滅。問：劫云何過？答：

刀兵病饑饉說名中劫過者，三種中劫過，謂刀兵、病疫、饑饉。刀兵劫者，謂乃至人壽十歲時，貪麁惡境界，行諸邪法，各住害心，手執草木皆成刀劍，更相殺害。如是經七日，刀兵中劫過。疾疫劫者，亦壽十歲時，多諸疾病，無有醫師方藥瞻病，薄福德故，遇病輒死。如是經七月七日，疾疫中劫過。饑饉劫者，亦壽十歲時，饑渴增上體極羸劣，普天亢旱種殖不收數米而食，煎煮人骨以飲其汁。如是經七年七月七日，饑饉中劫過。如是說者，若於今世一日一夜持不殺戒，終不生彼刀兵劫中。一呵黎勒果施僧福田，終不生彼疾疫劫中。若以一食施僧福田，終不生彼饑饉劫中。此閻浮提惡劫互起，餘方則少有相似。如此間刀兵劫起，彼唯瞋恚增上。如此間疾疫劫起，彼唯羸劣少力。如此間饑饉劫起，彼唯增饑渴。問：云何大劫過？答：除地餘三種，是名大劫過。三大種說大劫過，謂火、水、風，非地種。何以故？不利故。利者壞大劫。復次地種壞劫者，壞劫應至第四禪，而未曾至第四禪。問：何故壞劫不至第四禪？答：淨居天故。彼無上地生，即彼般涅槃故。亦不下生，下地非數滅故。若彼住經壞劫者亦不然，增上福力生彼處故，內擾亂非分故。若彼地內有擾亂者，則外有災患。彼初禪內有覺觀火擾亂，故外為火災所燒。第二禪內有喜水擾亂，故外為水災所漂。第三禪內有出入息風擾亂，故外為風災所壞。問：第四禪未曾有擾亂者，何得不常？答：剎那無常所壞故。如是說者，第四禪地不定相續，隨彼天生宮殿俱起，若天命終彼亦俱沒。問：何等劫盡最初？答：

七火次第起者，謂最初火劫起。如是說言，若火劫將起，爾時人壽八萬歲，地獄命終者不復還生，當知劫盡。乃至地獄無有一眾生住，是名地獄劫盡。如地獄劫盡，畜生、餓鬼亦如是。若畜生於人有用者與人俱盡。是時閻浮提唯有一人，無有教者能入初禪，從初禪起已舉聲唱言：離生喜樂甚為快樂。如是音聲展轉相告遍閻浮提。諸餘眾生亦無師教悉入初禪，乃至閻浮提無一眾生住，是名閻浮提劫盡。唯除欝單曰。欲界一切善趣亦復如是。欝單曰命終無得禪者，離欲非分故。又於彼時初禪一眾生無有教者而入第二禪，從禪起已舉聲唱言：定生喜樂甚為快樂。如是音聲遍至梵天。餘諸眾生亦復如是。乃至初禪無一眾生住，是名眾生世劫盡。是時世界久遠虛空，乃至七日出。問曰：從何處出？答：有說劫成時由乾陀山後有七日輪住，從彼而出。有說一日分為七分。復有說一日七倍熱。復有說從無間地獄火出。如是說者，眾生業力故，增上果器世界起。彼業盡如是擾亂生，乃至梵天燒然如是。七火次第過然後一水災者，七火災過已然後一水災，乃至壞第二禪。問：水從何處起？答：有說從第三禪際雨熱灰水。復有說水輪涌出。擾亂起如前說。七七火七水者，七火災次第過然後一水災，如是七七火災一七水災。復七火後風者，復七火災過然後一風災，水災風災從火災次第起。此則善說。是遍淨天六十四劫壽也。水災所漂乃至第二禪，風災所壞乃至第三禪，百億四天下一時俱壞。十九中劫世間空，一中劫器世界壞，一中劫器世界成，十九中劫漸次第住。若處最初空，是處最後住；若處最後空，是處最前住。問：云何心亂？答：

錯亂本業報怖畏及傷害者，四因緣心亂，謂四大錯亂、本業報、恐怖及傷害身。四大錯亂者，飲食不適故四大錯亂，四大錯亂故令彼心亂。本業報者，本造心亂，業報已熟。問：何者是？答：好傳衰禍令他愁苦。或復罵言：汝癡狂心亂。驅迫眾生令墮嶮處，焚燒山澤強與人酒，或以妄想倒說佛語。如是比業，得心亂果。恐怖者，見非人形來驚畏，恐怖故彼心則亂。傷害身者，為非人所打故。彼以不淨污大眾會處及佛僧塔，故彼處非人瞋即打，故彼則心亂。此說凡夫人。聖人無本業行報心亂。若先種定報業者，先受報已然後超昇離生。若種不定報業者，若超勝離生彼業則滅。心亂者在欲界，彼地獄不心亂，常亂故。畜生餓鬼及人則心亂，除欝單曰。欲界天亦有心亂。問：何等聖人心亂？答：須陀洹、斯陀含、阿那含、阿羅漢、辟支佛，唯佛心不亂、聲不壞、髮不白、面不皺、不漸般涅槃。

世尊擾亂業久已滅盡，行妙行故。亂者意識非五識心，不分別故。有漏心亂非無漏，真實行故。是故若說心狂亂是散亂耶。作四句。初句，謂狂者善有漏心、不隱沒無記心。第二句，謂自相住者穢污心。第三句，謂狂者穢污心。第四句，謂自相住善心及不隱沒無記心。問：何等大能解支節耶？答：若能解支節聖說水火風。三大能解支節非地大，不利故。火大解支節者，謂命終時火大增遍燒筋，燒筋已節節解，節節解已不久命終。水大解支節者，謂節節解時先令筋爛，筋爛已餘如前說。風大解支節者，令筋碎，筋碎已餘如前說。支節解已，不過日夜命終，四大錯亂故。地獄無解支節，支節常解故，業報故不死。畜生、餓鬼及三方解支節，除欝單曰，無罪業故。天亦如是。凡夫聖人解支節，唯除佛。罪報者解支節，佛無罪報故。已說解支節，退今當說。

退法有三種，得退、未得退、習行退。得退者，所得功德遇退因緣則退。未得退者，應得功德放逸故不得。習行退者，已得功德，有因緣故不得習行。問：何等人何事退？答：或一人一退。若得退者是鈍根聲聞非利根，利根者三昧力故，是故說。或云何知有得退？答：以說二種阿羅漢故，謂退法、不退法。若言道退果不退者，不然。何以故？斷得與道合故，得者道諦攝，是故道退非斷者，不然。若言離煩惱種云何生者，應說如初無漏心無前因而生，彼亦如是。復次有自分因分故，從無際生死煩惱自分因分生。言煩惱於三處起非說者，不然。何以故？為起煩惱具滿故說眾生起。煩惱具有三因緣，謂因力、境界力、方便力。彼欲愛使未斷未知是因力，欲愛纏所著法是境界力，彼不正思惟是方便力。是彼說意。若從彼說不正思惟者，前不正思惟非分則不起。若有前不正思惟，此則無窮。又復善無記心至竟不生，若不生者解脫亦非分，燒諸煩惱不應還生。如火燒木為灰，至竟為灰不復為木。如是阿羅漢以智火燒煩惱薪，不應復為煩惱。彼不應如是。何以故？譬不合故。云何如燒薪有灰？若如是，阿羅漢煩惱有餘如灰耶？若有餘者非阿羅漢，有煩惱故。若無者，不如上譬。然非彼聖道如火燒薪，但聖道起斷煩惱得解脫得作證。彼若離聖道亦捨解脫得，繫得還起。如諸退相違經說，當知說不時解脫故。未得退說二者，若彼未得退者，謂聲聞、辟支佛，非佛，住一切最勝根故。聲聞者不得佛、辟支佛勝根，辟支佛不得佛勝根，是故有未得退。略說一切眾生若修行皆應得聖慧眼，若不修行入名色者是為未得退。問：云何知有未得退？答：信佛說故。如世尊說：諸天及世人退於智慧者，染著於名色，不見聖諦故。謂彼習行退三聖俱亦然者，若習行退者，謂聲聞、辟支佛、如來三聖悉有，以中間諸因緣故，所得功德不能常現在前。問：云何知有習行退？答：說心心法退故。如世尊說：於此四種心心法得現法安樂住，我說彼一一退。如修多羅廣說。又復說，不動意解脫身作證成就遊者，彼不退。以是故知世尊亦有習行退，是故說。世尊多遊未至，非根本地。何以故？近欲界故。雖不動意解脫有習行退，然彼成就得修故，彼一切現在時得常隨轉，彼心心法者現在修，謂不現在前者名為退。習行退最多者謂世尊。何以故？功德無邊故。如轉輪聖王廣受境界。又說攝他故名不動，自攝故名心心法。世尊多攝他、少自攝，如是世尊大悲大捨。問：何處不退？答：斷者無礙知者解脫若不正思惟相續無窮則餘念不得生也

諸天則不退者，諸天不退，以利根天得果故，利根者則不退。若鈍根人得果然後生天亦不退，無生故。聖人無生不退，此前已說，退具非分故。世尊說五退具，多事業等。五退法彼天則無，是故不退，以天不退故。當知退者必人中，以退具可得故。果退終不死者，果退者終不死，要還得果。何以故？下地生非數滅故，非數滅法終不更現在前，不生法故。以果所攝道決定及決定究竟故，以果道蘇息處故，彼人得蘇息。又果處善自護故，以果處具三因緣及五因緣故，前已說。彼三果退非須陀洹果，見道斷煩惱非對治事故，見道斷煩惱依我處轉而無有我。修道斷煩惱是對事，修道斷煩惱淨處轉，彼有淨想不淨想。彼思惟諸行不淨，得離欲淨思惟，於見不淨退。無有法我我所思惟，於非我見退。復次須陀洹果方便廣前施戒修等向解脫，如是比。又須陀洹果見道得故無有見道退，速道故、利故、非想非非想處對治故。若阿羅漢果退至須陀洹果，當知退三果，彼對治煩惱得成就故，亦不造諸業如彼住於果者。若得果人所不為，彼退果人亦不作。何以故？得不作律儀故、聖道已滅惡行故，如曾服藥。復次希望具足故，彼人希望滅果，對治惡行故。問：齊何當言菩薩？答：

若有眾生，以一食施，起決定心，發無畏言：我當作佛。能起相報增長彼業，齊是名菩薩，以能從此作相似相續業故。若不如是，但有空名。菩薩雖有初起不退心，是則菩提決定非趣決定。謂造相報業已，是則俱決定。是故齊相報業為名。以彼離四因緣故，謂離惡趣、離非男、離卑姓、離不具根。得一因緣，謂生性識宿命。以生識宿命故，聞即受持。眷屬信受，離眾生過，度三阿僧祇劫，於百劫中種相報業，除釋迦牟尼。釋迦牟尼菩薩精進故，除九劫，餘九十一劫。有說二三阿僧祇非劫阿僧祇，謂劫阿僧祇、生阿僧祇、善行阿僧祇。問：相報業為何等性？答：身業口業增上意業。又是思慧，性非聞慧。以劣故，非修慧。欲界不定故，閻浮提種非餘方。男子非女人，佛出世非不出世，見佛非不見佛，緣造業非緣餘。有說一思願種三十二相業，後種種業滿。又復說一定心一行一緣，眾多思願現在前，有願足下安平住果，有願乃至肉髻，彼一一相百福眷屬。福量者，有說一轉輪聖王福，是名一福量。又復說一帝釋福。有說劫成時一切眾生業增上器世界生，是名福量。有說除近佛地菩薩，諸餘眾生福樂自在業，是名一福量。佛無學法是菩提，謂盡智、無生智，薩埵求此智故名菩提。薩埵得此菩提，覺一切法，故名為佛。雖相報業後得轉輪聖王，而聖王相者當知是餘業報。問：幾種薩婆多？答：趣應言到，與趣同名

此四種薩婆多，一種異分別者，彼說諸法隨世轉時，分異非事異。如乳變為酪捨味力饒益不捨色，如金銀器破已更作餘器，捨形不捨色。法從未來至現在亦如是。當知此是轉變薩婆多。相異者，過去法與過去相合，不離未來現在相。如人著一色非不著餘，彼亦如是。此說有過，若過去諸法不離未來現在相者，竟何所成亦成合義？若爾者，則世亂。如人著一色，於一色愛著，亦行亦成就，於餘成就而不行，是故彼說世亂。譬亦相違。分分異者，說諸法隨世轉時，分分異非事異。此則不亂建立世。何以故？業別故。謂法未作業說未來，作業說現在，作業已說過去。彼異者，彼說諸法隨世轉時，前後相待，非事異亦非分異。如一女人亦名女亦名母，前後相待故。謂觀女則知母、觀母則知女，此最亂建立世。彼說過去世一剎那有三世，說言觀前起相名未來，觀後起相名現在。問：諸師說諦無間等各各異。薩婆多及婆蹉部說次第諦無間等，曇無得等說一無間等。何者為實？答：今當以五支如實說。五支者，一曰宗、二曰因、三曰譬、四曰合、五曰結，六曰義如下偈說

修行者先苦無間等，後乃至道。問：何故？答：智諦異相故。苦集滅道智各異相，行別故。若行是苦智，此行非餘智。若不爾者，無四智建立。諦亦異相，彼逼迫是苦相、生起是集相、寂滅是滅相、出離是道相。非不異智異相諦一無間等。譬如見瓶時不見衣，以瓶衣異相故。以異相故，見瓶不見衣、見衣不見瓶。彼亦如是，於異相諦見苦時不見餘，如是一切。是故次第無間等。說一無間等者，彼說於諦一無間等。何以故？信聖賢故。如世尊說：比丘於苦無疑、集亦無疑、滅道亦如是。如燈俱作四事、熱器、燒炷、油盡、破闇。如是一智知苦乃至修道，是故一無間等。彼說智諦異相者，不然，一相故。一切慧一智相，於一切法境界作無我行。如世尊說：一切法無我，智慧者能見。彼厭於苦時，是即道清淨。諦相亦如是說。瓶衣異相者，此亦不然。何以故？自相無間等，非分故。共相境界無間等，非自相，謂色等五陰壞相。共境界智一無間等，若異者則自生過。次第無間者言：汝言賢聖說者，此則密語，此說有餘義。如世尊說：若苦無疑，於一切無疑。為彼疑行故說。若彼苦無間等生，彼疑至竟不行，非數滅故。為除有餘說，故世尊說。給孤獨修多羅如是說言：長者！於四聖諦次第無間等。如是廣說。所說如燈者，燈有多性多業過，我不取燈事。若分別時燈捨自名，前已說。彼明色入攝，力能破闇，彼熱觸入攝，能作餘事。若不爾者，壞決定義。慧不如是，若言同者則有過，若言一相者此亦不然，行別故。無常行智異，苦空無我等行智亦各異，如是比。若不爾者，無解脫門。不壞行是解脫門。如汝說緣一切法作無我行，以頓觀一切法故。此則不定思惟分。定思惟行各別諦緣，是故不應說彼厭於苦時是即道清淨，不可以厭行緣於滅道，滅道是可樂事故。一切緣者不通一切，相違故。以無我行不即行，此無我行故、自性不自觀故。亦無二決定性，亦不觀相應共一行一緣故，亦不觀共有共，一果一決定故。又說一切行無常者亦非無常行，作滅無間等，滅者常故。當知彼行遠，以向真諦故說。如所說觀此眾生長夜成就身口意惡行。言此眾生即是地獄及餘惡趣，實非此人即是地獄，以向地獄故說。彼亦如是。又復是空無間等者，則非無願無相，彼一切法境界非分故。莫言有過，是故一切法無我行是不定思惟。定思惟者有漏緣，若不爾者解脫門減。若言自相無間等非分者，不然。何以故？以觀故。是自相共相，謂逼迫相是苦相，觀三諦故是自相，觀陰故是共相。如是一切，當知皆以觀故說自相共相。言不爾者，不然。何以故？以不壞觀故，前已說。前說中陰後當說，今當說。問：為有中陰、為無？答：壞相即無常相雜觀名為壞三脫，異觀故不壞

此說有中陰。何以故？世尊所說故。如世尊說：七士夫趣有中般涅槃。若無中陰者，則無中般涅槃。若言有中夭從彼般涅槃者，不然，天趣中不說故。世尊修多羅說：四天王天乃至非想非非想處，不說有中夭。餘亦有過。若說生般涅槃，復有名生天耶？如是一切。阿那含亦應如是說過。是故彼是妄想說。若言壽命中間般涅槃者，不然，除欝單曰及後邊菩薩，多有眾生不盡壽而死，此皆是中般涅槃耶？是故此皆有過。問：此云何？答：譬如村間道。如從一村至一村，如是死陰生陰，從死陰趣生陰亦如是。如《阿濕波羅延經》說：若彼處來，如是廣說。若無中陰者則無去來，是故應有中陰。若言為除有餘說修多羅，故世尊說修多羅及偈言。五無間罪作已，次第生無間地獄中。又復為梵志說偈言：少為老病漂，到於閻王所，梵志無住處，亦無有資糧。是故無中陰者此不然。何以故？業趣無間，故說修多羅及偈，謂作無間業已必先受無間報，然後受餘業報，亦必生地獄趣中非餘趣。如汝所解，世尊說修多羅，五無間業作已，次第生地獄中。為要五無間生地獄中？為二三四耶？為更餘罪生地獄中耶？當知此經及偈意。

若言如影者，如月極遠，影現水中，非彼月來至水中。如是死陰生陰如影，眾生生，何用中陰為者，此亦不然。何以故？彼則有俱過。月及水俱，死陰生陰不俱，是故有過。眼識足下身，識譬亦如是。若先取生陰而捨死陰，如折樓虫者，不然。何以故？趣不別及二識合過故。是故說有中陰，如所說四種薩婆多。問：為有一切有、為無？答：

此有是薩婆多所立。一切者，謂十二入。彼諸入有自相非餘，一切相所作別故。作業別，前已說。一切無一切者，謂學法中有學法無無學法，無學法中有無學法亦無學法。如空中亦無有跡，如是比。問：此說有，云何無有？答：無有他相法。如眼相是眼入，無餘入相，相別故。以是故說一切法不雜。

有三世薩婆多，此薩婆多所立。問：何故？答：現在世者，觀過去未來故施設，若無過去未來者，則無現在世。現在世無者，亦無有為法，是故有三世。莫言有咎。若言久遠是過去、當有是未來，非是有，唯有現在者，此不然。何以故？有業報故。世尊說：有業有報。非是業、報俱現在。若業現在，當知報在未來。若報現在，當知業已過去。若言俗數說者，亦說作者不可得。若言俗數說有業有報者，此亦不然。世尊亦說作者不可得。此亦俗數說耶？神口所說第一義空修多羅，而汝妄想說此有故彼有，如是比。當知如汝說，久遠是過去、當有是未來，非是有，唯現在是有者，莫作是說。我亦能說現在者於既往是未來，於當有是過去。此非智者說。如所說若無信等五根，我說是凡夫輩。若學人纏所纏，信等五根不現在前，道與煩惱不俱故。是故應知有過去未來。若異者，聖人應是凡夫。若言得隨生，此亦不然。無法得非分故。依處非分故。聲聞僧無佛者。聲聞僧不攝佛。何以故？三寶不減故。若世尊聲聞所攝，應有三寶非三佛，無別體故。歸依及不壞淨念等亦如是。莫言有過，是故聲聞僧不攝佛。如世尊修多羅說：憍曇彌！施僧亦是供養我。當知是說比丘僧、聖僧、福田僧，世尊者彼三僧所攝，破煩惱故、聖故、第一義福田故，非聲聞僧自覺故。

若廣說者眾生怖畏，是故我今不廣說。章句深達，阿毘曇明淨智慧所解，諸論音聲妙義於此略說。

我今於尊者法勝所說中，以少智慧思量撰集造立章句，將以申述助宣遺法，非欲憍慢求名稱故。如彼所說，若生諸煩惱是聖說。有漏滅道亦生煩惱，而非有漏增，煩惱非分故。無漏緣煩惱滅而不增，前已說。是故我說增也。無漏緣軟中上不增者，不然，依增故。

於此論章句義味，能決定知、善分別說者，於諸智慧眾中心無怯畏，善解法相故。

經本至略，義說深廣，難可受持。如虛空論，難可了知，前已說。是故增益論本，隨順修多羅義，令易了知。以知義故，煩惱則斷。

頗住無礙道，而得於諸滅， /
此相違煩惱，非彼無漏見？ /

頗諸煩惱滅，離欲者獲得， /
不斷於煩惱，而得無垢盡？ /

頗無垢淨地，未曾得而得， /
非離欲非退，不依於見道？ /

頗獲未曾得，而得於寂滅， /
不捨彼不得？若能知者說。 /

若成就八忍，亦成就七智， /
此諸無漏見，不見何無漏？ /

頗法未曾得，有漏邊境界， /
唯有不動者，彼能擊善法？ /

已起無漏慧，於彼未起者， /
前生非後因？若能知者說。 /

頗離六地欲，聖亦成彼果， /
不成無漏禪？若能知者說。 /

頗諸無漏法，而為界所攝， /
能生彼法者，不入彼界中？ /

頗一大種滅，於禪地不起， /
二大種在前？若能知者說。 /

頗法因三道，是三種自性， /
謂三種一地，亦復在三地？ /

頗有有漏受，二成一不成， /
二根二種成，是說為身證？ /

九地煩惱滅，而得於諸禪， /
不得無色定，或復得當說？ /

一法眾多性，或一三有無， /
彼是無學法，因力所長養？ /

頗法是有分，與彼餘有分， /
相似生住壞？若能知者說。 /

頗諸相應法，或說餘有分， /
或復說有分？若能知者說。 /

頗二阿那含，共生於一地， /
第一法或成，俱得一地果？ /

頗有不動法，俱受於一有， /
一成就九地，善有漏一無？ /

頗住一剎那，得捨三脫門， /
或復捨於二，一捨還復得？ /

頗成沙門果，成就聖非聖， /
而不得斷知？若能知者說。 /

度彼無勝海，少力所不任， /
今我隨所能，宣說甚深義。 /
世間貧窮人，彼可卒令富， /
無智則不然，要須大方便。 /
世間寶易得，慧寶甚難獲， /
是故應勤學，漸入甚深智。 /
正解涅槃路，邪惑生死徑， /
慧能滅癡闇，如日除幽冥， /
為求解脫故，當勤修智慧。 /
