# 菩薩名經 · 第十卷

> 宋 羅濬集

---

我聞如來聲世間頗難遇 /
斯言若真實當賜汝衣服 /
若彼佛世尊為利世間現 /
必應見哀愍令我覩真相 /
言念湏頃佛放虛空中󱅨 /
現不思議身普放大光明 /
勝鬘及眷属皆悉來集會 /
合掌瞻仰禮稱嘆大導師 /
如來妙色身世間無與等 /
無比不思議是故今敬禮 /
如來色無盡智慧亦復然 /
一切法常住是故我皈依 /
善調心過及與身四種𢙣 /
到不思議地是故今謹禮 /
知諸法炎智身無礙𠇍𦊱 /
於法無忘失故我今謹禮 /
稽首過稱量稽首無等倫 /
稽首法自在稽首超思惟 /
哀愍覆護我及法種增長 /
逮及最後身當在如來前 /
我所有福業今世及餘生 /
由斯善根力佛當攝受 / 󷃷

## 謹按金剛頂瑜伽尊禮懺悔文

普為梵釋四王天龍八部帝王人王師僧父母及善知識道場眾等法界有情並断除諸障皈命懺悔至心懺悔弟子眾等自從無始曠大刼來至于今日迷無我斍計有我人我計既興常緣我所根塵浩渺識蔭奔波擊動身心猶如電轉清淨眼耳鼻舌身意一念不覺飜作六師偷法王財供邊見賊賊既熾盛破涅槃城殘法身樊燒慧命如此等罪越塵沙由迷至迷莫測終始今始覺悟深悔自慚曉夜驚惶身心戰慄永断迷覺貪愛我人投涅槃城歸安樂國以無我覺降伏六師収法王財納三堅藏資給慧命增益法身燃法性燈常炤無盡行理事塵界不迷三寶三乘誓當弘護迷覺之罪隨懺消滅懺悔迴向已至心皈命禮三寶至心發弟子眾等及法界有情始從今日乃至無上菩提念念堅固念念勝進身心自得辨說無礙於一念中具足一切種智湏知諸法畢竟空寂而常度脫一切眾生同證涅槃不以涅槃為證發已至心皈命禮三寶。𭛔𡧱𢿘󷃷󷃷󷃷

## 菩󴅽名經序後

古之學道無自虛空入者道不可以虛空入則佛書之傳寫可已耶此大藏之積所以警悟後來而世人能於經中求入古佛至處譬如乘舡入海扶杖登途豈有不遂其所徃哉不輕居士愍其卷柣繁委牽塵涉世之人不能盡覽於是編集諸聖名號毗盧人天森羅眼界覩其文者能生十地之心回是想者克證應真之果辟支利智亦莫不然率天下之人懽喜踊躍共作龍華上客其利豈不哉輙書一二以附其後。󳑧
