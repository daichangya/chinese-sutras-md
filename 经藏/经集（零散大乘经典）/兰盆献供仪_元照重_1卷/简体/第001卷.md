# 兰盆献供仪 · 第一卷

> 宋 元照重集

---

## 1

昔孤山法师甞作兰盆礼赞文，三宝目连共为六位，启白忏悔各四句而已，仍用常途罗汉礼请之声。后真悟律师更为天竺祖礼唱之，遂加启请冠于赞首，移孤山四句以为叹佛。予谓释子奉行兰盆，固当代为存亡露过陈悔，又依经设供必先呪愿，此二乃法会之至要，而昔皆遗之。故今于叹佛后依经出呪愿法，又礼赞后别出悔文，余竝仍旧贯，无别改作。有加圭峰一赞及劝请等偈，今例不存，各其志尔。

余杭沙门释元照重集。

初入道场，三礼已，互跪烧香。散华首者唱云：

恭以牟尼化主，大孝慈尊，三祗功行告圆，万德庄严克备。在因在果，咸推孝顺为宗；居圣居凡，皆以报恩为本。寻以王宫诞瑞，弃金轮而出家；道树证真，伏天魔而成圣。指三千为化境，演八万为法门。亲升忉利天中，为摩耶而说法；躬向迦维国内，酬净饭以担棺。覩目连救母无方，示自恣盂兰玅供。使盆罗百味，式贡三尊，仰贤圣之威光，济自他之存没。今则爰当休夏，聊展微肴，普伸供献之仪，用答劬劳之德。惟冀十方圣众，俱降道场，同享克诚，俯回昭鉴。

唱已，一礼复跪，执炉冥想。众圣请云：

唯愿降临道场，受我供养。三请，一礼，下同。

。请已起立，称叹三宝，同声呪愿

我等各为报答所生父母罔极深恩，具饭百味、五果、香油、挺烛，供养三宝．十方自恣大德众僧。愿使现在父母寿命百年，无一切苦恼之患，乃至七世父母离饿鬼苦，生人、天中，福乐无极，徧周法界。无量众生承此熏修，俱沾利乐。三徧，或更陈叙宣疏，或念佛等，临时自裁，然后礼赞。唱云：

故我一心归命顶礼。此同声和已三礼，下竝同

。赞已，互跪追想存亡父母，恳切至诚忏悔

至心忏悔。我等所生父母，多世亲缘。自背真常，长流生死。顺无明之倒想，随欲境以攀缘。恣放六情，故为十恶。贪嗔边见，杀盗邪婬。两舌恶口以欺诬，绮语妄言而诳惑。加以恡财荒色，酣酒嗜音。慢辱僧尼，轻陵佛法。飡噉众生血肉，伤残无量合灵。不思万劫之殃，但顾一时之美。或现遭厄难，或后受沉沦。忝当割爱出家，理合修身报德。幸值佛欢喜日，僧自恣时。仰遵调御法门，式奉盂兰盆供。但以生缘义重，哀慕情深。由是輙叙瑕疵，代申忏悔。仗三宝威神加被，众僧功行冥熏。令彼罪根，俱时除灭。亡没迁神于天上，永脱冥途。生存保寿于人间，常无病恼。善根弥固，正信增深。俱出轮回，尽生安养。无缘普覆，有感遂通。愿赐哀怜，俯垂护念。三徧

忏悔已，至心归命顶礼。此一人唱已，一礼起，绕旋唱云：

旋绕三称已，讽盂兰盆经，或余经等，尽诚便散。

稽首释迦真教法，三乘贤圣目连尊。 /
我今禀教报亲恩，愿轸慈悲听赞叹。 /

历劫修行成圣道，目连哀请演真乘。 /
父王反拜踊虚空，田主闻言解罗网。 /
修因证果同归孝，化他自行尽酬恩。 /
愿回慈眼视众生，令彼存亡皆受赐。 /

金口广谈无量教，报亲唯此应机缘。 /
拔苦偏称自恣僧，垂慈更示兰盆法。 /
庆喜宣传言已备，昙摩翻译道弥光。 /
王臣贵贱悉遵行，玅训明明逾日月。 /

悲智俱修称大士，上求下化历僧祇。 /
济物长乘六度舟，利他悉到三空岸。 /
内证将臻诸佛境，随缘或现比丘形。 /
而今既降道场来，愿使存亡皆离苦。 /

利智不因师匠授，谛观缘起悟无生。 /
说法传灯号部行，修心无侣称麟喻。 /
真空顿了看华谢，烦恼全除听钏声。 /
而今既降道场来，愿使存亡皆离苦。 /

山间树下安居胜，四谛深观得有余。 /
暄喧生死果全倾，寂寂涅槃心已证。 /
六通自在超魔境，八解逍遥号福田。 /
而今既降道场来，愿使存亡皆离苦。 /

神通第一居无学，为报亲恩乃出家。 /
自力难除慈母殃，哀号遂奉如来教。 /
发起微言资后世，揄扬孝道利群生。 /
而今既降道场来，愿使存亡皆离苦。 /

绍兴甲子季夏，比丘宗炬，重写募缘，刊板流通。各为生身父母，历劫亲缘，忏涤罪根，庄严净土。
