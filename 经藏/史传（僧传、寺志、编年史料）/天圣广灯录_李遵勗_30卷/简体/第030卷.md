# 天圣广灯录 · 第三十卷

> 宋 李遵勗编

---

世间事无常，犹如云出电，尊者今时至。 /
应舍家出家。

一切法胜唯有行，清净寂定不过心， /
染着恩爱最冤家，诸有恐怖是老死。 /

山羊被杀因作声，飞蛾投灯由火色。 /
水鱼悬钩为吞饵，世人趣死以境牵。 /

本无生老病死过，并及地火水风空， /
湛然三世无师教，常净自然证解脱。 /

法本法无法，无法法亦法，今付无法时。 /
法法何曾法。

如来弟子，且莫涅槃，得神通者，当赴结集。 /

法法本来法，无法无非法，何于一法中， /
有法有不法。

本来付有法，付了言无法，各各须自悟。 /
悟了无无法。

非法亦非心，无心亦无法，说是心法时， /
是法非心法。

通达非彼此，至圣无长短。汝除轻慢意， /
疾得阿罗汉。

若因地倒，还因地起，离地求起，终无其理。 /

稽首三昧尊，十力圣弟子，我今愿回向。 /
勿令有劣弱。

心自本来心。本心非有法，有法有本心。 /
非心非本法。

巍巍七宝山，常出智慧泉，回为真法味。 /
能度诸有缘。

我法传于汝，当现大智慧。金日从屋出， /
照曜于天地。

通达本法心，无法无非法，悟了同未悟。 /
无心亦无法。

我从无量劫，至于生此国，本姓颇罗堕， /
名字婆须密。

无心无可得，说得不名法。若了心非心， /
始解心心法。

心同虚空界，示等虚空法，证得虚空时， /
无是无非法。

贤劫众圣祖，而当第七位，尊者哀念我。 /
请为宣佛地。

我所得法，而非有故，若识佛地，离有无故。 /

父母非我亲，谁是最亲者？诸佛非我道。 /
谁是最道者？

汝言与心亲，父母非可比，汝行与道合， /
诸佛心即是，外求有相佛，与汝不相似。 /
欲识汝本心，非合亦非离。 /

虚空无内外，心法亦如是。若了虚空界， /
是达真如理。

我师诸祖中，当继第八位，法化众无量。 /
悉获阿罗汉。

真理本无名，图名显真理，受得真实法。 /
非真亦非伪。

此地变金色，预知于圣至，当座菩提树， /
觉华而成已。

师座金色地，常说真实义，回光而照我。 /
令入三摩谛。

真体自然真，因真说有理，领得真真法。 /
无行亦无止。

我昔生梵天，梵天寿命尽，下生毗离国。 /
与汝同忧苦。我见汝无衣，心生怜愍故， /
分身为窠围，令汝无忧苦。 /

迷悟如隐显，明暗不相离。令付隐显法。 /
非一亦非二。

稽首长老尊，当受如来记。今于此地上， /
宣通第一义。

隐显即本法，明暗元不二。今付悟了法。 /
非取亦非离。

非隐非显法，说是真实际。悟此隐显法， /
非愚亦非智。

身现圆月相，以表诸佛体。说法无其戒， /
用辨非色声。

为明隐显法，方说解脱理。于法心不证， /
无瞋亦无喜。

此树生奇耳，食以不枯槁，智者解此因。 /
当师其至道。

入道不通理，覆身还信施。汝年八十一。 /
此树不生耳。

本对传法人，为说解脱理，于法实无证。 /
无终亦无始。

稽首提婆尊，而出于仁者，仁者无我故。 /
我欲师仁者。

我已无我故，汝须见我我。汝若师我故， /
知我非我我。

三界一明灯，回光而照我，十方悉开朗。 /
如日虚空住。我得遇大圣，愿依师解脱。 /
志诚头面礼，唯垂赐纳受。 /

于法实无证，不取亦不离，法非有无相。 /
内外云何起？

善哉大圣者！心明如日月，一光照世界， /
暗魔无不灭。

稽首大慈父，和南骨血母。我今欲出家。 /
幸愿哀愍故。

若人生百岁，不解诸佛机，未若生一日， /
而得决了之。

诸佛大圆镜，内外无瑕翳，两人同得见。 /
心眼皆相似。

心地本无生，因地从缘起，缘种不相妨。 /
花果亦复尔。

有种有心地，因缘能发萌，于缘不相碍。 /
当生生不生。

性上本无生，为对求人说。于法既无得， /
何怀决不决？

稽首三昧尊，不求于佛道，不礼亦不慢， /
心不生颠倒，不坐不懈怠，但食无所好， /
虽慢而不迟，虽急而不躁，今我遇尊者， /
和南依师教。

言下合无生，同于法界性。若能如是解， /
通达事理竟。

我行四国土，寻光到于此，汝是谁居舍？ /
而感生圣子。

泡幻同无碍，如何不了悟？达法在其中。 /
非今亦非古。

心随万境转。转处实能幽。随流认得性。 /
无喜复无忧。

我今无太子，欲收于汝故。汝现神通者， /
令我心不定。汝有神通者，当现本来身， /
汝无神通者，常作宫千子。 /

认得心性时，可说不思议，了了无可得。 /
得时不说知。

一法一切法，一切一法摄，吾身非有无。 /
何分一切塔？

正说知见时，知见俱定心，当心即知见。 /
知见即于今。

圣人说知见，当境无非是。我今悟真性。 /
无道亦无理。

真性心地藏，无头亦无尾，应缘而化物。 /
方便呼为智。

心地生诸种，因事复生理，果满菩提圆。 /
华开世界起。

路行跨水复逢羊，独自栖栖暗渡江。 /
日下可怜双象马，二株嫰桂久昌昌。 /

心中虽吉外头凶，川下僧房名不中。 /
为遇毒龙生武子，忽逢小鼠寂无穷。 /

路上忽逢深处水，等闲见虎又逢猪。 /
小小牛儿虽有角，清溪龙出总须输。 /

震旦虽阔无别路，要假姪孙脚上行。 /
金鸡解衔一颗米，供养十方罗汉僧。 /

八月商尊飞有声，巨福来祥鸟不惊。 /
怀抱一鸡重起会，手把龙蛇在两楹。 /
寄公席帽权时脱，蚊子之虫足去形。 /
东海象归披石胀，二处蒙恩总不轻。 /
日月并行若不动，即无冠子上山行。 /
更惠一峰添翠岫，玉教人识知始名。 /

高岭无人又脱衣，小蛇虽毒不能为。 /
可中井底着天近，小小沙弥善大机。 /

大浪虽高不足知，百年凡木长干枝。 /
一鸟南飞却归北，二人东往复还西。 /

可怜明月独当天，四个龙儿各自迁。 /
东西南北奔波去，日头平上照无边。 /

吾此记词，腰长脚短。合掌向天，回头失伴。 /
身着红衣，又如素绢，立在目前，还如不见。 /
好好思量，水清月现。 /

鸟来上高堂欲惊，白云入地色还青。 /
天上金龙日月明，东阳海水清不清。 /
手捧珠轮重复轻，虽无心眼转醒醒。 /
不具耳目善观听，身体元无空有形。 /
不说姓字但签名，意寻书卷错看经。 /
口说恩幸心无情，或去或来身不停。 /

尊胜今藏古。无肱又有肱。龙来方授宝。 /
奉物伏嫌名。

起自求不碍。师言我没绳，路上逢僧礼。 /
足下六枝分。

三四全无我。隔水受心灯。尊号过诸量。 /
从瞋不起增。

奉物可曾物。言勤又不勤。唯书四句偈。 /
为对瑞田人。

心里能藏事。说向汉江濵。湖波探水月。 /
将照二三人。

领得弥勒语，离乡日日敷。来梁移近路。 /
余筭脚天途。

艮地生玄旨，通尊媚亦尊。比肩三吼族。 /
足下一毛生。

灵集媿天恩。生芽二六人。法中无气味。 /
石上有功勋。

本是大虫男。翻成师子谈。官家封马岭。 /
同相三十三。

九女出人伦。八个绝婚姻。朽床添六足。 /
心祖众中尊。

走戊与潮隣，鹅乌子出身，二天虽有感， /
三化寂无尘。

说少何曾少。言流又不流。草若除其首。 /
三四继门修。

在胎为身，处世名人。在眼曰见，有耳曰闻。 /
在鼻辨香，在口谈论，在手执捉，在足运奔。 /
徧现俱该沙界，收接在一微尘。 /
识者知是佛性，不识唤作精魂。 /

师寿于百岁，八十而造次，为近至尊故。 /
熏修而入道。虽具少智慧，而多有彼我， /
所见诸贤等，未甞生珍敬。四五修功德。 /
其心未恬静，聪明轻慢，故而获致于此。 /
得王不敬者，当感果知是，自今不踈怠。 /
不久成其智，诸圣悉在心，如来亦复尔。 /

仰覩两扇，低腰捻钩。九鸟射尽，唯有一头。 /
至即不至，要假须刀。逢龙不住，遇水即逃。 /

吾本来兹土。传法救迷情。一华开五叶。 /
结果自然成。

亦不覩恶而生嫌，亦不观善而勤措， /
亦不舍智而近愚，亦不抛迷而就悟。 /
达大道兮过量，通佛心兮出度。 /
不与凡圣同躔，超然名之曰祖。 /

江槎分玉浪。管炬开金锁。二三相共行。 /
九十无彼我。

本来缘有地，因地种华生，本来无有种， /
华亦不能生。

华种虽因地，从地种华生，若无人下种， /
华地尽无生。

华种有生性，因地华生生，大缘与性合。 /
当生生不生。

身是菩提树，心如明镜台，时时勤拂拭。 /
莫遣惹尘埃。

菩提本无树。明镜亦非台。本来无一物。 /
何处有尘埃。

有情来下种，因地果还生。无情既无种， /
无性亦无生。

心地含诸种，普雨悉皆生。顿悟华情已， /
菩提果自成。

头上养亲，口里须餐。遇满之难，杨柳为官。 /

震旦虽阔无别路，要假儿孙脚上行。 /
金鸡解一粒米，供养什邡罗汉僧。㘅 /

心里能藏事。说向汉江濵。湖波探水月。 /
将照二三人。

心地含诸种，普雨悉皆萠。顿悟花情已， /
菩提果自成。

心地含诸种，遇泽悉皆萠。三昧花无相， /
何坏复何成？

领得弥勒语，离乡日日敷。东梁移近路。 /
余气脚天徒。

心地随时说，菩提亦秖宁，事理俱无碍。 /
当生即不生。

自从大士传心印，额有圆珠七尺身。 /
挂锡十年栖蜀水，浮杯今日渡漳濵。 /
一千龙象随高步，万里香华结胜因。 /
愿欲事师为弟子，不知将法付何人。 /

心如大海无边际，口吐红莲养病身。 /
虽有一双无事手，不曾祗接等闲人。 /

流不止问如何，真照无偏说自他。㳂 /
离相离名人不禀，吹毛用了急还磨。 /

大道绝同，任向西东。石火莫及，电光枉通。 /

何代隐荒丘。茆堂独幽。随缘三事衲。 / 𥨊
顿觉万缘休。貌古因持戒，身贫为少求。 /
吾师登鸟量，物外绝追游。 /

诗咏人问事。空门何不删。探珠宜静浪。 /
动水取应难。名利心须剪，非朋不用攀。 /
舍邪归正道，何虑不闲闲。 /

夺人不夺境。缘自带𫍢讹。拟欲求玄旨。 /
思量返责么。骊珠光璨烂，蟾桂叶婆婆。 /
觌体无差互，还应滞网罗。 /
夺境不夺人。寻言何处真。问禅禅是妄。 /
究理理非亲。日照寒光澹，山摇翠色新。 /
直饶玄会得，恬似眼中尘。 /
人境两俱夺。从来正令行，不论佛与祖。 /
那说圣凡情。拟犯吹毛劒，退伤值木盲。 /
进前求妙会，特地打精灵。 /
人境俱不夺。思量意不偏。主宾言不异。 /
问答理俱全。踏破澄潭月，穿开碧落天。 /
不能明妙用，沦溺在无缘。 /

闲佩毗卢印。人天末位尊。宝航横凤浦。 /
金锡挂龙门。去后梁王感，来光魏主恩。 /
葱山擕只履，半偈动乾坤。 /

别嗣神州祖。联灯又一回。密传三祖印。 /
还梦五侯街。玄字乾坤太，慈天日月开。 /
逆流漳浦上，天感泣云雷。 /

北齐传得印。独步出人间。祖地江河阔。 /
随天日月闲。妙音流四海，瑞气溢三山。 /
一句南来信，清风撼雪关。 /

翠合鸡山树。峩峩祖岫松。凝霜分五叶。 /
含雪振双峰。月逈金河内，珠添玉镜中。 /
飕飅传细离，天下播真宗。 /

东山分祖印。空际月成轮。碧眼风光翠。 /
黄梅树色春。九枝添瑞鶴，一叶拂祥麟。 /
别得金僊记，曹谿第五人。 /

南得黄梅意。曹谿记法泉。三衣兼祖印。 /
一钵尽师传。慈月光千海，玄河注百川。 /
神洲十二代，法眼继相传。 /

天中慈月三峰逈，指外悬河万派深。 /
仙舸独游华藏海，无边川泽喜归心。 /

熊耳宗师葬洛阳，龙城天子位千行。 /
回担只履葱山上，惊杀梁王与魏王。 /

麟眠法苑分千叶，马踏曹谿迸万泉。 /
古佛传中亲授记，月转碾破海中天。 /

百丈和霜岭上松，蛇盘鶴性瘦如龙。 /
下堂索著称名字，不会师心一万重。 /

龙控悬河海月秋，烟霞风雨一时収。 /
波涛急急人难会，截断千江水不流。 /

祖派波澜半偈玄，曹谿舟棹接风烟。 /
一转海底龙潭月，碾破鸡山雪岭前。 /

身受龙华三会主，搥开凤阁九重城。 /
梁王筑倒金刚佛，更门如何不讲经。 /

药岫龙泉照瞻清，乾坤宗匠尽流行。 /
格高一句难分出，蓦就云岩谷口明。 /

一片丹霞见石头，麒麟双凤况难传。 /
锋欲说宗门印，哽得师心掩耳休。𨦵 /

白凤烟霞控鸟窠，骊龙珠耀祖山河。 /
当初捻起布毛意，体用毗卢些子多。 /

龙劒雕弓祖佛威，霜锋雷电急难追。 /
当初金镞胷前过，由未重玄多许为。 /

雪彩霜威马祖风，虎降高格气如龙。 /
谁人会得归宗路，一镞三关海内通。 /

虎见烟萝透洞门，心中古佛震乾坤。 /
龙泉截断麒麟角，撼得毗卢海月昏。 /

一派曹源与灌谿，龙行风雨动云霓。 /
后机箭筈波澜急，撼得毗卢海岳低。 /

龙吟凤彩震乾坤，熊耳鸡山海内闻。 /
一片雪霜三岛外，虎心半偈洒风云。 /

六叶牛头枡别栽，五天熊耳纵云雷。 /
须知四祖垂机接，百鸟衔华更不来。 /

发意当初问石头，江河心𣸣渺分流。 /
唤回指出毗卢印，便得如山万事休。 /

虎径龙泉遶行岩，凤栖霜倚鶴和杉。 /
谁人会得宗师意，纽转乾坤好不参。 /

龙宫鹿苑百川通，八藏三乘在掌中。 /
却是江西逢马祖，回头踏转大虚空。 /

踈岭松萝五叶云，毗卢天外别为秦。 /
骊龙踏落虚空月，木马重嘶雨露新。 /

锡撼风霜虎豹愁，楚王城里倒骑牛。 /
腾腾尽喝关南皷，声压云雷动九畴。 /

熊耳鸡山五印玄，蛇盘凤口九瓟泉。 /
紫霄峰上一轮月，照破曹谿半夜圆。 /

别沐曹谿水，栖衡岳万重，有心传五叶， /
无意据千峰。洞鶴争藏翼，岩鸡息瘦容。 /
一声乾象外，海内继真风。 /

五天慈雨细。师得润禅林，碧眼千灯印。 /
清源一派心。有涯来敻远，无底更深沉。 /
别嗣曹谿后，众人仰德音。 /

根蔕欲何寻。孤奇逈众林。凤来敲节目。 /
龙去晓知音。撼雪精神别，吟风体物深。 /
平常烟霭里，动转振虚心。 /

出石雄委逈，樛林况莫同。翠含烟霭外， /
闰布雪霜中。影撼千谿月，声联五叶风。 /
妙音传药峤，天下定真宗。 /

澧水风涛急。参差海岳摧。浪中澄得月。 /
天外振惊雷。龙领珠难取，谿岩宝易栽。 /
接人机路险，寰海更谁偕。 /

深沉分派异。方外一轮孤。海底清天镜。 /
潭中碧眼珠。千重排雪岸，半偈彻氷壶。 /

## 杭州南山兴教寺惟一禅师

初开堂升座，维那白槌云：法筵龙象众，当观第一义。师云：重言不当，大众还委么？且作么生是第一义？若自观者，名为正观；若佗观者，名为邪观。或有问话，请埀见示。

时有僧问：觉华开处，徧满娑婆，祖意西来，合谈何事？师云：孤猨呌落中岩月，野客吟残半夜灯。进云：恁么则昔日灵山，今朝兴教。

师云：相识满天下，知心有几人？学人伫思，师云：速还三拜。

问：师唱谁家曲？宗风嗣阿谁？师云：不避来机，速当一问。进云：恁么则五老峰前亲得旨，今朝兴教度群迷。师云：不是智音者，那能辨浊清？

问：承古有言：如来有正法眼藏，付嘱摩诃迦叶。和尚今朝当付何人？师云：者里有多少人？进云：未晓者如何领会？师云：还我话来。

上堂，僧问：不落见闻，请师答话。师云：三十年后。

问：众手淘金，谁是得者？师云：是儞眼皮重。进云：恁么则骏马不移蹄。师云：金在什么处？

问：狂风忽起，扫荡烟云，学人到此为什么不会？师云：真个不会。进云：不探龙领，争获骊珠？师云：珠在什么处？

问：达磨未来时如何？

师云：索桥路险人难度。进云：来后如何？师云：少林闲坐九年余。

问：牛头未见四祖时如何？师云：南来冬熟笋。进云：见后如何？师云：北去夏宜桃。

问：佛末出世时如何？师云：白云数重。进云：出世后如何？师云：青山一带。

问：如何是道？师云：刺头入荒草。进云：如何是道中人？师云：干屎橛。

问：曹谿一曲师亲唱，未审如何和得齐？师云：儞试道看。进云：恁么则谢师举唱。师云：秖为宫商调不同。

问：大耳三藏第三度为什么不见国师？师云：脚跟下看。进云：如何得见？师云：草鞋根断。

问：和尚未见栖贤时如何？师云：春来好寒。进云：见后如何？师云：秋去盛热。

## 真州定山惟素山主

有僧问：古人拈槌竖拂不当宗乘，未审山主如何为人？师云：旦莫强惺惺。进云：恁么则却成起动也。师云：龙头虵尾汉。

问：如何是不迁？师云：暑往寒来。进云：恁么则迁去也。师云：啼得血流无用处。

问：达磨心印师已晓，试举家风对众看。师云：门前有个长松树，夜半子规来上啼。进云：恁么则白鼍一派，流注十方。师云：日月丽天，风云难蔽。

问：知师洞达诸方旨，临机不答旧时禅，如何是新奇？师云：若到诸方，不得错举。进云：学人慇懃于座右，莫不秖此是新奇？师云：折草量天。

问：如何是定山境？师云：清风满院。进云：忽遇客来，将何祇待？师云：莫嫌冷澹。

师云：若论家风与境，也不易酬对，多见指定处所，教他不得自在。曾有僧问大随：如何是和尚家风？答云：赤土上画簸箕。又云：肚皮上不贴牓。且问诸人作么生会？更有夹山、云门、临济、风穴皆有此话，播于诸方，各各施设不同，又作么生会？法无异辙，殊途同归。若要省力易会，但识取自家桑梓，便能绍得家业，随处解脱，应用现前，天地同根，万物一体，唤作衲僧眼睛，緜緜不漏丝发。苟或于此不明，徒自伶俜辛苦。

有僧问：众手淘金，谁是得者？师云：莫作贵。进云：不作贵又如何？师云：金在什么处？

问：如何是佛？师云：含齿戴发。进云：恁么则人人具足。师云：远之又远。

问：如何是不生不灭法？师云：春到百华开，秋来群木落。进云：恁么则一年一度春也。师云：欠子细在。

问：牛头未见四祖时如何？师云：成象立业。进云：见后如何？师云：立业成家。

问：如何是一味法界？师云：花红柳绿。进云：如何是定山路？师云：峭。进云：履践者如何？师云：崄。

问：万法归一，一归何所？师云：一叶落，天下秋。进云：如何领会？师云：三十年后。

问：承教有言：无上法王有大陀罗尼门，名为圆觉，流出一切清净真如、菩提涅槃。未审圆觉从什么处流出？师云：山僧顶戴有分。进云：恁么则信受奉行。师云：依稀似曲才堪听。

师又云：将知佛法，须是彻底悟得，方能始终一贯，作用施为，得其自在。若是学成者，终有剂限。子细穷究，便随末忘本，唤作流浪生死，无本可据。所以教中云：何况能以有思惟心，测度如来圆觉境界？如取萤火烧须弥山，终不能着。若论此事，无用心处，亦非懈怠而得。却请上座各自回光返照，与道稍有相应。其如不达宗旨，总成逐块。

僧问：十二时中如何得与道相应？师云：皇天无亲，唯德是辅。进云：恁么则不假修证也。师云：三生六十劫。

问：如何是深山岩崖逈绝无人处佛法？师云：月明千嶂里，风动万年枝。进云：恁么则处处菩提道，明明功德林。师云：薰天炙地。

问：如何是佛法大意？师云：山高海深。

问：不见一法即如来，方得名为观自在。如何是观自在？师云：好好礼三拜。进云：莫秖者便是？师云：十万八千。

## 苏州西山尧峰院颢暹禅师

初开堂，有僧问：法筵龙象众，当观第一义。如何是第一义？师云：儞去什么处来？

问：海门三级浪，专听一声雷时如何？师云：犹是未警发在。

问：如何是祖师西来意？师云：尽道九年曾面壁。

问：如来路上无私曲，便请玄音和一场。师云：莫并巴儿曲，须超白雪辞。

问：祖祖相传传祖印，师今得法嗣何人？师云：同道方知。

问：如何是和尚为人一句？师云：山僧自来不曾容易。

上堂云：止止不须说，言诠道复优。有疑如未决，对众莫淹留。

时有僧问：学人有疑，请师决。师云：者回更莫淹留。

问：未经炉冶时如何？师云：争得成器？

问：善财徧参，还具本分事也无？师云：善财徧参为什么事？

问：一念万年时如何？师云：还得尽善也未？

问：能所俱忘时如何？师云：那个是儞忘底能所？

问：如何是真规自宛然？师云：千圣不能宣。

问：如何是道？师云：尧舜其犹病诸。

问：如何是密作用？师云：秖恐大众未肯儞。

问：学人乍入丛林，乞师一接。师云：去。

问：承教有言：是法平等，无有高下。如何是平等底法？师云：尧峰高，宝华低。学云：恁么则却成高下去也。师云：情知儞恁么会。

问：承教有言：妙湛总持不动尊，首楞严王世希有。如何是不动尊？师云：世希有。学云：恁么则不动真际随处发挥去也。师云：却不令人赞叹。

师云：诸上座！秖如此僧问不动尊，山僧向他道：在希有。意旨又且如何？莫是三秖果满，万行功圆，是世之希有么？又莫是当人分上本自圆成，不劳修证么？若也恁么会，实谓妄认缘尘，分别影事。既不许上座恁么会，向者里作么生承当？若也承当得，便乃不从一地主一地，寂灭性中无有异。若向者里承当未得，不免须待龙华重授记在。各请歇去。珍重。

上堂，闻雷声，乃示众云：还闻雷声么？还知起处么？若知起处，便知身命落处；若也不知，所以古人道：不知天地者，刚道有乾坤。不如吃茶去。

上堂，僧问：如何是尧峰境？师云：多少人看望不足。

问：如何是道？师云：夕死可矣。问：如何是金刚力士？师云：者里用不着。

问：如何是孤峰节操松？师云：而今未堪看，更待雪霜中。

问：如何是佛？师云：休更历僧祇。

问：鱼龙得水时如何？师云：踊跃无尽。

问：片云出洞时如何？师云：何必龙吟。

问：亡僧迁化向什么处去也？师云：苍天！苍天！

师复云：大众！秖如未后一僧问：亡僧迁化向什么处去也？山僧向化道：苍天！苍天！且道意旨落在什么处？莫是悲伤迁逝，痛忆道人么？若乃恁么评论，实谓罔知去处。要知去处么？更不用久立歇去。

师春日上堂云：久去春来，楼阁门开，若也入得，不用俳徊。诸上座！还向者里入得也未？若也入得，所以古人道：是处是弥勒，无门无善才。若也入之未得，自是诸上座狂走，更不忉忉。久立，珍重！

## 苏州吴江圣寿院志升禅师

初开堂时，有僧问：知师久酝葡萄酒，今朝慈济为谁开？师云：想儞也未知滋味。进云：恁么则优昙华扸，法界馨香，佛日初开，昏衢永耀。师云：不劳如此。

问：宝座既登于此日，家风一句请师宣。师云：儞还证明得么？学云：恁么则人天有赖，四众咸忻。师云：闲言语。

问：师赴群心扬祖道，未知祖道嗣何方？师云：同道方知。学云：恁么则锦里昔年亲得旨，松江今日度群迷。师云：却不是我同道。

问：四众临筵当此日，玄机一决为谁宣？师云：儞不妨刢利。进云：恁么则非唯大众朝宰沾恩。师云：莫乱道。

上堂，僧问：如何是佛？师云：人天赞莫及。

师又云：若论佛法，更有什么事？所以道：古今山河、古今日月、古今人伦、古今城郭，唤作平等法门，绝前后际。诸人还信得及么？若信得及，依而行之。久立，珍重。

## 杭州临安县功臣山开化院守如禅师

初开堂日，有僧问：朝宰既伸于三请，师将何法报深恩？师云：何以儞特致？

问：如何是功臣为人一句？师云：自来不曾埋没人。

问：承教有言：清净本然。云何忽生山河大地？师云：且道是谁致得？进云：恁么则满眼青山无寸树，极目渌水绝波澜。师云：也是错会。

问：如何是功臣境？师云：上座合具行脚眼。进云：恁么则峨嵋？凝千寻雪，鼇背巍笼五色烟。师云：勿交涉。

问：皷声雄震云徒集，利人一句请师宣。师云：也须是儞重发扬始得。进云：学人秖恁么，师意又如何？师云：将谓汝会我意。

师又云：晨朝一粥，诸人已各知时，如今不可更要山僧处分吃茶去。便下座。

上堂，云：大众还知道圣僧同诸人到者里么？既劳尊降，焉敢稽留？久立，珍重。

## 杭州景德灵隐寺惠明禅师延󱸡

筠阳人也，俗姓张。年十三出家，二十受具，二十三行脚，徧参知识。

景德二年，游钱塘，遂挂锡于灵隐前住持慈济大师文胜。一日，示众云：纵目所观，复何所见？

才闻有悟，乃为颂曰：

天禧二年，府主马侍郎请开堂升座，维那白槌云：法筵龙象众，当观第一义。师云：还观得么？且作么生观？为复向长走升座处观？为复向维那白槌处观？若恁么观，即没交涉。

时有僧问：昔日梵王请佛布演三乘，今日侍郎请师当说何法？师云：今日何似当时？进云：恁么则人天有赖。师云：赖个什么？

问：祖祖相传传祖印，师今得法嗣何人？师云：儞也证明不得。进云：恁么则灵隐得旨，云居师孙。师云：莫乱道。

问：承侍郎牋疏有言：黄花翠竹当斩，直示于真如。学人上来，请师直示。师云：侍郎曲为上座。进云：恁么则赵州栢树人人委，灵隐黄花处处开。师云：儞也报侍郎恩未得。问：如何是灵隐境？师云：一任观取。进云：如何是境中人？师云：儞作么生会境？

问：不涉有无，请师道。师云：话堕也。

问：如何是道？师云：道远乎哉？问：如何是佛？师云：巍巍堂堂。

问：如何是观音入理之门？师云：我亦从中证。

问：承古有言：不是风动，不是幡动。未审此理如何？师云：歇去得也未？

问：学人已踏破明暗双关，请师一接。师云：费力作么？

问：如何是露地白牛？师云：头角甚分明。

问：如何是正真一路？师云：丝发不通。进云：恁么则依而行之。师云：莫乱走。

问：山岳无亏时如何？师云：白云横洞口。

上堂，云：与上座一线道，且作么生持论佛法？若也水泄不通，便教上座无安身立命处。当此之时，祖佛出头来也有二十棒分。恁么道，山僧还有过也无？不见云门大师道：世尊生下，周行七步，日顾四方，一手指天，一手指地，云：天上天下，唯我独尊。我当初若见，一棒打杀与狗吃却。何以如此？图得天下太平。且道云门恁么说话，有佛法道理也无？虽然如此，云门也秖具一只眼。久立，珍重。

纵目所观一何覩，烟风叠嶂翠崔嵬。 /
若晓自心非万法，祖师谁道是西来。 /

秋风萧索凋黄叶。几处衣砧声切切。 /
此个圆成入理门，何处更教余重说。 /

自爱居山独守愚，白云来往岂相疎。 /
有时茶罢林间去，信脚腾腾步不虚。 /

## 常州荐福院归则禅师

上堂日，僧问：请师一言，令学人达本源。师云：汝是行脚人。进云：未达者又如何？师云：谁是未达者？

问：如何是祖师西来意？师云：东畔打钟声。问：知师已唱胡家曲，未审宗风嗣阿谁？师云：宗风谁不知？进云：一曲已蒙师举唱，学人抚掌又如何？师云：汝未是知音者。

## 湖州何山宣化院惠忠禅师

开堂日，维那白槌云：法筵龙象众，当观第一义。师云：唯在谛观，不须求觅。恁么告报，却成重说偈言。若据适来维那白了，便好散去；既若未散，有事请问。

时有僧问：一佛出世，天雨四华，地摇六动。和尚出世，有何祥瑞？师云：更不要雨华。进云：恁么则大众沾恩，学人礼谢。师云：我却谢儞。

问：优钵华易见，善知识难逢，学人无问，请师不答。师云：莫谩大象。进云：还有向上事也无？师云：儞唤什么作向上事？

问：如何是何山境？师云：雨来山色暗，云出洞中明。进云：今日亲得观光也。师云：见什么？

问：诸佛出世转大法轮，和尚出世如何为人？师云：儞什么处见诸佛出世？进云：还有奇特事也无？师云：莫寐语。

问：祖风荡荡时如何？师云：儞是行脚僧。

## 杭州灵凤山太守禅院惠端禅师

俗姓吕，常州无锡县人。依杭州龙华寺悟乘禅师出家受具，得法于本师，更不他游。

师初升座时，有僧问：优昙华折人皆委，祖令亲行事若何？师云：识法者惧。进云：恁么则施行有据。师云：人小胆大。

问：承闻和尚亲见龙华，是否？师云：承闻谁说？进云：已遂成山志，何忘立雪功？师云：闲言语。

问：如何是佛法大意？师云：一人举令。进云：如何领会？师云：四海晏清。

问：梵王请佛，盖为群生。施主请师，当为何事？师云：少人证据。进云：施主诚，学人礼拜。师云：言犹在耳。䖍

上堂，僧问：如何是佛？师云：捏。进云：未审如何修证？师云：上上更加泥。

问：如何是涅槃？师云：好山好水。进云：不会。师云：益子益孙。

师上堂云：门庭肃静，宾主谁分？海晏河清，君臣道合。乾坤大地，古佛家风，十世古今，祖师宗令，如斯提唱，犹是买帽相头。若是本分衲僧，迢迢十万八千。珍重！

## 湖州海会院岳禅师

初开堂，拈香毕，便有僧问：如何是第一义？师云：不欲再三。进云：恁么则得闻于未闻。师云：闻底事作么生？进云：专得流传。师云：更须子细。

问：昔日么竭陀国亲行此令，和尚今日如何方便？师云：儞拟不遵。进云：天上忽雷惊宇宙，人天无不尽沾恩。师云：闲言语。

问：龙出洞中，雷腾霄汉，师登宝座，四众咸臻。向上宗乘，乞师一言。师云：一任贬剥。进云：恁么则学人礼谢。师云：得个什么？

问：梵王请佛，盖为群生；施主请师，当为何事？师云：谢儞证明。进云：恁么则天人群生类，皆承此恩力。师云：知恩人难得。

## 东京景德寺僧志言者

寿春人，姓许氏，受业于本寺七俱胝院，常亲法华讲席。一日，如感心恙，肆逸无羁，容止甚异。每遇诸涂，俱书空不已。或纸札示人，墨书道丽，往往事符其久。始诵法华经，因著称，终呼为言风子。然饮啖匪常，弊垢靡澣，而殊微俗状。集仙王质潜试之，具中馔。既而延入齐房，致问：如何是祖师西来意？函答曰：青山影竞泼岚起，宝塔高吟撼晓风。

又云：请法华烧香曰：未曾斋戒觅，不向佛僧求。

又僧问：儞是凡是圣？法华以手指曰：我在者里住。

后有国子助教徐岳问：如何是祖师西来意？曰：街头东畔底。进云：未会。曰：三般人问不得。

又有人问：如何是祖师西来意？曰：文殊在里寺，堦头莫问佗。

达者目为散圣，如佛图澄、寒山、拾得者也，故附于此。
