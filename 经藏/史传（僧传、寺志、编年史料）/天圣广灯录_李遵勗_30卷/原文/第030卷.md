# 天聖廣燈錄 · 第三十卷

> 宋 李遵勗編

---

世間事無常，猶如雲出電，尊者今時至。 /
應捨家出家。

一切法勝唯有行，清淨寂定不過心， /
染著恩愛最冤家，諸有恐怖是老死。 /

山羊被殺因作聲，飛蛾投燈由火色。 /
水魚懸鈎為吞餌，世人趣死以境牽。 /

本無生老病死過，并及地火水風空， /
湛然三世無師教，常淨自然證解脫。 /

法本法無法，無法法亦法，今付無法時。 /
法法何曾法。

如來弟子，且莫涅槃，得神通者，當赴結集。 /

法法本來法，無法無非法，何於一法中， /
有法有不法。

本來付有法，付了言無法，各各須自悟。 /
悟了無無法。

非法亦非心，無心亦無法，說是心法時， /
是法非心法。

通達非彼此，至聖無長短。汝除輕慢意， /
疾得阿羅漢。

若因地倒，還因地起，離地求起，終無其理。 /

稽首三昧尊，十力聖弟子，我今願迴向。 /
勿令有劣弱。

心自本來心。本心非有法，有法有本心。 /
非心非本法。

巍巍七寶山，常出智慧泉，迴為真法味。 /
能度諸有緣。

我法傳於汝，當現大智慧。金日從屋出， /
照曜於天地。

通達本法心，無法無非法，悟了同未悟。 /
無心亦無法。

我從無量劫，至于生此國，本姓頗羅墮， /
名字婆須密。

無心無可得，說得不名法。若了心非心， /
始解心心法。

心同虗空界，示等虗空法，證得虗空時， /
無是無非法。

賢劫眾聖祖，而當第七位，尊者哀念我。 /
請為宣佛地。

我所得法，而非有故，若識佛地，離有無故。 /

父母非我親，誰是最親者？諸佛非我道。 /
誰是最道者？

汝言與心親，父母非可比，汝行與道合， /
諸佛心即是，外求有相佛，與汝不相似。 /
欲識汝本心，非合亦非離。 /

虗空無內外，心法亦如是。若了虗空界， /
是達真如理。

我師諸祖中，當繼第八位，法化眾無量。 /
悉獲阿羅漢。

真理本無名，圖名顯真理，受得真實法。 /
非真亦非偽。

此地變金色，預知於聖至，當座菩提樹， /
覺華而成已。

師座金色地，常說真實義，迴光而照我。 /
令入三摩諦。

真體自然真，因真說有理，領得真真法。 /
無行亦無止。

我昔生梵天，梵天壽命盡，下生毗離國。 /
與汝同憂苦。我見汝無衣，心生憐愍故， /
分身為窠圍，令汝無憂苦。 /

迷悟如隱顯，明暗不相離。令付隱顯法。 /
非一亦非二。

稽首長老尊，當受如來記。今於此地上， /
宣通第一義。

隱顯即本法，明暗元不二。今付悟了法。 /
非取亦非離。

非隱非顯法，說是真實際。悟此隱顯法， /
非愚亦非智。

身現圓月相，以表諸佛體。說法無其戒， /
用辨非色聲。

為明隱顯法，方說解脫理。於法心不證， /
無瞋亦無喜。

此樹生奇耳，食以不枯槁，智者解此因。 /
當師其至道。

入道不通理，覆身還信施。汝年八十一。 /
此樹不生耳。

本對傳法人，為說解脫理，於法實無證。 /
無終亦無始。

稽首提婆尊，而出於仁者，仁者無我故。 /
我欲師仁者。

我已無我故，汝須見我我。汝若師我故， /
知我非我我。

三界一明燈，迴光而照我，十方悉開朗。 /
如日虗空住。我得遇大聖，願依師解脫。 /
志誠頭面禮，唯垂賜納受。 /

於法實無證，不取亦不離，法非有無相。 /
內外云何起？

善哉大聖者！心明如日月，一光照世界， /
暗魔無不滅。

稽首大慈父，和南骨血母。我今欲出家。 /
幸願哀愍故。

若人生百歲，不解諸佛機，未若生一日， /
而得決了之。

諸佛大圓鏡，內外無瑕翳，兩人同得見。 /
心眼皆相似。

心地本無生，因地從緣起，緣種不相妨。 /
花果亦復爾。

有種有心地，因緣能發萌，於緣不相礙。 /
當生生不生。

性上本無生，為對求人說。於法既無得， /
何懷決不決？

稽首三昧尊，不求於佛道，不禮亦不慢， /
心不生顛倒，不坐不懈怠，但食無所好， /
雖慢而不遲，雖急而不躁，今我遇尊者， /
和南依師教。

言下合無生，同於法界性。若能如是解， /
通達事理竟。

我行四國土，尋光到於此，汝是誰居舍？ /
而感生聖子。

泡幻同無礙，如何不了悟？達法在其中。 /
非今亦非古。

心隨萬境轉。轉處實能幽。隨流認得性。 /
無喜復無憂。

我今無太子，欲收於汝故。汝現神通者， /
令我心不定。汝有神通者，當現本來身， /
汝無神通者，常作宮千子。 /

認得心性時，可說不思議，了了無可得。 /
得時不說知。

一法一切法，一切一法攝，吾身非有無。 /
何分一切塔？

正說知見時，知見俱定心，當心即知見。 /
知見即于今。

聖人說知見，當境無非是。我今悟真性。 /
無道亦無理。

真性心地藏，無頭亦無尾，應緣而化物。 /
方便呼為智。

心地生諸種，因事復生理，果滿菩提圓。 /
華開世界起。

路行跨水復逢羊，獨自栖栖暗渡江。 /
日下可怜雙象馬，二株嫰桂久昌昌。 /

心中雖吉外頭凶，川下僧房名不中。 /
為遇毒龍生武子，忽逢小鼠寂無窮。 /

路上忽逢深處水，等閑見虎又逢猪。 /
小小牛兒雖有角，清溪龍出總須輸。 /

震旦雖闊無別路，要假姪孫脚上行。 /
金鷄解銜一顆米，供養十方羅漢僧。 /

八月商尊飛有聲，巨福來祥鳥不驚。 /
懷抱一鷄重起會，手把龍蛇在兩楹。 /
寄公席帽權時脫，蚊子之蟲足去形。 /
東海象歸披石脹，二處蒙恩總不輕。 /
日月並行若不動，即無冠子上山行。 /
更惠一峰添翠岫，玉教人識知始名。 /

高嶺無人又脫衣，小蛇雖毒不能為。 /
可中井底着天近，小小沙彌善大機。 /

大浪雖高不足知，百年凡木長乾枝。 /
一鳥南飛却歸北，二人東往復還西。 /

可憐明月獨當天，四箇龍兒各自迁。 /
東西南北奔波去，日頭平上照無邊。 /

吾此記詞，腰長脚短。合掌向天，迴頭失伴。 /
身著紅衣，又如素絹，立在目前，還如不見。 /
好好思量，水清月現。 /

鳥來上高堂欲驚，白雲入地色還青。 /
天上金龍日月明，東陽海水清不清。 /
手捧珠輪重復輕，雖無心眼轉醒醒。 /
不具耳目善觀聽，身體元無空有形。 /
不說姓字但籤名，意尋書卷錯看經。 /
口說恩幸心無情，或去或來身不停。 /

尊勝今藏古。無肱又有肱。龍來方授寶。 /
奉物伏嫌名。

起自求不礙。師言我沒繩，路上逢僧禮。 /
足下六枝分。

三四全無我。隔水受心燈。尊號過諸量。 /
從瞋不起增。

奉物可曾物。言勤又不勤。唯書四句偈。 /
為對瑞田人。

心裏能藏事。說向漢江濵。湖波探水月。 /
將照二三人。

領得彌勒語，離鄉日日敷。來梁移近路。 /
餘筭脚天途。

艮地生玄旨，通尊媚亦尊。比肩三吼族。 /
足下一毛生。

靈集媿天恩。生芽二六人。法中無氣味。 /
石上有功勳。

本是大蟲男。翻成師子談。官家封馬嶺。 /
同相三十三。

九女出人倫。八箇絕婚姻。朽牀添六足。 /
心祖眾中尊。

走戊與潮隣，鵝烏子出身，二天雖有感， /
三化寂無塵。

說少何曾少。言流又不流。草若除其首。 /
三四繼門修。

在胎為身，處世名人。在眼曰見，有耳曰聞。 /
在鼻辨香，在口談論，在手執捉，在足運奔。 /
徧現俱該沙界，收接在一微塵。 /
識者知是佛性，不識喚作精魂。 /

師壽於百歲，八十而造次，為近至尊故。 /
熏修而入道。雖具少智慧，而多有彼我， /
所見諸賢等，未甞生珍敬。四五修功德。 /
其心未恬靜，聰明輕慢，故而獲致於此。 /
得王不敬者，當感果知是，自今不踈怠。 /
不久成其智，諸聖悉在心，如來亦復爾。 /

仰覩兩扇，低腰捻鈎。九鳥射盡，唯有一頭。 /
至即不至，要假須刀。逢龍不住，遇水即逃。 /

吾本來茲土。傳法救迷情。一華開五葉。 /
結果自然成。

亦不覩惡而生嫌，亦不觀善而勤措， /
亦不捨智而近愚，亦不拋迷而就悟。 /
達大道兮過量，通佛心兮出度。 /
不與凡聖同躔，超然名之曰祖。 /

江槎分玉浪。管炬開金鎖。二三相共行。 /
九十無彼我。

本來緣有地，因地種華生，本來無有種， /
華亦不能生。

華種雖因地，從地種華生，若無人下種， /
華地盡無生。

華種有生性，因地華生生，大緣與性合。 /
當生生不生。

身是菩提樹，心如明鏡臺，時時勤拂拭。 /
莫遣惹塵埃。

菩提本無樹。明鏡亦非臺。本來無一物。 /
何處有塵埃。

有情來下種，因地果還生。無情既無種， /
無性亦無生。

心地含諸種，普雨悉皆生。頓悟華情已， /
菩提果自成。

頭上養親，口裏須餐。遇滿之難，楊柳為官。 /

震旦雖闊無別路，要假兒孫脚上行。 /
金雞解一粒米，供養什邡羅漢僧。㘅 /

心裏能藏事。說向漢江濵。湖波探水月。 /
將照二三人。

心地含諸種，普雨悉皆萠。頓悟花情已， /
菩提果自成。

心地含諸種，遇澤悉皆萠。三昧花無相， /
何壞復何成？

領得彌勒語，離鄉日日敷。東梁移近路。 /
餘氣脚天徒。

心地隨時說，菩提亦秖寧，事理俱無礙。 /
當生即不生。

自從大士傳心印，額有圓珠七尺身。 /
掛錫十年棲蜀水，浮杯今日渡漳濵。 /
一千龍象隨高步，萬里香華結勝因。 /
願欲事師為弟子，不知將法付何人。 /

心如大海無邊際，口吐紅蓮養病身。 /
雖有一雙無事手，不曾祗接等閑人。 /

流不止問如何，真照無偏說自他。㳂 /
離相離名人不稟，吹毛用了急還磨。 /

大道絕同，任向西東。石火莫及，電光枉通。 /

何代隱荒丘。茆堂獨幽。隨緣三事衲。 / 𥨊
頓覺萬緣休。貌古因持戒，身貧為少求。 /
吾師登鳥量，物外絕追遊。 /

詩詠人問事。空門何不刪。探珠宜靜浪。 /
動水取應難。名利心須剪，非朋不用攀。 /
捨邪歸正道，何慮不閑閑。 /

奪人不奪境。緣自帶譊訛。擬欲求玄旨。 /
思量返責麼。驪珠光璨爛，蟾桂葉婆婆。 /
覿體無差互，還應滯網羅。 /
奪境不奪人。尋言何處真。問禪禪是妄。 /
究理理非親。日照寒光澹，山搖翠色新。 /
直饒玄會得，恬似眼中塵。 /
人境兩俱奪。從來正令行，不論佛與祖。 /
那說聖凡情。擬犯吹毛劒，退傷值木盲。 /
進前求妙會，特地打精靈。 /
人境俱不奪。思量意不偏。主賓言不異。 /
問答理俱全。踏破澄潭月，穿開碧落天。 /
不能明妙用，淪溺在無緣。 /

閑佩毗盧印。人天末位尊。寶航橫鳳浦。 /
金錫挂龍門。去後梁王感，來光魏主恩。 /
葱山擕隻履，半偈動乾坤。 /

別嗣神州祖。聯燈又一迴。密傳三祖印。 /
還夢五侯街。玄字乾坤太，慈天日月開。 /
逆流漳浦上，天感泣雲雷。 /

北齊傳得印。獨步出人間。祖地江河闊。 /
隨天日月閑。妙音流四海，瑞氣溢三山。 /
一句南來信，清風撼雪關。 /

翠合雞山樹。峩峩祖岫松。凝霜分五葉。 /
含雪振雙峯。月逈金河內，珠添玉鏡中。 /
颼飅傳細離，天下播真宗。 /

東山分祖印。空際月成輪。碧眼風光翠。 /
黃梅樹色春。九枝添瑞鶴，一葉拂祥麟。 /
別得金僊記，曹谿第五人。 /

南得黃梅意。曹谿記法泉。三衣兼祖印。 /
一鉢盡師傳。慈月光千海，玄河注百川。 /
神洲十二代，法眼繼相傳。 /

天中慈月三峯逈，指外懸河萬派深。 /
仙舸獨遊華藏海，無邊川澤喜歸心。 /

熊耳宗師葬洛陽，龍城天子位千行。 /
迴擔隻履葱山上，驚殺梁王與魏王。 /

麟眠法苑分千葉，馬踏曹谿迸萬泉。 /
古佛傳中親授記，月轉碾破海中天。 /

百丈和霜嶺上松，蛇盤鶴性瘦如龍。 /
下堂索著稱名字，不會師心一萬重。 /

龍控懸河海月秋，煙霞風雨一時収。 /
波濤急急人難會，截斷千江水不流。 /

祖派波瀾半偈玄，曹谿舟棹接風煙。 /
一轉海底龍潭月，碾破雞山雪嶺前。 /

身受龍華三會主，搥開鳳閣九重城。 /
梁王築倒金剛佛，更門如何不講經。 /

藥岫龍泉照瞻清，乾坤宗匠盡流行。 /
格高一句難分出，驀就雲巖谷口明。 /

一片丹霞見石頭，麒麟雙鳳況難傳。 /
鋒欲說宗門印，哽得師心掩耳休。𨦵 /

白鳳烟霞控鳥窠，驪龍珠耀祖山河。 /
當初捻起布毛意，體用毗盧些子多。 /

龍劒雕弓祖佛威，霜鋒雷電急難追。 /
當初金鏃胷前過，由未重玄多許為。 /

雪彩霜威馬祖風，虎降高格氣如龍。 /
誰人會得歸宗路，一鏃三關海內通。 /

虎見烟蘿透洞門，心中古佛震乾坤。 /
龍泉截斷麒麟角，撼得毗盧海月昏。 /

一派曹源與灌谿，龍行風雨動雲霓。 /
後機箭筈波瀾急，撼得毗盧海岳低。 /

龍吟鳳彩震乾坤，熊耳雞山海內聞。 /
一片雪霜三島外，虎心半偈灑風雲。 /

六葉牛頭枡別栽，五天熊耳縱雲雷。 /
須知四祖垂機接，百鳥銜華更不來。 /

發意當初問石頭，江河心濆渺分流。 /
喚迴指出毗盧印，便得如山萬事休。 /

虎徑龍泉遶行巖，鳳棲霜倚鶴和杉。 /
誰人會得宗師意，紐轉乾坤好不參。 /

龍宮鹿苑百川通，八藏三乘在掌中。 /
却是江西逢馬祖，迴頭踏轉大虗空。 /

踈嶺松蘿五葉雲，毗盧天外別為秦。 /
驪龍踏落虗空月，木馬重嘶雨露新。 /

錫撼風霜虎豹愁，楚王城裡倒騎牛。 /
騰騰盡喝關南皷，聲壓雲雷動九疇。 /

熊耳雞山五印玄，蛇盤鳳口九瓟泉。 /
紫霄峯上一輪月，照破曹谿半夜圓。 /

別沐曹谿水，棲衡嶽萬重，有心傳五葉， /
無意據千峯。洞鶴爭藏翼，巖雞息瘦容。 /
一聲乾象外，海內繼真風。 /

五天慈雨細。師得潤禪林，碧眼千燈印。 /
清源一派心。有涯來敻遠，無底更深沉。 /
別嗣曹谿後，眾人仰德音。 /

根蔕欲何尋。孤奇逈眾林。鳳來敲節目。 /

## 杭州南山興教寺惟一禪師

初開堂陞座，維那白槌云：法筵龍象眾，當觀第一義。師云：重言不當，大眾還委麼？且作麼生是第一義？若自觀者，名為正觀；若佗觀者，名為邪觀。或有問話，請埀見示。

時有僧問：覺華開處，徧滿娑婆，祖意西來，合談何事？師云：孤猨呌落中巖月，野客吟殘半夜燈。進云：恁麼則昔日靈山，今朝興教。

師云：相識滿天下，知心有幾人？學人佇思，師云：速還三拜。

問：師唱誰家曲？宗風嗣阿誰？師云：不避來機，速當一問。進云：恁麼則五老峯前親得旨，今朝興教度群迷。師云：不是智音者，那能辨濁清？

問：承古有言：如來有正法眼藏，付囑摩訶迦葉。和尚今朝當付何人？師云：者裏有多少人？進云：未曉者如何領會？師云：還我話來。

上堂，僧問：不落見聞，請師答話。師云：三十年後。

問：眾手淘金，誰是得者？師云：是儞眼皮重。進云：恁麼則駿馬不移蹄。師云：金在什麼處？

問：狂風忽起，掃蕩煙雲，學人到此為什麼不會？師云：真箇不會。進云：不探龍領，爭獲驪珠？師云：珠在什麼處？

問：達磨未來時如何？

師云：索橋路險人難度。進云：來後如何？師云：少林閑坐九年餘。

問：牛頭未見四祖時如何？師云：南來冬熟笋。進云：見後如何？師云：北去夏宜桃。

問：佛末出世時如何？師云：白雲數重。進云：出世後如何？師云：青山一帶。

問：如何是道？師云：刺頭入荒草。進云：如何是道中人？師云：乾屎橛。

問：曹谿一曲師親唱，未審如何和得齊？師云：儞試道看。進云：恁麼則謝師舉唱。師云：秖為宮商調不同。

問：大耳三藏第三度為什麼不見國師？師云：脚跟下看。進云：如何得見？師云：草鞋根斷。

問：和尚未見棲賢時如何？師云：春來好寒。進云：見後如何？師云：秋去盛熱。

## 真州定山惟素山主

有僧問：古人拈槌豎拂不當宗乘，未審山主如何為人？師云：旦莫強惺惺。進云：恁麼則却成起動也。師云：龍頭虵尾漢。

問：如何是不遷？師云：暑往寒來。進云：恁麼則遷去也。師云：啼得血流無用處。

問：達磨心印師已曉，試舉家風對眾看。師云：門前有箇長松樹，夜半子規來上啼。進云：恁麼則白鼉一派，流注十方。師云：日月麗天，風雲難蔽。

問：知師洞達諸方旨，臨機不答舊時禪，如何是新奇？師云：若到諸方，不得錯舉。進云：學人慇懃於座右，莫不秖此是新奇？師云：折草量天。

問：如何是定山境？師云：清風滿院。進云：忽遇客來，將何祇待？師云：莫嫌冷澹。

師云：若論家風與境，也不易酬對，多見指定處所，教他不得自在。曾有僧問大隨：如何是和尚家風？答云：赤土上畫簸箕。又云：肚皮上不貼牓。且問諸人作麼生會？更有夾山、雲門、臨濟、風穴皆有此話，播於諸方，各各施設不同，又作麼生會？法無異轍，殊途同歸。若要省力易會，但識取自家桑梓，便能紹得家業，隨處解脫，應用現前，天地同根，萬物一體，喚作衲僧眼睛，緜緜不漏絲髮。苟或於此不明，徒自伶俜辛苦。

有僧問：眾手淘金，誰是得者？師云：莫作貴。進云：不作貴又如何？師云：金在什麼處？

問：如何是佛？師云：含齒戴髮。進云：恁麼則人人具足。師云：遠之又遠。

問：如何是不生不滅法？師云：春到百華開，秋來群木落。進云：恁麼則一年一度春也。師云：欠子細在。

問：牛頭未見四祖時如何？師云：成象立業。進云：見後如何？師云：立業成家。

問：如何是一味法界？師云：花紅柳綠。進云：如何是定山路？師云：峭。進云：履踐者如何？師云：嶮。

問：萬法歸一，一歸何所？師云：一葉落，天下秋。進云：如何領會？師云：三十年後。

問：承教有言：無上法王有大陀羅尼門，名為圓覺，流出一切清淨真如、菩提涅槃。未審圓覺從什麼處流出？師云：山僧頂戴有分。進云：恁麼則信受奉行。師云：依稀似曲纔堪聽。

師又云：將知佛法，須是徹底悟得，方能始終一貫，作用施為，得其自在。若是學成者，終有劑限。子細窮究，便隨末忘本，喚作流浪生死，無本可據。所以教中云：何況能以有思惟心，測度如來圓覺境界？如取螢火燒須彌山，終不能着。若論此事，無用心處，亦非懈怠而得。却請上座各自迴光返照，與道稍有相應。其如不達宗旨，總成逐塊。

僧問：十二時中如何得與道相應？師云：皇天無親，唯德是輔。進云：恁麼則不假脩證也。師云：三生六十劫。

問：如何是深山巖崖逈絕無人處佛法？師云：月明千嶂裏，風動萬年枝。進云：恁麼則處處菩提道，明明功德林。師云：薰天炙地。

問：如何是佛法大意？師云：山高海深。

問：不見一法即如來，方得名為觀自在。如何是觀自在？師云：好好禮三拜。進云：莫秖者便是？師云：十萬八千。

## 蘇州西山堯峰院顥暹禪師

初開堂，有僧問：法筵龍象眾，當觀第一義。如何是第一義？師云：儞去什麼處來？

問：海門三級浪，專聽一聲雷時如何？師云：猶是未警發在。

問：如何是佛？師云：無比不思議。

問：先聖出世為一大事因緣，和尚今日出世當為何人？師云：秖恐儞未是其人。

問：如何是祖師西來意？師云：盡道九年曾面壁。

問：如來路上無私曲，便請玄音和一場。師云：莫並巴兒曲，須超白雪辭。

問：祖祖相傳傳祖印，師今得法嗣何人？師云：同道方知。

問：如何是和尚為人一句？師云：山僧自來不曾容易。

上堂云：止止不須說，言詮道復優。有疑如未決，對眾莫淹留。

時有僧問：學人有疑，請師決。師云：者迴更莫淹留。

問：未經爐冶時如何？師云：爭得成器？

問：善財徧參，還具本分事也無？師云：善財徧參為什麼事？

問：一念萬年時如何？師云：還得盡善也未？

問：心徑未通時如何？師云：是誰之過？

問：能所俱忘時如何？師云：那箇是儞忘底能所？

問：如何是真規自宛然？師云：千聖不能宣。

問：如何是道？師云：堯舜其猶病諸。

問：如何是密作用？師云：秖恐大眾未肯儞。

問：學人乍入叢林，乞師一接。師云：去。

問：承教有言：是法平等，無有高下。如何是平等底法？師云：堯峯高，寶華低。學云：恁麼則却成高下去也。師云：情知儞恁麼會。

問：承教有言：妙湛總持不動尊，首楞嚴王世希有。如何是不動尊？師云：世希有。學云：恁麼則不動真際隨處發揮去也。師云：却不令人讚歎。

師云：諸上座！秖如此僧問不動尊，山僧向他道：在希有。意旨又且如何？莫是三秖果滿，萬行功圓，是世之希有麼？又莫是當人分上本自圓成，不勞修證麼？若也恁麼會，實謂妄認緣塵，分別影事。既不許上座恁麼會，向者裏作麼生承當？若也承當得，便乃不從一地主一地，寂滅性中無有異。若向者裏承當未得，不免須待龍華重授記在。各請歇去。珍重。

上堂，聞雷聲，乃示眾云：還聞雷聲麼？還知起處麼？若知起處，便知身命落處；若也不知，所以古人道：不知天地者，剛道有乾坤。不如喫茶去。

上堂，僧問：如何是堯峯境？師云：多少人看望不足。

問：如何是道？師云：夕死可矣。問：如何是金剛力士？師云：者裏用不著。

問：如何是孤峯節操松？師云：而今未堪看，更待雪霜中。

問：如何是佛？師云：休更歷僧祇。

問：魚龍得水時如何？師云：踊躍無盡。

問：片雲出洞時如何？師云：何必龍吟。

問：亡僧遷化向什麼處去也？師云：蒼天！蒼天！

師復云：大眾！秖如未後一僧問：亡僧遷化向什麼處去也？山僧向化道：蒼天！蒼天！且道意旨落在什麼處？莫是悲傷遷逝，痛憶道人麼？若乃恁麼評論，實謂罔知去處。要知去處麼？更不用久立歇去。

師春日上堂云：久去春來，樓閣門開，若也入得，不用俳徊。諸上座！還向者裏入得也未？若也入得，所以古人道：是處是彌勒，無門無善才。若也入之未得，自是諸上座狂走，更不忉忉。久立，珍重！

## 蘇州吳江聖壽院志昇禪師

初開堂時，有僧問：知師久醞葡萄酒，今朝慈濟為誰開？師云：想儞也未知滋味。進云：恁麼則優曇華扸，法界馨香，佛日初開，昏衢永耀。師云：不勞如此。

問：寶座既登於此日，家風一句請師宣。師云：儞還證明得麼？學云：恁麼則人天有賴，四眾咸忻。師云：閑言語。

問：師赴群心揚祖道，未知祖道嗣何方？師云：同道方知。學云：恁麼則錦里昔年親得旨，松江今日度群迷。師云：却不是我同道。

問：四眾臨筵當此日，玄機一決為誰宣？師云：儞不妨刢利。進云：恁麼則非唯大眾朝宰霑恩。師云：莫亂道。

上堂，僧問：如何是佛？師云：人天贊莫及。

師又云：若論佛法，更有什麼事？所以道：古今山河、古今日月、古今人倫、古今城郭，喚作平等法門，絕前後際。諸人還信得及麼？若信得及，依而行之。久立，珍重。

## 杭州臨安縣功臣山開化院守如禪師

初開堂日，有僧問：朝宰既伸於三請，師將何法報深恩？師云：何以儞特致？

問：如何是功臣為人一句？師云：自來不曾埋沒人。

問：承教有言：清淨本然。云何忽生山河大地？師云：且道是誰致得？進云：恁麼則滿眼青山無寸樹，極目淥水絕波瀾。師云：也是錯會。

問：如何是功臣境？師云：上座合具行脚眼。進云：恁麼則峨嵋？凝千尋雪，鼇背巍籠五色烟。師云：勿交涉。

## 杭州景德靈隱寺惠明禪師延󱸡

筠陽人也，俗姓張。年十三出家，二十受具，二十三行脚，徧參知識。

景德二年，遊錢塘，遂挂錫于靈隱前住持慈濟大師文勝。一日，示眾云：縱目所觀，復何所見？

纔聞有悟，乃為頌曰：

天禧二年，府主馬侍郎請開堂昇座，維那白槌云：法筵龍象眾，當觀第一義。師云：還觀得麼？且作麼生觀？為復向長走陞座處觀？為復向維那白槌處觀？若恁麼觀，即沒交涉。

時有僧問：昔日梵王請佛布演三乘，今日侍郎請師當說何法？師云：今日何似當時？進云：恁麼則人天有賴。師云：賴箇什麼？

問：祖祖相傳傳祖印，師今得法嗣何人？師云：儞也證明不得。進云：恁麼則靈隱得旨，雲居師孫。師云：莫亂道。

問：承侍郎牋疏有言：黃花翠竹當斬，直示於真如。學人上來，請師直示。師云：侍郎曲為上座。進云：恁麼則趙州栢樹人人委，靈隱黃花處處開。師云：儞也報侍郎恩未得。問：如何是靈隱境？師云：一任觀取。進云：如何是境中人？師云：儞作麼生會境？

問：不涉有無，請師道。師云：話墮也。

問：如何是道？師云：道遠乎哉？問：如何是佛？師云：巍巍堂堂。

問：如何是觀音入理之門？師云：我亦從中證。

問：承古有言：不是風動，不是幡動。未審此理如何？師云：歇去得也未？

問：學人已踏破明暗雙關，請師一接。師云：費力作麼？

問：如何是露地白牛？師云：頭角甚分明。

問：如何是正真一路？師云：絲髮不通。進云：恁麼則依而行之。師云：莫亂走。

問：山嶽無虧時如何？師云：白雲橫洞口。

上堂，云：與上座一線道，且作麼生持論佛法？若也水洩不通，便教上座無安身立命處。當此之時，祖佛出頭來也有二十棒分。恁麼道，山僧還有過也無？不見雲門大師道：世尊生下，周行七步，日顧四方，一手指天，一手指地，云：天上天下，唯我獨尊。我當初若見，一棒打殺與狗喫却。何以如此？圖得天下太平。且道雲門恁麼說話，有佛法道理也無？雖然如此，雲門也秖具一隻眼。久立，珍重。

縱目所觀一何覩，煙風疊嶂翠崔嵬。 /
若曉自心非萬法，祖師誰道是西來。 /

秋風蕭索凋黃葉。幾處衣砧聲切切。 /
此箇圓成入理門，何處更教余重說。 /

自愛居山獨守愚，白雲來往豈相疎。 /
有時茶罷林間去，信脚騰騰步不虗。 /

自愛居山任寂寥，豈同塵世事喧囂。 /
松門秖在煙霞際，到者方知路不遙。 /

## 湖州何山宣化院惠忠禪師

開堂日，維那白槌云：法筵龍象眾，當觀第一義。師云：唯在諦觀，不須求覓。恁麼告報，却成重說偈言。若據適來維那白了，便好散去；既若未散，有事請問。

問：祖風蕩蕩時如何？師云：儞是行脚僧。

## 杭州靈鳳山太守禪院惠端禪師

俗姓呂，常州無錫縣人。依杭州龍華寺悟乘禪師出家受具，得法於本師，更不他遊。

問：承聞和尚親見龍華，是否？師云：承聞誰說？進云：已遂成山志，何忘立雪功？師云：閑言語。

問：如何是佛法大意？師云：一人舉令。進云：如何領會？師云：四海晏清。

## 東京景德寺僧志言者

壽春人，姓許氏，受業於本寺七俱胝院，常親法華講席。一日，如感心恙，肆逸無羈，容止甚異。每遇諸塗，俱書空不已。或紙札示人，墨書道麗，往往事符其久。始誦法華經，因著稱，終呼為言風子。然飲啖匪常，弊垢靡澣，而殊微俗狀。集仙王質潛試之，具中饌。既而延入齊房，致問：如何是祖師西來意？函答曰：青山影競潑嵐起，寶塔高吟撼曉風。

又云：請法華燒香曰：未曾齋戒覓，不向佛僧求。

又僧問：儞是凡是聖？法華以手指曰：我在者裏住。

後有國子助教徐岳問：如何是祖師西來意？曰：街頭東畔底。進云：未會。曰：三般人問不得。

又有人問：如何是祖師西來意？曰：文殊在裏寺，堦頭莫問佗。

達者目為散聖，如佛圖澄、寒山、拾得者也，故附於此。
