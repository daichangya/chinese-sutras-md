# 贤劫十六尊 · 第一卷

---

于彼轮坛外，贤劫千佛中， /
十六为上首，弥勒持军持， /
不空莲华眼，除忧梵夹相， /
除恶三股杵，香象执莲华， /
大精进锵戟，虚空藏宝光， /
智幢幢幖帜，无量光莲华， /
贤护持宝瓶，纲明纲伞盖， /
月光半月幢，无量意梵夹， /
辨积持华云，金刚藏独股， /
普贤五智印，种子初阿字， /
吽字左按地。

金刚界外院，地居空行天， /
略说有五类，忿怒称吽字， /
安布二十天，芰荷以为座， /
东北那罗延，执轮罗刹形， /
俱摩罗铃契，摧碎夜迦天，童子形 /
伞盖宝东门，梵天持红莲， / 如天
天帝独股杵，火天在东南，童子形赤色 /
三角为标帜，日天童子形， /
金刚食持鬘，焰魔檀荼印， / 赤色
荧惑火光聚，西南罗刹主，恐怖相赤色 /
执锤并眷属，岁星天持棒， /
金刚衣夜迦，西门持弓箭， /
水天执羂索，次置于月天， / 童子形
风幢西北隅，金刚面执钩，罗刹形灰色黑 /
调伏金刚剑，门东多门天， / 金色
掌塔持宝棒，伊舍那戟印。 / 左持劫波罗

如是大天众，威德有多门， /
妃后并眷属，皆在曼荼罗， /
应当具开示，供养夜迦天， /
应居北门东。
