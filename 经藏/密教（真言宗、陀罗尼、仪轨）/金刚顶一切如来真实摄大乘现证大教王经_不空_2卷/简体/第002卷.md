稽首薄伽梵、大毘卢遮那！ /
能为自在王，演说金刚界， /
无边功德法，成五解脱轮， /
三十七智身，我今归命礼。 /
瑜伽大教王！开演一佛乘， /
如来三密藏，是乘无比喻， /
最上最第一，唯佛不共智， /
相应成佛门，为令悟入者， /
圆成净法身。三世薄伽梵！ /

瞻礼于圣会，不舍菩提心。 /
恭敬阿阇黎！等同一切佛！ /

即是诸如来！金刚莲华手！ /
虚空巧业尊，故应坚守护。 /
本尊三昧耶，倍过于身命， /
