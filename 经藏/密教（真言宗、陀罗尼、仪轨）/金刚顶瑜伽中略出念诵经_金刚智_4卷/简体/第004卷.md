为利诸众生，令得三身故， /
身、口、意相应，归命礼三宝。 /
金刚身、口、意，遍满三界者， /
能为自在主，演说金刚界， /
我尽稽首礼。雄猛阿閦鞞， /
降伏诸魔者；彼宝现最胜， /
及礼如理法；归命阿弥陀， /
成就不空者，于金刚萨埵， /
利益众生者；归命虚空藏， /
能授灌顶者；依护大观音， /
从瑜伽生者；秘毘首羯磨， /
至心我尽礼。

「『诸法如影像，清净无浊秽， /
无取、无可说，因业之所生。 /
如是了此法，离自性无依， /
利无量众生，是如来意生。』 /

「『我是普贤，坚固萨埵，虽非身相， /
自然出现，以坚牢固，为萨埵身。』 /

「『此跋折啰，是诸如来，无上悉地。 /
我是金刚，授与我手，以我金刚， /
执持金刚。』

「『我是不空王，从彼金刚生， /
以为大钩召。诸佛成就故， /
能遍一切处，钩召诸如来。』 /

「『我是诸如来，无上金刚智， /
能成就佛事，最上钩召者。』 /

「『我自性清净，能以染爱事， /
奉事于如来。以离染清净， /
染故能调伏。』

「『此是一切佛，离垢爱染智， /
以染害离染，一切受安乐。』 /

「『我是最胜，一切智者，所共称说。 /
若诸妄想，分别断除，闻常欢喜。』 /

「『此是诸佛等，善哉能转者， /
此殊妙金刚，能增益欢喜。』 /

「『我是自灌顶，金刚宝无上， /
虽无住著者，然为三界主。』 /

「『此诸如来许，能灌众生顶。 /
我是手授者，及授与我者， /
以宝而饰宝。』

「『无比大威光，能照众生界， /
令诸佛依护，虽复净即是， /
净中能复净。』

「『此是诸佛智，除灭无智暗， /
以微尘等量，超越于日光。』 /

「『无比量幢，我能授与。一切利益， /
满足悉地；一切所求，一切能满。』 /

「『此是诸如来，希求能圆满， /
名为如意幢，檀波罗蜜门。』 /

「『我是为大笑，一切胜中上， /
恒常善住定，以为佛事用。』 /

「『此是诸如来，示生现希有， /
大智能踊跃，二乘所不知。』 /

「『我是第一义，本来自清净， /
筏喻于诸法，能得胜清净。』 /

「『此是诸佛慧，能觉了贪爱， /
我及所授者，于法而住法。』 /

「『我是诸佛语，号为文殊声， /
若以无形色，音声可得知。』 /

「『此是诸如来，般若波罗蜜， /
能破诸怨敌，灭罪中为最。』 /

「『于执金刚中，金刚轮为上， /
彼以才发心，而能转法轮。』 /

「『此是诸如来，能净治一切， /
是名不退转，菩提之道场。』 /

「『自然之秘密，我为密语言， /
若说于正法，远离语戏论。』 /

「『此是诸如来，金刚之念诵， /
于诸如来秘，能为速成就。』 /

「『诸佛羯磨不唐捐，羯磨金刚而能转， /
唯我住兹能广为，以无功用作佛事。』 /

「『此是诸如来，最上毘首磨， /
我及所授者，羯磨能羯磨。』 /

「『精进所成甲坚牢，坚牢于余坚牢者， /
以坚牢故非色身，能为最上金刚身。』 /

「『此是诸如来，最上慈甲胄， /
坚固精进护，名为大亲友。』 /

「『我是诸佛大方便，有大威德应调伏， /
若为寂静利众生，摧灭魔故作暴恶。』 /

「『此是诸佛现，最上降伏者， /
金刚牙器仗，哀愍方便设。』 /

「『我是三摩耶，坚牢缚身者， /
诸愿求成就，虽解脱示缚。』 /

「『此是诸如来，坚牢金刚缚， /
若为一切印，速疾成就故， /
三摩耶极难，羯磨能超度。』 /

「『诸佛与萨埵，金刚极坚牢， /
若以坚牢故，非身金刚身。』 /

「『诸佛金刚契，我是宝金刚， /
坚牢灌顶门，说如来身印。』 /

「『一切佛谓我，清净法金刚， /
若以性清净，虽染而清净。』 /

「『一切如来智，我多种羯磨， /
金刚若唯一，尽遍佛世界， /
能事业羯磨。』

「『我无比供养，余无有能者， /
若以爱供养，能成诸供养。』 /

「『我是无宝，名宝供养，若于三界， /
为胜谛王，即以供养，而为教令。』 /

「『我是诸供养，以为歌咏者， /
虽能令欢喜，假设如空响。』 /

「『广大一供一切供，能作利益遍世间， /
若以金刚舞仪式，而能成就佛供养。』 /

「『我为天供养，能令善滋茂， /
若入诸众生，速得证菩提。』 /

「『我是花供养，能为诸严具， /
供养宝性已，速获于菩提。』 /

「『我是大供养，以为清净灯， /
若具法光明，速得诸佛眼。』 /

「『我涂香供养，是殊妙悦意， /
若以如来香，遍授一切身。』 /

「『我是诸如来，坚固三摩耶， /
若我钩召已，祗奉一切坛。』 /

「『我是诸如来，金刚固羂索， /
设入诸微尘，复令彼引入。』 /

「『我是诸如来，金刚坚钩锁， /
虽一切缚解，为生故受缚。』 /

「『我是诸如来，金刚摄牢固， /
能为一切主，亦复作童仆。』 /

「『愿来一切诸有中，唯一坚实秘密者， /
用能折伏暴恶魔，现证无边离自性， /
我今钩召依教请，愿周云海来集会。』 /

「『金刚萨埵摄受故，得为无上金刚宝； /
金刚言词歌咏故，愿成金刚胜事业。』 /

「『于诸世界种类中，能作尘数诸佛事， /
如来示现大神变，随应显现种种身。 /
无比不动常坚法，悲体能除世间苦， /
能授悉地诸功德，无比等力胜上法。 /
无有譬喻等虚空，少分功德尚无际， /
遍众生界胜悉地，无比无量尽能成。 /
常法清净由悲起，愿力成就住世间， /
能为利乐无边际，大悲为体常遍照。 /
悲行不动、不取灭，游化三界授悉地， /
诸不可量尽通达，虽已善逝现希奇。 /
常住三世力无碍，最上依怙无能超， /
能授一切三摩耶，愿我速成胜悉地。』 /

「『诸部莲座天人师，得大解脱超三界， /
功德圆满大悲者，我皆至心尽归依。 /
最胜慧者所住处，劣乘怖之比稠林， /
能速灭除生死有，我今归依最胜法。 /
能除贪、恚、痴蛇毒，以慧得出生死宅， /
起大悲心觉悟者，敬礼归命众中尊。』 /

「『普贤法身遍一切，能为世间自在主， /
无始无终无生灭，性相常住等虚空。 /
一切众生所有心，坚固菩提名萨埵， /
心住不动三摩地，精勤决定名金刚。 /
我今说此诚实言，惟愿世尊扶本愿， /
利众生事诸悉地，慈悲哀愍为加持。』 /

「『诸佛覩史下生时，释、梵、龙、神随侍卫， /
种种胜妙吉祥事，愿汝今时尽能获。 /
迦毘罗卫诞释宫，龙王澍沐甘露水， /
诸天供养吉祥事，愿汝灌顶亦如是。 /
金刚座上为群生，后夜降魔成正觉， /
现诸希有吉祥事，愿汝此座悉能成。 /
波罗奈苑所庄严，为五仙人开妙法， /
成就无量吉祥事，愿汝今时咸证获。』 /

「『诸佛金刚灌顶仪，汝已如法灌顶竟， /
为成如来体性故，汝应受此金刚杵。』 /

「『一切诸法性，垢净不可得， /
非实亦非虚，皆从因缘现。 /
应当知诸法，自性无所依， /
汝今真佛子，应广利众生。』 /

「『三界极重罪，不过于厌离， /
汝于贪欲处，应生厌离心。』 /

「『此等三摩耶，诸佛为汝说， /
守持善爱护，当如保身命。』 /

「『金刚萨埵摄授故，得成无上金刚宝， /
今以金刚法歌咏，愿为我作金刚事。』 /

「结萨埵金刚契已，作是思惟：『如诸劫树能与种种衣服、严身资具，彼等皆为供养一切如来作事业故，我今奉献。』密语曰：西方国王长者以种种花香、璎珞装挂树上，布施一切，此名劫树

「唵萨婆怛他揭多阿努怛啰婆曰噜跛摩三摩地婆钵那跛那部折那网萨那布穰暝伽三慕达罗窣发啰拏三末曳吽无上二合无可反

「论曰：以一切如来无上金刚喻三摩地修习，上妙饮食、衣服、云海普皆供养。

「结羯磨金刚契已，作是思惟：『虚空藏中一切如来为承事故，即想一一佛前皆有己身亲近侍奉。』诵密语曰：

「唵萨婆怛他揭多迦耶祢耶怛那布穰暝伽三慕达啰窣发啰拏三末曳去泥底反𤙖

「论曰：以自身奉献一切如来云海，普皆供养。

「结达摩金刚契已，作是思惟：『我今此身与一切菩萨身等同无异。』复应观察诸法实性平等无异。作是观已，诵密语曰：

「唵萨婆怛他揭多质多祢耶怛那布穰暝伽三慕达啰窣发啰拏三末曳𤙖

「论曰：以一切如来心奉献云海，普皆供养。

「结宝幢契已，复应观察：『尽生死中一切众生苦恼所缠，深生哀愍，我今为救护故，发阿耨多罗三藐三菩提心。是故，若未度者，我当令度；未安慰者，当令安慰；未涅槃者，令得涅槃；及雨种种宝，随彼所求皆令满足。』作是思惟已，诵此密语：

「唵萨婆怛他揭多摩诃跋折噜嗢婆摩但那波罗蜜多布穰暝伽三慕达啰窣发啰拏三末曳𤙖

「论曰：以一切如来大金刚所生檀波罗蜜云海普皆供养。

「结香身契已，作是思惟：『愿一切众生身、口、意业、一切不善愿皆远离，一切善法愿皆成就。』作是念已，诵此密语：

「唵萨婆怛他揭多阿耨多啰摩诃部驮贺啰俱舍啰波罗蜜多布穰暝伽三慕达啰窣发啰拏三末曳田夜反𤙖

「论曰：以一切如来无上菩提所生善戒波罗蜜多云海普皆供养。

「结触地契已，复作是念：『愿一切众生成就慈心，无相恼害，离诸怖畏，彼此相视心生欢喜，以诸相好庄严其身，成就一切甚深法藏。』作是思惟已，诵此密语：

「唵萨婆怛他揭多阿耨多罗摩诃达磨网报陀乞叉地波罗蜜多布穰暝伽三慕达啰窣发啰拏三末曳无可反𤙖

「论曰：以一切如来无上法大觉悟忍辱波罗蜜多云海普皆供养。

「结金刚鬪胜精进契已，作是思惟：『愿一切众生修菩萨行，被精进坚固甲胄。』作是念已，诵此密语：

「唵萨婆怛他揭多僧娑啰诃钵哩哆伽摩诃毘离耶波罗蜜多布穰暝伽三慕达啰窣发啰拏三末曳去当迦反去𤙖

「论曰：以一切如来不舍生死大精进波罗蜜多云海普皆供养。

「结三摩地胜上契，作是思惟：『愿一切众生尽能调伏烦恼、随烦恼怨仇，获得一切深禅定相。』作是念已，诵此密语：

「唵萨婆怛他揭多阿耨多啰摩诃扫溪毘贺啰驮那婆啰蜜多布穰暝伽三慕达啰窣发啰拏三末曳企伽反田夜反𤙖

「论曰：以一切如来无上大安乐住禅定波罗蜜多云海普皆供养。

「结一切如来能授与一切众生愿者宝生契已，作是思惟：『愿一切众生成就五种明处智，一切世间、出世间智慧普皆成就，得真实见，获得尽除烦恼所知障智，以辩才、无畏等一切佛法严饰其心。』作是念已，诵此密语：

「唵萨婆怛他揭多阿耨多罗。戞囇沙宁耶婆啰拏婆萨那弭奈耶那摩诃钵穰波罗蜜多布穰暝伽三慕达啰窣发啰拏三末曳更鎋反力揩反烦恼也所知也障习气也能调伏也二合大慧也㗚𤙖

「论曰：以一切如来无上调伏净烦恼习气大慧波罗蜜多云海普皆供养。

「结胜上三摩地契已，应当思惟：『诸法真实性相皆空、无相、无作，一切诸法悉皆如是。』作是观已，诵此密语：

「唵萨婆怛他揭多悟呬耶摩诃钵哩钵底布穰暝伽三慕达啰窣发啰拏三末曳密修行𤙖

「论曰：以一切秘密修行云海普皆供养。

「复应思惟：『我今所出语言音声令一切众生悉皆得闻。』作是念已，诵此密语：

「唵萨婆怛他揭多婆袪祢耶但那布穰暝伽三慕达啰窣发啰拏三末曳语言也𤙖

「复以金刚语言应以清美音赞之，颂曰：

「如是赞已，若更有余胜妙赞颂，随意赞之。其赞咏法，晨朝当以洒腊音韵、午时以中音、昏黄以破音、中夜以第五音韵赞之。如不解者，随以清好音声赞叹，常应每日四时念诵——谓晨朝、日午、黄昏、夜半也。应持四种数珠作四种念诵——作四种者，所谓：音声念诵，二、金刚念诵，三、三摩地念诵，心念是也，四、真实念诵，如字义修行是也——由此四种念诵力故，能灭一切罪障苦厄，成就一切功德。四种数珠者，如来部用菩提子、金刚部用金刚子、宝部用宝珠、莲花部用莲子、羯磨部用杂宝间错为之。行者若能随顺瑜伽修行三摩地念诵者，则无有时分限数，于一切时无间作之。合口动舌默诵是也

「次明供养饮食法，应以香洁种种饮食供养。若不能办，随力作已，复当心念：『世间所有一一上妙饮食、种种珍果、蒲桃、石榴、诸非时浆而作供养。』若己身不获，修供养者即令明解此法弟子如上作之。

「又以涂香、烧香、种种妙花、灯鬘、末利等而作供养。复以幢幡、缯盖、上妙天衣、及余殊胜诸供养具，各以本密语加之、或加本部尊密语已，随其力能而供养之。末利者，以诸食饮、果子等和水置瓶盆中，是以施鬼神也五部佛语是也

「唵萨婆怛他揭多悉地跋折啰三摩耶底瑟咤翳沙怛婆含驮啰野冥跋折啰萨埵系系系系吽愿住今也亡可反尤甘反，于我我今持也形以反

「论曰：一切如来金刚萨埵成就三摩耶愿住我所，我常守护。

「如是作法已，所有一切漫茶啰秘密三摩耶智，师应教授。若弟子于三摩耶契有退失者，师应遮制，莫令毁坏。弟子于师应恭敬尊重，莫见师短；于同学所莫相嫌恨。应告之言：『汝于一切众生常生慈愍，哀矜示诲，莫生厌离。』为说偈言：

「欲令弟子坚持欢喜故，为说偈言：

「弟子受师教已，顶礼师足，白言：『如师教诲，我誓修行。』

「复应为诸已灌顶弟子——令其圆满寂静法故、为除其灾障故——应与作护摩法。于灌顶坛火天方不应绝，远作四肘，坛高一磔手。中凿君茶，径圆一肘，深十二指，好净泥拭。两重作椽，内椽高、阔各一指，外椽高、阔各有四指，底须平正。即于其底泥作轮像，式跋折啰像，柄向南出，如世丁字。柄长四指，阔亦四指，横头长八指，高、阔各四指。

「次外作土台，形如莲叶。次外敷师坐位，君茶周围布吉祥草，为圣众坐位，洒净香水、敷草洒水皆顺转作。

「应以酥、酪、乳蜜、乳糜、饼、果、五谷者，谓稻、谷、菉豆、油麻、小麦等是。取吉祥树为柴，如无此树，取有白汁树代之，谓谷桑等是。齐整短截，别取小枝如拇指大，长十二指，一百八枚。

「酥谷及柴并置台右——若不能凿作君茶，即以赤色画其形状——中安火炉，余如上若。

「师北面坐，引诸弟子左次列跪，取先净火、或新钻者，以香水二具置其台上——一供养佛菩萨、一供火天——洒水作净，置君茶内已，诵此密语：

「南莫三漫多跋折啰南怛旃茶摩诃路洒那萨发啰耶唅摩含𪢐𤙖引二合

「诵此密语三遍，净水洒火，并洒茅草、诸供具等。

「次即然火，勿以口吹，当以物扇。取白檀香泥遍涂君茶，以白香花散台四面。于火焰中想有啰字变为火天，白色发黄，三目四臂——右边二手：一执君持、一手执杖；左边二手：一作无畏相、一捻数珠——想火天身遍生火焰。上直前舒掌，竖掌向外

「次执香炉请佛菩萨，所请法式如大坛中说，谛想诸佛菩萨皆来赴会，坐吉祥草。

「其师观羽作无畏相，止羽握腕，如臂钏像。即召火天，诵此密语：

「唵婀揭娜多曳儞卑儞跛耶儞婆湿尾穰系哩使萨哆三摩𨰿哩呬怛婆婀虎低摩贺婀萨民散儞系覩婆婆唵阿揭娜曳贺卑劫弊婆呵那耶儞卑儞跛耶萨婆诃平必迦反无可反而佉反上上无可反卑迦反毘迦反必也反㘕

「诵此密语时，想有火天来依如上所想身中，即以香水弹手洒火。

「次执祭杓，酌上酥油、乳蜜等物各三杓，以沃火中以祭火天，或和杂一处共酌三杓亦得。祭时，每杓诵此密语一遍。密语曰：

「纳莫三漫多勃陀南唵婀伽娜曳萨婆呵平

「师以止羽执金刚杵，以檀度钩弟子观羽智度，别以小杓如前沃火，人各各二十一杓，一一心念诸佛、菩萨及火天，于五部中心密语随喜诵之，一杓一遍，以用供养。若须除灾者，诵此密语：

「纳莫三漫多勃驮南婀摩诃扇地伽多摩诃扇陀迦罗钵唎舍忙达摩涅哩若多萨破婆窣覩婆达摩三漫多钵啰多萨婆诃平人者反

「一一弟子准此作之，若阿阇梨法加诵之至一百八遍。又以酥、油、乳、蜜等相拌和已，小杓酌之，数至一百八遍，沃火供养，每杓诵上大乘三摩耶百字密语一遍。

「若意欲别须供养诸菩萨等，即各随诵本心密语——或三七、七七，随意沃之——以上一百八枚小柴，一一两头刺酥蜜中，时时投火。

「所作法已，次应供养给施如上所说座后外八方诸天、神、眷属等，准前诵密语法酌沃火中。

「如是作已，师出洗手，还归本座，如前酌三杓供养火天讫，告弟子言：『汝已具足得灌顶法，假使以诸世间种种供养，不如己身奉施诸佛菩萨，汝应各发如是心。』令诸弟子各自发愿已，师应手执香炉遍供养佛、菩萨及火天已，即诵密语，请归本处。即从座起，就大坛位，告弟子言：『诸佛为利益一切众生故，说此殊胜福田妙法。汝应随力各办香花供养大众，能令汝得无量果报。』

「复为供养一切如来及金刚部众，应以羯磨契及三摩耶契如上供养。

「复以金刚赞叹密语作四种密供养法已，诵此伽他曰：

「复以金刚舞合掌及金刚戏笑等作密供养法。

「次应手执香花供养外坛圣众已，告诸弟子言：『汝等各随力能供养诸佛。』彼等修供养毕，为欲护诸弟子身故，应于诸佛菩萨所请所献花、香、果、饼等少分各各分赐诸弟子。复令重作要誓，如上所说，不得辄说此法。作教诫已，令弟子各还本位。

「师即随力如常念诵礼赞已，即请坛中佛菩萨及眷属等归本土。即竖结萨埵金刚契，诵此密语：

「唵讫哩覩婆萨婆萨埵遏他悉提捺多曳他努伽达凡勃陀蜜洒盐布那啰虐么娜耶微唵跋折啰萨埵牟已作胜上也一切众生也利益成就授与也入随愿三合，归还佛国土鱼伽反上无桂反，复垂降赴也𭫠

「论曰：已作胜上利益成就授与一切众生竟，愿一切诸佛菩萨归还本国。若重请召，惟愿降赴。

「此契及密语，一切坛中请佛、菩萨、诸部眷属还本处者皆悉用。」
