# 一切如来白伞盖大佛顶陀罗尼 · 第一卷

> 唐 不空译

---

启讽放光大佛顶如来万行首楞严 /
开无相门圆寂宗字字观照金刚定 /
瑜伽妙旨传心印摩诃衍行揔持门 /

十方世界诸如来护念皈命受持者 /

纵使骂詈不为过诸天常闻梵语声 /
神通变化不思议陁罗尼门最第一 /
大圣放光佛顶力掩扬善证菩提 / 𢙣
唯闻念者瞻卜香不一切余香气 / 𭊴
僧破二百五十戒比丘尼犯八波罗 /
闻念佛顶陁罗尼便得具足声闻戒 /

听者念者得加持同获涅盘寂灭乐 /
