## 004

时娑伽罗龙王与九十一子及诸龙围绕往诣佛所，头面礼足，瞻仰尊颜，一心合掌以偈赞曰：

说是偈已复白佛言：「世尊！我今亦欲助佛说呪，摧伏鬼神除诸灾患。」即说呪曰：

「那地那地那地婆隷波罗罗地质多罗赐鼻多罗赐毘那栖隷栴陀隷阇驶摩登祇瞿利干陀利婆尸利摩诃婆尸利婆尸罗陀陀罗婆尸陀那狸隷阿帝阿吃帝咤咤咤咤妬妬妬妬智智智智毘知智叱掘弥弥掘弥弥智弥智羽黎羽黎毘羽黎那罗那雉那陀陀隷陀陀隷」

说是呪已，大地诸山、三千世界六种震动，一切诸天皆悉欢喜。「三佛陀显现此经，城邑聚落官府诸处，此经所在百由旬内不得中住。如此猛呪，过去诸佛之所显现，使为帝主作大拥护，无诸灾害，作一切吉祥，一切众患悉皆消除。」

尔时地神往至佛所，顶礼佛足，说偈赞曰：

「是深妙说，为天、阿修罗之所供养。我今亦当助佛，说是明呪，勇猛必行。」即说呪曰：

「度弥度弥度度弥度弥护弥护弥呼呼呼呼弥呵罗娑隷呵达茶呵呵逻娑陀那娑逻支陀陀隷质埵婆罗泥婆涕婆他婆帝婆泥婆婆婆泥呵罗婆帝遮钵罗赐钵罗卑赐奴罗娄赐毘陀婆帝陀婆尼迦娄卑尼摩陀泥摩诃摩陀尼斯斯细奇细」㝹

说是呪已，大地诸山并及大海悉皆震动，夜叉鬼神众号呼失声，唱言：「呜呼呜呼！怪哉怪哉！」罗刹亦尔。「此经所在国邑聚落官府诸处百由旬内，我等不得住在其中，结呪界周匝千由旬内。」

尔时佛放眉间光明，光名感悟，大光遍照三千大千世界，一切众生覩斯光者，尽皆感悟如来所说。诸园苑神、诸井泉潢池神、根神果神、地神龙神、阿修罗神，放逸天、持华鬘天、曲脚天，乘空夜叉、干闼婆、罗刹、鬼神、究槃茶、毘舍阇、富单那、饿鬼、紧那罗、陆生龙、旷野神、揵陀神、颠鬼狂鬼癎鬼、日月星辰、护世四天王、三十三天、焰摩天、兜率天、化乐天、他化自在天、魔天魔眷属天、梵辅天、大梵天、少光天、无量光天、光音天、少净天、遍净天、无量净天、不广身天、不热天、善现天、色究竟天、摩醯首罗天，此等诸天遇斯光已，皆自见身尽被五缚。以佛神力，令诸天众一切同时飞来向佛，礼世尊足在一面坐。如来尔时即变大地化成金刚，一切世间无能坏者，复化十方悉皆火起。

尔时世尊即以佛眼观此三千大千世界谁有不来集在会者，谛观察已，见此世界无有一人而不来者，即说呪曰：

「阇隷摩隷阇罗摩隷摩隷泥伊隷隷呵摩那那罗那那隷婆隷敷罗鞞隷鞞鞞隷鞞黎渒那俾泥俾那娑伽隷娑伽隷卑泥颇栖颇罗颇栖颇求迷颇罗颇罗颇求迷求渒隷颇隷鞞颇罗地贺罗罗地苏罗帝毘苏罗地优浮地涅浮地浮黎浮地娑罗泥隷泥黎罗弥隷摩诃罗隷摩诃那隷喝罗阇泥隷泥泥罗隷牟隷目帝阿罗罗惫毘罗惫罗罗惫罗阇罗惫罗阇颇隷」𭌲𭌲𭌲𭌲𭌲𭌲𭌲

说此呪已，天、龙、阿修罗、夜叉、罗刹皆大惊怖，生于厌患，身毛皆竖，不乐听是结大呪界，欲陷形去，地如金刚不得陷入，周匝火然犹如地狱。此诸天众皆住空中一心听呪，即说呪曰：

「郁去目去那去那去去那去那佉去驱弥隷驱弥细驱驱弥细驱步驱步路步佉步佉步佉那佉步佉雷驱罗细丘摩摩泥驱驱摩泥跂跂摩隷歧歧隷佉罗佉跂隷佉那佉泥隷佉婆婆佉梨泥毘佉地佉陀婆惫婆婆嗘婆那佉腻嗘泥隷嗘栖隷嗘嗘栖隷脾嗘嗘栖隷」

说是呪已，而此大地动、遍动、等遍动，摇、遍摇、等遍摇，六返震动。诸鬼神等见是事已，皆失声大唤，唱言：「呜呼怪哉。」自相谓言：「是等天王共说此呪，我等今者无有生路，断绝一切诸鬼神等。」

尔时摩醯首罗白佛言：「世尊！如来所说结呪界经，若自能持、若教人持，若有读者，一切皆应离于婬欲修于梵行，不食五物：一黑石蜜、二油、三蜜、四鱼、五肉，终身不食。若诵是呪，诸夜叉、罗刹，恒伺其便为作恼害。或时轻蔑为遮鬼故，于五种味断而不食。若有外道邪见之人，不信此呪诈伪诵读者，必损其寿。如来为欲护四众故，说是呪经。我今亦欲助佛说呪。」即说呪曰：

「卢头娑细卢头娑帝卢呵隷罗婆婆罗泥卢遮隷卢陀遮隷呜呵罗地卢细卢栖泥卢卢栖泥卢陀罗呵泥卢陀罗呵隷卢卢呵泥卢卢呵隷卢多郅住卢注路注路牟那注路牟贺呵郅牟陀遮隷遮遮隷余利余利遮遮隷毘遮帝」

说是呪已，空中诸天其心调伏，还下在地寂然听法。尔时世尊为诸天众说诸法要示教利喜。闻是经时，无量那由他众生，远尘离垢得法眼净。诸有夜叉、罗刹、究槃茶、毘舍阇，于佛法中不生信者，为惊动故，如来尔时即出右臂示大地狱，见地狱中烧炙煮烂而命不绝，诸此罪人恶业未尽命则不断。佛告大众：「如斯地狱楚毒无量，是以汝等不应作恶。」诸鬼神等见大地狱，心生惊怖身毛皆竖，五体投地而白佛言：「世尊！我等从今已往当受五戒。」复白佛言：「佛涅槃后正法灭时，若持如此结呪界经，夜叉罗刹来轻蔑者，当使其心劈裂七分，有大沸血从面门出，命终当堕无间地狱不可救济。」佛告阿难：「汝当受持诵读是结呪界经，恭敬礼拜。汝等天人当知过去诸佛亦说是呪，未来诸佛亦说是呪，现在十方诸佛亦说是呪界经，我今复说是大结界神呪之经。」即说呪曰：

「奚奚迷奚奚迷弥梨迷弥梨迷摩诃弥梨迷呵罗隷呵罗隷呵罗隷槃遮炎隷波遮罗遮啰啰奚罗遮遮罗遮罗摩遮咤罗摩咤罗那摩诃因陀罗牟罗那牟罗那逻遮陀娑逻娑逻那阇大啰驮阿迦细那迦细那细那罗那细毘娑那细奚速隷毘陀隷」𪏭

说是呪已，十方火焰悉皆变灭，一切大地还伏如故。诸天大众皆悉右绕礼佛而退。佛说经已，诸比丘、比丘尼，及大菩萨、阿难等，欢喜顶受。

佛告阿难：「若有读诵此经者，当常食乳，净自洗浴着鲜洁衣，于一切人不生嫌心，于诸众生当生慈心。于佛像前作诸天龙王像，及余鬼神皆图形像，以牛粪涂地作七重界。界场中央着诸华鬘，烧百一种香。为佛烧苏合香，萨阇赖阇香与摩醯首罗天，咄迦香与梵天，遮迦香与魔王，多迦罗香与化乐天，阿具娄香与他化自在天，婆罗娑香与兜率陀天，修富娄香与焰摩天，牛王香与帝释，胶香与四天王，零陵香与伽罗龙王，熏陆香与毘摩质多阿修罗王，那赖娑香与毘浮沙罗刹王，多利娑香与地神，甲香与地夜叉神，毘罗贰香与放逸天，那赖陀香与十方鬼神。

「如是等烧百一种香，各各于彼天像前烧。诵此呪者右膝着地，一百八遍烧香于天前。各涂地作七处呪场，在此场上发大誓愿，舍自己身与三世佛。有夜叉罗刹不信于佛，欲害呪者、灭结界经，为遮恶故应当舍身与佛，愿诸如来忆念于我。当令呪者身如金刚，一切世间无能坏者。五体投地顶礼佛已，应诵是呪，应向四方散胡麻子，当诵此呪一百八遍。当诵呪时，净居善现天当现身在其人前，身真金色，彼天安慰诵呪之人。彼诵呪人应当惊悚。彼诸天等各入已形像之中，慰喻呪人而告之言：『善哉善哉！汝之所诵结呪界经，今得吉成。我等为汝随汝所作，汝于我前不应惊怖。』以金色身立呪者前，安慰之言：『善哉善哉！能诵此呪。我等今者为汝仆使，为汝所役。』此是结界劝成就相。诵此呪时，应以月十五日及月满时，夜诵令利，随意所乐，若园苑若宫殿、若大池若河边、若有饮食若乘骑、衣服华鬘诸香等物，皆毘首羯摩天之所化作在诵呪人前。若求雨时，烧藿香供养娑伽罗龙王，呪四枚石，有龙住处呪石掷中，天即降雨。若族姓子族姓女，随其所须雨之时节，久近能称其意。若有欲得如意宝珠，应于佛前向娑伽罗龙王像，应诣生藕华池河所，烧香供养龙王，七遍诵是结呪界经。应于池所呪场之中佛形像前，作五种音乐而为庄严。

「尔时娑伽罗王即于佛前与如意珠。得此珠已能雨珍宝。尔时四方应有火起，尔时应以苏和娑利沙子置于火中，应诵魔王呪。若欲鬪战求胜敌者，应七遍烧香，以七色𫄧结为七结，七遍诵呪，当应以此结系幢头。设有刀箭欲来向身，自然堕落终不伤害。欲结界者，诸天王所烧香供养，在香烟上七遍诵呪，复烧香以十色𫄧结作七结，以娑利沙掷置火中，诸夜叉罗刹咸自见身自然火然。界内有树，以此呪线系于树上。若复欲使日月住者，此呪神力亦能住之，终不能得越此呪界。若欲得象乘马乘骆驼乘，应于冢间作诸呪具，应以胶香供养毘沙门，诵此呪经，尔时便得种种随意所乘。若欲使夜叉、罗刹，于月二十九日，在冢间著白净衣，以香烟供养四大天王。若欲动地，应著白净衣，不嫌恨意，于一切众生心生平等，应上车轮上，以多利婆香供养地神，诵此呪经，大地震动。若欲使火不横起，把箭诵呪。诵呪已竟，即以此箭向四方所射，火即不起。若为毒箭所中，应诵此呪呪水，以所呪水饮之洗浴，毒即消除。若欲隐形，应以香供养摩醯首罗天王，以七色线系作七结，七遍诵呪，以结系头置之顶上，即得隐形。若欲飞行，应百遍诵此结呪界经，呪娑罗几子以置顶上，烧香供养念佛地功德『若此神呪实是恒沙诸佛之所说者，愿我飞行。』即能飞行，诸佛忆念护持力故。若欲使诸王大臣、沙门婆罗门欢喜忆念得自在者，应烧香供养四大天王，当呪于油，以此油涂四王像口，一切见者皆生欢喜而得自在。若欲见一切鬼神夜叉提婆利沙，油涂已眼，烧香供养四大天王，日日诵念此结界经，以四色线结作四结，系着顶上，得如意见。若往到处处天所，与诸天等相娱乐者，应自洗浴，以香涂身，著白净衣，上车轮上，于诸众生无嫌恨意，烧一切香读诵此经，欲界天王自来现身在其人前，即将其人诣诸天前，以天庄严之具而庄严之，以天音乐而娱乐之。若为一切鬼神所着所捉者、噏人精气者，应以十色线七过，烧种种香七遍，诵经系线作七结，摩醯首罗天王梵众之主、释提桓因、四大天王还益其精气，除造逆罪及谤正法、谤毁贤圣者。若彼恶鬼毁诵呪者，当堕无间泥犁，受苦一劫不可救济。若欲入火火不烧者，应七遍烧香烧一切香，七遍诵此呪经，以五色线系作百结，以此呪缕系着咽下，入大火中火不能烧。欲得断除厌道魅蛊及毘陀罗呪，应以香供养魔王，诵此呪经，以酥娑利沙烧掷火中，诵魔王呪，一切厌蛊蛊道毘陀罗呪消灭如灰，令彼诸恶无有力势，呪咀之患自然不行。欲止恶风暴雨者，当驱乌令去，烧乌巢窟，以香供养毘浮沙罗刹王，诵此呪经止恶风雨。一切鬼神、夜叉、罗刹、究槃茶、金翅鸟、毘舍阇，若欲禁制，遮一切恶、立一切善，当诵读是大结呪界经，以赤线系作百结，以香供养诸天，诸天等当集在一处为其说法。」

佛言：「我涅槃后，诸天集会诵此呪，能使鬼神皆受五戒。若诵持此经者，于诸众生应慈心平等不害一切，恒修实语终不虚诳。见此结呪界经，一切诸天世间皆应恭敬礼拜，不生疑惑归依供养。」佛告阿难：「汝于此经呪界不应生疑，此经如实终无虚妄。若怀疑者，当堕无间地狱，受苦一劫不可救济。所以者何？此结呪界经，是一切诸佛之所宣说。阿难！若有受持读诵此经者，以曾供养诸佛殖诸善根，诸佛护故，此经自然来在手中，此人即是受经真器。持此经者，天人世间皆应礼拜供养恭敬，此持经者即是天人世间塔寺。阿难！若为菩提族姓男女，于此经中能读一四句偈，受持读诵若教他说，如弹指顷心生随喜，当知此人必定当得菩提之道。若求辟支佛、若求声闻乘能信解者，于现在世得止诸漏。若在家，于三乘未有决定，得此经者得于决定。若有能持是经典者，当知供养过去诸佛深种善根，无量世中当作转轮圣王。若求帝释，无量世中当得帝释；若求梵王，无量世中当得梵王。我以决定记上四种人。若有读诵经人所，于弹指顷生恶念者，此愚痴人名为远离一切诸佛，于三乘中即无种子，此人当堕地狱。阿难！若有善男子善女人，信解是呪界经，使他读诵作此经器者，此人即成就梵福。若不信此经者，诸天即隐此经。何以故？此人必生不信疑惑之心，当生恶道堕地狱中。首陀会天当夺此经，礼拜香华供养。若能供养此经，即为供养恒沙诸佛。阿难！汝以是故，应当受持此经，为于安乐利益拥护四众。」阿难及诸弟子闻佛所说，欢喜奉行。

「大圣世雄天人尊，常以慈心愍一切。 /
善哉一切智导师，世间黑暗作照明， /
一切诸天所不达，唯有瞿昙独知之。 /
今我归命大慈悲，唯愿为我作拥护。」 /

「归命佛世雄，正觉两足尊， /
瞿昙所知见，诸天所不达。」 /

「我今归依赞大智，能证最胜甘露法， /
灭结最上大正觉，如是瞿昙我今礼。 /
善说此经三佛陀，功德具足护一切， /
广济众苦与安乐，一切鬼神皆摧伏。 /
我于世间为宗主，我最能灭诸鬼神， /
我于众生为其父，于千世界得自在。 /
我今助佛欲说呪，诸天世间共印封， /
我今印封无能越，正觉垂矜忆念我。」 /

「我今归命大道首，两足之尊最胜觉， /
诸寂灭中为第一，是故我今稽首礼。」 /

「归命上丈夫，具足大智尊， /
解脱诸烦恼，怜愍众生故， /
说甘露呪界，摧伏诸鬼神， /
拥护有命者。我亦欲助佛， /
宣说大猛呪，唯愿三佛陀， /
哀愍忆念我。」

「我今归命赞，坚实大精进， /
最胜不思议，是故今敬礼。」 /

「归命赞叹世所供，归命无上世大师， /
归命断结世勇猛，能拔一切诸毒箭， /
最胜寂灭解脱尊，能解一切诸缠缚。」 /

「归命于大智，坚实功德聚， /
牟尼天人尊，无上法中王， /
瞿昙世大师，故我今敬礼。」 /

「我今归命圣实尊，法王智光照世间， /
能以正法导一切，大慈大悲救三界， /
济度一切诸众生，大圣瞿昙我今礼。」 /

「归命大圣智光明，离诸三有正导师， /
分别诸有及涅槃，是故归命真实尊。 /
我今亦欲助佛说，愿当怜愍忆念我。」 /

「寂灭无为最上尊，调伏诸根悉清净， /
自得解脱亦脱彼，解脱一切生死轮。 /
己自得度亦度他，能度生老及病死， /
最上调伏诸外道，今礼二足天人尊。」 /

「救济一切世间苦，能与无量众生乐， /
今礼如是灭结尊，能归佛者得无畏， /
归命世雄能度世，我今敬礼人中尊。 /
鬼神之众究槃茶，一切世人及非人， /
诸能恼害如是众，今为禁制愿佛念， /
诸非人等皆应听，今我为世作拥护。」 /

「归命于佛善说者，如来善导诸众生， /
能与一切众眼目，灭结大师我今礼。 /
善说此经度众苦，无上法王众中尊， /
能护一切诸世间，能遮一切诸恶鬼。 /
我今亦欲助说呪，唯愿世尊忆念我。」 /

「世尊大慈拔毒箭，如是最胜我今礼。 /
能导世间诸众生，法王妙法如甘露， /
善说此经护一切，今我归命赞世雄。 /
我亦助佛欲说呪，唯愿世尊忆念我。」 /

「稽首大精进，世间之真济， /
能放智光明，照于世间暗， /
阿修罗不了，如来悉通达。 /
亦欲助佛说，唯愿忆念我， /
为护诸众生，力能禁制鬼。」 /

「归命世所赞，最上无与等， /
三界大导师，能示正道者。 /
成就大威德，永灭烦恼结， /
人中之胜龙，一切众生父。 /
于无量劫中，具真实功德， /
力能摧众魔，魔军悉退散。 /
所证无上道，难可得思议， /
能转妙法轮，显现四真谛。 /
演斯真要法，解脱众苦缚， /
说大结界经，利益诸天人。 /
诸恶鬼神等，闻佛说呪经， /
悉皆远逃避，至百由旬外。」 /

「我今归命大悲愍，能尽一切诸苦际， /
能救众生令解脱，能与一切诸安乐。 /
谁得闻此善妙说，而当不生欢喜心？」 /
