## 佛道天贵星

此星主人清高，有德有行，大事成小，灾祸无侵。若更得天权、禄、驿星助者，荣昌富贵。若犯重者，主悲泣翻悔，中下小人半吉之命。若逢孤、厄、破、刃照命者，必为朝堂折挫之人，见贵而未为全吉也。

时在厄中人混沌，惺惺作事又痴呆； /
此人带疾方延寿，还须劳碌作生涯。 /

---

## 鬼道天厄星

此星在命，主人带疾，若逢破、刃相冲，灾疾必重；若逢权、贵星，主人轻疾，乃中上命也；若逢孤、驿、奸星，主作事迟疑，一生啾唧，定主蹭蹬离祖，乃中下命也。

时辰落在天权宫，性格操持志气雄； /
作事差迟人也喜，一呼百喏有威风。 /

---

## 人道天权星

此星在命，主人聪明俊秀，洒落襟怀，有权有势，多智多能，若逢贵、福、文、寿星相助者，人人拱听；重犯者，权而无权，乃中命也。若逢厄、破、孤、驿在命者，作事劳力，财帛不聚，未能先能、未会先会，浮浪中命也。

时辰落在天破宫，推金积玉也成空； /
夜眠筭计图家富，钞袋谁知有蛀虫。 /

---

## 畜道天破星

此星主财帛空虚，祖业耗散。若得权、贵、福星相助，亦为中命。如遇驿、刃、孤、厄犯重者，作事艰难，重重破败，浮浪东西之下命也。

大如沧海细如毛，佛口蟠心两面刀； /
奸狡机谋藏毒性，意多翻覆最难调。 /

---

## 修罗道天奸星

此星照命，主人一生劳碌，啾唧奔波，指东说西，机变难测。若得天贵、福星相助，财帛丰盈，亦为上命。若逢权、刃星者，必为奸权残忍之小人，言清行浊，执性凶谋，有害人之心，无容人之量，贪瞋太重，非善人也。若逢孤、厄、破、驿，定为悭贪嫉妒之小人，乃下命也。

命遇天文秀气清，聪明智慧意惺惺； /
男才女秀身清吉，满腹文章锦绣成。 /

---

## 仙道天文星

此星照命，主人聪明怜俐，学识过人，作事和美。若逢天贵、天福、天艺星相助，定为鳌头独占，虎榜登名，金堦玉阶之人也。若遇天权、天刃星者，文武多才，乃为上命。如遇破、厄、孤、驿及犯重者，乃多学少成，不为书筭文墨之辈，必为云游湖海之人，乃手艺术士之下命也。

命逢天福是生时，定然仓库有余盈； /
宽洪大量根基稳，财帛光华有福齐。 /

---

## 佛道天福星

此星坐命，主人受福清闲，性情自在，度量宽洪，根基稳实。又得权、刃相扶，衣帛充足，仓库盈余，堆金积玉之命。若犯重者，衣禄不多。若逢驿、孤、奸、破星者，必主悭贪嫉妒，衣禄艰难之命也。

人道若逢天驿星，搬移离祖不曾停； /
身心不得片时静，走遍天涯足未宁。 /

---

## 鬼道天驿星

此星照命，主人离乡别井，骨肉情疎，劳碌身心，自成自立之命。若逢福、权、贵、刃、寿、文星者，必主官禄供给，车马相随，乃荣显之命。若逢孤、破、厄星，犹如风吹树叶，水上浮萍，心猿意马，奔驰不定，方外云游，江湖涉之下命也。若犯重而刃、厄相刑者，必为徒流之类。䟦

时辰若逢此天孤，六亲兄弟有如无； /
定作空门清净客，总有妻儿情分疎。 /

---

## 人道天孤星

此星照命，主一生孤独，男人得之，六亲无分，女人得之，尅子妨夫。孤星犯重者，反不为孤，必为半僧半俗，身在俗门，心在空门之人。若得权、福、贵、寿星助，乃上命也，亦不免少年刑尅。若逢破、驿、奸、厄、刃星，必为云水漂流，下命也。凡选故家之命，要看孤星为主。

天刃为人性太刚，是非终日要争强； /
持刀弄斧刑心重，好似将军入战场。 /

---

## 畜道天刃星

此星照命，主一生刚狠，性格躁具，自做自是，不受人触，受不得闲气，风火性过，端然无事。若得权、贵、福星，为人不俗，礼义足以化强暴，乃上命也。若逢孤、破、奸、厄，胆大心粗，形体残疾，不免断发身死，乃下命也。恶星少而吉星多者，亦为中命。犯重者，必主残疾。

天艺生人性最灵，将南作北逞多能； /
所为方便机关巧，到处和同作事勤。 /

---

## 修罗道天艺星

此星照命，主人多智多能，机巧近贵。若犯重者，主资质昏钝，懒惰愚顽，多学少成，匠作用力之辈。若得天权、贵、福、文、寿俱全，刚柔相济，虽为艺术，亦可成立。若逢天孤，可为僧道之出类者，乃中命也。若逢破、厄，则艺业无成，终为下命。

天寿生人命最长，上恭下敬性温良； /
一闻千悟心慈善，喜怒中间有主张。 /

---

## 仙道天寿星

此星照命，主人长寿康徤，智慧聪明，作事温良，有救人之心，无伤人之意，恩中招怨，作事朴实，众人钦敬，平生安稳，有始有终，喜怒不形，若得天权、福、贵、刃星相助，必主宽洪大量，福寿绵绵，犯重者有寿无福，犯孤、破、厄星，乃中命也。

---

## 十二星总论

详夫观命之法，当以命宫限数为先，男怕孤、驿凶星，有天福、天贵者不妨；女怕破、刃、厄星，有天权星者，助夫旺子。有天文、天艺星者，性巧。有天福、天贵、天寿星者，命稳实。有天奸星而犯重者，定主贫贱淫污，玷辱宗祖。行运而逢两重者，命限大晦，月分而逢孤、破、厄星者，此月亦主凶灾。男命而重天贵者，贵而不贵；两重天权者，权而无权；天文重者，男女泛滥。女命天贵重者，终许见贵，若见四重贵者，尅子而衣禄丰盈；天福重者，衣禄自然；厄在时日重者，反不为厄；逢三厄者，不唯无厄，而衣禄有余。命限天权星者，虚贵而刑妻尅子。四厄星者，主二子衣禄有余。命有二权星者，壮重正大；命有三权星者，必主威权。有二天破星者，衣禄反稳；有三破星者，破败下命；有四破星者，无衣禄而寿不长。奸星见重者，反不奸而正大；有三奸星者，狡狯下流之人；有四奸星者，亦主徙流刑败。文星重者，主富贵；文星三者，衣禄少而多文学；四文星者，尅妻而损目。二福者，尅妻而见贵；三福星者，有寿而无福；四福星者，衣禄充。二驿星者，反生安闲；三驿星者，主下贱；四驿星者，得奴仆力。二孤星者，有子孙；三孤星者，女尅夫，男尅子；四孤星者，妻贫穷。二刃星者，多慈善；三刃星者，乃贵人有权之命；四刃星者，权贵而寿夭。二艺星者，刑妻而尅子；三艺星者，曚瞳而昏愚；四艺星者，踊蹬而无成。二寿星者，性愚鲁；三寿星者，出家而高寿；四寿星者，离祖而穷苦。贵、驿二重多劳碌，破若逢文必夭亡，权若见孤多刑尅。二孤尅寿者，年虽高而破败招非；少年重奸者，悭贪而福亦不永。艺若逢奸，刑伤破败；刃若见厄，疾病贫穷。生时逢二厄，早岁凶亡；四柱有三孤，中年破败。刃厄同宫，损自己而伤手足。贵、寿、权生年月，必丰祖业而显门闾；破、刃、孤、厄会于一时，难为夫妻子息。十二星之理，于斯备矣，论一生之命，孰有疑焉，智者详审而细推之，自可究祸福于前知也。󱚉

## 论十二月生

正月生人，利官近贵，大事成小，仔细小心之命，能招四方财源，妻儿和合，竝无尅破。

端然相貌是前缘，平生快乐福绵绵； /
贵人接引增吉庆，和合团圆过百年。 /

---

## 正月生人诗

二月生人，心性温和，心无毒害，聪明多智，六亲少缘，中限发财大富贵，半真半假之命。

平生性善自家知，一生衣禄自丰肥； /
钱糓家宝多富贵，高人欢喜小人欺。 /

---

## 二月生人诗

三月生人，心性宽弘，凡事忍耐。初限平平，中限发福，末限荣华富贵之命。

为人心直自宽怀，平生招得四方财； /
中限荣华时发福，犹如枯木遇春来。 /

---

## 三月生人诗

四月生人，心性不定，名动四方，爱结朋友，不住祖业，自立家风。初限、中限平平，末限大发富贵。

一年命限胜一年，不须瞋恨苦忧煎； /
更得持斋方便福，夫妻和合永团圆。 /

---

## 四月生人诗

五月生人，温和良善，心性伶俐，有权势威风，行事正直，贵人接引，夫妻中途离别之命。

出入常常遇横财，贵人接引笑颜开； /
田园事业多兴旺，富贵荣华次第来。 /

---

## 五月生人诗

六月生人，性巧伶俐，为人远达，身有艺术，不守祖业。初有财，中限吉利，末限富贵，机谋太重，乃好命也。

平生衣禄自然昌，为人显达好文章； /
优游快乐家豪富，夫妻谐老百年长。 /

---

## 六月生人诗

七月生人，为人慈善，作事仔细爱好。初限平平，中限少好，末限富贵荣华之命也。

一世为人不必忧，安然无事挂心头； /
家业田园宜自立，方知福禄命中求。 /

---

## 七月生人诗

八月生人，眼目光晖，聪明达理，正真无私，有艺有财，文章近贵之命也。若离祖，生大贵。

为人端正貌堂堂，心地聪明性善良； /
作事多能心达理，佗年运到福绵长。 /

---

## 八月生人诗

九月生人，性刚，招人是非，有威权近贵之命。姻缘相尅，子晚妻迟之命也。

买卖生人事事强，营谋动作志轩昂； /
若能修善多作福，管取衣资积满箱。 /

---

## 九月生人诗

十月生人，大海之心，不动不懒，先难后易，衣禄充身之命也。先女后男，出家亦难为师长徒弟，在家亦难为子息夫妻，命中多招刑尅。

十月生人庆吉星，灾殃永退不相侵； /
持斋善念行方便，衣禄盈余自称心。 /

---

## 十月生人诗

十一月生人，有权性急，伶俐近贵，心多计谋，身有陪疾。初限平平，中限发福，末限富贵之命也。

早年独立自成家，衣禄从心自可夸； /
骨肉弟兄无倚靠，相交朋友水中华。 /

---

## 十一月生人诗

十二月生人，百年劳心，心直口快，亦主暗疾，父母兄弟难靠衣禄，自能得四方之财，半吉之命也。

初限勤劳受苦心，自成自立不求人； /
心慈口快难藏毒，长幼团圆过几春。 /

---

## 子时

生人，性急，命带刚强，作事反复不定，招人是非，父母妻子有尅，自手成家之命也。十一、十八、三十六、四十六、五十八、八十九岁之寿。

---

## 丑时

生人，父母刑尅，一生敬贵，有势有力，末限大好，福禄有余之命也。十八、二十六、三十一、四十六有灾，其年可持斋作福，七十三岁之寿。

---

## 寅时

生人，父母、兄弟、妻子多尅，离祖方好。初限平平，末限发财。二十六、二十九、三十三、三十九、四十九、六十六岁，主得气血之疾，过此九十六岁之寿。

---

## 卯时

生人，父母、兄弟、妻子无力，初限、中限作事无成，末限安稳，一生难守祖业，出家入赘，先凶后吉。十八、二十六岁上有灾，过此可延九十岁寿。

## 辰时

## 酉时

生人，为人淳厚，难为父母兄弟。初限反复，末限大好，二十二、二十八、三十九、四十六小灾，过此七十七岁之寿。

## 戌时

生人，清俊秀美，一生快乐之命，但福禄亦主进退。初中二限平安吉利，末限父母相刑，妻子有损。十四、二十六、二十九、三十六有灾，过此七十五岁之寿。

## 亥时

生人，心直口快，自然福禄加增，一生辛勤劳碌。初限祖业难守，末限大吉之命也。二十六、三十六、四十九、五十六小灾，过此八十八岁之寿。

## 子

初生人，先尅母，自成家计，作事七进八退，十成九败，六亲疎淡，衣禄浮沉，末限享福，好收成结果之命。

子初果如何？作事进退多；师术僧道吉， /
一世受奔波。

生子先儿郎，子息不过双；娶妻换头妇， /
末后发田庄。

中生人，无尅破，一生作事估强，有起有倒，有成有败，末后虽大兴旺，须用离祖入赘为吉。

天禄虽兴旺，时值活离宫，前程防小失， /
作福保亨通。

末生人，先主尅父，六亲不得力，子息不顺，一生勤苦劳碌，作事有头无尾，财帛不聚，更改之命，晚景好。

子末将过丑，子孙三个有，好子须一个， /
老景三春柳。

## 丑

初生人，无尅破，主进田庄，衣禄俱全，富贵安间，子孙荣显，末限大好之命。

晚景收成好，二子换头妻，兄弟相形尅， /
荣华福禄齐。

中生人，为人老实，进益田庄，自小夫妻得力，父母六亲相和，末限大发富贵之命。

丑正先防父，头男防老伤，须要防妻损， /
爷娘亦恐伤。聪明伶俐有，福禄益衣粮， /
财帛田园广，荣华末运昌。 /

末生人，心地好善，先凶后吉，前主尅母，孤独自成，男女皆离祖之命也。

丑末先尅母，女命三妨父，先男后有女， /
晚景贵人助。

## 寅

初生人，主先尅父，依禄有余，为人聪明发达，自成自立，有盈有亏，心性不定，好胜好间，末限有福之命。

寅初进田庄，儿女喜成双，财禄中年旺， /
晚景自安康。

中生人，若无冲尅，父母双全，衣禄盈余，有福有寿，自成家业，先主荣华，末景安常之命。

寅中命吉昌，聪明性气刚，一生宜出祖， /
名姓四方扬。寅正少兄弟，三孙世代长， /
尅妻须保守，财旺益田庄。 /

末生人，先尅母，自家成立，六亲无倚，离祖出家之命，一生勤苦劳心，妻子有尅，带疾方可延寿。

寅末命平安，祖业末能看，一生多险厄， /
舟破上高滩。子媳招宜晚，头妻未有缘， /
弟兄无倚靠，假子送归天。 /

## 卯

初生人，先主尅母，四方衣禄有助，祖业既成又败，作事有头无尾，家计自成立之命。

生来初卯时，为人最孤恓，衣禄随时度， /
见喜又生悲。廿土自成立，堪怜尅正妻， /
兄弟不得力，子息定招迟。 /

中生人，命无尅破，一生主得横财，不求自至，武艺立身之命。

富贵架高梁，衣禄甚风光，一生家业旺， /
武艺近君王。子息成行列，妻富定见双， /
宫星身命主，兄弟列成斑。 /

末生人，先尅父。十九作事成败，衣禄进退。末限平平，亲子难招。祖业虽多，不得承受。独权自立，在外成家之命也。

初限甚劳碌，忧勤自立家，知音时运至， /
枯木又生花。命里多兄弟，田庄又属佗， /
子息虽难靠，贤妻甚可夸。 /

## 辰

初生人，先尅父，若是长子，必然难为兄弟，聪明晓事，慈心爱人，大事成小，衣禄平常，自成自立之命，子息晚招，离祖出赘方可。

衣禄四方来，兄弟六亲乖，平地生荆， / 𣗥
间非扰闷怀。双亲椿早折，妻子泪盈腮， /
一生多反复，疑是命中该。 /

中生人，先主尅母，衣禄平平，立心公道，刚直中限，富贵性急，如风吹火，易发易解，自成家业，妻王高门，赘媚外居之命。

日日走奔波，财源自有无，六亲不得力， /
口舌事常多。辰正妻官厄，儿孙未见知， /
外子承亲母，晚景甚巍峩。 /

末生人，命无尅破，心性公平，财禄稳足，多受快乐，如鱼化龙门，飞腾变化，显达家门之命。

鱼龙变化身，衣禄自然盈，一朝雷雨作， /
四海振声名。辰末头妻尅，阗房亲上亲， /
亲儿虽得力，外子更相亲。 /

## 巳

初生人，先主尅母，初年富贵，田宅进退，权柄自立之命。

此命出寻常，修行烧好香，子母多离别， /
家业始荣昌。巳初子孙早，鸿鴈不成行， /
田园进复退，财帛日中霜。 /

中生人，先生尅父，平生惟直，开口谭天说地，为人多管闲事，多成多败，六亲无力，志气超群之命。

立身身自稳，举意意冲天，胆气如天大， /
末限福绵绵。巳中子孙望，亦主进田园， /
尅妻二子立，后代子孙贤。 /

末生人，无尅破，衣禄丰足，兄弟俱全，性巧近贵，为人成家快乐之命，若出家大吉。

巳末喜文章，成家大吉昌，蟾宫相咫尺， /
立在贵人乡。巳末福无量，妻宫恐见伤， /
立身多快乐，晚景受安康。 /

## 午

初生人，无尅破，一生富贵，文武皆通，为人慷慨，出众超群，但六亲无力，出外成家之命。

生来正午初，一动百人扶，安车并坐马， /
变化贵人摸。六亲不得力，兄弟亦多疎， /
妻房多财富，富室拥千奴。 /

中生人，先尅父，衣禄辛苦，成败反复，先难后吉，末限发达之命。

生来不自由，衣食周未周，巴巴啾唧过， /
何处逞风流。

末生人，先尅母，六亲无力，祖业难居，衣禄辛苦，勤俭生涯，末限成家之命。

午末命平常，财子随分过，若要求进益， /
一生见奔波。

## 未

初生人，无尅破，兄弟完全，到处风流，先勤后怠，衣食足用，不求自至，初限辛苦，晚景添财。

未初无破败，二子命中招，兄弟相完聚， /
田宅后滔滔。

中生人，先尅父，衣禄自然，心中平等，人事周全，功名富贵，六亲难为，前凶后吉之命。

未中先尅父，又主损头妻，兄弟须相忍， /
外子后相依。

## 申

初生人，无尅破，性巧聪明，逢凶有救，大事成小，一生稳厚，损妻子，自成家业之命。

命里根基旺，家庭福有余，早发文武籍， /
锦绣换麻衣。

中生人，先尅父，六亲无力，招是惹非，小人不足，衣禄有余之命。

慈善度春秋。

末生人，先尅母，六亲不得力，婚配宜迟，妻招一姓，为人多疑，逢凶化吉之命。

奔花抛祖业，独立自孤持，外生随母老， /
末限定盈余。

## 酉

初生人，无尅破，衣禄充足，多招祖业，性巧聪明，男如龙虎，文武皆通，女精巧，晚景称意。

金运自光晖，事业锦衣归，运筹多智慧， /

中生人，先尅父，六亲不和，宜与二姓同居身间，心自性操持，发福之命。

衣禄颇随时，犹如报晓鸡，能啼催早起， /

末生人，先尅母，六亲不得力，性急不悔，衣禄无亏，辛荣反复，子息难为，终年孤独之命。

## 戌

初生人，先尅父，兄弟不得力，良善近贵之命，晚景发福，孝弟忠信。

良善行公道，财产天送来，自成自立命， /
常近贵人台。

中生人，先尅母，六亲无靠，食衣在于公门，逢凶化吉，心贪快乐，辛苦劳心，胆如麻子，口似风颠，末限发福之命。

处众得谦和，皇恩受禄多，威德人钦敬， /
主张谁敢过？

## 亥

初生人，先尅父，作事百般如意，一生近贵能为，福寿全有之命。

万般风流事，功名自有成，种种皆遂意， /
福寿满山青。

中生人，无尅破，父母前声应后声，平等有权，不犯灾厄，亲近贵人，晚景发达之命。

亥中无尅破，衣禄多饶益，有权兼有势， /
性气不能测。

末生人，先尅母，衣禄随时，六亲得力，贵人扶助，宜作福修斋，末后得贵子显达之命。

十二时中亥末迟，衣禄无多但随时， /
肯向善心修斋戒，定生贵子来相持。 /

## 诗

上半年夜半前作前半月，下半年夜半后作后半月。不问男女，地支四字，子寅午申戌为阳，丑亥酉未巳卯为阴。四字中阳多阴少主尅父，阴多阳少主尅母。得之于心，应之于手。年上起月，月上起日，日上起时，时上起刻，男顺女逆，逢凶则凶，逢贵则贵，运掌之间，照然莫能迯焉。

此法玄机通天地，大月从上数至下， /
小月从下数至上，先问得病月期数， /
便知病人患吉凶，玅诀推筭无人会。 /
先天毫定生死，初一日起子细论，𨤲 /
马立人生灾有救，马倒收拾入幽冥， /
马斜有灾即可治，禄正命重命不伤， /
禄马俱倒鬼到门，禄斜有灾请医冥。 /

子午卯酉四字高，为人聪明逞英豪， /
多有兄弟难倚靠，一双父母不相交。 /
时初时末无伴侣，时正孤单独自挑， /
财重禄荣身贵显，翼冲云汉福滔滔。 /
寅申巳亥四字强，为人聪慧近文章， /
时正兄弟三四个，时初时末也成双。 /
父母无刑多倚靠，荣华富贵坐高堂， /
若得父母双全在，晚景荣华大吉昌。 /
辰戌丑未四字孤，上妨父母六亲疎， /
虽有兄弟难倚靠，祖房常被别人祖。 /
时初管取先亡父，时末尅母在冥途， /
公门事业为生计，男为僧道女为尼。 /
