结契念本明，下当次第说。 /
阿閦如来契，二羽金刚缚， /
左右而掣开，二手旋舞仪， /
左拳安于脐，右羽垂触地。 /
下至诸尊位，先缚后旋舞， /
印契虽各别，旋舞例准此。 /

「毘卢遮那佛，右羽金刚拳， /
以握力指端。

「宝生如来印，左拳仰安脐， /
右羽为施愿。

「弥陀如来契，二羽仰相叉， /
进力竖相背，禅智横其端。 /

「不空如来印，左拳复安脐， /
右羽施无畏。

「金刚界菩萨，二羽如莲形， /
忍愿头相拄，相次渐微开。 /

「金刚焰菩萨，左羽侧安心， /
微曲于愿指，右羽逼左羽， /
微曲于忍指，亦侧不着左。 /

「金刚甘露契，左羽仰安腿， /
犹如掌物势，右羽曲忍禅， /
当心侧安置，向心不触体。 /

「金刚力菩萨，右羽曲忍指， /
侧安当于心，次以左羽来， /
微曲于愿指，亦侧不触右。 /

「观自在菩萨，二羽金刚婆， /
开手而仰散。

「金刚手菩萨，左拳安腰侧， /
右羽如施愿，禅押于忍度。 /

「虚空藏密契，左拳安腰侧， /
右羽在心侧，以禅押忍度。 /

「大悲菩萨印，左拳安腰侧， /
右羽屈戒度，右旋往心散。 /

「地藏菩萨契，二羽进力钩， /
掣开而散印。

「萨埵菩萨印，左拳安腰侧， /
右手于脐侧，屈禅掐忍进。 /

「妙吉祥菩萨，左拳安腰侧， /
右羽禅捻忍，两眼随手视。 /

「弥勒菩萨印，左拳安腰侧， /
右羽在心前，掐忍指中文。 /

「此处应念，十大明王，真言印契， /
广如别卷。」
「灯供养菩萨，左手捧右羽， /
忍指申供养。

「琵琶菩萨契，二羽作弹势。 /

「烧香菩萨契，二羽执香炉， /
如供养佛势。

「饮食供养契，二羽于面前， /
犹如捧物势。

「衣供养菩萨，二羽金刚拳， /
禅智捻进力，飜旋于右羽， /
想如着衣势。

「散华菩萨契，左羽如掌华， /
右羽禅捻忍，右羽向掌华， /
犹如取华势，想散佛顶上。 /

「贯华菩萨契，二羽于怀中， /
犹如取华势，想从佛顶上， /
顶后而旋系。

「涂香菩萨契，二羽向外旋， /
直竖而外散。

「此八大菩萨，在于第三院， /
次第居四门，右左而安坐。 /
次镜菩萨契，左羽安腰侧， /
右羽执于镜，光外照于佛。 /

「歌供养菩萨，左拳安腰侧， /
右羽忍进指，直竖而相拍。」 /

「甘露菩萨印，想左羽掌内， /
而掌甘露水，右羽戒指弹， /
想洒佛坛上。

「舞供养菩萨，二羽作舞势。 /

「此四大菩萨，在于第三院， /
次第各安居，四隅而安坐。 /
秘密供养已，更以饮食献， /
华果及涂香，种种而供养。 /
若不心疲倦，不尽诸法式， /
欲出于道场，当念奉送明。 /
复自谛思惟，仰启诸如来： /
『我运心供养，内外诸法事， /
或有误错者，愿佛哀愍我， /
再降甘露水，洗涤一切罪， /
悉皆令消灭。』再念百字明。 /
百字明既竟，然念奉送明。 /

「金刚阿阇黎，与弟子灌顶， /
如上先想坛，亦应诵密言。 /
所为四明王，钵啰抳也怛迦， /
真言用稻华，打弟子五障。 /
钵纳么明王，而烧白芥子， /
熏授法之者，一切诸烦恼。 /
咤枳啰惹王，加持于净水， /
以洒弟子身，而除诸罪垢。 /
播多罗真言，用加持生饭， /
供养于诸天，龙神八部等。」 /

「此法甚深秘，不得妄宣传， /
除逢智慧人，乃可为演说。」 /
