除灭于三垢，开敷正觉眼，犹如水生叶。 /
是饶益众生，最初之善庆。 /

人天应供养，殊胜法能令，诸众生永寂。 /
是则为世间，第二之善庆。 /

正妙法相应，获得多闻庆。人天修罗等， /
应供福田僧，富吉祥惭愧，功德殊胜众， /

利益诸群生，帝释天神众，翊从如去者。 /

汝今得同彼，作寂之嘉庆。 /

佛子佛为汝，决除无智瞙，犹如世医王， /
善用于金筹。

为世无比利，汝从佛心生。 /

所作随教行，勿生疑虑心。 /

必定当成佛。应一切种类，常念持真言， /
古佛大仙说，故应当忆念。 /

即有盛受义，平等法无受，故无有住处。 /

即同诸佛位，甚深寂灭法，非名言可喻。 /
佛佛所同证，故言同正觉。若非毕竟空， /
则无有三乘，无三乘圣众，此堕所灭见。 /
证此毕竟空，不能利一切。如来大悲者， /
甚深方便智，于无相法中，方便而显示。 /
能满一切愿，方便力如是，此法无人授。 /
亦不由佗悟，于道场自觉，证实无师智。 /

世间真言等，说量世间法，世知识诸天， /
自在福德者，彼所说真言，及与大力印， /
悉皆现世果，是故说为量。有少殊异者， /
谓是生灭法，无有坚住谓，当来世无也。 /

出世诸真言，本初作不生。 / 无作也

及佛声闻众，菩萨等真言。 /
我今说其量，超越于三时，从缘而生起。 / 亦可〔云〕〔用〕皆字
可见非见果，从身语意生。 /
世间所称说，果能经一劫。等正觉所说， /
真言逾劫数。

诸佛之大仙。佛子众三昧，清净离诸想， /
有想为世间。

从业得果者，有成就熟时，若得悉地者， /
于业自在得，心无自性故。〔回〕〔转〕，须受亦得，不受亦得也 /
心性离因果，解脱于业生。 /

奇哉一切佛，方便不思议，于无藏性慧， /
以慧含为藏。

彼尊无有相，远离于见相，无相诸圣尊， /
而现相中来。

诸救世尊说，当知声性空，即空所造作。 /
一切众生类，如言而妄执，非空亦非声， /
为修行者说。

## 百字真言法品第二十三

复次秘密主！于此三昧门句以空加持，于一切法自在得成正觉，是故此字即同本尊阿字。第一句明法普皆围遶无相，彼尊现离相无尊相中而来者，佛为欲满彼修真言行者令圆满故，复说此三昧句也。空者谓字也字即本不生不可得空也。由此毕竟不可得之空，具足众德普摄一切佛法也。此摄于梵音是摄取之摄，如摄取诸物令在己身之义也。由以此空加持力故，能摄一切法成佛也。此中自在者，梵音与观自在之自在有异，此是摄取义，谓能摄取一切法也。如王者于其境内随意摄取皆得自在，如来法王于一切法自在亦如是也。是故此字最为尊者，言此字即是尊，即为天为神。天者众中之首，此字亦如是，于一切法中最为其尊。犹如世间地居天中，帝释为第一；诸世仙圣中，梵天为第一；诸圣智中，佛为第一。此字，于一切真言门中最为第一也。由此一字成无量功德，故无上也。明即真言之别号也。明法普皆自围遶者，谓从一字亦无量字，生无量明，周帀围遶，如前所说字轮也。虽有如是围遶，而体即空，寂灭无相。于无相中见相，即是相中而离于相。又于无相之中而现有去来等事，普应世间，当知皆是真言不思议加持之力也。以字加持自身故，即同于此空。于此字中而成就一切佛法，犹如世间万物因空得成，而空本体无相，于无相中而现种种形声也。尊是义，字是相，即与前品义同也。􆿅阿􆿅阿􆿅阿􆿅阿

声字出字真言生，真言生果成就。一切救世者，声空知即空，所作世间一切随类如言而妄执，非彼空非及声二修行，故说即声通达入即三昧证。依法置相应字，照明阿字句，多种真言想经文也。依于字，阿字即同虚空，当知本来离相，离相而有来去之相。从阿字而有声生，阿字既本空，所生之声亦本空也。所以者何？此声者约缘而有，谓依喉舌腭等众缘相待触而有众声生，但属众缘无有自性，而此能生众缘亦复从缘，当知即是本不生也。约字有真言生，真言生即有果成就，如是即救世者所说也。若识此声即与空等，从空而有声，表于字空声相依。若能知此者，所作世间事业其相万端，皆不出阿字门也。以随顺世间故，有分别而起。不了者，依此而生种种忆想执取之心。然而实虚空及声，二俱离故。即此偈，互相释也。即入声解脱，即是真言行者所说也。若了知者，即声表于空，空示于缘，互相释也。此合移入二俱空中也。即声即空，即此理，即具万德。以识空声等故，即入真性之理。入真性，即是住三昧也。与此三昧相应，即是法也。虽本不生，而生一切法。即百字轮，青黄等种种色，方圆三角等种种形，乃至无量不可说等差别之相，依此而照明也。自佗皆空，从空立理，皆是加持用也。进入者，通达也。由住斯理，即是住三昧也。􆿅阿〔谓于声得自在，即证于三昧了知也〕更问

依法置相应，此相应作和合亦得也。置与布同也。以此字为照明，照明谓成其德也。一从字等类意，例一切字也。多种真言想，想谓有所分别义，例此于一字明解一切真言义也。想改为分别。种种真言名，谓由一字中现无量义、现无量说，于一切众生之类中各现无量言语，皆从此一字生也。于此中立众多真言名也。证此理者，依法置相应字，即是上来一字中置无量字，形色各异，如百字轮等皆依此而现，应如是照知而观察之。当知此阿字有无量义、无量种种差别，真言亦如是也。此字义乃是自本来今佛佛道同有此真理之字义也。乃此成自然慧之妙门真言等行，非世间人所立也。即此如来自然智门，非是始起，亦非如来为一类众生故创立，乃佛佛道同法位常住，虽从本自成，亦要因缘方便乃得明白显现也。此中但明一字，然百字法门皆可知，故言百字门，谓举一字则百字可知也。法谓众多义，非达磨之法也。谓百字之轨仪也。于百字中生种种德名法也。􆿅阿

## 次菩提性品第二十四

即腾百字法品中义而说喻也。犹如虚空方，一切无所依。犹如虚空物，虽见无所依；真言救世亦然，非彼之所依。如教说虚空，远离于三世；真言救世者，亦离于三时。依真言救世者，同虚空三世等离经文也。犹如虚空遍一切方所，一切万有皆依之而得成立，然虚空无所依。如是一切真言皆依于此真言救世者，而此真言本不生体，都无所依，同彼虚空遍一切处也。此见是现见、现量见，烟等不染，空亦然也。唯住于名趣，远离作者等，虚空但假名，导师所宣说。又如世间观于虚空，谓有所见，而实虚空离一切观，不与眼对也。又约虚空具一切相，而非此空具一切相，空亦不入彼相中，自佗俱离。当知此真言救世者亦如是，与虚空无异也。虽无所不有，而毕竟清净，体同虚空。虽同虚空，毕竟清净，无法可得，而无所不有，无所不成也。又如虚空离于三时，即过去、未来、现在也。真言亦尔，随世间故，说有三世，谓当修、已修、正修，当证、已证、现证之类。而实真言之体，出过于三世，等同于虚空，况随顺世人说三世耶？救世者，谓约空见种种法，此法既从本不生而生，当知此体亦同根本也。犹如虚空一切方遍依常，如是一切法真言救〔世〕，常遍于一切法而无所依也谓烟云等谓空等中虽见一切日月烟云等，然空无所依也，物等不依彼空也世所极成也〔谓有种种假名也。谓世人说为虚空，但是假名也〕

唯名行位作者等，离虚空假名字等，宣说道非名依所有。如虚空，真言亦然。真言自在，此假字见经文也。唯住于名行，此行亦可为趣。谓有名趣，谓唯名之趣，亦名是趣也。唯立于名趣，虚空假名等，假施设也。前偈云：空但有名。后偈意云：此名亦同于空，不可得也。如虚空唯有名字，而不可得离于作者。如世间人以分别戯论故，取是空相以为实有，而生种种妄计。或言虚空是常；或言众色所围，此孔穴中是虚空相；或言此空依作者处而生。此等诸见无量无边，如经论广说。以要言之，皆不离断常二见。乃至二十小乘师，亦立空法以为实有。以是因缘，有无量过失。〔今谓即是言路之义也〕〔此等是顺世间故立此名也〕

名亦无所有，等同于虚空。真言主亦然，现住于假名，非净秽受生，或果亦不生。若无如是等，种种世分别，于彼常勤修，求一切智句。谓现量假立也〔此或是多种义也，诸果亦不生也〕〔谓志求此也〕

今此中云虚空者，即是不可得。空即是大空，空亦复空，但有名字，而实体即不空，离空与不空之相也。导师以方便故，假以言说，以开悟众生。然亦空，名字亦不可得。若有名可存，即是有相。有相即心生灭，不入实智，云何得名阿字自然之慧、实相之智耶？如空无所依，当知真言亦如是，毕竟无所依。佛以方便，欲令众生普门入于佛慧，从空立假，令依此假而志求于理。空既本体无生，从空所依之假，从何而有？当如是生于实见也。如是知见，即是菩提之性。菩提性者，不离真言耳。此真言之义，即是菩提。离此之外，别有菩提，无有是处也。

非火水风地，非日月等执，非昼夜，非生老死，非损伤，非，非秊岁等，非成坏劫数，非染非净，受生果或亦不生，若一切无畏。如是等分别种种世所，于彼勤修，常作一切智句，乐欲经文也。言真言之性，非地水火风等，如虚空遍地水火风，此四依空成一切事，而空无依。此真言中，地水火风等不思议用，依字门，而此字，非地水火风之句也。非日非月，即九执等曜，皆世人所立，非真实也。今此菩提之性，无明无明等差别，云何得有昼夜之异耶？离于因缘，实相常住，即是大日如来之体，云何不离生死耶？害是损伤义，亦是衰秏义也。而此真言之性，常恒无变，离诸衰恼变秏之事，无有时分劫数成坏之相。当知如是正观真言之性，不依于妄执也。乃至劫初时不成，劫尽时不坏，其本无始，其末无终，故离劫数时分等也。以无所不有故非净，毕竟空故非非净。一切众生以此阿字而具一切垢秽之法，如来即以此字而成一切功德，故非净非非净也。若言从观而生，以有所观有所成故，随行受生，真言皆离此也。乃至从净观功德，从无量功德而受意生之身，亦复皆空，故无受生之果也。以此等皆是有所得法，而真言之性自然实智，于一切法都无所得。当知如上种种分别，非真实见，其数无量。以要言之，真言之性皆离如是世间分别之见也。若了知此而如是修真言之行，即是一切智句也。乐欲者，随意即成也。句是住处义，一切智之住处即是佛住也。当知菩提性等于虚空，虚空等于菩提性。菩提性者，即是阿字门一切智句也。􄚴刹􄖩那􈁃牟􈂪呼􈇬栗多􆿅阿􆿅阿􆿅阿

## 次三三昧耶行品第二十五

尔时执金刚秘密主白佛言：世尊说言三三昧耶，云何说此法为三三昧耶？如是说已，佛告执金刚秘密主言：善哉，善哉！秘密主！汝问吾如是义。秘密主！汝当谛听，极善作意，吾当演说。金刚手言：如是，世尊！愿乐欲闻。时金刚手问此三三昧耶法。言此者，前已说之而不周备，腾上而问，故言此也。问意言：此三三昧耶者，何法是三三昧耶？佛以此问是大事因缘，故加叹已而诫令谛受，乃至唯然受教，如文可解也。此三三昧耶，大本中广释可有一千二百偈，今此中举其大宗，余义不出此门也。佛言：有三种法相续，除其为障与无障相应，言障除即是无障相应生也，名三三昧耶。云何彼法相续？次佛答中，初三法者，相续、不间断是三昧耶义。然梵音相续与障义同，亦可具含二旨也。以相续若有间断，即非三昧耶，此即障生，故兼二义也。所谓无间相续者，即是言行相应、心口相应，一发心已身口所行不相违越，口有所誓心行亦如是修之，名三昧耶也。〔相续是其相生也〕由与瑜伽相应无障即三三昧耶也

经云：初心不观自性，从此发慧如实智生，离无尽分别网，是名第二心菩提相无分别三菩提句。秘密主！彼如实见已，观无尽众生界，悲自在，转无缘，观菩提心生，所谓离一切戏论，安置众生皆住无相菩提，是名三三昧耶句。此三中，最初但能发心誓欲成佛，然未能正观如来功德，不能了知以何法而得成佛，未能具有观照之慧，但有求佛之心，而未能了达自己身之本性有何功德，但有此慧性能于生死中最初发心而求佛果，此是初三昧耶也。从此心后得如实智生，谓能以慧决择了知此是功德、此非功德等，是处非处邪正之相，以得如实智故，能离无尽分别妄见之网，善灭诸戏论，安住真实相中，然此实智即是菩提心也。三昧耶是等义，此心等发名三昧耶也。初心虽未具实智，然亦誓成佛度人，即是等心，故亦得三昧耶名也。从此第二心相续无间无障故，次即于此真实句中了真假已，于一切无尽众生而起大悲心，是第三三昧耶也。以一切众生皆同此性而不能自了，而受生死轮回无际，我今已自觉了，当普开佛之慧光令悉如我，即大悲也。由见实故非实自除，非从外有法来入身也，除妄时实相自现也。上说此经有三句义，菩提心为种子，即初句也。大悲为根，即第二也。前以大悲为根，今乃居第三何耶？此中以照了为根，以能照了是非故方能生悲，义相成也。第三方便为究竟，此云大悲，亦相成也。由兴大悲故施方便而摄一切，此三事从初至后相续不间，名三三昧耶也。以住真了妄为彼众生故而兴大悲，除一切众生戏论，从此以后即以方便而作佛事也。戏论者，如世戏人以散乱心动作种种身口，但悦前人而无实义，今妄见者所作亦同于彼，故名戏论也。菩提众生住者，为令众生住于斯法如我无异，即是安住诸子秘密藏中之义也。〔本性也，初也〕〔谓了实相，了是智也〕〔谓此大悲愿也〕

复次，秘密主！云何三三昧耶？最初名佛心，初心等正觉，第二名为法，彼续次生心，所谓名为僧。此三三昧耶，导师如是说，住于此三等，修行菩提行。次种种导首，为利诸众生，当得成菩提，三身自在转，引摄诸众生。次三三昧耶，初以大悲方便成佛，次从佛有法，次从法有僧，此三即一体，其实无二性。以是等故，名三昧耶也。〔谓广流布种种道门〕〔前别时解云是佛是法是僧义也〕􄙺娑􄗥么􄗱〔也〕

复次三三昧耶者，谓住此三昧耶即成菩提，住菩提为众生故现种种色、说种种道，当知即以此心能摄三身，是三昧耶义也。如上说三宝，是三三昧耶也。三昧耶是等义，即此三宝等故名三三昧耶。从此三三昧耶次具三身，亦名三三昧耶也。住三身故有利益之事。利益何等？即是利益众生也。住三身中示现种种道，亦摄得众生，摄是自在摄取义也。

次于一身中示三身，谓佛、法、僧也。即是一体三宝，当知皆是从一身之中起也。此中三三昧耶，皆相承次，因前生后也。次承上复有所生，谓示说三乘，广作佛事，导利众生，所作办已，入于涅槃，涅槃之后，复成就无量众生也。谓一类众生，佛在时未能发心，因佛灭度，或于遗法之中乃成就，皆是也。

秘密主！观彼解了三三昧耶诸真言门，修菩提行诸菩萨等，于真言法则而作成就，彼不着一切妄执无能为障碍者，对此有异名为余。不欲懈堕无利谈话，不信心广积集资财，复应不作二事，谓饮诸酒及卧床上。秘密主！观彼三昧耶知诸真言门，菩萨修行真言法持诵，彼不着一切妄执住无为障者，经文也。

佛告金刚手：观彼上来所说，皆由住三三昧耶。由住此三昧耶，如法持诵，心心不间，所谓不着一切妄执也。由妄执故，诸障得生。若住此三平等者，即不着一切妄执。即此三平等者，即是菩提，诸障何由得生耶？此即是离一切障之大宗也。复有余障生之由，谓不欲懈怠。又无益谈论，于真言行不念诵，不勤修行，以此虚度时日亦尔，障得其便也。又不信。又广聚资财，以求时纷动，守护勤劳，失时受苦。以如是等种种因缘，令行者为障所得便也。以上皆是障生之缘，复有二种：谓不得饮酒，酒是生障之缘，此第一也；以饮酒故，诸不善得生故也。又不卧床上，此第二也；以安寝床上，生种种欲心放逸之想，故不得也。当敷艸藉，西方持诵者，多用吉祥茅为藉也。此有多利益：一者、以如来成道时所坐故，一切世间以为吉祥，故持诵者藉之，障不生也。又诸毒虫等，若敷此者，皆不得至其所也。又性甚香洁也，以此艸极利，触身易破，如两刃刀形也。行人持诵余暇而休息时，寝此艸藉，若放逸自纵，即为所伤，故不得纵慢也。又佛所以自借此艸者，除世间憍慢心故。为太子时，种种逸乐，坐卧宝床，宝机承足等，若出家犹习之，即与本在家无异。以能舍如是事而坐艸藉，一切人天皆生敬心，亦效除慢心入正法，佛尚如此，况我等耶？行者观如是功德，故修行此也。〔即于此真言行中，以有障故，歘尔无由乐欲是也。或由不欲心生故，障得入之也。不欲即是不愿求等也〕〔以不勤进故，如钻火未热数息，即障入之也〕〔由不信故，障得便也〕

此下依梵本经文大乘道：虚空相菩提，一切分别离。若彼菩提，乐求菩萨名。此答菩萨名也。虚空无有相，菩提亦如是。犹如虚空无相无分别，又虚空无相而众德所依，万像依之而立。菩提亦如是，毕竟无相无分别，而具一切功德也。于如是实相欲求证达，是名菩萨。

次释佛义。此下梵本经文。十地得成自在，善通达，知法空如幻，此一切同趣行，知一切世间，于佛得名。此答佛义也。谓满足十地自在通达，于一一地中皆善通达而得自在，了知诸法同于空幻，又知众生深心所行、心所趣向。以有斯德故，一切世间号之为佛。佛之名觉字，因斯而起也。此下梵经文。虚空相法无二，唯一相十力，佛是名正觉，亦号释迦佛义也。前但云知法空如幻，今云虚空之法一切无相，即以此中了达故，以十力遍知一切法无所不知。如菩萨藏经中说，十力甚广也。此菩提如虚空无二相，于一相中心无所住，以此故得佛十力。由正住此十力，名正等觉也。佛与正觉，名号殊而体一也。善调身口意，摄伏自在故，能降诸魔。非但降于外魔，内障亦遍降伏之。世出世中以为尊故，复号人中尊。此义经中阙文不释，余处如是解也。

已下梵经文。慧害唯无言说，自性自证智，说此是如来，此答如来名也。此慧能害无明，故云慧害。虽不云无明，然所害者即是无明，其义自显也。此自证境界出过语言道，以知自证非可宣说而授与人，住如此智故得如来名也。又如佛之理自然而证，名为如来。又如诸佛所行之道自然证处，我亦如是而去，故名如去也。大本中具答此各有百余偈，传法者但略其宗要，各一偈答之，其大意亦具也。

尔时执金刚秘密主白佛言：世尊！愿说诸尊令威验现前、令尊现形诸真言门。修菩萨行诸菩萨犹作其形，令行者观缘尊形，即本尊形同于自身，无有疑惑而得悉地。如是说已，佛告执金刚秘密主：善哉善哉云云。佛言：秘密主！诸尊有三种形，谓字、印、形貌。彼字有二种，谓声及菩提心。印亦二种，谓有相、无相，正是色义，谓有像、无像也。尊形亦二种，谓净、非净。彼证净形，形谓身也、体也。离一切相非净有相之身，即有显形众色。彼二种尊形成二种事，有相故成就有相悉地，非相故随生非相悉地，上亦例着之。次引佛为证有相，欲持成有相，佛常如是说也。若心住非相，即成非相也。佛语先标之也。是故一切种当住于非相，言事随心故，随心故宜求出世也。观本尊形已，为无疑悉地，得此以上金刚手问也。本尊者，梵音。若但云者，直云所尊之义也。本尊亦云自尊，谓自所持之尊也。然彼行者，犹身印真言及观本尊，此三事和合故，本尊即自降临道场而来加被也。然此行者初行之时，尚是凡夫自无德力，何能即感佛菩萨等随言而应耶？但由彼佛菩萨等先立诚言大誓愿故，若有众生依我此法而修行之不亏法则者，我必冥应，或虽不来而遥加护之。若行人法则如法而不应赴，即是违本所愿，故不得不应也。亦如方珠向月而水降，圆镜向日而火生，因缘相应而无思念，此法亦可为喻，非是诸佛有心行而同凡夫之赴应也。若心不相应事缘有阙，则本尊不加护念，故无应验，非佛菩萨等之过也。然行者以此事故，当须正观本尊清净之身，若见已即以其身而为己身，如是无疑虑者，所求悉地无不成果也。经云缘观者，即是行者各各约其本尊作如是观也。无疑者，由与彼尊相应故，无复疑难之心也，是故所修必成。已上问竟。􄙺娑􄕽地􄕵提􄙖婆􄕘多􄕵提􄙖婆􄕘多

佛言：善哉，善哉！秘密主！汝能问吾如是之事，是故金刚手极善作意，我今说之，乃至愿乐欲闻。以金刚手善能次第问疑，为劝未来真言行诸菩萨故，又复慰谕诫劝也。

次佛言：秘密主！本尊形有三事，谓字、印、形也。形即尊形也。彼字二种声菩提心者，谓行者最初修行字，略有二种观于字义：一但观菩提心，此菩提心即是字也，谓等，但举其首，然诸字皆是也。以为初首，故云菩提心也。或观字轮，谓以所持真言为轮形入身，如上持诵品说，或观种子字皆是也。或不观字但念于声，谓上观此声如铃铎声等次第不绝，及以此声调出入息，如上说皆是也。已说字竟。􆿅阿􄑀迦􄑼遮􄓚咤􄕗多􄖵婆􄗱野

印形亦有二种，谓有形、无形也。形即是青、黄、赤、白等色，方、圆、三角等形，屈、申、坐、立及所住处之类也。印谓所执印，即刀棓、羂索、金刚杵之类也。初心别缘而观，谓先观画尊等，约此而观，名为有形。后渐纯熟，又以加持力故，自然而现，与心相应。尔时，此本尊但从心现，不约外缘，故云无形也。私谓：或可初得世三昧，见其本尊如是形、如是色、如是住处坐立、如是漫荼罗中持如是印等，犹是有相，故名有形。后持真言，宛然直见，如镜像等，不相而相，故名无形也。

次本尊形有二种，谓清净、非净。谓彼行者初因有相引入无相，先观圆明佛菩萨印身，初作不见约画像等而观，渐约法力所加渐得明了，尚有所障闭目则见、开目则不见。次渐开目闭目皆得明见，渐渐不加作意亦见，乃至触身亦复有碍，犹如目对世人等也。次约此有相渐引入于清净处，以有相故名为非净。由此所等引故，住清净处寂然无相名为净也。净者是果、非净是因，非净谓形色印像之类也。由此非净引而成净，由无常之因而至常果也。私谓此三事各有二种，即行次第也。观持真言观于字，次观声渐细，次观形尊又细，次不约缘而观又细，次观就无缘又有杂不净及纯净也。或可横说之，此三事出各有世出世方便，故皆有二也。􄙺三􄗥摩􄚪呬􄕗多

经云：彼二种者，谓上来三事各有二种也。彼二种中即有二种事成就：有想故有相，非相故非相，悉地随生等云云。谓若以有相事观见者，事相有相有得成就；若无相者，亦得无相悉地成就也。又云：此三事二种中，随以一事即致成就，然皆有世、出世成就及事成、理成也。故前三种中各有二种成就二事。

经云有相，有相欲成，若住非相，则非相成就，是故成种种事，当住非相。此劝令离一切相，住于非相也。结劝也。以住非相，理成就故，一切不思议神变不加心相，自然而成妙业。非如世间成就，在于生灭心行之中，而力有限，又非究竟，故劝求其胜者也。私谓：然大般若等中，具说洗涤观心之事，然须有本也。今行人先约别缘起观，乃至具见十方佛会诸世界等种种境界，以为悉地，而后于般若洗涤净除，即成不思议大用，顿入佛果。若不知行行次第，但观彼文，不入深智，多错会经意，直尔入空，失圆顿道也。故此一两品，最须谛观其意耳。

## 次无相三昧品第二十九

复次大日世尊告执金刚秘密主言：秘密主！彼真言门修菩萨行诸菩萨，乐欲成就无相三昧，当如是思惟：相从何生？为自身耶？自心意耶？彼身因业而生等艸木瓦石，谓自性如是也。谓业生之身，自性如是也。顽同木石，业生谓从心起。此观是有相，有相为外，外所有身语等，如是观之也。顽同草木性，离于分别作，谓业由心生也。从因业生是内也，外谓土木造立是外也。

佛告金刚手秘密主：彼非想三昧成就，愿欲真言门菩萨行。修行诸菩萨如是思惟：从何相生自身自心意者？即是修瑜伽者已能观于本尊等，乃至现得种种奇妙之境。然犹是世三昧摄，未得三平等慧。今更开示入三平等观也。若此观明白了身口意实相，即入净菩提心初法明门上菩萨地也。先明身实相观者，谓经云：彼身业生艸木塼瓦等性，如是作离顽如外作，或业生如形像见等经文也。上来言当住非想等，今此品中若修真言行者，若欲得此非想三昧成就者，当造斯观也。〔此是私释，然大意如此也〕

经云自身自心意者，谓从心有思生，心是清净心，意是分别也。然此身同木石，其性顽愚者，言此四大若离于心，即同木石也。如大般若观身念处中说，如明目人自观仓囷之中种种米麦等。此身亦如是，身念处观开时，自见三十六物各各异相，尔时身相即除。如开仓见米麦时，仓囷名除也。乃至一一皆缘生，次第深说也。更问

次又明以身同于像也。如作像者，以土木杂物和合为像，或佛或天，或余父母形等，以不善观故，随生所尊所爱之想。然一一细观，但众缘合会，都无自性。今我身亦尔，诸界假合，自不了故，而生身见。若细观时，都无自性，但从心有，如幻梦等境，从缘而生，实不可得也。又此身者，以因心故，状若六情有知，然实不尔。如人心不观察，则有所住，则虽日月之明，或有所不见，雷霆之响，或时不闻。又如过去一心禅观比丘，乃至从道行，有大军过，而不见之。当知若离于心，则此身虽具眼耳等根，犹如木石无知也。又如像喻，若此木石等像，或谓火所烧，水所坏，刀所伤，金刚等所碎；或忿怒粗语加之，不能动其少许心想，令生不喜；或种种供养，被以妙衣，献以名馔，涂以妙香，炫以妙色，乃至人天上供之具，丰盈于前，亦不生喜。当知彼像本性自空，是我心分别故，而生增减，或毁或供，俱颠倒不实耳。如外观像者，须以此观而观自身，尔时不见身相，离于分别。如是观察其身，见身实相，即证无想三昧也。故凡观察时，先须约相有相之缘，渐次深入，自然即相无相，即缘无缘。若不得此方便，但直尔观空，而不知以何因缘故空，着是空法，多生异见，故修行次第，须有指适也。

何以故？愚童凡夫，于自性空形像，自我分生，谓从自身生我分别也。颠倒不实，起诸分别，或供养，或除供养等，或毁骂，皆除舍之也。然观身时，合有语观，以摄入身观，故不别说。今略显之，即是智度论意也。今此语从何有耶？谓从喉咽唇舌脐等众缘，心动风界，互相触故，得有此声，犹空谷响，都无自性。凡夫不了，故闻好生欣，闻逆情生怒耳。今如是见声实相，即知此声不生不灭，同于实相，是入音声平等慧性也。次即观心，以法无形相，观可觉知。先从粗观，了此身平等，语平等，自知深入，易可观察也。

复次，秘密主！心性离一切相，思惟性空，当思惟此也。秘密主！心于三时求不可得，离彼三世，彼性如是，当思念之而离于相。

复次秘密主！行人尔时既观外相，次了内心亦空。此心离一切相，于三世中求皆不可得。如虚空离三世，心亦如是，出过三世生住灭法也。

复次秘密主！有心想者，谓愚童凡夫之所分别，谓约心取相不能了知，不实妄起有如是说。彼不如实知，谓由有是妄执不能如实知也。如是思念，谓思凡夫起是思惟也。如是谓凡夫有此分别也。已上属心句也。

秘密主！以此真言门，修菩提行诸菩萨，谓当了知有相而起无相也。谓菩萨如是思惟，证得无相三昧，由得住于无相三昧故。秘密主！彼人当得由除妄故，真言实相实体现前，行住坐卧常现前也。如来所说真言，彼常亲对而住。由识真言之体，如前十喻，即是悉地相也。然凡愚以不了心实性故，谓为我心、我愚、我智、我顺、我违，自生种种缚着之想。以心虚妄故，所有身口亦皆虚妄也。彼不知何事耶？谓不见真实。由不见真实故，由如婴童无所晓解。若见心实相时，自然离如是一切戏论分别也。以不知心实相故，而生妄执，名为凡愚。若了知者，即诸佛也。〔说相显无相也〕

次经云：秘密主！真言行菩萨证得无相定，如无相定住，得如来说真言亲对，而彼常住。此经文引不具，当捡经细观也。此意言：此真言行菩萨如是离相修行之时，名住无想定也。由住此无想三昧故，如来所说一切真言皆现前而证，故名亲对也。如是证理之时，即名常住。常住者，即同佛住也。今此品合次六十心说之，说义次第于彼先言不便，故以此中结会而说也。私谓：上来经文大意不过三行，谓口真言、身法印、意观佛也。然此三事皆缘生法，缘合而有，都无自性，不生不灭，即是阿字之门、法界之性。凡夫不知，云何得入？故佛先说此三真言门，渐得三昧，乃至亲覩本尊，见种种神变之境。由是心有所着，不得三平等住。今说入三平等法门，若行者于瑜伽心中而复能如是观察，离于身口意分别戏论，即得现前而证。真言实相同于佛住，自体常住同于如来也。无相三昧品了

## 世出世间持诵品第三十

上来一部经意，只为修真言行诸菩萨等，明持诵入道之法，而今此品专得其名，当知统说一部之要旨也。

复次秘密主！今说秘密念诵法，亦令一一诵诸真言，佛菩萨等别别说。谓随彼之中取一一，谓各各也。于诸真言中随取一一各别而作心念诵，第二作出入息念诵，此二法最第一相应也。常如是作此二法，是名第一念诵也，勿异此也。若异此者，于念诵有所阙支分，由不具故也。然以内外相应分之有四，我先已说也，今已下更说之。彼世间者有所攀缘，谓三种中但观字印身，观之识其本性，知印即字、字即身，无碍而心湛然，是念诵也。若以字作出入息，字即真言之体，以此出入息资身，名出入息也。然此二中由出入息有少所缘故，当知意念诵最为上也。字印尊无所分别，作出入息亦得也。经初金刚手已曾问佛持诵之法，上来亦有略答之处，然未具足。今为决择故，更具分别其宗要之行也。其秘密者，上来诸品所明非不秘密，然此中宗要乃秘密中之秘密也。一一念诵，或作意念诵，或作出入息念诵，此明差别行法不同也。一一念诵者，谓专心口诵真言，口中声出时，一一声字皆悉谛了，不间断攀缘也。作意者，即直是心持，作心想念诵不出声也。出入息念诵，如上所说服风等是也。二相应者，谓于三念诵中，其作意及出入息，此最相应最为第一也。常勿异者，谓常当依此而作，勿异缘异想也。若不尔者，徒用功无益也。持真言者阙支而用者，谓字有点而不导，或字阙，或应长声而短声呼之，如是类甚众，皆名阙支念诵也。右此内外相应，合有四种念诵也。言世间有缘相续，所谓字句。句是举足行步，谓观此字，如一一步字，即是种子字也。前已出世念诵，身字印合为一，随用一即得。今世间念诵，即分异之，或观字，或观尊，或观印也。谓句及本尊，就世间中，念诵出入息，最为上也。前出入息，变字为出入息。今世间念诵，见出入息中有字，了了分明，是有分别也。前出世间，不作如是分别也。于真言中，分别为二，即方有相，一体无分别，是无相也，皆是有缘也。次明世间持诵者，彼有缘相续字句，此中或取一字缘之，或取句等，想在本尊心上，如前具明，是外念诵也。取一字者，即是种子字，或真言初首之字。若真言小者，或具想其句，如上说，如连环等，在本尊心上。圆明之中，此二种，或字或句，随息出入，不绝不间歇。诵时才令自耳闻息，出时字出，入时字入，令随息出入也。今谓天台云：诵经是圆寂数息，是此意也。今以此字一缘，与息出入，自然念念相续，心不散乱，恬然易入三昧也。此为世间念诵，最为上也。又经明此义，如观镜像，分明而见。今观字、见字、观印、观尊，即见之，此是有相也。若行者见此真实，即不住有相，然犹未入无相。若观菩提心，是一向无相也。此心即是佛，佛即是自身，自身成佛，一相无异相，故名无相也。随谓或来或去，随心也。即四色是也

世间念诵，以出入息为上也。当知出世间意念诵，远离于诸字，字与本尊作一合相。不坏，谓不分为二，取为分别也。一合相，谓合为一，令不取着，不坏此相也。不坏意色相，谓色相像与心不相异，故云不坏也。勿异于法则，谓教法如是也。住是法则，诵三落叉，如前说。我所说多种念诵，谓遍数、时节、现相、增益等。三落叉是数，数是世间也。出世落叉是见三相，谓字、印、本尊，随取其一一合相是也。字、印、尊等，身、语、心等，名见也。乃至能令持诵者净，令一切罪除；若不净，更一月等，如前也。然今所说念诵数，谓牒上文也，不应异此法则也。又上明尊神者，言此字句念诵之法，诸尊皆尔。上从佛部，下至八部，凡有念诵，皆当如是作之。其出入息念诵，亦随本尊法，一一有此行法也。出世间者，当知是意念诵之法，离于文字也。岂拨离前来真言字等，方名离文字耶？不如是也。谓能达字之本性，即是圆明常住，本来不生。不生者，即心是也。心之体性，圆明清净，具足众德，而无分别，当观如是之字也。此字者，还即是前来本尊真言之字及句耳。但了知此字从心而生，心既圆明湛寂，从心所生之字，其性亦尔。所云离字声等者，谓离分别缘念之心，及声想等也。然持诵时，有诵有观，或可兼行，或但修观照也。诵谓如上缘于声字，或出入息等，照谓观此字之体性也。然初观时，带于有相，若观种子一字，其圆明初即小作，若具观句等，即大作。圆明状如连环等，以心观照，令宛然分明，后即从此而观其性也。本尊作一相不坏取，意不坏形，勿异法则者，真言本尊，即是初观圆明之字也。今既已观圆明之字，

次即观本尊，如上已说。一相者，即身口意也。观本尊心上作此圆明即是心，其身印等即是身，其真言字等即是语。今已明见本尊，而观本尊三事一相平等如于实相。又观本尊三平等一相即同于我，我之三相亦复一相平等不异于尊。此圆明之性不异菩提心，菩提心不异本尊自佗平等也。又所观字虽不同，然皆是三昧门。若解一字之性相，即解一切字之性相。若解一切字之性相，即悟一字之性相。字即本尊，本尊即心，心即法界体性也。是故此字即是不思议字。如阿者，一切亦尔也。如字者，印等亦如是也。于此不思议三相，谓字真言相、身印相、本尊心相，不遣不立、不增不益、不损不减，当作一切平等观，而达一切法、成一切智。当依此法，则勿异此而作也。此即是三落叉义也。落叉梵音是相义，亦是见义也。我于种种经教中，凡有持诵相应处，多言诵一落叉或三落叉等，或言为除罪障故诵一落叉，极重障者不过三落叉，便得罪业清净。然此义有余，今当决之。所谓落叉者，是相也。若得三相，当是罪得除也。先明身相，谓身体先时粗重，今则轻安。乃至或行百里千里，迅疾而往，不觉劳倦，速疾异当。先时静坐系缘，多为小虫蚊虻等所恼，今悉不生，无复腻垢可恶之相。广如大品中所说，此是身相也。语相者，随有所诵，暂发声时，本尊即至。又如大品所说，口发诚言，非人不娆于佗之类，皆是语业净相也。意亦有殊异相，谓发生无量慧解，如经一月四月，分别不尽等。或先时贪耆，如是如是食味，或不得者，身即不安。今时寂然，不复思念，乃至多日不食，恬然得喜悦之味，无余食想，身亦不困。或先多种种烦恼，今皆静息，皆是意净相也。由具此三净相，故名三落叉。若不尔者，徒自劳形，虚数遍数，难得成就，无所益也。既得此三相，当更增修胜行也。或时诸天八部，飞行空中，不敢履践其影。或来敬礼问讯天诸童子，以为给使，问其所须。如此是谁得知耶？但持诵者，自知而已。此亦罪除净相也。􆿅阿

然上来明离一切相，今说三相，与此云何相应耶？今答：此三相以阿字故，此三即一相，亦非一亦非异。如天台所解，与此略同。谓一相一切相，非一非一切，即相即无相，即非相非无相，皆是此意也。如是三相平等，住于实相，是三落叉义也。身实相是一落叉，除一切身垢；语实相是二落义，除一切语垢；意实相是第三落叉，除一切心垢。三垢除已，三功德生，即是分证如来功德也。又落叉是垛义，是标义。如文殊经中明学射，初虽远垛，后渐近之，乃至任运中的。首楞严三昧亦尔。以是因缘，名落叉也。

复次，身印、口真言、意本尊，即是三行；差别不同，即是三相。即此三相，入阿字门故，离于三相，一相平等。如是照见，是三落叉义。落叉者，见也，故云勿异。勿异者，不得佗观也。复次，前三句义，谓菩提心为种子，大悲为根，方便为究竟。从首至终，皆明此三事，或自显此三德，或为成佗三行。言三落叉者，即与此相应也。谓行者最初，先须有菩提心，此是一切佛法因也。若不发心，则离于妙因，何有进行耶？虽已有心，若望路不进，有愿无行，何能成就大悲胎藏，生功德身乎？或虽能进行，以离方便故，而有疑心；因疑心故，一切不成，亦不得入实相也。是故佛令诸行人，必须依师而学，不得自专。以自利根、分别力故，輙寻经文，便自行之，随闻便用，不入漫荼罗，不受三平等戒，不能具解方轨。以不知故，虽发心修行，勇猛精进，然以方便差失故，所为不成；以不成故，而生疑心；以疑心故，谤毁如来深密之藏，即是五无间因，趣五无间道。以是因缘，须具三句义，不得阙少是三落叉义也。以此事故，次后品付嘱中，复明择弟子相，文相承蹑耳。即因也

## 嘱累品第三十一

次是劝嘱品，经虽不言，其义如是也。次佛告大会，即是经文之初十世界尘数金刚菩萨等也。今说经欲了，故加付嘱也。汝等应当住不放逸者，即是承蹑前文，此大乘密教当如法相承，若传受失宜，即是专擅自恣而越法则，故云住不放逸也。复次，如上三句义自利利佗之行，汝等当住阿字义秘密教中而作佛事，若不随此，即是住于放逸也。以差机而授，或伤彼善根，故经云：有智若闻，即能信解；无智疑悔，即为永失。若菩萨不深观众生本末、因缘、种相、体性，而卒尔传法，即是为人天怨，是为大放逸行也。故次云于此法门，若不知彼根，不得授与佗者，根即信等五根利钝之相也。除我弟子者，谓已依我教而住，心相体信，方堪授之。若余世间外道之类，未入正法，信心未固，当且于余深法中示教利喜，不得輙尔为说也。若菩萨照机识因，自由己智力，今为末代传法人等，更明外迹可传之相也。前经初已明择弟子相，今又说之，然皆略举宗旨，大本中具明也。良晨生者，大本中具明如是宿次，如是执曜时节而生，则有如是根性，如是相貌，宜即与如是如是教法，其言甚广。又一一皆有浅略深秘两说，今此中但举其纲目耳。求胜上事，即是发菩提心，唯求如来具足之行，凡所施为，非求余事，所行广普尊妙也。微细慧者，谓闻一字一句，即能自以智力，广解无量义趣，广演无僻之类也。思念恩德者，乃至从师闻一句之义，乃至成佛，犹不忘报之，当知知恩报恩也。渴仰者，谓心殷勤希求胜法，犹如萨陀波伦之类，乃可为说也。欢喜住者，谓闻妙法，心喜踊跃，遍于身心也。不求彼法者，乃至不受余经一字之类也。

次又辨其外相，略说其色，谓青白也，即是非白，又非大黑，是吉祥色也。大本广明，今但举一隅耳。头广，谓如罗云，顶如伞盖之类，然不太广，又不令小，要在丰纤得中而相具也。高项，谓颈不太长，又不短缩，以要言之，修直得中，而不过甚也。额广而严，亦谓极理太广，又须具足端严之相也。鼻修直者，谓非太隆高，非太卑平，当如金铜之类也。略说身心堪为道器之相，如是之人，乃堪传习也。彼具相者，子谓佛子，如是人等，应当与之慇勤摄受教之也。瑜伽论十地中说也。佛又劝嘱，必是堪继传者，当勤教授之，勿令失时也。时金刚手等具大德者，时彼听众闻说是者，于诸本尊所说之法，我顶戴受持得已，谓如受王教，奉行流布，当作供养。时众重起礼佛，为法久住故，请佛加持也。闻佛所说，顶受奉持，为一切智作礼，而请如来加护。所以者何？佛已付嘱如是秘藏，以荷重任，行如来事，其軄不轻。然此妙法，如来在世，犹多怨嫉，何况末代恶世之中。然我等已发诚愿，要此令如是之经，广行流布。是故请佛，以自在神力，加护我等，令所愿得成也。法眼道，久住世，遍一切者，即是弘经之愿，以佛加持，令此法眼，久行于世也。此是开佛知见之大直道，一切诸佛所行之路，故云法眼道也。当令此道，久住于世，穷众生际，又横遍世界，无不流通也。即是上行等云，随佛有迹之处，我皆誓传此法门，弘经之意也。时佛受彼请故，即以真言，而加持此法，如经中说也。时诸上首菩萨，闻佛说已，顶戴受持已，广说摩诃毗卢遮那成菩提加持神变经竟。〔即是上来会众等〕〔未说句义，更问〕

大日经抄记。

问：前三句：一者、菩提心为种子；二者、大悲为根；三者、方便为后。今就大悲藏漫荼罗说之，为以中胎为菩提心，次八叶为大悲，外三院为方便也？答云：此有二种：若有修行者，因中说之；有如来，果地说之也。且如最外院八部等世天，即是前八心中，从初解守斋已去，乃至受用果等也。然有善根开发，与正道相应，即是大悲胎藏华台之因也。如来以方便力而引导之，乃至今成就世间八心以来，是外院之位，渐渐向里也。及二乘亦在此内。次又知有胜法无上心，稍进引入第二、第三，皆是大悲句也。次成佛果，入中胎，即是方便句也。然此八叶及中胎五佛、四菩萨，岂异身乎？即一毗卢遮那耳。为欲分别如来内证之德，表示于外，故于一法界中，作八叶分别说耳。且如四菩萨东南普贤者，何也？普贤是菩提心也。若无此妙因，终不能至无上大果，故最初得名。次文殊师利者，大智慧也。先发净菩提心，如普贤观经，次第乃至毗卢遮那，遍一切处，常、乐、我、净波罗蜜等之所摄成，皆是净菩提心也。次即说第一义空，我心自空，善恶无主，观心无心，法不住法等，即妙慧也。以此第一义空之妙慧，净彼遍一切处净菩提心，平等慧利刃，断无始无明根，即入菩萨正位，故虽有菩提心，而无慧行，即不可成果，故次明文殊也。次西北方弥勒，即是大慈大悲，俱是第二句中义也。以此大悲藏，增长成就妙菩提树枝条华叶，故次说弥勒也。若慧而无悲，则方便不具，则不得成菩提，不能具六度摄众生也。次东北方观音，即是证也。证谓行愿成满，得入此华台三昧也。若就未成果时观之，此则差次浅深，今以佛成平等慧观，从因至果，但是如来一身一智行耳，是故八叶皆是大日如来一体也。若如来但住自证之法，则不能度人，何以故？此处微妙寂绝，出过心量，说何示人耶？故渐次流出，入第一院，次至第二院，次至第三院，虽作如此流出，亦不离普门之身，其八部之众，皆是普现色身之境界也。若就情机而说，则三坛从深至浅，乃至世天真言义浅，但是应身道方便，未究竟也。若开实性，即世天真言，与大日如来何相异耶？从如来则从深至浅，从内渐外，而成三重坛，从众生则从浅至深，从外渐内，而成三重坛也。

又如字义，即是此之次第也。初字，在东方，如梵音阿字，有初首之义，以顺世间法，诸方中东为上，故喻菩提心，最是万行之初也，其名曰宝幢佛。次即此字，是行也，若但有菩提心，而不具修万行，终不成果，与前四菩萨义不殊，其佛即是华开敷也。次即字，三菩提也，以万行故，成正等觉，其佛名阿弥陀，即西方也。次即是大涅槃，其字曰，是正等觉之果，果故说也。次即入中字，是方便也，此是毗卢遮那佛本地之身，华台之体，超八叶，绝方所，非有心之境界，唯佛与佛乃能知之，为念本誓，开示大悲藏，普引众生入佛慧故，复以加持神力，普现身口意，遍满生死中，当知此即是方便也。若离方便，如来本地尚不可说，何况以示人耶？不可为诸上首之菩萨说，何况流入生死中耶？以此方便，同于大空而现众像，当知一切大会漫荼罗，皆是一身，无别身也，即是普门身，即是法界身，即是金刚界身也。又菩提黄色，是金刚性。次行赤色，是火义，即同文殊之义，万行以妙慧为导，不得离慧而有作也。次成菩提白色，即是圆明究极之义，又是水义，如我昔所愿，今者已满足，化一切众生，皆令入佛道。为是事故，是起大悲故也。次即是大涅槃，迹极返本，众生有缘之薪尽，则如来方便之火息，故涅槃也。佛日已隐于涅槃山，故色黑也。中心空具一切色，即是加持世界漫荼罗普门之会，毕竟清净，无所不有也。其百字轮所以从外向内，亦是此义也。如中胎者，一切本尊亦如此说。如金刚手种子字，即成五事是菩提心是行是三菩提是涅槃是方便。所以云方便为后，是此义也。如莲华尊亦有五事是菩提心是行是成菩提是涅槃是方便。如文殊以字为种子，亦有五义菩提心行成菩提涅槃方便。余一切尊种子字，皆亦如是广说。以是义故，金刚手者，即是大日如来；观世音者，亦是大日如来；文殊师利者，亦是大日如来；乃至鬼神八部，一一亦有此义，亦即是成大日如来。体虽是一，而义各异。所以瑜伽中云：毗卢遮那言：我即是文殊、观音等，我即是天，即是人，即是鬼神，即是龙鸟。如是等无不即是者，由此义也。又云：此大悲藏本尊位次等，及形色各殊。为未深入瑜伽者，初学之时，不得正观本尊，故佛以方便示此，令心有所缘耳。及观成时，以法力所加故，自然恒与佛会相应。设不作念，犹自明了，况加观耶？如是时，自然真见漫荼罗也。此地者，即是净菩提心。是上所表，皆是大日如来法身妙庄严之相也。又观音、文殊、普贤、弥勒，已在八叶中，即大日如来大法身也。为度人故，渐出于外。故次图中，复有文殊、观音等，以类可解也。又云：如八叶中，普贤是菩提心，文殊是慧，弥勒是悲。此菩提心即是大日如来，不离大日如来有菩提心也。大慧即是大日如来，不离此大日如来别有慧也。悲即是大日如来，不离于大日如来别有悲也。当知准此说之，万德皆尔。犹如天台、法身、般若、解脱义，若但法身，不得名法身之类，与此相合也。􆿅阿􆿆阿􆿓暗􆿔恶􈓜􄙖􄙖􄙗􄙠􄙡􈓥􄙺􄙻􄚦􄚧􈑲􄗥􄗥􄗦􄗯􄗰􈑳
