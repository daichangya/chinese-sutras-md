# 金刚顶经观自在王如来修行法 · 第一卷

> 唐 不空译

## 001

我今依《金刚顶经》演金刚莲花达摩法要。先须入于灌顶三昧耶曼茶罗，发大菩提心，舍身命财饶益一切，勇猛精进随念相应，慈悲喜舍无有间断，如是之人方应修习。其曼茶罗画像等法，广如余经所说。凡入精舍欲念诵时，先以五轮着地，顶礼本尊观自在王如来；次礼北方不空成就如来；乃至无动、宝生、遍照如来！悉皆依法至诚敬礼，双膝而跪莲花合掌，忏悔三业一切过咎：

密言曰：

「唵馺婆婆婆秝陀萨婆达摩馺婆婆婆秝度澸」一二合去入二三二合去四入五

次应随喜过、现、未来诸佛菩萨所集福智。

次应右膝着地虚心合掌置于顶上，想礼诸佛如来及菩萨足，诵密言曰：

「唵钵纳摩尾多」二合上多字半音与尾字合呼

礼诸佛已依座印而坐，入定思惟观无量如来周遍法界，行者己身悉在彼会，然后结秘密三昧耶印，坚固缚以檀慧禅智相合而竖，以此惊觉圣众，诵密言曰：

「唵婆日啰跛娜莾三昧耶萨怛梵」一二合二二合三四三合五

次应结一切如来欢喜悦意三昧耶印。准前印，唯以忍愿入掌中。密言曰：

「唵三莾耶呼苏啰多萨怛梵」一引二去三三合四

次结开心印。观二乳上有「怛啰咤」字，以金刚缚三拍开之。密言曰：二合

「唵婆日啰满驮怛啰咤」一二合二三二合四

次结入智字印。于己面前观一红莲华上有「娑」字，以坚固缚禅智入中进力相拄，想「捻其」字内于心中，诵密言曰：

「唵婆日啰吠舍恶」一二合引二三

次结阖智字印。不易前印，进力拄禅智背想阖心门，密言曰：

「唵婆日啰母瑟致」一二合二二合三四𤚥

次结辟除结界印。戒方右押左外相交，忍愿相拄，以进力钩戒方，禅智捻檀慧头，密言曰：

「唵阿密栗覩娜婆婆吽泮咤」一二合二合二三咤半音呼之四

以此印左转三匝辟除不善，右旋三匝随意远近以为结界。

次结三摩地印。二羽仰叉，进力相背而竖，禅智捻进力，头置于跏上，诵密言曰：

「唵三么地钵娜名颉哩」一引二二合三二合引

其出入息一一明了，观虚空中无量诸佛！一时弹指警觉行者而告之言：「汝今云何成无上觉，不知诸佛实相法要？」行者尔时闻警觉已，白佛言：「云何名真实？唯愿如来为我解说。」尔时诸佛告行者言：「善哉，善哉！能作是问，汝想心中所内『恶』字莹彻于心，诵密言曰：

「『唵唧多钵啰底味邓迦弭』一二合二三𡀔

「当默诵一遍，便想为月轮如在轻雾，为欲令其月轮得清净故，诵此密言曰：

「『唵冒地唧多母怛跛娜夜弭』一二二

「诵已谛观心月极令清净，如处大虚廓无瑕翳，复于心月想一莲华，诵密言曰：

「『唵底瑟咤婆日啰钵娜么』一二合二二合三二合四

「想其莲花与月渐渐而引，周遍法界量等虚空，诵密言曰：

「『唵萨颇啰婆日啰钵娜么』一二合二二合三二合四

「其引莲华中放无量光，随光流出无量无边际极乐世界，一一世界妙宝庄严，皆有观自在王如来与圣众前后围遶，如是观已渐敛其莲华，诵密言曰：

「『唵僧贺啰钵娜么』一二合二二合三

「如是一切世界诸佛如来随华而敛，量等本身，即变己身为无量寿佛，身红颇梨色，放大光明，结三么地印。金刚莲华座想行者己身为如来已，复恐散乱而有退失，次作加持印而加持之。坚固缚以进力屈如莲叶，禅智并竖印心、额、喉、顶，随所印想『颉哩』字，诵密言曰：二合

「『唵婆日啰达么颉哩』一二合二三二合

「次结灌顶印。莲华合掌，进力相蹙如宝，檀慧竖相远置于额上，密言曰：

「『唵钵娜么啰怛那毘诜遮萨婆颉哩怛』一二合二二合引三四五二合六二合七𤚥𡀔

「次结莲华鬘印。以前印从额分手绕至顶后结莲华拳，如系华鬘势徐徐前下散，诵密言曰：

「『唵钵娜么啰怛那么隷』一二合二二合三引四牟含反五𤚥

「次结甲胄印。结莲华拳前后绕身如擐甲法，诵密言曰：

「『唵阿婆耶钵娜么迦婆制满驮啰乞洒吽憾』一二二合三四五二合六七八𤚥

「次结欢喜印。莲华合掌微拍三声诵密言曰：

「『唵钵娜么覩使野护』一二合二二合引三

「复于面前观安乐世界琉璃为地功德乳海，于其海中观『颉哩』字变为微妙开敷莲华，即变其华为观自在王如来！色相庄严如前身观。二合

「次结莲华钩印。莲华合掌进力如钩，诵密言曰：

「『唵钵娜懵句舍吽若』一二合引二三四五

「次结莲华索印。即以前印进力如环，诵密言曰：

「『唵钵娜么母伽播舍吽』一二合引二三四

「次结莲华锁印。芙蓉合掌进禅相捻，力智亦尔，相钩成锁，诵密言曰：

「『唵钵娜么塞怖咤』一二合二二合三四𤚥

「次结莲华铃印。以莲华合掌，禅智入中进力如环，诵密言曰：

「『唵钵娜么吠舍恶』一二合引二三

「次结莲华部百字密言。捧阏伽器，以欝金、龙脑相和香水而为供养，诵百字密言曰：

「『唵钵娜么萨怛婆三么耶么弩播攞耶钵那么萨怛婆帝尾弩波底瑟姹涅哩擢茗皤婆苏覩洒谕茗皤婆阿弩啰讫覩茗皤婆苏报洒谕茗皤婆萨婆悉簟寐钵啰也瑳萨婆羯么苏者茗唧多失唎药句𠰷吽诃诃诃诃护薄伽梵萨婆怛他孽多钵娜么莽茗闷遮钵娜茗皤婆么诃三么野萨怛婆恶』一二合二二合三四五二合六二合七二合二合八二合茶护反九二合十二合十一二合十二二合十三十四二合十五十六十七十八十九二十二十一二十二二十三二十四二合二十五二十六二合二十七二十八二合二十九引三十

「次结莲华内四供养嬉戏印。芙蓉合掌禅智并竖，诵密言曰：

「『唵钵娜么逻细呼』一二合二三四引

「次结莲华鬘印。即以前印二臂俱申，诵密言曰：

「『唵钵娜么么隷怛啰咤』一二合二三二合半音轻呼

「次结莲华歌印。以芙蓉合掌屈拄诸度，从脐而上至口方散，诵密言曰：

「『唵钵娜么拟帝拟』一二合二妍以反三同上音四

「次结莲华舞印。以芙蓉合掌左右而旋于顶上散，诵密言曰：

「『唵钵娜么儞哩谛讫哩咤』一二合二二合三二合半声四

「次结莲华外四供养烧香印。莲华合掌下散犹如焚香，诵密言曰：

「『唵钵娜么度闭恶』一二合二二合三四

「次结莲华散华印。莲华合掌前上散犹如散华势，诵密言曰：

「『唵钵娜么补瑟闭唵』一二合二二合三四

次结莲华灯印。莲华合掌禅智竖相逼，诵密言曰：

「『唵钵娜么儞闭儞一二合二引三四

「次结莲华涂香印。十度作莲华合掌，当心分散如涂香势，诵密言曰：

「『唵钵娜么囐提虐』一二合二三四

「次结根本印。坚固缚以忍愿相拄，如莲叶形，诵密言曰：

「『唵路计什婆啰啰惹颉哩』一二合二引三二合四

「结根本印诵明七遍已，然后执莲子珠相应念诵，于四时中随力而作。若欲止时重结根本印，复诵七遍根本陀罗尼，次结八供养印，然后发遣本尊。

「发遣印。以前根本印从脐至面方散，合掌于顶上，想观自在王如来复还本宫，诵密言曰：

「『唵婆日啰钵娜么穆』一二合二二合三四

「发遣本尊已随意发愿，复以甲印护身，以马头明王结界印左旋解界，随意经行往诸净处，读《大乘大般若经》、《华严》、《涅槃》及《楞伽》等经，行住坐卧常念本尊无令间断。」

「我从无量劫，沦滞生死海； /
今以清净心，发露而悔过。 /
如诸佛所忏，我今亦如是； /
愿我及众生，一切皆清净。」 /

「过去三世佛、菩萨与众生； /
所集诸善根，合掌尽随喜。」 /
