# 太虚大师全书．第十九编　文丛(第137卷-第321卷) · 第321卷

> 民国 释太虚着

---

发扬大乘佛法真义，
应导现代人心正思。

灵慧光如，真惟法善，德圆智深，理顺性健。 /
悟澈心源，言契经典，禅续祖灯，旨超玄辩。 /

真觉平等业形本空无始迷蔽或扶或攻 /
悟理达幻冰释水融供养如佛一塔普同 /

户枢南北筦钥西东四民超敏物阜德丰 /
道声一树天下响风觉济今世唯佛大雄 /
慧日破暗法雷振聋建佛教会拯灾恤窘 /
书报刊布经像流通亦修净业亦习禅功 /
增高继长岁有不同爰发文采焕烂虚空云蒸霞蔚垂之无穷！ /

十九出家三十成道说法四十一年普润二木三草乘鹫山之夙愿其智者之再来纵玉泉之可竭必斯塔之无颓。 /

此非汝躲跟处亦非汝舍命场直须身奉尘刹洞然海印发光。 /

妥师之骨于磨镜台摧邪扶正师其再来 /

此土缘深弥陀观音长老承化善净其心 /
母慈子孝资贤师明信愿行备极乐永生 /

有大龙象崛起湘衡空所依傍特立独行 /
因礼南海遂留甬东机辐缘凑中兴天封 /
为法为众任劳任怨大廋岭上真风卓然 /

懿惟法师佛门神骏雉水钟灵诞玆贤俊 /
德慧天然雄伟和慎智探觉源悲垂济振 /
应化适机法雨周润释难析疑辩雷迅震 /
荷担如来作育后进众望方隆无常忽顺 /
哀我僧伽丧此重镇归骨光孝塔耸千仞 /
式仰高风泰山俱峻 /

天生哲人好善成性一生善举屈指罔尽 /
滔滔江汉南国之纪赖公版筑方便行李 /
维桑与梓必恭敬止弦诵声闻济济髦士 /
为善最乐慷慨挥金至公自奉辞甘就辛 /
晚崇净业兆征生莲妥兹灵宅亿万斯年 /

八字打开，
一尘不立，
四明第一山，
中道从容入。

摄化阎浮，
应居兜率，
时时示时人，
时人自不识。

戡天缩地逢今日，
护法安僧仗将军！

巍巍堂堂，
众圣中王，
现身雪窦，
不离华藏。

禅门艳称雪窦颂，
海外犹傅碧岩集，
今日当场拈出时，
清风匝地起何极。

诸法刹那生，诸法刹那灭， /
刹那生灭中，无生亦无灭。 /

依有力慧，运即慧力，十五年前，顿入佛律； /
十五年来，广布法益。正信长留，江汉无竭！ /

方冀药师延留东方，何期弥陀已接西方！ /
唵、哑、吽、慧力！愿无往而不吉羊！ /

岳岳居士江汉之英家敦孝友商着贤声 /
在群在国义勇成名及其皈佛既智且仁 /
慧树正信三宝昌明力拯灾难普度众生 /
勤奋精进菩萨之行一十五载契以至诚 /
化缘方永何忽舍身追念功谊实恸余情 /
虚空有尽悲愿长存觉灵不昧应同此心 /

其生也直其逝也善直性不生善德常湛 /
常湛不生何去何住不生之生无逝而逝 /
逝八七余佛声相续今日起龛功行满足 /

五蕴非有四大本空通身般若法界常融 /
般若火聚脑后神光四边莫触一性圆常 /
一性无性中边绝待大火聚中得大解脱 /

如来设教方便多门庄严梵刹净土净心 /
水月道场空华佛事智悲交融所行无滞 /
建胜幢于处处映帝网于重重量同法界寿等虚空 /

弘誓持正法，护世济民生，兹值灾难剧，舍众忽归真。
敬修释尊教，愿见速转生，德化敷遐迩，国泰天下宁。
