# 蒲室集 · 第十五卷

> 笑隱大訢著

---

野澷澷兮菉葹霜貿貿兮露滋露滋兮匪暘不晞彼羙不見兮以渴以飢 /
湘之涉兮阻且隮挂長蛇兮吼玄羆 /
景翳翳兮歷崦嵫念徂歲兮愆芳期羌不畏乎色 / 󳏭
誰招魂兮若有知遡長風兮覽予懷寄音塵於竹帛兮猶不媚厥姿 /
王之兮參差風之佩兮陸離𧂐 /
芳霏霏兮闖吾帷縆朱弦兮待之娛予之獨兮澹忘 /

耳有聞兮如語目熒熒兮如睹來翩翩兮而欲舉倐而去兮疇與 /
奠蘭烝兮桂酒我祭而享兮尉我荼苦 /
念舊居之衡宇今而乘兮馬泉深兮長溜水翳翳兮隂茂 / 㱕𩣭
孝思兮無斁自我躬兮我後䔍 /

南山兮朝隮夕容與兮水涯復儃兮余次賔而肅之子欵扉 / 󵖕
撫瑤席兮布函文樂無歝兮澹忘不瀆兮去不違 / 㱕𮒸
軼其疆兮猶有畛畦山中之人兮薜蘿衣󳌤 /
游萬物兮守天倪行之獨兮世無知匪雲之從兮其從誰 /

湘之波兮夕風夕風兮龍吟在泓韶之亂兮盈耳接鈞天兮雲中 /
雲毬旓兮葆羽下風肅肅兮雨瀧瀧渺梧江兮涕無從 /
涕漬玉兮爾竹維篁鳳翩翩兮不顧其凰 /
不念先君子勗萬邦

水有源兮木有本我有親兮親沒而不返念我稚子有鬌髧髧 /
俄丱而冠兮歲莫纂纂墓有朽骨兮呼不應 /
河之嚙兮胡不仁幽則鬼兮明則人死生雖異兮豈無其心 /
我親不見兮何有我身我求而獲兮寧有鬼神 /

昔在唐虞比屋可封其民不知倥侗顓蒙五子歌夏 /
常棣詠周漢興孝廉其俗曰偷桒沃而隕泉流而遠 /
歲不我與予懷婉娩親之育我如不保矣我育我貴 /
親之耄矣親疾而呻我痛在腹親喪三年于曰不足 /
我圃我廬于親之居桮棬猶存親食之餘我匪木石 /
念之維何聖訓是則靡知其它事君以忠友弟以愛 /
以吾宗如親之在乃作高門國有令典亦有卿公󸇑 /
釃衎衎高門言言過者必式于以作詩歌之無斁𨣧 /

客去復留客留終去鼉吟夜風鳩乳新雨有匹鳴鳥 /
灌木濟濟豈無交友不如晤語亦有多譽束帛乘馬 /
無爽我懷我疾遄愈 /

雲隮于天倐往而還我行于邁以日以年雲之將雨 /
翳翳其隂孰無父母獨勞我心我次于野飲馬于河 /
載旌揚揚其儀孔多鵬鵾海運豕豢于牢乃分之宜 /
豈曰賢勞占子矣鵲集于桷恩榮于家子有高爵 / 㱕
賜號與秦曳組若若載笑載言與子滿酌 /

爾烝維藉我佩斯紉有肖于德薰然而春匪夷匪惠 /
國士振振高風百世懷哉若人 /

泉之始達維石齧齧不盈缾罌而酌不竭決而之 / 䟽
為江為湖澤及于物不如其初是故君子道不苟售 /
雖有夔臯愧于巢由我石孔貞我泉孔維德似之 / 󷖑
永矢弗渝

風水不可期知君定來否何處唱歌聲月明大谿口 /

適性無廣廈安居自光榮我生亦觧后均爾眾物情 /
方春戒穡事孰謂吾無營濁醪聊自適客至亦共傾 /
喧寂庶可齊所貴吾道貞睠言千載惻惻茲抱盈 / 𨗿

玄運撫八極萬化同其根委佩天池月晞髮扶乘暾 /
仙佛皆幻跡著書亦寓言神交千載上一洗濁世昬 /

歸鳥投故林落葉庇本根人生首丘念所重骨肉恩 /
蜀土昔離亂脫身間道奔及茲承平久慈孝况所敦 /
苦心在丘壠志不慕田園敢辭萬里遠衣薄霜霰繁 /
白首攜仲子斗酒酹幽魂墟里盡荊故老無一存 / 𣗥
幸託賢守令大書刻墓門采詩無國史傳之令子孫 /

故家西江上遊子未成而我豈不懷所慚志多違 / 㱕
十五知好道從師別庭闈朅來苕上寺遭時蹈危機 /
秋風走淮甸晏歲東海涯交情無厚親面諾心已非 /
感子始終意見我無瑕疵愛惡有好醜人孰不自知 /
目覩凌雲質自足為我規况同早入室甚知多令儀 /
前年黨禍作眾潰如星馳老師臥一室四海浮雲悲 /
我時闕服役賴子能扶持子去我始至曾不慰渴飢 /
遂令八十翁落日鄉土思別來鞠再華田圃霜露滋 /
窮檐白日晚苦心徒爾疲感激子遂行信有天下奇 /
草堂白頭親有弟供甘肥敢忘師道尊恩義無或虧 /
意氣重然諾為道况孜孜神機不停佇天馬脫覉 / 𮩸
能不念離索潦倒成荒嬉尺書豈無郵問謁多愧辭 /
我有心與目孰不為鳶母老家亦殫弟妹貧賤離 / 䲭
長絕伯父恩骨朽葬無資天誅不可逭何用涕交頥 /
因子感我私聽歌行步遲誓言如白水我歸豈無期 /

六旬苦不雨寢食不遑安佳人重遠別西風古長于 /
辟書豈無華中臺切雲端執蕳畫諾群彥集孔鸞 / 𮚏
丹心照白日雄辭瀉驚湍所愛溫如玉何湏銕作肝 /
賢才期有用行志良獨難上言保明哲下以濟時艱 /
關陝民食子蜚蝗蔽淮壖便須給餽餉胡能及朝飡 /
維斗不可酌西望銀河乾安得仙人掌盤玉露溥 / 󸈈

豐草霜不死孤陽地中回佳人獨憔悴窮居謝行媒 /
朅來為親友飲馬寒江隈鷄鳴戒蓐食晨發急景催 /
念子孝道每食涕盈腮霜露感祥練聞琴有餘哀䔍 /
我生非人類未可置蒿萊師老不得養疇當恤凶灾 /
尺書那忍寄未語先心摧驪駒且勿歌作詩補南陜 /

中年涉憂患事與壯心違誅茅依磵曲我歸已無時 /
上人受經地遠赴千里期江烟連竹色香露滴薔薇 /
重無拒客政使過門稀只許毘耶老天華不著衣𨵿 /

昔居西巖下茅屋三四間野服愧朝命孤雲不知還 /
使君起西土白晝風景間遠謁承明廬對榮敢犯顏 /
錫燕上林苑筐篚屢所頒高度宜清要蘭基遂通班 /
哦詩泉上寺春溜荅潺潺感予松菊荒日暮思故山 /
公才濟時用我退亦靜留衣從此別勇往無後艱 / 𢢀

吾友瑛與照昨日去霅水竪子語燈火惜別中夜起 /
君來豈有期送迎如聚螘歡笑失窮憂明燭代短晷 /
溪翁樂禪寂文字棄康粃恩公雲門來相向氣劘壘 /
馬鄧列仙癯杜鄭國良士道術有至樂無庸實筐篚 /
不能信留孰有重於此洞庭波如山月出光散綺𪧐 /
高齋桂團團萬卷淨窓几夫各有慮豈為守閭里 / 󷴕

作勞田中酒味薄可漉人生一醉飽良不負吾腹㱕 /
牽携影參差歌吹非有曲流風一胥靡此樂不可復 /
吾人孰非古亦有心與目封倫恨不留重睹貞觀俗 /
昔在唐虞世苗民有不服地墝知良農畜瘠求善牧 /
願持畫史心獻君比和玉朝來愧斯圖惻愴意未足 /

露盤何亭亭高挹南山青南山豈終固托茲金石貞 /
方諸貴同潔九鼎儗或輕芳澤晞朝日恩光照紫庭 /
瓊液寒初凝黃流注不盈我願為膏沐添然一氣清 /
葭既堅落蕭亦滋榮但念括山遠沾衣戒霄征󸈙󸈁 /
仙人餌玉屑游子藜藿情亦欲備甘旨非學長生 / 𨵿

我愛魯司談笑隳三都中流天一柱孰憂顛不扶𭁵 /
使君蘭臺去惡如摧枯利刃剗芽肎顧蔓難圖𫝸󸇧 /
問俗湘水上重吊楚大夫長笛幽憤作落日壯心孤 /
歸舟百靈護風雨聞號呼 /

皎皎瓊林枝一見足良願三年獲周旋臺端肅懲勸 /
野吹結夕隂江烟寒歌長步遲遲庶以展懷戀 / 𭘧𦽦

啄木驚我夢丁丁伐平林書來敘別久長憶倚梧吟 /
重江蛟鰐橫感子遠訪尋氣肅蟄戶閉天高鳥遺音 /
楓林生野吹河漢蕩秋隂相期如古人庶以展我心 /
令躬崇道德不貴玉與金 /

峽冬拖長冰崖滑如積銕客子涕縱橫悲助嗚咽 / 󲞣
仰視浮雲崩再聽蒼石裂不畏行路難但感芳年歇 /

石丈吾畏友此君義不薄寧知是圖畫清風滿丘壑 /

有苾藉芳烝彼羙蒨蒼玉山林雨露深保此媚貞獨 /

萬有一空一空具萬有真宰靜無營大化自樞紐㱕 /

我有錦繡叚翠鯨卷波濤君家古刀尺裁剪不憚勞 /
散作五色雲隨風九天高天高望不極江水日滔滔 /

孔子萬世師委史尚為之吳君學孔氏義盡所當為 /
國用資泉府况復官非卑錢幣有輕重相權酌其宜 /
舟車運四海使命速星馳流行防壅遏新故代有時 /
糜腐炎燎監臨肅官威邇來苦剜偽奸弊日繁滋𢌿 /
閘閱役閭左逃奔困囚纍君才剸煩劇洞照情無遺 /
游刃柝肎綮爬梳理棼絲彊弱均惠施示信明質劑 /
駢羅紛碎不異貝與龜貿易欣所獲童稚莫或欺𤨏 /
巨賈或深藏或負歌而嘻互市置酒慶父老再陳辭 /
郡樂僚友飛章省與臺為政盡如此寧憂事不治󳹳 /
陳平宰天下分杜先自期况君早榮遇陪直通金閨 /
晶熒瑚璉器淩厲青雲姿壯業知不負祖張書吾詩 /

鼓琴由藝進讀書以學博過耳音不留空言亦奚託 /
千古會吾心於焉有真樂雨過晚凉生臨池看魚躍 /

舜琴解民慍象傲未必悛周公賦棠棣莫釋管蔡冤 /
不齊物之情大聖何能全鎦氏陵秀詩禮世蟬聮 / 󸈤
討論自師友萬卷金縣所適况吾土山水清而妍 / 󸈠
鳴悅佳頳尾便漪漣富貴苦憂患皆由外物遷󸅸䕃 /
漂泊悲夜雨遠征愧飛鳶怡愉有至樂孰若斯堂賢 /
一翁與二季也敢獨專聮璧上金榜側耳鴻臚傳 / 󷑐

遠山如故人夢寐思見之見之了非夢十居可無期 /
乃知畫者意善幻牽吾思居然磵之曲彎碕俯茅茨 /
川容得春媚渙渙流晴澌魚罟散蓬藋鹿疃縱橫馳 /
澄江起暮色客袂風凄其所歷紛可數身世亦足悲 /
百年俱幻境對此奚獨疑 /

臥病長江上朔風撼我床坭垣壞積雨弱柳空自長 /
猶懷嵩璉何曾羨奎章白壁忍橫道千金戒垂堂㱕 /
鳳皇五色羽風雨傷摧殘坐視不遑恤百憂如驚湍 /
我夜不得寢我食不得飡因知古人意相戒行路難 /

鵾鵬雖鉅物為瑞不如鳳五金利而堅良王世所重 /
古來德輔時不必俗用公德配古人文藝復掩眾 / 󷰬
前驅失班揚後顧無屈宋譬之武事嚴萬甲卷殽雍 /
往年試春闈對筞天威動烈風挾長波電影掠飛鞚 /
稱此衣繡榮人品賴飄綜任眾難獨專桷襍楹棟 / 󲵋
分憲得問俗施惠徵前痛積水散鳧鷖良疇沒菰葑 /
飛章檡守令邦賦足輸貢懷德民不欺率教童知誦 /
平生許經濟無由預賓從方外亦何有天地一空洞 /
所慚世嬰不虞禍機中車僨長途暮舟哀壑凍䌉󲐤 /
甘澤被污萊巨照燭昏瞢乞退悔苦晚誰無鉢飯供 /
願從金華山芋區荒可種更憐長公忍別阻追送 / 󷑐
短歌愧知己空懷好音哢 /

呼韓欵塞稱藩臣已知絕漠無王庭馳突猶漢使者 / 𡘆
縱馬夜出居延城我有飲器非飲酒開凾視之萬鬼走 /
世世無忘頓功月支強王頭在手悵下朔風吹酒寒󰂛 /
凝酥點雪紅斕班想見長纓繫馬上髑髏濺血如奔湍 /
手麾欲回斗杓轉河決崑崙注尊滿酒酣劒吼浮雲悲 /
使者辭歡就舘古稱尊獻孰知盟誓生戈矛㱕󸆁𬾨󷽡 /
斬取樓蘭縣漢功臣猶數義陽󸇳𬾃 /

海門五月潮如山龍伯奰蒼蛟頑越俗輕生好巫鬼 / 𭕘
婆娑踏舞洪濤間群巫姣服盱獨好歌聲忽絕紅旗倒 /
孝娥死父屍出天地無情日杲杲雄詞不愧邯鄲兒𢬘 /
萬金莫購中郎題碑隂八字非隱語德祖有智如滑稽 /
豈是阿瞞不解此感媿上馬路迷女德猶能奮其節 / 㱕
壯夫氣吐萬丈霓奸雄復欲欺後世白頭猶愛漢征西 /
丹青似是董狐筆千年要與竹帛齊 /
娥江新廟照江水可憐銅爵草萋萋 /

我本白雲人見山每回首披圖得松泉感我塵埃久 /

我家只在九江口從此扁舟到牛斗翻愁天上銀濤堆 /
石轉雲崩萬雷吼水行地底不上天龍泓豈與滄溟連 /
風葉無聲飛鳥絕月光雲影天茫然丈人何來自空谷 /
謫僊招隱當不辱林稍噴雪舞飛華尚想隨風唾珠玉 /
馬首青山如喚人來好及松華春 / 㱕

觧公頭上巾今者孰不樂荒墤委荊遂令畫師意 / 󸆼
萬古留酸辛酸辛復何益東海飛紅塵 /

世無伯樂亦久矣駿馬何由千里至披圖猶似得權奇 /
豈伊畫師知馬意何人致此銕色驪毛繞腹新蹄 / 󲣿𮢶
帝閑遠謫天駟下馳來月窟浮雲低古王有土數千里 /
八極周游寧用爾方今萬國效奔命合遣龍媒獻天子 /
飈馳電沒爭辟易萬里所向無前敵男兒馬上定乾坤 /
腐儒詩書果何益幾愁骨折青海烟黃沙野雪穹廬前 /
幸逢好事真傳似向長鳴誰與憐𭂁 /
嗟我身如倦飛鳥十年繭足愁山川安得千金購神駿 /
攬轡欲盡東南天

憶昔壯年游東溟大舩椎鼓江上行天女吹華龍象舞 /
風水夜作蛟鮀驚浩歌聲戞牛斗上百年有志非功名 /
箋經肎讓甘露上書獨許嵩仲靈青春悠悠去不返󷓟 /
萬里孤蓬尚漂轉可憐歲晚長于城冰雪連天江漢遠 /
紫雲如盖青石寒必逢勝處一解顏平生始識周處士 /

師年八十不可待又欲為母營朝餐况聞大法可痛哭 /

## 大元廣智金悟大禪師太中大夫住太龍翔集慶寺

自太慧果禪師大弘臨濟之宗於東南晚得佛照光以為之嗣北磵簡傳之至物初觀而得晦機熙公江南既歸國朝禪宗尊共扶其道者數公而已晦機充以老成為國柱右隆然繼之名稱普聞於天下者則廣智全悟大禪師訢公其人也公諱大訢字笑隱姓陳氏本九江義門唐尚書操諸孫分居南昌先墓有豫章之木持異神於相地者占之曰是當生奇男子為名僧其道大行樹枯其徵也已而果然師生於至元甲申八月二十七日生之夕所居宅地若震動人為驚異稍長入鄉校穎悟過常兒書過眼轉成誦其親以出游至佛寺必瞻拜戀慕不能去父母知其忘俾從伯氏之為僧於郡城水陸院法雲者九年雲之徒彰為薙髮受具戒居八年學問日廣知求佛法大意一山萬公住廬山之開先即徃見焉時年十七山一見留之左右日夕警誨歎曰吾友晦機在百丈子欲諮決究竟非見吾友不可師稟命詣百丈晦機識其奇偉於眉睫間即使侍方丈他日謂之曰昔黃龍得旨泐潭領徒游方及見慈明氣索汙下汝且道過在甚處語未絁師抗聲曰千年桃核裏覓甚舊時仁久之俾掌書記一日舉百丈野狐話問之師擬議晦機震威一喝師於是群疑頓釋得無礙智同參苦咨問之師後有頌云百丈野狐野狐百丈埋著一坑伏惟尚享諸方多誦之晦機一日定中見天門有榜師名為首因謂師曰昔東山祖有言我不得勤遠則負慈明矣汝善保任乎晦機遷淨慈師從之仍以為書記晦機說法文理精詣甞謂師曰昔雪竇真淨及我妙喜以來內自教乘傍及儒老子百家之言深入要眇故其文言浩乎如川至之不可禦也師神觀高邁音吐如洪鐘素以博洽聞至其辨論古今如指諸掌執筆書事文士良史莫或過之一時名勝如恩斷江如一溪茂古林宣無言卓有行業皆與師為忘年交本中峯居天目山之師子嚴中外信向甚盛師甞謁之語至夜參半忽大風厓石欲堕左右辟易師危坐如平時峰亦服其定力矣而學士大夫如吳興趙文敏公孟頫已西鄧康莊公文原四明袁文清公桷房山高公彥敬東陽胡長孺汲仲錢唐仇遠近仁延祐進士莆城禓載仲金華黃溍溍鄉及今翰林待制京兆社本伯原前後負時盛名與師為文學之友者也晦機著萬一山銘屬師代作請文敏公書之公一見大驚異以為真得古文法公為杭州僧作顯教院記亦屬師代之及成不易一字署己名以書至大辛亥初受請住湖州之鳥回祝香之次諸山咸歎晦機之得人矣大報國寺者回宋故宮而為之延祐庚申灾諸剎尊共迎師起癈未從也趙公為親作以請既至大作新之寺田之在宜興者連歲不入師為歸其侵始有以食其眾江淛行省丞相脫歡公故荅剌順德王之子也以世勛名德靖重知大體兼行宣政院事領東南浮圖之教凢大剎非名德不輕授特請師住中天竺人無間言而師名日起矣天曆初元師夢神龍騰空覺而異之作偈以識既而天子以金陵潛邸作大龍翔集慶寺命江南行御史臺督視其成甞有曰江南大剎皆前代所為甲乙之次頗有定品今日之作規制位望冝無加焉方大臣難於開法主者師之器量久在淵衷命為太中大夫號曰廣智全悟大禪師為開山弟一代師恢弘鬯達汎應無滯偉然江海之上舒卷自在不偏於空寂又明年與蔣山曇芳忠俱召至京師京師之為禪宗者出迎河上曰國家尚教乘廟之建為禪者寂然禪剎興於今代自師始吾徒賴焉師謝曰遵其行之為律宣其言之為教傳其心之為禪有言有行皆所以明是心也吾徒無負祖師西來意它不足論也日召對奎章閣賜坐說佛心要深契上旨舘於太禧宗禋院勑設伊蒲妙饌賜貂裘金衲衣及諸金幣皆內府珍異上甞知師所為文曰蒲室集者命昭孝寺大司徒法洪取進法洪亦博洽內外典深為講達上問師嗣法何人曰元熙也因其道業源委上嘉歎命學士虞集製銘賜之居十日中使問尉洽至請還從之賜中天竺名曰天曆永祚寺而命師之菴居曰廣智皆命虞集為之書祖道於城南僧舍凢食設皆貴臣以上旨為之主上之眷斯寺也外以臺臣護視使者從中來賜與無虛月皇上至元二年以老病求退御史大夫撒迪公以聞優詔不許加號釋教宗主兼領五山寺餘如故而賜予尤厚匡匪之頒徧及寺眾勑外臺護視使安居而終老焉先百丈有禪清規其徒遵用之甞有旨命師脩改乃分為九章今行焉於是中朝西域高昌三韓滇池于闐與湖江淮漢蜀閩廣之俊傑四面而至法席莫尚焉師之居於是也自中朝外藩臺閣風紀貴人名公卿至者莫不頎盖為禮非人力所能致也而文詞語言流傳四方震蕩耳目亦顧雄發於一時矣初給錢為中鈔者二十萬緡設官領之取子錢以為食後癈其官以歸寺之人出納為息不能盡一稍病之至正元年勑有司市民良田以傳寺歲賦粟以食公私無所係累歎曰吾徒庶晏佚一搏於朝夕吾亦老且休矣四年五月一日為文書請以徑山忠曇芳代己升堂擊鼓辭眾退居廣智菴居兼旬肩輿與御史大夫脫歡公為別留書凢與交游之善者命弟子兩朝賜己金弊等以付寺僧俾營萬佛閣以報國恩既乃臥示疾明且天大風雨白晝變暝召入室弟子各加勉諭從容作偈儼然而逝是月廿四日壬子也得年六十一僧臘四十六初龍翔寺成營三於石頭城之東岡弟子龕奉全身措於院自憲臺郡縣大小吏士緇素老送者萬眾隂雲四興涼颸泄然行者不知暑眾散始罷八月礱石為坎於石城之岡十六日奉而藏焉表浮圖於其上其徒之在杭州報國永祚者又奉師遺齒髮而於鳳皇山師四會說法皆有語錄提頌敘說宗旨外集詩文若干卷即所謂蒲室集者也度弟子若干人傳法住山者若干人師性至孝父母蚤卒母蕭氏方盛年即持齊念佛以居師受請報國時母率餘子薦新祖考庭前忽生華形如白蓮盖芝類也鄉人聚觀香色彌月不減占者以為師之瑞應也師雖不得至左右而心常不忘目其文曰蒲室者所以識宗家睦州織鞋為養之故事也故其為文為人子言必曰孝為人臣言必曰忠為朋友之交言必曰信至語其徒脫愛冈離無明直指本性以悟為則誘掖以進之激昂以發之奮迅以决之機用迭發政令獨行其門人以所得各有記可考也噫人才實難江濤眇然居忌不恒能靜以應向使不為方外之歸亦足以用世者予與師相知四十年見師身受龍翔之寄至于今十有七載歸老江上亦十二年向與交游者皆已矣弟子懷渭本其甥也清脩善學有舅氏之風渭之為名亦所以識也以其同門之意使予書其遺事可勝慨乎乃述曰維昔至元皇有南服神明合完生息來復預章楩楠殿於湖江幹立條揚乃發駿厖文林蕭條靡契嘉會肆其脩能求法方外達磨傳心別濟為宗至妙喜天縱橫朗融遠紹緒流必有惠辯惟全悟師弘偉超鍊四坐道塲說法沛然吐辭湧泉如洪如元衛法如嵩不咈明教織蒲養親睦州之孝表裏東南捴于金陵皇作梵宮龍翔是徵崇臺在焉耳目攸寄以領佛事孰克堪是鼓鐘震驚龍象人天岳峙山連莫之雄先金具珠璧園林澤道護萬福好爵嘉錫宣其惠慈作新成規來嚮來參雲奔海馳皇仁如天函覆如一俾善其眾休燕以室風雨漂搖安如須彌生去來何足控持既念故交違越年歲訊諸門人以作斯記前奎章閣侍書學士翰林侍講學士通奉大夫知制誥兼脩國史蜀郡虞集記𪧐󵈢𪪺󷘳𪧐󸇿𦉴𭥍󷘳𮚏󴌞𨵿𰭵𮈒󸇿𥁞󷘳󷘳󸅵𤓰󷘳󵗡𥁞𮚏󴌞󷓟
