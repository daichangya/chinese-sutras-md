# 蒲室集 · 第十五卷

> 笑隐大䜣着

野澷澷兮菉葹霜贸贸兮露滋露滋兮匪旸不晞彼羙不见兮以渴以饥 /
湘之涉兮阻且𬯀挂长蛇兮吼玄罴 /
景翳翳兮历崦嵫念徂岁兮愆芳期羌不畏乎色 / 󳏭
谁招魂兮若有知溯长风兮览予怀寄音尘于竹帛兮犹不媚厥姿 /
王之兮参差风之佩兮陆离𧂐 /
芳霏霏兮闯吾帷縆朱弦兮待之娱予之独兮澹忘 /

耳有闻兮如语目荧荧兮如睹来翩翩兮而欲举倐而去兮畴与 /
奠兰烝兮桂酒我祭而享兮尉我荼苦 /
念旧居之衡宇今而乘兮马泉深兮长溜水翳翳兮隂茂 / 㱕𩣭
孝思兮无斁自我躬兮我后䔍 /

南山兮朝𬯀夕容与兮水涯复儃兮余次賔而肃之子欵扉 / 󵖕
抚瑶席兮布函文乐无歝兮澹忘不渎兮去不违 / 㱕𮒸
轶其疆兮犹有畛畦山中之人兮薜萝衣󳌤 /
游万物兮守天倪行之独兮世无知匪云之从兮其从谁 /

湘之波兮夕风夕风兮龙吟在泓韶之乱兮盈耳接钧天兮云中 /
云毬旓兮葆羽下风肃肃兮雨泷泷渺梧江兮涕无从 /
涕渍玉兮尔竹维篁凤翩翩兮不顾其凰 /
不念先君子勗万邦

水有源兮木有本我有亲兮亲没而不返念我稚子有鬌髧髧 /
俄丱而冠兮岁莫纂纂墓有朽骨兮呼不应 /
河之啮兮胡不仁幽则鬼兮明则人死生虽异兮岂无其心 /
我亲不见兮何有我身我求而获兮宁有鬼神 /

昔在唐虞比屋可封其民不知倥侗颛蒙五子歌夏 /
常棣咏周汉兴孝廉其俗曰偷桒沃而陨泉流而远 /
岁不我与予怀婉娩亲之育我如不保矣我育我贵 /
亲之耄矣亲疾而呻我痛在腹亲丧三年于曰不足 /
我圃我庐于亲之居桮棬犹存亲食之余我匪木石 /
念之维何圣训是则靡知其它事君以忠友弟以爱 /
以吾宗如亲之在乃作高门国有令典亦有卿公󸇑 /
酾衎衎高门言言过者必式于以作诗歌之无斁𨠨 /

客去复留客留终去鼍吟夜风鸠乳新雨有匹鸣鸟 /
灌木济济岂无交友不如晤语亦有多誉束帛乘马 /
无爽我怀我疾遄愈 /

云𬯀于天倐往而还我行于迈以日以年云之将雨 /
翳翳其隂孰无父母独劳我心我次于野饮马于河 /
载旌扬扬其仪孔多鹏鹍海运豕豢于牢乃分之宜 /
岂曰贤劳占子矣鹊集于桷恩荣于家子有高爵 / 㱕
赐号与秦曳组若若载笑载言与子满酌 /

尔烝维藉我佩斯纫有肖于德薰然而春匪夷匪惠 /
国士振振高风百世怀哉若人 /

泉之始达维石啮啮不盈缾罂而酌不竭决而之 / 䟽
为江为湖泽及于物不如其初是故君子道不苟售 /
虽有夔臯愧于巢由我石孔贞我泉孔维德似之 / 󷖑
永矢弗渝

风水不可期知君定来否何处唱歌声月明大谿口 /

适性无广厦安居自光荣我生亦觧后均尔众物情 /
方春戒穑事孰谓吾无营浊醪聊自适客至亦共倾 /
喧寂庶可齐所贵吾道贞睠言千载恻恻兹抱盈 / 𨗿

玄运抚八极万化同其根委佩天池月晞发扶乘暾 /
仙佛皆幻迹著书亦寓言神交千载上一洗浊世昬 /

归鸟投故林落叶庇本根人生首丘念所重骨肉恩 /
蜀土昔离乱脱身间道奔及兹承平久慈孝况所敦 /
苦心在丘垅志不慕田园敢辞万里远衣薄霜霰繁 /
白首携仲子斗酒酹幽魂墟里尽荆故老无一存 / 𣗥
幸托贤守令大书刻墓门采诗无国史传之令子孙 /

故家西江上游子未成而我岂不怀所惭志多违 / 㱕
十五知好道从师别庭闱朅来苕上寺遭时蹈危机 /
秋风走淮甸晏岁东海涯交情无厚亲面诺心已非 /
感子始终意见我无瑕疵爱恶有好丑人孰不自知 /
目覩凌云质自足为我规况同早入室甚知多令仪 /
前年党祸作众溃如星驰老师卧一室四海浮云悲 /
我时阙服役赖子能扶持子去我始至曾不慰渴饥 /
遂令八十翁落日乡土思别来鞠再华田圃霜露滋 /
穷檐白日晚苦心徒尔疲感激子遂行信有天下奇 /
草堂白头亲有弟供甘肥敢忘师道尊恩义无或亏 /
意气重然诺为道况孜孜神机不停伫天马脱覉 / 𮩸
能不念离索潦倒成荒嬉尺书岂无邮问谒多愧辞 /
我有心与目孰不为鸢母老家亦殚弟妹贫贱离 / 䲭
长绝伯父恩骨朽葬无资天诛不可逭何用涕交頥 /
因子感我私听歌行步迟誓言如白水我归岂无期 /

六旬苦不雨寝食不遑安佳人重远别西风古长于 /
辟书岂无华中台切云端执𫈉画诺群彦集孔鸾 / 𮚏
丹心照白日雄辞泻惊湍所爱温如玉何湏銕作肝 /
贤才期有用行志良独难上言保明哲下以济时艰 /
关陕民食子蜚蝗蔽淮壖便须给餽饷胡能及朝飡 /
维斗不可酌西望银河干安得仙人掌盘玉露溥 / 󸈈

丰草霜不死孤阳地中回佳人独憔悴穷居谢行媒 /
朅来为亲友饮马寒江隈鸡鸣戒蓐食晨发急景催 /
念子孝道每食涕盈腮霜露感祥练闻琴有余哀䔍 /
我生非人类未可置蒿莱师老不得养畴当恤凶灾 /
尺书那忍寄未语先心摧骊驹且勿歌作诗补南陜 /

中年涉忧患事与壮心违诛茅依磵曲我归已无时 /
上人受经地远赴千里期江烟连竹色香露滴蔷薇 /
重无拒客政使过门稀只许毘耶老天华不着衣𨵿 /

昔居西岩下茅屋三四间野服愧朝命孤云不知还 /
使君起西土白昼风景间远谒承明庐对荣敢犯颜 /
锡燕上林苑筐篚屡所颁高度宜清要兰基遂通班 /
哦诗泉上寺春溜荅潺潺感予松菊荒日暮思故山 /
公才济时用我退亦静留衣从此别勇往无后艰 / 𢢀

吾友瑛与照昨日去霅水竖子语灯火惜别中夜起 /
君来岂有期送迎如聚螘欢笑失穷忧明烛代短晷 /
溪翁乐禅寂文字弃康粃恩公云门来相向气劘垒 /
马邓列仙癯杜郑国良士道术有至乐无庸实筐篚 /
不能信留孰有重于此洞庭波如山月出光散绮𪧐 /
高斋桂团团万卷净窓几夫各有虑岂为守闾里 / 󷴕

作劳田中酒味薄可漉人生一醉饱良不负吾腹㱕 /
牵携影参差歌吹非有曲流风一胥靡此乐不可复 /
吾人孰非古亦有心与目封伦恨不留重睹贞观俗 /
昔在唐虞世苗民有不服地墝知良农畜瘠求善牧 /
愿持画史心献君比和玉朝来愧斯图恻怆意未足 /

露盘何亭亭高挹南山青南山岂终固托兹金石贞 /
方诸贵同洁九鼎儗或轻芳泽晞朝日恩光照紫庭 /
琼液寒初凝黄流注不盈我愿为膏沐添然一气清 /
葭既坚落萧亦滋荣但念括山远沾衣戒霄征󸈙󸈁 /
仙人饵玉屑游子藜藿情亦欲备甘旨非学长生 / 𨵿

我爱鲁司谈笑隳三都中流天一柱孰忧颠不扶𭁵 /
使君兰台去恶如摧枯利刃刬芽肎顾蔓难图𫝸󸇧 /
问俗湘水上重吊楚大夫长笛幽愤作落日壮心孤 /
归舟百灵护风雨闻号呼 /

皎皎琼林枝一见足良愿三年获周旋台端肃惩劝 /
野吹结夕隂江烟寒歌长步迟迟庶以展怀恋 / 𭘧𦽦

啄木惊我梦丁丁伐平林书来叙别久长忆倚梧吟 /
重江蛟鳄横感子远访寻气肃蛰户闭天高鸟遗音 /
枫林生野吹河汉荡秋隂相期如古人庶以展我心 /
令躬崇道德不贵玉与金 /

峡冬拖长冰崖滑如积銕客子涕纵横悲助呜咽 / 󲞣
仰视浮云崩再听苍石裂不畏行路难但感芳年歇 /

石丈吾畏友此君义不薄宁知是图画清风满丘壑 /

有苾藉芳烝彼羙蒨苍玉山林雨露深保此媚贞独 /

万有一空一空具万有真宰静无营大化自枢纽㱕 /

我有锦绣叚翠鲸卷波涛君家古刀尺裁剪不惮劳 /
散作五色云随风九天高天高望不极江水日滔滔 /

孔子万世师委史尚为之吴君学孔氏义尽所当为 /
国用资泉府况复官非卑钱币有轻重相权酌其宜 /

糜腐炎燎监临肃官威迩来苦剜伪奸弊日繁滋𢌿 /
闸阅役闾左逃奔困囚累君才剸烦剧洞照情无遗 /

骈罗纷碎不异贝与龟贸易欣所获童稚莫或欺𤨏 /

郡乐僚友飞章省与台为政尽如此宁忧事不治󳹳 /

鼓琴由艺进读书以学博过耳音不留空言亦奚托 /

鸣悦佳頳尾便漪涟富贵苦忧患皆由外物迁󸅸䕃 /

卧病长江上朔风撼我床坭垣坏积雨弱柳空自长 /

我夜不得寝我食不得飡因知古人意相戒行路难 /

鹍鹏虽巨物为瑞不如凤五金利而坚良王世所重 /

於穆圣祖如天之临维佛大圣克恊帝心帝心于人一视同体设教多岐趋善一轨佛光之道闻于朔方受命于南隂时康乃升高坐乃钟鼓以诱以谕有来如雨内默斯照外应斯虚徃复无朕寂用一如境变万殊其立也独匪留而久匪逝而速长于之麓牛首如伏后人是瞻于曰不足孰图师恩刻石于原维其似之庶几不泯𮚏𦒱

## 大元广智金悟大禅师太中大夫住太龙翔集庆寺

自太慧果禅师大弘临济之宗于东南晚得佛照光以为之嗣北磵简传之至物初观而得晦机熙公江南既归国朝禅宗尊共扶其道者数公而已晦机充以老成为国柱右隆然继之名称普闻于天下者则广智全悟大禅师䜣公其人也公讳大䜣字笑隐姓陈氏本九江义门唐尚书操诸孙分居南昌先墓有豫章之木持异神于相地者占之曰是当生奇男子为名僧其道大行树枯其征也已而果然师生于至元甲申八月二十七日生之夕所居宅地若震动人为惊异稍长入乡校颖悟过常儿书过眼转成诵其亲以出游至佛寺必瞻拜恋慕不能去父母知其忘俾从伯氏之为僧于郡城水陆院法云者九年云之徒彰为薙发受具戒居八年学问日广知求佛法大意一山万公住庐山之开先即徃见焉时年十七山一见留之左右日夕警诲叹曰吾友晦机在百丈子欲咨决究竟非见吾友不可师禀命诣百丈晦机识其奇伟于眉睫间即使侍方丈他日谓之曰昔黄龙得旨泐潭领徒游方及见慈明气索污下汝且道过在甚处语未𫄟师抗声曰千年桃核里觅甚旧时仁久之俾掌书记一日举百丈野狐话问之师拟议晦机震威一喝师于是群疑顿释得无碍智同参苦咨问之师后有颂云百丈野狐野狐百丈埋着一坑伏惟尚享诸方多诵之晦机一日定中见天门有榜师名为首因谓师曰昔东山祖有言我不得勤远则负慈明矣汝善保任乎晦机迁净慈师从之仍以为书记晦机说法文理精诣甞谓师曰昔雪窦真净及我妙喜以来内自教乘傍及儒老子百家之言深入要眇故其文言浩乎如川至之不可御也师神观高迈音吐如洪钟素以博洽闻至其辨论古今如指诸掌执笔书事文士良史莫或过之一时名胜如恩断江如一溪茂古林宣无言卓有行业皆与师为忘年交本中峰居天目山之师子严中外信向甚盛师甞谒之语至夜参半忽大风厓石欲堕左右辟易师危坐如平时峰亦服其定力矣而学士大夫如吴兴赵文敏公孟𫖯已西邓康庄公文原四明袁文清公桷房山高公彦敬东阳胡长孺汲仲钱唐仇远近仁延祐进士莆城禓载仲金华黄溍溍乡及今翰林待制京兆社本伯原前后负时盛名与师为文学之友者也晦机着万一山铭属师代作请文敏公书之公一见大惊异以为真得古文法公为杭州僧作显教院记亦属师代之及成不易一字署己名以书至大辛亥初受请住湖州之鸟回祝香之次诸山咸叹晦机之得人矣大报国寺者回宋故宫而为之延祐庚申灾诸刹尊共迎师起癈未从也赵公为亲作以请既至大作新之寺田之在宜兴者连岁不入师为归其侵始有以食其众江淛行省丞相脱欢公故荅剌顺德王之子也以世勋名德靖重知大体兼行宣政院事领东南浮图之教凢大刹非名德不轻授特请师住中天竺人无间言而师名日起矣天历初元师梦神龙腾空觉而异之作偈以识既而天子以金陵潜邸作大龙翔集庆寺命江南行御史台督视其成甞有曰江南大刹皆前代所为甲乙之次颇有定品今日之作规制位望冝无加焉方大臣难于开法主者师之器量久在渊衷命为太中大夫号曰广智全悟大禅师为开山弟一代师恢弘鬯达泛应无滞伟然江海之上舒卷自在不偏于空寂又明年与蒋山昙芳忠俱召至京师京师之为禅宗者出迎河上曰国家尚教乘庙之建为禅者寂然禅刹兴于今代自师始吾徒赖焉师谢曰遵其行之为律宣其言之为教传其心之为禅有言有行皆所以明是心也吾徒无负祖师西来意它不足论也日召对奎章阁赐坐说佛心要深契上旨馆于太禧宗禋院𠡠设伊蒲妙馔赐貂裘金衲衣及诸金币皆内府珍异上甞知师所为文曰蒲室集者命昭孝寺大司徒法洪取进法洪亦博洽内外典深为讲达上问师嗣法何人曰元熙也因其道业源委上嘉叹命学士虞集制铭赐之居十日中使问尉洽至请还从之赐中天竺名曰天历永祚寺而命师之庵居曰广智皆命虞集为之书祖道于城南僧舍凢食设皆贵臣以上旨为之主上之眷斯寺也外以台臣护视使者从中来赐与无虚月皇上至元二年以老病求退御史大夫撒迪公以闻优诏不许加号释教宗主兼领五山寺余如故而赐予尤厚匡匪之颁徧及寺众𠡠外台护视使安居而终老焉先百丈有禅清规其徒遵用之甞有旨命师修改乃分为九章今行焉于是中朝西域高昌三韩滇池于阗与湖江淮汉蜀闽广之俊杰四面而至法席莫尚焉师之居于是也自中朝外藩台阁风纪贵人名公卿至者莫不颀盖为礼非人力所能致也而文词语言流传四方震荡耳目亦顾雄发于一时矣初给钱为中钞者二十万缗设官领之取子钱以为食后癈其官以归寺之人出纳为息不能尽一稍病之至正元年𠡠有司市民良田以传寺岁赋粟以食公私无所系累叹曰吾徒庶晏佚一搏于朝夕吾亦老且休矣四年五月一日为文书请以径山忠昙芳代己升堂击鼓辞众退居广智庵居兼旬肩舆与御史大夫脱欢公为别留书凢与交游之善者命弟子两朝赐己金弊等以付寺僧俾营万佛阁以报国恩既乃卧示疾明且天大风雨白昼变暝召入室弟子各加勉谕从容作偈俨然而逝是月廿四日壬子也得年六十一僧腊四十六初龙翔寺成营三于石头城之东冈弟子龛奉全身措于院自宪台郡县大小吏士缁素老送者万众隂云四兴凉飔泄然行者不知暑众散始罢八月砻石为坎于石城之冈十六日奉而藏焉表浮图于其上其徒之在杭州报国永祚者又奉师遗齿发而于凤皇山师四会说法皆有语录提颂叙说宗旨外集诗文若干卷即所谓蒲室集者也度弟子若干人传法住山者若干人师性至孝父母蚤卒母萧氏方盛年即持齐念佛以居师受请报国时母率余子荐新祖考庭前忽生华形如白莲盖芝类也乡人聚观香色弥月不减占者以为师之瑞应也师虽不得至左右而心常不忘目其文曰蒲室者所以识宗家睦州织鞋为养之故事也故其为文为人子言必曰孝为人臣言必曰忠为朋友之交言必曰信至语其徒脱爱冈离无明直指本性以悟为则诱掖以进之激昂以发之奋迅以决之机用迭发政令独行其门人以所得各有记可考也噫人才实难江涛眇然居忌不恒能静以应向使不为方外之归亦足以用世者予与师相知四十年见师身受龙翔之寄至于今十有七载归老江上亦十二年向与交游者皆已矣弟子怀渭本其甥也清修善学有舅氏之风渭之为名亦所以识也以其同门之意使予书其遗事可胜慨乎乃述曰维昔至元皇有南服神明合完生息来复预章楩楠殿于湖江干立条扬乃发骏厖文林萧条靡契嘉会肆其修能求法方外达磨传心别济为宗至妙喜天纵横朗融远绍绪流必有惠辩惟全悟师弘伟超炼四坐道塲说法沛然吐辞涌泉如洪如元卫法如嵩不咈明教织蒲养亲睦州之孝表里东南捴于金陵皇作梵宫龙翔是征崇台在焉耳目攸寄以领佛事孰克堪是鼓钟震惊龙象人天岳峙山连莫之雄先金具珠璧园林泽道护万福好爵嘉锡宣其惠慈作新成规来向来参云奔海驰皇仁如天函复如一俾善其众休燕以室风雨漂摇安如须弥生去来何足控持既念故交违越年岁讯诸门人以作斯记前奎章阁侍书学士翰林侍讲学士通奉大夫知制诰兼修国史蜀郡虞集记𪧐󵈢𪪺󷘳𪧐󸇿𦉴𭥍󷘳𮚏󴌞𨵿𰭵𮈒󸇿𥁞󷘳󷘳󸅵𤓰󷘳󵗡𥁞𮚏󴌞󷓟
