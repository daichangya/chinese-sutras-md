# 圆通三慧大斋道场仪 · 第九卷

> 宋 侯溥作　侯冲整理

观音胜会启坛场，密咒柴油水米香。 /
安息飞烟云雾卷，兰膏发熖慧灯光。 /
缁流济济皆精洁，贤圣巍巍尽赞扬。 /
法雨满空甘露洒，道场无处不清凉。 /

观音感验难思议，能与众生作福缘。 /
柴油净水诵真言，所冀吉蠲无触秽。 /

压油纵有伤生悮，破暗宁无利物心。 /
更凴秘密作加持，烁破群昏无限量。 /

妙湛灵源常混混，真空性水自渊渊。 /
众生无始妄情昏，普愿沾濡心垢净。 /

佛世比丘烧沉水，香严闻已悟圆通。 /
檀那敬请圣观音，拙具罗香凴此咒。 /

心地清凉由法力，色身安快仗资粮。 /
我今称赞此密言，菩萨天人常赐我。 /

身口意业本来同，一念迷真失本宗。 /
喝散障云无点翳，一轮杲日照长空。 /

闻法欢喜赞，乃至发一言， /
则为已供养，一切三世佛。 /

八功德水自天真，善洗众生业垢尘。 /
流入毘卢华藏界，个中无处不超伦。 /

聚沙成塔亘青天，举指分明在目前。 /
法界荡无尘一点，自然涌出一枝莲。 /

五分法身真妙香，人人具足露堂堂。 /
无根树下亲拈出，供养圆通大法王。 /

荆棘林中业火生，经由大地任纵横。 /
金刚界出摩诃力，直向如来行处行。 /

揭谛揭谛四天王，统领鬼兵降道场。 /
守护东西南北去，邪魔外道悉逃亡。 /

一花五叶祖师传，浅白深红有万般。 /
宴座岩前无说处，纷纷坠落紫云端。 /

顶螺青绀云盘翠，肉髻珠红果艳分。 /
照曜朦胧五彩明，当空宛转千花秀。 /

菩萨修行愿力深，光明山上运悲心。 /
云铺碧落兴慈意，潮震沧溟吐梵音。 /
千贝辐轮文紫玉，万题胸字色黄金。 /
耳通眼慧希昭鉴，此日香坛伫降临。 /

水澄秋月现，恳祷福田僧。 /
惟有佛菩萨，是真归仗处。 /

道场清净众，各各当至心。 /
至心勤皈依，至心勤礼拜。 /
大圣大慈悲，观世音菩萨。 /
惟有观世音，能延人寿命。 /
惟有观世音，能延人福禄。 /
是故我等众，今日须控告。 /
惟愿圣慈悲，开受我等请。 /
令我寿命长，永修一切善。 /
令我福禄盛，厚结一切缘。 /
今日已往去，永不复退转。 / 二说

惟有观世音，灵功被幽显。 /
惟有观世音，誓度诸有情。 /
是故我等众，今日须控告。 /
唯愿圣慈悲，开受我等请。 /
令我所荐严，承此妙善力。 /
往生光明山，亲礼紫金容。 /
日闻微妙法，超证最上乘。 /
今日已往去，永不复退转。 /

警策诸人切至诚，制心一处善芽生。 /
凡夫境界尘埋没，佛法门庭路坦平。 /
速舍魔王烦恼窟，求登大觉涅槃城。 /
齐称偈赞，合掌听宣治路明。祈延寿伸追荐 /

山号光明小白花，石阶舍利产灵芽。 /
八功德水清堪玩，五色祥云翠可夸。 /
玛瑙阶前排宝树，琉璃池畔映金沙。 /
天香间发鸣仙乐，菩萨毫光散彩霞。 /

观音住在补陀山，自在逍遥日月闲。 /
自把数珠还自念，慈观诸趣复慈颜。 /
神通游戏诸三昧，相好端严四八般。 /
大众返闻闻自性，相逢衹在刹那间。 /

观音古佛大慈悲，权现菩提萨埵仪。 /
足下黄金千辐相，顶门心月一双眉。 /
初回启请蒙垂降，合掌虔诚再祷祈。 /
欲请上乘狮子座，先持启白陀罗尼。 /

《楞严经》说圣观音，能接众生入觉林。 /
真观既同清净观，梵音无异海潮音。 /
铁轮磨顶情非舍，金鉴为怀誓不成。 /
世出世间如意事，专诚启祝定随心。 /

开坛宝诵妙通玄，地涌声雷镇上天。 /
绵绵福果善修来，湛湛心如明镜台。 /
台镜明如心湛湛，来修善果福绵绵。 /
天上镇雷声涌地，玄通妙诵宝坛开。 /

稽首光明大佛顶，如来万行首楞严。 /
光中化佛演微言，诵念溥令祛宿业。 /

满目旃檀紫竹林，头头显露圣观音。 /
初时已证圆通会，先发菩提四善心。 /

三慧门高绝品题，而今识与辩端猊。 /
含灵识本从头悟，净圣垂慈为奖提。 /
超果超因离胜迹，假名假相示筌第。 /
福田寿域无涯际，携手相从阔步跻。 /

四善心惟正性强，慈悲恭谨是坛场。 /
但能念念无生灭，自证空空绝忖量。 /
佛法地平堪履玩，是非门险莫谈扬。 /
更能猛劢除人我，觉悟修行见法王。 /

人天虔洁共归依，召请方严第一时。 /
上圣赴缘临垢浊，众生翘首仰慈悲。 /
飘飖璎珞清音间，芬馥旃檀瑞气随。 /
欲仗密言成胜事，辄坚精意为加持。 /

云何为供养，无上两足尊？ /
愿说其义趣，闻者当奉行。 /
香花众伎乐，衣服药卧具。 /
如是等供养，云何为最胜？ /

当发菩提心，广济诸群品。 /
是则供正觉，三十二相明。 /
设满恒沙刹，珍妙庄严具。 /
奉献诸如来，及懽喜顶戴。 /
不如以慈心，回向于菩提。 /
是福为最胜，无量无有边。 /
余供无过者，超逾不可计。 /
如是菩提心，必成等正觉。 /

诸天龙鬼神，听我师子吼。 /
今于如来前，弘誓发菩提。 /
生死无量劫，本际不可知。 /
为一众生故，尔数劫行道。 /
况此诸劫中，度脱无量众。 /
修行菩提道，而生疲倦心。 /
我欲从今始，起于贪欲心。 /
是则为欺诳，十方一切佛。 /
瞋恚愚痴垢，悭嫉亦复然。 /
我今说实语，远离于虚妄。 /
我若于今始，起于声闻心。 /
不乐修菩提，是则叹世尊。 /
亦不求缘觉，自济利己身。 /
当于万亿劫，大悲度众生。 /
如今日佛土，清净妙庄严。 /
令我得道时，超逾亿百千。 /
国无声闻众，亦无缘觉乘。 /
淳有诸菩萨，其数无限量。 /
众生净无垢，悉具上妙药。 /
出生于正觉，总持诸法藏。 /
此誓若诚实，当动大千界。 /

观音修证出悲华，观见众生行业差。 /
无量净王元古佛，不眴太子选其家。 /
师资身现三王子，左右莲开二朵花。 /
以大音声劝回向，菩提心发遍河沙。 /

释名摄化理幽深，梵语华言仔细寻。 /
湿伐罗耶称自在，婆卢枳底即观音。 /
生生善解无穷难，劫劫能除有漏心。 /
三业归依头面礼，闻声救苦便垂临。 /

存念观音各不同，五门八法互含融。 /
是心是佛如如理，无我无人念念空。 /
兴福疏标慈普应，世亲论载数何穷？ /
称名归依修三昧，一法通时万法通。 /

观音仪相实无边，金色荧煌映紫檀。 /
白亵花装为胳膊，毘楞伽宝作天冠。 /
顶中化佛无边亿，项上分辉有万般。 /
作是观时为正观，若他观者被渠谩。 /

我等自从无始劫，因迷觉海性沉圆。 /
无明妄动能所生，境风鼓击波浪起。 /
由缘妄见体昏昧，外感顽空相现前。 /
空分四大互相凌，见起六根常融别。 /
妄将心境分成二，故使一真性相殊。 /
由兹生死苦无穷，如旋火轮无休息。 /
幸逢最后佛垂范，因悟从前万苦辛。 /
今投圣众忏前愆，应念化成无上道。 /

我昔枉受轮回苦，皆由心境妄缘攀。 /
而今循省已知非，力行断惑常无倦。 /
法门无尽常修学，苦海弥天驾法船。 /
我今妄习顿能除，愿我真心常不昧。 /
愿我直入三摩地，愿我对境悟圆通。 /
愿我得果成宝王，还度如是恒沙众。 /

空有多闻迷实相，于无漏业不能修。 /
当来苦果竟难逃，直向圣门求解脱。 /

会上因缘三世佛，圆通海会佛菩萨。 /
声闻罗汉贤圣僧，摩诃般若般罗密。 /

菡萏红莲凝舌相，苹婆丹果艳唇端。 /
威仪相若象王行，说法音同狮子吼。 /

道场清净众，各各当志心。 /
志心勤归依，志心勤礼拜。 /
大圣大慈悲，观世音菩萨。 /
唯有观世音，能拔众生苦。 /
唯有观世音，能灭众生罪。 /
凡我等愚迷，令我延寿命令我所荐严。 /
自无始劫来，深造诸黑业。 /
皆由身口意，及我诸先代。 /
内外诸眷属，或已生人天。 /
而未登圣地，或以业缘牵。 /
未得受快乐，是故我等众。 /
今日须控告，唯愿圣慈悲。 /
开受我等请，令我诸罪苦。 /
无有不消灭，诸罪苦灭已。 /
各发菩提心，诸恶不复作。 /
众善力奉行，今日已往去。 /
永不复退转。三说

再伸警策礼观音，黑业消除白业深。 /
随喜尽超三有海，见闻俱出八邪林。 /
如如理悟无生理，了了心通大觉心。 /
众善奉行不退转，圣凡一体古犹今。 /

启请今当第二回，五轮投地业山摧。 /
心心洗忏千生罪，念念消除万劫灾。 /
返本还源求解脱，背尘合觉免轮回。 /
凝然珍重将伸礼，须仗真言震法雷。 /

礼拜能除我慢障，礼拜能除我慢愆， /
礼拜能感尊贵身，礼拜能生三善道。 /

丈六金身现碧空，莲池海会紫霞红。 /
自从西域垂明教，辍起恒河化日中。 /

圆通何处不圆通，那个圆通在海东？ /
三拜起来开豁眼，一枝杨柳笑春风。 /

分明势至露堂堂，昔日曾修日月光。 /
不离弥陀常左右，手持如意异奇香。 /

愿救我苦厄，大悲覆一切。 /
普放净光明，灭除痴暗冥。 /
为免杀害苦，烦恼及众病， /
必来至我所，施我大安乐。 /
我今稽首礼，闻名救厄者。 /
我今自归依，世间慈悲父。 /
唯愿必定来，免我三毒苦， /
施我今世乐，及与大涅槃。 / 三说

三回伏地转懃翘，观想观音路匪遥。 /
再祷再祈灾网断，一心一意障云消。 /
随声发响洪钟叩，说法当机大海潮。 /
菩萨慈悲来赴感，种瓜不是豆生苗。 /

没溺四生拘溷浊，循环五道恣缠绵。 /
若非慈悲圣观音，孰与垂哀为救护？ /

此咒名为甘露药，能救一切诸有情。 /
无量众苦悉消除，是故名为施无畏。 /

救拔无边罪苦时，惟凭大士运慈悲。 /
迷途困厄多邪见，圣智哀怜出苦危。 /
尽与灭除烦恼障，普令永断世间痴。 /
善财亲见为良友，摄取众生应病医。 /

凡夫三业不清凉，历劫尘埋在苦乡。 /
自作教他何觉悟？故为误犯少筹量。 /
了知本性元无性，顿悟身光自有光。 /
今日忏除何所喻？琉璃瓶内伫朝阳。 /

观音垂愿化娑婆，接引众生出爱河。 /
灵验昭彰难可述，神通变化孰能过？ /
自知悟道方成佛，益已安禅便利他。 /
念念念成无相念，分明具足六波罗。 /

大悲大名称，吉祥安乐人。 /
常说吉祥句，济度极苦者。 /
众生若闻名，离苦得解脱。 /
亦游戏地狱，大悲代受苦。 /
或处畜生中，化作畜生形。 /
教以大智慧，令发无上心。 /
或处阿修罗，软言调伏心。 /
令除憍慢习，疾至无为岸。 /
现身作饿鬼，手出香色乳。 /
饥渴逼切者，施食得饱满。 /
大慈大悲心，游戏于五道。 /
常以善集会，无上胜方便， /
普救一切众，令离生死海。 /
当得安乐处，到大涅槃岸。 /

观音化现几多身，六道三途出苦轮。 /
普愿超凡兼入圣，尽令舍妄悉归真。 /
随缘在欲元无欲，离相居尘不染尘。 /
定慧慈悲皆摄受，新成旧佛佛成新。 /

我昔所造诸恶业，皆由无始贪嗔痴。 /
不悟自性本来真，枉入四生并六趣。 /
一念回光而返照，譬如云散月当空。 /
不历僧祗获法身，自利利他悉圆满。 /

愿身口意常清净，一切罪业悉消除。 /
愿我心同如意珠，一切所愿悉成就。 /
一一消除微细惑，背尘合觉获真常。 /
舜若多性可销亡，烁迦罗心无动转。 /

三界悠悠如梦幻，四生扰扰但奔驰。 /
归依无上佛菩提，便是当来坚固藏。 /

会上因缘三世佛，圆通海会佛菩萨。 /
声闻罗汉贤圣僧，摩诃般若波罗密。 /

胸藏黄金题卍字，足轮碧玉间千花。 /
三十二相遍庄严，千百亿身常救苦。 /

道场清净众，各各当志心。 /
至心勤归依，至心勤礼拜。 /
大圣大慈悲，观世音菩萨。 /
唯有观世音，开示我修道。 /
唯有观世音，速令我修真。 /
自悟性本空，圆明同太虚。 /
不垢忘不净，不生亦不灭。 /
是故我等众，今日须控告。 /
唯愿圣慈悲，开受我等请。 /
令我所追荐，精修大乘行。 /
直截至佛地，普济诸有情。 /
今日已往去，永不复退转。三说 /

三回警策证圆通，心识圆明意气雄。 /
有作因缘俱是幻，无为行业等虚空。 /
傍生饿鬼如来用，地狱天堂善逝功。 /
直截根源归佛地，人人尽识主人翁。 /

菩萨随缘化有情，四生能化百千形。 /
春来处处花盈谷，秋到家家月满庭。 /
省觉到头俱是幻，悟迷毕究了无因。 /
圆融行布皆无碍，收拾归来在一尘。 /

观音菩萨运慈悲，妙觉随缘显相形。 /
赵璧连城三大弃，众生是佛几人知。 /
梁皇不契西来意，达么潜回北魏时。 /
明觉觉来无所觉，有为同悟悟无为。 /

稽首难思真法界，圆通海会众圣贤。 /
我今升座演鸿仪，惟愿慈悲垂加护。 /

解脱修心道可攀，证真如理出尘寰。 /
昔年未悟金藏鑛，今日方知玉在山。 /
般若智明登彼岸，菩提心发遍人间。 /
陀罗尼藏谁能识？识得元来不等闲。 /

六波罗蜜遍熏修，便得超凡入圣流。 /
万行圆融天地阔，三轮清净鬼神愁。 /
岩前已绝啣花鸟，石畔长闲献果猴。 /
今古堂堂观自在，何须驰骋四方求？ /

修行地位强区分，悟则元来本一门。 /
背境观心心已寂，悟心无境境何存？ /
月沉巨海真无玷，云散长空岂有痕？ /
一则为多多即一，五般香𦶟遍乾坤。 /

众生迷到入邪林，妄念攀缘水火侵。 /
有我有人烦恼宅，非真非妄涅槃心。 /
执情难悟尘埋镜，离相方知鑛出金。 /
实状元来无一物，迷云散尽见观音。 /

隔垣听音响，遐迩俱可闻。 /
五根所不齐，是则通真实。 /
音声性动静，闻中为有无。 /
无声号无闻，非实闻无性。 /
声无既无灭，声有亦非生。 /
生灭二圆离，是则常真实。 /

见闻觉知无障碍，色香味触常三昧。 /
如鸟空中衹么飞，无取无舍无憎爱。 /
若能当处常湛然，始得名为观自在。 /

子欲识观音，猿啼暖谷深。 /
嫩林莺语细，槁木晚螳吟。 /
悲极诚难入，慈全不易寻。 /
声声诸国土，一一即君心。 /

凡夫具足法，迷悟随六识。 /
一入自在门，不费纤毫力。 /
