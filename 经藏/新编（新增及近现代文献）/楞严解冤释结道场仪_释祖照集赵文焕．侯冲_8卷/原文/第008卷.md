# 楞嚴解冤釋結道場儀 · 第八卷

> 宋 釋祖照集　趙文煥．侯沖整理

貪愛冤心識是誰？瞿曇直截為拈提。 /
昏昏自蔽無休日，往往難逃不盡時。 /
衣裹靈珠貧自苦，宅埋寶藏轉成癡。 /
悲心特與揮標指，月在長天水在池。 /

香飄一線入伽藍，接足慇勤覓指南。 /
賓主序分容剎海，君臣道合仰優曇。 /
龍蟠虎踞安禪定，象往獅來作對談。 /
一大因緣殊勝事，前三三與後三三。 /

本自元常一主翁，情生償債走西東。 /
阿難遭問心隨境，大覺垂慈業已空。 /
綰疊六成埋有相，掣開三世了真容。 /
佛前佛後沉冤類，跳出龍門一點紅。 /

三寶巍巍住世間，名空即色化人天。 /
頂中螺髻青山翠，面上真人赤肉團。 /
隱果現因含法界，示權歸實應機玄。 /
聖凡一體香雲屋，指出冤家入笑顏。 /

楞嚴勝會啟壇場，密咒清泉甘露漿。 /
安息飛煙雲霧捲，蘭膏發焰慧燈光。 /
緇儒濟濟皆嚴潔，賢聖巍巍盡讚揚。 /
法雨滿空甘露灑，道場何處不清涼？ /

華藏世界所有塵，於一塵中現法界。 /
寶光現佛如雲集，此是如來剎自在。 /

身口意業本來同，寸念迷真失本蹤。 /
喝散障雲無點翳，一輪杲日照長空。 /

五分法身真妙香，人人具足露堂堂。 /
無根樹下親拈出，供養無上大法王。 /

八功德水自天真，善洗眾生業垢塵。 /
流入毗盧華藏海，個中無處不超倫。 /

聚沙成塔亙青天，舉止分明在目前。 /
法界蕩無塵一點，自然彖出一枝蓮。 /

荊棘林中業火生，經由大地任縱橫。 /
金剛突出摩訶力，直向如來行處行。 /

振鈴持咒繞香壇，警覺邪魔心膽寒。 /
休誇須彌藏芥子，且觀佛剎睹毫光。 /
聖賢感格慈悲廣，理事圓融宇宙寬。 /
心垢蕩除無罣礙，相逢大士有何難？ /

樂音樹下悟重玄，普運慈心覆大千。 /
直使三生冤歇滅，不令六類債纏綿。 /
靈根穎脫曾無累，密咒宣陳自有緣。 /
今日投誠希鑒照，願垂慈愍副傾虔。 /

道場清淨眾，各各當至心。 /
至心勤歸依，至心勤禮拜， /
大聖大慈悲，解冤結菩薩。 /
菩薩大慈悲，能救眾生苦； /
菩薩大慈悲，能解眾生冤。 /
彼我悉圓融，冤親總平等。 /
解結無垢染，災害永不生。 /
成就涅槃心，發明便解脫。 /
圓滿諸功德，清淨大總持。 /
智慧為導師，彈指超無學。 /
今日已往去，永不復退轉。 / 三說

樂音樹下樂無憂，普照光明盡遍周。 /
解去諸冤須無礙，頓超累劫豈能酬？ /
威神自在功難深，妙用縱橫道可求。 /
妙覺妙明明妙處，大千世界一浮漚。 /

菩薩慈悲願力深，逍遙變化自由身。 /
紅塵堆裏常清淨，白業情中度苦輪。 /
相好端嚴如海量，神通妙用若天真。 /
人人返本迴光照，那個親疏辨主賓。 /

我今稽首一切智，三千世界希有尊。 /
種種妙行悉莊嚴，色若琉璃淨無垢。 /
憐憫世間大悲者，說法利益無冤情。 /
佛之功德無有窮，是故誠心略讚仰。 /

啟迪菩薩大行時，三賢十地絕思議。 /
欲明裴相真方便，須問圭峰老古錐。 /
克念三心祈顯煥，堅舒五誓力行持。 /
豁然雲散蟾輪現，萬古神光說向誰？ /

三心克備道芬芳，五願堅持愈更光。 /
智向覺天為日月，悲於苦海作舟航。 /
先明本性歸真宅，轉化群生達故鄉。 /
若要更知君子行，先人後己也何妨。 /

善惡猶同誰與何？堪嗟人世少禪那。 /
開顏祇在養時有，掣肘元從害處多。 /
萬種千端能坐斷，十方三際自消磨。 /
如其一念隨他轉，永劫無由出愛河。 /

恩中冤結火炎炎，不顧衣珠自解粘。 /
每以篇章矜識達，常將望族恃威嚴。 /
誇豪傲物多殘害，倚勢凌人弗退謙。 /
今日道場須指出，勸君宜把信香添。 /

區區來向母胎中，致害何曾念凱風？ /
菩薩化身臨彼岸，夜叉隨手立長空。 /
三生冤債當時斷，千軸靈文逐處通。 /
今日相忘須解結，優曇花發雨濛濛。 /

世上多多有萬般，而今拈出豈相瞞？ /
劉王入院情何重？居約迎官事可看。 /
忽遇王真心膽戰，若言成益骨毛寒。 /
儻能彼此無相累，業海波濤一念乾。 /

天上天下無如佛，十方世界亦無比。 /
世間所有我盡見，一切無有如佛者。 /

道場清淨眾，各各當至心。 /
志心勤歸依，志心勤禮拜。 /
大聖大慈悲，解冤結菩薩。 /
菩薩大慈悲，能解根塵縛； /
菩薩大慈悲，能除生死罪。 /
六類悉蠲除，六根常清淨。 /
負心修忍辱，瞋恨不能加。 /
負命悉冤讎，尸羅轉清淨。 /
負財與佈施，負力毗梨耶。 /
呵罵惡聲除，智慧尤光顯。 /
鞭撻不相續，禪定力加持。 /
種種俱對治，六類皆潛滅。 /
具足波羅蜜，無量總持門。 /
進趨各修行，圓明於理智。 /
今日已往去，永不復退轉。 /

四眾歸依至意深，再三撈漉始知音。 /
人人自有昭昭在，佛佛何須遠遠尋？ /
凡聖悟來元是我，古今無異一真心。 /
會中倘若知斯旨，不在忉忉費古今。 /

惟願三途苦輪息，總令熱惱得清涼。 /
皆發無上菩提心，同出愛河登彼岸。 /

枝末根源品類多，俱生俱滅總包羅。 /
時時震動寒如瘧，念念遷流急似梭。 /
煩惱魔軍應壞散，菩提覺樹自娑婆。 /
楞嚴禪髓稱奇絕，覿面相呈會也麼？ /

異口同音告阿難，根塵縛脫互摧殘。 /
十方共聽慈風軟，萬劫同誇業海乾。 /
興福拈時珠燦燦，世尊演處玉珊珊。 /
安公錯句真消息，掃蕩煙塵法界寬。 /

真性有為空，緣生故如幻。 /
無為無起滅，不實如空華。 /
言妄顯諸真，妄真同二妄。 /
猶非真非真，云何見所見？ /
中間無實性，是故若交蘆。 /
結解同所因，聖凡無二路。 /
汝觀交中性，空有二俱非。 /
迷晦即無明，發明便解脫。 /
解結因次第，六解一亦亡。 /
根選擇圓通，入流成正覺。 /

迷真逐妄兩俱非，窮子伶侽弗見歸。 /
護法呵空心豁達，掌珠雙破悟玄機。 /
昔年深密雖宣演，今日楞嚴愈發揮。 /
偈頌長行皆指出，拈來不離目前機。 /

陀那微細識，習氣成瀑流。 /
真非真恐迷，我嘗不開演。 /

幻法云何立？是名妙蓮華。 /
金剛王寶覺，如幻三摩提。 /
彈指超無學，此阿毗達磨。 /
十方薄伽梵，一路涅槃門。 /

陀羅微細最難知，真妄如何說向伊。 /
種子含藏無失沒，現行發用又支離。 /
瀑流滾滾奚能止？幻法重重豈可推？ /
彈指若超無學地，自然光透兩條眉。 /

祇夜伽陀恣舉揚，文詞精瑩玉鏘鏘。 /
已聞法句超真際，更聽玄音悟大方。 /
凡聖何曾分楚越？根塵爭得有膏肓？ /
如來苦苦親宣說，六解須知一也亡。 /

攬几拈巾為發揮，廣長舌相轉璇璣。 /
根中解去心尤妙，喻上看來語更微。 /
興佛以玄通佛意，阿難示迹啟天機。 /
六窗杜絕獼猴睡，笑倒雲山老衲衣。 /

於湛精明既不通，狂花亂髮遍空中。 /
根塵互遣亡纖翳，法喻重宣有異功。 /
左右各牽迷至理，是非鋒起入煩籠。 /
結心解處俱分散，焰焰金烏出海東。 /

一念初萌萬仞高，含藏八識自堅牢。 /
豫且網內應難免，地藏珠中豈可逃？ /
六類紛紛俱繫綴，四生浩浩共煎熬。 /
奢摩他體能端的，彼此相忘入聖曹。 /

大略區分十八般，考窮元在一毫端。 /
廟堂豪傑須當勉，草茵凡庸切好看。 /
妙理雖云超六度，深冤宜在運三檀。 /
倘逢平等相忘處，天上人間各自安。 /

一切諸導師，普現於十方。 /
汝觀牟尼尊，所作甚希奇。 /
佛身不在內，亦不在於外。 /
神力故顯現，導師法如是。 /

道場清淨眾，各各當志心。 /
志心勤歸依，志心勤禮拜， /
大聖大慈悲，解冤結菩薩。 /
菩薩大慈悲，能滅生死苦； /
菩薩大慈悲，能解根塵縛。 /
發明真實慧，三觀永澄明。 /
頓悟於本源，漸修無量行。 /
六度皆圓滿，超證寂滅門。 /
彼我悉相忘，成就菩提道。 /
利益廣無邊，普濟於一切。 /
今日已往去，永不復退轉。 /

三回警策事無他，意在人人會也麼？ /
三觀澄明俱在我，六根清淨悉同科。 /
根塵縛脫何思慮？生死空花總是訛。 /
鏡上看來心自見，何勞馳騁動干戈？ /

四心圓備喜圓成，三觀澄明轉更精。 /
五濁界中乘一念，十方境上度尋聲。 /
塵塵應現機緣熟，處處光明路坦平。 /
地位階差皆展演，返觀何處不崢嶸？ /

再三讚禮盡按誠，未復慇勤事鼎精。 /
自己靈光常不昧，何勞諸聖愈佳名。 /
菩薩妙道從即入，彼我圓融患不成。 /
展事投誠君薦取，除根伐樹勿入情。 /

三段因緣二已周，常觀寂寂好參求。 /
忘心頓證淵源理，直下承當便轉頭。 /

解結除冤樂有餘，勤修觀行為祛除。 /
靈編舉處分三種，正眼看來本一如。 /
句裏藏機須薦取，定中發慧自相隨。 /
到頭展縮皆由我，在則人兮亡則書。 /

清淨慈悲喜捨心，無窮無盡去來今。 /
慈同彌勒源流遠，悲若觀音行願深。 /
定慧圓明須適悅，冤親平等任昇沉。 /
希顏慕藺勤精進，佇看優遊功德林。 /

粗中之細細中粗，萬行因花次第敷。 /
每以三賢為入劫，常將十信作凡夫。 /
看來位位成前後，悟去塵塵絕有無。 /
更道忘心便頓證，等觀元是一毗盧。 /

忘心頓證豈相淹？不在多多為解粘。 /
圓覺妙門真簡要，楞嚴大定絕廉纖。 /
慈風扇處三根普，法雨傾時四海霑。 /
三世如來關捩子，為君拈出莫勞謙。 /

六度修行為對治，直須精進勿遲疑。 /
根塵深結知何日？彼我相忘在此時。 /
菩薩已蒙垂愍念，眾生更在力行持。 /
等將法界俱迴向，是處歡悰也大奇。 /

妙供敷陳理事兼，沉檀鼻觀悟香嚴。 /
銀碗祖焰神光續，金色優曇古佛拈。 /
性水碧波澄海印，蘋婆丹果味甘甜。 /
慇勤持獻牟尼座，沙界均蒙雨露霑。 /

聖人豈離方洲部？凡輩徒嗟風馬牛。 /
既沐光臨深有賴，更祈再會遽無由？ /
誰知一月千江水，無去無來處處周。 /

梵音初震一聲雷，無限人天眼豁開。 /
怪得香風拂庭戶，龍天圍繞世尊來。 /
