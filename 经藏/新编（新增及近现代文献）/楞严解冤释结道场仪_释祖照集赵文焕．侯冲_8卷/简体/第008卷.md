# 楞严解冤释结道场仪 · 第八卷

> 宋 释祖照集　赵文焕．侯冲整理

---

贪爱冤心识是谁？瞿昙直截为拈提。 /
昏昏自蔽无休日，往往难逃不尽时。 /
衣裹灵珠贫自苦，宅埋宝藏转成痴。 /
悲心特与挥标指，月在长天水在池。 /

香飘一线入伽蓝，接足慇勤觅指南。 /
宾主序分容刹海，君臣道合仰优昙。 /
龙蟠虎踞安禅定，象往狮来作对谈。 /
一大因缘殊胜事，前三三与后三三。 /

本自元常一主翁，情生偿债走西东。 /
阿难遭问心随境，大觉垂慈业已空。 /
绾叠六成埋有相，掣开三世了真容。 /
佛前佛后沉冤类，跳出龙门一点红。 /

三宝巍巍住世间，名空即色化人天。 /
顶中螺髻青山翠，面上真人赤肉团。 /
隐果现因含法界，示权归实应机玄。 /
圣凡一体香云屋，指出冤家入笑颜。 /

楞严胜会启坛场，密咒清泉甘露浆。 /
安息飞烟云雾卷，兰膏发焰慧灯光。 /
缁儒济济皆严洁，贤圣巍巍尽赞扬。 /
法雨满空甘露洒，道场何处不清凉？ /

华藏世界所有尘，于一尘中现法界。 /
宝光现佛如云集，此是如来刹自在。 /

身口意业本来同，寸念迷真失本踪。 /
喝散障云无点翳，一轮杲日照长空。 /

五分法身真妙香，人人具足露堂堂。 /
无根树下亲拈出，供养无上大法王。 /

八功德水自天真，善洗众生业垢尘。 /
流入毗卢华藏海，个中无处不超伦。 /

聚沙成塔亘青天，举止分明在目前。 /
法界荡无尘一点，自然彖出一枝莲。 /

荆棘林中业火生，经由大地任纵横。 /
金刚突出摩诃力，直向如来行处行。 /

振铃持咒绕香坛，警觉邪魔心胆寒。 /
休夸须弥藏芥子，且观佛刹睹毫光。 /
圣贤感格慈悲广，理事圆融宇宙宽。 /
心垢荡除无罣碍，相逢大士有何难？ /

乐音树下悟重玄，普运慈心覆大千。 /
直使三生冤歇灭，不令六类债缠绵。 /
灵根颖脱曾无累，密咒宣陈自有缘。 /
今日投诚希鉴照，愿垂慈愍副倾虔。 /

道场清净众，各各当至心。 /
至心勤归依，至心勤礼拜， /
大圣大慈悲，解冤结菩萨。 /
菩萨大慈悲，能救众生苦； /
菩萨大慈悲，能解众生冤。 /
彼我悉圆融，冤亲总平等。 /
解结无垢染，灾害永不生。 /
成就涅槃心，发明便解脱。 /
圆满诸功德，清净大总持。 /
智慧为导师，弹指超无学。 /
今日已往去，永不复退转。 / 三说

乐音树下乐无忧，普照光明尽遍周。 /
解去诸冤须无碍，顿超累劫岂能酬？ /
威神自在功难深，妙用纵横道可求。 /
妙觉妙明明妙处，大千世界一浮沤。 /

菩萨慈悲愿力深，逍遥变化自由身。 /
红尘堆里常清净，白业情中度苦轮。 /
相好端严如海量，神通妙用若天真。 /
人人返本回光照，那个亲疏辨主宾。 /

我今稽首一切智，三千世界希有尊。 /
种种妙行悉庄严，色若琉璃净无垢。 /
怜悯世间大悲者，说法利益无冤情。 /
佛之功德无有穷，是故诚心略赞仰。 /

启迪菩萨大行时，三贤十地绝思议。 /
欲明裴相真方便，须问圭峰老古锥。 /
克念三心祈显焕，坚舒五誓力行持。 /
豁然云散蟾轮现，万古神光说向谁？ /

三心克备道芬芳，五愿坚持愈更光。 /
智向觉天为日月，悲于苦海作舟航。 /
先明本性归真宅，转化群生达故乡。 /
若要更知君子行，先人后己也何妨。 /

善恶犹同谁与何？堪嗟人世少禅那。 /
开颜祇在养时有，掣肘元从害处多。 /
万种千端能坐断，十方三际自消磨。 /
如其一念随他转，永劫无由出爱河。 /

恩中冤结火炎炎，不顾衣珠自解粘。 /
每以篇章矜识达，常将望族恃威严。 /
夸豪傲物多残害，倚势凌人弗退谦。 /
今日道场须指出，劝君宜把信香添。 /

区区来向母胎中，致害何曾念凯风？ /
菩萨化身临彼岸，夜叉随手立长空。 /
三生冤债当时断，千轴灵文逐处通。 /
今日相忘须解结，优昙花发雨蒙蒙。 /

世上多多有万般，而今拈出岂相瞒？ /
刘王入院情何重？居约迎官事可看。 /
忽遇王真心胆战，若言成益骨毛寒。 /
傥能彼此无相累，业海波涛一念干。 /

天上天下无如佛，十方世界亦无比。 /
世间所有我尽见，一切无有如佛者。 /

道场清净众，各各当至心。 /
志心勤归依，志心勤礼拜。 /
大圣大慈悲，解冤结菩萨。 /
菩萨大慈悲，能解根尘缚； /
菩萨大慈悲，能除生死罪。 /
六类悉蠲除，六根常清净。 /
负心修忍辱，瞋恨不能加。 /
负命悉冤仇，尸罗转清净。 /
负财与布施，负力毗梨耶。 /
呵骂恶声除，智慧尤光显。 /
鞭挞不相续，禅定力加持。 /
种种俱对治，六类皆潜灭。 /
具足波罗蜜，无量总持门。 /
进趋各修行，圆明于理智。 /
今日已往去，永不复退转。 /

四众归依至意深，再三捞漉始知音。 /
人人自有昭昭在，佛佛何须远远寻？ /
凡圣悟来元是我，古今无异一真心。 /
会中倘若知斯旨，不在忉忉费古今。 /

惟愿三途苦轮息，总令热恼得清凉。 /
皆发无上菩提心，同出爱河登彼岸。 /

枝末根源品类多，俱生俱灭总包罗。 /
时时震动寒如疟，念念迁流急似梭。 /
烦恼魔军应坏散，菩提觉树自娑婆。 /
楞严禅髓称奇绝，觌面相呈会也么？ /

异口同音告阿难，根尘缚脱互摧残。 /
十方共听慈风软，万劫同夸业海干。 /
兴福拈时珠灿灿，世尊演处玉珊珊。 /
安公错句真消息，扫荡烟尘法界宽。 /

真性有为空，缘生故如幻。 /
无为无起灭，不实如空华。 /
言妄显诸真，妄真同二妄。 /
犹非真非真，云何见所见？ /
中间无实性，是故若交芦。 /
结解同所因，圣凡无二路。 /
汝观交中性，空有二俱非。 /
迷晦即无明，发明便解脱。 /
解结因次第，六解一亦亡。 /
根选择圆通，入流成正觉。 /

迷真逐妄两俱非，穷子伶侽弗见归。 /
护法呵空心豁达，掌珠双破悟玄机。 /
昔年深密虽宣演，今日楞严愈发挥。 /
偈颂长行皆指出，拈来不离目前机。 /

陀那微细识，习气成瀑流。 /
真非真恐迷，我尝不开演。 /

幻法云何立？是名妙莲华。 /
金刚王宝觉，如幻三摩提。 /
弹指超无学，此阿毗达磨。 /
十方薄伽梵，一路涅槃门。 /

陀罗微细最难知，真妄如何说向伊。 /
种子含藏无失没，现行发用又支离。 /
瀑流滚滚奚能止？幻法重重岂可推？ /
弹指若超无学地，自然光透两条眉。 /

祇夜伽陀恣举扬，文词精莹玉锵锵。 /
已闻法句超真际，更听玄音悟大方。 /
凡圣何曾分楚越？根尘争得有膏肓？ /
如来苦苦亲宣说，六解须知一也亡。 /

揽几拈巾为发挥，广长舌相转璇玑。 /
根中解去心尤妙，喻上看来语更微。 /
兴佛以玄通佛意，阿难示迹启天机。 /
六窗杜绝猕猴睡，笑倒云山老衲衣。 /

于湛精明既不通，狂花乱发遍空中。 /
根尘互遣亡纤翳，法喻重宣有异功。 /
左右各牵迷至理，是非锋起入烦笼。 /
结心解处俱分散，焰焰金乌出海东。 /

一念初萌万仞高，含藏八识自坚牢。 /
豫且网内应难免，地藏珠中岂可逃？ /
六类纷纷俱系缀，四生浩浩共煎熬。 /
奢摩他体能端的，彼此相忘入圣曹。 /

大略区分十八般，考穷元在一毫端。 /
庙堂豪杰须当勉，草茵凡庸切好看。 /
妙理虽云超六度，深冤宜在运三檀。 /
倘逢平等相忘处，天上人间各自安。 /

一切诸导师，普现于十方。 /
汝观牟尼尊，所作甚希奇。 /
佛身不在内，亦不在于外。 /
神力故显现，导师法如是。 /

道场清净众，各各当志心。 /
志心勤归依，志心勤礼拜， /
大圣大慈悲，解冤结菩萨。 /
菩萨大慈悲，能灭生死苦； /
菩萨大慈悲，能解根尘缚。 /
发明真实慧，三观永澄明。 /
顿悟于本源，渐修无量行。 /
六度皆圆满，超证寂灭门。 /
彼我悉相忘，成就菩提道。 /
利益广无边，普济于一切。 /
今日已往去，永不复退转。 /

三回警策事无他，意在人人会也么？ /
三观澄明俱在我，六根清净悉同科。 /
根尘缚脱何思虑？生死空花总是讹。 /
镜上看来心自见，何劳驰骋动干戈？ /

四心圆备喜圆成，三观澄明转更精。 /
五浊界中乘一念，十方境上度寻声。 /
尘尘应现机缘熟，处处光明路坦平。 /
地位阶差皆展演，返观何处不峥嵘？ /

再三赞礼尽按诚，未复慇勤事鼎精。 /
自己灵光常不昧，何劳诸圣愈佳名。 /
菩萨妙道从即入，彼我圆融患不成。 /
展事投诚君荐取，除根伐树勿入情。 /

三段因缘二已周，常观寂寂好参求。 /
忘心顿证渊源理，直下承当便转头。 /

解结除冤乐有余，勤修观行为祛除。 /
灵编举处分三种，正眼看来本一如。 /
句里藏机须荐取，定中发慧自相随。 /
到头展缩皆由我，在则人兮亡则书。 /

清净慈悲喜舍心，无穷无尽去来今。 /
慈同弥勒源流远，悲若观音行愿深。 /
定慧圆明须适悦，冤亲平等任升沉。 /
希颜慕蔺勤精进，伫看优游功德林。 /

粗中之细细中粗，万行因花次第敷。 /
每以三贤为入劫，常将十信作凡夫。 /
看来位位成前后，悟去尘尘绝有无。 /
更道忘心便顿证，等观元是一毗卢。 /

忘心顿证岂相淹？不在多多为解粘。 /
圆觉妙门真简要，楞严大定绝廉纤。 /
慈风扇处三根普，法雨倾时四海沾。 /
三世如来关捩子，为君拈出莫劳谦。 /

六度修行为对治，直须精进勿迟疑。 /
根尘深结知何日？彼我相忘在此时。 /
菩萨已蒙垂愍念，众生更在力行持。 /
等将法界俱回向，是处欢悰也大奇。 /

妙供敷陈理事兼，沉檀鼻观悟香严。 /
银碗祖焰神光续，金色优昙古佛拈。 /
性水碧波澄海印，苹婆丹果味甘甜。 /
慇勤持献牟尼座，沙界均蒙雨露沾。 /

圣人岂离方洲部？凡辈徒嗟风马牛。 /
既沐光临深有赖，更祈再会遽无由？ /
谁知一月千江水，无去无来处处周。 /

梵音初震一声雷，无限人天眼豁开。 /
怪得香风拂庭户，龙天围绕世尊来。 /

稽首释迦大慈父，楞严海会众圣贤。 /
今时教诫演鸿仪，望赐慈悲密加护。 /
