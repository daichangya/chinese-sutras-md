# 毒语心经 · 第一卷

> 白隐慧鹤注释　南天棒邓州提唱

## 着语竝颂

葛藤窟里瞎老汉无裩却归草里坐可怜傅大士处处失楼阁莫言冷淡无滋味一饱能消万劫饥

南天棒白崖曰无风起浪肚里参天荆棘

听松子卿曰南天棒老汉云衲之顷在尾阳总见僧堂偶隣单老兄见有所持写本之毒语心经者羡望不已速借该书而以及一读有夜途明炬雾海南针感依而书写之于时文久三癸亥年仲秋也后来平常持坐右爱读不怠向白隐东岭两尊宿一一下语评唱矣野衲于囊方著述南天棒提唱毒语心经次白隐东岭两尊宿之着语评注可以南天棒老汉之评句错而加提唱之话头编辑惭汗惭汗今当编白崖窟语录正错依命一句一字不加校订露出其肺腑参学士宜可究可参

拨转参天烂葛藤绊缠四海五湖僧 /
愿君认得出身路藕线孔中弄快鹰 /

摩诃

唐飜云大是什么四维上下无等匹多错作广愽会了君子爱财取之有道为我过小底般若来

南天棒白崖曰大破关中收图书

百亿须弥毫末露三千世界海中沤 /
蟭螟眼里双童子玩弄阎浮争未休 /

般若

唐飜云智慧人人具固固圆弄泥团汉有何限不崄崖撒手未曾见在何故灯下不截爪可令尺蠖辨长短莫使蜗牛耕石田

南天棒白崖曰石虎吞却木羊儿

双耳如聋眼如盲虚空夜半失全身 /
不容令鹙子亲见戾脚波斯过别津 /

波罗密多

唐飜云到彼岸者里是什么所在掘土求青天虾跳不出斗宝所在近更进一步钓丝绞水谢郎舟明眼衲僧暗结愁

南天棒白崖曰穷鸟入怀则猎人不忍射

大地谁是此岸人甚怜错立洪波津 /
参究若未命根断修历三祗抂苦辛 /

心

历劫无名错安著名字金屑眼中翳衣珠法上尘是什么多错认驴鞍桥学道之人不识真唯为从前认识神无量劫来生死本痴人唤为本来人

南天棒白崖曰仁者见之谓之仁智者见之谓之智

分明三世不可得一扫长空绝点埃 /
禅榻夜阑冷如铁半窓明月带梅来 /

经

如是我闻一时佛在咄谁舒卷多向故纸堆中求黄卷赤轴又百合一片

南天棒白崖曰一粒粟中藏世界半升铛内煑山川

毕波罗窟里未结集此经童寿译无语 /
阿难岂得听北风窓纸隙南鴈雪芦汀 /
山月苦如瘦寒云冻欲零千佛纵出世 /
不添减一丁

观自在

补陀岩萨埵人人具大士尽大地一个不见不自在底人咳唾掉臂终不假别人力谁系缚儞着伸左手搔佛首即非无屈右手触狗头何日免得

南天棒白崖曰睡美不知山雨过觉来殿阁生微凉

执捉运奔不假他唯因情念积多罪 /
是非憎爱总拈抛许汝生身观自在 /

菩萨

简异二乘与十号暂时假设菩萨名在途中不离家舍离家舍不在途中为君夺却四弘愿行却是君子可八

南天棒白崖曰只今唯有西江月曾照吴王宫里人

超出我空无相窠沉浮业海生死波 /
南无救苦大悲身百亿分身无际涯 /

行

道什么事生也夜眠昼走放尿屙屎行云流水坠叶飞花拟议三途地狱虽然恁么地非一回白汗流亲见彻大有事在

南天棒白崖曰自携瓶去沽村酒却着衫来作主人

手捉脚运惟什么饥餐渴饮作么生 /
个中若着一毫相复为浑沌眼睛 / 󰦥

深般若波罗密多

咄剜好肉生疮怪哉所谓般若其何为物哉既是有浅深将其似河水者乎试道作么生是有浅深底般若恐有认楚鸡去

南天棒白崖曰乌龟带劒上灯台

求空破色之言浅全色见空此日深 /
若把色空谈般若瓮中跛鼈逐飞禽 /

时

又是剜好肉了去劫已前来劫后吹毛匣里灵光寒和盘托出夜明珠

南天棒白崖曰庭树不知人去尽春来还发旧时花

昨晨扫却旧年煤今夜炼磨新岁锤 /
带根松矣叶加橘还着新衣待客来 /

照见

烁迦罗眼绝纤埃莫向石灰箩里眨眼者里是何所在尽大地是沙门一只眼只是玄沙道底

南天棒白崖曰汉来汉现胡来胡现

蟭螟眼里蚁旋磨虮虱耳中蛛结罗 /
兜率阎浮泥犂狱分明掌上庵摩罗 /

五蕰皆空

灵龟拽尾争免得其踪色蕰如鉄围山受想如金刚剑行识如如意宝只知途路远不觉又黄昏

南天棒白崖曰短袴长衫白苎巾咿咿日下急推轮

认他色受想行识执作自家娟媿躬 /
譬似浮沤留水上或如闪电拂长空 /

度一切苦厄

客杯弓影元非蛇梦里明明三世有觉来空空大千无

南天棒白崖曰洛阳路上相逢着尽是经商买卖人

后鬼推扃前鬼拄两头奋力汗通身 /
终宵争拒渐天晓堪笑元惟相识人 /

舍利子

咄小果尊者有什么长处者里佛祖乞命内秘外现着何处净名室内不能转女身七狂八颠忘却么

南天棒白崖曰科头箕踞长松下白眼看他世上人

智是祗园第一枝惊奔长爪托胎时 /
亲参大士留此典罗睺教师鹙女儿 /

色不异空空不异色

好一釜羹被两颗鼠粪污却美食不当饱人吃拂波求水波是水

南天棒白崖曰若把西湖比西施淡粧浓抹两相宜

色不遮空空体色空非破色色身空 /
色空不二法门里跛鼈拂眉立晚风 /

色即是空空即是色

是何闲家具母教猱升木又是二千年滞货钓丝绞水谢郎舟

南天棒白崖曰渔歌烟浦咸称富贵樵唱云村共乐升平

黄鸟风微希皷瑟红桃日暖薄笼烟 /
蛾眉螓首一群玄各戴花枝锦绣肩 /

受想行识亦复如是

荒草里横身见怪不怪其怪自坏雪佛日出后一场懡㦬

南天棒白崖曰石女舞成长寿曲木人唱起太平歌

地风火水飞禽迹色受想行眼里花 /
石女掷梭张瘦臂泥牛蹴浪皷瞋牙 /

舍利子是诸法空相

揑目强生花从来无诸法何求空相净地上撒屙

南天棒白崖曰只见锥头利不知凿头力

山河大地蜃楼涌地狱天堂海市开 /
净邦秽土龟毛笔生死涅槃兔角枝 /

不生不灭不垢不净不增不减

可愍新鲜果凭么否何计诸法不生不灭无谩人好手臂不向外曲

南天棒白崖曰水带荷花白烟和杨柳青

眼里童子期客出谷神不死待人叫 /
众生界畔不污染诸佛土中净相无 /
分八万门何欠少容三千刹若隣虚 /
邯郸枕上新尊贵又入南柯纳税租 /

是故空中

狐窠鬼窟陷坠多少行人湛湛黑暗深坑诚可怖畏

南天棒白崖曰击碎我法二空见泥狱踏断今时那边瞎兔径

冻馁百余僧凤凰各展腊扇贺新阳 /
壁悬碧目紫髯老瓶入氷肌玉骨芳 /
寒锁琴唇黄鸟口暖浮禅榻赤麟盲 /
编茅包赠自然蓣封圈寄来养老糖 /

无色无受想行识

梦幻空花何劳把捉得失是非须放过事起叮咛用空无去为什么

南天棒白崖曰青山自青山白云自白云

寥廓虚凝寂灭场山河大地只是名 /
开心为四合色一心色从来空谷声 /

无眼耳鼻舌身意无色声香味触法无眼界乃至无意识界

有眼耳鼻舌身意有色声香味触法秋天旷野行人断马首西来知是谁

南天棒白崖曰深溪绝无樵子语阴崖却有猎人过

六识才生六境浮意根休处六尘休 /
根境识为十八界譬如沧溟发一沤 /

无无明亦无无明尽乃至无老死亦无老死尽

紫罗帐里撒真珠破布囊里真珠知者正知是宝牛饮水成乳蛇饮水成毒五云常拥人不到肃索仙家十二楼

南天棒白崖曰江上晚来堪画处渔人披得一蓑归

十二缘生十二灭生名凡夫灭圣人 /
此维独觉所观境空里浮飞眼里尘 /
眼里飞尘谁见得可贵圆顿大法轮 /
法轮影里亲荐取超过疥癞野干身 /

无苦集灭道

夜明帘外珠痴人按劒立水中盐味色里胶青白鹭下田千点雪黄鹏上树一枝花

南天棒白崖曰山家富贵银钱树渔父风流玉一蓑

通红四个铁昆仑夜半着鞋云外奔 /
集谛苦谛道灭谛非终非始非圆顿 /
陈如跋提及拘利不觉自燎却面前 /
莫谓鹿园摝虾蚬金仙密待大乘根 /

无智亦无得

又是鬼家活计此语错会底甚多棺木里瞠眼分明纸上张公子尽力高声唤不󰉵

南天棒白崖曰枯木里龙吟髑髅里眼睛

黑火洞然黑暗光茫茫天地失玄黄 /
山河不在镜中观百亿须弥空断膓 /

以无所得故菩提萨埵

放下着抱脏叫屈随缘赴感靡不周而常处此菩提座不明三八九对境多所思

南天棒白崖曰覔火和烟得担泉带月归

菩提萨埵摩诃萨唐飜道大心众生 /
入三途代众生苦游戯十方不待请 /
誓不取偏真小果上求菩提化有情 /
虚空直饶消殒尽永鞭愿轮利群氓 /

依般若波罗密多故

苦屈苦屈若见一法可依怙蓦地须吐却幽州独自可最苦是江南

南天棒白崖曰苦瓠连根苦甜瓜彻蔕甘

可谈罗汉有贪瞋莫说菩萨依般若 /
若见一法有所依非无罣碍即系缚 /
菩萨般若体无殊如珠走盘潇洒落 /
非愚非智非圣凡只恨画蛇添双脚 /

心无罣碍无罣碍故无有恐怖远离一切颠倒梦想

不是分外事神通竝妙用荷水也搬柴举头残照在元是住居西

南天棒白崖曰桑柘影斜秋社散家家扶得醉人归

非心非性非涅槃非佛非祖非般若 /
十界无孔热铁锤虚空系碎常寥廓 /
才开口狮子嚬吟狐兔狸貉尽惊惧 /
应物现身如幻师随机转变无造作 /
见他李母患左肩数壮灸张婆右脚 /
颠倒梦想恐惧忧宛如一滴投巨壑 /
赤使齐时被轻裘鲤逝时有棺无椁 /
唤起庵中午眠僧告山童折篱偷箨 /

究竟涅槃

陷人坑子年年满又是鬼家活计充什么臭皮韈吾党之直者异于是父为子隐子为父隐

南天棒白崖曰日日日东出日日日西没

一切众生生灭心直维诸佛大涅槃 /
木鸡含卵立棺木瓦马逐风归本贯 /

三世诸佛依般若波罗密多故

压良为贱大抵还他肌骨好不涂红粉自风流镬汤无冷处

南天棒白崖曰十谒朱门九不开满身风雪又归来

般若生三世诸佛三世诸佛演般若 /
主伴无尽唵苏鲁旧巢受风鸣宿鶴 /

得阿耨多罗三藐三菩提

不可向虚空里钉橛去犊牛纵可生儿诸佛终不依般若得菩提何故般若菩提体无二故若又更有一法可得即非如来譬如大火聚进傍则佛祖亦丧身失命

南天棒白崖曰竹影拂阶尘不动月穿潭底水无痕

白獭可缘木得鱼佛不依法得菩提 /
道如来有一法得如道应真各有妻 /

故知般若波罗密多是大神咒

担水河头卖何楼漆器莫拈出字经三写乌焉成马又是小卖弄夜行莫踏白非水多是石

南天棒白崖曰寥寥天地间独立有何极

可贵自性大神呪转热铁丸作醍醐 /
地狱阎浮天上界雪花一片落红炉 /

是大明咒

莫谓大明咒拗折山形柱杖子从来大地黑漫漫乾坤失色日月吞辉黑漆桶里盛黑汁

南天棒白崖曰风吹碧落浮云尽月上青山玉一团

本有圆成大明咒光明寂照尽山河 /
无量旷劫罪障海水上浮沤眼里花 /

是无上咒

跟下又作么生为我拈将最下底来坠叶虽怜疎雨感黄粱争似暮云亲󱯾

南天棒白崖曰细雨洒花千点雨淡烟笼竹一堆愁

最上最尊最第一释迦弥勒犹伊奴 /
此是人人本具物唯要当人绝后苏 /

是无等等咒

话作两橛那一橛着何处谁道上下四维无等匹七花八裂德云间古锥几下妙峰顶佣他痴圣人担雪共填井

南天棒白崖曰欲修行利济人却成此不唧汉𠺕

旧年寒苦梅得雨一时开疎影月移去 /
暗香风送来昨是埋雪树今复带花枝 /
吃困寒多少可贵百卉魁 /

能除一切苦

劈百合求中心削圆方竹杖挽却紫茸毡九九元来八十一一九与二九相逢不出手

南天棒白崖曰白云堆里不见白云流水声里不闻流水

儞若心空及第来五阴四大一时灰 /
天堂地狱间家具佛界魔宫百杂摧 /
黄鸟张声和白雪乌龟带釰上灯台 /
若人欲得此三昧白汗通身须一回 /

真实不虚

者个是大小大虚妄箭过新罗终日交肩我何似生

南天棒白崖曰女为爱己者粧士为知己者死生己者母知己者鲍叔也

齐晏杀三士蜀维败两将假鸡声避虎 /
卖狗肉悬羊指鹿见人伏着蜂断父望 /
陶朱携越女纪信降楚王吞炭伏桥下 /
投簪泣井傍载主尸兼鲂折父齿咬耳 /
明中修栈道暗里度陈仓若是亲见彻 /
匣中三尺霜

故说般若波罗密多咒

前头是什么如憎醉进酒酒浓元不在多杯十年归不得忘却来时道

南天棒白崖曰吾徒不知锦囊重里得青山暮色归

一回举了又一回积雪堆头积雪堆 /
只是更无廻避处为谁醉后添多杯 /

即说咒曰

第二重亦在渔唱薪歌着何处鸎吟燕语作么生莫入海择浮沤

南天棒白崖曰狐猿叫落中岩月野客吟残半夜灯

七字荒唐二十四又添四首五字城 /
不是呈高明诸老慰住庵饥寒弟兄 /
君若无转身一路葛藤无底大深坑 /
莫言吾偈甚难解须知自家无眼睛 /
者里若看难会处烂咬急切着神精 /
一回白汗亲咬着和千七百拔根茎 /
吾曾辛苦窥涯际折此无星等子秤 /
无星秤子若拗折宛如狮子长威狞 /
禅门幸有此灵验何不参究尽至诚 /
此道今人弃如土悬丝慧命谁相赓 /
我今非老好文术劝发诸方杰出英 /
上士一见知落处庸流还论他韵声 /
宋朝司马文正子可惜斯人眼未明 /
每见祖师难透话道成隐语恼后生 /
五无间业应忏悔谤法罪障甚不轻 /
世上今多此邪党禅园荒落寔可惊 /
若君了佛祖心地于佛祖言岂如盲 /
辨自家得力真伪祖师言教似镜清 /
今时学道尽莽卤或以口传或识情 /
纸授口传以为足祖庆遥隔万里程 /
大丈夫愿忘躯命回转一花五叶荣 /

揭谛揭谛波罗揭谛波罗僧揭谛菩提娑婆诃般若心经

君子易事而难说也落霞与孤鹜齐飞秋水共长天一色南村北村雨一犂新妇饷姑翁哺儿

南天棒白崖曰虚名万事雪埋井幻影百年绳系风

延享甲子改元冬诸子合心造活字 /
一字应放十孔方总数既垂二千字 /
其志留我睡余言我心匪石岂不喜 /
于此予还述此偈欲谢诸子亲切情 /
颂终合掌祈祝曰虚空尽我愿无穷 /
称赞般若功德聚普回向真如法界 /
归命三世诸佛陀及十方贤圣祖师 /
护法诸天龙夜叉大千世界诸神祇 /
愿我住庵诸兄弟道情勇徤如金刚 /
向上玄关速透过心性戒珠常圆明 /
诸魔挠尽扫除去利益群生无休期 /
