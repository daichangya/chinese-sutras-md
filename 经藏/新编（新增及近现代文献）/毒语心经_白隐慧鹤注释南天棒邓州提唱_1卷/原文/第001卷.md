# 毒語心經 · 第一卷

> 白隱慧鶴註釋　南天棒鄧州提唱

---

## 著語竝頌

葛藤窟裡瞎老漢無裩卻歸草裏坐可憐傅大士處處失樓閣莫言冷淡無滋味一飽能消萬劫飢

南天棒白崖曰無風起浪肚裏參天荊棘

聽松子卿曰南天棒老漢雲衲之頃在尾陽總見僧堂偶隣單老兄見有所持寫本之毒語心經者羨望不已速借該書而以及一讀有夜途明炬霧海南針感依而書寫之于時文久三癸亥年仲秋也後來平常持坐右愛讀不怠向白隱東嶺兩尊宿一一下語評唱矣野衲于曩方著述南天棒提唱毒語心經次白隱東嶺兩尊宿之著語評注可以南天棒老漢之評句錯而加提唱之話頭編輯慚汗慚汗今當編白崖窟語錄正錯依命一句一字不加校訂露出其肺腑參學士宜可究可參

撥轉參天爛葛藤絆纏四海五湖僧 /
願君認得出身路藕線孔中弄快鷹 /

摩訶

唐飜云大是什麼四維上下無等匹多錯作廣愽會了君子愛財取之有道為我過小底般若來

南天棒白崖曰大破關中收圖書

百億須彌毫末露三千世界海中漚 /
蟭螟眼裏雙童子玩弄閻浮爭未休 /

般若

唐飜云智慧人人具固固圓弄泥團漢有何限不嶮崖撒手未曾見在何故燈下不截爪可令尺蠖辨長短莫使蝸牛耕石田

南天棒白崖曰石虎吞却木羊兒

雙耳如聾眼如盲虛空夜半失全身 /
不容令鶖子親見戾脚波斯過別津 /

波羅密多

唐飜云到彼岸者裏是什麼所在掘土求青天蝦跳不出斗寶所在近更進一步釣絲絞水謝郎舟明眼衲僧暗結愁

南天棒白崖曰窮鳥入懷則獵人不忍射

大地誰是此岸人甚憐錯立洪波津 /
參究若未命根斷修歷三祗抂苦辛 /

心

歷劫無名錯安著名字金屑眼中翳衣珠法上塵是什麼多錯認驢鞍橋學道之人不識真唯為從前認識神無量劫來生死本癡人喚為本來人

南天棒白崖曰仁者見之謂之仁智者見之謂之智

分明三世不可得一掃長空絕點埃 /
禪榻夜闌冷如鐵半窓明月帶梅來 /

經

如是我聞一時佛在咄誰舒卷多向故紙堆中求黃卷赤軸又百合一片

南天棒白崖曰一粒粟中藏世界半升鐺內煑山川

畢波羅窟裏未結集此經童壽譯無語 /
阿難豈得聽北風窓紙隙南鴈雪蘆汀 /
山月苦如瘦寒雲凍欲零千佛縱出世 /
不添減一丁

觀自在

補陀巖薩埵人人具大士盡大地一箇不見不自在底人咳唾掉臂終不假別人力誰繫縛儞著伸左手搔佛首即非無屈右手觸狗頭何日免得

南天棒白崖曰睡美不知山雨過覺來殿閣生微凉

執捉運奔不假他唯因情念積多罪 /
是非憎愛總拈拋許汝生身觀自在 /

菩薩

簡異二乘與十號暫時假設菩薩名在途中不離家舍離家舍不在途中為君奪卻四弘願行卻是君子可八

南天棒白崖曰只今唯有西江月曾照吳王宮裡人

超出我空無相窠沈浮業海生死波 /
南無救苦大悲身百億分身無際涯 /

行

道什麼事生也夜眠晝走放尿屙屎行雲流水墜葉飛花擬議三途地獄雖然恁麼地非一回白汗流親見徹大有事在

南天棒白崖曰自携瓶去沽村酒却着衫來作主人

手捉腳運惟什麼飢餐渴飲作麼生 /
箇中若著一毫相復為渾沌眼睛 / 󰦥

深般若波羅密多

咄剜好肉生瘡怪哉所謂般若其何為物哉既是有淺深將其似河水者乎試道作麼生是有淺深底般若恐有認楚雞去

南天棒白崖曰烏龜帶劒上燈臺

求空破色之言淺全色見空此日深 /
若把色空談般若甕中跛鼈逐飛禽 /

時

又是剜好肉了去劫已前來劫後吹毛匣裏靈光寒和盤托出夜明珠

南天棒白崖曰庭樹不知人去盡春來還發舊時花

昨晨掃卻舊年煤今夜鍊磨新歲鎚 /
帶根松矣葉加橘還着新衣待客來 /

照見

爍迦羅眼絕纖埃莫向石灰籮裏眨眼者裏是何所在盡大地是沙門一隻眼只是玄沙道底

南天棒白崖曰漢來漢現胡來胡現

蟭螟眼裏蟻旋磨蟣蝨耳中蛛結羅 /
兜率閻浮泥犂獄分明掌上庵摩羅 /

五薀皆空

靈龜拽尾爭免得其蹤色薀如鉄圍山受想如金剛劍行識如如意寶只知途路遠不覺又黃昏

南天棒白崖曰短袴長衫白苧巾咿咿日下急推輪

認他色受想行識執作自家娟媿躬 /
譬似浮漚留水上或如閃電拂長空 /

度一切苦厄

客杯弓影元非蛇夢裏明明三世有覺來空空大千無

南天棒白崖曰洛陽路上相逢著盡是經商買賣人

後鬼推扃前鬼拄兩頭奮力汗通身 /
終宵爭拒漸天曉堪笑元惟相識人 /

舍利子

咄小果尊者有什麼長處者裏佛祖乞命內秘外現著何處淨名室內不能轉女身七狂八顛忘却麼

南天棒白崖曰科頭箕踞長松下白眼看他世上人

智是祗園第一枝驚奔長爪托胎時 /
親參大士留此典羅睺教師鶖女兒 /

色不異空空不異色

好一釜羹被兩顆鼠糞污却美食不當飽人喫拂波求水波是水

南天棒白崖曰若把西湖比西施淡粧濃抹兩相宜

色不遮空空體色空非破色色身空 /
色空不二法門裡跛鼈拂眉立晚風 /

色即是空空即是色

是何閒家具母教猱升木又是二千年滯貨釣絲絞水謝郎舟

南天棒白崖曰漁歌煙浦咸稱富貴樵唱雲村共樂昇平

黃鳥風微希皷瑟紅桃日暖薄籠煙 /
蛾眉螓首一群玄各戴花枝錦繡肩 /

受想行識亦復如是

荒草裏橫身見怪不怪其怪自壞雪佛日出後一場懡㦬

南天棒白崖曰石女舞成長壽曲木人唱起太平歌

地風火水飛禽跡色受想行眼裏花 /
石女擲梭張瘦臂泥牛蹴浪皷瞋牙 /

舍利子是諸法空相

揑目強生花從來無諸法何求空相淨地上撒屙

南天棒白崖曰只見錐頭利不知鑿頭力

山河大地蜃樓湧地獄天堂海市開 /
淨邦穢土龜毛筆生死涅槃兔角枝 /

不生不滅不垢不淨不增不減

可愍新鮮果凭麼否何計諸法不生不滅無謾人好手臂不向外曲

南天棒白崖曰水帶荷花白煙和楊柳青

眼裏童子期客出谷神不死待人叫 /
眾生界畔不污染諸佛土中淨相無 /
分八萬門何欠少容三千剎若隣虛 /
邯鄲枕上新尊貴又入南柯納稅租 /

是故空中

狐窠鬼窟陷墜多少行人湛湛黑暗深坑誠可怖畏

南天棒白崖曰擊碎我法二空見泥獄踏斷今時那邊瞎兔徑

凍餒百餘僧鳳凰各展臘扇賀新陽 /
壁懸碧目紫髯老瓶入氷肌玉骨芳 /
寒鎖琴唇黃鳥口暖浮禪榻赤麟盲 /
編茅包贈自然蕷封圈寄來養老糖 /

無色無受想行識

夢幻空花何勞把捉得失是非須放過事起叮嚀用空無去為什麼

南天棒白崖曰青山自青山白雲自白雲

寥廓虛凝寂滅場山河大地只是名 /
開心為四合色一心色從來空谷聲 /

無眼耳鼻舌身意無色聲香味觸法無眼界乃至無意識界

有眼耳鼻舌身意有色聲香味觸法秋天曠野行人斷馬首西來知是誰

南天棒白崖曰深溪絕無樵子語陰崖卻有獵人過

六識纔生六境浮意根休處六塵休 /
根境識為十八界譬如滄溟發一漚 /

無無明亦無無明盡乃至無老死亦無老死盡

紫羅帳裏撒真珠破布囊裡真珠知者正知是寶牛飲水成乳蛇飲水成毒五雲常擁人不到肅索仙家十二樓

南天棒白崖曰江上晚來堪畫處漁人披得一簑歸

十二緣生十二滅生名凡夫滅聖人 /
此維獨覺所觀境空裏浮飛眼裏塵 /
眼裏飛塵誰見得可貴圓頓大法輪 /
法輪影裏親薦取超過疥癩野干身 /

無苦集滅道

夜明簾外珠痴人按劒立水中鹽味色裏膠青白鷺下田千點雪黃鵬上樹一枝花

南天棒白崖曰山家富貴銀錢樹漁父風流玉一簑

通紅四箇鐵崑崙夜半著鞋雲外奔 /
集諦苦諦道滅諦非終非始非圓頓 /
陳如跋提及拘利不覺自燎却面前 /
莫謂鹿園摝蝦蜆金仙密待大乘根 /

無智亦無得

又是鬼家活計此語錯會底甚多棺木裡瞠眼分明紙上張公子盡力高聲喚不󰉵

南天棒白崖曰枯木裏龍吟髑髏裡眼睛

黑火洞然黑暗光茫茫天地失玄黃 /
山河不在鏡中觀百億須彌空斷膓 /

以無所得故菩提薩埵

放下著抱臟叫屈隨緣赴感靡不周而常處此菩提座不明三八九對境多所思

南天棒白崖曰覔火和烟得擔泉帶月歸

菩提薩埵摩訶薩唐飜道大心眾生 /
入三途代眾生苦遊戱十方不待請 /
誓不取偏真小果上求菩提化有情 /
虛空直饒消殞盡永鞭願輪利群氓 /

依般若波羅密多故

苦屈苦屈若見一法可依怙驀地須吐却幽州獨自可最苦是江南

南天棒白崖曰苦瓠連根苦甜瓜徹蔕甘

可談羅漢有貪瞋莫說菩薩依般若 /
若見一法有所依非無罣礙即繫縛 /
菩薩般若體無殊如珠走盤瀟洒落 /
非愚非智非聖凡只恨畫蛇添雙脚 /

心無罣礙無罣礙故無有恐怖遠離一切顛倒夢想

不是分外事神通竝妙用荷水也搬柴舉頭殘照在元是住居西

南天棒白崖曰桑柘影斜秋社散家家扶得醉人歸

非心非性非涅槃非佛非祖非般若 /
十界無孔熱鐵鎚虛空繫碎常寥廓 /
纔開口獅子嚬吟狐兔狸貉盡驚懼 /
應物現身如幻師隨機轉變無造作 /
見他李母患左肩數壯灸張婆右脚 /
顛倒夢想恐懼憂宛如一滴投巨壑 /
赤使齊時被輕裘鯉逝時有棺無椁 /
喚起庵中午眠僧告山童折籬偷籜 /

究竟涅槃

陷人坑子年年滿又是鬼家活計充什麼臭皮韈吾黨之直者異於是父為子隱子為父隱

南天棒白崖曰日日日東出日日日西沒

一切眾生生滅心直維諸佛大涅槃 /
木雞含卵立棺木瓦馬逐風歸本貫 /

三世諸佛依般若波羅密多故

壓良為賤大抵還他肌骨好不塗紅粉自風流鑊湯無冷處

南天棒白崖曰十謁朱門九不開滿身風雪又歸來

般若生三世諸佛三世諸佛演般若 /
主伴無盡唵蘇魯舊巢受風鳴宿鶴 /

得阿耨多羅三藐三菩提

不可向虛空裏釘橛去犢牛縱可生兒諸佛終不依般若得菩提何故般若菩提體無二故若又更有一法可得即非如來譬如大火聚進傍則佛祖亦喪身失命

南天棒白崖曰竹影拂階塵不動月穿潭底水無痕

白獺可緣木得魚佛不依法得菩提 /
道如來有一法得如道應真各有妻 /

故知般若波羅密多是大神咒

擔水河頭賣何樓漆器莫拈出字經三寫烏焉成馬又是小賣弄夜行莫踏白非水多是石

南天棒白崖曰寥寥天地間獨立有何極

可貴自性大神呪轉熱鐵丸作醍醐 /
地獄閻浮天上界雪花一片落紅爐 /

是大明咒

莫謂大明咒拗折山形柱杖子從來大地黑漫漫乾坤失色日月吞輝黑漆桶裏盛黑汁

南天棒白崖曰風吹碧落浮雲盡月上青山玉一團

本有圓成大明咒光明寂照盡山河 /
無量曠劫罪障海水上浮漚眼裏花 /

是無上咒

跟下又作麼生為我拈將最下底來墜葉雖憐疎雨感黃粱爭似暮雲親󱯾

南天棒白崖曰細雨洒花千點雨淡烟籠竹一堆愁

最上最尊最第一釋迦彌勒猶伊奴 /
此是人人本具物唯要當人絕後蘇 /

是無等等咒

話作兩橛那一橛著何處誰道上下四維無等匹七花八裂德雲間古錐幾下妙峯頂傭他癡聖人擔雪共填井

南天棒白崖曰欲修行利濟人却成此不唧漢𠺕

舊年寒苦梅得雨一時開疎影月移去 /
暗香風送來昨是埋雪樹今復帶花枝 /
喫困寒多少可貴百卉魁 /

能除一切苦

劈百合求中心削圓方竹杖輓卻紫茸氈九九元來八十一一九與二九相逢不出手

南天棒白崖曰白雲堆裏不見白雲流水聲裡不聞流水

儞若心空及第來五陰四大一時灰 /
天堂地獄間家具佛界魔宮百雜摧 /
黃鳥張聲和白雪烏龜帶釰上燈台 /
若人欲得此三昧白汗通身須一回 /

真實不虛

者箇是大小大虛妄箭過新羅終日交肩我何似生

南天棒白崖曰女為愛己者粧士為知己者死生己者母知己者鮑叔也

齊晏殺三士蜀維敗兩將假鷄聲避虎 /
賣狗肉懸羊指鹿見人伏著蜂斷父望 /
陶朱携越女紀信降楚王吞炭伏橋下 /
投簪泣井傍載主屍兼魴折父齒咬耳 /
明中修棧道暗裏度陳倉若是親見徹 /
匣中三尺霜

故說般若波羅密多咒

前頭是什麼如憎醉進酒酒濃元不在多盃十年歸不得忘却來時道

南天棒白崖曰吾徒不知錦囊重裏得青山暮色歸

一回舉了又一回積雪堆頭積雪堆 /
只是更無廻避處為誰醉後添多盃 /

即說咒曰

第二重亦在漁唱薪歌著何處鸎吟燕語作麼生莫入海擇浮漚

南天棒白崖曰狐猿叫落中岩月野客吟殘半夜灯

七字荒唐二十四又添四首五字城 /
不是呈高明諸老慰住庵飢寒弟兄 /
君若無轉身一路葛藤無底大深坑 /
莫言吾偈甚難解須知自家無眼睛 /
者裏若看難會處爛咬急切著神精 /
一回白汗親咬著和千七百拔根莖 /
吾曾辛苦窺涯際折此無星等子秤 /
無星秤子若拗折宛如獅子長威獰 /
禪門幸有此靈驗何不參究盡至誠 /
此道今人棄如土懸絲慧命誰相賡 /
我今非老好文術勸發諸方傑出英 /
上士一見知落處庸流還論他韻聲 /
宋朝司馬文正子可惜斯人眼未明 /
每見祖師難透話道成隱語惱後生 /
五無間業應懺悔謗法罪障甚不輕 /
世上今多此邪黨禪園荒落寔可驚 /
若君了佛祖心地於佛祖言豈如盲 /
辨自家得力真偽祖師言教似鏡清 /
