## 赞礼地藏菩萨忏悔发愿法

〔题解〕

《赞礼地藏菩萨忏悔发愿法》，中国人所撰礼忏发愿文，中国佛教三阶教经典。一卷。作者不详。

地藏菩萨是中国佛教崇奉的四大菩萨之一，地藏信仰也是中国佛教的重要信仰形态之一。作为幽冥教主，地藏菩萨在中国佛教中占有独特的地位。但地藏信仰在中国有一个发生、发展的过程。两晋南北朝时期，在佛典中，地藏菩萨衹是作为参加者偶尔出现在释迦牟尼的法会上。进入隋唐以后，他的地位逐渐提高，正式成为人们礼赞崇拜的对象，并由此出现一批与地藏菩萨相关的典籍。《赞礼地藏菩萨忏悔发愿法》亦为其中之一。

本文献抄写于唐代，约为七世纪后半叶到八世纪上半叶。值得注意的是：

第一，从本文献看，地藏菩萨完全没有显现出幽冥教主的神格，这说明，直到八世纪上半叶，地藏菩萨还不具备后世赋予的幽冥教主的身份。

第二，本文献虽然名为《赞礼地藏菩萨忏悔发愿法》，但其礼拜对象却极其庞杂，并非仅礼拜地藏菩萨。这种表现形态蕴含着什么意义，值得进一步研究。

第三，本文献抄写在敦煌遗书BD05922号的末尾。该遗书共抄写三个文献，前面所抄的两个文献分别为《七阶佛名经》与《人集录依诸大乘经中略发愿法》。由于前两个文献均为公认的三阶教经典，而《赞礼地藏菩萨忏悔发愿法》的内容又与《人集录依诸大乘经中略发愿法》及三阶教思想相互呼应，因此，可以肯定《赞礼地藏菩萨忏悔发愿法》也属于三阶教经典。所以，地藏菩萨信仰与三阶教的关系，应该成为我们关注的问题。而对这一点，以前学术界尚缺乏充分的重视。

总之，本文献是研究地藏信仰在中国形成与发展的重要资料；也是近年发现的关于三阶教的新资料，对三阶教研究具有重要价值。

本文献的抄本，至今在敦煌遗书中仅发现一号。

地藏菩萨摩诃萨，五浊恶世救苦者。 /

愿救诸众生，离苦得解脱。 /

香鬘宝衣自严饰，两手各现如意珠。 /
光照十方诸佛国，见闻三障永清净。 /

愿救诸众生，离苦得解脱。 /

曾于过去无数劫，刀兵疫病饥馑时。 /

眷属悉现声闻像，照临大集礼世尊。 /
赞佛散华成宝盖，大众咸供唱善哉。 /
故我稽首大慈悲，地藏菩萨摩诃萨。 /
愿救诸众生，离苦得解脱。 /

故我稽首大慈悲，地藏菩萨摩诃萨。 /
愿救诸众生，离苦得解脱。 /

狮子奋迅幢三昧，善登一切智山王。 /
能伏外道诸邪论，为欲成熟诸有情。 /
所在佛国皆现住，发起无量胜功德。 /
故我稽首大慈悲，地藏菩萨摩诃萨。 /
愿救诸众生，离苦得解脱。 /

欲界他化自在天，乐变化天覩史多。 /
夜摩帝释四天王，地藏菩萨摩诃萨。 /
愿说正法救众生，离苦得解脱。 /

敬礼现作圣人身，大乘佛身菩萨身。 /

愿说正法救众生，离苦得解脱。 /

敬礼现作凡人身，转轮王身刹帝利。 /
婆罗门身茂舍身茂字吠音，戌达罗身丈夫身。 /

愿说正法救众生，离苦得解脱。 /

敬礼现作鬼神身，揵达缚身阿素洛。 /
紧捺洛身大蟒身，龙身药叉罗刹身。 /
鸠槃荼身毕舍遮，饿鬼羯咤布怛那。 /
奥阇诃洛诸鬼身，地藏菩萨摩诃萨。 /
愿说正法救众生，离苦得解脱。 /

敬礼现作畜生身，狮子香象牛马身。 /

敬礼现作地狱身，剡魔王身狱卒身。 /

我从无始生死来，愚痴憍慢毁三宝。 /
身语意业种种恶，自作教他见随喜。 /
今对佛前皆发露，惭愧忏悔愿除灭。 /
从今已往永不作，防护当来诸罪咎。 /

我今至诚发誓愿，从今生死尽后际。 /

唯愿慈尊哀摄受，我等所发真誓愿。 /

## 〔录文〕

至心忏悔：

忏悔已，归命三宝。

至心发愿：

发愿已，归命三宝。

〔录文完〕
