「不滅亦不生，不斷亦不常等。」 /

「我稽首禮佛，諸說中第一。」 /

「諸法不自生。」

「亦不從他生。」

「共生亦無性。」

「亦不無因生。」

「如諸法自性，不在於緣中。」 /

「以無自性故，他性亦復無。」 /

「亦非緣生果。」

「果不從緣有，有無果生止； /
若說生法時，無依無所生。」 /

「果不從緣生，此果緣中生。」 /

「果若別異解，無道理可依； /
若一法作成，果體不可立。」 /

「非無緣有果，無緣果亦無； /
如是世俗中，常性不可得。」 /

「非有亦非無，緣義和合爾。」 /

「諸法無自性，非有亦非無。」 /

「於此無緣法，云何有緣緣？」 /

「若法未生時，即不應有滅。 /
滅法何能緣？故無次第緣。」 /

「諸法無自性，非有亦非無； /
此有彼法起，如是無所有。」 /

「若謂緣無果，果從緣中出； /
是果何不從，非緣中而出？」 /

「若果從緣生。」

「是緣無自性。」

「從無自性生，何得從緣生？」 /

「如衣因所成，能成因別異； /
成法若自無，別異因何有？」 /

「果不從緣生，不從非緣生， /
以果無有故，緣非緣亦無。」 /

「已去無有去。」

「未去亦無去。」

「離已去未去，去時亦無去。」 /

「動處則有去，此中有去時。」 /

「非已去未去。」

「是故去時去。」

「云何於去時，而當有去法？ /
以離於去法，去時不可得。」 /

「若去時有去，則有二種去： /
一謂有去時，二謂去時去。」 /

「若有二去法，即有二去者。」 /

「以離於去者，去法不可得。」 /

「若離於去者，去法不可得。」 /

「去者即不去。」

「不去者不去。」

「離去不去者，無第三去者。」 /

「若言去者去，云何有此義？」 /

「若離於去法，去者不可得。」 /

「去法若欲去，非無去者去。」 /

「已去中無發。」

「未去中無發。」

「離已去未去，去時中無發。」 /

「去未去去時，云何有分別？」 /

「去者即不住。」

「不去者不住。」

「離去不去者，何有第三住？」 /

「去者若當住，云何有此義？ /
以離於去法，去者不可得。」 /

「去未去去時，止息諸分別。」 /

「所有行止法，皆同去義說。」 /

「去法即去者，是事則不然。」 /

「若謂於去法，即為是去者； /
作者及作業，即一性可立。」 /

「去法異去者，是事亦不然。」 /

「因去知去者，不能用是去。」 /

「先無有去法，故無去者去。」 /

「因去知去者，不能用異去； /
於一去者中，不有二去故。」 /

「若實有去法，去者不用三； /
不實有去法，去者不用三。」 /

「去法有不有，去者不用三。」 /

「是故去去者、所去處皆無。」 /

「見聞及嗅嘗，觸知等六根， /
此見等六根，說能取諸境。」 /

「是眼即不能，自見於己體。」 /

「若不能自見，云何能見他？」 /

「火喻即不能，成於眼見法。」 /

「去未去去時，前已答是事。」 /

「見若未見時，即不名為見。」 /

「若言能所見，此云何和合？」 /

「能見亦不見，見法無性故。」 /

「所見亦不見，見法離性故。」 /

「離見不離見，見者不可得。」 /

「以無見者故，云何有所見？」 /

「見可見無故，識等四法無。」 /

「四取等諸緣，云何當得有？」 /

「聞嗅味觸知，如是等諸根， /
而悉同於上，眼見法中說。」 /

「若離於色因，色即不可得。」 /

「離色因有色，色則墮無因； /
無因無有義，何法無因立？」 /

「若復離於色，有其色因者， /
即是無果因；無果因何立？」 /

「若已有色者，色因無所起； /
若無有色者，亦不用色因。」 /

「無因而有色，是事亦不然。」 /

「是故於色中，離有無分別。」 /

「果若似於因，此說即不然。」 /

「果若不似因，是事亦不然。」 /

「所有受心想，諸行一切種， /
及餘一切法，皆同色法說。」 /

「彼一切諸法，皆同色法說； /
若諍論安立，隨所起即空。」 /

「一切不離空，一切得成就。」 /

「若見一物性，一切法亦然； /
若解一法空，一切皆空故。 /
言說有所得，諸所作皆空； /
一切無所得，一切皆成就。」 /

「空相未有時，先無彼虛空。」 /

「云何無相中，彼有相可得？」 /

「無實相無體，云何相可轉？」 /

「於無相法中，相則無所相。」 /

「離有相無相，無異處可轉。」 /

「所相既無體，能相亦不立。」 /

「能相無有故，亦無有所相。」 /

「是故無能相，亦無有所相。」 /

「離所相能相，亦無有別相。」 /

「若使無有有，云何當有無？」 /

「有無既已無，誰為知解者？」 /

「非有體無體，無能相所相。」 /

「遣有言無性，亦不取無性； /
如說青非青，不欲成其白。」 /

「見有性無性，彼即少智慧； /
無真實微妙，聖慧眼開生。 /
雖觀於諸性，當寂止諸見； /
此即勝義諦，遠離一切見。」 /

「若先有染者，後有其染法； /
云何離染法，而有染者生？」 /

「有染者復染，云何當可得？」 /

「若有若無染，染者亦復然。」 /

「染者先有染，離染者染成。」 /

「有染復染者，亦云何當得？」 /

「如是若同生，亦復非道理； /
染法染者二，此當云何用？」 /

「彼染法染者，非一性有合。」 /

「異性若有合，云何當可得？」 /

「若一性可合，離伴亦應合。」 /

「異性若有合，離伴亦應合。」 /

「若異性有合，染染者何用？」 /

「若染染者二，各各自體成； /
是二若有合，前亦應得合。」 /

「異相不成合，汝欲求成合； /
合相若已成，復欲成其異。」 /

「如是染染者，非合不合成； /
諸法亦如染，非合不合成。」 /

「若生是有為，即應有三相。」 /

「若生是無為，不作有為相。」 /

「生等三法離，即無相業用。」 /

「住何有滅相？無常何有住？ /
若先有住法，後不復應有。 /
若常有無常，有住不有常； /
或先有其常，後即不有常。 /
無常與住同，若有其體者， /
有常即邪妄，或有住亦妄。」 /

「不於一時中，生住滅和合。」 /

「生住滅諸相，別有有為相； /
有即是無窮，無即非有為。」 /

「生生之所生，唯生於本生； /
本生之所生，復生於生生。」 /

「若謂是生生，能生於本生； /
生生從本生，何能生本生？」 /

「若謂是本生，能生於生生； /
本生從彼生，何能生生生？」 /

「若謂生生時，能生本生者； /
生生若未生，何能生本生？」 /

「如燈能自照，亦能照於他； /
彼生法亦然，自生復生他。」 /

「燈中自無暗，住處亦無暗， /
破暗乃名照，無暗即無照。」 /

「無少處可照，是燈何能照？ /
生亦無少分，生法可成就。」 /

「云何燈生時，而能破於暗？ /
彼燈初生時，不能及於暗。」 /

「燈若不到暗，而能破暗者； /
燈在於此間，應破一切暗。」 /

「若燈能自照，亦能照他者； /
暗亦於自他，暗蔽定無疑。」 /

「生法若未生，自體不能生。」 /

「生法若已生，生已復何生？」 /

「非已生未生，生時亦不生。」 /

「去未去去時，前品此已說。」 /

「若生時有生，彼生相已破。」 /

「云何生時生，而說為緣起？」 /

「若法眾緣生，彼自性寂滅。」 /

「是故生時生，如是皆寂滅。」 /

「若法未生時，如瓶等何有？ /
緣法假和合，生已復何生？」 /

「若生時有生，是即有所生？ /
諸生性如幻，此生復誰生？」 /

「若生已復生，是生即無窮。」 /

「若無生而生，法皆如是生。」 /

「有法不應生，無亦非道理； /
有無俱不然，前品此已說。」 /

「若滅時有生，無體而可得。」 /

「若法不滅時，彼體不可得。」 /

「未住體不住，住不住相違； /
住住時不住，此復何有住？」 /

「若滅時有住，彼無體可得； /
住滅二相違，住位中無滅。」 /

「諸法於常時，皆有老死相。」 /

「而有何等法，離老死有住？」 /

「住不自相住，異住非道理； /
如生不自生，亦不從他生。」 /

「此住若未住，住體云何立？ /
此住若已住，復何住可成？ /
若已住更住，此住即無窮； /
若或無住住，法皆如是住。」 /

「已滅法不滅，未滅法滅空。」 /

「彼滅時亦然，無生何有滅？」 /

「此分位定住，先分位顯明。」 /

「異分位定住，先分位已滅。」 /

「如彼一切法，生相不可得； /
即此一切法，滅亦不可得。」 /

「若法是有者，滅即不可得； /
不可於一處，有有無二性。」 /

「無法即無果，滅亦不可得； /
如無第二頭，不可言其斷。」 /

「法不自體滅，他體亦不滅； /
如生不自生，他體亦不生。 /
此滅若未滅，自體可能滅； /
此滅若已滅，滅已復何滅？ /
是滅若有異，滅即是無窮； /
滅若無所滅，法皆如是滅。」 /

「生住滅不成，即無有為法； /
有為法不成，何得有無為？」 /

「如夢亦如幻，如乾闥婆城， /
所說生住滅，其相亦如是。」 /

「老亦不離老，老時無所有； /
此性老不成，異性亦如是。 /
是故一法中，老即不可得； /
老老而無老，非自體他體。 /
此老不自老，一切老亦然， /
老若有別異，老即是無窮。 /
解脫出離道，自具足亦然， /
若法離自相，果亦不可得。」 /

「已脫不可說，未脫不可說， /
脫未脫無說，脫時亦無說。 /
此解脫若異，解脫即無窮； /
若無脫而脫，皆如是解脫。」 /

「色法如聚沫，受即如浮泡， /
想同陽焰生，行如芭蕉相， /
識如彼幻法，顯示所立法， /
如夢如影像，亦同於響應。」 /

「應修善法行，勿修惡法行； /
修善法行人，二世安樂寂。」 /

「作者若有實，亦不作實業。」 /

「實所作無故，無所作差別。」 /

「有業無作者。」

「無實所作故。」

「有作者無業。」

「作者亦無實。」

「若實有作者，亦實有作業； /
作者及作業，二俱墮無因。」 /

「若有果無因，因即非道理。」 /

「作作者無體，作用不和合。」 /

「若無法非法，所作等無體。」 /

「法非法無故，從生果亦無。」 /

「無果無解脫，亦無生天道； /
非唯生天道，解脫道亦無。」 /

「作者實不實，亦不作二業； /
有無互相違，一處即無二。」 /

「作作者作用，所作實非實； /
著即生過失，此因如先說。」 /

「所作實不實，亦實亦不實； /
作者及作業，此因如先說。 /
作者諸所作，非實非不實； /
應知業亦然，此因如先說。 /
實所作即無，不實又無因； /
有無互相違，一處何有二？」 /

「因作者有業，因業有作者。」 /

「世俗遣異性，我見成就相。」 /

「若勝義諦中，有作者作業； /
彼能取所取，此亦應遮遣。 /
作者作業等，此義如是故； /
餘法自及他，相因義應觀。」 /

「眼耳等諸根，受等心所法； /
彼所取若成，有取者先住。」 /

「若無彼先住，何有眼耳等？」 /

「以是故當知，先已有法住。」 /

「眼耳等諸根，受等心所法， /
有法先住者，以何可了知？」 /

「若離眼等根，有法先住者。」 /

「應離眼耳根，有見等無疑。」 /

「一切眼等根，實無法先住。」 /

「眼等根所取，異相復異種。」 /

「若眼等諸根，無法先住者； /
彼眼等諸根，當云何先有？」 /

「若見即聞者，聞者即受者； /
一一有先住，如是非道理。」 /

「若見聞各異，受者亦復異； /
見時若能聞，即成多我體。」 /

「眼耳等諸根，受等心所法， /
彼從諸大生，彼大無先住。」 /

「眼耳等諸根，受等心所法， /
若無先住者，眼等亦應無。」 /

「彼眼等先無，今後亦復無， /
以三時無故，有性皆息滅。」 /

復次頌言：

釋曰：遣一性故。

釋曰：薪火二法遣異性故。

釋曰：總遣異性故。此中薪火二法，一性異性俱不可見，如瓶非木。又如水中蓮花，異性不成故。是故勝義諦中薪火二法非相因有，而彼二法畢竟空故。

復次頌言：

釋曰：一性異性互相因待次第不成。復次頌言：

釋曰：彼能取所取非作者作業一性可著，亦非異性所取，離亦不生。若異性所取，即互不到，不到即不燒，不燒即不滅，不滅即是常。若法常住，彼即互相因待不成。若成不成，二法相因畢竟無體。若人計火從餘方來，有其能取及所取者，此義不成。故下頌言：

釋曰：彼瓶衣等因果二法，同生不同生、能相所相，彼等所成，如非泥團即是其瓶，彼瓶果法有作用故。亦非異瓶別有果法作用所成，非彼二法互相因待，若成不成相因無體。此如是故，餘處隨應所說亦然。若勝義諦中無一異性，是故不應取著。

如有頌言：

復次頌言：

「若火即是薪，作作者一性。」 /

「若薪異於火，離薪應有火。」 /

「異即應常然，火不因薪故； /
薪即復無功，此業用相違。」 /

「火若常然者，然火功相違； /
此如先所說，離薪別有火。」 /

「異火即不到。」

「不到即不燒。」

「不燒即不滅。」

「不滅即常住。」

「若異薪有火，即薪能到火； /
如此人至彼，彼人至此人。」 /

「若異薪有火，欲令薪到火； /
彼二互相離，薪火何能到？」 /

「若因薪有火，亦因火有薪。」 /

「二何法先成，薪火相因有。」 /

「若因薪有火，火即成復成。」 /

「亦非不有薪，而有火可得。」 /

「若法有因待，是法還成待。」 /

「二法無所成，已成云何待？」 /

「若未成有待，未成當何待？」 /

「若因待有成，自待非道理。」 /

「二因成無體，無不因薪火。」 /

「因薪火亦無。」

「因火亦無薪。」

「火不餘處來。」

「薪中亦無火。」

「餘法亦復然，如去來品說。」 /

「即薪而無火。」

「異薪亦無火。」

「火中亦無薪，薪中亦無火。」 /

「如說薪火法，能所取亦然。」 /

「餘諸法皆同。」

「及彼瓶衣等。」

「非受非不受，異復云何有？ /
如能取所取，諸所說亦然。」 /

「若人執有我，諸法有實性， /
各各差別說，彼不解佛法。」 /

## 觀生死品第十一

復有人言：勝義諦中亦有生死。何以故？如佛所言：「生死長遠，眾生愚迷不知正法。我欲令彼如理修行得盡生死，乃作是言：『汝諸苾芻，應如是學。』」以此證知勝義諦中有其生死。

論者言：如佛所說，皆是方便世俗施設，非勝義諦，亦非不有生死而說。長時有法可盡，彼生死者眾生所受。若如理修行，即能盡彼生死有性。此中先說薪火二法能取所取彼等次第，此非道理。

復次頌言：

釋曰：此義云何？所言生死者即是無際，無際即無始。今此義者，無最上、無先際，故言無際。又非有彼先際，故名無際。故下頌言：

釋曰：先後義無體，無自性故，如兔角等，應如是見。由如是故，中亦不可得說，非不有故，如兔角等。

復次頌言：

釋曰：生死無自性，彼云何有？故下頌言：

釋曰：此中應問：如所表示無先後共，即次第不生，而何有眾生受生老死？又云何修行盡生死有性？此即不成。故頌答言：

釋曰：若不離老死而有生者、應不離老而有死邪？故下頌言：

釋曰：若或異法有所成者，譬如牛馬，異體應可同生。云何生不有死？又何不死有生？若生老死先有體者，即彼本來有其生死。

復次頌言：

釋曰：無因即無所依，無依即無生，無生即無相續有性。

復次頌言：

釋曰：此義云何？若言生時有其死者，以彼生滅二法無同時性。又復無因二俱不生，彼無性故。若或同生，又生老死無相待因性。

復次頌言：

釋曰：勝義諦中戲論不生故。

復次頌言：

釋曰：能知所知等一切法，先後共次第皆不和合。若先有果後有其因，果即無因，此即因有相違。若先有因後無果者，即因果不和合。若因果二法同時有者，如是決定彼因果性亦復無體。若已生若未生，二法相因俱無體故。能相所相，所說亦然。

復次頌言：

「大牟尼所說，生死無先際。」 /

「今此如是說，無先亦無後。」 /

「若無有先後，中復云何有？」 /

「是故此中無，先後共次第。」 /

「若使先有生，後有老死者， /
不老死有生。」

「後老死非理。」

「若使後有生，先有老死者； /
彼所有老死，無生即無因。」 /

「無此生老死，亦無有先後； /
老死亦復然，亦應與生共。」 /

「若不生即無，先後共次第； /
云何戲論言，有生老死合？」 /

「若諸法因果，能相及所相， /
所受及受者，真實義如是。」 /

「非但說生死，先際不可得； /
諸法亦復然，先際不可得。」 /

## 觀苦品第十二

復有人言：勝義諦中有彼諸蘊苦所成性。如佛所言：略說五取蘊，由苦所得故。

論者言：此等所說皆世俗諦，非勝義諦。何以故？此苦果故。此苦果者，多種分別。

復次頌言：

釋曰：有一類人欲令此苦各別繫屬。故下頌言：

復次頌言：

釋曰：若自作者，而彼諸法皆自體所成，非同生性故。若離自體，即無對待因性。亦非同生可有，故下頌言：

釋曰：緣所成故。此中若法緣所成性，即無自作，此遣法自相。又復亦非他作道理。

復次頌言：

釋曰：今此五蘊與未來五蘊諸有所作，非此二法互有他性。何以故？滅與未生二無性故。此中亦非苦能作苦，自作他作云何可成？

復次頌言：

釋曰：若復離蘊無所施設，彼復云何有苦可作？

復次頌言：

釋曰：此非離苦而復有苦，苦無異故。

復次頌言：

復次頌言：

釋曰：或有人言：若人自作苦，即非他所成，應有他作邪？對此異意，故下頌言：

釋曰：今此如是，非有所作，亦非有苦。若以彼苦自作苦者，即自所作，道理相違。是故此說以無有人何有他作？彼無性故。若復他無自體，是中云何他能作苦？若人自體不生，即無所有。他體不生，即無他作，是故無有他能作苦。若或自他二法共作苦者，亦非道理。

復次頌言：

如有頌言：

釋曰：勝義諦中苦無體故。

復次頌言：

釋曰：此復云何？色等亦然。故下頌言：

釋曰：色非自體作故。彼能作所作，若有若無，皆非所作。若有能作，即所作無體。無即非能作，云何無中計有我作？此即著於能作。亦非他法成已復成色法作用，是中亦非他性可成。今此所說，若從緣生，彼即無有異法可得，亦非自他緣法不生，又一切法非無因故。由是勝義諦中色等諸法體不可得。

「自作及他作，共作無因作。」 /

「彼等於諸果，所作非道理。」 /

「苦若自作者，即不從緣成。」 /

「以有此蘊故，有未來五蘊。」 /

「若有此五蘊，與未來蘊異； /
於此彼蘊中，應有他作苦。」 /

「若人自作苦，離苦何有人？ /
云何自作中，離人而有苦？」 /

「若苦他人成，授與此人者； /
他亦名自作，離苦何有苦？」 /

「若他人作苦，離他何有苦？ /
亦非有作已，他能授於此。」 /

「自作若不成，復何有他作？ /
若他人作苦，即亦名自作。」 /

「苦不名自作，亦非他人作， /
是故所作中，離苦人無體。」 /

「若有自他作，即有共作苦； /
今無自他共，無因亦非理。」 /

「他相若自作，他相此無因； /
此若有自因，何有無因作？」 /

「非但說於苦，四種俱不有。」 /

「外諸法皆同，四種俱不有。」 /

## 觀行品第十三

前品所說破色等蘊，此即亦有對治相違。何以故？如佛所言：「諸苾芻！汝等應當如實了知色是無常，乃至識法亦是無常。」以此文證，有色等蘊。

論者言：此世俗諦增上所說，非勝義諦。故有頌言：

釋曰：此虛妄者，是邪智境界。愚人不實，於虛誑法無分位中計色有性。

復次頌言：

釋曰：此即無所得相違。故下頌言：

釋曰：無所有故，譬如兔角，虛妄之法而不和合。是故虛妄法者，雖有所說皆是虛妄。故佛世尊廣為開示，普盡一切若根若隨煩惱、所知二障等法皆悉是空，使令除斷，即彼空性離二邊故。此中所說諸虛妄法，決定皆是世俗諦有。若虛妄法，於勝義諦中如乾闥婆城。又或虛妄法者，雖復所說，是中亦非妄法可有，故佛世尊諸有所說悉無相違。若言諸法不有，即是證成自性空義，遣妄執故。

復次頌言：

釋曰：若見有法變異之性，彼即無我。無我即無常，無常即不有。如是所說，是為虛妄。此法如是。故下頌言：

釋曰：雖說諸法皆空，即彼諸法猶如空花，亦非有彼無自性法，又或無所成故。

復次頌言：

釋曰：若法有異，自性亦異。若彼諸法無自性者，即不和合。是故若見諸法各各自性有別異者，云何不說此為虛妄？故下頌言：

釋曰：若其無者，即無法可有異性和合。計有性者，即墮過失。此復云何？

復次頌言：

釋曰：若後異者，譬如老作老相，此即自比量相違。

或有人言：若不離自體有法可異者，乳應即成酪。若爾，即有因一向過失。

復次頌言：

釋曰：亦非離彼滋味氣勢報體等法乳即成酪，以緣性故。又復亦非異乳有酪，此即於第二時有一向過失。故下頌言：

釋曰：亦非異乳有酪可得，此即不墮一向過失。是故無有異法可見，有即虛妄。何以故？自性空故。勝義諦中亦無少分不空之法，對待空法而有所成。

復次頌言：

釋曰：因不成故，此中非有空法可說。今此如是證成世尊所說空義。如其所說，此復云何？故下頌言：

釋曰：此即遣諸空執。諸佛世尊所說無疑，何況有異？若欲有其空者，此乃於法自性有所取著。此中亦非有性可取，應當捨離。若或於空有所取者，此即邊執。彼有執者無異方便，應知此等佛所不化。

「若彼虛妄法，是世俗有為； /
無妄涅槃法，即是勝義諦。」 /

「彼虛妄法者，諸行妄取故。」 /

「即彼虛妄法，是中何所取？」 /

「諸法無自性，見有異性故。」 /

「無性法亦無，一切法空故。」 /

「若法無自性，法云何有異？」 /

「若法有自性，亦復何有異？」 /

「若諸法即異，無異法可有； /
現住法若異，後變異不成。」 /

「若法即有異，乳應即成酪。」 /

「若或異於乳，云何得成酪？」 /

「若有不空法，即應有空法； /
無少不空法，何得有其空？」 /

「遣有故說空，令出離諸見； /
若或見有空，諸佛所不化。」 /
