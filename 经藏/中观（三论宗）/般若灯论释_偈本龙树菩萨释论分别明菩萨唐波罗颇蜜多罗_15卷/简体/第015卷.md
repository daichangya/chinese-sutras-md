# 般若灯论释 · 第十五卷

> 偈本龙树菩萨  释论分别明菩萨  唐 波罗颇蜜多罗译

---

普断诸分别，灭一切戏论， /
能拔除有根，巧说真实法。 /
于非言语境，善安立文字， /
破恶慧妄心，是故稽首礼。 /

「不灭亦不起，不断亦不常， /
非一非种种，不来亦不去。 /
缘起戏论息，说者善灭故， /
礼彼婆伽婆，诸说中最上。」 /

「无时亦无处，随有一物体， /
从自他及共，无因而起者。」 /

「香附子苦参，庵摩罗除热， /
石女无有儿，竹笋重有苦， /
兔印记月光，阳春时作乐。」 /

「因缘及缘缘，次第增上缘， /
四缘生诸法，更无第五缘。」 /

「所有诸物体，及以外众缘， /
言说音声等，是皆无自性。」 /

「自我等诸体，内入等众缘， /
一一皆不有，以无自性故。」 /

「缘中无作者。」

「离缘亦无作。」

「若有若无作，诸缘作不成。」 /

「非定有定无，诸缘义应尔。」 /

「非有非非有，非有无法起。」 /

「婆伽婆所说，真实无缘法； /
此法体如是，何处有缘缘？」 /

「不起诸法灭，是义则不然； /
灭法则非缘，及何等次第？」 /

「诸法无自体，自相非有故。」 /

「此有彼法起，是义则不然。」 /

「非一一和合，诸缘中有果； /
如是则非缘，云何果得起？」 /

「若果缘中无，彼果从缘起； /
非缘中亦无，云何果不起？」 /

「缘及果自性。」

「诸缘无自体。」

「若缘无自体，云何转成果？」 /

「非无缘有果。」

「何有缘非缘？」

「若诸缘起彼无起，彼起自体不可得， /
若缘自在说彼空，解空名为不放逸。 /
若人知无一物起，亦复知无一物灭， /
彼非有故亦非无，见彼世间悉空寂。 /
本来寂静无诸起，自性如是已涅槃， /
能为依怙转法轮，说诸法空开示彼。 /
有无不起俱亦非，非有非无无起处， /
世间因缘悉如是，但彼凡夫妄分别； /
常无起法是如来，彼一切法如善逝。」 /

「已解彼诸阴，无起亦无灭； /
虽行彼世间，世法不能染。」 /

「已去不应受。」

「未去亦不受。」

「离已去未去，去时亦不受。」 /

「非已去未去，彼处去时去。」 /

「若去时去者，云何有是义？」 /

「去时去空故，去时去不然。」 /

「说去时去者。」

「去时中无去。」

「去和合去时，去者唯分别。」 /

「若去时中去，复及此行去， /
则堕二去过，此义则不然。」 /

「若有二去法，则有二去者。」 /

「离去者有去，是义则不然。」 /

「离去者无去。」

「离去者有去，是义则不然。」 /

「若其无彼去，何处有去者？」 /

「彼去者不去。」

「未去者不去。」

「异去及未去，无第三去者。」 /

「若谓去者去，此义云何成？」 /

「去者无去故，不成义如是。」 /

「去者去既空，何有去者去？」 /

「去者与去合，则堕二去咎。」 /

「一去了去者，二谓去者去。」 /

「离去者有去，是义则不然。」 /

「已去中无发，未去亦无发， /
去时中无发，何处当有发？」 /

「未发无去时，亦复无已去， /
彼初起去空，未去何处发？」 /

「无已去未去，亦无彼去时； /
于无去法中，何故妄分别？」 /

「如是一切时，未曾见初发， /
而言有去等，过失则甚多。」 /

「去者则不住。」

「未去者不住。」

「异去未去者，谁为第三住？」 /

「去者若当住，此义云何成？ /
去者去空故，去住不可得。」 /

「去时则无住。」

「无彼已去故。」

「去起作及息，其过同去说。」 /

「去法即去者，如是则不然； /
去法异去者，是义亦不然。」 /

「若谓彼去法，即是于去者， /
作者及作业，则为一体过。」 /

「若谓彼去法，定异于去者。」 /

「离去有去者，离去者有去。」 /

「去者及去二，为一异故成。」 /

「彼二无有成，云何当有去？」 /

「因去了去者，彼去则不去。」 /

「如见有是人，往村等去故。」 /

「先无有去法，故无去者去。」 /

「因去了去者，异去亦不去。」 /

「此物与彼物，有异者不成。」 /

「去者是一故，去有二不然。」 /

「有实无有实，亦有实无实， /
如是三去者，各不用三去。」 /

「是故去无性，去者亦复然， /
去时及诸法，一切无所有。」 /

「眼耳及鼻舌，身意等六根， /
彼色等六尘，如其数境界。」 /

「如是彼眼根，不能见自体， /
自体既不见，云何得见他？」 /

「有分眼见色，非彼能依识。」 /

「眼不见色尘，意不知诸法， /
此名最上实，世人不能度。」 /

「彼一切诸法，若先有自体； /
如是有眼根，云何不自见？」 /

「识不在眼色，不住二中间， /
非有亦非无，彼识住何处？」 /

「火喻则不能，成彼眼见义。」 /

「去未去去时，已总说遮故。」 /

「眼若未见时，不得说为见； /
而言眼能见，是义则不然。」 /

「见则无彼见，非见亦无见。」 /

「若已遮于见，应知遮见者。」 /

「离眼不离眼，见者不可得。」 /

「见者无有故，能所二皆空。」 /

「见所见无故，识等四种无。」 /

「彼取缘等果，何处当可得？」 /

「耳鼻舌身意，闻者所闻等， /
应知如是义，皆同眼见遮。」 /

「内外地界无二义，如来智慧能觉了， /
彼无二相及不二，一相无相如是知。」 /

「『眼不能见色，意不知诸法， /
此是无上谛，世间不能了。』」 /

「若离于色因，色则不可得。」 /

「若当离于色，色因亦不见。」 /

「离积聚无体，彼觉无可取， /
故知缘起空，我说无自性。 /
无物从缘起，无物从缘灭， /
起唯诸缘起，灭唯诸缘灭。」 /

「此物与彼物，异者则不然。」 /

「不异无有体，束芦及别处， /
若一若异等，凡夫妄分别。」 /

「离色因有色，色则堕无因。」 /

「无因而有物，终无有是处。」 /

「若离色有因，此因则无果； /
无果而有因，云何有是义？」 /

「色若已有者，则不待色因； /
色若先无者，亦不待色因。」 /

「无因而有色，是义则不然。」 /

「是故于色境，不应生分别。」 /

「若果似因者，此义则不然。」 /

「若果不似因，义亦不应尔。」 /

「受阴及心阴，想行一切种， /
如是等诸法，皆同色阴遮。」 /

「若观一物体，则见一切体； /
如是一物空，一切皆空故。」 /

「我为世间说诸阴，彼阴为彼世间依， /
能于彼阴不作依，世间诸法得解脱。 /
世间如彼虚空相，彼虚空相亦自无， /
由如是解无所依，世间八法不能染。」 /

「三有假施设，物无自体故， /
但于假设中，妄想作分别。 /
以觉分别时，自体不可得， /
以无自体故，彼言说亦无。」 /

「先虚空无有，毫末虚空相。」 /

「此中验虚空，无毫厘实体。」 /

「若先有虚空，空则是无相。」 /

「无处有一物，无相而有体。」 /

「无相体既无，相于何处转？」 /

「无相相不转，有相相不转。」 /

「离有相无相，异处亦不转。」 /

「所相不成故，能相亦不成。」 /

「是故无所相，亦无有能相。」 /

「离所相能相，是体亦不有。」 /

「离色因有色，是义则不然， /
色本无体故，无体云何成？」 /

「无有体。」

「何处？」

「无体当可得？」

「与体无体异，何处有解者？」 /

「是故知虚空，非体非无体， /
非所相能相，余五同虚空。」 /

「先地等无有，微毫相可得。」 /

「有无俱是边，乃至心所行； /
彼心行灭已，名为正心灭。」 /

「遮有言非有，不取非有故； /
如遮青非青，不欲说为白。」 /

「少慧见诸法，若有若无等， /
彼人则不见，灭见第一义。」 /

「世间如空相，虚空亦无相， /
若能如是知，于世得解脱。」 /

「染者不知法，染者不见法， /
若人安受此，名为极盲暗。」 /

「若先有染者，离染染者成。」 /

「因染得染者，染者染不然。」 /

「染者先有故，何处复起染？」 /

「若有若无染，染者亦同过， /
染者先有染，离染者染成。」 /

「离染者染成，不欲得如是。」 /

「有染复染者，何处当可得？」 /

「染及染者二，同时起不然； /
如是染染者，则不相观故。」 /

「染及染者一，一则无同时。」 /

「染及染者异，同时亦叵得。」 /

「若别同时者，离伴亦应同。」 /

「若别同时起，何用染染者？」 /

「若染染者二，各各自体成， /
何义强分别，此二同时起？」 /

「如是别不成，求欲同时起； /
成立同时起，复欲别体耶？」 /

「有何等别体，欲同时起耶？」 /

「由染染者二，同不同不成； /
诸法亦如染，同不同不成。」 /

「若起是有为，亦应有三相。」 /

「若起是无为，何名有为相？」 /

「起等三次第，无力作业相。」 /

「离住无法体，无常何有住？ /
若初有住者，后时不应故。 /
若常有无常，一切时无住； /
若先是常者，复不得无常。 /
若无常与住，共法体同时， /
有住无无常，有无常无住。」 /

「云何于一物，同时有三相？」 /

「若诸起住坏，有异有为相， /
有则为无穷。」

「无则非有为。」

「彼起起起时，独起根本根， /
根本起起时，还起于起起。」 /

「若谓起起时，能起根本起； /
汝从本起生，何能起本起？」 /

「若谓根本起，能起彼起起； /
彼从起起生，何能起起起？」 /

「汝谓此起时，随所欲作起； /
若此起未生，未生何能起？」 /

「如灯照自体，亦能照于他； /
起法亦复然，自起亦起彼。」 /

「灯中自无暗，住处亦无暗， /
彼灯何所照，而言照自他？」 /

「云何灯起时，而能破于暗？」 /

「此灯初起时，不到彼暗故。」 /

「若灯不到暗，而破彼暗者； /
灯住于此中，应破一切暗。」 /

「若灯能自照，亦能照他者； /
暗亦应如是，自障亦障他。」 /

「此起若未起，云何生自他？」 /

「此起若已起，起复何所起？」 /

「起时及已起，未起皆无起； /
去未去去时，于彼已解释。」 /

「由起时名起，此义则不然； /
云何彼起时，而说为缘起？」 /

「由诸法无性，自体非有故； /
此有彼得者，如是则不然。」 /

「随处若一物，未起而有体。」 /

「已有何须起？」

「体有起无故。」

「若谓起起时，此起有所起。」 /

「彼起能起作，何等复起是？」 /

「若起更有起，此起无穷过。」 /

「若起无起起，法皆如是起。」 /

「有体起无用，无体起无依， /
有无体亦然，此义先已说。」 /

「若灭时有起，此义则不然。」 /

「法若无灭时，彼体不可得。」 /

「未住体不住，住体亦不住， /
住时亦不住，无起谁当住？」 /

「灭时有住者，是义则不然。」 /

「若法无灭时，彼体不可得。」 /

「彼一切诸法，恒时有老死； /
何等是住法，而无老死相？」 /

「住异住未住，此义则不然； /
如起不自起，亦不从他起。」 /

「此住若未住，自体云何住？ /
此住若已住，住已何须住？ /
住若异住住，此住则无穷； /
住若无住住，法皆如是住。」 /

「未灭法不灭，已灭法不灭， /
灭时亦不灭，无生何等灭？」 /

「法体若住者，灭相不可得。」 /

「法体若无住，灭亦不可得。」 /

「彼于此位时，不即此位灭； /
彼于异位时，亦非异位灭。」 /

「若一切诸法，起相不可得； /
以无起相故，有灭亦不然。」 /

「法若有体者，有则无灭相。」 /

「一法有有无，于义不应尔。」 /

「法若无体者，有灭亦不然； /
如无第二头，不可言其断。」 /

「法不自体灭，他体亦不灭； /
如自体不起，他体亦不起。」 /

「起住坏不成，故无有有为。」 /

「有为不成故，云何有无为？」 /

「如梦亦如幻，如干闼婆城， /
说有起住坏，其相亦如是。」 /

「应行善法行，恶法不应行， /
此世及后生，行者得安乐。」 /

「若有实作者，不作有实业。」 /

「若无实作者，不作无实业。」 /

「有实者无作。」

「业是无作者。」

「业及彼作者，则堕于无因。」 /

「无因义不然，无因无果故。」 /

「作及彼作者，作用具皆无。」 /

「法非法亦无，作等无体故。」 /

「若无法非法，从生果亦无。」 /

「有无互相违，一法处无二。」 /

「有者不作无，无者不作有。」 /

「此由着有过，彼过如先说。」 /

「作者实不实，亦实亦不实， /
不作三种业，是过先已说。 /
作业实不实，亦实亦不实， /
非俱作者作，过亦如先说。」 /

「缘作者有业，缘业有作者， /
由此业义成，不见异因故。」 /

「如业作者离，应知取亦尔。」 /

「及余一切法，亦应如是观。」 /

「眼耳等诸根，受等诸心法， /
此先有人住，一部如是说。」 /

「若取者无体，眼等不可得； /
以是故当知，先有此住体。」 /

「若眼等诸根，受等诸心法， /
彼先有取者，因何而施设？」 /

「若无眼等根，先有彼住者， /
亦应无取者，眼等有无疑。」 /

「或有取了人，或有人了取； /
无取何有人？无人何有取？」 /

「一切眼等根，先无一人住。」 /

「由彼眼等根，异异了彼异。」 /

「若眼等诸根，先无一住者， /
眼等一一先，彼别云何有？」 /

「见者即闻者，闻者即受者； /
一一若先有，是义则不然。」 /

「若见闻者异，受者亦差别。」 /

「见闻者不同，是我则多体。」 /

「眼耳及受等，所从生诸大， /
于彼诸大中，取者不可得。」 /

「眼先无取者，今后亦复无； /
以无取者故，无有彼分别。」 /

「以觉观察时，物体不可得； /
以无自体故，彼法不可说。」 /

「若火即是薪，作者作业一。」 /

「若火异于薪，离薪应有火。」 /

「如是常应燃，以不因薪故。」 /

「复无燃火功，火亦无烧业。」 /

「若火正燃时，汝谓为薪者； /
彼时唯有火，谁是可燃薪？」 /

「若异则不到。」

「不到故不烧，不烧故不灭， /
不灭住自相。」

「此物共彼物，异者则不然。」 /

「然异于可燃，此二能相至； /
如女至丈夫，如丈夫至女。」 /

「若然异可然，此二相到者。」 /

「火薪既有异，则不互相观。」 /

「若火观于薪，若薪观于火； /
何等体先成，而说相观有？」 /

「若火观薪者，火成已复成； /
薪亦当如是，无火可得故。」 /

「若此待得成，彼亦如是待； /
今无一物待，云何二体成？」 /

「若体待得成，不成云何待？ /
不成而有待，此待则不然。」 /

「无火可观薪，薪非不观火。」 /

「无薪可观火，火非不观薪。」 /

「火不余处来，薪中亦无火。」 /

「如薪余亦遮，去来中已说。」 /

「即薪非是火，异薪亦无火。」 /

「火亦不有薪，火中亦无薪， /
薪中亦无火。」

「已遮火及薪，自取如次第， /
一切净无余，瓶衣等亦尔。」 /

「若计我真实，诸法各各异； /
应知彼说人，不解圣教义。」 /

「离身不见法，离法不见身， /
不一亦不异，应当如是见。」 /

「生死有际不？佛言毕竟无。 /
此生死无际，前后不可得。」 /

「非独于生死，初际不可得； /
一切法亦然，悉无有初际。」 /

「此既无前后，彼中何可得？」 /

「是故前后中，次第此不然。」 /

「若谓生是先，老死是其后； /
生则无老死，不死而有生。」 /

「若先有老死，而后有生者； /
未生则无因，云何有老死？」 /

「生及于老死，俱时则不然； /
生时即死故，二俱得无因。」 /

「若彼先后共，次第皆不然。 /
何故生戏论，谓有生老死？」 /

「如是诸因果，及与彼体相， /
受及受者等，所有一切法， /
不但于生死，前际不可得， /
如是一切法，悉亦无前际。」 /

「苦集亦世间，见处及彼有。」 /

「有人欲得苦，自作及他作， /
共作无因作，彼果皆不然。」 /

「苦若自作者，则不从缘生。」 /

「由现阴为因，未来阴得起。」 /

「处处缘起法，不即是彼缘， /
亦不异彼缘，不常亦不断。」 /

「若前阴异后，后阴异前者； /
此阴从彼生，可言他作苦。」 /

「若人自作苦，离苦无别人； /
何等是彼人，言人自作苦？」 /

「若他人作苦，持与此人者； /
离苦何有他，而言他作苦？」 /

「自作若不成，何处有他作？ /
若他人作苦，彼还是自作。」 /

「自作苦不然。」

「苦不还作苦。」

「若他作苦者。」

「无他谁作苦？」

「若一一作成，可言二作苦。」 /

「自他二不作，无因何有苦？」 /

「不独观于苦，四种义不成； /
外所有诸法，四种亦皆无。」 /

「婆伽婆说彼，虚妄劫夺法。」 /

「若妄夺法无，有何名劫夺？」 /

「婆伽婆说此，为显示空义。」 /

「见法变异故，诸法无自体。」 /

「有体非无体。」

「由诸法空故。」

「自体若非有，何法为变异？」 /

「若法有自体，云何有变异？」 /

「彼体不变异，余亦不变异； /
如少不作老，老亦不作少。」 /

「若此体即异，乳应即是酪。」 /

「异乳有何物，能生于彼酪？」 /

「若一法不空，观此故有空； /
无一法不空，何处空可得？」 /

「若有解空者，皆是见法性。」 /

「若离于和合，无有如是体； /
是故空无起，我说无自性。」 /

「如来说空法，为出离诸见。」 /

「诸有见空者。」

「说彼不可治。」

「见可见见者，此三各异方， /
二二互相望，一切皆不合。」 /

「应知染染者，及彼所染法， /
余烦恼余入，三种皆无合。」 /

「异共异有合，此异不可得， /
及诸可见等，异相皆不合。」 /

「非独可见等，异相不可得， /
及余一切法，异亦不可得。」 /

「异与异为缘。」

「离异无有异。」

「若从缘起者，此不异彼缘。」 /

「异中无有异。」

「不异中亦无。」

「由无异法故，不异法亦无。」 /

「一法则不合，异法亦不合。」 /

「合时及已合，合者亦皆无。」 /

「法若有自性，从缘起不然。」 /

「若从因缘起，自性是作法。」 /

「若有自性者，云何当可作？」 /

「法既无自性，云何有他性？」 /

「自他性已遣，何处复有法？」 /

「若人见自他，及有体无体； /
彼则不能见，如来真实法。」 /

「有体既不立，无法云何成？」 /

「此法体异故，世人名无体。」 /

「佛能如实观，不着有无法， /
教授迦旃延，令离有无二。」 /

「法若有自体，则不得言无。」 /

「法有自性者，后异则不然。」 /

「若有是自性，则不得言无； /
自性有异者，毕竟不应然。」 /

「若无自性者，云何而可异？」 /

「实无有一法，自性可得者。」 /

「有者是常执，无者是断见； /
是故有智者，不应依有无。」 /

「若法有自性，非无即是常； /
先有而今无，此即是断过。」 /

「有无是二边，净不净亦尔； /
是故有智者，离边不住中。」 /

「若诸行是常，彼则无流转。」 /

「无常无流转。」

「众生亦同过。」

「舍摩唯眼见，一种名丈夫， /
多闻说后世，如人言兽迹， /
汝今极端正，恣食任所之。 /
过去业皆无，此身唯行聚， /
死者竟不还，此事汝应信。」 /

「若人流转者，诸阴入界中， /
五种求尽无，谁为受流转？」 /

「若从取至取，则招无有过； /
无取复无有，其谁当往来？」 /

「诸行涅槃者，是事终不然。」 /

「众生涅槃者，是事亦不然。」 /

「解脱若有我，有我即是常； /
解脱若无我，无我即无常。」 /

「诸行生灭相，不缚亦不解； /
众生如前说，不缚亦不解。」 /

「若为诸取缚，缚者无解脱。」 /

「无取故无缚，何位人可缚？」 /

「若缚者先缚，可言缚能缚； /
而先实无缚，去来中已遮。」 /

「缚者则无脱。」

「未缚者无脱。」

「缚时有脱者，缚脱则一时。」 /

「我灭无诸取，我当得涅槃。」 /

「受如是执者，此执为不善。」 /

「不应舍生死，不应立涅槃； /
生死及涅槃，无二无分别。」 /

「大仙所说业，思及思所起， /
于是二业中，无量差别说。」 /

「如前所说思，但名为意业， /
从思所起者，即是身口业。」 /

「身业及口业，作与无作四， /
语起远离等，皆有善不善。」 /

「受用自体福，罪生亦如是， /
及思为七业，能了诸业相。」 /

「若住至受果，此业即为常； /
业若灭去者，灭已谁生果？」 /

「如芽等相续，而从种子生， /
由是而生果，离种无相续。」 /

「种子有相续，从相续有果； /
先种而后果，不断亦不常。」 /

「如是从初心，心法相续起， /
从是而起果，离心无相续。」 /

「从心有相续，从相续有果， /
故业在果先，不断亦不常。」 /

「求法方便者，谓十白业道； /
胜欲乐五种，现未二世得。」 /

「人能降伏心，利益于众生， /
是名为慈善，得二世果报。」 /

「作此分别者，得大及多过； /
是如汝所说，于义则不然。」 /

「不失法如券，业如负财物， /
而是无记性，约界有四种。」 /

「不为见道断，而是修道断； /
以是不失法，诸业有果报。」 /

「若见道所断，彼业至相似， /
则得坏业等，如是之过咎。」 /

「一切诸行业，相似不相似， /
现在未终时，一业一法起。」 /

「如是二种业，现在受果报， /
或言受报已，此业犹故在。」 /

「度果及命终，至此时而灭； /
有漏无漏等，差别者应知。」 /

「虽空而不断，虽有而不常； /
诸业不失法，此法佛所说。」 /

「业从本不生，以无自性故； /
业从本不灭，以其不生故。」 /

「业若有自体，是即名为常； /
而业是无作，常法无作故。」 /

「若业是无作，无作应自来； /
住非梵行罪，今应得涅槃。」 /

「破一切世俗，所有言语法， /
作善及作恶，亦无有差别。」 /

「以有业住故，而名不失者； /
亦应与果已，今复更与果。」 /

「烦恼若业性，彼即无自体； /
若烦恼非实，何有业是实？」 /

「说业及烦恼，而为诸身因； /
业烦恼自空，身从何所有？」 /

「为无明所覆，为爱结所系， /
而于本作者，不一亦不异。」 /

「业不从缘生，不从非缘生； /
以业无自体，亦无起业者。」 /

「无业无作者，何有业生果？ /
既无有此果，何有受果者？」 /

「如佛神通力，现作化佛身， /
于是须臾间，化身复起化； /
此初化身佛，而名为作者， /
化佛之所作，是即名为业。」 /

「业烦恼亦尔，作者及果报， /
如干闼婆城，如幻亦如焰。」 /

「若我是阴相，即是起尽法； /
我若异诸阴，是则非阴相。」 /

「我既无所有，何处有我所？ /
无我无我所，我执得永息。」 /

「得无我我所，不见法起灭； /
无我我所故，彼见亦非见。」 /

「得尽我我所，亦尽内外入， /
及尽彼诸取，取尽则生尽。」 /

「解脱尽业惑，彼苦尽解脱； /
分别起业惑，见空灭分别。」 /

「为彼说有我，亦说于无我； /
诸佛所证法，不说我无我。」 /

「为说息言语，断彼心境界， /
亦无起灭相，如涅槃法性。」 /

「一切实不实，亦实亦不实， /
非实非不实，是名诸佛法。」 /

「寂灭无他缘，戏论不能说， /
无异无种种，是名真实相。」 /

「从缘所起物，此物非缘体， /
亦不离彼缘，非断亦非常。」 /

「不一亦不异，不断亦不常， /
是名诸世尊，最上甘露法。」 /

「诸修真实者，今虽未得果， /
将来决定得，如业不假勤。」 /

「诸佛未出世，声闻已灭尽， /
然有辟支佛，依寂静起智。」 /

「现在及未来，若待过去时， /
现在及未来，过去时已有。」 /

「现在与未来，过去时中无； /
现在与未来，待何而得有？」 /

「不待过去时，彼二则不成， /
现在及未来，是则无有时。」 /

「与过去无别，余二次第转， /
及上中下品，一体等应观。」 /

「未来及过去，若待现在时， /
未来及过去，现在时中有； /
未来及过去，现在时中无， /
未来及过去，待何而得有？ /
不待现在时，彼二则不成， /
未来及过去，是则无有时； /
现在及过去，若待未来时， /
现在及过去，未来时中有。 /
现在及过去，未来时中无， /
现在及过去，待何而得有？ /
不待未来时，彼二则不成， /
现在及过去，是则无有时。」 /

「不取不住时，住时亦不有； /
可取不可取，云何可施设？」 /

「此彼体相待，世谛法如是； /
第一义无体，离体何有时？」 /

「因物故有时，离物无有时， /
亦无少物体，何处时可得？」 /

「若谓众因缘，和合而果生； /
是果先已有，何须和合生？」 /

「若谓众因缘，和合而果生； /
和合中无果，何须和合生？」 /

「若谓众因缘，和合而有果， /
是果应可取，而实不可取。」 /

「若谓众因缘，和合无果者； /
是则众因缘，与非因缘同。」 /

「与果作能已，而因方灭者； /
与因及灭因，则便有二体。」 /

「若因未与能，而因先灭者； /
因灭而果起，此果则无因。」 /

「若同时和合，而能生果者； /
能生及所生，堕在一时中。」 /

「若未和合前，已有果起者； /
离彼因缘已，果起则无因。」 /

「若因变为果，因即有向去； /
先有而复生，则堕重生过。」 /

「为已灭生果？为未灭生果？ /
因灭者已坏，云何能生果？」 /

「因果和合住，云何得生果？ /
不与果和合，何物能生果？」 /

「无有过去果，与过去因合； /
亦无未来果，与已生因合。」 /

「已果及未因，毕竟无和合； /
未果及已因，亦复无和合。」 /

「无有已生果，与已未因合； /
亦无已坏果，与已未因合。」 /

「因若不和合，云何能生果？ /
因若有和合，云何能生果？」 /

「因中果若空，云何能生果？ /
因中果不空，云何能生果？」 /

「未起果不空，不空则无灭； /
以无起灭故，果得不空过。」 /

「果不空不起，果不空不灭； /
以果不空故，无起亦无灭。」 /

「果空云何起？果空云何灭？ /
以果是空故，无起亦无灭。」 /

「因与果一者，终无有是义； /
因与果异者，亦无有是义。」 /

「因果若一者，能所则为一； /
因果若异者，因则同非因。」 /

「果若已有者，何用从因生？ /
果若未有者，因复何能生？」 /

「自体及众缘，和合不能生； /
自体既不生，云何能生果？」 /

「是故果不从，缘合不合生； /
以果无有故，和合法亦无。」 /

「离成无有坏，与俱亦无坏； /
离坏无有成，与俱亦无成。」 /

「离成则无坏，云何得有坏？ /
离死则无生，无坏何有成？」 /

「若成与坏俱，云何当可得？ /
亦如生与死，不可得同时。」 /

「若离坏有成，云何当可得？ /
诸体上无常，一切时中有。」 /

「成与坏同时，云何而可得？ /
亦如生与死，同时者不然。」 /

「成坏互共成，此二无有成； /
离此二互成，二法云何成？」 /

「尽者无有起，无尽亦无起； /
有尽者无坏，无尽亦无坏。」 /

「若离彼成坏，则无有物体； /
是成坏二法，离物体亦无。」 /

「有成坏二法，物体空不然； /
有成坏二法，体不空不然。」 /

「是成坏二法，一体者不然； /
是成坏二法，异体者不然。」 /

「我常见物体，有成亦有坏， /
是故知体法，定有而不空。」 /

「起者先已遮，无起法亦遮； /
见成者愚痴，见坏者亦尔。」 /

「有体不生体，亦不生无体； /
无体不生体，亦不生无体。」 /

「法体不自生，亦不从他生， /
亦无自他生，今说何处生？」 /

「诸法有体者，即堕断常见； /
当知所受法，若常若无常。」 /

「起尽相续者，由果及与因； /
因灭而果起，不断亦不常。」 /

「是起尽相续，由因及果者， /
因灭而果起，若断及若常。」 /

「先有自体者，后无则不然； /
涅槃时便断，即有断灭过。」 /

「死有者是灭，取初有不然； /
死有未灭时，取初有不然。」 /

「是死有灭时，能生初有者， /
灭时是一有，生时是异有。」 /

「灭时及生时，取初有不然； /
而此灭阴者，后复还生耶？」 /

「如是三时中，有相续不然； /
若无三时者，何有有相续？」 /

「非阴不离阴，阴如来互无； /
非如来有阴，何等是如来？」 /

「因阴有如来，则无有自体； /
若无自体者，云何因他有？」 /

「法从他缘起，有我者不然； /
若无有我者，云何有如来？」 /

「若无有自体，云何有他体？ /
若离自他体，何等是如来？」 /

「彼未取阴前，已有非如来， /
而今取阴故，始是如来耶？」 /

「彼未取阴时，则无有如来； /
未取无自体，云何后取阴？」 /

「犹如未有取，不得名为取； /
若离于彼取，无处有如来。」 /

「一异无如来，五种求不得； /
云何当以取，施设有如来？」 /

「如来所取取，此取不可得， /
取及取者空，及一切种空。」 /

「十力无垢轮，一切三有日， /
无量众所归，普照无明暗。」 /

「彼所取五阴，不从自体有； /
若无自体者，云何有他体？」 /

「法体如是故，取及取者空； /
云何当以空，而说空如来？」 /

「空则不应说，非空不应说， /
俱不俱亦然，世谛故有说。」 /

「若法有自体，见空有何益？ /
诸见分别缚，为遮此见故。」 /

「于寂灭法中，无常等四过， /
亦于寂灭中，无边等四过。」 /

「麁重执见者，说如来有无； /
如来灭度后，云何不分别？」 /

「如来自体空，不应起思惟： /
灭后有如来，及无有如来。」 /

「戏论生分别，如来过分别； /
为戏论所覆，不能见如来。」 /

「若以色见我，以音声求我， /
是人行邪道，不能见如来。」 /

「以如来自体，同世间自体； /
如来无体故，世间亦无体。」 /

「分别起烦恼，说有贪瞋等， /
善不善颠倒，从此缘而起。」 /

「爱非爱颠倒，皆从此缘起； /
我无自体故，烦恼亦非实。」 /

「我若有若无，是二皆不成； /
因我有烦恼，我无彼不起。」 /

「谁有彼烦恼，有义则不成； /
若离众生者，烦恼则无属。」 /

「身起烦恼见，缘于我我所； /
烦恼与染心，五求不可得。」 /

「爱非爱颠倒，本无有自体； /
以何等为缘，而能起烦恼？」 /

「色声香味触，及法为六种， /
爱非爱为缘，于物起分别。」 /

「色声香味触，及法体六种， /
如干闼婆城，如焰亦如梦。」 /

「若爱若非爱，何处当可得？ /
犹如幻化人，亦如镜中像。」 /

「若不因彼爱，则无有不爱； /
因爱有不爱，是故无有爱。 /
无不爱待爱，无爱待不爱， /
若以爱为缘，施设有不爱。」 /

「无有可爱者，何处当起贪？ /
不爱若无体，何处当起瞋？」 /

「于第一义中，毕竟无颠倒； /
如来终不说，是我无我等。」 /

「无常谓常者，名为颠倒执； /
无常亦是执，空何故非执？」 /

「执具起执者，及所执境界， /
一切寂灭相，是故无有执。」 /

「执性无有故，邪正等亦无； /
谁今是颠倒？谁是非颠倒？」 /

「已起者无合，未起亦无合， /
离已未倒者，有合时不然。」 /

「无起未起者，云何有颠倒？ /
诸倒悉无生，何处起颠倒？」 /

「常乐我净等，而言实有者； /
彼常乐我净，翻则为颠倒。」 /

「我及常乐等，若当是无者； /
无我苦不净，而应是可得。」 /

「以彼无因故，则无明行灭， /
乃至生老死，是等同皆灭。」 /

「若人诸烦恼，有一自实体， /
云何能断除？谁能断有体？」 /

「若一切法空，无起亦无灭， /
说圣谛无体，汝得如是过。」 /

「若知及若断，修证作业等， /
圣谛无体故，是皆不可得。」 /

「圣谛无体故，四果亦无有； /
以果无体故，住果者亦无。」 /

「若无有僧宝，则无有八人； /
圣谛若无体，亦无有法宝。」 /

「若无法僧者，云何有佛宝？ /
若三宝皆空，则破一切有。」 /

「若因果体空，法非法亦空； /
世间言说等，如是悉皆破。」 /

「汝今自不解，空及于空义， /
能灭诸戏论，而欲破空耶？」 /

「诸佛依二谛，为众生说法： /
一谓世俗谛，二谓第一义。」 /

「若人不能解，二谛差别相， /
即不解真实，甚深佛法义。」 /

「若不依世谛，不得第一义； /
不依第一义，终不得涅槃。」 /

「少智愚痴者，以恶见坏空； /
如不善捉蛇，不如法持呪。」 /

「诸佛以是故，回心不说法； /
佛所解深法，众生不能入。 /
汝今若如是，于空生诽谤， /
谓法无起灭，乃至破三宝。」 /

「若然于空者，则一切皆然； /
若不然空者，则一切不然。」 /

「汝今持自过，而欲与我耶？ /
亦如人乘马，自忘其所乘。」 /

「汝若见诸法，皆有自体者； /
诸体无因缘，还成自然见。」 /

「若因果无待，作者及作业， /
及至起灭等，一切法皆坏。」 /

「从众缘生法，我说即是空， /
但为假名字，亦是中道义。」 /

「未曾有一法，不从因缘生， /
如是一切法，无不是空者。」 /

「若一切不空，无起亦无灭， /
无四圣谛体，过还在汝身。」 /

「不从缘生者，何处当有苦？ /
无常即苦义，彼苦无自体。」 /

「苦既无自体，何处当有集？ /
以集无有故，是则破于空。」 /

「苦若定有性，先来所不见， /
于今云何见？其性不异故。」 /

「苦若有体者，不应有灭义； /
汝着有体故，即破于灭体。 /
苦若有定性，则无有修道； /
道若可修者，即无有定性。」 /

「若道是可修，即无有自体； /
苦集乃至灭，是等悉皆无。」 /

「为灭苦者道，何有道可得？ /
不解苦自体，亦不解苦因。」 /

「既无果自体，住果向亦无； /
以无有八人，则无有僧宝。」 /

「若无四圣谛，亦无有法宝； /
无有法僧故，云何当有佛？」 /

「不以觉为缘，佛堕无缘过； /
不以佛为缘，觉堕无缘过。 /
佛有自体者，诸菩萨修行， /
为佛勤精进，不应得成佛。 /
是法及非法，无人能作者， /
不空何须作？有体作不然。」 /

「无法非法因，果得无因过； /
若离法非法，汝得无待果。」 /

「若汝欲得有，法非法因果； /
从法非法起，云何不是空？」 /

「一切言说事，世间皆被破； /
若坏缘起法，空义亦不成。」 /

「一物不须作，亦无人起业， /
不作名作者，则坏于空义。 /
无生亦无灭，是则名为常， /
种种诸物类，皆住于自体。」 /

「未得者应得，及尽苦边业， /
一切烦恼断，以无空义故。」 /

「所谓苦与集，乃至于灭道？ /
见有生灭者，是见名不见。」 /

## 观涅槃品第二十五

释曰：今此品者，亦为遮空所对治，令解涅槃无自体义故说。

鞞婆沙人言：彼先言，若一切非空，则无有起灭，此谓无自体义。无自体者，如石女儿，则无起灭。烦恼无自体故，非是起灭。而烦恼及名色因亦非起灭者，如上偈说「无断苦证灭，复谁得涅槃？」彼先已作此说者，我今欲得有所断故证于涅槃。如经所说：「染与染者共起烦恼。此尽灭故，名为涅槃。如是涅槃，心得解脱，譬如灯灭。」得涅槃者，由烦恼有自体故。如彼上说无自体者，若无烦恼体亦无涅槃，譬如石女儿。复次若以无自体为验无得涅槃者，亦破得涅槃义，即是破于差别法体，是彼立义出因之过。论者言：汝说不善。诸法无自体者，如幻灯灭，是亦不违世谛智境界故。无自体者，从无始因缘展转而起，如幻如焰。诸行无起，即是涅槃。证得涅槃亦复如是，无有自体。我亦不立无体体故，非立义过。上引石女为喻者，于第一义中得成。汝执有自体义者，不可坏故，有所断者不然。以是故，若不见真实理而说有自体者，得涅槃义不成，法自体坏故。是事云何？汝向出因、立义、譬喻，三法皆不成故有过。复次鞞婆沙人言：如彼偈说「若一切非空，则无有起灭。无断苦证灭，复谁得涅槃」者不然。我今立有涅槃。云何为涅槃？谓第一义中诸行有自体，断诸烦恼及灭名色而得涅槃故，非如驼角。涅槃不尔，有体有断有灭有得故。论者言：如先偈说「若一切非空，则无有起灭。无断苦证灭，云何得涅槃」者，此谓有自体，不可坏故。自体者，若是自宗出因立喻有相似者，所成能成则为有力。而今无此力故，因与喻义亦不成，又亦违汝先所立义。我今问汝所立涅槃，为是第一义谛？为是世谛？若欲得是第一义谛者，我今答之。如论偈说：

释曰：此谓如是涅槃，我所欲得。如汝所说，断故灭故为出因等，断诸烦恼得涅槃者，此等因义今皆不成，颠倒心故作如是说，义皆不然。复次诸执有涅槃者，或说涅槃是真实法，或说涅槃是施设法。二俱不然。以是义故，次须观察。如论偈说：

释曰：此谓涅槃有自体者，无验可令信解。若令涅槃有体，即堕老死相。何以故？无有体离老死相，亦无老相死相离体。小乘之人不欲涅槃有老死相，以是故，如我出验，第一义中涅槃非是体，无老死相故，譬如石女儿。是故汝宗因义不成。因不成故，亦与正义相违故。复次今更与过。若汝不欲涅槃是有为，而欲得涅槃是无为者不然，无处有一物是体复是无为者。今当立验，涅槃非是体，无为故，譬如空华。复次更说其过，如论偈说：

释曰：此谓体者，皆藉因得有施设，涅槃是体不得无因。以是故此中出验，涅槃非是体，无因能施设故，譬如兔角、多摩罗跋。及修多罗人等言：如鞞婆沙师说，涅槃如灯灭。我今说涅槃者，但是无起，于世谛中施设有故，我所立者其义相应。论者言：今答此者，如论偈说：多摩罗跋者唐言赤铜叶

释曰：鞞婆沙等分别涅槃是第一义善，以息烦恼为因。今汝义非如是体故，而言涅槃无体者，为无善等耶？义皆不然，譬如空华。若言涅槃无实无自体者，无如是验能令开解。涅槃非无体者，汝之所说难令人解。复次鞞婆沙分别涅槃先有体后无体，以灯为喻者，此是显示世间所解，以灯未灭时有体，灭已是无体。若汝计无体，同彼已灭灯者，如向偈说「若涅槃无体，云何是无因？」此谓如灯无体而有，因施设作灯。如是诸阴烦恼无体而有，因施设为涅槃。如论偈说：

释曰：如汝所说，涅槃无体是第一义，以是故因有来去流转相而施设有生死。涅槃有体无体者，是世谛中所说，非第一义。如论偈说：

释曰：如经说：「或有人以有求出有，或有人不以有求出有，是皆不然。」若言涅槃是体者不然。犊子部言：我今立涅槃者，与彼不同，有是体义、有非体义。有二义故，无如上过，是义应尔。论者言：汝所立者其义不然。如论偈说：

释曰：此谓体非体相违故。若是体则非非体，若是非体则不是体。若相待者，则有体非体相。如是说者，义不相应。何以故？有分别执着过故。犊子部言：涅槃者云何非体？谓身及诸根无体故，名为非体。云何是体？谓有毕竟无上乐故，名为是体。论者言：此语不善。身诸根及觉等已遮故，亦即是遮无起等。毕竟无上乐者，如遮有为起，亦遮彼乐。若欲以无为乐令物解者，无此验体，汝之所立义不相应。复次若言涅槃有自体者，如论偈说：

释曰：此偈显何义耶？谓显体非体外别有涅槃相。若彼法与此法有别相而是法体者不然，譬如水与火。如是体非体为涅槃相者不然。复次修多罗人言：涅槃者非体非非体故，俱不可说。彼向言有二体过及有为者不然。论者言：亦无是事。今答此语，如论偈说：

释曰：此谓如明与暗，有明故可说暗。如是有体非体故，有非体非非体得成。复次如论偈说：

释曰：此谓若言以智能了者，此智先已遮故。如论偈说：

释曰：此谓身中有神、神与身一、神与身异、离身有神、即身是神，诸不记中皆不说，是故第一义中涅槃不成，汝出因义亦不成，其过在汝。鞞婆沙人复言：第一义中有涅槃，怖畏生死者为求彼故起勤精进，不见求者为得无法故起勤精进。论者言：如我宗中不见有人得彼涅槃，第一义中生死及涅槃俱无差别故。如论偈说：

释曰：此谓生死涅槃同无所得，是二俱不可得故。亦如分别性无故，生死涅槃皆不可得，已令信解。是故如汝所说为得涅槃而起精进为因者，其义不成，亦违于义。今以涅槃生死令开解者，如论偈说：

释曰：涅槃者真如法界空之异名，真如无别异故，譬如虚空，虽有方之殊别而无异相。鞞婆沙人言，彼说一切恶见皆以空能出离，及欲得涅槃是空者。若谓涅槃是无能对治诸见者不然，是故有涅槃，是对治故，譬如明对治暗。论者言：此中灯光能照及有体者不成故，汝喻无体，是能成立之过。我言空者，谓一切诸法不可得也，即是说有所得对治。然彼有所得境界，一切时不可得故而空，非是有体，无生故，譬如空华亦非是无，先已说遮故。执着空者亦是邪见，是故智者应舍此执。若无智者执空有体，空有体故则无利益。如《宝积经》说，佛告迦叶：「若有人言能见空者，我说彼人不可治也。」如是故空义不成。汝言对治为因者，因义不成。复次若第一义中有此见者，彼对治法可然。今观此诸见无故，如论偈说：

释曰：此谓如来灭后，为有如来？为无如来？为亦有如来亦无如来？为非有如来非无如来？世间有边、世间无边、亦有边亦无边、非有边非无边，乃至世间常、世间无常、亦常亦无常、非常非无常。如是四见有十二种，如来灭后依涅槃起，世间边等依未来起，世间常等依过去起，如是等见云何起邪？由有虚妄分别习气过故。然此分别无有自体，已令开解。以是故，如论偈说：

释曰：如是等分别所依止境界无体。彼依止无体故，分别心亦无体。所以者何？一切法一切时一切种从众缘和合生，毕竟空故，无自性故。如是法中何者有边？谁为有边、亦边无边、非边无边，乃至何者是身？谁为有身、身一神一、身异神异。如是等六十二见，于毕竟空中皆不可得。以是故，如修多罗中偈说「所分别既无，分别何处起。能分别灭故，所分别亦亡。」论初已来推求诸法，有亦无、无亦无、亦有亦无亦无、非有非无亦无，是名诸法实相平等性空，灭诸戏论得安隐道。若依世谛中出因者，已如前说过。修多罗人言：第一义中有涅槃，佛为令众生证得故，观根观心观法观时观方而为说法。若无涅槃者，佛不应作此说法，乃至说八万四千诸行烦恼对治门。为得涅槃而有所说，故有涅槃。论者言：若第一义中以说法为因，汝欲得尔耶。如论偈说：

释曰：有所得皆谢者，谓有所得境界无体故，有所得心亦无体。复次有所得境界无为故，有所得心亦不起，如是一切有所得皆谢。戏论息者，谓有所得境界无体，彼境界言说相亦不起，以是故名戏论息。吉祥者，谓一切灾殃悉无体故，名为吉祥。由彼所起分别性，一切法不成，及一切法不可说故。第一义中以说法为因者，如上偈说「如来无处所，无一法为说。」复次因自觉所得真实法者不可言说，然此言说者，同分别境界故。所证真实法者不可言说，如上偈说「如来无处所，无一法为说。」复次如来说法者云何？为摄诸有故，无量千劫积集福智聚，佛身从此福智聚生，譬如如意珠悉能显现一切色像。以一切众生心自在愿力故，如来无功用有声出摄于三乘。佛身力故，所有闻者迷故，谓言如来为我说法。为说法者，于世谛中施设而有。复次阴非如来，离阴亦无如来，先已观故。如来名者，无有一物无能说者，亦无听者，亦无说处，以无实体故。如上偈说「如来无处所，无一法为说。」复次诸行无所造作，及诸行聚是无漏，二障俱断，为不共佛法等作依止，具此四法故名如来。彼诸行聚无所造作故，有说法者不然。乃至听法者是有漏行聚，而言听者受者皆是言说，无有实体。第一义中如幻如化，谁说谁听？以是故如来无处所，无一法为说。复次如来行菩萨道时，种宿愿力自在，以四摄法摄诸众生。是诸众生以种定报善根因缘力故，由信乐诸根心愿自在。为令一切众生欢喜故，六十种具足无功用说法，声依如来起，然如来常定。心无功用力所作无觉观体而言有声出者，是皆不然。以如是故，如来无处所，无一法为说。复次于先佛所说法，自解自证故。一切诸法皆先佛已说，今佛随顺而说，不加一字。以是故，如来无处所，无一法为说。复次第一义中一切诸法毕竟空故，无有一法为总相智、为别相智可取。以是故，如来无处所，无一法为说。如《金刚般若经》说：「如来为菩萨时，定光佛边无一法可受。何以故？不可取不可说故。诸外道等甚可怜慜，我今以此无体自体空最上乘所说道理破其邪辩。」然彼外道依止恶见道理，而自覆藏己宗之过，执其所见，说是偈言：

外道等谓论者言：彼佛法中若言世谛中有悲慜者，犹如石女哭儿。论者言：此中明第一义者，一相故所谓无相，无佛亦无大乘。第一义者，是不二智境界。汝说偈者，正是说我佛法道理。今当为汝说如来身。如来身者，虽无分别，以先种利他愿力为大誓庄严熏修故，能摄一切众生。于一切时起化佛身，因此化身有文字章句次第出声，不共一切外道声闻辟支佛故，而为开演二种无我，为欲成就第一义波罗蜜故，为欲成就乘最上乘者故，名为大乘。有第一义佛故，依止彼佛而起化身，从此化身起于说法。由第一义佛为说法因故，不坏我所立义，亦不坏世间所欲。复次萨婆多人言：如来所说法者，皆是有分别故说法，以他众生心自在愿力起说法因故，譬如为声闻等说法。论者言：是义不然。化佛说法者是无分别，非如汝语一向分别。萨婆多人言：佛无分别而为说法者不然，无分别故，譬如土块。论者言：化佛与第一义佛不可说异故。世谛中有佛者，不遮世谛中彼第一义佛为说法因者，亦不遮第一义中如来无戏论故。分别如来若有悲若无悲，皆是戏论，如是戏论悉皆无体。所悲慜众生及能起悲者，亦皆无体。如汝先说，若世谛中有悲，谓如石女哭儿者，是喻不然。悲云何相？谓见他有苦起忧苦心，是名悲相，譬如慈母怜极爱子。诸佛菩萨于诸众生起怜慜心，亦复如是。纵令石女有悲怜心，于我何妨？而复不尔，譬如龟毛空与太虚空而不相似。是故设有悲者，诸佛悲心与石女悲心亦不相似。诸佛悲者，无量劫来积集熏修究竟具足，遍满一切诸众生界。若石女无此悲者，更莫复言世谛有悲者与石女悲相似。此品初鞞婆沙等所立验者，论主已说其过，显示涅槃无有自体。以是故，此下引经显成。如《梵天王所问经》偈言「实无有涅槃，如来说涅槃。如虚空自结，如虚空自解。」梵王白佛言：「若有分别众生欲得一切法有起有灭者，佛于其人亦不出世。若于涅槃起分别相言是有体者，然彼众生决定不能出于生死。世尊！涅槃者其义云何？一切相皆寂灭是为涅槃。一切所作皆已谢是为涅槃。世尊！愚痴众生于佛法中虽得出家，而堕外道见中求涅槃体，如于麻中求油、指手言得，何异乳中求觅生酥？若于一切法毕竟寂灭中求涅槃者，乃至邪慢外道中声闻非佛法中声闻，若是正见成就行者，不作一法有起有灭，亦不欲得证获一法，亦不见圣谛理。」如摩诃般若中说，佛告须菩提：「涅槃者，如幻如梦、如影如焰、如镜中像、如水中月、如干闼婆城。」

「无退亦无得，非断亦非常， /
不生亦不灭，说此为涅槃。」 /

「涅槃有自体，即堕老死相； /
涅槃是体者，即是有为法。」 /

「涅槃若有体，云何是无因？ /
亦无有一法，离因而得有。」 /

「汝涅槃非体，云何是无体？ /
若涅槃无体，云何是无因？」 /

「涅槃非无体，而不藉因者； /
若无因无缘，是名为涅槃。」 /

「大师所说者，断有断非有； /
是故知涅槃，非无亦非有。」 /

「若汝说涅槃，是体是非体； /
涅槃是体故，解脱者不然。」 /

「若汝说涅槃，二俱有自体； /
涅槃是无为，二体是有为。」 /

「汝若说涅槃，非体非非体； /
体非体若成，二非体亦成。」 /

「非体非非体，若是涅槃者； /
如是二非体，以何法能了？」 /

「如来灭度后，不言有与无， /
亦不言有无，非有及非无。 /
如来现在世，不言有与无， /
亦不言有无，非有及非无。」 /

「生死边涅槃，无有少差别； /
涅槃边生死，亦无少差别。」 /

「生死际涅槃，涅槃际生死， /
于此二中间，无有少许法。」 /

「灭后有无等，及常等诸见， /
涅槃前后际，诸见所依止。」 /

「诸体悉皆空，何有边无边， /
亦边亦无边，非边非无边？ /
何有此彼物，何有常无常， /
亦常亦无常，非常非无常？」 /

「有所得皆谢，戏论息吉祥； /
如来无处所，无一法为说。」 /

「彼第一义中，佛本不说法， /
佛无分别者，说大乘不然， /
化佛说法者，是事则不然， /
佛无心说法，化者非是佛。 /
于第一义中，彼亦不说法， /
无分别性空，有悲心不然。 /
众生无体故，亦无有佛体， /
彼佛无体故，亦无悲慜心。」 /

## 般若灯论释观世谛缘起品第二十六

释曰：今此品者，亦为遮空所对治，而以世谛缘起故说。

自部人谓我言：彼先言如来无处所、无一法为说者，其义不然。论者言：我今当说。如来为欲惊怖一切外道及人天等众生，令息诸恶见过患故，说缘起法。佛由觉了缘起法故，名称高远遍一切世间，以是因缘故名为佛。汝今与缘起法作过者，自违所欲。如论偈说：

释曰：明所对治名为无明。而此无明能覆障众生智慧，造作后有诸行。云何名后有？谓未受生者与不相离和合因果共趣向后有故，名为后有。云何名诸行？行有三种：一谓无我法、二谓刹那、三谓三种业。云何为三业？谓福、非福、不动等。复有三种，谓身、语、意。无明者非独为诸行缘，亦能与识等后支展转为缘。体亦非独无明复障众生，更有诸余烦恼行者，谓造作有为法故名之为行。如论偈说：

释曰：云何为识？于一一物分别取境界故名识。托者言生。行缘者，谓行与识为缘，故名行缘。亦非独诸行与识为缘，彼识生时亦有诸心数法共生，以是故亦以诸心数法为缘。复次行缘识者，如阿罗汉亦有诸行，何故不与托后有识为缘？以彼爱绳断故，不与托后有识为缘。是故爱等诸烦恼，亦与受后世识作缘，何故独言诸行耶？为诸行有胜力故。譬如王者鬪战得胜，非独王胜，一切兵众亦名为胜，由王为主故言王胜。复次或有人起如是意言：无明为不善诸行因可然，但愚痴者是不善故，云何得与善法诸行为因耶？此谓未断无明者，为欲受天女眷属乐故，而造诸福德行，以是故无明亦与福德行为展转因。复次生死者，是第一义不善所有福德诸行，系属生死者皆名不善，以是故无明能总与诸行为缘。复次善趣、不善趣、不动趣三种业者，各有上中下差别，是等诸行名为往诸趣业。往诸趣者，诸师各执不同。如萨婆多人说言：有彼中阴，以有名色相续往托生处故。正量部人、昙无毱多部人等说言：无彼中阴，但以行为缘而识得起，尔时名为托生。复次计有中阴者言：有色诸众生等于一处灭，是有色众生还相续生，无间前后起至彼异趣，名为托生，相续随生故，譬如灯。以是故名色依止阴而有相续，从死刹那至受生刹那无间生故，名为受生，譬如现在人从此到彼。复次无中阴者言：色界死有生有，二有中间更无中有，有漏故，譬如无色界死有生有而无中有。何以故？死有中间有身起者，非是中阴，身是报故，譬如现在所受得身。复次有身起者，是苦谛所摄故，譬以意体为身，往至异处，刹那刹那相续随起故，而无中有，非一向有阴。汝立中阴义者，是义不成。复次有中阴者言：若无中阴，云何得至后受生处耶？复次无中阴者言：从死有相续至生有时，如授经、如传灯、如行印、如镜像现、如空声响、如水中日月影、如种子生芽、如人见酢口中生涎，如是后阴相续起时，无有中阴往来传此向彼。是故智者应如是解，如上偈说「识相续托已，尔时名色起。」云何为名色耶？名有二种：一谓自往诸趣、二谓为烦恼所使强令入诸趣中。复次名者，谓无色四阴，总名为名。云何为色？色者可变异故名色，谓四大及四尘等。非独识为名色缘，无明行等亦为彼缘。复次识缘名色者，识及无明等非是定与名色为缘。有处有化生者，而亦与彼六入为缘。如无色界生者，此识但与名为缘。如论偈说：

释曰：云何为内六入？谓眼入、耳入、鼻入、舌入、身入、意入等。眼入者，以色为境界故。彼清净色是眼识所依止处故，名清净色以为眼入。如是以声等为境界，彼清净色是耳等识所依止处故，名清净色为耳等入。意入者，以无间次第灭为彼意入。云何为入？谓识及心心数法等从清净色中起故，名之为入。何故名触？谓与苦受、乐受、不苦不乐受等各和合故名触。如论偈说：

释曰：识得生者，如眼以色为缘，识缘色故而识得生。如是耳以声为缘，耳识得生，乃至意以法为缘，意识得生。云何名触？如论偈说：

释曰：境界与根意等三种为一体故，而名为触。触为缘故起三种受，如论偈说：

释曰：此谓求欲之相而名为爱。无闻凡夫为乐受故起贪求心，如舐刀蜜，不觉后时伤舌过患。若为乐受起贪者可尔，云何于苦受不苦不乐受而起贪耶？谓以苦受不苦不乐受亦为爱缘故，受苦受时亦有求离心生，亦是爱也，是故无过。四取者，谓欲取、见取、戒取、我语取。云何为取？谓积集义。复次爱增长故，亦即是取。为得五欲乐故起追求心，亦名为取。如论偈说：

释曰：有者是业相。复次有者是生异名，而生之因法亦名为有。若尔者，云何即因是果耶？今现见因受果名故，譬如佛出世。乐彼识等五支果分是现在世所摄故，而言从无明行生。若得值善知识、听闻正法、起正思惟，于苦乐等诸行能见无常苦空无我等行。复次诸行无生自体空，彼起真实智者不复起爱，不起爱故无复追求，如上偈说「若无有取者，脱苦断诸有。」此义云何？谓有取故有有，若无取则无有。有云何相？如论偈说：

释曰：此谓亦说五阴因为有支体。复次五阴因名有者，谓非独五阴因名有，无色界四阴因亦名有。生者谓先无阴体今有阴起。老者谓变坏相。死者谓无阴体。病者谓身为苦所逼。忧悲者，谓从爱别离、怨憎会等，内被烧然有相起故。哀泣者，谓丧失所爱及有福德眷属，因此发声称其德行而哀泣之。苦谓身受，愁谓心受，劳倦者谓身心疲极。如是广说生等皆名为苦者云何？如论偈说：

释曰：独苦阴起者，谓不与乐和合故。阴者谓聚，起者谓生阴，相续者是世谛所摄缘起，非第一义。如先品中已说无起令信解故，我所立者不破。若言生死行流转者，云何是不起耶？我今答之，如论偈说：

释曰：诸行生死根，无智所作者，此谓无智者不见诸行无始已来展转从缘起如幻如焰，过患故而求于乐，为求乐故造福非福不动等诸行。见实不作者，谓圣道已起见真实故，智障烦恼体无明已断故。如论偈说：

释曰：此谓诸行不生，阙于缘故，如种子无体故芽则不生。今修习何智得断无明，如此论中所说照缘起智，遮一切诸体有自体，解人法二无我境界。空智修者，谓数数习。如论偈说：

释曰：此谓行等一一有支对治道起故，则灭此等有支更不起者，由行灭故。行灭则识灭，乃至生老死忧悲等灭。唯独苦阴正永灭者，是世谛所摄故。若第一义中是无明等无起无灭，云何复名缘起耶？佛依世谛故说第一义，我义如是。如前偈说「不依于世谛，不能说第一。」以是故不坏我所立义。此品初自部人谓我言立义有过者，今说无此过故，而以世谛缘起令物信解，是品义意。如佛说无起者名为缘起，此谓不起者说为缘起。若彼无起，云何有灭？若能于无灭觉无灭者，名解缘起法等。

「无明之所覆，造作彼三种， /

## 般若灯论释观邪见品第二十七

释曰：今此品者，亦为遮空所对治，令解诸见空故说。

自部人言：有自体五取阴，是见处故，阴若是无而为见处者不然。五阴是见处者，如《俱舍论》中说，彼五阴者，是苦是集、是世间、是见处，如是等是有故。论者言：不然。今当观察诸见，此中如论偈说：

释曰：此谓我于过去，为是有、为是无、为亦有亦无、为非有非无？如是诸见依过去世起。世间常、世间无常、亦常亦无常、非常非无常等四见，因待现在世阴故说，过去世阴常等诸见皆依此起。依者谓缘，为谁缘？谓诸见缘。见有何义？谓执著于取等。如论偈说：

释曰：此诸见依过去世起。世间有边、世间无边、亦有边亦无边、非有边非无边等四见，因现在阴故。未来当起阴者，名为后边。今且观察，依止先世起诸见者，如论偈说：

释曰：云何不然？谓时别故、异业所生故，譬如余众生，复次身及诸根亦别故。若言根等虽异而我是一者，此亦不然。如论偈说：

释曰：此谓如提婆达多过去世我还是今日我者不然，取别故，譬如耶若达多我。以是故，前世生还是今日生者不然。复次若欲得我相异取相者，如上偈说「若离于诸取，复有何我耶？」无如是我故，离阴有我先已广遮。计有我者若作是意，不欲令我无体，即以取为我体者，作是分别如似说无我者，亦以取体为我。如论偈说：

释曰：第一义中取不是我。取有起灭法二体，先已说无我，令信解故。云何为取？谓取及取者。取是业，取者是作业人，譬如薪火二种。复次如先已遮我故，我义不成。云何不成？如先偈说「取非即是我，以有起灭故。」我者亦非是有亦非是无。如是我者，世谛中亦不能令物解。今当更答计离阴有我者，如论偈说：

释曰：此谓我若异取者不然。何以故？若离取有我者，云何可说取是我相？若无相可说，则离取无我。若谓离取无我但取是我者，是亦不然，离取无有我异故，譬如余物。此中立验，不异取有我，取是可取法、我不可取故，譬如取自体。何以故？取有起灭，我则不尔。复次云何以取即为取者？若谓离取而有取者，是亦不然。若不取五阴而有取者，应离五阴别有取者。彼义如是。我今说道理者，如论偈说：

释曰：此谓我不离取亦不即取，而非无取亦不是无，已令物解。若言过去世有我者不然。如论偈说：

释曰：此谓问者不欲得如此。云何欲得？谓欲得前世五阴与今世五阴为缘。我今立验，如提婆达多，今世五阴与过去五阴不得有异，相续不异故、过去阴为因故，譬如提婆达多。过去五阴，非但有此离前应独立过，亦更有余咎，如上偈说「如是应常住，不为现阴缘。」云何为缘耶？谓后阴不起故。若尔者则不从死有生，而彼前世所受生阴仍在过去，今别更有异阴于现在生。以是故，则有大过。云何为过？如论偈说：

释曰：若尔者即有断过，失于诸业果报故。又彼人作罪，此人受果。复次若言业之与生一时起者不然。如论偈说：

释曰：我者云何是造作耶？谓先无后有。我者先不起烦恼业，应如瓶以外法为生因，不以先世所集业为生因。如是能生后阴因者，则为无体，非有非不有。复次过去世亦同前二种过。非有非不有者，无如是法故。观察过去世有无等四句已。今当次观未来四句，如论偈说：

释曰：此谓来世一异俱不俱等，今亦如是遮故。如论偈说：

释曰：如是我者即堕常过。自部人言：一异等义有何过耶？论者言：若未生天即是天者，我则无起，无起者即是常。以是故，我未生天时应能起天所作业；而无是事。若谓我是常，未生天时已能起天所作业者，世人所不信故。复次若我无常，此人中我天中生时，昔人中我今即坏故。若汝意谓欲得有异而无如上所说一过者，是事不然。计异者亦有过故，如论偈说：

释曰：其过云何？谓有异故，譬如提婆达多与耶若达多，二我相续则为有过。复次若有人言：我相续是一，有是天义、有是人义。今当答之。如论偈说：

释曰：云何不然？谓有天处，有天即是常。天处无人故，无人即是无常。若有人处，有人即是常。人处无天故，无天即是无常。犹如一物一处亦白亦黑者，其义不然。若有人言：我非是常亦非无常者，如论偈说：

释曰：此义难令人解故。复次第一义中者，如论偈说：

释曰：有处者，若天世处、人世处。有人者，谓若天若人。住处者，谓住天等世界处。有去者，谓有人向异趣处去。若尔者，此我无始已来恒有，而即是常；而无是事。云何无耶？谓众生及人先已遮故。以是义故，无有常我。若言虽无常我而有无常我者，是亦不然。如论偈说：

释曰：此谓待常故说无常。本无有常，待何说无常？复次常无常等皆已不成。今当观察边等四句，如论偈说：

释曰：边者云何？谓究竟处尽处等名边，如似阿罗汉涅槃阴。而今有后世在者，谓前世阴为因，后世阴为果，展转无终，如是依前阴因起后阴果故。然今有此诸阴展转相续起，如论偈说：

释曰：此中立验，有无明烦恼未尽，诸阴相续不断，此阴有果故，譬如灯焰相续。以是故，世间有边者不然。此相似果起不坏者，非前阴不坏有后果故，譬如灯前焰。以是故，世间无边者不然。如所说验义者，应如论偈说：

释曰：此谓前阴起已即灭，不为后阴相续因者，即是有边。如论偈说：

释曰：云何无边？谓一切时常住故。是义不然，如论偈说：

释曰：此谓无世间最后边等四句。所以者何？如论偈说：

释曰：云何不然？如前二种灯喻验中已破故，是为不然。如论偈说：

释曰：此谓若一人是亦有边亦无边成者，以相待故，非有边非无边亦成；而无是事。如第一义中总说一切见皆不然，作如是令物解者，如论偈说：

释曰：此谓若第一义中一切诸体皆空者，有何人？缘何境？以何为因？起何等见？以彼人空、境空、因空、见空故，有人、有境、有因、有见起者不然。以是义故，品初自部人言，第一义中有如是五取阴自体是见处者，此出因义不然。云何不然？第一义中已令物解一切诸见悉皆空故不然。若依世谛中而立因者，自违汝义。佛婆伽婆为世亲者，见一切众生虚妄分别起种种苦种子诸见故而起怜愍。如论偈说：

释曰：断苦者，谓断一切众生生死等一切诸苦。妙法者，谓清净故，名为妙法。能灭烦恼熏习火故，名为清净。复次一切功德因增长圆满故，亦名清净。妙法者，所谓大乘。如《胜鬘经》说：「世尊！摄受妙法者，谓守护大乘。何以故？世尊！一切声闻、辟支佛乘，皆从大乘中出生故。乃至一切世间出世间善法，亦皆从大乘中出生故。世尊！譬如阿耨达池出四大河。如是如是，世尊！大乘者能生声闻、辟支佛乘。如是乘者，以慈悲喜舍为因，不以世间名利为因。」今礼瞿昙者，谓能开示无上妙法宝故，名为瞿昙。复次姓瞿昙故，名为瞿昙。礼者云何？有二种礼：一谓口言称叹；二谓屈身头面着地。如《梵王所问经》偈言「深解因缘法，则无诸邪见。法皆属因缘，无自定根本。因缘法不生，因缘法不灭，若能如是解，诸佛常现前。」此品初说自部人立验有过，又以诸见空故而令开解，是品义意。如《般若》中说，佛告勇猛极勇猛菩萨摩诃萨：「知色非起见处、亦非断见处，乃至受想行识非起见处。亦非断见处。若色受想行识非起见处、亦非断见处者，是名般若波罗蜜。」今以无起等差别缘起令开解者，所谓息一切戏论，及一异等种种见悉皆寂灭，是自觉法、是如虚空法、是无分别法、是第一义境界法，以如是等真实甘露而令开解，是一部论宗意。问曰：诸佛所说，初中后皆真实。此论中何须广立诸验耶？答曰：或有愚钝诸众生等，于佛阿含不能正信，为欲摄取彼众生故，广立诸验。我今顶礼龙树阿阇梨故，而作颂曰：

般若灯论释第二十七品竟。

「还是昔我者，但是取自体； /
若离彼诸取，复有何我耶？」 /

「若取是我者，何处更有我？ /
由取起灭故，云何是取者？」 /

「若异于彼取，有我者不然； /
离阴应可取，而不可取故。」 /

「我不异于取，亦不即是取； /
而复非无取，亦不定是无。」 /

「今世无过去，是事亦不然； /
过去前生者，与今世不异。 /
若今与前异，离前应独立； /
如是应常住，不为现阴缘。」 /

「诸业皆断坏，此人所造业， /
彼人当受报，得如是过咎。」 /

「非生共业起，此中有过故； /
我是作如瓶，先无而后起。」 /

「或有如是见，来世有我起； /
来世无我起，同过去有过。」 /

「若天与人一，我则堕于常； /
天既是无生，常不可生故。」 /

「若天与人异，我则堕无常； /
天与人异故，相续者不然。」 /

「若天在一分，人又在一分， /
常无常共俱，一处者不然。」 /

「若常与无常，二义得成者； /
非常非无常，汝意亦得成。」 /

「有处有人来，从住处有去； /
生死则无始，而无有是事。」 /

「若无有常我，谁复是无常， /
亦常亦无常，非常非无常？」 /

「世间若有边，云何有后世？ /
世间若无边，云何有后世？」 /

「此诸阴相续，犹如然灯焰； /
以是故世间，非有边无边。」 /

「前世阴已坏，后阴别起者， /
则不因前阴，是名为有边。」 /

「若前阴不坏，后阴不起者， /
既不因前阴，而即是无边。」 /

「一分是有边，一分是无边； /
离彼有无边，更无俱等边。」 /

「云何一取者，一分是有坏， /
一分是无坏，如是者不然。」 /

「有边及无边，是二得成者， /
非有非无边，其义亦得成。」 /

「是第一义中，一切法空故， /
何处何因缘，何人起诸见？」 /

「佛为断诸苦，演说微妙法， /
以怜愍为因，我今礼瞿昙。」 /

「牟尼法王子，大智阿阇梨， /
以般若妙理，开演此中论。 /
善解利他行，为照世日月， /
显了甚深法，说得佛道因。 /
阇梨所作者，我今悉解释， /
息诸恶见故，造般若灯论。 /
此般若灯者，深妙无比法， /
然我今所作，若有少福德， /
以此般若灯，愿摄众生类， /
见法身如来，遍满十方刹， /
得自所觉法，息诸见戏论， /
寂灭无分别，无比如虚空。 /
复愿般若灯，普照于世界， /
为暗所覆者，建立于涅槃。」 /

「愿以一念善，随喜回向等， /
与一切众生，命终见弥勒。」 /
