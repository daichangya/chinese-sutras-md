# 大乘中观释论(第10卷-第18卷) · 第十八卷

> 安慧菩萨造  宋 惟净等译

能见及所见见者等各异 /
彼更互相望一切皆无合 /

如是染染者及彼所染法 /
瞋等余烦恼余处三无合 /

异共异有合彼见等诸法 /
异性无所有故不可说合 /

非唯见等法异性无所有 /

余诸法皆同无异性可得 /

异因异有异异离异无异 /
若法从因出彼无异可得 /

若异异于异离异无所得 /
彼异不异异离异无有异 /

异中无异性不异中亦无 /
无有异性故即无彼此异 /

一法不自合异法亦不合 /

合法及合时合者悉皆无 /

从因缘和合诸法即无生 /

若从因缘生即自性有作 /

自性名作法云何当可得 /
自性无虚假离佗法所成 /

若法无自性云何见佗性 /
自性于佗性亦名为佗性 /

离自性佗性复云何有法 /
若有自佗性即诸法得成 /

有法若不成无法亦不成 /
有坏名为无世人说无体 /

若见自佗性或有体无体 /
彼则不能见如来真实义 /

世尊已成就离有亦离无 /
教授迦旃延应离有无二 /

若自性佗性或有体无体 /
自体有异性法即不可得 /

从识种子生成三有境界 /
见境界无我三有种子灭 /

若见彼异性非诸法有体 /
云何自体无异性当可得 /

言有即着常言无即断见 /
是故有无性智者无依着 /

若法有自性非无即是常 /
先有而今无此还成断见 /

诸行若轮转常即无徃来 /
无常无徃来众生亦同等 /

汝今且观如是人诸根圆具及所行 /
又若说彼有多闻或为恶兽所食噉 /
恣佗所食为所弃过去佗身彼即无 /
不还后世无怖心应知此身唯行聚 /

人若有徃来于蕴处界中 /
五种推求无谁受徃来者 /

能取及所取无诸有徃来 /
无有即无取何有徃来者 /

彼诸行无灭此云何可有 /
众生亦无灭复云何可有 /

诸行生灭法无缚亦无解 /
缚解若有作即缚解不生 /

若因取名缚有取即不缚 /
无取亦不缚何分位可缚 /

有众生可缚彼缚即有体 /
缚法彼若无如调达所缚 /

若先有其缚彼缚能缚身 /
今既无所缚如去来品说 /

已缚即不缚未缚亦不缚 /
离已缚未缚缚时亦不缚 /

已缚即不解未缚亦不解 /
若缚中有解缚解即同时 /

若我灭无取我得涅槃者 /
此或有彼执还成执于取 /

不应舍生死不应立涅槃 /
有无皆成谤此说非道理 /

自能降伏心复能摄受佗 /
即有慈爱心此说降伏体 /

思及思所生大仙所说业 /
彼业有多种次第而分别 /

彼所说思者此即是意业 /
从思所生者所谓身语业 /

受用故生福施受用福生 /
非福亦复然此名受用义 /
并思为七种了知诸业法 /
身语表无表远离不远离 /

业住至果熟彼业即是常 /
若灭即成无云何有果生 /

若芽等相续芽等复生余 /
种先而果后不断亦不常 /
若不先植种果生即不能 /
因随果法中从芽等相续 /

若心有相续心法即现转 /
果若离于心无相续可转 /
从心有相续从相续有果 /
业先而果后不断亦不常 /

求法方便者是十白业道 /
此世及佗世得五欲胜果 /

若如汝所说次第而分别 /
彼有过失生其过多复大 /

今我复说此顺正理分别 /
诸佛及缘觉声闻等赞说 /
不失如契书业如所负财 /
界分别有四皆自性无记 /

见道所不断至修道乃断 /
是故不失法能持于业果 /

若见苦时断彼即有过失 /
有相似业故断即坏于业 /

一切相似法诸业有系属 /
诸界一法生一业一法起 /

所有二种业现非无常性 /
住至度果已如是还复生 /
或至命终灭或至度果灭 /
此无漏分别彼相亦无漏 /

虽空亦不断生死亦不常 /
业果报不失此法佛所说 /

诸业本不生非伺察可得 /
业力心相续业果二俱坏 /

若业本不生业云何有坏 /
若其有所生彼云何不坏 /

若法有自体有业而可住 /
二世受报已彼业还复在 /

此诸业烦恼业因烦恼成 /
彼烦恼无实业云何有实 /

若说业烦恼以为身因者 /
业烦恼自空身因复何有 /

众生无明复爱结所萦缠 /
作作者受者不一亦不异 /

业不从缘生不从非缘生 /
见有业相违是故无作者 /

无作者作业何有业生果 /
既无实有业受者当何有 /

如佛神力化化成具足相 /
是化复起化初化名化者 /
诸法如化相作作者无作 /
说作者等体皆云何可有 /

诸法无有体如干闼婆城 /
烦恼业及身作者果亦然 /

蕴中若有我有即生灭分 /

若异蕴有我有即非蕴相 /

若或无有我我所当何有 /
无我无我所我我所即灭 /

诸业烦恼尽即名为解脱 /
而彼业烦恼从分别中生 /
一法如是故余法亦复然 /
无定意分别无定故差别 /

此所说想法想即心境界 /
无生亦无灭如涅槃法性 /

一切实不实

非实非不实

亦实亦不实此即诸佛教 /

若佗信寂静无戏论所戏 /
无异无分别此即真实相 /

若法从缘有而不即是因 /
亦不异于因故非常非断 /

无一义多义不断亦不常 /
此诸佛世尊正法甘露句 /

正觉不出世声闻复灭尽 /
彼缘觉正智从于猒离生 /

若现在未来因过去时者 /
彼现在未来过去时已有 /

若现在未来过去时中无 /
彼现在未来因何而可有 /

现在及未来若不因过去 /
即无彼二时不因过去故 /

若因过去时或不因过去 /

此如前所说上中下等法 /
应知无一异亦无次第转 /

时不住无取时住亦无有 /
离时何有体异体亦无时 /

若谓众因缘和合生果者 /
和合中有果何湏和合生 /

若谓众因缘和合生果者 /
和合中无果云何和合生 /

若谓众因缘和合有果者 /
和合中无取何有果可取 /

若谓众因缘和合无果者 /
是即彼因缘与非因缘同 /

因若未与果是因先灭者 /
因灭而果生果起即无因 /

若因缘和合如是果同生 /
能生及所生亦如灯与光 /

亦非先有果然后方和合 /
生已还复生即堕一时过 /

若先无和合而有果生者 /
是即离因缘乃成无因果 /

法灭即是无坏法无别体 /
是即前生因而堕重生过 /

因生果已灭而复何有灭 /
又若因住果离果何有住 /

无彼过去因与过去果合 /
亦无未生果与已生因合 /

亦无未生因与已生果合 /
已生即不见有和合可得 /

若法无和合因何能生果 /
若法有和合因何能生果 /

因果若是空云何能生果 /
因果若不空云何能生果 /

不空即不生不空即不灭 /
以得不空故不生亦不灭 /

空即云何生空亦云何灭 /
以空故不生以空故不灭 /

因果若一性即无法可生 /
因果若异性亦无法可生 /

果自体若有因即何能生 /
果自体若无因亦何能生 /

亦非因缘成亦非自体有 /
又非和合生此何能生果 /

若因缘和合所作得成者 /
果若无集因即因缘不合 /

离成无有坏离坏亦无成 /
共成无有坏共坏亦无成 /

坏法亦如成无共离道理 /
成法亦如坏无共离道理 /

离坏若有成云何当可得 /
法体无常徧无处而不有 /

若离成有坏云何当可得 /
亦如生与死非同时而有 /

若二互共成彼二互无有 /
成坏二无故云何有成就 /

尽即无有成不尽亦无成 /
尽即无有坏不尽亦无坏 /

彼成坏二法非空故可有 /
又成坏二法非不空可有 /

此成坏二法非一性可有 /
此成坏二法亦非异性有 /

有体不生体无体不生体 /
体不生无体有无体不生 /

法不从自生云何从佗生 /
自佗既不生如所生亦然 /

灭已不复生因即堕于断 /
若生灭相续故因果有体 /

若法住自体无法有分位 /
至涅盘时断即诸法断灭 /

死有若已灭取初有不然 /
死有若未灭取初有不然 /

若初有灭时而死有生者 /
灭时是一有生时是异有 /

亦无法灭时与生时和合 /
是即同所依此灭彼蕴生 /

如是此三时有相续不然 /
若无彼三时云何有相续 /
有相续若无云何有成坏 /
若无彼成坏法云何可成 /

即蕴无如来

异蕴无如来

如来无诸蕴

何处有如来

若无有自体云何有佗体 /
彼佗体既无何有人等相 /

若法因佗有彼无体可生 /
无体故无性云何有如来 /

若无有自体云何有佗体 /
离自体佗体何处有如来 /

何名未取蕴自体无别体 /
异蕴亦无取何得有如来 /

无一性异性五种求亦无 /
云何所取中施设有如来 /

此如是所取自性无所有 /
若无有自性云何有佗性 /

法无自体故能取所取空 /
及一切种空空何有如来 /

空即不可说不空亦不有 /
俱不俱亦然假施设故说 /

若不依俗谛即不说胜义 /
若不依胜义即不说涅盘 /

若法有自性见空即无益 /
诸见分别缚今此悉遮遣 /

寂灭中何有常无常等四 /
寂灭中何有边无边等四 /

佛种本无性一异不可说 /
不可说即无何施设可有 /

颠倒分别习无执中生执 /
若如来本无即无分别因 /

如来自体空思惟不可有 /
云何谓如来灭后有与无 /

佛已过戏论能破诸戏论 /
戏论所覆者彼不见如来 /

若以色见我以音声求我 /
是人行邪道不能见如来 /

彼如来自体即世闲自体 /
如来体不成世间亦无体 /

寂灭中何有常无常等四 /
寂灭中何有边无边等四 /

因分别故起说彼贪瞋痴 /
善不善颠倒此等从缘有 /

若善不善倒从缘生贪等 /
以烦恼无性故烦恼无实 /

汝意若离我谓有诸烦恼 /
从因缘有者此烦恼悉遮 /

有身见烦恼染者亦不有 /
五种求悉无诸蕴亦不有 /

善不善颠倒彼皆无自体 /
颠倒名虚妄观如来品说 /

善不善等法当云何可得 /
如干闼婆城如燄亦如梦 /

若不因不善善即无施设 /
以因不善故善亦无所有 /

若不因于善不善无施设 /
以因于善故不善无所有 /

此若无有善当云何有贪 /
又若无不善云何当有瞋 /

若无常谓常此执颠倒者 /
空中无无常何有颠倒执 /

若无常谓常此执颠倒者 /
无常若成执空何非颠倒 /

能执业用境此等目性空 /
皆是寂灭相是故无有执 /

执性无有故何言邪与正 /
计无常等法而成于颠倒 /

无未生颠倒及已生颠倒 /
亦非颠倒时有颠倒生起 /

未生当云何有颠倒可得 /
颠倒若不生何处有颠倒 /

若常乐我净此四是有者 /
彼常乐我净是即非颠倒 /

若常乐我净此四是无者 /
彼无常苦等是即应不有 /

若颠倒法灭如是无明灭 /
以无明灭故诸行等亦灭 /

有何法可断此中云何断 /
若实有自性自体无系属 /

若烦恼无实无故何名断 /
离有体无体有何法可断 /

若一切法空无生亦无灭 /
以无生灭故四圣谛亦无 /

若知及若断修证等作用 /
如是四圣谛无体即不有 /

四圣谛若无即无四圣果 /
苦等谛若无亦无向果者 /

若无八圣人是即无僧宝 /
若无四圣谛亦即无法宝 /

若无法僧宝云何当有佛 /
若如汝所说是即破三宝 /

若因果体空即无法非法 /
世俗诸所行亦破一切法 /

诸法无自体有执非道理 /
此中佛所说空故有行相 /

诸佛依二谛为众生说法 /
一是世俗谛二是胜义谛 /

若人不了知二谛差别法 /
彼不解真实甚深佛法义 /

若不依世俗即不说胜义 /
不得胜义故即不证涅槃 /

呪师法不成不善摄蛇毒 /
恶见坏于空其义亦如是 /

故诸佛世尊不欲为说法 /
众生不能解以法为非法 /
于甚深空义而实不能入 /
以如是因故不坏复云何 /

汝谓我着空不空亦不有 /
以空不有故不应生毁责 /

以有空义故一切法得成 /
若不有空者一切法不成 /

汝今自有过而返谓我有 /
譬如乘马人自忘其所乘 /

汝若见诸法皆有自体者 /
法若非因缘还成汝自见 /

因果有定性作作者亦然 /
乃至生灭等汝悉破果法 /

若从因缘生诸法即无体 /
缘亦是假名非一异可有 /

若不从缘生无少法可有 /
由从缘生故彼皆如幻士 /

若一切不空无生亦无灭 /
以无生灭故四圣谛亦无 /

若不从缘生云何当有苦 /
无常是苦义彼体无所有 /

苦体若不有云何当有集 /
是故若无集此即破于空 /

苦若有定性自性无所作 /
自体若有着此即破于灭 /

道若有定性修即不可得 /
道若是可修定性无所有 /

若彼苦与集及灭无所有 /
而灭苦道谛云何当可得 /

若苦法不生灭法云何有 /
苦自体无知彼法复云何 /

苦法不知故余断及作证 /
修习亦复无即无四圣谛 /

若无四圣谛即无有法宝 /
以无法僧故云何当有佛 /

不以菩提缘佛堕无缘过 /
不以佛为缘菩提还成过 /

若佛有自体无菩提可成 /
无菩萨修行亦无得果者 /

不空何所作自体所作无 /
法非法亦无果亦无所有 /

因法非法故是即有其果 /
法非法若生不空何有果 /

汝亦破世间一切所行相 /
以破空义故复坏于缘生 /

若破于空义即无法可作 /
此何能发起无作有作者 /

世闲众物类老少等变异 /
若自体不灭有定性为常 /

若见缘生义见非见相应 /
即能见苦集灭道谛亦然 /

若一切法空无生亦无灭 /
无断无所证云何成涅槃 /

若一切不空无生亦无灭 /
无断无所证云何成涅槃 /

无退亦无得不断亦不常 /
不灭亦不生此说为涅槃 /

若涅槃有体即堕老死相 /
涅槃非老死而无老死法 /

若涅槃有体涅槃即有为 /
此乃无有法而是无为者 /

若涅槃有体云何名无取 /
若法体是有何法无取邪 /

若涅槃有体无体当何有 /
涅槃有体故无无体可成 /

若涅槃无体云何名无取 /
非无体可有涅槃即无取 /

有体有生死即有往来相 /
因彼无取故即说为涅槃 /

佛大师所说断有及非有 /
胜义无无体此即成涅槃 /

若有无二法共成涅槃者 /
彼有无二法解脱性不成 /

涅槃有无成云何得无取 /
而彼有无相二因取故成 /

若有无二法共成涅槃者 /
涅槃是无为有无是有为 /

若有无二法共成涅槃者 /
彼二非一处如明暗不俱 /

非非有非无而成于涅槃 /
彼有无二法无能成所成 /

若非有非无而成涅槃者 /
此有何可说亦有何可取 /

如来涅槃后不说有与无 /
俱有及俱非如来悉不说 /

非生死涅槃有少法差别 /
涅槃与生死亦无少差别 /

实际涅槃际空际生死际 /
非彼二中闲有毫厘差别 /

依止于涅槃先际及后际 /
说常等边等有无等诸见 /

若诸法皆空何有边无边 /
亦有亦无边非有非无边 /

何一性异性何有常无常 /
亦常亦无常非常非无常 /

诸所得皆寂远离诸娆恼 /
无我无所成诸法无所得 /

众生无明复后复起三行 /
由三行造业生人等诸趣 /

以行为因故而取著于识 /
由着彼识故增长于名色 /

由名色增故而生于六处 /
六处随起触所生如次说 /

因眼及与色与名色为缘 /
如是法和合是故识生起 /

由眼色识三故能生于触 /
从触复起受此受相三种 /

因受起于爱以受故爱生 /
从爱生于取所取有四种 /

因取故有有谓取者有故 /
若无取解脱是故无彼有 /

有者谓五蕴从蕴故起生 /
生故有老死及忧悲苦等 /

诸忧悲苦恼皆从生所起 /
如是即唯有一大苦蕴生 /

此无明及行为生死根本 /
智者于无明而不见有体 /

若无明息灭诸行亦复灭 /
无明行灭故智者如是修 /

灭法对治生即真实所转 /
此一大苦蕴如是苦皆灭 /

## 观诸见品第二十七

复有人言胜义谛中有众生相续是见处故此非不有相续所起是故今此自体相续皆如梦等。

论者言如汝所说有其相续是见处者此非道理如下颂言。

释曰今此如是即起世闲常等诸见谓世闲常世闲无常亦常亦无常非常非无常如是诸见因见世蕴依过去起今此所说过去世者名为先际。

次下颂言。

释曰于未来世为有起邪为无起邪亦有亦无非有非无邪如是即起边等诸见谓世闲有边世闲无边亦有边亦无边非有边非无边如是诸见因见世蕴依未来起此说未来名为后际。

论者言此言有者非胜义谛谓胜义谛中诸见皆空复云何有故下颂文证成此义。

释曰何所以邪此中所言谓过去世即非今世以无勤力而可成故又时世别故别业生故如数论师言彼过去世即今世者此非道理汝宗大谛神我过去世者非今世有何以故无差别故若无差别即因果不异是义不成一切因喻而悉无体诸所成法时非时处因相不住亦非同时而有所成是义显明又复此中二法不和合故若言因果无别异者即自体中而有遮遣云何体中故遮异性而言不异此复云何若自体中有所遮遣如是应有乐苦痴性所成和合若尒应汝最初本所成法即是乐苦痴性无别何以故性无别故若乐苦痴无别异者汝最初谛何故所成而各异邪又复何故汝宗乐等及大谛等神我等中诸根大种各有自体彼大谛等各各有果既容别异如是即应果起果成是义亦容互相长养故知乐等及大谛等各有自体以彼乐等有因和合故且非同时所成法中何等有因何等无因如是知者所作如理若汝意谓乐等法中诸乐等因此有异者彼乐等果亦即有异故非因果二法无别若无别者即彼如是所起之果而无道理何以故因果无异故又差别诸因自体若一即差别果自体不成以果所成诸差别法有多种体一果不生故云何汝宗彼萨埵等自性互相于果法中能建立邪为离互相长养性故何以故而彼互相长养法中无所生故此中云何如前所说大谛等法如是长养即有次第若一种法一种功用离自力能而亦互相不得成故以互长养彼无体故若尒即应如是同生我及大等于是时中生成果义诸长养等如前所说悉无体故如是乐等及彼地等次第同生俱无长养又复如前彼地等法及萨埵等緫集诸体同一住持有所行故同时成办故若尒即是地等诸法互相长养乃至决定所作事用于和合中不有和合所成之义谓彼无体故长养亦无体若离长养所成果法不能建立由如是故若如所说悉不能立如汝所说萨埵之言与彼啰阇怛摩二法开示所行乃有相违何以故谓萨埵功用不能长养彼二法故决定所行皆不有故若啰阇摩开示所行二法决定而不有者如是果起果成于自体中皆悉遮遣异法和合于自体中悉亦遮遣而不成故如是即应乐苦痴果亦无别异何以故乐苦痴果说有异故如是亦应大谛神我果体有过谓以乐苦痴法因果无异如是因果二法无体岂得和合若法一处无别异者即如是处决定所作而无因果不有异性故此乃因义不成一切事用一切所成此有何义是中云何萨埵自体有其事用及一切果又复何名有一切事一切自体如是有者即是有因及有果法若谓因果是一体者诸有缚因即是解因如是有智即是无智如是起相即是坐相如是善趣因即是恶趣因由如是故是即无彼因果可见又复亦应无缚无解此等皆如诸处广说即于如来阿含等中一切无体又此色依分位大无义利是故一切事用一切所成悉不和合亦无一切事用一切果体各别决定因果二法和合相续于诸事用果体亦无所证由是因故因果差别无异相续而可起故所言一切者此说即是诠表之义于诠表中亦非无异而有所成若或各别决定境界诸根作用皆寂止者汝宗大谛神我等法亦应不定无因果体故时处因相皆无果利悉已遮故于一切事一切所成徧一切处若或有者此复何义亦非同时有法所成是义显明若复异体不有果者即一切事用悉无所得此义既明前所遮遣悉非道理。

或有人言身虽有异而我是一以有我故过去世中有我可得此说毕竟如是决定取差别故此说有取是故有我别异所成。

论者言取有别者此无差别何以故或谓决定异取有我者下颂遣言。

释曰亦非有蕴既变坏已我复有成所言有者谓成就义由取故有我以有我故即有我所此即二种分别建立第三分别而复无体彼法体者取不即我谓积集故如外物体亦非别异诸有法体所作坏已而复有来何以故若取有所得云何有其作者作业二法差别是故无因有我可得此中如是广说证成亦非无我但为遮遣我故乃说无我。

复次颂言。

释曰如佛所言我若无体即于苦乐悉得舍离由是乃于善趣解脱今此遮遣我语取故。

复次颂言。

释曰何故不可得邪谓所取中无能取义离差别相故若离能取亦无所取谓以离取无异取故。

复次颂言。

复次颂言。

释曰今此证成复何义邪。

次下颂言。

释曰若离于此有异可成即离于彼亦异可成何以故若此世异彼有所起者即彼如是有生无死谓前世有死此世有生前若无死此亦无生以前世死是此世生。

复有人言或别异法有别异性彼法虽坏相续得成。

论者言先世我体若已断者与此相违何以故诸业坏故又此人造因彼人受果造因者异受果者异此如是等皆有过失。

复次颂言。

释曰若异作异受此非道理何所以邪下颂荅言。

释曰谓由先有所积集故。

复次颂言。

释曰如其所说审谛观察乃以多种开示其义今此遮遣依止未来而起诸见未来有我或无我邪如是诸见皆同过去然后一性异性俱不俱等此中皆止此复云何故下颂言。

释曰如是有法此即不生以天有故所以者何若法有生即无其常是故未来世中不见有我亦不见无我此俱有过。

复次颂言。

释曰若人身生即天身坏此云何有以异性故如提婆达多与演若达多二蕴各异于异性中即不见有相续可得。

复有人言亦有天身亦有人身。

故颂遣言。

释曰若如是有亦天亦人者彼有过失是即半身有所成故。

复有人言此中非常非无常是可有邪。

故颂遣言。

释曰今此遮遣所说成义此中意者即彼如是转复难解何以故若天界人界何有所来若天若人亦复有其何趣可去若或有其天等同分我即无始而乃有常非有一法来去可成所有众生及补特伽罗如前所说悉已遮止是故此中所说亦无常法可得以非道理故无有常故又复常法无对待因故是故无常不能有成又复离彼常无常法复有何法而得起邪。

复次颂言。

复次颂言。

释曰言有边者譬如世闲焚烧种子不复有其相续和合是故亦无后世可有言无边者亦无种类所作果故是故边无边二而悉不有。

复次颂言。

释曰此复云何若先蕴已坏不因是蕴后蕴复生此即说为世闲有边谓诸蕴已灭无和合故若先蕴不坏亦不因是蕴后蕴不生此即说为世闲无边谓以先蕴一切分位二俱不见是故世闲有边无边此皆不有。

复次颂言。

释曰若我是一亦不可得此复云何。

故颂遣言。

释曰坏及不坏各一分者皆非道理。

此中意者若言二分亦悉止遣。

复有人言非有边非无边应可有邪。

故颂荅言。

释曰此中何故湏止遣邪谓若有所得即有过失其或无者又复云何如是若有决定所得此即离于中论所说若或无所得者云何于彼实不实法中有遮遣邪若汝所乐乃至众生有所得者即非中论所说有相违故由此应知世俗谛中即有所得胜义谛中一切遮遣虽言无所得于佗所得亦容有成非悉遮遣谓于和合有相违故若尒即于比量而不相违但于胜义谛分各别遮遣有所得故世俗法中非离所作谓与世俗一向义边诸缘生法不相违故若谓定实有所得者亦非道理何以故见量相违故此中应问若尒于有分中岂不相违荅见量无所得故此无过失是故应知诸言自者皆见量摄此即是为不颠倒说此复云何能了知邪谓于二中若了不二即无虚诳若于见量比量法中了达见量比量之义是为正说于诸分位中若微细若广多一切义门得决定见量者彼见量智于一切因及彼一切世俗法中无不了达然于一切以见量所证皆如梦幻如干闼婆城等若于一切不如实义中皆非见量此说正理若于形显色等所取相中先所惯习诸思念事于梦所见此等皆如盲人观色由此应知世闲一切此彼所取皆如梦中昔惯习事及睡眠人惯习思念有何差别但从徃昔习念而有沉于梦寐觉已即无世闲一切悉无所得于见生中有所得相起分别者皆如梦等若于梦中所见色像此亦非无又过去生中已起别异一切色像与见生中梦中起者而各有异不和合故如三摩地所生大种所成三摩地境界此相似者形显色等所成亦然是故一切境界无实皆是梦中意识所起此即比量之名如比量义而不相违此如是等广说证成如来决定一切所说无不和合是故世俗胜义一切所说于彼世俗胜义谛中俱不相违今此应知诸见不生下颂所说如是证成。

释曰此中亦无诸见所起一切境界作者作业此等诸法皆是无生如是一切种种分别所生诸见起多种苦及多种类若能了知无种类已普徧世闲起大悲心皆如亲友緫结颂曰。
