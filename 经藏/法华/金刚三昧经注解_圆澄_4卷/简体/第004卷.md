# 金刚三昧经注解 · 第四卷

> 明 圆澄注

---

大慈满足尊，智慧通无碍，广度众生故。 /
说于一谛义，皆以一味道，终不以小乘。 /
所说义味处，皆悉离不实，入诸佛智地。 /
决定真实际，闻者皆出世，无有不解脱。 /

无量诸菩萨，皆悉度众生，为众广深问， /
知法寂灭相，入于决定处。如来智方便， /
当为入实说。随顺皆一乘，无有诸杂味， /
犹如一雨润，众草皆悉荣，随其性各异。 /
一味之法润，普充于一切，如彼一雨润。 /
皆长菩提芽，入于金刚昧，证法真实定。 /
决定断疑悔，一法之印成。 /

大觉满足尊，为众敷演法，皆说于一乘， /
无有二乘道。一味无相利，犹如太虚空， /
无有不容受。

随其性各异，皆得于本处。如彼离心我， /
一法之所成，诸有同异行，悉获于本利。 /
灭绝二相见，寂静之涅槃。 /

亦不住取证，入于决定处。无相无有行， /
空心寂灭地，寂灭心无生，同彼金刚性。 /

不坏于三宝，具六波罗蜜，度诸一切生。 /
超然出三界，皆不以小乘，一味之法印。 /
一乘之所成。

如来所说义，出世无有相，可有一切生。 /
皆得尽有漏，断结空心我，是则无有生。 /
云何无有生，而得无生忍？ /

满足大智尊，广说无生法，闻所未曾闻。 /
未说而今说，犹如净甘露，时时乃一出。 /
难遇难思议，闻者亦复难，无上良福田。 /
最上胜妙药，为度众生故，而今为宣说。 /

大哉菩萨，智慧满足，常以本利， /
利益众生。于四威仪，常住本利， /
导诸群庶，不来不去。 /

若集若独行，分别及以染，回神住空窟， /
降伏难调伏，远离诸欲刺，解脱魔所缚。 /
超然露地坐，识阴般涅槃。 /

尊者大觉尊，说生无念法，无念无生心， /
心常生不灭，一觉本觉利，利诸本觉者， /
如彼得金钱，所得即非得。 /

具足般若海，不住涅槃城，如彼妙莲华。 /
高原非所出。诸佛无量劫，不舍诸烦恼， /
度世然后得，如泥华所出。如彼六行地， /
菩萨之所修，如彼三空聚，菩提之真道。 /
我今住不住，如佛之所说，来所还复来。 /
具足然后出。复令诸众生，如我一无二， /
前来后来者，悉令登正觉。 /

因缘所生义，是义灭非生，灭诸生灭义， /
是义生非灭。

## 4

如来藏品第七

尔时，梵行长者从本际起，而白佛言：尊者！生义不灭、灭义不生，如是如义即佛菩提，菩提之性则无分别，无分别智分别无穷，无穷之相惟分别灭。如是义相不可思议，不思议中乃无分别。尊者！一切法数无量无边，无边法相一实义性，唯住一性其事云何？

前来解脱等菩萨问者，显中道义。次继之以舍利弗问者，显真空义。此中长者问者，显俗谛妙有义。妙有不有，真空不空，皆庄严法性不思议境也。生义不灭者，所谓自性非生灭也。灭义不生者，所谓生灭是因缘也。如是无生而不碍于炽然发生，无灭而不妨于寂然常灭，即佛之中道菩提。为度众生文字表显，作如是议论。若究竟菩提自性，则无可分别。凡夫于无分别作分别解，名之为识。诸佛于分别时达无分别义，名之为智。何以为智？以一切万法由分别故，了达无生，故曰无穷之相，唯分别灭。如是之义，生与无生，灭与不灭，分别及不分别，皆不可得而思议也。以不思议故，称性发挥，如壮士展臂，何处更容分别也？以无分别故，具收无量无边佛法。我惟住一性，其义云何？蹑前一切佛法皆住一四句偈中意也。

佛言：长者！不可思议。我说诸法为迷者故、方便导故，一切法相一实义智。何以故？譬如一市开四大门，是四门中皆归一市；如彼众庶随意所入，种种法味亦复如是。

佛谓汝能常守一性，是不可思议也。何以故？盖由众生真如不守自性，随缘变现，深沉不觉，欲返其迷，故以种种方便引导其心。虽说种种方便，究竟所归，无非一实义尔。譬如一市而开四门，四门所入，无非一市。以东西南北所来路异，适其便宜，不得不四，而所到之处，不得不一。何以故？无二处故。一切众生，利钝偏圆，根基不一，所说之法，不得不异，究竟所归，惟一自性，无二性故。所以能住一性，则不可思议也。

梵行长者言：法若如是，我住一味应摄一切诸味。佛言：如是，如是。何以故？一味实义如一大海，一切众流无有不入。长者！一切法味犹彼众流，名数虽殊其水不异。若住大海则括众流，住于一味则摄诸味。

领前一市开四门，则知住一味即具摄诸味。佛印许之。复广其喻，一味如大海，众味如百川，即一而多，即多而一，圆融自在。海不言我能具内百川，百川亦不言我等同归大海，无出无入，是如是义。上则以喻显法，此下以法合喻，文显可解。

梵行长者言：诸法一味，云何三乘道其智有异？佛言：长者！譬如江、河、淮、海，大小异故，深浅殊故，名文别故。水在江中名为江水，水在淮中名为淮水，水在河中名为河水，俱在海中唯名海水。法亦如是，俱在真如唯名佛道。长者！住一佛道即达三行。

心性惟一，凡夫根机大小之不同。如江河等水譬心性，大小譬根机也。真如不守自性，随类得名，犹水无定名也。水在江则名江，水等用譬心性。在凡名凡，在圣名圣。广譬则六道四生，其类无量，莫有不从一性之所出生。若能了性还源，总一佛性。惟一性故，能住一义，即达三行。

梵行长者言：云何三行？佛言：一、随事取行，二、随识取行，三、随如取行。长者！如是三行总摄众门，一切法门无不此入，入是行者不生空相，如是入者可谓入如来藏，入如来藏者入不入故。

随事取行者，真如不守自性，随缘变现，即俗谛幻有义。随识取行者，真如不坏自性，随缘不变义。随如取行者，即真俗不二，中道不思议义。所有世、出世间，不出此空、假、中三种妙门，摄尽无余。入此三门，不生空想，不生不空想，亦不生空不空想，三谛圆融，入即非入，非入即入，遮照自在，是如来藏义。文经句略，具言则有空如来藏、不空如来藏、空不空如来藏。如云入是行者，不生空相，非专明一真谛可知。

梵行长者言：不可思议入如来藏，如苗成实无有入处，本根利力利成得本，得本实际其智几何？

所言如来藏者，即是自性本来具足，非从修得。由众生迷其本有，佛以方便调伏，令其反迷得悟，故说修行垢尽，明现法尔。如来岂从外来？以非外来修行，则自然得道。如苗成实，不期然而然，不知所以然而然之矣。实非苗外而有，若耘获得所，苗则成实；若不得方，则实不成。众生道果，亦复如是。若知正修道则可冀，不得正修道则不成。道既可成，当其得道之时，得几智慧？

佛言：其智无穷，略而言之其智有四。何者为四？一者定智，所谓随如；二者不定智，所谓方便摧破；三者涅槃智，所谓慧除电觉；四者究竟智，所谓入实具足道。长者！如是四大事用，过去诸佛所说，是大桥梁、是大津济，若化众生应用是智。长者！用是大用复有三大事：一者于三三昧内外不相夺，二者于大义科随道择灭，三者于如慧如定以悲俱利。如是三事成就菩提，不行是事则不流入彼四智海，为诸大魔所得其便。长者！汝等大众乃至成佛，常当修习勿令暂失。梵行长者言：云何三三昧？佛言：三三昧者，所谓空三昧、无相三昧、无作三昧，如是三昧。梵行长者言：云何于大义科？佛言：大谓四大，义谓阴界入等，科谓本识，是为于大义科。

定智者，即前随中道如如之义也。不定智者，即前随事取行也。涅槃者，即前随识取行也。三者即空假中之异名。究竟智者，非空非假，亦非中道，故曰二边纯莫立，中道不须安。前三行是因，是自修之行。此四智是果，是利他之德。以一切法趣真如，是趣不过者故。真如是定智，顺机适宜，无方化度故。解脱是不定智，众生为无明所覆，烦恼所缠，唯般若照惑，无惑不破，惑破则安乐，故般若名涅槃。空假中三名竝立，则名不当实，故名究竟。三者俱忘，名实俱非，言思道断，是为入实具足也。如是四智，非我独唱，过去先佛，莫不说此。是知此四是大桥梁，一切贤圣同登故，一切众生莫不获周济故。既圣凡同沾其利，汝欲化众生，舍此无他也。三昧云：正见亦名正定。以正见故，内不起诸惑。以正定故，外不为诸境所夺。此特自利之意。若具论利他，内不见能度之心是空，外不见所度之众是无相。内外既空，中间无作。天然自在，不为内外所夺矣。大谓四大，即色身。义谓阴界入，即是色心。科谓本识，前所谓本根利力也。以本根为体，然后验彼利钝，择善灭恶。何以择灭？若彼六道之众，单迷心者，开心故说五阴。单迷色者，说十二入。色心俱迷者，为说十八界。随其道类，择以修之，所谓善巧方便也。如慧者，不碍智照，而方便调机也。故曰般若无知，而无所不知。如定者，不起灭定，而现诸威仪也。不起灭定，则自利已具。不碍智照，则利他有余。长者问意，谓入如来藏，当得几智？而如来藏，当得四智。而是四智，非有所得。能修三事，不期入而入。不修此三，则不得入矣。以不入故，便为大魔所摄。是知此三，非特凡夫小圣，便可中止。乃至成佛，不应暂舍。释文中具二缺一，所谓举二则知其三也。

梵行长者言：不可思议！如是智事，自利利人，过三界地，不住涅槃，入菩萨道。如是法相，是生灭法，以分别故。若离分别，法应不灭。

如是智事，指上四智。方便摧破，是利他。随如是自利慧，除电觉，兼自他而言也。此中合赞，自利故，超过三界九地；利他故，方便化生，不住涅槃。菩萨道，即前入实具足道。若此四智作四智解，则是生灭法，以有分别故。若了四智无相，当体无生，离诸分别。如是心法，本非生灭，以生处不可得故。

尔时，如来欲宣此义而说偈言：

法从分别生，还从分别灭，灭诸分别法， /
是法非生灭。

善不善法从心化生，以心随分别则有法生。法之所生起于分别，还由分别微细剥，法法何状？以无状故，分别不生，法亦随灭。能分别是心，所分别是法，心法两忘，真性独朗，非生非灭。故古人云：灵光独耀，逈脱根尘，但离妄缘，即如如佛。结答：长者所解，我住一味，应摄诸味。㓟

尔时，梵行长者闻说是偈，心大欣怿，欲宣其义，而说偈言：

诸法本寂灭，寂灭亦无生，是诸生灭法。 /
是法非无生，彼则不共此，为有断常故。 /
此则离于二，亦不在一住。若说法有一， /
是相如毛轮，如水迷倒，为诸虚妄故。 / 𦦨
若见于法无，是法同于空，如盲无目倒。 /
说法如龟毛，我今闻佛说，知法非二见。 /
亦不依中住，故从无住取。如来所说法， /
悉从于无住，我从无住处，是处礼如来。 /
敬礼如来相，等空不动智，不着无处所， /
敬礼无住身。我于一切处，常见诸如来， /
惟愿诸如来，为我说常法。 /

是法寂灭者，指真如来觉之法也。生灭者，指虚妄所生之法。是虚妄分别之法，即真如无生之理。以真如离二边分别，着断常，如水火之不共，势使之然也。夫真如之理，非惟不着二，亦复不住中。三处无着，可谓无方大道也。彼外道凡夫，不谙真如实隐之义，于一切法妄起分别，作有无论。若说法有，则落常见，如毛轮水。本无见有，宁非虚妄？此斥常见凡夫也。若见法无，宁同虚空？而虚空者，无见无闻，无知无觉。汝现有见闻，岂同无目？现有言说，岂等龟毛？此斥断见外道也。彼为邪师所教，堕此二见。我闻世尊开示，故三处不着。何以不着？以法无定方故。如来说法，无有定法可说。以如来说法无定，我从无定处留心。以无住故，无所不住。如彼虚空，周徧法界，而非来去。头头尔，法法尔，触目现前，常见如来也。𦦨

尔时，如来而作是言：诸善男子！汝等谛听，为汝众等说于常法。善男子！常法非常法，非说亦非字，非谛非解脱，非无非境界，离诸妄断际，是法非无常。离诸常断见，了见识为常，是识常寂灭，寂灭亦寂灭。善男子！知法寂灭者，不寂灭心，心常寂灭。得寂灭者，心常真观，知诸名色唯是痴心，痴心分别，分别诸法，更无异事出于名色。知法如是，不随文说，心心于义不分别我，知我假名即得寂灭，若得寂灭即得阿耨多罗三藐三菩提。

汝请，我为汝说常法。常与无常，但有言说，而无实体。若真常之理，非言可说，非字可载，非谛可信，非解脱可求。虽非言语等，而实有法，非同外道虚无不实比。虽是有法，乃自心具足，非外境界。既不同于外境，即不同于断常。何以不同？以吾自心真常之法，非无故非断，非有故非常。能了自心真常，则知心乃寂灭之常，非断灭之常也。若定执有寂灭可得，则亦堕虚妄，实为不可。既无寂灭可得，何以知其为寂灭耶？以所知之法寂灭，而能知之心未尝寂灭也。以心常寂灭，不必更知得寂灭者。心冥真观，知诸名色等法，体是寂灭。由心分别，见有是非。了法如是，则知一切法非字非言。以知非故，不堕文言。心契实义，则不着我及无我，是二皆寂灭故。

尔时，长者梵行闻说是语，而说偈言：

名相分别事，及法名为三，真如正妙智。 /
及彼成于五。我今知是法，断常之所系， /
入于生灭道，是断非是常。如来说空法， /
远离于断常，因缘无不生，不生故不灭。 /
因缘执为有，如采空中华，犹如石女子， /
毕竟不可得，离诸因缘取，亦不从他灭。 /
及于己义大，依如故得实，是故真如法。 /
当自在如如。一切诸万法，非如识所化， /
离识法即空，故从空处说。灭诸生灭法， /
而住于涅槃，大悲之所夺，涅槃灭不住。 /
转所取能取，入于如来藏。 /

领上名色诸法，痴心分别而有，则世出世间所有诸法，皆是对待生起，并皆不实。法虽多名，不出五种，所谓名、相、妄想、正智、如如也。领上非名非字，是悟名空；非境界，则悟相空；非谛，则悟妄想空；非解脱，则悟正智如如空。以正智对妄想，以如如对幻相，既以对待生起，了妄本空，则真亦不立。我向闻外道所说，一一皆执为实，为有无所转，断常所系，入彼生灭，非真常不生灭道。今闻如来所说第一义空，远离二释，是二边法从因缘生，是真空之法不属因缘，以因缘之法定属生灭，真空不生，故无有灭。若彼外道执因缘所生之法是有者，即落常见；若执定无者，即落断见。如是有无戏论之中，欲求实义，了不可得，如狂人采空中之华，如求石女生子，毕竟不可得也。了达因缘者，不从因缘而起生相，亦非离因缘而取灭相，故中观云：因缘所生法，我说即是空，亦名为假名，亦名中道义。已谓本识，义谓阴界入，大谓四大，如是等悉了不实，惟依如如正体乃得名实，是故真如乃名自在。一切万法皆依识变，离识非有，不得名如，以离识非有故，佛称真而说空。说空在破有，若破有住空，缺于大悲，双舍有无，不涉生死，不住涅槃，超然中道，然后能取所取皆入如来之藏，以如来藏有空不空，空不空故。

尔时，大众闻说是义，皆得正命，入于如来如来藏海。

总持品第八

尔时，地藏菩萨从众中起，至于佛前，合掌胡跪，而白佛言：尊者！我观大众，心有疑事，犹未得决。今者如来欲为除疑，我今为众随疑所问，愿佛慈悲，垂哀听许。佛言：菩萨摩诃萨！汝能如是救度众生，是大悲愍，不可思议。汝当广问，为汝宣说。

总持前七品之义也。能持如地，所持如藏，故地藏菩萨表之也。又离能绝所，如地之持物，含育万有，如地能藏也。因闻前无生之义，而众疑未尽，故起问，明为众所问，拣自无疑也。如来深相赞叹者，印其自无疑，而为众故问，使现前之众，各各自信，勿作他观尔。

地藏菩萨言：一切诸法云何不缘生？尔时，如来欲宣此义，而说偈言：

若法缘所生，离缘可无法，云何法性无， /
而缘可生法？

内识为因，外境为缘。又资始为因，助因为缘。或因心而有分别，以心为因，以境为缘。或因境而起分别，则境为因，以心为缘。二者递互生起，各无自性。以无性故，我说因缘无生。若彼凡夫执有因缘能生诸法，是法既从缘生，缘散则灭，灭则显发一切都无，无则是谁修证无生法忍？若是无生法性，既不属于生灭，岂彼生灭之因缘，能生此无生之法性耶？

尔时地藏菩萨言：法若无生，云何说法？法从心生。于是尊者而说偈言：

是心所生法，是法能所取，如醉眼空华。 /
是法然非彼。

法若无生者，则应无文无字无说无示，领前非说非字等以为难本。若非言则不应有说，若非字则不应有示，既无说示，云何而说法从心生？世尊答：谓法本无生，以一切众生迷本无生著于能所，故我说能所所生之法，皆是妄想非是本心，犹如醉眼狂见空华。今此经中所说第一真如之法，非同妄心故说无生，欲令众生随宜获悟，故前则隐实施权，权说法从心生，今则废权显实，故说法本无生，不相违也。

尔时地藏菩萨言：法若如是，法则无待。无待之法，法应自成。于是尊者而说偈言：

法本无有无，自他亦复尔，不始亦不终， /
成败则不住。

一切诸法，法法相待，所谓因待缘成，无待无说。今观法性无生，如是应非有待。无待则法应自立，谓世间之法，因待成立。出世本法，无名无相，非说非字，非惟无有对待，抑且自亦不立。何以不立？偈答：法本无有无，因有说无。世间情见法本无无，何待之有？有无既然，自他亦尔。此之真法，过去无始，未来无终。既无终始，成败何有？夫真如法性，取譬虚空，极为恰当。以空无生故，空亦不灭，法性亦尔。以空无成故，空亦无败，法性亦尔。如是之法，当默得之，言思之外可也。若落意思，则亦不是尔。

尔时，地藏菩萨言：一切诸法相即本涅槃，涅槃及空相亦如是。无是等法，是法应如。佛言：无如是法，是法是如。

三乘说法有生有灭，一乘说法非生非灭，即是涅槃。以涅槃不生不灭故，为度众生假说不生灭名。若真实领意，是生灭是不生灭俱不可得，以不可得故始称真如。菩萨领悟如是亲切故，如来印其解为是。若有如是可得是亦虚妄，以无如是可得故名为如。

地藏菩萨言：不可思议！如是如相非共不共，意取业取即皆空寂，空寂心法俱不可取亦应寂灭。于是尊者而说偈言：

一切空寂法，是法寂不空，彼心不空时， /
是得心不有。

非共者，不与三乘生灭法共也。非不共者，亦非离生灭而别有法可得也。意取即能取，业取即所取。若共不共，能取所取，皆归空寂者，故不可思议。偈中重释不可思议之意。若法惟一空寂，则三乘一乘，何有优劣。而此真如法性，虽是空寂，而空寂之中，具含不空妙有也。彼三乘人，迷心执法，执有空寂。而一乘之人，悟心不空，真得空心矣。是心非空非不空，非空不空，是谓不可思议也。

尔时地藏菩萨言：是法非三谛，色空心亦灭，是法本灭时，是法应是灭。于是尊者而说偈言：

法本无自性，由彼之所生，不于如是处， /
而有彼如是。

三谛者，色是俗谛，空是真谛，心是中道谛。上言此心非空非有，似同三谛。菩萨深解非空非有，犹是言诠称性。所解三谛，亦非寂灭亦灭，而云法应是灭，作长灭解，故作此问。偈答：无性之法，由彼色心妄缘之所生起。今了法性无有如是之名，何处更有如是色心耶？然以法性无生，无所不生，随缘变现，非是永灭。

尔时，地藏菩萨言：一切诸法无生无灭，云何不一？于是尊者而说偈言：

法住处无在，相数空故无，名说二与法， /
是则能所取。

一切诸法生灭本同，今以无生无灭融之，应等虚空，云何不一有种种名？佛答：无住处，无有体性也。相数空者，用处空也。体只有名，用但有说。能说是用，所用是体，是二者皆由能所建立。有能有所，二者两立，尚不合一，何况诸法各有能事，何得混同？

尔时，地藏菩萨言：一切诸法相，不住于二岸，亦不住中流，心识亦如是。云何诸境界，从识之所生？若识能有生，是识亦从生。云何无生识，能生有所生？

诸法不住三际，则境不可得；心识不住三际，则识不可得。既各不可得者，则二者各无自性。无性而云境从识生，似有所生；识能有生，应从境生。既具能、所，安得称无？何故无生识性，而有能生、所生？

于是尊者而说偈言：

所生能生二，是二能所缘，俱本各自无。 /
取有空华幻，识生于未时，境不是时生。 /
于境生未时，是时识亦灭，彼即本俱无。 /
亦不有无有，无生识亦无，云何境从有？ /

识本无生，能生所生，皆由虚妄自搆，二者本自无体。凡夫作有解者，如取空华，终不可得；二乘作无解者，如灭空华，欲何所为？如是用心，同名妄想。何以知其为妄想耶？谛审观之，若识未生时，境即不有；境未生时，识亦不有。观之心境未形已前，何处有能生所生？有有有无，皆是识心虚妄所计尔。为度众生，权说无生识性。若真实所论，则无生亦无，何处有境？

尔时，地藏菩萨言：法相如是内外俱空，境智二众本来寂灭，如来所说实相真空，如是之法即非集也。

内空者智空，外空者境空。所言空者，寂灭不可得也。若有空可得，还堕虚妄。以寂灭不可得，始称真实。一切万法，从此发生，而无积聚。故曰从无住本，立一切法者是也。菩萨领前心境二法，非三际所收，则知境智内外，等一寂灭。寂灭无生，而无所不生，无有积聚，用呈其解。

佛言：如是！如实之法无色、无住，非所集、非能集，非义、非文，一本科法深功德聚。

真如实际之中，不立一尘，岂干色相？色尚无有，何有方所可住？方处既无，则能所积集，一切泯绝。何以泯绝耶？小乘教中，有文有义，故多诤讼。大乘第一义空，非义非文，惟有无生本识，终不容他毫末名相。无世间积集，有出世间功德积聚也。

地藏菩萨言：不可思议，不思议聚，七五不生，八六寂灭，九相空无，有空无有，无空无有。如尊者所说，法义皆空，入空无行，不失诸业，无我我所，能所身见，内外结使，悉皆寂静，故诸愿亦息。如是理观慧定真如，尊者常说实如空法，即良药也。

不可思议者，真如之体也。不思议聚者，乃真如之用。体具不思议熏，众生为无明熏，则为烦恼；圣贤为闻思所熏，便成解脱。真如具不思议变，故众生名烦恼积集，圣贤名功德积聚。经文似讹。五识与八识，同一现量，无为性收；六识与七识，同一比量，有为法收。有为有生灭，应云六七不生；无为无去来，应云五八寂灭。因前八种识，一分有为，一分无为，同依九识为根本。若彼二处不有，则九识亦空。何以故空？文字诠表故。空及不空，皆属文言。若言思道断，则有无无有，皆不可得。菩萨善得文字性空，入第一义空，于空中有不空义。无行故，无所不行；无所不行故，不失诸业。入第一义空故，能见所见，我及我所，内外结使，悉皆寂静。内外既离，则心绝攀缘，诸愿已息。慧是性体，定是性用，是二者皆一真如所统。一念不思议观，圆具三法。世尊常说如是空法，向带疑惑，不能谛信。今日谛思，真是良药也。

佛言：如是。何以故？法性空故。空性无生，心常无生；空性无灭，心常无灭；空性无住，心亦无住；空性无为，心亦无为。空无出入，离诸得失，阴、界、入等皆悉亦无；心如不着，亦复如是。菩萨，我说诸空，破诸有故。

印可空法即良药之解也。下则释成何以空法为良药耶？以法性空故。所言法性者，性即能也。以诸法能一刹那无生相可得，能一刹那无灭相可得。虽无生灭可得，而能随顺生灭建立。其犹虚空，体非群像，不碍万象发挥故。欲知法性之空，当观诸虚空。心乃性之主，性乃心之能。能即是用，主即是体。体用不二，等一真空。何以性能是空？以阴界入等世出世间一切诸法，其相不有故。用处常空，心无可着。以无着故，同彼性空。达性空故，不复为三界所系，故是良药也。然则我所说空，实名药病句。病去则药除，乃名智者。病除而服药不休，药返成病，宁非狂人？我说诸空在破于有，有破则空亦当弃。执空有得，则堕二乘及诸外道，非我之谬也。

地藏菩萨言：尊者，知有非实，如阳水；知实非无，如火性生。如是观者，是人智也。𦦨

陆地阳，本非是水。渴鹿望之谓水，用喻一切诸法，本无有相。凡夫迷执，作有义解。火性生于木中，本无方所形像可得，钻之出已，实能烧物。用喻真如法性，本无方所形像可得，遇缘应用，毫不相亏。故庞居士云：但愿空诸所有，慎勿实诸所无。能如是观者，宁非智乎？𦦨

佛言：如是。何以故？是人真观，观一寂灭相与不相等以空取，以修空故不失见佛，以见佛故不顺三流，于大乘中三解脱道一体无性，以其无性故空，空故无相，无相故无作，无作故无求，无求故无愿，以是业故净心，以心净故见佛，以见佛故当生净土。菩萨于是深法三化勤修，慧定圆成即超三界。

真观者，能所双寂，等一真空。以空故，不见二相，非有所取。空一切相，即一切心，是名佛。佛者，觉也，觉自心故。一切众生，迷背自心，流落三有，枉受生死。能觉自心，逆彼三有之流，顺入大乘圣流。大乘之道，性惟一体，证有三门，故称三解脱。无相即是法身，以法身无相故。无作即是解脱，虽破尘沙，不障化道。体惟无作无求，又名无愿，即是般若。智备于内，不假外求故。众生以贪、瞋、痴秽浊自心，顺三有流。圣贤以空、假、中庄严自心，入圣道流。见佛是正报，生净土是依报。若正若依，皆不外乎自心也。三化者，空、假、中三种化门，勤修不倦，自利利他，无所不备。慧是般若，定是解脱，圆成是法身。三德具足，何三界之不超也？

地藏菩萨言：如来所说无生无灭即是无常，灭是生灭，生灭灭已寂灭为常，常故不断是不断法，离诸三界动不动法，于有为法如避火坑，依何等法而自诃责入彼一门？

为对生灭说无生灭？既有所对，非真寂灭。何也？对生灭说不生灭，昔时之权。今观一乘法性，本无生灭，何须更灭？若起心动念，灭彼生灭，转觉虚妄。若一念不生，前后际断，生灭不生，始称真常。常故不为三界所留，动与不动，皆不为碍。直契无为，反观有为之法，等于火坑。然则见闻知觉，凡有名相，尽名有为。离彼有为，则无处用心。若即彼有为，复堕名相，不知依何法而自责，不知依何法而入一门。

佛言：菩萨于三大事诃责其心，于三大谛而入其行。地藏菩萨言：云何三事而责其心？云何三谛而入一行？佛言：三大事者：一谓因，二谓果，三谓识。如是三事，从本空无，非我真我，云何于是而生爱染？观是三事，为系所缚，飘流苦海，以如是事常自诃责。三谛者：一谓菩提之道是平等谛，非不平等谛；二谓大觉正智得谛，非邪智得谛；三谓慧定无异行入谛，非离行入谛。以是三谛而修佛道，是人于是法无不得正觉，得正觉智，流大极慈，己他俱利，成佛菩提。

因即无明缘行，果即生老病死。识为主宰，统摄三世，过去二支为因，现在五支为果；现在三支为因，未来二支为果。识性无体，以无明不觉，妄起分别为谬；生死无源，以识心妄取为过。若能深观无明过患，则识心不起；识若不生，则生老病死当体寂然。如此则三界往还皆由三事，为凡夫心粗，不能细观，妄执为有。细以观之，则本来是空，非实是我；妄执为我，岂真我耶？了我非我，何爱染之有？故当深观为业所系，漂流苦海，莫不皆由此三事也。初信如此道力不能胜于习气，要当数数呵责，渐至于无可呵责，自当出于三界也。菩提之道平等者，即法身平等，有情之类皆可证得，故大觉乃正智所得。非邪智得者，即是般若，劝择师友故，以邪妨正，其害深故。慧定无异者，即是解脱，梵行虽多，不出此二，故曰诸佛所得法，定慧力庄严。能修定慧是正智，不能修定慧，空谈玄理而无实行，总名邪智。世多其病，可不戒诸？能以三事自诃，三谛自修，革彼三有之流，入正觉智流，自利已足，若不发起慈悲拯救众生，则似缺一分，直须自他俱利，然后成佛也。

地藏菩萨言：尊者！如是之法则无因缘，若无缘法因则不起，云何不动法得入如来？

领前三事本空之义。若三事本空，则此法不属因缘。不属因缘，则当体湛然。何故说有入谛有不入谛耶？若有入有不入，则不得称如来。若名如来，则应无所入。盖菩萨恐人作有得想，故兴此问也。

尔时，如来欲宣此义而说偈言：

一切诸法相，性空无不动，是法于是时， /
不于是时起。法无有异时，不于异时起， /
法无动不动，性空故寂灭，性空寂灭时， /
是法是时现，离相故寂住，寂住故不缘。 /
是诸缘起法，是法缘不生，因缘生灭无。 /
生灭性空寂，缘性能所缘，是缘本缘起。 /
故法起非缘，缘无起亦尔。因缘所生法， /
是法是因缘，因缘生灭相，彼则无生灭。 /
彼如真实相，本不于出没，诸法于是时， /
自生于出没，是故极净本，本不因众力。 /
即于后得处，得得于本得。 /

一切诸法，皆称法性。若即相以观，则法法宛然。若即性以观，则法法空寂。以空寂故，不属三际。法不于是时起者，当处湛然不可得故。无异时者，不属二边故。不异时起者，前后际断故。既非前后中间，当体空寂，何有动与不动？从无住本，建一切法。当其寂灭无为之时，而无所不为。诸法炳然显现，其犹森罗之现空界。空无能现之心，像无所现之念。各各无心，各各不缘，是寂灭缘。以寂灭故，不妨随缘应现，究竟其体毕竟无生。何也？以彼因缘自相生灭，各无自性，惟一性空。统以收之，无有不尽。缘由因起，因藉缘成。本具能所，皆由因缘。缘无则起性亦灭。转释上义。何以缘无起性亦灭？释云：因缘生法，是法是缘，全体生灭。生灭是自因缘，彼法性本非生灭。谓从因缘所生之法，是法是自因缘，何干法性？以因缘有生灭，法性无生灭，故曰彼则无生灭。何以无生灭耶？释云：法性即真如之别名。夫真如实相之性，既非内外，何容出入？然彼诸法，皆藉真如为体，而自出自没。了彼生灭，即不生灭之体。故法性为真如极净之本体，照体独立，不假众缘。但非初心凡夫所得之境，乃圣贤历位熏修，自十信、十住、十行、十回向至等觉，后位登妙觉，得其本得也。

尔时，地藏菩萨闻佛所说，心地快然。时诸众等无有疑者，知众心已，而说偈言：

我知众心疑，所以殷固问。如来大慈善， /
分别无有余，是诸二众等，皆悉得明了。 /
我今于了处，普化诸众生，如佛之大悲， /
不舍于本愿，故于一子地，而住于烦恼。 /

菩萨因众有疑而起问，知疑息而说偈，可谓全体大慈，曾不立有己也。而世尊大慈，适其所问，广为分别，使在会之众，皆得明了。彼虽明了，仅得自利，未得利他，重复劝修大慈悲行，普利众生，不舍本愿，视众生如一子，子病父母亦病，故常住烦恼也。

尔时如来而告众言：是菩萨者不可思议，恒以大慈拔众生苦。若有众生持是经法、持是菩萨名，即不堕于恶趣，一切障难皆悉除灭。若有众生持此经者，无余杂念，专念是经如法修习。尔时菩萨常作化身而为说法，拥护是人终不暂舍，令是人等速得阿耨多罗三藐三菩提。汝等菩萨若化众生，皆令修习如是大乘决定了义。

偈云，不舍本愿。而菩萨之愿云，众生度尽，方证菩提，地狱未空，终不成佛。以其誓愿不可思议，慈悲不可思议，拔众生苦，而众生不可不知报恩也。若欲报恩者，无他，若持此经，若持菩萨名，非惟知恩报本，抑且广获自利，不堕恶道，灭障除罪也。此经者有二，一谓持文字三昧，以大乘有不思议熏变，获利如上说。二谓实相自心，念念现前，昭昭不昧，获益如上。法尔如然，非是强言。故当修习菩萨化身说法，终不暂舍，令至菩提者，结赞恒以大慈拔苦也。汝等现前菩萨，有二种缘，一者当学地藏菩萨大慈普护，二者常教众生修习如是经典。

尔时，阿难从座而起，前白佛言：如来所说大乘福聚决定断结，无生觉利不可思议，如是之法名为何经？受持是经得几所福？愿佛慈悲为我宣说。

经分三分，序分正宗已竟，此当流通分也。大乘福聚，以经不可思议，其福德果报，亦不可思议也。决定断结者，转凡成圣也。以一切众生，为无明所封，眼与色结，耳与声结等，于生死中，不成解脱。今闻此经一乘实相，了证法法无生，即是本觉妙明之自性也。然虽本觉如是，为无明封执，不舍定执，三大阿僧祇劫，修行乃证。而此经者，如来才一敷扬，当念现前，不因修得，是谓不可思议也。如是顿妙之法，名为何等？而受持者，得何功德？

佛言：善男子！是经名者，不可思议，过去诸佛之所护念，能入如来一切智海。若有众生持是经者，则于一切经中无所希求。是经典法，总持众法，摄诸经要。是诸经法，法之系宗。是经名者，名摄大乘经，又名金刚三昧，又名无量义宗。若有人受持是经典者，即名受持百千诸佛。如是功德，譬如虚空，无有边际，不可思议。我所嘱累，唯是经典。

述成阿难所赞，实不可思议也。非三乘所有，乃诸佛护念故也。三乘中所有经典，依而修行，仅获自分之果，或得声闻果者，或得缘觉果等。而此经一闻受持，即能入如来智海，宁非不可思议也。此经乃自心三昧之力，诸佛出世，无非指明人人自心见性成佛，以为本怀。故诸经所指，无出于此。故受持是自性真经，则余经无所希求也。心为总持之大本，心为万法之洪源。心为所诠，经为能诠。能所合目，故此为总持之本，诸经之要也。摄大乘是能诠，无量义是所诠。若能若所，皆以金刚三昧之力，断诸事理等障，故是诸经所系之宗也。是经乃诸佛之本怀，故受持一经，即受持百千诸佛之名，功德正等。此犹略喻，若广喻之，若虚空之叵思议也。

阿难言：云何心行？云何人者，受持是经？佛言：善男子！受持是经者，是人心无得失，常修梵行；若於戏论，常乐静心；入于聚落，心常在定；若处居家，不着三有。是人现世有五种福：一者、众所尊敬；二者、身不横夭；三者、辨答衺论；四者、乐度众生；五者、能入圣道。如是人者，受持是经。

心无得失者，六祖云：不思善，不思恶，只恁么去，自然心入无生，湛然常寂。又楞严云：心言直故，于其中间，永无诸委曲相。此论其安心，则自然达体，证法身佛，是受持义。常修行者，于六度万行，备体而行，自成妙用，证报身佛。故楞严云：理须顿悟，乘悟并消，事假渐除，因次第尽。乐静入于聚落，即静而动，以修真谛。居家而不着三有者，即俗而真，以修俗谛，释成修梵行义。不言中道者，文略尔。能如是三观圆修，广举有无量功德，略举则权标五种。迷心则随物所转，心悟则物随我转，故为众所尊。不了自心，妄执世寿。能悟自心，则知尘劫不灭，何天横之有？不了自心，则心外求法，所有言论，皆名局执。若了自心，则心外无法，通达无碍，辨拆邪论。自心既明，则自然乐度众生。此上四种，前二自利，后二利他，具论因地。能入圣道，乃论果德。

阿难言：如彼人者，度诸众生得受供养不？佛言：如是人者，能为众生作大福田，常行大智，权实俱演。是四依僧，于诸供养乃至头、目、髓、脑亦皆得受，何况衣、食而不得受？善男子！如是人者，是汝知识、是汝桥梁，何况凡夫而不供养？

一切福田，众生本自有之，奈何为无明所覆，烦恼所缠？如衣下之明珠，如宅主之宝藏，迷不受用，故如贫子。是人持是经者，能示人之衣珠，指人宝藏，故是福田。有大智者，四依有二种：一者小乘，二者大乘。小乘四依者：一能终身乞食，二能终身冢间树下宿，三能终身集粪扫衣，四能有病服腐败药。大乘四者：依法不依人，依义不依语，依了义经不依不了义经，依智不依识。小乘全在自利，大乘多分利他。以能利他故，头目髓脑尚应得受，如阿难位入圣流，尚应恭敬，何况凡夫？

阿难言：于彼人所受持是经，供养是人得几所福？佛言：若复有人持以满城金银而以布施，不如于是人所受持是经一四句偈不可思议。善男子！令诸众生持是经者，心常在定不失本心，若失本心即当忏悔，忏悔之法是为清凉。

广喻则河沙七宝不以为胜，恐人惊骇，权以满城金银布施，不若从受四句功德，全部则不可思议也。何以如此？以此纯载自心，得自心智宝世宝，勿喻持心，则心不失定，所有诸业烦恼，应念清凉。

阿难言：忏悔先罪不入于过去也。佛言：如是，犹如暗室若遇明灯，暗即灭矣。善男子！无说悔先所有诸罪而以为说入于过去。

罪福无性，亦无方所，在迷则如处大梦，处悟则黑暗顿消，谁论三世？

阿难言：云何名为忏悔？佛言：依此经教入真实观，一入观时诸罪悉灭，离诸恶趣当生净土，速成阿耨多罗三藐三菩提。

忏则忏其前愆，悔则悔其后过。前愆既灭，后过不起，中间安然，便名净土。阿难恐人不解，重复发明。佛谓菩提自性，如镜光明，尘垢所埋，有而不现。垢尽明现，不从外来。一入观时，非特灭罪而已。无上菩提，当念具足。

佛说是经已，尔时阿难及诸菩萨四部之众，皆大欢喜，心得决定，顶礼佛足，欢喜奉行。

## No. 651-B
金刚三昧经注解䟦

知者以心了言，不知者以言了心。以言了心，不能亡言；以心了言，不惟亡言，亦且亡心。不至亡言，不名了言；不至亡心，不名了心。又亡言之至，方得亡心；亡心之至，方名入道。大道岂可以心思言议，于是乎有言哉？又岂可以离心思言议，于是乎无言哉？金刚三昧经，直截上乘，开示了义，更得云门湛然师出手眼，一番拈弄，其旨愈明。师传曹洞正宗，诠释文字，乃其绪余耳。曹洞宗有宝镜三昧，即金刚三昧之异名。本色草料，家常茶饭，师烂嚼知味，自味味人，当机者少。有瞻赜顾居士，信根坚固，慧解清圆，其知味者也，为师刊刻流通。断言禅伯命一言为殿言，如此或亦得师之心乎？

华山明河识
