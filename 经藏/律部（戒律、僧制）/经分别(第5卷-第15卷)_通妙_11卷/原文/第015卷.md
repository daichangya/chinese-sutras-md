# 經分別(第5卷-第15卷) · 第十五卷

> 通妙譯

---

歸命彼世尊應供等正覺 /

當言善愛語切勿語不善 /
為言愛語者牛即曳重載 /
彼亦得財寶由此皆歡喜 /

妄語．罵．離間句．宿之二種 /
除有智者外實有．粗罪．掘 /

草木與異語譏嫌並出時 /
彼之二戒者先來及拖出 /
脫腳牀坐臥門窗有蟲水 /

心高無放逸智慧學聖人 /
常念心寂靜苦惱不復存 /

不選任．日沒尼處．利與衣 /
縫衣及公路船．取食．獨十 /

施食．別眾．數餅．足食有二 /
非時．蓄藏．乳楊枝此十事 /

餅．語．跋難陀等三以及個別特信家 /
摩訶男與波斯匿軍．射此等以為十 /

飲酒與指．水輕侮．恐怖．火 /
沐浴及壞色不還與．藏之 /

故意殺．蟲及發諍覆藏粗罪．未二十 /
賊隊．豫約．阿利吒被舉．騫荼十學處 /

如法．誹謗與無知打．舉手以及無根 /
故意．屏聽與不平同意．沓婆並轉施 /

王．寶物．同住針筒與臥牀 /
綿．坐具．疥瘡雨衣及佛衣 /

不知聖典義此教咒文者 /
不法學習者俱是不見法 /

我為嗜好肉味香來食王之美味飯 /
為食不說我之法〔但知我〕法聖者讚 /

如此可恥婆羅門為彼之財與名利 /
〔於是現世〕不法行此為〔來世〕墮獄因 /
離去矣大婆羅門他有情亦以煮食 /
汝之行此不法行〔汝〕勿碎如碎石瓶 /

歸命彼世尊應供等正覺 /

所得應滿足過欲實為惡 /
以捉白鳥王汝等黃金失 /

## （二）

諸大姊！今誦出此七滅諍法。

每諍論生起為止靜而滅除之——

諸大姊！七滅諍法已誦竟。於此，我今……知解。

諸大姊！已誦出因緣、已誦出八波羅夷法、已誦出十七僧殘法、已誦出三十捨墮法、已誦出百六十六波逸提法、已誦出八提舍尼法、已誦出眾學法、已誦出七滅諍法。凡是已收入佛之戒經，正確含攝於戒經者，盡於每半月誦出，由此一切和合、歡喜、無諍而修學之。

應與現前毘尼、

應與憶念毘尼、

應與不癡毘尼、

應作自言治、

多人語、

覓罪相、

如草覆地。

———比丘尼分別終———

———兩分別終———
