# 发菩提心戒 · 第一卷

> 石经寺主讲经律沙门志仙记

---

## 1

夫菩提心戒者为修六度万行之泉源是证三身佛果菩提之根本功最甚深理难思议是以三世诸佛同说三世菩萨同学故经云戒如明日月亦如璎珞珠微尘菩萨众由是成正觉。

念三宝六师佛菩萨念梵释四王金刚天

将释戒文分为八段第一奉请贤圣第二想陈妙供第三忏悔罪第四受三归依戒第五翻邪归正第六正受菩提心戒第七遣相第八普皆回向八段不同。𠍴

且初第一奉请贤圣

人各整衣跪合掌闻举弟子某甲等处随言后说䠒

三说念无尽三宝愿降临

第二想陈妙供

三说念供养无尽诸三宝

第三忏悔罪𠍴

念普贤菩萨忏悔师

第四受三归依戒

三说念誓受如来三归依戒

第五翻邪归正

念归命无尽佛法僧

第六正受菩提心戒

三说念戒清凉菩萨摩诃萨

第七遣相

三说念远离一切诸性相

第八普皆回向

三说念皆共速成无上觉

始从此座一刹那间生在佛家终至后身三僧祇内得名佛子此心若在万德咸归此心若失万德皆丧是故应当善好护持。

上来普为四众发菩提心已竟齐念摩诃般若。

弟子某甲等稽首皈命礼遍虚空法界 /
十方诸如来瑜伽揔持教诸大菩萨众 /
及礼菩提心能满福智聚令得无上觉 /
是故志心礼

弟子某甲等十方一切刹所有诸供养 /
花鬘涂香等饮食幢幡盖诚心普奉献 /
诸佛诸法藏诸大菩萨众及诸贤圣等 /
我今志心礼

弟子某甲等从无始来轮回生死 /
乃至今日所造众罪无量无边 /
不自觉知自作教他见作随喜 /
我今忏悔不复更造唯愿诸佛 /
慈悲摄受令我罪障速得消灭 /

弟子某甲等稽首投诚菩提道场 /
归依如来无上三身归依方广 /
大乘法藏归依僧伽诸菩萨众 /

弟子某甲等归依佛竟归依法竟 /
归依僧竟従今已往乃至成佛 /
更不归依二乘外道惟愿诸佛 /
慈悲摄受

弟子某甲等
仰启尽十方无量无边界一切佛菩萨 /
従今日已往乃至成正觉誓发菩提心 /

有情无边誓愿度福智无边誓愿集 /
佛法无边誓愿学如来无边誓愿侍 /
无上菩提誓愿成

弟子某甲等今所发觉心 /
远离诸性相蕴处及界等能取所取执 /
诸法悉无我平等如虚空自心本不生 /
空性圆寂故如诸佛菩萨发大菩提心 /
我亦如是发是故志心礼 /

愿以此功德普及于一切 /
我等与众生皆共成佛道 /

石经寺主讲经律沙门乹统八年十月十五日记志仙
