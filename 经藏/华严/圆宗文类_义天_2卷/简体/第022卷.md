# 圆宗文类 · 第二十二卷

> 高丽 义天集

---

天上天下，金僊世尊。一心十号，四智三身。 /
度脱五阴，超逾六尘。生灵归敬，所谓能仁。 /

万法惟心，心须至净。由彼一念，能生万行。 /
背觉为妄，悟真则圣。稽首法门，昭然佛性。 /

六度无懈，四恩匪常。为人眼目，助佛津梁。 /
体润一雨，心薰众香。道无不在，此土他方。 /

稽首于十方，一切诸三宝，我今赞此经。 /
众生悟圆通。

方广大圆宗，主时成就道，四严别显处。 /
十身坐其中，同异众云集，称扬无有穷。 /
内流海慧等，共赞佛之功，六种皆震动。 /
征祥天地充。一切世界海，遍满尽虚空。 /

如来能现相，所现相齐圆，念言众诸问， /
佛地等何焉？四十齿光昭，云奔至有缘。 /
现瑞表说法，会中主普贤，莲华怱尔出。 /
流为诸教源，称扬力靡极。无穷尽四天。 /

普贤三昧如来藏，十方诸佛悉加持， /
刹尘皆入起亦尔，菩萨十益在此时。 /
一切微动庄严界，妙音演法雨摩尼， /
毛光赞已新旧请，欲观深理次品知。 /

世界十缘起立已，种种依外形各差别。 /
内体亦多为，一切庄严具，极净行所持。 /
尘数佛现异，劫住修短期，感人能转变。 /
包容尽现知。

华藏世界体，毗卢往昔因。菩萨清净行， /
咸能持风轮，安布建立土，刹网说微尘。 /
中有妙华光，层层上下分，诸刹皆傍遶。 /
十海各右巡，行布百十一，圆融难具陈。 /

毗卢二遍照，昔说是威光，净光胜音界， /
山出海中央，山上林东邑。林间有道场。 /
前后遇四佛，胜云照十方。王等礼足已， /
各各颂称扬。见二得三昧，嗣位转轮王。 /
后说大方便，佛号华眼幢。 /

体德为名号，序分初方同，菩萨念请问。 /
佛答现神通。复次文殊说，四十法门宗。 /
久成三世主，示现在因中。娑婆百亿界， /
佛号数无穷，种种何差别？盖是宿成功。 /

娑婆四圣谛，具无量果因，苦者名逼迫， /
集能坏善□，灭则云寂静，道乃一乘门。 /
各有无边号，随心调众人，密则等异界。 /
立名如微尘，圆融为主伴，一一具难陈。 /

身照事法界，智照二宗源。世尊足轮下。 /
四义信为前，光明放百亿，刹土际无边， /
二十有六节，十重就略诠，初重现本界， /
乃至究竟天，赞述超情理，菩提因果玄。 /
偈称八相等，体性业行全，威德法性后， /
因果遍周圆。

菩萨问明者，法问十甚深，文殊难九首。 /
共配十信心，一性何差别事在性中住？ /
众生何调伏？随缘佛化临，苦乐无美恶。 /
迷妄业报因。一法说诸法，随根现多门。 /
福田等无异，由器差别分，即悉不断或。 /
勤惰在于人，持法起诸惑，服药不服同。 /
有慧何用五？如王臣助风，世尊唯一道。 /
随情感是功。九首问佛境，般若量虚空。 /
神力皆明现，十方如是中。 /

净行知首问：三业等百余，汝今利乐众， /
赞者是文殊，云何获胜妙？说因愿有诸， /
一百四十一，得已动必无。 /

文殊问信德，贤首略言宣，我今随力说。 /
海水一滴焉。发心求正觉，三宝本为缘。 /
道元功德母。涅槃自初贤。持戒修学处。 /
则能福慧全。三昧门有十，大用具融诠。 /
龙等二十喻，菩萨万行圆，诵持比品者。 /
其福胜于前，十方皆震动，恶道息无边。 /

忉利天宫会，十住法慧弘，本处皆齐现。 /
不离一切升。帝释瞻佛至，座置普光明， /
请已入妙胜，止息诸乐声，善根即忆念， /
三世尽赞称。既坐殿广愽，十方悉亦应。 /

须弥顶上帝释宫，十方菩萨来斯国， /
世尊两足指光明，普照一切在神力， /
东方法慧总称扬，余九别赞佛功德。 /
演说十住行所依，成位不退行无极。 /

慧住于湛然，得位无有退。菩萨承威神， /
入方便三昧。界外刹尘佛，三业悉加诲， /
起定获胜力，住处等虚空，十千信行满。 /
观佛十缘宗，治地心悲智，积正行无穷。 /
佛法家生贵，理事善巧通，正修念岂动？ /
不退止观融，童住菩提故，王子当绍隆。 /
灌顶最为上，成就位满中，显证现祥瑞。 /
偈说义重重。

行体有三种，戒四等慧诠。正念白菩萨： /
答：十梵行源，观身等非相，皆悉归湛然。 /
不生于二解，佛法疾现前。 /

发心功德者，三世佛智开，天王问法慧， /
答：即甚难该承力，为汝说后喻胜前来。 /
发已能知际，摄胜德五圆，六种皆震动。 /
他方证亦然。偈中复显义，菩提心最玄。 /

法慧明照了，所照能所诠，精进欲请说。 /
赞毕听许然，问云修习等。答即行体全。 /
从行成因德，因成果德圆，十颂义再显。 /
应后故重宣。尔时说此意，欢喜奉行焉。 /

夜摩宫中会，十行德林诠，不离菩提树。 /
齐升于彼天。天王见佛已，殿座各严全， /
体备等有四，功德法无边，请毕如来受。 /
忆念昔因缘，说偈赞十佛，一切界同宣。 /
入殿跏趺坐，宽容乃忽然。 /

微尘世界集于会，十林菩萨来十方， /
足趺放光百千亿，一切如是悉称扬。 /

顺理造修行，三昧入思惟。微尘世界外， /
诸佛悉加持，功德林定起，说法不可思。 /
欢喜等列十，现证尽同词，重颂如前意。 /
十地颇相梯。

十无尽藏品，三世佛说同，征名列总数。 /
自他所利通，心净号为信，依圆遍计融。 /
制止戒成就，饶益无有穷，惭能崇重善， /
远离三毒攻，轻拒暴恶愧，来于五欲中。 /
闻则教广愽，明有置记空，辍已，惠人施。 /
内分差别之，决择诸法慧，于色如实知。 /
令心明为念，菩萨舍离痴，文义无忘失。 /
所记在任持，巧宣知实相，诸佛典岂违？ /
总叹胜能者，愿向究竟期。 /

化主应根愿，升于兜率天，树下皆齐现。 /
不离亦如前，殿座成妙宝，兴供种种焉。 /
观佛殊胜德，初后两义诠，受请乃居殿。 /
王获益善圆，歌乐咸炽盛，承力赞无边。 /
如来就座已，一切悉亦然。 /

众集兜率刹尘数，来从妙宝尽十方， /
佛膝放光能普照，首称偈赞金刚幢。 /

回向于三处，入起定前同，诸佛悉加被。 /
具说十种宗，救护众生等，随离相圆融。 /
不坏三宝信，用十境无穷，等于一切佛。 /
知法如虚空，至处谓大愿，善根遍处时， /
无尽功德藏，由缘无尽之，随顺坚固者。 /
咸依心法持，等顺一切众，积聚善根宜。 /
如相谓善合，远离于诸迷，无缚着解脱。 /
六十一门知，等法界无量，师位起大悲。 /
动地生信行，周遍世界天，十方菩萨众， /
同号至会前，偈颂劝修习。善住名普贤， /
校量此功德，莫测际无边。群生等知数， /
佛子行难宣。

凡圣隔绝故，超居他化天，序分明四胜。 /
入于智慧禅。如持已定起，普告三义诠， /
十地标名竟。金刚藏默然，三家伸五请。 /
法门甚深玄，欢喜获圣性，能益二空全。 /
离垢咸具净，懈愧是根源。发光成就定， /
总持法无边，慧住最胜，成菩提分圆。 / 𦦨
难胜得双运，行相令互违。现前缘起智， /
难察平等持，远行至无相，出世道慈悲。 /
不动无分别，深行难可知，善慧无碍解， /
广说义难思。法云谓大智，含众蔽如空， /
影像总明喻，四河入海充，职位在佛数。 /
利益十方通，无善不可得。偈颂结重重。 /

重会普光殿，境性为定焉。在于摩竭国， /
始成正觉圆。普眼从座起，合掌白佛前： /
欲问分四义，将答𠡠普贤，说十大三昧。 /
称法界无边。

普贤告诸菩萨众，具说他心等十通， /
住于如是不思议，三世无碍智皆同。 /

普贤告诸菩萨言：十种忍法得无碍， /
已今当说三世尊，总结颂意前文内。 /

阿僧祗品者，十大数标。通心王白佛问： /
赞许说渊宗。恭敬受尊命，明显数重重。 /
德德极无尽，深广普贤穷。 /

如来之寿量，众生见不同。心王告众会： /
别举刹十重，初说娑婆等，世界不能穷， /
玄极最后处，普贤满其中。 /

菩萨随根具悲智，住非一处名皆异， /
八方山海仙人等，城邑杂居十有二。 /

如来果法超言虑，众会菩萨作念焉。 /
佛国土等不思议，世尊加被三业全， /
青莲华藏德无畏，则能通达法界圆。 /
承力总告为宣说，正显十门次第全。 /

如来十身标显德，普贤诫听尽宣畅， /
一一难思互相融，有莲华藏微尘相。 /

逐相葢姿好。佛告宝首宣，我音为菩萨。 /
放光兜率天，常有四十种，中说清净焉。 /
能照微尘界，闻益义难诠。 /

普贤行品内，所说平等因。复告诸菩萨： /
但随众生根，略演如来境。为诸无智人， /
若起瞋心者，成百万障门。勤修法六十。 /
持则少作功，明现其瑞证，诸佛悉结通。 /
十方菩萨众，一切世界中，颂显诫听许。 /
悲智互相融。

有法三身十身通，果用化用总名焉。 /
放大光明加二主，性起妙德问普贤。 /
长行颂言皆悉请，如来不思现无边， /
十门尽答平等果，内更有多具难宣。 /
喻说种种无有喻，显名受持秘密圆。 /
地六震动众供养，十方证成亦然。 / 𫁉
一切世界咸如是，偈文重重意在前。 /

八会法堂内，说离世绝通，行位显无碍。 /
前后相圆融。佛在摩竭等，人定庄严中， /
咸动声皆听，三昧起亦同。菩萨知众集， /
发问六位宗，普贤从信答，二百门尽穷。 /
结劝共宣说，现瑞一切充，人法皆证成。 /
颂中意亦重。

说入法界会，悟证能所通，在于逝多内。 /
念请众心同，佛入频申定，集已广赞功。 /
举失显其德，表是小乘宗。菩萨承神力， /
称扬偈颂中，普贤遍开发，十种法句穷。 /
白毫光照益，一切尽虚空。文殊述神变， /
十方悉满充，无涯光大用，利益众皆蒙。 /
前后分本末。本会此云终。渐顿互交映。 /
人法各相融。文殊寄十信，善财积集全。 /
德云等寄住，佛境智慧渊，善见等寄行， /
随顺解脱焉。鬻香等寄向，调香法具宣。 /
婆珊等寄地，尽破痴随眠。摩耶至慈氏， /
会摄差别缘。妙德与遍吉，因果悉周圆。 /
见开此经者，获福最深玄，如熏金刚种。 /
不坏力弥坚，所作赞功德，回向尽无边。 /

庄严楼阁建幡幢，师子频申坐道场。 /
诸大声闻犹未寤，眉间放出白毫光。 /

娑罗林里象王回，古昔如来塔庙开。 /
百一十城游已徧，云何重去涉尘埃。 /

四维上下徧寻求，胜国谁为大比丘？ /
七日妙峰无所见，经行都在别山头。 /

大海广愽不可尽，佛功德海极渊深。 /
十有二年观境界，宝莲华座出波心。 /

隐显经行不滞留，空中鸟迹更何求。 /
众生佛界元如是，岂独楞伽一比丘。 /

大师子座振威风，升降庄严市肆中， /
轮字法门谁与辨，十方世界语音同。 /

十方世界微尘刹，各有如来坐道场， /
彼佛不来吾不往，明明影像水中央。 /

海幢舍得施门开，普眼光明示善财， /
刹刹尘尘诸变化，便无一法外边来。 /

心如大海全容受，志若须弥不动摇。 /
坐普庄严金宝座，众生病恼见能销。 /

十方十刹微尘数，诸佛庄严诸国土， /
执手分形徧往时，童子未甞离本处。 /

逆顺由来是强名，刀山火聚任峥嵘。 /
善财底事生疑悔，赖有诸天为证明。 /

柱壁金铃宝鉴中，摩尼璎珞互含融。 /
汝应观我诸宫殿，法界重重一一同。 /

比丘善见住三目，言我此生方出家， /
于一念中兴供养，如来三十八河沙。 /

我于往昔见师利，□悟入巧神通智， /
十千童子围遶时，河渚聚沙自为戏。 /

素衣垂发无缨络，我宅资生物物空。 /
一器置前谁谓小，大千诸欲悉能充。 /

无量国土诸众生，种种所须不同欲， /
自从明智视虚空，一切有求皆满足。 /

食衣宝女诸菩萨，最上层中现世尊。 /
长者善财初执手，八方无不大开门。 /

疗治众生普十方，藤根国里大医王， /
善知和合诸香法，一一香中无量香。 /

无厌足王大方便，能令众生断邪见， /
刀截汤煑猛火焚，当知一切法如幻。 /

随顺世间三昧法，慈幢高建发明光。 /
大千沙界人天类，台殿云雷悉向王。 /

安住王都金色光，遇光身意自清凉。 /
我求此法无厌足，过去如来出妙香。 /

九十六种各异见，我悉调伏有方便。 /
普令舍离执着心，山顶日光中夜徧。 /

调和善别一切香，成就清净安隐乐。 /
天上人间香不同，谁能平等无诸着？ /

大士能游生死海，宝洲珍宝施群生， /
安危随顺都明了，止处不留行则行。 /

百千围遶庄严幢，无忧林中无上胜。 /
无依无作大神通，成就一切菩萨行。 /

输那国土比丘尼，徧坐林中宝座时， /
何事善财心右遶，百千周匝木相随？ /

频申瞬目妙声音，触处能除贪欲心。 /
险难国中人不识，庄严宝地布黄金。 /

三世如来不涅槃，栴檀座上白毫端。 /
众生及我元无二，开塔应须次第观。 /

观音常在如来所，普现众生一切前， /
补怛洛迦山险绝，宝林香草间流泉。 /

正趣东方妙藏来，疾行解脱普门开。 /
四维上下俱周徧，步步光明示善财。 /

四手长舒挹海时，面以洗濯震威仪。 /
有谁得遇芥陀利，散掷金花多少枝。 /

光明徧地震同时，宝藏庄严处处随。 /
从往昔来常受用，云何神足按方知。 /

城入东门日已沉，空中身现色真金。 /
光明能破诸痴暗，一一令生解脱心。 /

空闲止息恶音声，游戏神通变化成。 /
开示出家门正路，死生长夜度众生。 /

坐宝莲华侍世尊，百千毛孔现身云。 /
妙音随应明明说，普喜幢标解脱门。 /

普救众生妙德神，大光从两臂间伸。 /
善财入顶身充满，三昧智灯清净轮。 /

念念出生广大喜，庄严解脱光明海。 /
普人无边法界门，摩尼幢座莲华里。 /

无明昏寐警众生，守护如来一切城。 /
为大法师无碍，普贤行愿自圆成。󳬩 /

娑婆世界日光没，清净池莲覆合华， /
若水若山若城野，罢游观处得还家。 /

摩尼宝网覆虚空，日月星辰影像中。 /
一切法门平等入，微尘佛刹本来同。 /

楼阁庄严接善财，诸天围遶化门开， /
毗卢海藏吾亲入，曾见世尊兜率来。 /

智光圆满照因陀，劫海无涯展转多。 /
生死本来无过患，谁能重去问瞿波。 /

住诸世间无所住，我身非一非多处， /
宝阁莲华纳十方，三千大千菩萨母。 /

佛出母胎师子吼，至成正觉伏魔军。 /
我皆明忆先遗忘，清净庄严解脱门。 /

菩萨云何修与学，人间天上徧咨询？ /
毗罗城里真知识，非不开陈解脱门。 /

童子善能知众艺，于诸菩萨学字智， /
昌持如是字母时，般若波罗不思议。 /

解脱无依处道场，利人接物为宣扬。 /
六根三昧何穷尽，功德波涛智慧光。 /

勤求正法无休息，徧事如来尽信诚。 /
清净庄严坚固力，皆从无着念中生。 /

善财未离沃田城，妙月欣闻长者名。 /
解智光明安可见？宅中唯有大光明。 /

出生城里无胜军，解脱了知无尽相。 /
如诸菩萨大辨才，普见世尊无尽藏。 /

我以住于诚愿语，未曾虚妄示众生， /
无边无量诸功德，随意施为莫不成。 /

德生童子有德女，了悟世间皆幻住， /
菩萨施为本亦然，孰为生死忧悲苦？ /

楼前弹指众门开，一一门中一善财。 /
现已却从来处去，去无有处本无来。 /

尔时摩顶手长舒，百十由旬指坦涂， /
既置善财如所住，普门何处见文殊？ /

毗卢海藏泯纤尘，香象无踪孰可亲。 /
不起大心开普眼，安知身在普贤身。 /

执象或亡象，取空空外求，斯人皷识浪。 /
浩劫只冥搜。即象见无象，万象归毛头。 /
圆机覩一叶，法界知春秋。 /

## 毗卢遮那佛华藏世界图赞

佛说华严经，真人妙觉不由诸乘，非大圆智不能信解。

德宗朝有龙象观公，能于是经了第一义，居上都云花寺，名闻十方。妙门嗣肇，是其上足，以经中九会，纂成华藏，俾人瞻礼，即色生敬。因请余赞之，即说赞曰：

清净不染华中莲，捧持世界百亿千， /
踊出香海浩无边，风轮负之尽夜旋。 /
大雄九会化诸天，释梵八部来森然。 /
从昏至觉不依缘，初初极极性自圆。 /
写之绡素色相全，是色非色言非言。 /

宿植明因，专求正真。庵园悔迹，莲界分身。 /
阐扬释教，拯济迷津。流一雨常，恒净六尘。 /

辩圃方开，言泉广濬。护持忍辱，勤修精进。 /
讲集天华，征符地震。运斯法力，殄兹魔陈。 /

爰标十观，用契四禅。普断烦恼，遐祛盖缠。 /
心源鉴彻，法镜澄悬。慧筏周运，慈灯永传。 /

名简紫宸，声流绀城。梵众纲纪，僧徒楷则。 /
镇洽四生，曾无懈息。播美三千，传芳百亿。 /

朕观法界，旷閴无垠。应缘成事，允用虚根。 /
清凉国师，体象玄门。奄有法器，我祖聿尊。 /
教融海岳，恩廓乾坤。首新二疏，拔擢幽昏。 /
间气斯来，拱承佛日。四海光凝，九州庆溢。 /
敝金僊门，夺古贤席。大手名曹，横经请益。 /
仍师巨休，保余遐历。爰抒颛毫，式扬茂实。 /
真空罔尽，机就而驾。白月虚秋，清风适夏。 /
妙有不迁，缘息云化。邈尔禹仪，焕乎精舍。 /

走者之麟，飞者之凤。犹我人杰，法门梁栋。 /
雷吼一音，石排四众。六相能演，十玄斯综。 /
后素图真，腾光化身。叶文耀掌，莲界栖神。 /
镜挂尘表，灯传海濵。东林佛影，永契良缘。 /

## 海东华严始祖浮石尊者赞并序

公讳义想，新罗人也。其遗芳余美，动满大宋史传，三韩谚记。予公隙乘闲，披玩图籍，历代高僧，皆有赞颂。惜哉浮石一圣，未有人赞之。唯新罗翰林学士崔公致远，有灵游画像赞十六句。然此以举佛山石体，寺僧能现梦中之事述之，似未尽浮石之余美。揽笔为文，輙赞其德曰：

海印三昧，舍那独尊。称法界性，开一乘门。 /
大云覆世，甘露涤烦。付嘱祖祖，宣布言言。 /
鸡贵义持，鸿才杰出，多能不群，九圣之一。 /
求无上师，入终南室。学了师亡，往虚归实。 /
善妙有色，爱恋求欢。见心匪石，反誓行檀。 /
金鳞负舰，利涉海澜；巨石浮空，盖护寺山。 /
十山游讲，磨肩争集，众石倾听，点头如答。 /
西芥东针，六师同叶。前灯后灯，十圣传法。 /
手撰文义，呪投火烟。二百余字，烬余有全。 /
字字投水，行行编贝。三十余句，屈曲成偈。 /
总华严义，为法界图。焕然标的，粲若玑珠。 /
寸纹知锦，一毛知凤。略掇清芬，輙成赞颂。 /

真法性本净。妄念何由起。许妄从真生。 /
此妄安可止？无初则无末，有终应有始。 /
无始而有终，长怀懵斯理，愿为开秘密。 /
祈之出生死。

真法本非真。妄复何曾起。妄不从真生。 /
无妄何所止？既许无初末，宁容责终始？ /
无始复无终。谁当懵兹理。胡不趣无生。 /
乃云祈生死。

迷真妄念生，悟真妄即止。能迷非所迷， /
若得全相似，从来未曾悟，故说妄无始。 /
知妄本自真，方是恒常理。分别心未亡， /
何由出生死？

法性非垢净。真妄非如理。去妄复存真。 /
兹妄安所止。无物本自无，强无无不已。 /
有始见有终，见始非无始，诸法自无性。 /
无性无生死。

真妄本假名。悟妄妄不起，心源性恒常。 /
恒性非终始，圣凡旨自玄。玄性玄不已， /
法界圆净身。元来复无旨。佛国无一物。 /
孰懵生死理。

真妄体常如，无灭亦无起，触目性皆空。 /
毕竟无可止。如如本不还，岂复云终始。 /
若存终始见，常懵真如理，生死即涅槃。 /
何祈出生死。

## 终南山草堂寺沙门宗密申明礼法师意

夫欲答他之问，须善达自他之宗。西域论义诸师，皆以此为定轨。复礼法师是经论宗匠，则天时为译经道场中上首。设问因流于天下旨，率尔不究诸宗乎？况言问天下学士已栋，却不经师学，不谙教理者。大乘经教，统唯三宗：一法相宗，二破相宗，三法性宗。诸宗禅门精传受者，亦不出此三类，已备彰都序。圭峰兰若禅藏一百卷，有都序两卷。今问此是法性囓镞关节，不问二宗。二宗所说，无此违妨也。不问法相宗。法相宗者，所说一切有漏妄法，无漏净法，无始时来，各有种子在阿梨耶识中。遇缘薰习，即各从自种子生起，都不关真如。谁言从真如生妄也？彼说真如一向无为寂灭，无起无止，不可难他从真有妄生也。不问破相宗。破相宗者，彼一向说凡圣染净，一切皆空，本无所有。设见一法胜过涅槃，亦如梦幻。彼且不立真，何况于妄？故不难云从真有妄也。唯疑法性宗。法性宗者，以此宗经论。论言依真起妄，如云法身流转五道如来藏，善恶受苦乐等也。悟妄即真，如云初发心时，即成阿耨菩提。知妄本自真，见佛即清净菩萨。凡圣混融，如云一切众生，本来成等正觉，般涅槃。毗卢遮那身中，具足三界六道众生等也。真妄相即，证此之门尤多。虽说烦恼菩提无始无终，此文例无量。又说烦恼终尽，方名妙觉，亦名始觉。华严六七二会，及起信首末之文，义宗有碍，自语相违。又皆是了义一乘经中所说，欲拣之，不可取一舍一。本经中便具说，不可拣前取后，拣后取前。欲合之又难会，俱用之又相违，难可合为一。是故试问天下学士，有达者即知真入道。复礼非不达也，是试验之问，非求人也。今诸人所答，悉迷问意，皆约泯相归理所说，都缘不识他所问从真起妄之由，修证妄真之理。然迷真起妄，盖有因由。息妄归真，非无所以。既不晓了，不及缄词。今但自述无相无为之见，何申问目，复礼法师？岂不知真妄俱寂，理事皆如也。如寂之中，何有问答？然有二门义理，易说易解，言无违妨。一者一向说有妄可断，有真可证。二者一向说非真非妄，无圣无凡。此二门皆可思可议。其难说难解者，是二门俱存，又不违碍，此乃不可思议。故胜鬘说众生自性清净心，为无明烦恼所染，无染而染，染而不染，皆云难可了知。复礼今问此议答，何但说无垢染耶？唯华严疏主和尚所答，约真如不变，不碍随缘，方为的当。复礼释本问宗密所申诸贤问意，意在诸人通决。然若不自课虚引例，则何以劝人？遂试答云：

本净本不觉，由斯妄念起，知真妄即空。 /
知空妄即止，止处名有终，迷时号无始。 /
因缘如幻梦，何终复何始？此是生生源。 /
穷之出生死。

不是真生妄。妄迷真而起。知妄本自真。 /
知真妄即止，妄止似终末，悟来似初始。 /
迷悟性皆空，空性无终始。生死因迷此， /
达此出生死。

人心南北异，佛法古今同。不坏真明俗。 /
还因色辨空。探幽唯罔象，失旨并童蒙。 /
有着斯为诤，妄情自可通。 /

欲了真如性。须遣忘执情。有心生死路。 /
无念涅槃城。烦恼谁为主？菩提尚假名。 /
不存分别见，佛道自然成。 /

华严法界大道场，不动纤毫一时彰。 /
古今殊未为往来，延促何曾有短长。 /
主伴互参犹帝网，圣凡交彻类灯光。 /
毗卢本绝多般相，青即青兮黄即黄。 /

华严真境廓沙洲，一一尘毛法界収。 /
五位觉城休凑泊，百重何处更推求。 /
洞明主伴全真际，顿晓毗卢越超修。 /
休说南方曾未到，一轮明月印中秋。 /

须知诸相皆非相，若住无余却有余。 /
言下忌言一时了，梦中说梦两重虚。 /
空花岂得兼求菓，阳焰如何更覔鱼。 /
摄动是禅禅是动，不禅不动即如如。 /

无相几时离有相？有余何处碍无余？ /
忘言谓了非为了，说梦云虚是滞虚。 /
虽没空华空结菓，宁妨幻水幻生鱼。 /
不禅不动常禅动，禅动镕融方契如。 /

万德圆融一念心，念该九世已当今。 /
色空互异二无别，性相交通两不侵。 /
山岳匪高尘劫大，江湖非濬路还深。 /
我宗事事元如此，君欲寻时试略寻。 /

金刚轮据大莲华，帝网方元是我家。 /
何事却来三界内，背违刹海守尘沙。 /

万德圆融具足身，此身我体本同伦。 /
何因异此生迷滞，别认虚空一聚尘。 /

欲识真空理。真空空不空。溪山虽异路。 /
云月本来同。

理圆诸相尽，心廓境还如，昨夜家家月。 /
清光混太虚。

今现在前，谁后谁先。若凡若圣，无心无偏。 /
灵光遽泻，日用洞然。瞥尔放过，东震西乾。 /

法非文字道无言，佛祖家风本不传。 /
扣寂要令空作响，忘机须使火生莲。 /
华严妙旨符三观，方广幽宗会十玄。 /
珍重分证归海国，一乘光阐大因缘。 /

华藏尘尘见普贤，远寻雪窦更何缘。 /
途中若有人相问，莫道休经去学禅。 /

超过毗卢越释迦，这般都是鬪春蛙。 /
眼中何处堪藏屑，空里从来不着华。 /
学道岂知背长道，出家谁信未离家。 /
堪嗟拥毳深林下，一钵炊粳两椀茶。 /
学教参禅四出游，争名竞利几时休。 /
精灵但逐壶中月，身世宁知水面沤。 /
奔走尘埃空没虑，潜藏林野亦狂谋。 /
年来始认真归路，誓与弥陀作抵头。 /

群居修性若为修，切忌劳神向外求。 /
秖与么时犹蹉过，忽相应处尚迟留。 /
拈槌竖拂还成拙，讨疏寻经但逐流。 /
欲识筒中端的意，直须针芥两相投。 /

逢原自得在资深，须慕前修竞寸阴。 /
微雨飘零盈臣海，隙尘飞聚耸高岑。 /
红衢逐利空归死，白首穷经不了心。 /
好与方朋研此理，始知无古亦无今。 /

诸生不远务横经，直拟揩磨一点灵。 /
帘上未妨承夜月，囊空应更聚秋萤。 /
当存大士兼怀操，莫学凡流独自醒。 /
窓案孜孜忘寝食，他年谁是出蓝青。 /

## 贤首判论

问：华严一真法界，即起信一心源也。然心融万有，便成四种法界，故圭峰以溥该诸教，逈异诸教，唯就一心而谈圆矣。然则起信以一心为本源，贤首判之则曰：心于终而兼于顿，且不该乎圆矣。与其圭峰之辞，何其异也？今诸生心愤口悱，其来久矣，讵可默无言乎？

## 儒释言性

问：专习三藏，不见域内之文；偏学六经，岂知方外之教？然则周、孔罕言性命，而佛祖之训详矣。且皇唐李习之宗乎孟轲，谓人之性善；杜紫微法于荀子，谓人之性恶；皇甫湜稽诸扬雄，谓人之性善恶混。韩氏又曰：上焉者善，下焉者恶，中焉者混。圣宋缙绅，如欧阳永叔、章表民、王、陈而下，其说非一乎？义学穷子史，究六经，而诸贤之作，其孰与吾教合焉？

## 贤首国师寄海东书

唐西京崇福寺僧法藏，致书于海东新罗大华严法师：一从分别，二十余年。倾望之诚，岂离心首。加以烟云万里，海陆千里。限此一生，不复再面。抱恨怀恋，夫何可言。盖由宿世同因，今生同业。得于此报，俱沐大经。特蒙先师，授兹奥典。仰承上人归乡之后，开阐华严，宣扬法界无碍缘起。重重帝网，新新佛国。利益弘广，喜跃增深。是知如来灭后，光晖佛日。再转法轮，令法久住者，其惟法师矣。法藏进趣无成，周旋寡沉。仰念兹典，愧荷先师。随分受持，不能舍离。希凭此业，用结来因。但以和尚章疏，义丰文简。致令后人，多难趣入。是以具录和尚微言妙旨，勒成义记。谨因胜诠法师，抄写还乡，传之彼土。请上人详捡臧否，幸示箴诲。伏愿当当来世，舍身受身，同于卢舍那会，听受如此无尽妙法，修行如此无尽普贤愿行。傥余恶业，一朝颠坠。伏希上人，不遗宿昔。在诸趣中，示以正道。人信之次，时访存没。不具。法藏和南。侍者正月二十八日

华严探玄记二十卷两卷未成。一乘教分记三卷。玄义章等杂义一卷。别翻华严经中梵语一卷。起信疏两卷。十二门论疏一卷。新翻法界无差别论疏一卷。已上并因胜诠法师抄写将归。今月二十三日，新罗僧孝忠师遗金九分，云是上人所寄。虽不得书，顶荷无尽。今附西国君持澡罐一口，用表微诚，幸请捡。谨宣。

## 华严经社石记

有杭州龙兴寺僧南操，当长庆二年，请灵隐寺僧道峰讲大方广佛华严经，至华藏世界品，闻广愽严净事，操欢喜发愿，愿于白黑众中劝十万人，人转华严经一部，十万人又劝千人，人讽华严经一卷。每岁四季月，其众大聚会，于是摄之以社，斋之以斋，自二年夏至今年秋，凡十有余斋。每斋，操捧香胡跪，启于佛曰：愿我来世生华藏世界大香水海上宝莲金轮中毗卢遮那如来前，与十万人俱，斯足矣。又于众中募财，置良田十顷，岁取其利，永给斋用。予前牧杭州时，闻操发是愿，今牧苏州时，见操成是功。操自抗诣苏，凡三请于予曰：操八十一矣，朝夕迨尽，恐尽社与斋，来者不能继其志，乞为记诫，俾无废坠。予即十万人中一人也，宜乎志而赞之。噫！吾闻一毛之施，一饭之供，终不坏灭，况田千畒，斋四时，用不竭之征，备无穷之供乎？噫！吾闻一愿之力，一偈之功，终不坏灭，况十二部经常出于千人口乎？况十万部经常入于百千人耳乎？吾知操徒必果是愿，若经之句义，若经之功神，则存乎本传，若社人之姓名，若财施之名数，则列于别。斯石之文，但叙见愿、集来缘而已。󳬴

宝历二年九月二十五日，前苏州刺史白居易记。

## 大宋诸朝贤书大方广佛华严经序

大方广华严经者，盖穷微涉变，至大之迹也。其心泛照，非思虑所于；其迹无限，非象数所测。度有形之外，经恍惚之廷，浩渺难言而有以言，知其至而可以至者，大方广之义也。何则？夫至神无迹而存其意，万法无系而有其门，微言罕识而示其宗，大教非私而廓其慧。故能极导方来，济其慈救，去圣虽远，常若匪遥。而或者眩无迹便谓不可冀，味无系乃曰守其偏，惊罕识则必高其诚，疑非私靡不怠其入。夫道之大也，岂可以眩昧惊疑而论其趣舍哉？然万类至冥，其来已久，大雄誓振，恻再有开。是以如来开九会于奥区，阐兜沙之至论，爰集众圣，共谈斯道。此经所明，该万法则以门户为谕，用喜舍则以回向为先，悦归往则以严侈为容，亘杳莾则以广大为目，此大方广之本也。至若圣仙非一，神变迭兴，十地同归，趣成法界，大方广之迹也。自真籍东至，始于晋朝，非文无以见法，非译无以示众，秘语再飜，群心知悟，是以历世宝其书焉。大宋之兴，四圣丕承，法轮世转，守妙道于不言之教，范苍生于无名之德，俗仰大觉，而此书益兴，人能广道，是之谓也。至和二年，岁次鹑火，闽中沙门文用，诚心浚发，思建胜业，以为道俗虽分，心同则一，至理苟会，契合不差，将使贵胜同风，益坚外护。翰林学士天水公，夙悟真乘，领会宏趣，乃与共请公卿朝士等六十三人，共书此经一部，事业未半，用公化去。有钱塘沙门志广，赞成其志，历八稔乃终，藏之于东京兴国寺合。皇帝嘉乐群心，成兹法会，诏锡斋供，以侑其诚，中外欣，倾首愿慕。圣言久而更显，众辙践而有归，道固无亏，兹益尊矣。余以鄙薄，预闻始终，虽莫闻妙言，而窃覩成事，輙抒所知，为之记述，庶世之学者，有以审其端焉。

## 华严经赞序

夫华严者，廓诸佛之心境，莹万法之本际也。其为经，广大溥博，渊邃妙乎！以言其性，穷法界之无尽；以言其相，视尘刹之交彻；以言其理，包空色以皆真；以言其事，摄一多而同现。虽释天之宝网，海藏之灵珠，不足以喻其光辉照彻也。无来往之异，无古今之辨。无作之作，皷舞万类；无言之言，充徧群有。初心既悟，虽凡夫可入；积学未解，虽声闻莫覩。速证菩提，而为功不滞；兼济六合，而妙用难窥。此诚离权而就实，超渐而即顿也。盖降神出兴，为一大事；始成正觉，即演是经。至于小乘之戒，以善制恶；三乘之教，谈空破有。净名之擎佛刹，法华之变龙女，咸所以应机接引，随根示化尔，非华严之比也。予甞谓释典之有华严，犹六经之有大易。列卦以明时，立爻以通变，设众以尽意，而两仪之道，万物之情具矣。华严陈世以宅性，名佛以筌德，布位以表法，而一真之体，万行之果备矣。故学儒而不为易，学佛而不为华严，焉足以穷理尽性也？嗟夫！含识之类，自始迄今，为无明之所覆翳，堕瞋焰，触贪网，揭憍慢高幢，行谄诳稠林，入生死大苦海中，波涛飘泊，不求出离者，滔滔皆是也。万一志乐佛乘，回向清净，又多厌苦忻寂，趣求自了，生民，孰教孰矜？若知夫华严之城，以无明为智海，用本智为法身，伏请愿为胜缘，扩大慈为能事。众生未到波岸，我不独登正觉；众生未脱苦聚，我亦轮回世间。或化而天，或孕而人，或主世导俗，或人缠同行，亦又不心蠲饰，好就寥旷，遁山林，藉草石，然后为得也。是故虽通居五位，而还向文殊之妙智；虽总成十力，而勿舍普贤之至愿。圣神极致，安可思议哉？长文自婴祸酷，衘哀持诵，日用如流，祥禫甫迫，亲恩罔极，云何可报？经云：亦以无边偈，称述供养人中调御者。是称赞者，事佛求福之一端也。于是阅逝多长者论，探其指归，每品为之赞，并普贤行愿，凡四十篇。其卒章皆述荐亲之诚，庶几助我先君光禄证道超生之因也。噫！秋毫岂足量大空，勺水未能增巨海，诚之所发，不自知量乎？自缮写礼佛，以陈威神，详昭详鉴，丹悃谨序。󱳸󱳸

## 华严九会礼文序

世尊开大施门，雨称性法，摄群经而持出，融万德以同归。文殊智灯，偏刹尘而显现；普贤行海，随时处以圆成。七处本不异时，如帝网光交于众宝；一字莫非圆说，若海滴味摄于百川。二乘绝异于受持，六度犹迷于修习，苟非默契，孰可流通？华严法师诚公，行解轶伦，闻思入妙，深探秘奥，积有岁年，撮其枢机，制为偈赞。盖欲圆胜行于俄顷，会大经于数章，使赞呗交音，显彼十方之同说；诵持得旨，俨然九会之现前。可谓文约义丰，理圆事广，提法门之筦籥，奏净土之笙竿。凡获见闻，宜深庆喜，普愿大心之侣，顿严旷劫之因。谨序。

## 法界观门钞序

大雄氏既自觉矣，又觉一切众生与己无异，而众生未之觉耳。于是称法界性，说华严经，连章而累偈，极劝而直指，欲令众生一一自觉而皆已若也。后之人虽得其说，反谓其事悬远，多惶或迷闷，若孝公之闻王道，文侯之听雅乐，可悲也哉。唐初有杜顺师者，痛其若是，乃约华严经撰法界观，包总众义，列为三门，其文不过数纸，而备尽一经之意。后有圭峰师者，复因观文而为之注。今有从朗师者，又凭注文而为之钞。然则钞以释注，注以解观，观以括经，皆网举领会，言劈句，学之者庶乎识佛之心而复己之性乎。朗师专业华严逾二纪矣，传其法于四方者不可胜数，余力通圆觉、起信及诸部大乘经论。常以为去圣逾远，鬪诤坚固，非处晦致柔，以悲忍自立，何以焰智慧烛枯烦恼林乎。故虽知诸法本无染净，以方便故而持禁戒。虽知诸法本无动静，以方便故而习禅定。虽知诸法不在言说，以方便故而恒讲授。虽知诸法不在文字，以方便故而勤著述。大矣哉！古佛之言诠，诸祖之心要，焕乎炳焉，无所不至。识者览其钞，则知其人，察其道矣。或曰：观之设也，本束经之繁文，亦既注之而又钞之，得非抱薪救火乎？答曰：苟晓乎注，则钞可废矣；通乎观，则注可废矣；明乎经，则观可废矣；达乎心，则经可废矣。未晓若是，其可废乎？则钞之作也，义有在矣。呜戏！孔子修春秋，无丘明传之，无元凯注之，无颕达疏之，则褒贬隐而学者难为功矣。如来说华严，有杜顺观之，圭峰注之，朗师钞之，则圆顿显而学者易为力矣。夫如是，则彼三君子不得不谓之大儒矣，此三上人不得不谓之高僧矣。予逢掖之士，与朗师迹异。前年不第东归，且有天伦之戚，深惑福善祸淫之语，因取佛书孝之。适会朗师钞就，恳嘱为序，故斯。其经观之要，则有裴相休之注序在。予但嘉朗师之意，述制钞之由而已。㭊云云

时皇宋至道元年夏四月二十有六日序。

## 新注法界观序

佛无心外法，则天下之物无非心也。心体廓然是真法界，故周徧含容而无所殊，则物胡为而不然哉？此一尘所以具一法界，而大千经卷所以破尘而现也。夫惟众生，情沦于断常而不知心体之无寄，见著于一异而不知事相之无体，以故不得其门而入，而念念生灭，相续不断，乃至轮回异趣，往而不返，甚可哀也。唐有大菩萨曰社顺，深达是相而哀众生之迷也，故着为观法，栋去情解以显法体，镕融事理以会无二，使观物物莫非真空者，则交参摄入，自在无碍，此真入事严法界之门也。慧卿闻道十有余年矣，损之又损之，以求正念而未之契也。及得是观，如其说而修之，乃真知天下之物无非心者，而吾心相不可得也。故横心之所念而无能念可念，横口之所言而无能言可言，则吾安往而不知哉？呜呼，昔人有以杜顺为文殊师利菩萨者，真不虚也。若人者，是真世间之眼也。吾不敢以其说独善，輙以所证为之解释。有诚吾言而修之者，华藏之游，吾愿与之同之。温陵吕惠卿序。

## 法界观门钞序

原夫法界本离乎观照，故曰不可以智知；总持实无于文字，故曰不可以言宜。虽然，言不能宜，未体证者，如何获证？智不能如，未悟入者，如何得入？於戏！我大圣人，具妙方便，善于无名相中，假文字显，离识知境，资观照通。于是乎华严不得不经，法界不得不观。经观既设，时则有命世开士，详而注焉，集而解焉，不可阙也。且使义无滋蔓，辞不枝岐，斯为得矣。譬若浑仪在眸，则天地之数可准；葭伺管，则神化之用可期。法界观门，诚类于此。然斯文简要，旨趣幽深，非浅丈夫能跂及。廼有皇都大沙门，锡号净觉，名有朋者，甞慨众释繁略未驯，遂自操觚，搜抉精义，酌其折中，成一家言，号为集解，离为五卷，以辅翼观门，用资讲习。其精隽可味，尽在乎钞中。览其言，足以知其道矣。然钞文虽成，傅写无几。有惠悫道人，甞受观学于净觉师，欲其文之行远，以广法化，乃图镂板，省功于肆业之士，埀裕乎慕膻之流，恳蕲余言，以冠卷首。牢辞不获，粗述元由。其知净觉之德风行状，则有端明尚书李公塔铭在，今序略诸。去声灰

## 教义分齐章重校序此下三首

予禀具之初，受华严大部于横海法师之门。参承之暇，甞示诲曰：昔贤首国师述教义章，开一乘之渊旨，发五教之微言。故其立宗判义，独耀古今。兹实先圣之遗烈，作后世之龟鉴者也。若清凉之释大经，圭峰之解圆觉，长水之注楞严，皆所以抗志一乘，潜神五教，而章句出焉。然其间标题有乖谬，列门有参差，传写有讹舛。考兹三失，纷然久矣。何则？原夫先祖之标题也，以华严一乘教义分齐章为目，而圆觉广钞引之详矣。比见数本，或标云华严五教章，或题云华严一乘分教记，是岂祖师之意耶？向所谓标题有乖谬，其失一也。又若总列章门，稽诸舆本，皆以义理分齐系乎第九，所诠差别当于第十。近有佛陇学者，传乎径山写本，妄以第十门为中卷，反以第九门为下卷。向所谓列门有参差，其失二也。且夫三轴之文，难以文定；十门之义，宜以义求。其或舛克为尧，讹凤为风。此例实繁，不可具陈。所谓传写有讹舛，其失三也。嗟乎！法师之去也，几二纪矣。后之人胸臆其说，吾将谁从？因与二三子详校其辞，以垂当世。有霅川上人灵凤者，久奉祖训，施缗开勒。于是輙书往日所禀之语，告诸来裔云。师讳明覃

## 还源观疏钞辅解序

夫宗经为观，传诸后嗣，以教类之，略有三焉。昔帝心尊者，集法界观门，则宗乎化教矣。澄照律师，述净心诫观，则宗乎制教矣。苦乃化制并宗，性相互陈。唯贤首国师，妄尽还源，兼而有之。故其国顿之机，权小之流，悉皆普被耳。源景祐中，禀兹观门于昆山慧聚法师之门，并疏两轴，科文一册，皆法灯大师之所撰也。然其间所释序文，及诸观义，虽尽乎善，而未尽乎美。于是举要治繁，选言发行，探清凉之疏旨，索演义之钞辞，补其偏善之功，成其具美之绩，故命题曰疏钞补解焉。古人有言：不截盘根，无以验其利器；不剖文奥，无以辨其通才。后之孙谋，通吾祖观心，昭昭然若杲日之丽天，且不为昏情所翳者，其在兹乎？名讳清本

## 法界观助修记序

夫钞记之作也，非谓旁引教相，广叙章门而已。在乎发序意，通注辞，使其说授者，临文到旨，造解成观，此其大槩也。然兹观门，作为钞解，殆盈四家。西蜀仁周法师、开宝守真大师、浙水从朗法师、景德有明大师，虽皆连疏累偈，托文为证，而于所解之义，有多互违者。盖帝心集观，文高旨远；定慧为注，言约义微；丞相述序，本末交映。以故申明其辞，实难其才耳。抑又行之大者，莫先乎熏止习观。诸钞发义，虽列多门，而圆修造诣，竖无穷归源，躭味波玩，有年数矣。不揆荒鄙，輙事操觚，删众说之繁文，补诸祖之要义，勒成两卷，将传叔世，助观心而终焉。噫！吾祖既没，微言在兹，与我同志，无隐乎尔。

## 西湖昭庆寺结净行社集总序

一切有为，皆是尘妄，于尘妄了境，乃无为也。大千法门，不离自性，于自性识本，乃菩提也。境泯则不着，本达则无惑，我三世诸佛，以？河沙众生，演十二因缘，根于此也。其有精行洞识，化人无倦，立一心愿，际诸十方，以有为而至无为，以利己而成利众，吾闻之于华严净社焉。社建于钱唐昭庆寺，主于比丘省常上人。上人生钱唐，住昭庆寺，无碍之心，依古佛之行，精进圆满，诸戒具足，立大誓愿，而作是念，刺指取血，以血和墨，写模法式，书华严净行一品，一字三作礼，一礼一围绕，一围绕一念佛名号，然后始刻之方板，毕一千本，以一本施一人，又以栴檀香林，造毗卢圣像，圆此诚感，得之天匠，以八十开士，为一社焉。白莲之称，始继卢阜，况乎西湖之清音，昭庆之精屋，尘劳万变，中有静境，群动纷浊，独立戒定，如风烟歊杂，白云无间，荐绅大夫，争投文以求为社中人焉。上自丞相宥密，下及省阁名公，英衮声诗，远光江海，鸿彦弄藻，咸着铭纪，而斯皆道契清尚，以龟緺自卑。夙缘坚牢，有香火之约。六尘洒落，升堂者悉入信门。三觉通明，会境诸尽跻满教。故参知政事礼部侍朗武功苏公为净行篇序，今致仕吏尚书广平宋公为结社铭，故起居舍人知制诰孙公为结社卑阴序，今三司使给事中丁公为群公诗序。墨妙笔精，金相玉振。以春卿之妙词，内庭辍润色之暇。以天官之文伯，儒林为人之表。以西坦之才高，难可回御于修涂。以计相之识广，慧通外护于内典。今旧相右丞河内向公，首缀风骚，相继百数。以国辅之重，辞臣之望，非上人用大慈大悲之鸿愿，以身以心之真恳，又何以拂当世之云天，萃巨儒之竹素。续之者如入三昧，捧之者若登四禅。苟或总叙胜因，合归大手。如易者，山阴人也。文谢头陀，迹慙都讲。徒连叨于科第，而骤司于礼乐。犹且枢衣法席，稽首禅扉。将饮醍醐道映，舟航觉海。忏三业之口舌，少赞大乘。殊软贼之轩车，未亲丈室。远承高命，俾假微词。公干病多，江淹思涩。他年入社，愿除陶谢之俗情。今日序诗，聊助生融之末简。󳬴

时大中祥符二年冬十一月五日，信州翠微亭序。

## 施华严经净行品序

法界无边际，能周之者心识；众生无穷已，能拔之者誓愿。誓愿不广，不足摄众生迷妄之性；众生不度，不足契诸佛付嘱之心。苟暂时思惟，一念回向，则法界了然，无有障碍。诸佛繇是悉主赞叹，矧勤行而不惰哉！辛卯岁，有荥汤郑生自会稽至，以方广华严净行品一篇示予曰：彼方沙门号省常，辩才达识之士也。素行燕坐，不舍功用，捍劳忍苦，思拯焚溺。居常发广大之心，挺坐固之志，求与诸众生皷精进楫，登慈悲舟，张悟解帆，出生死海，不起本处而达彼岸。以为沥恳莫若刺血，传信莫若篆版，乃印是经凡一千卷，结八十僧社，散施念诵，期于无穷。俾未悟真谛者悉生归依，已种善根者悉令增长，受佛禁戒，入佛智慧，作是果报而无所作。以予乐在名教，早勤熏修，求为序引，以示来者。予闻是言，即摄衣稽颡而报之曰：彼上人者，果能立是见解，成是功德，予当布发以承其足，剜身以请其法，犹无瞋恨，何况陋文浅学而有吝惜哉！即时预千人之受持，同诸佛之赞叹，遂以事迹书于简编。至若报君亲之恩，化檀信之旨，则有常公发愿之文在焉。

淳化二季秋二十有四日序。󱑊

## 西湖结社诗序

夫事不能自大，必因乎树立；境不能自胜，必假乎指名。故世之人，观其树立而依归之，随其指名而趣向之。苟立事指境，能如是而为众所与者，所谓不可多得之人也。钱塘山水，三吴百越之极品，而西湖之胜又为最。环水背山二百寺，据上游而控胜槩者，今当师所栖之寺曰昭庆者也。开阖物表，出入空际，清光百会，野声四来，云木之状奇，鱼鸟之心乐，居处有遥观，游者踌躇，岂非万类之净界，达人之道场乎？师励志学佛，而余力于好事，甞谓：庐山东林，由远公莲社而著称，我今居是山，学是道，不力慕于前贤，是无勇也。繇是贻诗京师，以招卿大夫。自是贵有位者，闻师之请，愿入者十八九。故三公四辅，宥密禁林，西垣之辞人，东观之史官，洎台省素有称望之士，咸寄诗以为结社之盟。文自相国向公而降，凡得若干篇，悉置意空寂，投迹无何，虽轩冕其身，而林泉其心。噫！作诗者其有意乎？观其辞，皆若绩画乎？绝致飞，动手高情，往心东南，如将傲富贵，趣遗逸，朝夕思慕，飘飘然不知何许之为东林也，孰氏之为远公也。宗、雷之辈，果何人也？远公之道，常师之知；宗、雷之迹，群公悦之；西湖之胜，天下尚之。则是结社之名，亦千载之美谈也。谓爱常师能树立其事，指名其境，而为当世名公巨贤依归趣向之若是，真所谓不可多得之人也。既作诗以贻之，又命予为序，意若十八人中，使遗民著述为多。

景德三年春三月十日序。

## 大宋杭州西湖昭庆寺结社󳬴铭并序

大宗在宥，干大宝淳化纪号之元年。天象高明，七政齐而玑定。人时上瑞，五稼登而玉烛和。车书混壹于寰中，王帛骏奔于天下。俗跻仁寿，运洽升平。将相名臣，精通文武之教。缁黄上士，勤行道释之宗。由宝命以惟新，致彝伦之欣叙。苾𫇴盛事，简册宜书。杭州照庆寺僧曰省常，身乐明时，心发洪愿。上延景祚，下报四恩。刺血和墨，书写真经。书之者何？即大方广佛华严经净行一品也。每书一字，必三作礼，三围绕，三称佛名。良工雕之，印成千卷。若僧若俗，分施千人。又以栴檀香造毗卢像，结八十僧同为一社。再时经像成，乃膝地合掌，作是言曰：我与八十比丘，一千大众，始从今日，发菩提心。穷未来际，行菩萨行。愿尽此报已，生安养国。顿入法界，圆悟无生。修习十种波罗蜜多，亲近无数真善知识。身光徧照，令诸有情得念佛三昧，如大势至。闻声救苦，令诸有情获十四无畏；如观世音，修广大无边行愿海；犹如普贤，开微妙甚深智慧门；犹如妙德，边际智满，次补佛处；犹如弥勒，至成佛时，若身若土；如阿弥陀，八十比丘，一千大众，转次授记，皆成正觉。我今立此愿，普为诸众生，众生不可尽，我愿亦如是。伟矣哉！上人之言，如是志，如是心，如北斗建之而天下春，舌如南箕皷之而万物动。由是幅员四境，棋布百城，士人闻之，则务贞廉，息贪暴，填刑网，矜人民；释子闻之，则勤课诵，谨斋戒，习禅谛，悟苦空；职司闻之，则慕宽仁，畏罪业，尊长吏，庇家属；众庶闻之，则耳苦辛，乐贫贱，精伎业，惧宪章。善者闻之而迁善，恶者闻之而舍恶，夫何异哉？嘻！世末时移，风凋俗弊，悭痴塞路，很成群，王化有所不慑，国命有所不从，上人以是因缘，悉生回向，如趋宝肆，如登春台，斯所谓出其言善，千里之外应之也。乃有朝廷措绅之伦，泉石枕潄之士，猗顿豪右之族，生肇高洁之流，皆指正途，趋法会，如川赴海，如鳞宗龙，贲然来思，其应犹响。非夫励精素志，奋激清心，入金僊之室，游古佛之门者，孰能感人心，隆大教，若斯之盛也？上人姓颜氏，字造微，钱塘人也。母孙氏，始梦梵僧，终证法器。年方龆齓，性绝荤茹。七岁舍家，十五落发，礼菩提等吴越副僧统圆明大师志兴为师。十七受具戒，二十通性宗，二十一抗牧翟守素请讲大乘起信论，二十五金师钱俨上表奏赐紫方袍，又从五云大师志逢传唯心法门。雍熈中，梦感神僧示文殊像，由是化四众以造成，拟五台之相好。次则慕远公启庐山之社，易莲华为净行之名，福无唐捐，功已成就。内学之外，为诗甚工，汤休、皎然，不相上下。噫！昔慧远当衰季之时，所结者半隐沦之土；今上人属升平之世，所交者多有位之贤。方前则名氏且多，垂裕则津梁无已。道光远裔，行冠前修，此而不书，将遗巨美。白望风金地，恭职玉堂，遥贽斯文，以备僧史。凡入社之众，请勒名石阴。铭曰：龼𢘙

## 具请人位据人数多少资次排列他皆倣此

伏以大方广佛华严经者，佛为大心众生说一乘道，纯真境界，超绝权假，当念相应，即成正觉。故十会说法，不离菩提之场；刹那成佛，无待僧祇之劫。诸谛平等，同法界性；甚深广大，过诸思议。非圆通融会，安能宣扬此无尽藏海？诚上人闻修有本，行人胜流。善财遍参，渐进虚明之地；普贤大愿，会归悲智之门。此处吉祥，有众延请。盖亦示如来之知见，成大事之因缘。夫一切含灵，下至微尘之细；三世诸佛，上穷多劫之先。元明妙圆，本同具足。但以情生智隔，所立照亡，是致百千差殊，一多总别。上人以方便慧为人演说，譬之指月，亦同筏喻。不取于相，乃如实语。以是功德为大福田，则毗卢遮那光明遍照矣。

## 请讲大方广佛华严经疏

法界众生，本大方广。因沉苦诲，误认浮沤。不知幻身，实同诸佛。佛称是性，说华严经。付嘱大心凡夫，超绝假名菩萨。色空泯寄，理事相明。磨镜露光，光由中出。焦摸见像，像匪外来。尘尘具足解脱门，品品含容无量义。九会同时，音徧于迩遐。孤月三舟，异目妄分于去住。所谓一证一切证，一断一切断。成最正觉，顿示大根。非如它宗，进有揩渐。不遇明智，孰穷指归。讲主诚师，从闻思修，达体相用。东际瞻仰，早悟菩提。南方游行，徧参知识。皷倡一乘之教，洞开三观之门。自发初心，即周海藏。不移本位，应请河沙。大众所依，当毋辞避。

## 皇明年龄亿万谨疏

右伏以始觉精真，岂缘心之思议；无明幻妄，随事识以轮回。九相之法甚深，六染之心难辨，了斯义者，唯起信之谓欤！某师坐主识达本源，学穷秘奥，了悟三乘之权实，精研一性之深微，开示有方，汲引弥众。承禀弟子某甲座主性机颕悟，志操超殊，颇闻青出之名，尤着朱研之美。今者群心卛仰，来学渐多，愿闻龙悦之音，大演马鸣之旨。上资圣寿，远报佛恩，幸勿多谦，庶全众议。谨疏。

盖闻高老西河，尼父之遗风广振。玄归北海，季长之妙道遐宣。是知传教之宗，唯以择师为本。则彼六籍之源流甚溢，五常之疆畛非遥。犹资一衖之评，必俟三隅之返。矧乃大雄奥旨，上界真宗。若非洞达方言，何以阐扬圆教。仅同九译，方演一乘。则昔鶴林示寂灭之期，金棺掩耀。龙树诵玄微之义，玉轴腾芳。探秘宝于渊居，化群生于沙界。乃有法领则躬寻圣典，去涉兑郊。觉贤则首唱妙音，来仪震域。遂识杂华之殊号，始翻贝叶之正文。由是远从典午之朝，近至娲皇之运。仰惟开示，继有异人。述微言则琢玉争能，编奇迹则贯珠靡绝。其于博喻，不可殚论。然而仰测良缘，遐寻善诱。契彼东流之说，谕其西学之徒。使我蓬海一隅，桑津四境。金炉耀掌，远传薝卜之香。玉镜澄心，尽晓芭蕉之喻者，乃巨唐故终南山至相寺智俨和尚付大教于我先师，想大德之慧力也。伏惟和尚风篁激爽，霜桂标贞。运既叶于半千，义能探于第一。加以学包内外，识贯古今。五天之秘藉幽筌，敷弘有裕。四海之沉疑宿滞，剖折无遗。遂能挺秀于中华，仍得流徽于外裔。门人法藏和尚与我先师大德同叩玄揵，深窥妙门。无僧因升堂入室之谭，有昙衍出户面墙之论。自摄斋请益，当仁之意兴；及操袂言归，求友之声共切。藏和尚濬资先训，广集异闻。甞假牋函，寄传章疏。则足以见严师诱掖，益友切磋之厚也。天周二十秊后，有传业弟子大德决言、大德贤等，高焦智烛，继炤慧灯。山玉海珠，岂假求珍之远；青蓝绛茜，能成受彩之深。乃相与扬言于众曰：祖祖流传，师师授记。阅遗文而究玄理，窥囊诲而悟幽宗。一言见心，千载如面。然则至于恤贫擢贱，尚感厚恩；况乃发瞽披聋，难量慈化。每推诚于念祖，宜尽礼于尊师。岂可为我国先师，则己兴良会；为他方法祖，久则不致妙筵。纵欲观空，宁宜弃本。遂自中和四年，发大誓愿。每至南吕孟旬，奉为故终南和尚，及天竺翻经演偈之尊宿，与中国编章撰疏之法师，谨选精庐，同开讲席。高谭圣教，仰报法恩。伏愿清凉山中，迭耀奇相；兜率天上，齐成胜因。修定力以济众缘，假余光而炤未学。使龙宫密藏，早传上本之金言；鳀壑遐陬，遍诵大乘之宝偈。举足而永离前泥，修身而得接后尘。生也有涯，固难期于泡沫；殁而不朽，唯共托于香华。设至现鲸池，尘飞鲽海。灯灯绍焰，终祛北境之昏冥；叶叶传芳，不坠东林之誓约者也。㸦㑺灰

## 杜师之慧化乎伏惟

大德高挺岳灵，深涵海量。童年慕道，壮志辞家。舍华胄之簪裾，标法门之冠冕。始以教分顿渐，义有浅深。每嗟四郡之遐陬，未达一乘之奥典。乃言曰：就室之火为小见，炤庭之日为大智。是以务学不如务求，师古之遣训。岂可孔匏徒系，魏瓠虚捐。自追小鲁之踪，遂决入之计。时𤞃戎貊，熢举折警。言指道途，动多榛梗。然而既切为山之志，独怀背水之心。不惮艰危，远涉虎狼之国。能逃伤害，岂凭羊鹿之车。直泛重溟，高登彼岸。于龙朔二载，诣终南山至相寺。以俨和尚为严师，以藏和尚为益友。受业则若飜瓴水，传宗则如走坂丸。有滞必通，无幽不测。则悟百千，偈歒三十。夫执柯而既遂伐柯，学海而终能至海。十年精练，万里流传。振龙树之余芳，播鸡林之远俗。显敷妙义，遍谕群迷。披聩以法雷，开曚以智月。遂得慈航广济，化人而永谢爱河。法軚长驱，救物而皆离室。一自寂灭为乐，虚空是宗。每怀慥慥之诚，但想循循之诱。不涉鹫头之岭，自达妙音。能持鹊尾之炉，竞寻懿躅。高山仰止，何日忘之。是以弟子性起等，悲切藏舟，感深入室。同成社会，用报法恩。每值忌晨，仰谈遗教。伏愿祖师大德，兜率陀之天上，汲引众流。摩竭提之国中，炤临法界。海融智慧，云覆慈悲。传佛心而尽玩杂华，举宝手而长攀圣果。功虽尽，香火无尽。𥘿𭁵󱐑灰

## 华严社会愿文

夫圣人之设教也，示其无诳，化彼有缘。观身则晓露迎风，炼性则寒潭浸月。妄生妄而同拘下界，空至空而莫逭大期。是以麟野伤怀，负手应两之梦；鹄林变色，分身结双树之悲。则验去之与来，有若形之与影。既乃息形止影，是为舍幻归真。且昔庐峰远公，与众立誓，志期西境，遗美可寻。况览巨唐法藏和尚，寓我祖师大德书云：夙世同因，今生同业。愿当来世，舍身受身。同于卢舍那会，听受无尽妙法。则知儒室则颜回早逝，天上修文；释门则智𫖮相逢，山中叙旧。宛如符契，皆自因缘。矧乃方广真筌，世雄至鉴。包大空而阔视，从上界以遐宣。苟能叶于志斯宗，必也追踪于囊会。然则同声相应，固当适我愿兮；诸善奉行，孰曰非吾徒也。既究一乘之妙义，尽明三世之宿因。故我业中，先达龙象，共缔香社，特营法筵。如有先示灭者，众集皇福寺，讲经一日，追冥福也。噫！时当像末，俗尚浇浮，众病难除。但仰净名居士，流年渐促，谁封老寿？将罕见归人，然后识行人；至大觉，然后知大梦。莫不心存我净，目想他方。聊振妙音，同申弘愿。所愿者，祖师已降，后进之徒，永离辽海之隅，高涉灵山之会。栖身净域，悬智镜而炤群迷；携手香城，驾慈轩而恣常乐。纵销天石，继洒雨华。㨕

## 华严经社会愿文

夫以经为社者，乃聚人以善缘，报主以至诚之会也。唐历景午相月五日，献康大王宫车晏驾，台庭重德，宗室懿亲，相与追奉冥福，成华严经两部。将陈妙愿，乃着斯文。且夫生灭定期，圣贤同贯。君子则能知所息，哲人则亦叹其萎。逐逝水而云归，百身难赎；寐穷泉而莫寤，千载增悲。未超迷妄之尘，皆跼感伤之域。然则既失养神于玄牝，莫先归命于梵雄。能于九十刹那，精心向善；必使三千世界，惠力分慈。况乃手写金言，口传宝偈，则福滋玄路，不逾一瞬之间；志达绀园，永在四流之表。仰资妙果，共托觉林。伏惟先王克己为君，视民如子。百揆干干之虑，四聦悦谔谔之言。焕乎能耀文章，俨尔又安辞令。辟康庄于鲁道，广振儒风；治芜秽于释门，再光佛日。遂使尘消九野，波息四溟。方当永戢干戈，能苏万彚；岂料空遗弓劒，遽密八音。圣上当璧嘉微，嗣膺宝位。陟岗余恋，离抑哀情。以为报恩莫如结道缘，追福莫如兴法会。遂教大德贤隽，讲华严经。及降谭座，乃上言曰：窃见大和中，有僧均谅等，奉为宣懿王后，诱缁素之徒，结春秋之社。各賷经卷，共集仁祠。荐玄福以无穷，传妙音而不绝。虽名言莫及，而信愿增深。纵谷变而陵迁，永兰芬而桂馥。今欲遵依均谅故事，劝诱群臣写经。敢言炼石补天，唯撮尘稗岳。法能无碍，志必有成。仰𫖮圣慈，俯从丹请。上以孔怀兴咏，衔悲于鸿鴈行中。幽赞求慈，注意于狻猊座下。既览所奏，嘉而许之。仍择侍书中穷笔妙者，令写华严经世间净眼品第一，特宣天旨入会。至其会日，则降王人捧经就席。则彼梵王英之洁志为誓，似滞小乘。萧帝衍之降尊就卑，全轻大宝。岂若玩杂花之妙偈，资令萼之胜因。友于之至义逾彰，王者之尊威自峻。遂得众情风靡，善愿云兴。若万木之遇春阳，如百川之归巨寖。奥有上宰舒发韩金公林甫，国戚重臣苏判金一顺宪等，或兼金瑞彩，或盘石贵宗。高标廊庙之珍，深蕴栋梁之器。瞻茂陵而堕睫，指梵域以倾心。永慕天慈，同追海会。遂写义熈本经。复有国统及僧录等，写贞元新经。北宫长公主闻之，乃舍净财为带暨轴之直。美矣哉！天伦义重，已垂主会之荣。月姊恩深，又备装经之具。至于鸳鸯清贯，龙象高流。响应影从，隳肝沥瞻。功侔于血墨皮纸，价迈于香厨宝函。未浃一旬，共成十袠。则足以见我先大王修善化，推厚恩，而入人腹中之深也。如是众愿佥谐，年约两会。集于陵北寺，转读于百编真筌。伏愿先王月耀金姿，云承玉趾。纵赏于喜园春色，娱怀于灵岫梵音。设使西空芥城，东没蓬岛。妙缘无坠，仰天上之尊良。良会不亏，传日边之盛事。宜空圣众，炤达斯诚。󳷥󲦂𥨊新罗官名官名
