寶珠自性廣大海，七寶山等最殊勝， /
出興如斯供養雲，諸佛等處我奉獻。 /

如來妙色身，色相不思議，見者生歡喜。 /
恭敬信樂法。十方國土海，無量無邊佛， /
咸於念念中，各各現神通。大智諸菩薩， /
深入於法海，佛力所加持，能知此方便。 /

十力大雄最無上，譬如虗空無等等， /
境界廣大不可量，功德第一超世間， /
十力功德無邊量，心意思量所不及， /
人中師子一法門，眾生億劫莫能知， /
十方國土碎為塵，或有數計知其數， /
如來一毛功德量，千萬億劫無能說， /
如人持尺量虗空，復有隨行計其數， /
虗空邊際不可得，如來境界亦如是。 /
或有能於剎那項，悉知三世眾生心， /
設經眾生數等劫，不可知佛一念性， /
譬如法界徧一切，不可見取為一切， /
十方境界亦復然，徧於一切非一切。 /

欲具演說一句法，阿僧祇劫無有盡。 /
而令文義各不同，菩薩以此初發心。 /
光中現佛不可說，佛所說法不可說， /
法中妙偈不可說，聞偈得解不可說， /
不可說解念念中，顯了真諦不可說， /
示現未來一切佛，常演說法無窮盡。 /
一一佛法不可說，種種清淨不可說， /
出妙音聲不可說，轉正法輪不可說， /
於彼一一法輪中，演修多羅不可說。 /
於彼一一修多羅，分別法門不可說。 /
於彼一一法門中，又說諸法不可說， /
於彼一一諸法中，調伏眾生不可說。 /
或復於一毛端處，不可說劫常安住， /
如一毛端餘悉然，所住劫數皆如是。 /

菩薩功德無有邊，一切妙行皆具足， /
假使無量無邊佛，於無量劫說不盡， /
何況世間天及人，一切聲聞及緣覺， /
能於無量無邊劫，讚歎稱揚得究竟。 /
一切眾生數易知，三世心量亦可知， /
如是普賢諸佛子，功德邊際無能測， /
一毛度空可知邊，眾剎微塵可數知， /
如是大仙諸仙子，所住行願無能量， /
十方剎土碎微塵，於一念中不知數， /
毛端度空能知量，億劫宣揚不能盡。 /

十方一切諸眾生，二乘有學及無學， /
一切如來與菩薩，所有功德皆隨喜。 /

十方所有世間燈，最初成就菩提者， /
我今一切皆勸請，轉於無上妙法輪。 /

諸佛若欲示涅槃，我悉至誠而勸請。 /
惟願久住剎塵劫，利樂一切諸眾生。 /

我隨一切如來學，修習普賢圓滿行， /
供養過去諸如來，及與現在十方佛， /
未來一切天人師，一切意樂皆圓滿， /
我願普隨三世學，速得成就大菩提。 /

所有十方一切剎，廣大清淨妙莊嚴， /
眾會圍遶諸如來，悉在菩提樹王下。 /

所有禮讚供養佛，請佛住世轉法輪， /

願我臨欲命終時，盡除一切諸障礙。 /
面見彼佛阿彌陀，即得往生安樂剎。 /
我既往生彼國已，現前成就此大願， /
一切圓滿盡無餘，利樂一切眾生界。 /
彼佛眾會咸清淨，我時於勝蓮華生， /
親覩如來無量光，現前授我菩提記。 /
蒙彼如來授記已，化身無數百俱胝， /
智力廣大徧十方，普利一切眾生界， /
乃至虗空世界盡，眾生及業煩惱盡， /
如是一切無盡時，我願究竟恒無盡。 /

欲求寂滅樂，當學沙門法。衣食計身命， /
精麤隨眾等，諸眾等寅朝，清淨記六念。 /

諸行無常，是生滅法；生滅滅已， /
寂滅為樂。

如來證涅槃，永斷於生死。若能志心聽， /
常得無量樂。

人生不精進，喻若樹無根，採華置日中， /
能得幾時鮮？華亦不久鮮，色亦非常好。 /
人命如剎那，須臾難可保，是故勸眾生， /
勤修無上道。

西方日已暮。塵勞猶未除。老病死時至。 /
相看不久居。念念催年促，猶如少水魚。 /
勸諸禮佛眾，修學至無餘。 /

是日已過，命亦隨減，如少水魚。 /
斯有何樂？當勤精通，如救頭然。 / 眾等
但念無常，慎勿放逸。 /

煩惱深無底。生死海無邊。度苦船未立。 /
云何樂睡眠？睡眠當覺悟，攝心恒在禪， /
勇猛勤精進，菩提道自然。 /

比丘汝起起，何以著睡眠？睡眠有何利？ /
病時豈可眠？利刺身時，云何得睡眠？ / 㓨
汝今捨家時，出離之所願，當如其本願。 /

神光遷流轉，迄至五更初。無常念念至， /
恒與生死俱，勸諸行道者，修學至無餘。 /

世間不牢固，如水沫泡，汝等咸應當。 / 𦦨

佛身無去亦無來，所有功德皆明現， /

佛身普徧諸大會，充滿法界無窮窮。 /
寂滅無性不可取，為救世間而出現。 /

## 直言讚佛

夫阿彌陀佛者，以實相而為體，用般若而為心。金容蕩蕩，報身住於淨方；妙相巍巍，應化隨機所現。眾聖圍繞，如皎月處於羣星；相好端嚴，似青蓮敷於碧沼。毫光散彩，頞珠朗於五山；紺目澄清，眼秀同如四海。大慈大悲，分身三十六萬；同名同號，變相九千五百。一日放十二光，接引念佛眾生，四十八願不捨。大悲聖者，尋聲救苦於娑婆；勢至菩薩，慈心誘接於羣品。惟願彌陀海會聖眾，身住華臺，心存佛境。善哉聖德，超言思矣。

惟願十方諸慈尊，我及一切諸有情， /
願作證明護念我，我今懺悔復不造。 /
無量劫中所作罪，十惡五逆犯四重， /
毀謗三寶一闡提，速願消滅得清涼。 /
復應思惟如是罪，但從顛倒虗妄起， /
無有決定而可得，本來空寂常清淨。 /
願我及與諸眾生，速疾普共得開道。 /
速達本心無錯謬，永絕罪根盡無餘。 /

某甲等，普及四恩三有，法界眾生，法身壽命，本智光明，與阿彌陀佛，同一體性，而無量劫來，不了自心，起惑造業，或不孝父母，不順師長，殘忍無慈，殺生偷盜，不淨邪婬，妄言綺語，兩舌惡口，及貪嗔癡，十惡熾然，無罪不造，隨順邪師，不信三寶，或破五戒八戒，十戒二十五戒，二百五十戒五百戒，十重四十八輕，三千威儀，八萬細行，具足闡提，撥無因果，誹謗大乘方等經典，破人善事，無慈悲心，不肯勸進同梵行者，乃至殺父害母，殺和尚阿闍梨，出佛身血，破羯磨轉法輪僧，殺阿羅漢，破塔壞寺，殘毀經相，驅役僧徒，或用霸道，侵損現前十方三寶財物，不淨說法，污梵行人，如是普於三寶聖眾，師長父母，法界眾生，造種種罪，或自作教他作，或見作隨喜，重重無盡，徧周法界，充塞虗空，今對阿彌陀佛，皆悉懺悔，惟願阿彌陀佛，威神力故，如湯消氷，應念化成無上智覺。又復阿彌陀佛，四十八願，憐愍有情，放淨光明，攝取不捨，所居極樂，眾寶莊嚴，菩薩往生，永不退轉，修行無間，直至菩提，本師釋迦牟尼，及十方諸佛，慇懃勸讚，一念乃至十念，一日乃至七日，稱名繫念，決定往生，我等愚迷，不信不順，或時聞已，心則輕笑，見念佛人，惡心毀謗。設有信者，無決定心，若存若亡，或進或退，業緣深重，世務牽纏，身在道場，心緣世諦，口談極樂，意戀娑婆。於念佛時，心多散亂，三種淨業，片善無成，十六觀心，一時不徹。臨命終時，或遭橫死，墻崩屋倒，樹折嵓摧，水火漂焚，蟲傷獸齧，刀兵遽至，毒藥傷，卒病臨身，不遑念佛。或纏綿重病，苦逼身心，宛轉號呼，難安正念。或無善友，助發淨因。由是種種罪業因緣，臨命終時，不得見佛，不得往生淨土，還復流轉娑婆五濁惡世。三塗八難，隨業受生，五痛五燒，為最極苦，未來生死，無有盡期。或墮胎生金鎖之難，五百歲中，不得見佛。此皆從昔以來，不信阿彌陀佛，不信往生淨土，身口意業，輕慢毀謗。以是因緣，雖復發心，多諸障難。我今稽首阿彌陀佛，惟願天眼見我，天耳聞我，他心見我，大慈大悲，哀愍攝受，聽我懺悔，令我普及四恩三有。法界眾生，罪障、業障、煩惱障、所知障、不信佛言障、懶墮修行障、三塗長夜障、五濁惡世障、邊地疑惑障、不聞三寶障，凡是往生一毫之障，悉願消除，一切清淨，正信現前，不疑不退，決定往生極樂世界，速成正覺，轉大法輪，圓滿廣大行願。㬥

## 至心發願

願弟子普及四恩、三有法界眾生，從今已去，住第一義諦，修佛淨業正因，孝養父母，奉侍師長，慈心不殺，修十善業，受持三歸，具足眾戒，不犯威儀，發菩提心，深信因果，讀誦大乘，勸淨行者，念佛、念法、念僧、念戒、念施、念第一義天，以至誠心、深心，迴向發願心，稱佛名號，讚佛名號，讚佛光明，觀佛依正十六妙境，念佛本起四十八願，籌量三輩，深入五門，隨順三種菩提門，信受十方諸佛教，或以散心、定心。惟願阿彌陀佛法力宜加，神通顯益，令我等凝神覺路，暗蹈大方，進止威儀，不離見佛，如執明鏡，自見面像，及於夢中，常見彼國眾妙樂事，安慰我心，令生增進，哀愍覆護，法種增長，承佛威神，遠離魔事。又復無量劫來，業惑塵勞，皆為梵行，善根功德，同入大因，積集諸緣，盡用迴向。臨命終時，無諸障難，七日已前，預知時至，身無痛苦，心不顛倒，身心安樂，如入禪定。遇善知識，教存十念，阿彌陀佛與諸聖眾現在其前，放大光明，授手迎接，自見其身乘金剛臺，隨從佛後，如彈指頃。往生彼國已，見佛色身眾相具足，見諸菩薩色相具足，光明寶林演說妙法，聞已即悟無生法忍，身真金色，等無差別，三十二相，六通自在，具大辯才，演一切智，那羅延身，壽命無量，供養如意，妙服自然，不聞惡名，不著身見，諸上善人俱會一處，住正定聚，永不退還，究竟至於一生補處，受用清淨大乘法樂。晝夜六時，供養阿彌陀佛，每日清旦，奉事十方如來，聞法授記，得陀羅尼，化身自在，周遍十方無佛國中，成等正覺，極重苦處，遊戲神通，隨眾生心，應所知量，對現色相，晝夜說法，無有休息。於念念中，令不可說不可說眾生發菩提心；於念念中，令不可說不可說眾生住普賢行，福德資粮悉得圓滿，同成無上正等菩提，各各莊嚴淨土，各各攝化眾生，如阿彌陀佛等無有異。惟願阿彌陀佛慈悲證盟！

## 初西域流傳華嚴諸師

夫龍樹菩薩者，本是妙雲相佛示跡初地位中，是南印土梵之種也。家豪富貴，幼年聰利，超越無倫，生一切智，解四韋陀，天文地理，星歷占記，諸般幻術，無不了解，五國名稱，齅香知藥，悟欲苦本，速發誓願。九十日中，五印土所有經文，悉皆記之，開說義理，辯如流水，自謂一切智人，住水晶宮。大龍樹菩薩覺知彼故，以神力召至於海，開七寶藏庫，示方廣經。見此大不思議經，有其三品：上本經者，有十三千大千世界極微塵數偈，一四天下極微塵數品；其中本經者，有四十九萬八千八百偈，一千二百品；下本經者，有十萬偈，三十九品。龍樹誦之，流傳世間。得下本已，皎潔慧日，照於第一義天；運檝慈舟，遊於真如性海。契三十二之法，纂集諸經，造大不思議論，具十萬偈，廣傳西域。集大乘無相空之教，造十地論五百之偈，大莊嚴佛道論、大悲方便論各五十頌，無畏論十萬偈，摩訶衍釋論十卷，大智度論百卷，其名一切智人。我今眾等，禮讚功德，所獲善根，迴向一切眾生海，願皆永離纏葢，速悟菩提。

## 次八萬四千惑業懺悔

惟願帝網無盡，佛法僧寶，毗盧遮那如來，普賢文殊，海會聖眾，世出世神，慈悲本願，放大光明，炤於法會，證明護念，衰憫攝受。願我及一切眾生海，自從無始，直至今時，業海無盡，帝網重重，一切惑業，發露懺悔。夫性相諸宗中，有八萬四千法門，八萬四千功德，八萬四千煩惱，八萬四千十惡業。今末濁時至，人人造不善業，各各作惡無悔，由此怨魔外道，破滅正法。其八萬四千煩惱，有二種釋：一者眾生根本煩惱：一貪，二瞋，三慢，四無明，五疑，六身見，七邊見，八邪見，九見取，十戒禁取。然一惑力，復各有十，即為一百，應分九品。但上品重故，開為三品，中下輕故，各為一品，合為五百。於自五塵，總起五百，於他五塵，總起五百，各本一千。又有自他五塵，一一各別起五百為五千，別迷苦諦五千，別迷集諦五千，別迷滅諦五千，別迷道諦五千，如是別迷四諦為二萬，并本一千為二萬一千。又依貪行多者，二萬一千；依瞋行多者，二萬一千；依癡行多者，二萬一千；依等分多者，二萬一千，總成八萬四千。二者、以十惡為境，漸漸相成，一一各成十為一百，迷自他五塵成一千。於十諦法門迷者，其四諦、三諦、二諦、一諦是也。若迷故，說為諦等十諦。惑迷十善，即成一萬。今迷十諦，空有不同，分為二萬。或云迷十善二諦，分為二萬，及本一千，如餘經說。如是等法界帝網，惑海、業海重重無盡。若欲發露懺悔，當識逆順十心。

天台摩訶止觀云：若欲懺悔二世重障，當識順流十心。明知過失，當運逆流十心，以為對治。此二十心，通為諸懺之本。順流十心者：一、自從無始，闍識昏迷，煩惱所醉，妄計人我。計人我故，起於身見。身見故，妄想顛倒。顛倒故，起貪嗔癡。貪嗔癡故，廣造諸業。業則流轉生死。二者、內具煩惱，外值惡友，扇動邪法，勸惑我心，倍加隆盛。三者、內外惡緣既具，能內滅善心，外滅善事，又於他善都無隨喜。四者、縱恣三業，無惡不為。五者、事雖不廣，惡心徧布。六者、惡心相續，晝夜不斷。七者、覆諱過失，不欲人知。八者、魯扈抵突，不畏惡道。九者、無慙無愧。十者、撥無因果，作一闡提。是為十種順生死流。昏倒造惡，廁蟲樂廁，不覺不知，積集重累，不可稱計。四重五逆，極至闡提，生死浩然，而無際畔。今欲懺悔，應當逆此罪流，用十種心，翻除惡法。一者、先正信因果。決定孱然，業種雖久，久不敗亡，終無自作。他人受果，精識善惡，不生疑惑，是為深信，翻破一闡提心。二者、自愧尅責。鄙極罪人，無羞無恥，習畜生法，棄捨白淨，第一莊嚴。咄哉無鈎，造斯重罪。天見我屏罪，是故慚天。人知我顯罪，是故愧人。以此翻破無慙無愧心。三者、怖畏惡道。人命無常，一息不返，千載長往。幽途綿邈，無有資糧；苦海悠深，船栰安寄？賢聖呵棄，無所恃怙。年事稍去，風刀不奢，豈可晏然坐待酸痛？譬如野干，失耳尾牙，詐眠望脫，忽聞斷頭，心大驚怖。遭生老病，尚不為急，死事弗奢，那得不怖？怖心起時，如履湯火，五塵六欲，不暇貪染。如阿輸柯王，聞旃陀羅朝朝振鈴，一日已盡，六日當死。雖有五欲，無一念愛。行者怖畏苦到，懺悔不惜身命，如彼野干；決絕無所思念，如彼怖王。以此翻破不畏惡道心。四者、當發露。莫覆瑕疵，賊毒惡草，急須除之。根露條枯，源乾流竭。若覆藏罪，是不良人。迦葉頭陀令大眾中發露，方等令向一人發露。其餘行法，但以實心向佛像改革。如陰隱有癰，覆諱不治則死。以此翻破覆藏罪心也。五、斷相續心者。若決果斷奠畢，故不造新，乃是懺悔。懺已更作者，如王法初犯得原，更作則重；初入道場，罪則易滅，更作難除。已能吐之，云何更噉？以此翻破常念惡事心。六者、發菩提心。昔自安危人，遍惱一切境；今廣起兼濟，遍虗空界，利益於他。用此翻破徧一切處起惡心也。七修功補過者，昔三業作罪，不計晝夜。今善身口意，筞勵不休，非移山岳，安填江海。以此翻破縱恣三業心。八守護正法者，昔自滅善，亦滅他善，不自隨喜，亦不喜他。今守護諸善，方便增廣，不令斷絕，辟如全城之勳。勝鬘云：守護正法，攝受正法，最為第一。以此翻破無隨喜心。九念十方佛者，昔親狎惡友，信受其言。今念十方佛，念無礙慈，作不請友，念無礙智，作大導師。翻破順惡友心。十觀罪性空者，了達貪欲嗔癡之心，皆是寂靜門。何以故？貪嗔若起，在何處住？知此貪瞋，住於妄念，妄念住於顛倒，顛倒住於身見，身見住於我見，我見則無住處。十方諦求，我不可得。我心自空，罪福無主。深達罪福相，徧照於十方，令此空慧，與心相應。譬如日出時，朝露一時失。一切諸心，皆是寂靜門，示寂靜故。以此翻破無明昏闇。是為十種懺悔，順涅槃道，逆生死流，能滅四重五逆之過。若不解此十心，全不識是非，云何懺悔？設入道場，徒為苦行，終無大益。涅槃云：若言勤修苦行，是大涅槃，近因緣者，無有是處。即此意也。是名懺悔事中重罪也。

次懺見罪者，以見惑故，順生死流，如前所說。向運十心，附事為懺，懺鈍使罪。今扶理懺見，懺利使罪。然見心猛威，起重煩惱，應傍用事助。如服下藥，須加巴豆，令黈瀉盡底。是故還約十法，以明懺見。一、翻破不信者，即點身見心，令識無明苦集。如頭籃弗，得非想定，世人崇之。如佛不識苦集報盡，還墮須陀羅，得非想定。雖無麁想，有細煩惱，長爪利智，而受不受，高著外道，尚未出見，非是涅槃。況淺者，尚不逮籃弗，而言是真道，豈非大僻？是人愛著觀空智慧，是事不知，名為無明，而起違從，依見造行。見行依色，即是名色，名色即是苦等。迷苦起於愛有，有生未來生死，流轉相續，豈是寂滅？若謂生死盡者，乃是慢語。呼無明見心為道，非道為道，非因計因，名為戒取，豈非因盜？呼未來三途苦報為涅槃，此是見取，非果計果，是為果盜。身邊邪見，其事可知。如此見心，乃是苦集，非滅道也。尚非三藏道滅，豈是摩訶衍道滅？若能如是，即知世間因果，復識出世因果。故大品云：般若能示世間相，所謂示是道非道。是為深識見心苦集也。又深者，非但知無明苦集，亦識三藏因果，亦識因緣生法即空四諦因果。又復深者，亦知因緣即假無量四諦因果。又復深者，亦知因緣即中無作四諦因果，於一見心具識一切因果。故大經云：於一念心悉能稱量無量生死，是名不可思議。故名深信破不信也。二、生重慙愧者，不見我心中三諦之理，名慙愧。且約理觀論人天者，慙乾慧性地之人，愧四果淨天、三十心人、十地義天、五品六根清淨之人、四十二位天。例如作意得報名為人，自然果報名為天。二種天人亦復如是，方便道名為人，真理顯名為天。見心造罪，覆三諦理，不逮三種人天，是故慙愧，翻破無慙愧心也。三、怖畏者，知見心造罪，此過深重。大論云：諸佛說空義，為離諸見故，若復見有空，諸佛所不化。我今由見而起大罪，此間劫盡，他方獄生，此間劫成，還來此處，如是展轉，無量無邊。若說果報，所受之身當吐熱血死。故知見罪大重，既非無漏，不出生死，煩惱潤業，墮落何疑？一命不追，永無出日。為是義故，生大怖畏，翻破不畏惡道心也。四、發露者，從來諸見而生愛著，覆此三諦，不能決定生信。今知見過失，發却三疑，無所隱諱，顯其諦性，是為發露，翻破覆藏罪心也。五、斷相續心者，三諦之觀，勿令有間，以八正道治三惑心，斷而不習，此翻破相續惡心也。六、發菩提心者，即是緣三諦理，皆如虗空，空則無邊，愍傷一切，普令度脫。昔迷此起惑，有無邊故，罪亦無邊。今菩提心徧於法界，起無作善，亦徧法界，翻破昔徧空無作惡也。奏師子琴，餘弦斷絕，即此義也。七、修功補過者，三諦道品即是菩薩寶炬陀羅尼，是行道法，趣涅槃門。如此道品，念念相續，即是修功補過。昔執於見，謂為涅槃，於見不動，不修道品。設令動有入無，如屈步蟲，雖於見動，亦不能修道品。今知有無是見，不執為實，是名見動而不修道品。若破柝諸見，行於道品，是名見動而修道品。又體見即空、即假、即中，既言即者，於見不動而修三種道品，是為修功補於縱見之過也。八、守護正法者，昔護見，不令他破，方便申通。今護三諦諸空，不令見破，若有留滯，善巧申弘。亡身存法，猶如父母守讚其子，此翻破毀善事也。九、念十方佛者，昔服見毒，常無厭足，如渴思飲。又遇惡師，如加以鹹水，以苦捨苦。我慢矜高，諂心不實，於千萬億劫不聞佛名字。今念三諦，不來不去即是佛，無生法即是佛，常為諦理所護，此翻破狎惡友心。十、觀罪性空者，此三種惑，本來寂靜，而我不了，妄謂是非，如熱病人見諸龍鬼。今觀見如幻如化，來無所從，去無足跡，亦復不至東西南北，一切罪福亦復如是。一空一切空，空即罪性，罪性即空，此翻破顛倒心也。運此十懺時，深觀三諦，又加事法，以慇重心，不惜身命，名第二健兒，是名事理兩懺。󳬂䟦󱍮

我等為無明所覆，不識惑業罪因，今遇道場，方始覺知。歸命毗盧遮那如來，及一切賢聖海眾，燒香散華，一切惑業，發露懺悔，不敢覆藏。由此因緣，我及法界眾生海，帝網重重，一切惑業海，願皆清淨。

## 至心發願

十地經云：佛子！菩薩發如是大願，所謂：生廣大清淨，決定了解，以一切供養之具，恭敬供養一切諸佛，令無有餘。又願受一切佛法輪，願攝一切佛菩提，願護一切諸佛教，願持一切諸佛法。又願一切世界，佛興于世，從兜率天宮歿、入胎、初生、出家、成道、說法、示現涅槃，皆悉往詣，親近供養，為眾上首，受行正法，於一切處、一切時而轉。又願一切菩薩行，廣大無量，不壞不雜，攝諸波羅蜜，淨治諸地，總相、別相、同相、異相、成相、壞相，所有菩薩行，皆如實說，教化一切，令其受行，心得增長。又願一切眾生界，有色、無色，有想、無想，非有想、非無想，卵生、胎生、溼生、化生，三界所繫，入於六趣一切生處，名色所攝，如是等類，我皆教化，令入佛法，令永斷一切世間處，令安住一切智道。又願一切世間，廣大無量，細亂想，倒住正住，若入、若行、若去，如帝網差別，十方無量種種不同，智皆明了，現前知見。又願一切國土入一國土，一國土入一切國土，無量佛土普皆清淨，光明眾具以為莊嚴，離一切煩惱，成就清涼道，無量智慧眾生充滿其中，普入大願諸佛境界，隨諸眾生心而為示現，皆令歡喜。又願與一切菩薩同一志行，無有怨嫉，集諸善根，一切菩薩平等一緣，常共集會，不相捨離，隨意能現種種佛心，住其自心，能知一切如來境界威力智慧；得不退轉如意神通，遊行一切世界，現形一切眾會，普入一切生住，成就不思議大乘，修菩薩行。又願成不退轉行菩提行，身、語、意業悉不唐損，若暫見者則必定入法，暫聞音聲則得真實智慧，纔生淨信則永斷煩惱；得如是大藥王樹身，得如意寶身，修行一切菩薩行。又願於一切世界成阿耨多羅三藐三菩提不離一毛端處，於一切毛端處皆悉示現初生、出家、詣道場、成正覺、轉法輪、入涅槃；得佛境界大智慧力，於念念中隨一切眾生心示現成佛，念得寂滅；以一三菩提知一切法界即涅槃相，以一音說法令一切眾生心皆歡喜；示入大涅槃而不斷菩薩行，示大智慧地安立一切法，以法神通、智通、神足通、幻通自在變化充滿一切法界。以此十門為首，滿足百萬阿僧祇大願。佛子！此大願以十盡句而得成就。何等為十？所為：眾生界盡、世界盡、虗空界盡、法界盡、涅槃界盡、佛出現界盡、如來智慧界盡、心所緣界盡、佛智所入境界盡、世間轉法轉智轉界盡。若眾生界盡，我願乃盡；若世界乃至世間轉法轉智轉界盡，我願乃盡。而眾生界不可盡，乃至世間轉法轉智轉界不可盡故，我此大願善根無有窮盡。󱍮

發願已，至心歸命禮本尊毗盧遮那佛。

## No. 1470-A

欽忠義忠藎四川左布政雲南麗陽佛弟子木增，同麗江府知府授參政男木懿應襲，孫木靕暨諸子孫太學生木喬、木參，生員木宿、木櫾、木橒、木、木極、悟樂等，各捐淨捧，延僧命役，敬奉大方廣佛華嚴經三昧懺儀一部，共四十二卷六十一冊，直達南直，隷蘇州府。甞熟懸隱湖南村篤素居士毛鳳苞汲古閣中，鳩良工雕造。起于崇禎庚辰孟夏，終于辛巳春，凡一載功成。今寘此版於浙江嘉興府楞嚴寺藏經閣，祈流通諸四眾，歷劫熏修，見聞此法，永持不捨。所願一乘頓教，徧布人寰，三有羣生，俱明性海者耳。󴊛㮱󴉳

齎經僧係鷄足山悉檀禪寺比丘道源、玄契等。
