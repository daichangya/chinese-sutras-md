宝珠自性广大海，七宝山等最殊胜， /
出兴如斯供养云，诸佛等处我奉献。 /

如来妙色身，色相不思议，见者生欢喜。 /
恭敬信乐法。十方国土海，无量无边佛， /
咸于念念中，各各现神通。大智诸菩萨， /
深入于法海，佛力所加持，能知此方便。 /

十力大雄最无上，譬如虚空无等等， /
境界广大不可量，功德第一超世间， /
十力功德无边量，心意思量所不及， /
人中师子一法门，众生亿劫莫能知， /
十方国土碎为尘，或有数计知其数， /
如来一毛功德量，千万亿劫无能说， /
如人持尺量虚空，复有随行计其数， /
虚空边际不可得，如来境界亦如是。 /
或有能于刹那项，悉知三世众生心， /
设经众生数等劫，不可知佛一念性， /
譬如法界徧一切，不可见取为一切， /
十方境界亦复然，徧于一切非一切。 /

欲具演说一句法，阿僧祇劫无有尽。 /
而令文义各不同，菩萨以此初发心。 /
光中现佛不可说，佛所说法不可说， /
法中妙偈不可说，闻偈得解不可说， /
不可说解念念中，显了真谛不可说， /
示现未来一切佛，常演说法无穷尽。 /
一一佛法不可说，种种清净不可说， /
出妙音声不可说，转正法轮不可说， /
于彼一一法轮中，演修多罗不可说。 /
于彼一一修多罗，分别法门不可说。 /
于彼一一法门中，又说诸法不可说， /
于彼一一诸法中，调伏众生不可说。 /
或复于一毛端处，不可说劫常安住， /
如一毛端余悉然，所住劫数皆如是。 /

菩萨功德无有边，一切妙行皆具足， /
假使无量无边佛，于无量劫说不尽， /
何况世间天及人，一切声闻及缘觉， /
能于无量无边劫，赞叹称扬得究竟。 /
一切众生数易知，三世心量亦可知， /
如是普贤诸佛子，功德边际无能测， /
一毛度空可知边，众刹微尘可数知， /
如是大仙诸仙子，所住行愿无能量， /
十方刹土碎微尘，于一念中不知数， /
毛端度空能知量，亿劫宣扬不能尽。 /

十方一切诸众生，二乘有学及无学， /
一切如来与菩萨，所有功德皆随喜。 /

十方所有世间灯，最初成就菩提者， /
我今一切皆劝请，转于无上妙法轮。 /

诸佛若欲示涅槃，我悉至诚而劝请。 /
惟愿久住刹尘劫，利乐一切诸众生。 /

我随一切如来学，修习普贤圆满行， /
供养过去诸如来，及与现在十方佛， /
未来一切天人师，一切意乐皆圆满， /
我愿普随三世学，速得成就大菩提。 /

所有十方一切刹，广大清净妙庄严， /
众会围遶诸如来，悉在菩提树王下。 /
十方所有诸众生，愿离忧患常安乐， /
获得甚深正法利，灭除烦恼尽无余。 /

所有礼赞供养佛，请佛住世转法轮， /
随喜忏悔诸善根，回向众生及佛道。 /

愿我临欲命终时，尽除一切诸障碍。 /
面见彼佛阿弥陀，即得往生安乐刹。 /
我既往生彼国已，现前成就此大愿， /
一切圆满尽无余，利乐一切众生界。 /
彼佛众会咸清净，我时于胜莲华生， /
亲覩如来无量光，现前授我菩提记。 /
蒙彼如来授记已，化身无数百俱胝， /
智力广大徧十方，普利一切众生界， /
乃至虚空世界尽，众生及业烦恼尽， /
如是一切无尽时，我愿究竟恒无尽。 /

欲求寂灭乐，当学沙门法。衣食计身命， /
精粗随众等，诸众等寅朝，清净记六念。 /

诸行无常，是生灭法；生灭灭已， /
寂灭为乐。

如来证涅槃，永断于生死。若能志心听， /
常得无量乐。

人生不精进，喻若树无根，采华置日中， /
能得几时鲜？华亦不久鲜，色亦非常好。 /
人命如刹那，须臾难可保，是故劝众生， /
勤修无上道。

西方日已暮。尘劳犹未除。老病死时至。 /
相看不久居。念念催年促，犹如少水鱼。 /
劝诸礼佛众，修学至无余。 /

是日已过，命亦随减，如少水鱼。 /
斯有何乐？当勤精通，如救头然。 / 众等
但念无常，慎勿放逸。 /

烦恼深无底。生死海无边。度苦船未立。 /
云何乐睡眠？睡眠当觉悟，摄心恒在禅， /
勇猛勤精进，菩提道自然。 /

比丘汝起起，何以着睡眠？睡眠有何利？ /
病时岂可眠？利刺身时，云何得睡眠？ / 刾
汝今舍家时，出离之所愿，当如其本愿。 /
日日勤精进。

神光迁流转，迄至五更初。无常念念至， /
恒与生死俱，劝诸行道者，修学至无余。 /

世间不牢固，如水沫泡，汝等咸应当。 / 𦦨

仰白十身徧照佛，华藏世界诸如来。 /
娑婆本师释迦尊，普贤文殊诸上首， /
刹海圣众并徒众，华藏会上诸上人， /
释梵诸天众类神，获得他心道眼者， /
竝愿不舍慈悲力，证明我等二众人。 /
为修行愿总持门，时至心同礼忏。 / 某

处世界如虚空，似莲华不着水， /
心清净超于彼，稽首礼无上尊。 /

法性本空寂，无取亦无见，性空即是佛。 /
不可得思量。

若人欲了知，三世一切佛，应观法界性， /
一切惟心造。

一中解无量，无量中解一，了彼互生起。 /
当成无所畏。

若人欲识真空理，身内真如还徧外。 /
情与无情共一体，处处皆同真法界。 /
秪用一念观一境，一切诸境同时会。 /
于一境中一切智，一切智中诸法界， /
一念照入于多劫，一一念劫收一切， /
时处帝网现重重，一切智通无碍。 / 󳬩

清净如虚空，悉庄严世界，现一切众生。 /

宝珠自性广大海，七宝山等最殊胜， /
出兴如斯供养云，诸佛等处我奉献。 /

如来甚深智，普入于法界，能随三世转， /
与世为明导。诸佛同法身，无依无差别， /
随诸众生意，今见佛色形，具足一切智， /
徧知一切法，一切国土中，一切无不见。 /

如来清净妙法身，一切三界无伦匹， /
以出世间言语道，其性非有非无故。 /
虽无所依无不住，虽无不至无不去， /
如空中画梦所见，当依佛体如是观。 /
如于此会见佛座，一切尘中悉如是， /
佛身无去亦无来，所有功德皆明现， /
菩萨住于母胎中，十种最中微细现， /
慈心住天及初生，乃至成道入涅槃， /
广大寂静三摩地，不生不灭无来去， /
严净国土示众生，此树华神之解脱。 /
或现童男童女形，天龙及以阿修罗， /
乃至摩睺罗伽等，随其所乐悉令见。 /
众生形相各不同，行业音声亦无量， /
如是一切皆能现，海印三昧威神力。 /
真如平等无相身，离垢光明净法身， /
慧智寂静无量身，普应十方而演法， /
如来非以相为体，但是无相寂灭法， /
身相威仪悉具足，世间随乐皆得见。 /
如来一一毛孔中，一切刹尘诸佛坐， /
菩萨众会共围绕，演说普贤之胜行。 /
佛以本愿现神通，一切十方无不照， /
如佛往昔修治行，光明网中皆演说， /
或为日月游空中，或作河池井泉水， /
又或变作为地界，又亦能作风及火， /
汝应观佛一毛孔，一切众生悉在中， /
彼亦不来亦不去，此普见王之所了。 /
佛身普徧诸大会，充满法界无穷穷。 /
寂灭无性不可取，为救世间而出现。 /

净修诸佛力，如应入此门。我目甚清净， /
普见十方刹，亦见其中佛，菩提树下坐。 /
相好庄严身，无量众团遶，普念诸如来， /
而亦不分别，了知无量刹，诸根及欲乐。 /

譬如大宝山，饶益诸含识，佛山亦如是。 /
普益于世间。譬如大海水，澄净无垢浊， /
见佛亦如是，能除诸渴爱。譬如须弥山， /
出于大海中；世间灯亦尔，从于法海出。 /
如海具众宝，求者皆满足，无师智亦然。 /
见者悉开悟。如来甚深智，无量无有数， /

示现种种事。佛智亦如是，现诸自在力， /

满诸清净愿。譬如明净宝，普炤一切物， /
佛智亦如是，普炤群生身。譬如八面宝， /
等鉴于诸方，无碍灯亦然，普炤于法界。 /
譬如水清珠，能清诸浊水，见佛亦复然。 /
诸根悉清净。

## 直言赞佛

夫阿弥陀佛者，以实相而为体，用般若而为心。金容荡荡，报身住于净方；妙相巍巍，应化随机所现。众圣围绕，如皎月处于群星；相好端严，似青莲敷于碧沼。毫光散彩，頞珠朗于五山；绀目澄清，眼秀同如四海。大慈大悲，分身三十六万；同名同号，变相九千五百。一日放十二光，接引念佛众生，四十八愿不舍。大悲圣者，寻声救苦于娑婆；势至菩萨，慈心诱接于群品。惟愿弥陀海会圣众，身住华台，心存佛境。善哉圣德，超言思矣。

惟愿十方诸慈尊，我及一切诸有情， /

## 附慈觉忏悔文

某甲等，普及四恩三有，法界众生，法身寿命，本智光明，与阿弥陀佛，同一体性，而无量劫来，不了自心，起惑造业，或不孝父母，不顺师长，残忍无慈，杀生偷盗，不净邪婬，妄言绮语，两舌恶口，及贪嗔痴，十恶炽然，无罪不造，随顺邪师，不信三宝，或破五戒八戒，十戒二十五戒，二百五十戒五百戒，十重四十八轻，三千威仪，八万细行，具足阐提，拨无因果，诽谤大乘方等经典，破人善事，无慈悲心，不肯劝进同梵行者，乃至杀父害母，杀和尚阿阇梨，出佛身血，破羯磨转法轮僧，杀阿罗汉，破塔坏寺，残毁经相，驱役僧徒，或用霸道，侵损现前十方三宝财物，不净说法，污梵行人，如是普于三宝圣众，师长父母，法界众生，造种种罪，或自作教他作，或见作随喜，重重无尽，徧周法界，充塞虚空，今对阿弥陀佛，皆悉忏悔，惟愿阿弥陀佛，威神力故，如汤消氷，应念化成无上智觉。又复阿弥陀佛，四十八愿，怜愍有情，放净光明，摄取不舍，所居极乐，众宝庄严，菩萨往生，永不退转，修行无间，直至菩提，本师释迦牟尼，及十方诸佛，慇懃劝赞，一念乃至十念，一日乃至七日，称名系念，决定往生，我等愚迷，不信不顺，或时闻已，心则轻笑，见念佛人，恶心毁谤。设有信者，无决定心，若存若亡，或进或退，业缘深重，世务牵缠，身在道场，心缘世谛，口谈极乐，意恋娑婆。于念佛时，心多散乱，三种净业，片善无成，十六观心，一时不彻。临命终时，或遭横死，墙崩屋倒，树折嵓摧，水火漂焚，虫伤兽啮，刀兵遽至，毒药伤，卒病临身，不遑念佛。或缠绵重病，苦逼身心，宛转号呼，难安正念。或无善友，助发净因。由是种种罪业因缘，临命终时，不得见佛，不得往生净土，还复流转娑婆五浊恶世。三涂八难，随业受生，五痛五烧，为最极苦，未来生死，无有尽期。或堕胎生金锁之难，五百岁中，不得见佛。此皆从昔以来，不信阿弥陀佛，不信往生净土，身口意业，轻慢毁谤。以是因缘，虽复发心，多诸障难。我今稽首阿弥陀佛，惟愿天眼见我，天耳闻我，他心见我，大慈大悲，哀愍摄受，听我忏悔，令我普及四恩三有。法界众生，罪障、业障、烦恼障、所知障、不信佛言障、懒堕修行障、三涂长夜障、五浊恶世障、边地疑惑障、不闻三宝障，凡是往生一毫之障，悉愿消除，一切清净，正信现前，不疑不退，决定往生极乐世界，速成正觉，转大法轮，圆满广大行愿。㬥

愿弟子普及四恩、三有法界众生，从今已去，住第一义谛，修佛净业正因，孝养父母，奉侍师长，慈心不杀，修十善业，受持三归，具足众戒，不犯威仪，发菩提心，深信因果，读诵大乘，劝净行者，念佛、念法、念僧、念戒、念施、念第一义天，以至诚心、深心，回向发愿心，称佛名号，赞佛名号，赞佛光明，观佛依正十六妙境，念佛本起四十八愿，筹量三辈，深入五门，随顺三种菩提门，信受十方诸佛教，或以散心、定心。惟愿阿弥陀佛法力宜加，神通显益，令我等凝神觉路，暗蹈大方，进止威仪，不离见佛，如执明镜，自见面像，及于梦中，常见彼国众妙乐事，安慰我心，令生增进，哀愍覆护，法种增长，承佛威神，远离魔事。又复无量劫来，业惑尘劳，皆为梵行，善根功德，同入大因，积集诸缘，尽用回向。临命终时，无诸障难，七日已前，预知时至，身无痛苦，心不颠倒，身心安乐，如入禅定。遇善知识，教存十念，阿弥陀佛与诸圣众现在其前，放大光明，授手迎接，自见其身乘金刚台，随从佛后，如弹指顷。往生彼国已，见佛色身众相具足，见诸菩萨色相具足，光明宝林演说妙法，闻已即悟无生法忍，身真金色，等无差别，三十二相，六通自在，具大辩才，演一切智，那罗延身，寿命无量，供养如意，妙服自然，不闻恶名，不着身见，诸上善人俱会一处，住正定聚，永不退还，究竟至于一生补处，受用清净大乘法乐。昼夜六时，供养阿弥陀佛，每日清旦，奉事十方如来，闻法授记，得陀罗尼，化身自在，周遍十方无佛国中，成等正觉，极重苦处，游戏神通，随众生心，应所知量，对现色相，昼夜说法，无有休息。于念念中，令不可说不可说众生发菩提心；于念念中，令不可说不可说众生住普贤行，福德资粮悉得圆满，同成无上正等菩提，各各庄严净土，各各摄化众生，如阿弥陀佛等无有异。惟愿阿弥陀佛慈悲证盟！

## 初西域流传华严诸师

夫龙树菩萨者，本是妙云相佛示迹初地位中，是南印土梵之种也。家豪富贵，幼年聪利，超越无伦，生一切智，解四韦陀，天文地理，星历占记，诸般幻术，无不了解，五国名称，齅香知药，悟欲苦本，速发誓愿。九十日中，五印土所有经文，悉皆记之，开说义理，辩如流水，自谓一切智人，住水晶宫。大龙树菩萨觉知彼故，以神力召至于海，开七宝藏库，示方广经。见此大不思议经，有其三品：上本经者，有十三千大千世界极微尘数偈，一四天下极微尘数品；其中本经者，有四十九万八千八百偈，一千二百品；下本经者，有十万偈，三十九品。龙树诵之，流传世间。得下本已，皎洁慧日，照于第一义天；运檝慈舟，游于真如性海。契三十二之法，纂集诸经，造大不思议论，具十万偈，广传西域。集大乘无相空之教，造十地论五百之偈，大庄严佛道论、大悲方便论各五十颂，无畏论十万偈，摩诃衍释论十卷，大智度论百卷，其名一切智人。我今众等，礼赞功德，所获善根，回向一切众生海，愿皆永离缠葢，速悟菩提。

## 次八万四千惑业忏悔

惟愿帝网无尽，佛法僧宝，毗卢遮那如来，普贤文殊，海会圣众，世出世神，慈悲本愿，放大光明，炤于法会，证明护念，衰悯摄受。愿我及一切众生海，自从无始，直至今时，业海无尽，帝网重重，一切惑业，发露忏悔。夫性相诸宗中，有八万四千法门，八万四千功德，八万四千烦恼，八万四千十恶业。今末浊时至，人人造不善业，各各作恶无悔，由此怨魔外道，破灭正法。其八万四千烦恼，有二种释：一者众生根本烦恼：一贪，二瞋，三慢，四无明，五疑，六身见，七边见，八邪见，九见取，十戒禁取。然一惑力，复各有十，即为一百，应分九品。但上品重故，开为三品，中下轻故，各为一品，合为五百。于自五尘，总起五百，于他五尘，总起五百，各本一千。又有自他五尘，一一各别起五百为五千，别迷苦谛五千，别迷集谛五千，别迷灭谛五千，别迷道谛五千，如是别迷四谛为二万，并本一千为二万一千。又依贪行多者，二万一千；依瞋行多者，二万一千；依痴行多者，二万一千；依等分多者，二万一千，总成八万四千。二者、以十恶为境，渐渐相成，一一各成十为一百，迷自他五尘成一千。于十谛法门迷者，其四谛、三谛、二谛、一谛是也。若迷故，说为谛等十谛。惑迷十善，即成一万。今迷十谛，空有不同，分为二万。或云迷十善二谛，分为二万，及本一千，如余经说。如是等法界帝网，惑海、业海重重无尽。若欲发露忏悔，当识逆顺十心。

天台摩诃止观云：若欲忏悔二世重障，当识顺流十心。明知过失，当运逆流十心，以为对治。此二十心，通为诸忏之本。顺流十心者：一、自从无始，阇识昏迷，烦恼所醉，妄计人我。计人我故，起于身见。身见故，妄想颠倒。颠倒故，起贪嗔痴。贪嗔痴故，广造诸业。业则流转生死。二者、内具烦恼，外值恶友，扇动邪法，劝惑我心，倍加隆盛。三者、内外恶缘既具，能内灭善心，外灭善事，又于他善都无随喜。四者、纵恣三业，无恶不为。五者、事虽不广，恶心徧布。六者、恶心相续，昼夜不断。七者、覆讳过失，不欲人知。八者、鲁扈抵突，不畏恶道。九者、无慙无愧。十者、拨无因果，作一阐提。是为十种顺生死流。昏倒造恶，厕虫乐厕，不觉不知，积集重累，不可称计。四重五逆，极至阐提，生死浩然，而无际畔。今欲忏悔，应当逆此罪流，用十种心，翻除恶法。一者、先正信因果。决定孱然，业种虽久，久不败亡，终无自作。他人受果，精识善恶，不生疑惑，是为深信，翻破一阐提心。二者、自愧尅责。鄙极罪人，无羞无耻，习畜生法，弃舍白净，第一庄严。咄哉无钩，造斯重罪。天见我屏罪，是故惭天。人知我显罪，是故愧人。以此翻破无慙无愧心。三者、怖畏恶道。人命无常，一息不返，千载长往。幽途绵邈，无有资粮；苦海悠深，船栰安寄？贤圣呵弃，无所恃怙。年事稍去，风刀不奢，岂可晏然坐待酸痛？譬如野干，失耳尾牙，诈眠望脱，忽闻断头，心大惊怖。遭生老病，尚不为急，死事弗奢，那得不怖？怖心起时，如履汤火，五尘六欲，不暇贪染。如阿输柯王，闻旃陀罗朝朝振铃，一日已尽，六日当死。虽有五欲，无一念爱。行者怖畏苦到，忏悔不惜身命，如彼野干；决绝无所思念，如彼怖王。以此翻破不畏恶道心。四者、当发露。莫覆瑕疵，贼毒恶草，急须除之。根露条枯，源干流竭。若覆藏罪，是不良人。迦叶头陀令大众中发露，方等令向一人发露。其余行法，但以实心向佛像改革。如阴隐有痈，覆讳不治则死。以此翻破覆藏罪心也。五、断相续心者。若决果断奠毕，故不造新，乃是忏悔。忏已更作者，如王法初犯得原，更作则重；初入道场，罪则易灭，更作难除。已能吐之，云何更噉？以此翻破常念恶事心。六者、发菩提心。昔自安危人，遍恼一切境；今广起兼济，遍虚空界，利益于他。用此翻破徧一切处起恶心也。七修功补过者，昔三业作罪，不计昼夜。今善身口意，筞励不休，非移山岳，安填江海。以此翻破纵恣三业心。八守护正法者，昔自灭善，亦灭他善，不自随喜，亦不喜他。今守护诸善，方便增广，不令断绝，辟如全城之勋。胜鬘云：守护正法，摄受正法，最为第一。以此翻破无随喜心。九念十方佛者，昔亲狎恶友，信受其言。今念十方佛，念无碍慈，作不请友，念无碍智，作大导师。翻破顺恶友心。十观罪性空者，了达贪欲嗔痴之心，皆是寂静门。何以故？贪嗔若起，在何处住？知此贪瞋，住于妄念，妄念住于颠倒，颠倒住于身见，身见住于我见，我见则无住处。十方谛求，我不可得。我心自空，罪福无主。深达罪福相，徧照于十方，令此空慧，与心相应。譬如日出时，朝露一时失。一切诸心，皆是寂静门，示寂静故。以此翻破无明昏暗。是为十种忏悔，顺涅槃道，逆生死流，能灭四重五逆之过。若不解此十心，全不识是非，云何忏悔？设入道场，徒为苦行，终无大益。涅槃云：若言勤修苦行，是大涅槃，近因缘者，无有是处。即此意也。是名忏悔事中重罪也。

次忏见罪者，以见惑故，顺生死流，如前所说。向运十心，附事为忏，忏钝使罪。今扶理忏见，忏利使罪。然见心猛威，起重烦恼，应傍用事助。如服下药，须加巴豆，令黈泻尽底。是故还约十法，以明忏见。一、翻破不信者，即点身见心，令识无明苦集。如头篮弗，得非想定，世人崇之。如佛不识苦集报尽，还堕须陀罗，得非想定。虽无麁想，有细烦恼，长爪利智，而受不受，高着外道，尚未出见，非是涅槃。况浅者，尚不逮篮弗，而言是真道，岂非大僻？是人爱着观空智慧，是事不知，名为无明，而起违从，依见造行。见行依色，即是名色，名色即是苦等。迷苦起于爱有，有生未来生死，流转相续，岂是寂灭？若谓生死尽者，乃是慢语。呼无明见心为道，非道为道，非因计因，名为戒取，岂非因盗？呼未来三途苦报为涅槃，此是见取，非果计果，是为果盗。身边邪见，其事可知。如此见心，乃是苦集，非灭道也。尚非三藏道灭，岂是摩诃衍道灭？若能如是，即知世间因果，复识出世因果。故大品云：般若能示世间相，所谓示是道非道。是为深识见心苦集也。又深者，非但知无明苦集，亦识三藏因果，亦识因缘生法即空四谛因果。又复深者，亦知因缘即假无量四谛因果。又复深者，亦知因缘即中无作四谛因果，于一见心具识一切因果。故大经云：于一念心悉能称量无量生死，是名不可思议。故名深信破不信也。二、生重慙愧者，不见我心中三谛之理，名慙愧。且约理观论人天者，慙干慧性地之人，愧四果净天、三十心人、十地义天、五品六根清净之人、四十二位天。例如作意得报名为人，自然果报名为天。二种天人亦复如是，方便道名为人，真理显名为天。见心造罪，覆三谛理，不逮三种人天，是故慙愧，翻破无慙愧心也。三、怖畏者，知见心造罪，此过深重。大论云：诸佛说空义，为离诸见故，若复见有空，诸佛所不化。我今由见而起大罪，此间劫尽，他方狱生，此间劫成，还来此处，如是展转，无量无边。若说果报，所受之身当吐热血死。故知见罪大重，既非无漏，不出生死，烦恼润业，堕落何疑？一命不追，永无出日。为是义故，生大怖畏，翻破不畏恶道心也。四、发露者，从来诸见而生爱着，覆此三谛，不能决定生信。今知见过失，发却三疑，无所隐讳，显其谛性，是为发露，翻破覆藏罪心也。五、断相续心者，三谛之观，勿令有间，以八正道治三惑心，断而不习，此翻破相续恶心也。六、发菩提心者，即是缘三谛理，皆如虚空，空则无边，愍伤一切，普令度脱。昔迷此起惑，有无边故，罪亦无边。今菩提心徧于法界，起无作善，亦徧法界，翻破昔徧空无作恶也。奏师子琴，余弦断绝，即此义也。七、修功补过者，三谛道品即是菩萨宝炬陀罗尼，是行道法，趣涅槃门。如此道品，念念相续，即是修功补过。昔执于见，谓为涅槃，于见不动，不修道品。设令动有入无，如屈步虫，虽于见动，亦不能修道品。今知有无是见，不执为实，是名见动而不修道品。若破柝诸见，行于道品，是名见动而修道品。又体见即空、即假、即中，既言即者，于见不动而修三种道品，是为修功补于纵见之过也。八、守护正法者，昔护见，不令他破，方便申通。今护三谛诸空，不令见破，若有留滞，善巧申弘。亡身存法，犹如父母守赞其子，此翻破毁善事也。九、念十方佛者，昔服见毒，常无厌足，如渴思饮。又遇恶师，如加以咸水，以苦舍苦。我慢矜高，谄心不实，于千万亿劫不闻佛名字。今念三谛，不来不去即是佛，无生法即是佛，常为谛理所护，此翻破狎恶友心。十、观罪性空者，此三种惑，本来寂静，而我不了，妄谓是非，如热病人见诸龙鬼。今观见如幻如化，来无所从，去无足迹，亦复不至东西南北，一切罪福亦复如是。一空一切空，空即罪性，罪性即空，此翻破颠倒心也。运此十忏时，深观三谛，又加事法，以慇重心，不惜身命，名第二健儿，是名事理两忏。󳬂䟦󱍮

我等为无明所覆，不识惑业罪因，今遇道场，方始觉知。归命毗卢遮那如来，及一切贤圣海众，烧香散华，一切惑业，发露忏悔，不敢覆藏。由此因缘，我及法界众生海，帝网重重，一切惑业海，愿皆清净。

## 至心发愿

十地经云：佛子！菩萨发如是大愿，所谓：生广大清净，决定了解，以一切供养之具，恭敬供养一切诸佛，令无有余。又愿受一切佛法轮，愿摄一切佛菩提，愿护一切诸佛教，愿持一切诸佛法。又愿一切世界，佛兴于世，从兜率天宫殁、入胎、初生、出家、成道、说法、示现涅槃，皆悉往诣，亲近供养，为众上首，受行正法，于一切处、一切时而转。又愿一切菩萨行，广大无量，不坏不杂，摄诸波罗蜜，净治诸地，总相、别相、同相、异相、成相、坏相，所有菩萨行，皆如实说，教化一切，令其受行，心得增长。又愿一切众生界，有色、无色，有想、无想，非有想、非无想，卵生、胎生、湿生、化生，三界所系，入于六趣一切生处，名色所摄，如是等类，我皆教化，令入佛法，令永断一切世间处，令安住一切智道。又愿一切世间，广大无量，细乱想，倒住正住，若入、若行、若去，如帝网差别，十方无量种种不同，智皆明了，现前知见。又愿一切国土入一国土，一国土入一切国土，无量佛土普皆清净，光明众具以为庄严，离一切烦恼，成就清凉道，无量智慧众生充满其中，普入大愿诸佛境界，随诸众生心而为示现，皆令欢喜。又愿与一切菩萨同一志行，无有怨嫉，集诸善根，一切菩萨平等一缘，常共集会，不相舍离，随意能现种种佛心，住其自心，能知一切如来境界威力智慧；得不退转如意神通，游行一切世界，现形一切众会，普入一切生住，成就不思议大乘，修菩萨行。又愿成不退转行菩提行，身、语、意业悉不唐损，若暂见者则必定入法，暂闻音声则得真实智慧，才生净信则永断烦恼；得如是大药王树身，得如意宝身，修行一切菩萨行。又愿于一切世界成阿耨多罗三藐三菩提不离一毛端处，于一切毛端处皆悉示现初生、出家、诣道场、成正觉、转法轮、入涅槃；得佛境界大智慧力，于念念中随一切众生心示现成佛，念得寂灭；以一三菩提知一切法界即涅槃相，以一音说法令一切众生心皆欢喜；示入大涅槃而不断菩萨行，示大智慧地安立一切法，以法神通、智通、神足通、幻通自在变化充满一切法界。以此十门为首，满足百万阿僧祇大愿。佛子！此大愿以十尽句而得成就。何等为十？所为：众生界尽、世界尽、虚空界尽、法界尽、涅槃界尽、佛出现界尽、如来智慧界尽、心所缘界尽、佛智所入境界尽、世间转法转智转界尽。若众生界尽，我愿乃尽；若世界乃至世间转法转智转界尽，我愿乃尽。而众生界不可尽，乃至世间转法转智转界不可尽故，我此大愿善根无有穷尽。󱍮

发愿已，至心归命礼本尊毗卢遮那佛。

愿我临欲命终时，尽除一切诸障碍。 /
面见彼佛阿弥陀，即得往生安乐刹。 /

轮回三界中，犹如汲井轮，又如蚕作茧， /
茧成自缠缚。无上诸世尊，圆觉声闻众， /
尚舍无常身，何况诸凡夫，父母及妻子？ /
兄弟并眷属，目观生死急，云何不愁叹？ /
是故劝诸人，谛听真实法，共舍无常处。 /
常行不死门。

惟愿法界七处会，哀愍忆念众生海， /
主伴道场佛会处，虽作忏悔之法事， /
我等所作不堪量，若或错失或颠倒， /
不办不具或余剩，恐成杂乱之善根。 /
道场佛会慈悲力，又百字呪真谛力， /
所忏罪海愿清净，所作法行令圆满。 /

我等凡愚福力微，未得正念意浊乱， /
种种不具供养劣，忘失杂乱不称理， /
愿承三宝同体慈，摄受善根愿令成。 /
缘性圆融称法界，普贤行愿愿圆满。 /

仰白十身遍照佛，华藏世界诸如来。 /
娑婆本师释迦尊，普贤文殊诸上首， /
刹海圣众并徒众，华藏会上诸上人， /
释梵诸天众类神，获得他心道眼者， /
竝愿不舍慈悲力，证明我等二众人。 /
为修行愿总持门，某时至心同礼忏。 /

## 启白圣贤

所生功德，总用庄严法界。刹海众生，当愿天仙不坠，悟着乐而非常。国土清平，识真乘而是胜。群僚常居禄位，皆欣圆顿教门。人民永保安宁，咸修觉照之道。师僧父母，福庆汪洋。信施檀那，万行圆满。三途俱时离苦，八难竝悉消除。镬汤变为清凉池，铁床变作莲华座。息悲痛之响，同念佛之音。人人有返本之心，各各悉还源之照。常发今愿，当愿俱不退心。观行令成，同证华严海会，为上良缘。
