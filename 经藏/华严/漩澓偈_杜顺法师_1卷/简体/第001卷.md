# 漩澓偈 · 第一卷

> 杜顺法师造

---

若人欲识真空理身内真如还遍外 /
情与非情共一体处处皆同真法界 /
不离幻色即见空即此真如含一切 /
一念照入于多刧一一念刧收一切 /
于一境内一切智于一智中诸境界 /
秖用一念观诸境一切诸境同时会 /
时处帝网现重重一切智通无 / 𦊱㝵

真空不动智凡圣本来同虽为万有体曾无起作功

真如无作性亘等虚空岂如浮沤质出没在海中󳇐

无情无自性性体发于真顿现如镜像谁作自他身

智现情无心通事岂妨事理融无二何处非道场㝵

幻性本无宗根尘结色空了尘无自性一切法皆同

绝念超情识如镜照十方万像斯顿现那假在思量

譬如一镜鉴十方十方一一镜皆同 /
无心镜照古今九世重重相容㝵󲒠 /

心为万法宗万法一心通毛端一滴海一切海皆同 /

一一万法体同空一一虚空相容 / 󲒠
一海鱼龙尚无尽一切海中多少龙 /

三际无思理等空空中何法不含容 /
一智万差融事理尘尘刹刹普皆同 /

寂用系兴帝网宗一尘才举十方通 /
六相十玄融斯理主伴交暎重重 / 󲒠

尊从悲智起文殊海一沤片言通帝网漩澓显深幽
一心圆顿备十重万行周无边花藏界摄在一毛头
