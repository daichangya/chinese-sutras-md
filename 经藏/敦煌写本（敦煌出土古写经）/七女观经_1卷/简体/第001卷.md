# 七女观经 · 第一卷

---

## 1

闻如是。一时佛说七女观经。昔冥缘王有七女觉世非常。不着缯彩衣服。不着指镮臂钏。不捉香油涂身。岁三长斋月六斋。姊妹相将诣父王殿前。稽首白王。女等前身积罪无福。今值女身处。其深宫眼无所见。求王放女出城游观。王告女言。我作天下之文万基之主。有苑园浴地华台楼观。亦可观之。何用出城观乎。女对王曰。虽有苑园浴池华台楼观。可悦乐耳。非女游观之处。王即听之。出城东门。到其冢间。见一死尸。膖胀烂臭。狐狼践蹹。形骸异处。姊妹相将。遶尸三匝。涕零号泣。我等女身会当如是。姊妹七人各说一偈言。

第一女说偈言。

第七女说偈言。

第四忉利天王从天来下。到诸女前。问女言。汝等何所求欲使汝得之。诸女良久不答。复问女言。汝等何所求欲使汝得之。一女言乞愿无根无须无枝无叶。于其中生是则为乐。一女复愿。常无五欲。常处寂静。耳飡法音。目覩圣教。是则为乐。一女复愿。幽幽冥冥犹如虚空。登愿玄觉。常覩圣容。是则为乐。天帝语诸女言。止止。汝之所愿无想。吾不能得日月中王使汝得之。于是七女皆得道果。

企视鹅容步姿则欲入居 /
□死弃冢间禽兽竞共疽 /
一切皆如是何用于世殊 /

譬如一身居人去宅无光 /
身死如神誓乃知此非常 /
今覩死尸观忽然遇犲狼 /
一切皆如是安得有久长 /

譬如马驾车车破而马去 /
四大解散时魂神依何住 /
初集四大时来从何所处 /
乃知此非常唯福可恃怙 /

譬如好城墎众人乐安居 /
所求未厌足何其忽空虚 /
人命如草木春长冬以枯 /
唯有修福德智慧随身躯 /

人之不修福譬如乘船渡 /
四大乖离时如船舍岸去 /
地定风不动火微水还故 /
身非神常宅安得久长处 /

如人好庄严形着诸缯彩 /
自纵取时荣故使欲人待 /
侹然不动摇其神安所在 /
观世冢间尸将来宜应改 /

如雀在瓶中罗縠覆其口 /
縠穿雀飞去神明随所受 /
四大和合时如雀瓶中有 /
唯有修善福智慧随身首 /
