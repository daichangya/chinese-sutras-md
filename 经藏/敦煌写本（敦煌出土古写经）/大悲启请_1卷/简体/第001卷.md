## 1

大悲启请。准经凡欲受持。先志心念阿弥陀佛三遍缘。阿弥陀佛是观音本师矣

仰启月轮观自在广大圆满紫金身 /
千臂恒伸现世间千眼光明常遍照 /
一千二百真言契能满众生所愿心 /
面安三目遍庄严顶戴弥陀持宝器 /
宣赞真言微妙法受持当证佛菩提 /
辩才无碍化人天菩萨众中为上首 /
暂闻尚灭尘沙业讽念惟增成佛因 /
大悲愿力不思议是故我今恒赞念 /
南无大悲观世音愿我速知一切法 /
南无大悲观世音愿我早得智慧眼 /
南无大悲观世音愿我速度一切众 /
南无大悲观世音愿我早得善方便 /
南无大悲观世音愿我速乘般若舡 /
南无大悲观世音愿我早得越苦海 /
南无大悲观世音愿我速得戒定道 /
南无大悲观世音愿我早登涅槃山 /
南无大悲观世音愿我速会无为舍 /
南无大悲观世音愿我早同法性身 /

我若向刀山刀山自摧折
我若向火汤火汤自消灭
我若向地狱地狱自枯渴
我若向饿鬼饿鬼自饱满
我若向修罗恶心自调伏
我若向畜生自得大智慧
