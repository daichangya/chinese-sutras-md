# 菩萨名经 · 第十卷

> 宋 罗濬集

---

我闻如来声世间颇难遇 /
斯言若真实当赐汝衣服 /
若彼佛世尊为利世间现 /
必应见哀愍令我覩真相 /
言念湏顷佛放虚空中󱅨 /
现不思议身普放大光明 /
胜鬘及眷属皆悉来集会 /
合掌瞻仰礼称叹大导师 /
如来妙色身世间无与等 /
无比不思议是故今敬礼 /
如来色无尽智慧亦复然 /
一切法常住是故我皈依 /
善调心过及与身四种𢙣 /
到不思议地是故今谨礼 /
知诸法炎智身无碍𠇍𦊱 /
于法无忘失故我今谨礼 /
稽首过称量稽首无等伦 /
稽首法自在稽首超思惟 /
哀愍覆护我及法种增长 /
逮及最后身当在如来前 /
我所有福业今世及余生 /
由斯善根力佛当摄受 / 󷃷

## 菩󴅽名经序后

古之学道无自虚空入者道不可以虚空入则佛书之传写可已耶此大藏之积所以警悟后来而世人能于经中求入古佛至处譬如乘舡入海扶杖登途岂有不遂其所徃哉不轻居士愍其卷柣繁委牵尘涉世之人不能尽览于是编集诸圣名号毗卢人天森罗眼界覩其文者能生十地之心回是想者克证应真之果辟支利智亦莫不然率天下之人懽喜踊跃共作龙华上客其利岂不哉輙书一二以附其后。󳑧
