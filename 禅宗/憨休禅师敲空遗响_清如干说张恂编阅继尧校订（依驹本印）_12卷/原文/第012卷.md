曹谿正脈，南嶽稱雄，馬駒待識，崛起蠶叢。降蹋蹴，血染腥風，樹有臨濟，獨冠五宗。世系相承，遞亙太白，有般孫子，丕顯風穴。縱鐵牛機，振興家園，壁立萬仞，聲光烜赫。十坐道場，興善其一，八水生春，宗壇路關。人天改觀，如晦遇日，虎驟龍驤，機圓用疾。刀握王庫，紫電青霜，鼓擊塗毒，聞者喪亡。山低華嶽，瑞騰五岡，心燈炳炳、慧燄煌煌。乾坤道大、日月輝增，信衣遺藏，法重真乘。永奠宗社，木直從繩，一錐卓立，霞蔚雲蒸。孤光不滅，薪盡火傳，芥城劫石，虛空寧遷？林谷有，此則不然，稽首再拜，昭億萬年。

一花現瑞、兩桂垂陰，聯芳五葉，各紹門庭。 /
洞上真源，機貴回互，夜半正明，天曉不露。 /
苗蕃弁嶽，崛起青龍，川僧藞苴，獨振綱宗。 /
九月楊飛，寒冰燄結，機疾用圓，罕能湊泊。 /
梭騰化璧，穎脫襄錐，青蛇匣吼，白額岩威。 /
四海英賢，雲奔水赴；名公鉅卿，傾誠外護。 /
應機接物，指示隨方，當臺明鏡，不隱妍媸。 /
道播寰區、聲馳湖海，忘己為人，大功不宰。 /
風回洞上，不愧盧能，泥牛海吼、木馬空騰。 /
砥柱狂瀾，顛扶末運，緇白皈心，人天恭敬。 /
忘功罷業，休老林泉，身心寂靜，樂我大年。 /
四眾忻慕，預謀其法，祝師永永，建茲壽塔。 /
一錐無縫、八面玲瓏，天龍守衛，神鬼欽崇。 /
爰勒銘詩，來學仰止，壽量虛空，何終何始？ /

南山巍巍兮，若形儀之軒昂；渭水湯湯兮，若法乳之源長。道尊為眾歸兮，又何在乎開堂；德重能韜光兮，似大梅之智常。宗社方引領以屬望兮，為法門之棟梁；胡報緣之忽盡兮，早趨順乎寂場？自古佛祖有來必往兮，嗤俗子之悲傷；適草木之零落兮，迺藏真于五崗。庸詎知夫法身之不滅兮，樹松柏之蒼蒼？若斯人之道全德備兮，宜刊石以表彰；使千秋萬世兮，與日月以爭光；我誌其行實兮，貽後哲之來詳。

有大比丘，法門龍象，氣宇昂藏，學窮三藏。 /
嚴淨毗尼，師心宗匠，悟法皆空，知心是妄。 /
扶豎法幢，宗猷毗贊，痛耐鉗錘，老當益壯。 /
迥脫羅籠，幾曾血戰？時節到來，草鞋跟斷。 /
復命歸根，徹證無上，我作銘詩，千載炳煥。 /

異人傑出自慶陽，兄弟相從叩大方。本來面目詰獅王，虛空落地絕承當。倒轉蘆航返故鄉，潛行密運茲韜光。淵默雷聲難覆藏，緇白為之盡心降。重建古剎道之傍，胡為趨寂示無常？窣堵嵬然聳穹蒼，嵯峨峰五涇水長。銘詩我作清乃彰，劫石可消誌不忘。

生死機關，只在一竅，半生參勤，已得其要。 /
泥牛哮吼，虛空發笑，撒手歸來，尚能明妙。 /
書偈臨行，得真實效，劖銘金石，靈光永耀。 /

山川鍾英，秀毓斯人，緣生淝水、幻跡西秦。 /
六岔路口，粥有飯有，普濟為心，能歇狂走。 /
二十年來，舊店新開，繼志述事，公其人哉！ /
道行超卓，忘身為物，不著我人，化洽泰國。 /
四眾皈心，瞻彼慈仁，忽爾示寂，兔晦烏沉。 /
公真鐵漢，回頭是岸，裂破虛空，泥牛血濺。 /
撒手便行，夜半正明，歸根葉落，無滅無生。 /
一錐永耐，真光常在，劫火洞然，此塔不壞。 /

道運竺乾、法流東震，五葉彌芳，臨濟獨盛。 /
西有偉人，妙契天真，九苞威鳳、一角祥麟。 /
惜霜志久，幻緣非偶，木馬奔騰、鐵牛哮吼。 /
踏破虛空，無縫是崇，靈光炳耀，千古宗風。 /

歸去來兮！空門有路胡不歸？既覺塵勞之役役，奚躊躇而自悲？昔迴途之選佛，有丹霞之可追。遭逆冠之兇慘，悟夙業之隙非。出網鹿於三跳，投簪髮而緇衣。詢出世之奧論，探離言之旨微。乃聸梵宇，快意如奔，金繩界道，無上法門。詩書遐棄，貝葉唯存，公叔交絕，文舉空樽。習鐘魚以結課，慕拈花以破顏；瞻高車之易殆，思下乘以休安。披林花之馥郁，聽鳥語之關關；了世味如嚼蠟，破蕉鹿之夢觀。遠塵器之俗慮，絕人事之往還；蔭法雲於金地，嗅薝蔔而盤桓。歸去來兮！割恩愛以長遊，憶泰火之灰燼，縱富貴兮焉求？雖情華之初遣，惟養母以解憂。承菽水於歡膝，歌採芝於雲疇。疑弓息影，固壑藏舟。墮亡羊於岐路，悔類狐而首丘。無前知之明哲，愧飲牛之上流。信萬法之皆空，故事事而心休。已矣乎！奔出火宅今其時，如鳥脫籠不可留，胡為乎倉卒欲何之？唐虞不可見、成康未可期。刻遠公之蓮漏，種山芋而日籽。掩松龕以息慮，坐壁觀而捐詩。要唯人而自肯，意決志定復何疑？

歸去來兮！終南深處我將歸。瞻高霞之孤映，唯猿鶴之嘯悲。雖亮公之已往，其志尚之可追。感年華之易邁，嗟人世而日非。杖稜稜以導步，艸曳曳而牽衣。間幻住之斯寄，插莖艸於翠微。萬峰環拱，勢簇如奔，依山鑿徑，編槲為門。沙泉石井，古蹟猶存，鹿豖同飲，如公大樽。偕野鳥以適性，對山花以開顏。步平林以遊戲，臥衡茅以身安。美維摩之一默，妙黃龍之三關。問浮漚以寧識，常斂目而內觀。喜諸緣之頓息，獲寶所而追還；審齊物於吹萬，共樵叟以盤桓。歸去來兮！請息肩以遨遊。矧道本於無言，在學者之反求，奈迷頭之狂走，肯歇心不忘憂。漸風趨以日下，宜罷釣以歸疇。騰騰任運，如不繫舟。愧無補於宗社，特委質於林丘。當正法之凌替，悲濫觴之橫流，苟新條之有在，卒東風其未休。已矣乎！終南歸去正其時，如鯤徒化豈能留？胡為乎！汲汲將何之？龍華今尚遠，人壽難可期。雖異苗之蕃茂，固靈根以培籽。止溪流之菜葉，誦天龍之隱詩。倘燈傳之無盡樂，夫我淨復何疑？

法流東注，碧眼西來，一花始綻、五葉弘開。叢席碁布，宇內彌該，偏汝墳之毓秀，擅靈嶽之崔嵬。道樹冠神州而卓犖，石壁灑藻瀚以雄才。稱偉觀於天中，列輿紀而最推。維彼風穴、近接嵩高，深邃叵測，怒吼驚虓。先聞有聲，風起林稍。噓兩間之元氣，鼓萬物而炰烋。山鬼嘯而助響，艸木震以長號。艮維坤向，利創隋朝，運當五季，錫駐延沼。乘夙願兮非偶，投簪兮緇袍。應懸識兮是止，於傍陬兮縛茅。苦單丁兮七載，與百廢兮一朝。弘濟宗兮大振，繩祖武兮獨超。應真輩出，香火斯饒。山則嵂崒，千峰插天半之芙蓉；水則潺湲，雙澗繞十里之幽松。孤嶂列屏兮擬匡廬之雲錦，嵐亭疊翠兮記孟陽之詞宗。慈泉濟亢兮觀音變相，古洞窈窕兮哲士遺蹤。仙人橋畔兮想飛化龍之竹，望州亭際兮思齊洗耳之風。一徑高危兮紆盤白雲之頂，中峰峻極兮縹緲紫微之宮。石狀瓊臺而峭拔，巖嵌法洞以玲瓏。乃苦西巒蓊臠、東嶺巃嵷，雙峰環抱、萬柏蒼蔥，彷彿清虛之上；徘徊翠微之中。瀑瀉珠簾，寒飛千尺之雪；橋橫玉帶，勢吞萬丈之虹。綠竹凌霄，梴廉憲之高節；清流開沼，振太史之詞鋒。層臺翫月兮識盈虛之有數，重崖登眺兮覺宇宙之無窮。毘盧千尋兮任餐霞而浴日，聲聞五百兮隨馴虎以降龍。鐸振丹霄，壇豎開元之塔；閣聳青漢，鯨鳴寬和之鐘。壯金庭而增麗，對寶藏以飛雄。璑騰輝周玉，鐫牟尼之玉像；鏐散彩錦軸，懸水陸之金容。再瞻殿宇，榱桷輪囷；嵯峨林表，璀璨凌雲。豐碑記載歷朝志文，庭柯交蔭薝蔔氤氳。說法堂前，檜附凌霄之藻；飯田谷口，歲儲綠野之耘。廟祀玄天，星旗將溪光而閃爍；庵曰自在，祖塔下花雨而繽紛。甲中原之巨剎兮少林猶讓其左，傳五燈之慧燄兮風穴特萃其群。慨夫！玄黃易位、滄桑變更；緇侶寥寂、佛面蒙塵。會際鼎輩，祖道維新；席虛誰尸，蜀伯有陳。傳通玄林野之法胤，系天童密雲之嫡孫。本淵源於麟湖，受付囑於棲真。一杖飄然兮北邁，七坐名藍兮軼倫。是宜中州之應響，辛茲汝海以垂綸。搢紳曲垂而加護，緇素徑筏以歸仁。挽滹沱三十一世頹流之脈，繼沼師七百餘年無盡之燈。羨祖庭恢復於今日，冀曇華永茂乎千春。吁嗟兮法幢崛起，祖葉彌芳，鳳毛麟角、虎驟龍驤。英才之濟濟，發嫩桂之昌昌。拓舊模以廣大，俾宗社而益長。法化昭於日月，聲光齊乎天壤。第見此山亙恒沙浩劫而不朽兮！又何殊乎鷲嶺之與鴈堂？

慈悲觀世音，曼殊室利智，大行普賢王，一三三即一。譬如一缽水，而調諸眾味，鹹酸雖有異，濕性元不別。慈憫救世間，普施無礙法，各隨心所求，感之即來應。凡有所求者，端心歸一處，隨處若無心，所用無不是。

最妙吉祥，甚為希有，持逼如來，作獅子吼。鏡智大圓，藏身北斗，七佛曾師，拜讚稽首。

腳底洪濤撼碧空，柳頭甘露灑群蒙，慈容印現千江月，落落圓音紫竹風。

凝神而非定也，怡情而非笑也，經云觀自在，於斯蓋可想見，此豈菩薩也哉？

目無旁視，耳無旁聽，儼止若思，純乎其正。

瓶裏楊枝不放春，髼鬚髮認難真，盤陀石上蓮花淨，應是圓通第一人。䰄

露頂長鬚，是誰之像？淨水楊枝，贓物現放。宴寂岩間，無人合伴，蘿月松風，虛空提唱。可憐不遇知音，終日口掛壁上，眉毛不惜為人，誰肯一刀兩段？不如收拾歸來，抱膝長年自諳。將謂是圓通道人，卻元來法中龍象，不因題破面門，幾乎喚做個俗漢。

雲鬟高挽手攜瓶，賣俏塵中哄賺人，那識頭頭古佛現？分明獨露在金身。

普陀岩下古觀音，剎剎塵塵總現身，子玉時瞻修敬禮，一瓶楊柳送寧馨。

現隨類身，說無礙法，天上石麟，送往人家。蘭夢協懷，弄璋斯發，亦名慈母，故曰菩薩。

鍼鋒尖上現慈容，一線纔抽妙相通，感應隨機悲願普，盈庭寶樹自叢叢。

雲髮亂挽笑盈腮，玉步輕移入市來，一尾鮮魚人不買，可憐籃子又提回。

魚在籃中，腳不離地，憫癡眾生，行方便智。漫謂無人識得伊，撞著馬郎須迴避。

本無男女相，為度癡眾生，魚籃提在手，入市眼都瞠。雲髻盤高頂，白足凈無塵，賣盡風流人不識，至今剛喚作佳人。

梁王殿上道不識，卻來魏地展旗鎗，賺殺神光輸一臂，至今千古痛遺殃。

泛溟越漠到神州，話不投機出石頭，若無蘆枝橫雪浪，如何遮得這場羞？

這個老臊胡，有甚麼傝？冷地坐九年，幾乎莫合煞。斷臂與安心，花開遍地發，遇著忤逆兒，痛處錐一劄。不是不奉承，都緣手段辣，家私任簸颺，龍象從蹴蹋。！海神不貴夜明珠，滿把撾來當面撒。󳱥咦

，齷齷齪齪，半似癡獃、半似撒潑。布袋常攜來，知他是何物？十字街頭等個人，問著伸手便相索。看你這般窮伎倆，只待驢年得成佛。

皤著肚皮，虛粧好漢，游戲塵中，總難合伴。不居睹史多，卻來閻浮岸，無人識得渠，笑得雙眉斷。族姓每多遊，不知還自賺，終日賣嘴頭，所以人供養，若遇著燉煌，劈脊一頓棒。咄！咄！

以須彌為筆、以大海為墨，極丹青之巧繪而描邈者，徒肖其公之形；以虛空為口、以萬竅為舌，極世人之稱頌而讚美者，徒羨其公之名。庸詎知夫，日月麗天、風雨雷霆，與四時流行而不息者，乃公之心？肖公之形，須彷彿其為人；羨公之名，當慕義以忠貞。唯公之心，有不可得而思議者，強名之曰神。是故盡天地之中，凡有血氣者，莫不尊親。

天日人心兩不孤，曹瞞奸偽卻何如？尊王尊帝超千古，只在春秋一卷書。

黃面浙子，學稟生知，不念周由，醋氣太癡。單丁七載，道貴乘時；運遭五季，傑出唯師。應大風之符識，續濟脈之懸絲，垂鯨鯢釣於富水，縱銕牛機於南司。咄哉！減卻正法眼，宗風千古振坤維。

祖風萬世許誰同？道冠乾坤覆載隆，更有功名諱不得，被人喚作賣柴翁。

這位老尊慈，家聲尚赫奕。坐斷通玄峰，慣吹無孔笛。用處峭巍巍，棒頭血滴滴。四海走英賢、千古無倫匹。佛法沒人情，兒孫遍大地。古佛稱再來，藞苴幸同跡。漫同跡面目，儼然有誰識？

臨濟四世，有風穴沼，化彼汝墳，聲光日杲。牛鐵鯨釣，後流江表，七百年來，徽音已杳。誰其中興？吾師雲老，余也後承，斫額未早。欲識吾師真面目，莫向紙上去導討。

這個老宿，卻也奇特，軔跡西川，法嗣太白，雄踞天中，聲光烜赫，起風穴七百餘年無盡之燈，續滹沱三十一世頹流之脈。若即相以求真，大似虛空釘橛；若會真以離相，還同認指迷月。不落二途寫將來，夫是之謂臨濟正傳白拈賊。

臨濟金圈、楊岐栗棘，吞跳誠難，普天匝地。道冠神州，威光赫奕，佛祖爪牙，衲僧巴鼻。斷人命根、削凡聖跡，毀之有餘、讚之莫及。皓月當空，惟精惟一，瞻之仰之，中天杲日。

撒手懸崖，直下掀翻於通玄峰頂；赤身擔荷，樹大法幢於汝海天中。水赴雲奔兮，龍驤虎驟；獅吼象回兮，電掣雷轟。中興臨濟之道，再振少室之宗，捏人痛處，笑煞渠儂。普化打翻筋斗出，當頭一棒不相容。

這川巴老，卻難近傍，輪無孔鎚、握生鐵棒。見義勇為，當仁不讓，劈脊攔腮、魂飛膽喪。不容擬議思量，豈許起模畫樣？九坐名藍千巖，整洪爐廿載，鉗錘于叢林軌範，濟北綱宗赤手提，是故人天稽首無上師，風穴雲峨老和尚。

舌捲黃河、頭聳崒嶽，據曲彔床、提長柄拂。縱象王威、出獅子窟，震地喧天、神欽魔伏。倒跨千聖頂，直劈諸祖心腹。嗤馬簸箕，於南嶽菴前磨磚作鏡；笑周金關，於龍潭會裏焚疏吹燭，痛棒接禪流，慈恩利蒙俗。道大德備兮！讚之莫及；緇白咸稱兮！再來古佛。惜乎歸真何太速？且喜兒孫早已花開遍界香馥馥。𩕳

牙如利劍、口似血盆，超佛越祖、截鐵斬釘。傳曹溪之正脈，續臨濟之真燈。根蟠雙桂、葉茂三秦，煦如春風之惠物，藹如冬日之愛人。所以毘耶寫照、道俗傳神，一毛頭上定乾坤，等閒持護奉朝昏。

眉毛卓朔，頭髮髼鬆，金圈栗棘，陷虎擒龍。一條白棒，獨振綱宗，道光臨濟，聲震寰中。宗門殺手，凜凜真風，問是阿誰？金粟和尚，沖涵法兄。

生鐵鑄面，舉世誰同？晚主金粟，道冠天中。神機迥捷，氣宇威雄，一門超出，我弟你兄。惟兄克家，振起綱宗，是名風穴，嫡嗣沖翁。

眼似流星、鬚如鋼針，起滹沱之法幢，成風穴之中興。弘施大冶，煆象烹麟。慈攝人天掃波旬，佛祖到來也斷魂，早見餘光已分鄰，開遍曇花大地春。

摩醯頂一目，楊岐驢子三腳，高踞風穴山，坐斷白雲塢。始燉煌而終千峰，文身句身最卓擎。祖師心印赤手提，鐵牛之機難湊泊。𩕳

烏紗翅軟，怒髮上衝，環睜碧眼，寶劍威雄。曾感帝夢，逐鬼除兇，蕩清海宇，萬福來同。兩間正氣，千古英風，終南之傑，名馗姓鍾。

字卻不識、禪亦不會，舉拂撚鬚，兩眼相對。蚊子上鐵牛，石嘴花生碓，覿露甚分明，諸人會也未？會不會，隨尊貴，正好與捲卻青壇、掀倒禪床，看這一隊漢又作麼生進退？

這漢果真人耶？非真人耶？散步逍遙，似千方外有所得者。若論黃芽紫雪，於熊申吐納之間，則不無為。莊生笑殺世人問壽，故攜桃以應之，若求長生久視，定不在乎，此果真人者，必以余言為是。

骨瘦眉長、神清貌古，玉出藍田、鍚駐郢土。梵行清修，桑門翹楚，本色為人，慈而益溥。出語實頭，和而不侮，宴坐日翛然，長年不出戶。一炷爐煙一卷經，數珠百八手長數。時節偶到來，泥牛能起舞，撞倒須彌盧，踏破虛空鼓。撒手便歸家，日輪正卓午，後彥喜叢叢，香剎傳有主。淨禪攜來請吾題，涅槃會上無佛祖。咄！

分明眉目較些些，建立叢林老作家，有口不傳千佛戒，忘身專輔續拈花。德操嚴冷從風穴，壽景嵬峨聳太華，得坐披衣如意手，兒孫蟄蟄樂無涯。

戒不拘則、禪不續燈，廛居大隱，和光同塵，懷慖愊而弘揚祖道，拓寶坊而福利群生。有時施大法藥，復明人天正眼；有時揮棕櫚柄，坐斷文字葛藤。故德為世重、齒為世欽，且喜繼述有寧馨，紙上描來卻似真。只如無形無像，朕兆未分，縱是僧繇難下手，又何怪乎花紅柳綠，大地皆春？是誰得而描成？世閒疑殺幾多人。

覿面何須問姓名？當陽便識個中人，一生學佛為吾契，千古鴻儒與聖親。已羨階前蘭桂滿，須知裕後鳳麟臻，文殊不二如相訊，天竺維摩是比鄰。

丹穴神羽，天池化鯤。清灑襟懷，秋水澄華峰之月；秀入肺腑，春風度淇澳之筠。兼之才資天縱，慧業性成，文工武庫，詩邁少陵。將欲龍驤虎驟、霞蔚雲蒸，期必芥抬朱紫，蜚聲上林。胡為乎黃粱夢破，懸解遺形？且喜裕後有寧馨，慎寶鴻文續舊經，紙上描來孰是真？雲湛天空水月明。

蕭蕭道服手輪珠，面目分明識也無，白業修身成聖果，紅塵住腳了凡夫。庭前玉樹根培厚，劫外金藻蕊漸敷，天竺淨名多不讓，龍華期會定無殊。

一尚不存，何曾有四？濁惡世中，顯真俗智。身雖處塵，心越乎世，龐老西江，維摩不二。松下閑行兮，隨鶴塵以優遊；石上宴坐兮，觀流水而知義。等富貴如浮雲，釋妻拏之所繫，將絕慮以忘緣，破夢幻之斯寄。悟今是而昨非，故急流而勇退。現圓頂兮，明本來之相；挂方袍兮，絕塵勞之累。一串數珠一卷經，草菴缽孟好歸去，一失人身萬劫難，這回相見非容易。大丈夫兒不等閒，到頭若個能迴避，果能直下肯承當，鐵壁銀山都粉碎。咄咄！

壺範清肅，懿則純貞，柏舟早賦，彤史維陳。素心煦日，淑氣和春，令儀令德，拔萃超塵。羨門楣之梃秀，瑞闌寶之鳳麟。有女如子兮，生事死葬。盡思如在，予定省晨昏；儀容可瞻，予像之若親；丹青圖繪，予筆之非真；勘破夢幻，予侍佛明心；了妄歸來，予蓮胎上生。

虎符奠金甌，實昭代元勳之裔；龍券藏天府，蓋興朝公輔之儔。威不令而自嚴，英風偉卓；貌不言而眾慰，德量深幽。汾陽雅度、叔子風流。百年江漢見輕裘，名載凌煙最上頭。眉撐天漢、目湛清秋，射鵰歸去樂無休。茶鐺羽扇，書史是謀，太平不用擐戈甲，閒看鶴鹿自優游。

積代簪纓、盛世名臣，鷹揚鐵嶺、虎蔚龍蒸。勳開帝胄、畫堪麒麟，折衝閫外、控制西秦。綏帶輕裘，羊公楨榦；說禮敦詩，卻穀退讓。西顧忘憂，甲兵休戰，待漏朝天，衣冠其像。睹公之容、仰公之風，神清貌古，德士之雄。莊椿永茂，萬福攸同，宜爾子孫，繩繩不窮。

展圖忽睹笑顏開，仙鹿低昂鶴共徊，象服幽閑光淑德，虎幃篤贊助雄才。生成五福人中瑞，喜見三芝砌下培，日課輪珠修白業，天花影裏見如來。

英氣如生、目炯如電，壯士衛側，神駿猶健。捻鬚坐石，何其繾綣？論勳業可帶礪河山，論文章則春華如絢。有諸葛君名士之風，惜飛將軍數奇之變，棋局勘破早歸來，富貴浮雲何足羨？石鼎茶鐺綠樹間，儒釋道也隨心願，雲友昆仲須先薦，紙上何曾是真面？谷神不死知不知，東風吹落桃花片。

魯夫子曰：「善人，吾不得而見之矣！得見有恒者，斯可矣！」又曰：「入而無恒，不可以作巫醫。」張公號恒齋，其為人也，好善樂施，立心始終如一日，則可謂有恒矣！然以醫藥濟世，意在活人，非所以取利也。如吾佛世尊，以大法藥普施一切眾生出三界苦、得涅槃樂，所以稱大醫王。博施濟眾，唯聖者能之。張公神清貌古，愷悌慈祥，謙光應物，誠如其仁。年及耄耋，肖像請題。余喜張公之有恒而好善也，則可謂之善人也。善而有恒，則近道矣！後之子孫，見公之像、思公之德，當善繼其志，而善述其事可也。

春風品度，明月襟懷，翩翩犬雅，求福不回。武庫家舊，文章繡虎才，志養則敦孝友，勳業已繼麟臺。四海皆兄弟、道義盡朋儕，長松之下樂優哉，鶴鹿相隨得便倍，盈庭寶樹已成栽，經卷爐煙自偶諧，僉云凈名居士，亦曰金粟再來。千葉荷雯萬戶候，靜觀坐對滿池開。

赳赳虎賁，鷹揚東國，盛世遭逢，優游自得。坐石倚松，鶴鹿肥澤，桂秀蘭芳，壽量何則？碩人君子，其儀不忒。

倚松坐石者誰耶？容止端莊，溫而和厚。瀟灑塵表，祥洋乎國士之風；跡寄兵戎，彬彬然君子之躅。介爾眉壽，有鹿有鶴，裕後光前，蘭芬桂茁，是吾益菴善士也。

其形也恭、其容也敬，威而不猛，中軍之令。嚴守心城，六門是慎，不動干戈定太平，勳業雲臺何足勝？善士護念兮，惟動惟正；壽量無窮兮，樂天之命。

兩序請讚，援筆便判，坐斷葛藤，像誰模樣？若道是憨休和尚，劈脊好與三十拄杖；若道不是憨休和尚，喚大智舍利弗來，共汝等盡思度量。疏山曹家女，玄沙是汝虎，臨濟瞎驢兒，溈山大水牯，要且總沒交。畢竟如何？終南山色連天碧，萬派吞聲人渭河。蘇嚕唎　喝囉怛那。㗭

正令全提，壁立萬仞，路絕攀緣，不通凡聖。拋出紅爐熱鐵團，佛祖見也骨毛寒，揭開臨濟正法眼，珍重渠儂仔細看。

個等像貌，誰為寫照？理不通儒，道豈知妙？披著片袈裟，濫膺入僧寶，柱杖頭邊不讓人，佛來魔來一齊掃。看你這樣舉止，更有一般可笑。文監寺，須知道！秤錘捏出黃金汁，裂破虛空那一竅。咄！咄！

竿木隨身，逢場作戲，七處開堂，振綱剔獘。平生氣壓叢林，勿怪眼高一世。鐵打心腸冷似冰，大座當軒如火聚，獨有忍菴葆知客，相逢窄處難迴避。莫迴避，休擬議，若非踏倒佛祖頂，焉能蹶起臨濟？咄！𩕳

氣若行雲、止如谷神，智小謀大、德薄位尊。藏身北斗，獅子獰猙，等閒哮吼，百獸驚駭。得須彌倒走、香象奔騰，壁立萬仞可憐生，胡為乎喚他作興善和尚、憨休老人？

這白拈賊，機知迥別，虛空為口、電擊為舌，喚鐘作甕、證龜成鱉。眉毛蓋覆五須彌，趁起鐵牛振風穴。賊！賊！外道天魔皆腦裂。

咄哉瞎驢，毫無軌則，有人問著，驀頭便楔。為佛祖之生冤，作叢林之妖孽，依俙德嘺周金剛，彷彿滹沱那大伯。佛法沒人情，描他何所得？素禪人，須自瞥，愛渠名相受他惑，點把火來快燒卻，免為虛空安耳穴。

爾性愚兮爾貌憨，栽花石上獨相諳，空拳到處能成立，赤手臨時慣解粘。不肯祖師群隊裏，卻來關內起沉酣，生平佛法無多子，白棒一條作指南。

爾這瞎禿，無人無佛，文不根儒，道聽塗說；禪不合流，超宗異目。力剪邪見稠林，惹起諸人謗讟。金翅鳥當空、獅子王出窟，狐兔盡潛蹤、天魔皆膽落。呵佛兼罵祖，造罪過山嶽，臨濟兒孫那有你？定是闡提個種族。可憎有十分，描他做甚麼？董文學，聽我說，只好生擒來，打入阿鼻地獄。

春風繪其神、秋水湛其骨，眼蓋四天下、眉毛覆五嶽。名譽不喜揚，搢紳咸折服，興善晚來居，木蛇手內毒。釘空卻露痕，繫風不用索，佛祖結生冤，鹿外恨人骨。世波怒而堅砥柱之操，陳蔡厄而難君子之屈，一生擔板少人知，修羅隊裏能插足。智禪人，還識麼？乃臨濟下三十三世之孫，風穴雲峨老人之法嗣憨休也。

松下經行，不存伴侶，卓立孤標，迥絕依倚。不肯合汙同流，一生擔板誰許？逍遙閒自適，囉哩哩囉哩。尹善人，須薦取，從來相識滿天下，若謂知心能有幾？

藞苴個漢，甚底模樣？頭如木杓、口似匾擔，賦性專愚、為人倔強。若論佛法全無，看伊只好噇飯，在處和光同塵，行藏叵難度量。觸殺臨濟瞎驢，拗折芭蕉拄杖，水邊林下任逍遙，明月清風難比況。咄！咄！

手拈白拂露微笑，眼腦痴憨肚裏峭，陷虎機關毒最深，擘破三元與三要。

這骨董漢，得人僧罵，手中拄杖，不肯放下。一味惡打人，佛祖見也，怕怕怕怕。好事不出門，惡事傳天下。

鐵牛倒跨祖庭秋，塔勢崚嶒汝水頭，點破虛空懸慧日；撐開天漢瀉元流。深培鬱密松千本，直指橫斜月一鉤，風穴家聲千古在，兒孫蟄蟄起宗猷。

嶙峋古塔聳山隈，繡石橫碑半綠苔，郭外煙雲開復合，嶺頭明月去還來。傍城流水機猶在，充黃金世莫裁，八面無門空廓落，年年春到自花開。

和泥合水入廛來，倒嶽傾湫震法雷，大地懽承新雨露，靈芽喜茁舊根荄。塵塵凈滌空諸有，剎剎咸滋遍九垓，故教密雲彌布遠，普天化育躋春臺。

汝海韜光歲月深，時瞻綱紀肅叢林，鶤鵬乍徙凌霄漢，天馬猶憐善古今。手毒擒龍追電影，機先陷虎迸雷音，濟宗此去唯君辰，消息何時慰素心？

久惜秋霜志莫嘉，深潛汝海混龍蛇，翻身破浪伸頭角，奪食驅耕見爪牙。踏殺神駒推馬簸，雄吞佛祖讓勤巴，鐵牛機峻家聲在，祖道絲危賴作家。

陷虎擒龍世無雙，銅頭鐵額盡心降，全提正令雄三楚，倒握吹毛奠九江。末運流中撐砥柱，虛空背上立標幢，可憎格外鉗鎚辣，攛掇牛兒尾過窗。

參禪無妙訣，只要生死切，一句子話頭，常提無間歇。拔卻腦後釘，扭出虛空血，漆桶夜生光，笑倒乾屎橛。

參禪須猛利，不是小兒戲，一口氣不來，知向何處去？趁此色身強，早辦前程計，豎起鐵脊梁，心空取及第。

參禪莫散誕，麻繩著水蘸，長劍倚天寒，只教命根斷。跳過金剛圈，嚙碎鐵酸餡，佛祖生冤家，大事無不辦。

參禪須融豁，勿墮山鬼窟，板齒上生毛，虛空裏揣骨。地忽一聲，似賊入空屋，捉敗老臊胡，眼子烏律律。㘞

參禪勿拘絆，腳跟要穩當，照顧主人公，惺惺常呼喚。澄潭皎月輝，猶是生死岸，瞥爾眼皮穿，眉毛橫額上。

參禪怕掉舉，只要偷心死，縱與理相應，禪河窮到底。打破鳳林關，咬人是獅子，俊哉丈夫兒，只合當如此。

浩然歸去幾經霜，占斷瓊枝秪自芳，影散羅浮千樹雪，瓣分庾嶺五株香。冰心解凍留金鑑，玉骨凝寒信鐵腸，惟有孤貞先屬望，陽春曲裏韻偏長。

翠捲西風兩岸蒲，碧筒秘晚已停沾，鞭鳴玉勒來驄騎，界列金繩入坦途。縟綵光生留帶偈，韡花香散襲犀渠，應知下榻情何限？卻喜忘言道不殊。

院靜秋林景更清，木樨深處悟無生，尋香太史知何處？露滴金莖皓月明。

移錫來幽土，平蕪接水雲，天空雙雁落，地迥兩河分。園鹿高原見，荒雞野店聞，秋霜誰共惜？徒自憶離群。

近別峨嵋路，常懷第一峰，臺高無剩月，山靜有鳴鐘。老銀象，飛泉掛玉龍，何時深處去？一榻臥雲。

落日林塘靜，尋幽泛水亭，蟲聲鳴斷岸，鷗夢結寒汀。樹暝湖心影，船開水面萍，歸來相和句，月色滿柴扃。

客裏重陽日，登樓倩一觀，千林秋色老，萬井曙光寒。眼歷河山盡，心閒世界寬，卻思陶令賞，叢菊待誰看？

疏影橫斜襲遠香，晴烘麗日上莓墻，高情夢破梨雲曉，失路愁看驛使忙。竹裏彈琴清雪操，松間影鶴傍枝藏，冰心已許林和靖，宮額無煩點壽陽。

城北仙翁處士家，閒中日月樂無涯，數將甲子頻窺鶴，種就靈苗已吐花。風靜玉池眠白鹿，煙消金鼎熟黃芽，懸壺近市誰相識？秪許長房過不差。

客裏逢除夕，蕭然兩鬢華，寒深憎瑞雪，燭暈剪輕花。臘饌三冬盡，鄉心萬里賒，何時偕舊隱？泉石共生涯。

鬱鬱空林下，不知近九衢，荷池擎雨蓋，藤架引龍鬚。鶴翅彌天廓，雲情脫世狗，那堪深樹裏，崹鳥似巴斂。

秋興挽行色，林鐘散曉鴉，紅飛霜樹葉，黃綻竹籬花。竿木隨身穩，金風坦道賒，呂亭遙悵望，一雁落平沙。

望隨平野盡，旅雁正南時，浦樹零秋晚，關河策蹇遲。風吟松際月，菊吐路傍枝，握手難為別，欲言寄所思。

占得嵩高畢此生，蒲團終日絕逢迎，心空石室花無雨，露冷松巢鶴有聲。林下錫歸煙寺晚，橋邊月上石潭清，獅絃自是知音少，爐火頻煨折腳鐺。

深林鬱密稱幽棲，水滿平湖勝霅溪，白板宿雲驚過雁，瘦笻搘榻待鳴雞。城頭夜月千家思，隴外霜寒萬木低，最是秋晴天色好，閒吟踏步過庵西。

臘瓣含金鬥雪香，檀心都盡蝶蜂狂，疏容未是貪春早，恐負靈根在上方。

楖栗雄三楚，聲光振九州，霞標雲漢迥，雪谷翠雲留。猿嘯嵩門月，蟬吟赤壁秋，相期那可再？萬里水江流。

桐響驚秋葉，他鄉送客歸，浦雲含宿雨，江樹靄晴暉。旅況真難遣，鄉音頻覺稀，明朝千里路，相望兩依依。

飯罷經行候，涼颺碧草凄，板橋通曲水，岸柳夾長堤。乍響驚魚躍，旋飛避鳥栖，幽篁深處望，落照女墻低。

石徑陳年上蘚花，橋通孤岸傍人家，墻頭青杏兒爭摘，老圃肩鋤獨種瓜。

旦出西郊迥，清秋白露前，宿雲藏野店，曉露濕炊煙。岸江帆影，村墟土堠連，道傍翁仲石，沒姓幾多年？

蟋蟀鳴幽砌，空庭落葉深，荷枯香半歇，風勁竹長吟。問法無玄度，詶機有道林，浩歌唯自適，雲外幾知音？

鳥語迎詞客，龍光隱梵宮，香交花霧重，陰占柳塘空。格外通禪意，言前薦祖風，獅床如欲借，還許問蘇公。

客裏逢君別，離愁欲暮年，鄉心間過雁，遊子憶歸天。勿惜風塵苦，寧辭道路偏？秣陵如到日，長記白雲篇。

玲瓏琪樹映朝暉，瑞靄嚴城接翠微，嶽降嵩靈開紫極，鸞迎仙使到朱罪。談經石上塵都靜，隱釣溪邊鳥息機，已羨布金隆法護，諸天鐘鼓正瞻依。

吳山曾歷遍，錫已罷宵征，戶外懸秋月，床頭落澗聲。惜霜愁易遣，伐輻志先成，傾蓋頻相得，真堪話此情。

野水連空碧，沙禽暖尚依，蒹葭生旅思，促織叫絺幃。蟾影諸天近，秋聲亂葉飛，壯懷舒未已，處處擣寒衣。

天涯同作客，喜遇況清時，鶴性從瀟散，萍蹤任所之。疏桐憐月色，遠夢入鄉思，短鬢秋將半，芙蓉落未知。

湖中疑無地，積翠入山居，徑繞藤陰合，蟬吟木葉疏。澆畦鄰邵圃，游泳樂莊魚，既獲增幽賞，詞鋒振有餘。

萬事從緣合，一枝得暫安，窗虛殘月照，衲重曉霜寒。鳳德憑誰歎？獅絃只自彈，何如深竹裏，風韻日琅玕？

古云不惜過秋霜，面命如同記未忘，汝海浪平龍臥穩，慈泉壑靜派流長。臺高日暖爭花放，曲澗春深起蟄藏，唯有懷人思更遠，藝蘭澧浦詠馨香。

獨樹江頭望遠天，西風黃菊悵分緣，香盈驛路吹花裏，鴈帶秋雲落澗邊。入世頓忘霜骨脆，攄愁唯有道心堅，黯然賦別非同別，好誦莊生第一篇。

野草生新綠，看花獨破愁，狂心悲野馬，人世苦蝸牛。就燢憐桐響，汲泉愛月流，春風時不定，吹白少年頭。

雲凈曲天空，銷魂客路中，林高秋漢月，錫振楚江風。野店炊煙白，霜林醉葉紅，景行思仰止，極目望歸鴻。

鮦水期相識，冰心絕比鄰，那知同道侶，都是異鄉人？露白凝黃菊，楓丹憶紫蓴，孤雲蹤不紫，後會若為論。

特舉江東櫂，來聽塞北笳，息茵猶未暖，歸計已先賒。野店藏深樹，寒流漱淺沙，南塘今惜別，相思各天涯。

雲鶴蹤無定，乾坤盡是家，冥心澄曉霽，寓目斂晴霞。綠樹啼春鳥，紅香放野花，翛然忘歲月，何處覓生涯？

竹院風生露頂涼，林花低翠小紅香，篆煙消盡將斜日，古柏移陰過短墻。

乍別故山石，移來寶地裁，仙苓期未望，巢鶴計先猜。固本培根厚，抽枝漸葉開，蓬蒿遮莫掩，未可雪霜摧。

小搆藏幽篠，洒然萬籟清，稍垂新雨濕，葉響晚風生。倒水揩花鏡，高枝度鳥聲，坐來忘物我，秋月印湖明。

夢覺羅浮幻，清香散墨花，焦痕如墮影，折筆似枯槎。鎮日忘蜂採，長年趁蝶斜，隨時能寄目，野客興偏賒。

採銅曾說此山巔，問道同來有七賢，迷跡尚追千載事，傳心唯見一燈懸。虯藏樹老盤山洞，石斷碑殘上蘚錢，應是下方城郭近，鐘聲每送夕陽煙。

萬木陰森百鳥鳴，喃喃猶似誦經聲，泥龕洞鎖孤雲靜，塔影空懸皓月明。石上無塵松自老，山間洗缽沼常清，當年問道云何事？汝水東流傍楚城。

僵勝袁安臥，無人冒雪來，凍雲披牖竹，饑鳥啄庭梅。徹骨寒難禦，齊腰事可猜，爐頭賓主句，撥盡夜然灰。

積雨春初夜，楮幃冷素光，梁空懸佛火，風急送梅香。背郭聞譙暗，寒雞破夢長，窗虛擬射白，林外有荒塘。

邂逅期鮦水，頻歌蜀道難，他鄉猶惜別，故舊易為歡。晴樹花偏麗，春江曉尚寒，欲將風穴去，何日話彈冠？

寄息檀陰四載過，江城無奈別離何？雲情有戀依金馬，野意無媒聽玉珂。欲上嵩門參壁觀，還疑丈室對維摩，法輪已屬調羹手，日震雷音到薜蘿。

法護金城仰大才，檀林蓊鬱倩滋培，梵音喜並琴音振，佛日期從化日回。阡陌春和花已綻，閭閻風靜戶常開，孤笻西上頻留偈，詔侍金庭有鳳來。

日麗春晴，歸笻不計程，隔村紅樹遠，曠野綠雲平。應供逢齋主，隨機悅世情，高懷興有托，啼鳥一聲聲。

暫憩衡茅下，晴霞映錫光，塘深千樹柳，杏出一枝墻。吠犬僧初到，烹茶客愛嘗，任緣隨處可，何必是西方？

滿目真堪笑，陶潛許獨吟，鳶魚須會道，木石任幽尋。照破三生面，能開萬劫心，丈夫元無我，何必只儒林？

得便還家路，到來春草生，山空臺殿古，洞鎖曙雲平。傾蓋情偏重，忘言道不輕，子韶能物格，燈錄繼題名。

千里同風客，傾投意洒然，杯從閩海渡，榻共汝山緣。半壁扶人影，一龕散燭煙，坐來清夜永，月色到簾前。

窗明葉落已驚秋，草徑新鋤報客遊，尺素久裁傳雁足，新詩漫寄到庵頭。山廚食菌燒松火，石鼎烹泉待筧流，聞道蘆航將北渡，暮雲江樹不勝愁。

沼師弘法地，幽邃絕塵纖，薜荔藤垂幔，珠泉水挂簾。山光薰曰靜，塔勢簇雲尖，若個顏曾破，林花不倦拈。

古穴空山裏，雲深未可探，翠環千樹柏，紫載一峰嵐。祖道彌今古，禪燈易苦甘，中崖深夜月，疏影照蘿龕。

去年今日在南塘，此夕林巒世事忘，戶外好山青入眼，洞前明月素如霜。飛來寒瀑珠千顆，落盡窗陰葉半床，秋色撩人容易懶，且將清興寄詩囊。

鯛陽傾蓋盡情歡，此日先歌行路難，汝海澄波賒月色，嵩門峭壁倚天寒。神怡雪澗松千樹，釣穩漁璣竹一竿，歸去不妨花雨散，階前歷亂鳥銜殘。

寂歷山齋古，寒深夜未央，挑燈披道偈，擁衲坐繩床。月上虛窗白，庭陰剩菊黃，冥然心不起，獨對一爐香。

朦朧殿閣望重重，翠潑晴嵐上遠峰，行到白雲將盡處，水聲寒咽度溪鐘。

黃葉猶填徑，扶笻一到來，舊巢松鶴老，新蕊杏花開。鈴塔風傳語，庭碑字蝕苔，僧言兵劫後，今始闢蒿萊。

靈雨洒空濛，湖平接梵宮，白生虛殿角，綠上廢詩簡。漏盡無移榻，愁長有聒蟲，如何能慰目？望斷海門東。

谷風剪剪亂飛花，欲寫離情咨復嗟！乃兄真若鳳置，孤標卓立出雲霞。相期矢志囓冰雪，策勤斯道絕紛譁，胡為別路忽週遮？試歌風穴送還家。風穴山深在何處？萬柏蒼茫鎖煙霧，岈湍激吼豗雷，一道寒泉飛瀑布。東峰突兀殊覺高，摩青插紫當雲霄，下有蛟龍蟠旋隱居之窟宅，上有參天拂日掩映之松濤。鷲嶺蘭若處其下，梵音微動雨花飄，塔勢崢嶸齊中頂，仙人跨鶴來滄溟。月下吹笙步月歌，歌聲光炯炯，倏爾天風響嶙嶒，恍如萬馬之奔騰。石竅呼號山欲裂，翻空攪霧徙鶤鵬，扶搖直上九萬里，翠嵐極目杳川底。煙火人家帶郭城，錦屏疊出山如洗，樵牧雲深不見蹤，長歌松下草茸茸。笛聲隱隱過前阪，又聽忽達來西峰，絕壁面面兩相峙，洞戶當暄遠朝市。園蔬畦分七葉巖，那羅延窟亦如是！境何幽兮山何深？晨鐘暮鼓戀栖禽。谿何邃兮谷何窈？羚羊挂角絕追尋，昔有浙僧居此土，韜光宴息人不顧。一朝穎脫露囊錐，簇擁樓臺成常住，曲彔床子郢衙開，有識仰山須再來。七百餘年消息絕，而今才復振隳頹，鐵牛機峻從中起，峨峨萬仞誰能倚？唯君廿載侍巾瓶，紙襖抄來無窮已，誰云侍者參得禪？三呼三應自天然。瞎驢滅卻正法眼，人室親承絕蹄筌，雪浪千層翻汝海，鯨鯢鼓蕩增光彩。雲吐沫徹天衢，驚煞蟠螭與黃能，蘚徑春來點石斑，值君振策還羅山。芒鞋踏破蒼苔色，況復桃花開笑顏，人生天地常如客，豈惜風塵走南北？瞬息光陰過隙駒，肯取榮名以為則？昔聞河西罷夜參，胡僧金錫頗相諳。林下疋馬終歸去，廣眾徒知道已南，佛祖門庭識者懼，真誠不是小兒戲。懸鶉采藿度秋霜，只要馨香遍大地，此日送君歸故鄉，令人躑躅復徬徨。極目冥鴻杳天際，魚腹望剖心悒快。風穴何幽深？白雲常依護。虎負山之嵎，俄起獨散步。異曰驚虓知何處？葉落還尋舊山路。試看獰猙弄瓜牙，咬殺豬狗何其數？虎兄虎兄聽我歌，我亦尋山便歸去。㟏

昨夜風雲會汝淵，潛龍起蟄正春天，雷崩剎海千山動，雨沐林皋萬卉妍。林影忽開明積翠，巖陰尚合暗浮煙，揮毫欲灑銷魂字，卻為心知杖不前。

泉石耽同癖、驪歌唱汝墳，行蹤多野雪，曉日半山雲。祖席君全賴、禪燈我暫分，何時重攜乎？繞瀾論心聞。

數載懷幽愜，機鋒絕比鄰，他山唯共寺、故國幾經春？禪版香雲合、詩壇夢草新，萍蹤那可定？何處寄同倫？

林簇曉峰晴，伊川繞客行，孤村煙自白、亂水韻猶清。就食懷山店，逢人問旅程，碧雲天際遠，歸雁送春聲。

車嶺愁人地，殽函接暮陰，斷雲飛宿雨、群鳥下危岑。土屋居民少、桑田護草深，誰將青白眼，勘破一生心？

鍾應峨嵋秀、名高華嶽齊，星垣瞻斗北、河潤藉關西。擊壤民如市、栽花縣若谿，金甌知有卜，宸翰待親題。

策杖臨谿一問松，群賢畢集賞幽叢，茶烹雪水詩腸潤，露滴桃花石面紅。歌近清明聲雜遝，晴翻麥浪霧溟濛，孤懷喜獲尋真趣，鵠立憑高西復東。

未能化石去，應秪伴雲眠，幹老龍鱗結、枝高麈尾懸。驚濤聞唳鶴、傲雪見幽賢，處士家何處？東林隔竹煙。

見說前朝寺，今知唐代名，侵門唯嶽色、幽籟自松聲。月映山光動、林疏木氣清，可中無法說，樵斧韻丁丁。

所志從吾好，居然遠四鄰，閒中世味少、淡處道情真。飽眼山如畫、臞形鶴似人，寥寥空澗壑，不是為逃秦。

擇木看禽止、襄衣坐石苔，花光迎戶人、松影隔溪來。供食薇頻采、長吟句獨裁，迂懷機不讓，儘教白雲猜。

不記入山日，松門長自青，瓠瓢盛石髓、木客聽《鵝經》。種秫生三秀、書符走六丁，洞簫吹徹夜，舞鶴有遺翎。

腹空無寫句，紈扇喜知音，雅重雙眉雪、情消萬慮心。斷猿風外嘯、幽鳥座間吟，還憶王摩詰，無生道可尋。

桐陰午靜絕氛埃，鴿怖棲枝應客來，觀槿已容疏禮樂，乘輿且喜到宗雷。爐添柏子香還細，漏滴池蓮蕊自開，為愛群賢能載道，虎溪步過卻忘回。

修竹半欹斜，通流引漢槎，折巾高士宅、分券令公家。葉響常疑雨、亭香只見花，坐來忘溽暑，深樹聽啼鴉。

胸囊萬卷待鳴珂，少嶽靈鍾應不訛，風雅尚能驚慧遠，文章米肯遜東坡。蓮峰秀聳雲邊翠，桂斧聲清月下磨，把臂山房秋興切，呦呦鳴鹿聽松蘿。

徑草青長半掩門，何來車馬破苔痕？忘機只許鷗相狎，點首虛傳石解言。柳外蟬嘶清暑簟，座中茗酌勝芳尊，鳳池知待群公久，護法還當憶祗園。

晷漏初經夏日長，小池新鑿傍幽篁，臨窗蕉葉抽詩卷，倒壁松陰上石床。客過林深巢鳥喚，簾垂院靜草花香，誰將幻住陶真樂？也學伊人水一方。

蟬聲處處響高秋，笠颺西風資遠遊，參鶴姑停仙子馭，詞壇且息士人詶。晴川半落天低樹，野水遙橫岸泊舟，暫別檀陰徇振鐸，何年再共話林丘？

理策尋幽地、棲遲渭水邊，寒雲生斷壑、疏磬發孤煙。霽遠凝晴雪、原平燒晚天，比鄰有高士，惜醉欲逃禪。

一從分袂阻關河，兩見飛螢點薜蘿，土曠逢人青眼少，大空問路白雲多。菊英采采秋將淡，風雨蕭蕭雁不過，為憶綸竿淮汝上，蓼花深處釣滄波。

客邸凄其夏若秋，蒲觴競泛幾忘憂，山連蜀國三千里，水纔秦關百二州。漢苑荒苔閒草鬥，唐宮射彈罷媛愁，焚香洗缽長清晝，照眼榴花滿樹頭。

綠陰晴樹鎖江皋，極盡平疇沒野蒿，雲聳奇峰隨疊嶂，舟橫斷岸任飛濤。天邊樓閣蟻千穴，眼底乾坤馬一毛，為問華山陳處士，幾人曾此聽啼猱？

柏護招提紫翠攢，凌空爽籟動花壇，千峰玉削南山秀，一葉桐飛渭水寒。野徑偏宜雲去宿，閒庭獨許鳥來看，漫斟茗碗消殘暑，柳咽蟬聲露未乾。

葉醉霜林覆錦堆，晴峰遠映夕陽開，尋思客自乘龜至，借座人還解帶來。築就敢煩花作雨，功成豈用石為臺？門臨渭水堪垂釣，肯惜狂瀾盡挽回。

久切雲霓望，春中始見蘇，麥回千頃秀、桑發萬條枮。冼甲邊烽靖、乘時物澤敷，紀年知大有，昑興莫相孤。

琪樹鬱青蔥，巋然仰大雄，唐朝顯慶寺、秦代望夷宮。壁剩丹青古、庭遺石碣豐，法幢今再豎，寰海振宗風。

奄有林巒第一籌，半窗明月半窗秋，雲收雨腳連山翠，水落河聲到枕流。未信索珠詼象罔，豈知游刃解庖牛？柴門深扃垂簾暮，立雪空懷萬古愁。

綠樹春晴眼乍明，野雲生動曉風輕，門關院草僧初定，字墮庭碑石半橫。公案掀翻閒瓦礫，清談喜晤接簪纓，已知賓主機先契，蓮社相看續舊盟。

乾坤如此似飄迷，望入終南興莫窮，才拙固難期隱豹，技成終是愧雕蟲。雲連密樹村多暗，市隔平原徑少通，白拂罷拈花意懶，唯君千里喜同風。

重重佳氣靄松龕，極目雲林思再三，鯨釣幸分同渭水，霞棲忽去望終南。神迷夢蝶飛寒澗，雁托秋空繞翠嵐，想見靈源深密處，人天無路許誰參？

任運還同不繫舟，古人深得自優游，苗蕃弁嶽秋初茂，派接新豐洞上流。嘯樹猿聲清夜月，落花松徑點樵謳，慚余孤岸新棲鳥，鈍羽蘆中刷未休。

龍門喜托一登遊，賸與山中枕石頭，聞桂那堪詢太史？虛懷但願識荊州。愁連宵火秋將半，坐對吟壇興不休，句到投竿詩更好，敢期綸線共垂鉤？

莫問西來出世禪，白雲紅樹自翛然，錦囊好制投佳句，丘壑何消用買錢？野外流霞飛復住，枝頭倦鳥止猶遷，應知酒市非公隱，大業還須冀濟川。

近來憨拙懶談禪，喜接文光覺灑然，魚噉墨池將硯洗，草翻書帶上階牽。金門挾策唯君計，竿水逢場信我緣，看取長風驚破浪，漁山還解樂釣天。

昔緣邂逅在眭村，今射龍光到蓽門，玉玦開椷輝梵境，金英殘菊媚籬籓。禪床不假嫌蘇軾，書劍空忙笑許渾，欲就程庭深立雪，門墻高峻可容捫。

歸覲寧辭去？何堪念錫飛？霜寒枯徑草、露重冷鶉衣。梅市僊傳隱、漆園蝶見機，趨庭當有待，笻杖自依依。

渭水東流疾，蓬心客路賒，三年來古雍、兩鬢欲霜華。波捲輕鷗亂、舟移斷岸斜，夕陽紅樹遠，何處是人家？

肩橫楖栗過咸林，蘀隕繁霜客思深，雲外鳥歸江樹迥，舖前人送羽書臨。青山舊約逢知己，白社新盟貴賞音，又向旅亭重惜別，松風蘿月漫相尋。

凌空雪涌玉蓮高，獨立斜陽興倍豪，絕壁千尋懸鐵索，飛梯百丈走山猱。雲浮洞水從天注，石撼松濤鎮日號，振策何時峰頂上？還看仙子薦冰桃。

颯颯潼津柳、遲遲渭水濱，嶽雲飛宿鳥、曉日盻行人。楊震經傅聖、陳摶道入神，高名千古下，追憶總堪鄰。

雄關聞百二，經此復徘徊，華嶽三峰峻、黃河萬里來。城高金斗勝、雞唱鐵門開，德在寧亡鹿？咸陽豈聚灰？

腳底寒雲重，山頭大雨來，未臨函谷口、已望說經臺。過客愁羈旅、郵程任化裁，泥途當此日，吾道亦堪哀。

野色荒荒盡草萊，眠獅臥象總成哀，雲橫絕巘谿流去，日駕靈峰塔影來。隻履遺瞻千載上，一花韡疊萬年開，幾回躑躅頻惆悵，克振家聲愧不才。

雪花片片朔風寒，濟涉無舟岸更寬，石亂灘聲嘶度馬，波搖樹影倒回巒。盡誇入水長人見，纔覺浸膚過客難，若使神龜重協瑞，免教腳下起狂瀾。

杖笠韓城道，蕭條旅思中，土深塵跡暗、村廢社壇空。野水連天碧、晴霞燒晚紅，相逢各不問，去路只匆匆。

萍蹤無定住，暫為空山留，落葉飄如鳥、荒雲淡若秋。簾輝蟾影直、鐘動水光浮，昨夜有微雪，冷風吹不休。

風穴幾時到？晚行不暫停，暝沙博雁白、沆瀣閟峰青。擔人肩知重、途遙杖覺靈，翻思黃面老，雪夜睹明星。

谷口蒼涼萬木深，冰天朔氣釀獅林，空心潭影恒朝夕，崑為山光自。事參親入室，再參敢喝傳心，潺湲澗水長流澤，若個窮源肯為尋？

心馳歸覲切，師去到方聞，萬木仍幽壑、千峰鎖白雲。羨君能繼席、愧我贈無文，試看家聲振，禪燈遍界分。

移竿何處靜垂綸？鯨釣仍分汝水濱，一世銜冤叨父訓，三年累德愧門人。茶香鼎熟松窗語，殿古寒深坐榻塵，好是行藏無可覓，朋儕相向話來因。

真儀今再禮，何處問師心？道大輝千古、峰高壁萬尋。乾坤騰浩氣、江漢注靈襟，頂相無能見，鐘聲出暮林。

當年棲息地，今復見行藏，駿骨逸天馬、奇毛翥鳳凰。苔封仍仄徑、薜翳已沿墻，蓊鬱峰巒秀、綢繆殿閣張。一枝巢父穩、十笏凈名良，竇啟乾坤隘、窗開日月光。高巖無六月、古木有千章，鈴語天風動、溪鳴石瀨長。清涼圖入梵，絳葉柿飛霜，塔影輝蟾魄、松濤涌法堂。雲生煙壑杳、雨歇菅茅香，澤廣山藏豹、林深角挂羊。靈花韡疊疊、覺樹茂昌昌，感遇誠非偶，狎盟豈是狂？遐心胡爾棄、斯道屬儂行，裕後聲烜赫、光前燄煒煌。顧瞻為復眺，憶念不能忘。

秦西燕北兩分光，坐對寒燈話夜長，壁落短笻扶瘦影，甌花泛茗潤枯腸。半生知己連禪榻，奕世同門振祖綱，最是劇懷談不盡，滿天零露欲飛霜。

庭前古柏尚垂陰，遺蹟空存事已沉，唯有汝墳江上月，孤光夜夜照禪心。

合浦珠沉用已潛，瓊漿漫說水晶鹽，墦間總見齊人乞，李下休誇仲子廉。剖石未能憐卞壁，臨風猶易息燈炎，曠懷獨許寒山子，凍筆時呵未放拈。

屈放當時獨善身，何如舍己以從人？簞瓢有意非真樂，裘褐無心不是貧。幾度嶺梅香晚歲，數莖雪竹傲芳辰，年來未覓同文社，孰向窮經間泣麟？

占得幽棲適性靈，東風蘭壑自香馨，如何獨有金剛眼，不向人間逐浪青？

已知黃葉止啼錢，萬里終南獨往還，竹杖頭開撐霽雪，芒鞋跟斷踏春泉。迎風解頰桃將笑，向日舒眉柳欲妍，歸到靈源呈舊面，莫將此話作機緣。

細雨霏霏瀆草根，新晴喜見補燒痕，煙沉濕氣霾山麓，花映寒光照水村。歸雁有聲天際迴，片雲垂翳日邊昏，應知芋火煨衡懶，石上松蘿只自捫。

新晴野望遠山根，草色微微染翠痕，綠水通渠過柳陌，紅霞放眼入花村。泥銜燕嘴香猶滑，醉倒金尊日已昏，何處茶煙高避鶴？松稍占斷虱常捫。

山堂繾綣獨謳吟，歸雁飛飛向北林，蟢有晴絲垂几席，庭無花片惜春陰。尋源不汎漁人悼，滋啘虛懷楚客心，遙憶江南遊詠處，鷓鵠啼落亂紅深。

松風畟畟遠塵埃，鵲噪高枝報客來，古調詠詩傳雪嶺，翠雲捧日照香臺。喜瞻佳句金聲振，坐接清談玉麈開，此際林泉咸屬望，人天一吼響如雷。

涇原南望盡平川，村樹啼鳥夕照懸，蕭相城空耕后土，漢王陵在牧荒煙。千峰落色來天外，二水競流伏檻前，古道無人行跡少，野花芳草自年年。

餘寒消盡屬東風，是處春光物色同，石罅草絲縫漸綠，花嬌桃葉襯偏紅。盈盈一水江初漲，鬱鬱千林畫自工，農許歸鴻歸未得，煖沙由在夕陽中。

韶光二月半春殘，花事紛紜興欲闌，渭北水聲同海甸，終南山色似龍安。菜根香散晨炊熟，土井泉深綆汲難，見說幾多塵世客，茫茫欹枕夢邯鄲。

漠漠川原鎖夕暉，遙天盡處鴈行飛，秦宮隋苑樵歌起，漢寢唐陵牧笛歸。南北山峰青不斷，高低春樹綠還稀，璜雞只在乎蕪外，時有清風拂釣磯。

偶作三秦客，春深涇水邊，衝波看躍鯉、扃院聽飛鳶。茶熟來修靜、詩成寄草玄，嶺南與濟北，祖擔自橫肩。

涇水溶溶臘雪消，春光二月興偏饒，放開柳眼盈芳陌，笑破桃腮綴露條。壟外看雲秦樹曉，風前倚杖楚天遙，池塘綠轉將蛙部，物格由能憶子韶。

蕤柯翠滴半松杉，園杏花飛墜鳥銜，遙憶碧巖高隱處，一簾疏雨論風旛。

曾向文林葆聖胎，仙葩今對法筵開，紅英浥露乘春艷，粉萼農香過臘梅。十里不隨塵馬去，孤村豈逐涵旗回？枝枝笑破頭陀面，戲蝶遊蜂莫浪猜。

絪縕淑氣瑞香濃，本時刪益智功，日檢青箱循舊業，花縈紫菀發新叢。鎖陽山徑無冰片，續斷溪流有木通，竹榻使君過半夏，窗櫺故紙不防風。

露浥芳姿濕絳痕，春暉綺樹麗香溫，光搖晴日參差影，色映江天遠近村。流水何年通釣艇？令人沒世憶仙源，殷勤欲訪漁郎問，寂寞東風正掩門。

相將節序屆清明，土霧昏昏未肯晴，歷世百年虛夢幻，謀生千計泛蓬瀛。座中桃李皆春色，枝上笙簧盡鳥聲，景候遷移憐駐錫，麻衣重補欲身輕。

閒把瓶花插幾枝，翩翩蛺蝶滿庭墀，一簾風細幽香散，縱是瞿曇也不知。

憶爾當年禮覲時，皤皤兩鬢已垂絲，分持衛食臞形怯，遠歷風塵健步奇。芳草無言春欲暮，落花深徑自支藜，西來若問庭前柏，趙老婆心說向誰？

花泫芳叢露、荒原已及春，笻枯形節瘦、苔破辨痕新。處世難知己、臨機不讓人，幽居惟養拙，大塊一閒身。

野色彌芳草，春光逐杖藜，苔生青砌石、燕掠素塵泥。築塢花為徑、裁衣布作畦，南華雖有述，物性總難齊。

雨濕春花艷，風牽徑草長，畋流窮遠水、掃榻倩叢篁。難字書多檢、澄心世久忘，纖纖林外月，疏影落微涼。

卻勝山林僻，而無廛市喧，軍持時貯水、瓦鼎日生煙。雨後園蔬長、枝垂果樹偏，間來書草聖，那復傚張顛。

臨崖俯瞰錦山川，灼灼夭桃氣欲然，爛熳晴霞擬繡嶺，芬縕香霧靄春煙。但教涇水通漁櫂，未必秦時有洞天，青帝若能常似舊，蓬萊無復羨三千。

閒來徙倚悵飛鵬，世厲如羈足韝繩，迷屧常深方丈草，曝陽時補坐床藤。每思立雪巖前可，更憶傳衣嶺外能，誰惜少林西祖意？千峰高處幾曾登？

看山隨野外、曳杖過村前，犬熟無驚吠、榆生有繫錢。青黃兼菜麥、南北雜桑田，景物同人意，風光勝去年。

處處聽啼鳥、行行踏落花，好風牽壞衲、白日映流霞。樹老莓苔積、原平眺眼賒，炊煙新篝火，隔堡是人家。

寺古依平麓、春深靜隱淪，落花紅雨亂、歸雁白雲屯。坐觀無生理、覺從有漏身，萋萋芳草外，不盡醉遊人。

春光疇肯惜，友愛獨相鄰，辨盡諸方眼，師宗未可人。天涯猶布衲、世界老風塵，久矣禪鋒歇，因君話主賓。

小窗聞鳥語，關外故人來，塵世悲戎馬、禪燈冷砌苔。書從前月寄、懷向此時開，離思應無限，深宵話燭灰。

蔡州拂袖自城南，屈指頻過歲已三，別後卻憐消息杳，書來忽得驪珠探。關河暮雨西風疾，江漢春泥燕子含，紙上猶旌興福好，放禪鐘寂久停參。

野外連天草，春光欲暮時，看山移白日、聽樹囀黃鸝。花落風還細、簾疏月到遲，同條千里外，尺素連相持。

春色滿花涇、春光靄戶庭，遠山殘照紫，古柏一林青。墨氣飛香翰、龍蛇走筆靈，千金真罕購，什襲在茅亭。

雨洗空階凈、門關院草深，看花成獨笑、展卷只孤吟。篆裊爐煙散、香浮茗碗勘，何當過問訊？一慰客居心。

繁陰交漸綠，春去夏初臨，花落常疑雨、鳥飛只在林。檢書將擬見、過客喜聞音，想得心齊處，閒雲坐自深。

青青草色滿春池，坐倚南窗檢舊詩，花意不知禪影瘦，破顏猶笑飲光師。

翻盆不住潑天涼，蚯蚓緣階上法堂，點點含生垂樹葉，聲聲冷翠濕苔光。函經飽蠢成雕篆，巢燕饑雛語畫梁，坐看殢雲飛靉靆，墨花詩草硯田荒。

山寺蕭疏過雨頻，蟲聲寂寂久為堙，青迷遠岫高低樹，綠襯沿墻上下茵。畫幔香消梅紙潤，翻經蠹損帙痕新，可憐少室花三放，那識靈苗別有春？

長夏高原事事幽，荊扉獨啟看雲流，虛堂漫自調龍象，諧俗無妨應馬牛。薄暮江天風淅歷，連村晴樹鳥勾舟，殷勤好向磻谿問，近日何人用直鉤？

原高地僻勝居山，雖設柴門亦不關，說法堂前蔬圃綠，沿階石上蘚痕斑。投詩有客長過榻，瞬目無入為破顏，黃鳥時聞深樹裏，高枝不住語綿蠻。

傍池楊柳綠浮煙，半近村居半寺邊，綴露還同隋苑曉，飛花不取漢宮憐。風前嫋嫋思張緒，月下聲聲叫杜鵑，勿謂荒原羈絡馬，長條今已見參天。

奇字相忘近日無，那堪髦俊說工夫？拈香擇火人皆見，種月鋤雲我自圖。子建文章推繡虎，蒙莊岩穴等豐狐，對君不惜金山問，雲衲還將贈碩儒。

三竿過懶廢垂綸，積厚蒼苔滿院新，濕氣尚蒸前夕雨，晴軒猶凈隔窗塵。柏欹檻外頻傾露，鳥語枝頭似喚人，俯仰衡門歌復嘯，誰知此意適吾真？

松門鎮日望南山，碧嶂丹崖杳靄間，秀色詎知供飽眼？明霞相對益頹顏。雨添樹杪峰多翠，水落雲根石自斑，行道比年人似粟，幾能幽壑共雲閒？

深院無人坐亦佳，柴床終日絕安排，吟風好鳥歸清梵，糾月疏林到素懷。向去寒暄都契合，近來言笑總成乖，閒雲解謝車塵跡，長抱青山獨偶諧。

仄室新成搆，簷低我則降，坐禪人在榻、捲幔月臨窗。露下凝珠綱，花飛點石缸，幽棲擬丈室、垂釣憶三江。

岐黃學術素儒冠，三徑田園樂自安，屋後栽松方處士，門前種柳賸休官。童顏不向丹經駐，蓮漏還從白社看，愛爾塵緣姑少暇，時攜鳩杖訪宗壇。

茅檐土榻分元甘，養志崇高自古談，懶瓚黃麻曾止鳳，芙蓉紫服幾回驂。緣從何地今居北？道在隨方任指南，疇念秋深臨祖域，忍將高臥放痴憨。

墻邊多種樹，愛爾獨繁陰，白拂枯僧定、匡床古佛心。枝高根自固、幹老葉還森，圓寂聊相近，翫珠時一。

大暑流金處弗寧，濃陰日午罩槐庭，老榆作枕將移簞，童子敲門欲上經。蝶避炎蒸香翅軟，鶴愁巢孕古松青，獅絃漫調嵩山曲，未識何人為解聽？

山莊習俗慣來頻，高架俳優用享神，媚眼功名今日戲，浮雲富貴暫時人。當場喜著衣冠美，轉盻愁看艷冶塵，做盡機關成一笑，更闌人故總非真。

千林搖落葉飛霜，一帶晴川半夕陽，紫塞沙寒迴雁陣，昆明露冷墜蓮房。旋春脫栗炊新飯，漫記殘編檢舊囊，幾度郢原高處望，茫茫雲樹鬢毛蒼。

去年此日到禪窩，今日攜笻喜又過，已見布金成梵宇，更瞻留玉有檀那。黃花霜徑同緣少，紅葉秋林入畫多，自是願輪超象外，還將寶筏渡娑婆。

經天甲子始週輪，畢集群賢慶誕辰，出世昔曾稱一佛，懸車今已樂三秦。緣從西竺窮真諦，豈羨南華說大椿？居士青蓮詩酒在，知君金粟是前身。

高原獨偃息，巨釣人沉鯨，愛月不關戶、看山還倚楹。秋深平野闊、葉落半窗明，未解幽栖者，空憐白髮生。

一塢如山卜此居，煙花象外賸茅廬，簷非避俗低頭早，榻止容身願足餘。晴霽曉開村樹密，鐘聲晚度夜窗虛，毘耶丈室休嫌隘，獅座何曾滿得渠？

託根依凈土，冥密翠何深？傍石窣花逕、巡擔護榻陰。枝高還倦鳥、節上自虛心，底事相看客，敲門亦為尋。

籍甚清名久，欣傅冠借吳，王心抒速眷、民瘼望來蘇。江闊風帆迥、雲間漢月孤，登庸思碩輔，終始候冰壺。

喜托鄰居近，機緣契獨深，投閒來半日、知妄息三心。麥隴移秋候，河梁動別吟，虎丘多聖蹟，舫到亦相尋。

雅集祇園午夏長，彬彬文質倍風光，詞工白雪塵都凈，句入青蓮世亦忘。燒晚雲霞舖地錦，橫岡草樹噴天香，伊蒲幸飫群公饌，好待栽蓮過草堂。

何處存知己，居然借一丘？若將容我懶，豈為避八讎？野曠蒼煙合，磚拋白璧收，景從懷斗仰，明月滿齋頭。

常思顏子樂，第一出塵流，跡泯形俱化，機忘道可求。鵝瓶欣陸亙，蝶夢托莊周，未到無心地，關情總是愁。

長揖風塵客，還如出獄囚，因無心所住，故有語相投。聽籟從諸響，看雲每獨留，念能枯得盡，底事怕驚鷗。

煙花超象外，寂歷靜何其？屋破從雲補，垣頹任草支。偶因僧索偈，倏爾詠成詩，高士亦來此，社蓮若可期。

雨後稍清暢，幽尋獨坐時，偶舒空裏眼，未是眺中詩。綠蔭前村樹，紅披曙日曦，無人知此意，唯羨義真師。

孤雲蹤跡向關中，野性難堪此日同，投忝那能憐水國？奪標固是羨英雄。籬邊艾葉搖風綠，檻外榴花照眼紅，聞道品題賡白雪，寡酬還應屬文翁。

好掛詩瓢翠靄中，幸逢佳節賞心同，爐錘易襲雕龍隱，蒲酒爭看畫虎雄。階面苔深長掩綠，墻頭杏熟爛堆紅，從來詞翰非吾有，得失何關付塞翁？

林間掃石合堪眠，竹報相邀過士筵，鹿豕性情如是佛，麒麟勳業恐非仙。安心久已離諸妄，遊樂何妨涉眾緣？若問西來端的意，雞冠花發秀階前。

天霽雲收曙色開，芒鞋濕露半粘苔，積塵一夜風吹去，初日高林影射來。花自密時聞鳥語，樹當闕處見樓臺，推敲漫學騎驢背，敢倩文公逐句裁。

水邊林下道人家，物外幽閒絕市譁，未把琴書消世累，只將耕稼樂煙霞。青霄摶翼卑圖鳥，白業修身馭大車，邀我一餐禪悅飯，庭陰午過夕陽斜。

莫厭天涯頻作客，且回淚眼息征衣，禪房寂寞堪瀟灑，凈土於今正好歸。

翛然一榻寄樓中，四壁蕭疏孰與同？只見悲愁憐宋玉，豈知玄草誤楊雄？雲書雁字行飛白，葉剪霜林醉落紅，何處砧聲催暮雨？閑忙得坐看鄰翁。

名花只合在瑤臺，誰遣丹青妙筆裁？巧奪洛陽枝上色，真如懸圃苑中開。繁華眼底空塵跡，濃艷春長送客杯，未是沉香亭畔友，奴郎不用妒詩才。

一種超然凈有神，誰將賦粉汙埃塵？還疑薝蔔林中影，誤作同昌觀裏春。潔性那堪供俗眼，素心終是識高人，幽齋展去閒清翫，笑殺凡夫錯認真。

兩年音問隔西東，總是關河路不通，非謂宣尼憐鳳德，豈同阮籍泣途窮？高林半帶村煙落，遠水多從夕照紅，東望汝墳叢席地，可知吾道近汙隆。

胡為一別阻秦山？數載關河信息難，天上槎浮還寄石，人間路險是重關。巾瓶久念師心切，菽水疏違子道艱，那得長房能縮地，千峰深處奉慈顏？

勝地偏幽僻，亭依曲水迴，翠雲籠樹合，香露滴花開。空響風鳴葉，鞋拖徑滑苔，本無塵世擾，擬應到蓬萊。

群木搖池影，遊鱗亂若登，花將亭榭密，水欲岸沙崩。風落新松子，龍蟠老樹藤，隔溪人語響，飛鷺起前汀。

水際蒼煙合，行來路轉迷，晴吹魚戲浪，風掠燕銜泥。遠岸迎花笑，高枝聽鳥啼，逍遙忘倦屧，拄杖日相攜。

樹色搖空翠，花光曖路熏，過橋方塔見，隔水定鐘聞。月墮松間影，天垂野外雲，徘徊相顧步，徑草綠微。

高木晴簷外，空濛水氣騰，藂汀鷗鷺密，灑露竹枝升。梵韻連暉響，花稠半客憑，幽然蘿徑窈，得片看飛麟。

## 蔡志八詠有序

嘗閱郡邑諸志，皆勒八景，名人多倡和之，以備采風者知山川景物之勝。新蔡亦有八詠，閱志之暇聊為效顰，貽譏不恤。

夾岸垂楊鎖暮天，澄江一望水茫然，鷗眠別浦閒沙際，鳥趁歸帆集樹邊。晚色綠沉平野翠，晴霞紅映遠村煙，耦耕沮溺今何在？尚有行人問渡船。

雨歇長林爽氣清，嵐光遠霽蘸新晴，粘花未破紅猶潤，染草初勻緣尚輕。霧捲南天高楚岫，雲開北闕拱神京，更於何處堪登眺？碧水橋頭夕月生。

衝波逆折倒回流，雙合龍津杳靄浮，瀲灩水光晴盪口，空濛樹色影涵秋。輕鷗數點鄰魚火，奔馬千帆過客舟，應是詞源鍾豫汝，長風破浪自悠悠。

桑苞蠶事日紛紜，布穀催春谷口聞，井字分畦通舊陌，瓜藤蘸水漲斜曛。長驅犍犢行耕雨，暫歇犁鋤坐綴文，放牧歸來天色晚，笛聲吹破一溪雲。

九溝新水接天涯，溪上漁人樂自嘉，紅蓼岸邊晴曬網，白蘋洲畔釣橫車。流雲半度纖歌遏，澀浪微分短櫂斜，沽酒不辭青旆遠，歸來和月臥蘆花。

東望澗頭鳥不飛，濛濛雨色掩朝暉，青迷柳眼陰旋合，紅綻桃腮蕊漸肥。麥壟纔沾上潤，江城但覺冷煙微，何如蘇亢為霖去？灑春疇處處霏。

依依柳色野橋虛，沐雨梳風任自如，繫馬條柔還掩映，藏烏影淡只蕭疏。翠絲時纖鶯梭捷，青眼頻窺燕語餘，遊子坐忘歸去晚，幾回搔首更躊躇？

古寺風高萬木蒼，一泓澄澈有龍藏，灘聲韻落含宮徵，樹色光生映晚陽。不向禹門分錦浪，潛通汝水入淮長，傳聞旱禱蘇農困，願沛甘霖潤入荒。

不玄都麗，來分梵苑春，武陵持櫂者，總是世情人。開落誰知幻？品題自覺真，堪嗟塵土客，歲歲問迷津。

孤山真逸種，誰植在禪房？影瘦情元淡，香清味更長。素心能傲雪，冷艷獨欺霜，自別林逋後，何人看鶴翔？

聞道能棲鳳，根培自有年，取材枝尚古，聽燢客偏憐。葉響沉秋雨，陰森覆午天，飆風驚忽至，飛瀑下鳴泉。

未放先成葉，紅嬌襯緣陰，昌州云有別，工部獨無吟。簾拽風枝動，階移月影沉，從來仙品異，金屋豈能禁？

金色佳公子，枝頭送好音，掠郊穿樹密，修羽落花深。到處唯求友，他時卻在林，上方風日靜，塵世莫相侵。

色以黃為正，餘皆未足倫，此言聞古者，嗜好自今人。秋老能離俗，霜清不染塵，唯教陶令賞，醉裏獨知真。

拈花高閣勢崔嵬，雲棟風窗次第開，水色虛涵空世界，林光簇擁玉樓臺。

竹護窗虛接野塘，淨心宛在水中央，長林只許高僧臥，滿地松陰月一床。

霜葉蕭疏點碧嵐，平湖湛湛隱蘿龕，那知大士棲真處？水月溪前話指南。

無肉何如有此君？名流風韻昔時，亭閒坐愛探詩卷，秀色拖煙欲墮雲。

千章古木盡陰森，赤日行天暑不侵，有客逃禪成午坐，利名灰冷盡塵心。

塘邊野竹映寒空，石架危橋接梵宮，月上松門垂倒影，卻疑飲浪下長虹。

千樹垂絲兩岸莎，水天涵碧點青螺，輕舠不放遊人醉，酌向中亭賦綠荷。

雨徑香生淡若秋，萬竿清灑最深幽，彈琴坐對微風起，墮眼空青翠欲流。

長堤楊柳接湖心，一徑瀠迂幾許深？微笑那堪亭子上？春風拄杖日來尋。

一溝新水護招提，桐葉吹花湛碧溪，蘆荻自深塵跡少，往來橋上漫扶藜。

露電光陰夢幻身，綠雲紅雨不勝春，一莖草上乾坤別，勘破當年舊主人。

竹樹深藏水一方，山陰何必問流觴？萍開蕩漾輕舟去，轉過林花見草堂。

寶帶欣留信有因，錦袍錯落稱閒身，當年坡老風流甚？猶有題橋繼美人。

晴雲擘絮柳初柔，桂楫銜杯樂聖遊，九曲六橋花外轉，海山何必問瀛洲？

堤當斷處有橋通，一石長跨百尺虹，見說天台峰頂上，飛泉六月灑寒空。

矮柏千株繞院青，天龍長護塔中靈，豐碑昭豎傳燈永，從此南塘是祖庭。

空翠微分曙色開，高林日射影初來，何年驚起潭龍臥？剩脊長橫在水隈。

寶塔凌霄聳梵宮，層層搆結玉玲瓏，中心未止藏龍象，想助交華豎筆峰。

綠陰深靜日初長，醒眼花光映草堂，偶啟竹窗聞鳥語，林風吹過煮茶香。

小橋長駕碧溪頭，今古行人濟未休，試看道傍楊柳樹，長條折盡短條桑。

迢遞青門憶舊遊，別來今復見新秋，香吹籬菊含朝雨，水落江天起暮鷗。筆札久無鴻雁到，津梁應繫故山愁，遙想法社獅猊座，異日還當著聖流。

萬木蕭蕭落莽蒼，江城西望立斜陽，飛鴻始覺關河遠，尺素寧辭道路長？海內法幢還似昔，天涯人世已非常，十年揮麈談心處，杖屐相過記未忘。

千村木落曙煙寒，恨別關河憶昔難，故舊天涯真是遠，新知海內幾為歡？鶯聲每到林間聽，雁足還從嶺外看，午坐虛堂唯隱几，夢魂由自在長安。

十載秦川喜共尋，歸來此日已秋深，只緣風木思廬墓，敢向雲林惜寸心。北地時看鴻雁字，西方常憶美人音，晚風獨立溪橋上，遙望關門恨夕吟。

金英殘菊媚籬光，蜀客歸心路渺茫，曠別多年纔一會，離情此日正重陽。霜沉江樹排秋岸，水湛晴莎映野塘，歸到故園松菊在，莫愁無酒醉花傍。

天中汝穴桂昌昌，濟北宗師大樹行，臥去林泉聲望重，參來湖海道風長。一籬菊綻憐秋晚，片紙書成託雁翔，此日絲危垂祖道，何時排闥起汾陽？

紫雲縹渺降仙真，五馬堂開正小春，雪映庭柯輝寶樹，冰清汝水淨埃塵。鶴琴聲著衣冠美，繻褲歌揚德澤新，更喜弧光台省近，循良早已卜楓宸。

冬寒愛日步林垌，拄杖尋詩過草亭，撲面霜花飛地白，打頭風葉落天青。懷人每憶三生石，遮眼唯憑一卷經，聞道故人千里至，免將幽意託鴻冥。

鮦陽近代有王生，楷書精妙擅時名，風流不減王內史，體勢更愈歐率更。毫書工罷操鐵筆，露灑星飛落磐石，錚錚風樹入秋聲，恍如靜夜神鬼泣。飛龍鳥跡事杳茫，周宣石鼓裂岐踢，倒薤籀文今已矣！蘭亭幕底徒悲傷。王生筆藝妙天下，鐫我師銘永光大，何如盛貯篋笱中？一日汝南高紙價。岣嶁峰頭總不如，鐵心穿硯淬鋒初，太平天子紀功績，金券還當待爾書。

玉梅香噴五雲開，此際欣逢嶽降來，鵬翼早驚騰萬里，春風今喜育群才。尊傳北海文章盛，筵對南山壽域培，佇視上林迎鶴駕，珊珊劍佩近三台。

節序嚴冬暮，中宵忽震雷，勢傾驚地坼，聲發迸天開。雪霰風還勁，江寒浪復摧，天公知有意，浮世漫相猜。

烏啼漏盡曉寒催，臘去春回曙色來，雲隱雕甍金闕迥，經傳繡帙玉函關。爐煙裊裊迎獅座，淑氣蒸蒸拂寶臺，仰祝吾皇無量壽，諸天鐘鼓震如雷。

當年微笑說拈花，此日名亭意頗賒，座列諸賢推象馬，機詶一語定龍蛇。看梅暖放窗前蕊，煮雪香生鼎內茶，理策歸來池上望，眠鷗兩兩聚汀沙。

春日臨河一問津，流凘皺碧水粼粼，青欺岸柳將辭雪，綠轉商船欲礙蘋。岐路已知無墮淚，耦耕猶記說前人，轍環漫謂無機智，聖道於今盡屬塵。

春城花月影遲遲，送子亭皋悵別離，一帶曉煙村店柳，幾行歸雁旅人思。關河目斷黃塵暗，客路春深碧草知，歸到長安如有問？南塘新水漲春池。

曲水抱城流，舟橫古渡頭，長空群雁過，到岸一帆收。蟄起蛟龍窟，翔迴鷗鷺洲，欲尋仙子住，遙望白雲浮。

憶別西風歲幾更？憐君又徙隔江城，黃金有藥誰求得？白髮無情事可明。雨後看山隨足健，花前倚杖趁春情，應知四大虛調攝，學得無生勝養生。

何緣歸興遽匆匆？去住關心彼此同，兄弟鬢斑身俱老，師龕株守歲何窮？奇峰矗矗荒煙外，客路萋萋野草中，為憶白雲深密處，宗壇遙望振家風。

茅屋幾人家，板橋仄徑斜，秋林晴亦雨，春塢暖多花。

曾向林丘度歲華，菜根滋味共吾家，不誇元禮登龍客，豈羨張騫泛斗槎？入社喜知今日是，折腰幸悔昔年差，一尊詩酒青山在，滿壑松陰待墨花。木菴善書，故云。

十二瓊樓敞玉扉，金英浥露菊初肥，風清羽駕臨丹鶴，嶽降嵩靈下紫薇。淮甸穗岐歌政美，鮦陽化洽沐春暉，此時載道歡聲滿，聽祝沙堤待漏歸。

淡淡香風透竹門，孤山清韻孰銷魂？芒鞋不惜春光遍，踏到溪南第幾村？

正月中旬已動雷，仲春日見雪飛來，黃金凍折池邊柳，白玉摧殘閣外梅。石砌都平迷鶴徑，竹床常冷護冰胎，豐年不用多為瑞，米貴柴荒處處哀。

佳景寧幽遯，高人過結緣，雪消梅影瘦，春上柳枝妍。學就今時悟，經元舊日傳，心齋云坐久，即此是逃禪。

幽尋拄杖過田家，二月山桃未放花，隔水籬根聞吠犬，荒塘牛背有棲鴉。千塍麥秀浮村緣，一帶春晴趁竹斜，遙望炊煙出樹杪，重重茅屋碧雲遮。

院深苔色靜，風定鳥聲和，只應野人住，那堪高士過？關鐘停午課，爇鼎煮松蘿，相顧忘言笑，冥心契若何？

帝里賢書貴，先推製錦來，春雲籠月檻，花霧靄琴臺。麥岐民無餒，褲歌禁有開，風煙百里靜，瀟灑稱清才。

送客當春候，夭桃艷欲飛，騎塵人去遠，花埭鳥爭歸。一席青氈冷，雙親白髮違，何時旋馬首？傾想落珠璣。

積雨空林久，三春花事稀，秪看苔滿徑，那更日關扉？疏磐沉煙濕，寒雲逗竹飛，柴荒兼米貴，缽裏孰知饑？

兀坐清除寐，中宵覺爽然，挑燈明佛火，續篆裊爐煙。雨咽鐘聲暗，風狂水氣懸，想當塵土客，應著祖生鞭。

殢雲朝復夜，春木雨疏疏，破悶親茶碾，評詩對草廬。欲籌經世策，還讀古人書，何處尋真隱？予同卜此居。

水近寒生卑，茅堂睡起遲，青山終有待，白髮應無私。梵筴雲常護，匡床首自垂，紙窗塵跡暗，衡點日相貽。

松扉長掩綠，禪坐漏深時，已得安心法，何須歎路岐？肆情歌自放，脫穎事誰思？鷲嶺拈花意，參詢幾個知？

桐葉當檐靜，枝間聽鳥鳴，披衣還起坐，拄杖一經行。石畔茶煙豁，花邊露氣清，隔墻入語亂，總是不關情。

矮榻從雲度，翻書任鳥窺，徑迷煙草合，牖起竹風隨。苔長經旬雨，水深到石涯，寒煨榾柮盡，應得午炊遲。

深林春雨密，蘚滑徑為讎，水滿橫塘鷺，雲迷過客舟。床頭林靄濕，砌下水泉留，還憶宜都石？鞭能可一投。

池草芳春綠，詩懷觸處生，粘花交露重，睡鴨襯雲輕。雕技年來廢，幽思夢不成，相過投句客，應讓占時名。

## 送子勉宋郡丞之任敘州永寧衛

又代

雨苔生翠滿階除，嫩草新蟬意莫如，渴病已銷茶灶火，心王久遣倦魔書。每看蟻子尋腥誤，堪歎痴蠅逐臭虛，澗飲松餐能幾得？只安魂夢在蝸廬。

梵音高唱肅爐熏，曙日晴開萬樹雲，旛影乍臨猊座暗，磬聲初落下方聞。三身佛號傳天竺，萬壽歌揚祝聖君，廬嶽不須重問社，如今四海喜同文。

燒入祗林映赤霞，晴烘寶樹半雲遮，蟬聲處處驚飛葉，草色萋萋帶落花。駁地蒼苔蝸作篆，橫塘白水鷺為家，涼秋不禁單衣褐，獨立風前數暮鴉。

滅跗青蛙岸有衣，銜泥紫燕日爭飛，亭遮楊柳遵沙渚，水汎桃花繞釣磯。竹暗橋邊三徑杳，月明林下一僧歸，忘機自是閒鷗鳥，無那鐘聲出翠微。

聲光早著邁同儔，百丈津梁據上流，鯨釣今看垂激水，獅絃昔撫振中州。遙瞻海上籌添屋，應笑人間杖刻鳩，無位真人長浩劫，火雲堆裏駕慈舟。

剪雲將補破袈裟，落葉堆堆覆結跏，千里同風來楚客，一杯水渡自龍牙。欲恢祖域清魔斧，特詣都門叩帝家，盛世於今隆外護，宗壇終復看拈花。

空林養拙戶常關，古柏陰森盡日閒，結課人來溫洛社，栽蓮客到白香山。齋清古水聞高詠，石瘦寒梅見破顏，攜手橋頭重話別，紛紛倦翼鳥飛還。

纔欣無事到林丘，一榻翛然萬慮休，脫木棲鴉渾似葉，荒雲宿鷺靜如秋。窗前雪褁梅爭放，石外煙消竹自幽，從此萍蹤無定止，暫將幽興寄溪頭。

如梅似絮亂空飄，一色虛明望裏遙，白占疏林先樹見，翠埋欹竹幾枝饒？淺深莫辨溪邊路，高下難分水面，縱使世間煩熱處，自從經冷便魂銷。

飄飄瑞雪滿園林，靜掩松門宿霧沉，定缽香傳鐘鼓暗，虛簷梅拂草茅陰。詩懷頓發高人句，大地開明古佛心，訪戴無能重覓棹，空將幽思付閒吟。

閉戶常終日，堆堆雪滿林，靜中無世慮，淡處見禪心。蝶夢隨莊化，雞談羨宋深，吟懷思叔度，悵望野雲沉。

塔院欣初住，方塘始結冰，簷棲巡凍鳥，雪片灑寒燈。永日誰相得？干時我不能，往來溪上路，拄杖一枝藤。

安拙從吾志，衡門興自嘉，烹茶吟月色，鄰笛落梅花。葉滿林間路，鷗眠渚上沙，從來疏懶性，應得看流霞。

茅屋東林側，柴門傍水開，石邊幾個竹，窗外數枝梅。客為看花至，僧多禮塔來，悠然逸興遠，竟口一徘徊。

## 塔院新居三首

其二

其三

祖擔重挑借息肩，從來法社著英賢，山頭躍鯉聞新唱，室內傳燈憶舊緣。翠竹風敲聲愈古，靈松雪老色偏妍，看將一勺南塘水，為雨為霖潤大千。

老去心情只愛山，何時歸去足清閒？門常草掩塵緣少，石自苔封世絕攀。折木隨風供爂底，引泉倩筧到廚間，白雲嶺上誰收拾？飛去飛來任往還。

池邊竹樹接香臺，殿閣參差傍水開，拄杖有時閒自適，看花聽鳥幾回來？

四載南塘有勝緣，棠陰借蔭得安禪，心空妙諦王摩詰，道契真乘楊大年。案牘豈知元貝葉？宰官須信即金仙，暫虛前席遊西土，異日重栽白社蓮。

春城和煦靄氤氳，敝褐支笻袂欲分，璧水春晴延蔡國，嶽蓮曉發望秦雲。千村夕照鴉翻陣，萬里風高鶴破群，從此天涯魚信遠，何時尊酒再論文？

倦鳥思林欲息飛，短笻支草綠還微，金含柳色迎官路，玉破梅香襲客衣。水國天晴魚躍暖，關門地迥雁行稀，臨河不用多傷別，自是雲情得便歸。

杖笠棲遲近四年，逢場竿木只隨緣，六橋花雨飄金錫，一徑松濤洗翠煙。塔院種成棲鶴樹，池塘鑿就養龍淵，於今無愧林泉去，更冀香幢起法筵。

千斤祖擔誠非易，拄杖橫肩獨自行，雖續傳燈猶愧子，未能弘法尚慚生。光分麈尾承先澤，派衍滹沱冀後莫，此日塔前空拜別，淒涼風木痛含情。

一笠春風拄杖頭，驪歌曉唱出林丘，已看師友成新席，無那因緣續舊遊。花發林間競蕊放，雪消河畔解冰流，臨岐一語無多囑，祖道垂危賴爾儔。

春日融和喜載陽，玉華璀璨噴梅香，乘風破浪鯤將徙，布字凌雲雁正翔。紫茁蘭芽增地秀，紅苞杏蕊見天章，何緣惠我驚人句？敢惜珍藏念不忘。

華河正憶放參鐘，歸興長於詩興濃，兩隻草鞋獰似虎，一條拄杖活如龍。煩君壯志宗當振，愧我殘年老更慵，此日淮康相話別，春晴客路草茸茸。

祖道垂危正及秋，全瞻砥柱屹中流，障回汝海千波靜，坐斷雲峰萬壑幽。柏釀泉聲鄰翠巘，風敲竹韻入高樓，何時再詰風旛論？共掃莓苔坐石頭。

四載離關內，重來更覺新，露桃初放蕊，官柳正知春。社享民扶醉，田歌韻絕塵，柴桑良有士，尚憶虎溪人。

雪盡郊原百草生，春和處處有啼鶯，柳遮翠陌煙初合，花落紅畬野破耕。亂石到溪流水響，長林放眼遠山晴，滄桑幾度非韋曲，野老猶傳舊日名。

石徑穿雲到翠微，日高山寺未開扉，閒中品物輸龍象，物外煙霞信衲衣。塔隱靈松蘿欲放，花銜深谷鳥方歸，山居道者忘塵慮，獨坐蒲團久息機。

蕭條門徑不堪憂，車馬何緣肯一遊？色映雕甍搖棨戟，香浮金韉駐驊騮。久知姓字參龍榜，已睹奎文壓虎頭，攬轡澄清天下望，忘機未許狎輕鷗。

松煙濤聲入夢流，驚回明月到梁頭，人懷短髮心同素，竹對長竿笻共遒。展卷豈能齊上策？看山還復步平疇，何緣寄我瓊瑤周？快意如登謝眺樓。

得幽棲不買山，鄰居近喜接禪關，文章虎繡三川外，世業龍圖八水間。醒眼談能忘物去，醉心終是愛雲還，獅床待坐何時借？四大空空只自閒。

花落禪房厚作茵，老榆木枕就閒身，簷前雀鬥驚回夢，階下蟻爭已聚塵。斷壁走蝸文字古，空林過兩石苔新，誰將伎倆隨莊蝶？嗟彼蘧蘧負一春。

滿樹嫣然蜀錦堆，群芳落盡蝶蜂來，光含瑪瑙英初結，色孕燕支蕊乍開。六月火雲燒不死，一林香氣暑還裁，靜觀道者情元幻，缽底松花得共陪。

高牙風拂動長安，臘盡春回朔氣寒，雪噴玉梅開虎帳，桃迎金母餽螭盤。稱觴士躋元戎府，推轂鶯遷上將壇，獻歲明朝欣令節，長庚光耀五雲端。

皎皎枝頭冒暑開，清香時拂妙高臺，絕塵自是冰心老，傲熱還從雪嶺來。天上銀河乘夜淨，人間玉樹逐鸞回，幽芳未許他相並，游戲蟾蜍莫浪猜。

翠靄重重祗樹林，山廚宿雨曉煙沉，花光寒映墻頭濕，柳色風搖屋角深。四野草萊宜祖意，滿庭松柏靜人心，懶殘別有超方句，未許時流造次吟。

策蹇南來人古城，綠雲金地菜花生，柳舒官道青垂影，鳥搆危巢屋傍鳴。蔬圃緋連開杏色，柴門靜掩讀書聲，西方原隰消磨盡，野老紛紜試耦耕。

薰風拂拂火雲屯，天大將軍此現身，五百期昌名碩士，三千桃實獻真人。威行邊塞烽煙靜，澤及關河雨露新，暢好豐功榮八座，登壇早已卜楓宸。

離城未十里，南面是終南，塔占雲松古，花沉露朵酣。閑欹臨蘚石，自掃啟香龕，眾數酬人問，前三與後三。

庭際陰移樹影斜，鑣鳴歷歷近山家，光生畫戟朱纓麗，劍列星文柴氣賒。虎雲屯圖甲士，龍旗風動駐雲騧，山堂不盡談心曲，鼓角聲催候晚衙。

見說牛頭寺，層岩最上頭，田衣僧畎畝，石瀨鷺汀洲。興至情都遣，詩成景盡收，何時策杖去？日日共追遊。

名山勝地足遊觀，石磴縈紆上幾盤？樹色一林春入翠，花光滿院露凝寒。壁間題詠多詞客，潭底潛龍少釣竿，遙望終南岩壑好，又拖拄杖過層巒。

詩學從來仰大成，當年藻思動神京，荒祠宿莽鴟頭暗，野店炊煙谷口橫。海內文章人盛昔，夔州詞賦氣還生，豪吟已逐空山盡，騷客由含弔古情。

金勒郊巡到上方，朱纓簇簇禮空王，伊周世業勳名重，夔契經綸撫字良。午夜月明關塞靜，中書風動墨池香，宸指日遷調鼎，佇看鹽梅沛澤長。

氤氳紫氣接香臺，道是吾公嶽降來，仙使翩翩迎玉珮，梅英冉冉拂霞杯。河陽續著花多種，魏闕名高錦讓裁，此日關中欣介壽，弧光早已近三台。

雲峰遙望華山尖，喜和新詩筆數拈，每歎人龍懷馬岌，難裁別恨賦江淹。心齋已見形神化，面壁競聞世口箝，為語折中高尚士，時清不用更求潛。

見說峨嵋去，幽懷憶昔時，岩深千丈雪，樹老萬年枝。有夢勞傾想，無愁惜別離，峰頭如到日，為念爾題詩。

雪霽空明映遠山，旌旗閃爍到禪關，風吹鼓角威聲壯，日射金田曙色閑。問法竟能忘世相，籌邊早已靖驕頑，賢臣不待王褒頌，知在凌煙第一班。

## 葛制臺見過

關中八景，朝邑朱明府繪圖題詠，勒石於長安費宮之墨峒，一時聞人韻士競相屬和。偶客過，子曰：「師於宗門通文字禪，可能為我一一詠乎？」遂應之，各賦一首。

山客積素凝清標，夕陽西映光迢遙，峨峨顥色絕氛，千古萬古摩雲霄。猿鳥飛攀不敢度，仙客碁蹤恐亦誤，變幻須臾煙霧橫，瑤臺瓊室知何處？

華嶽峰頭有奇異，五指參差撐絕壁，雪霽高懸掌跡明，攫霧拏雲搏白日。傳聞巨靈擘此山，東措王屋西不還，神功浩杳難可測，層崖空望不可攀。

碧葦紅蓼兩岸斜，沿汀鳧雁圖平沙，車馬黃塵來何處？渡頭競立心紛挐。白波篙動羅紋捲，水勢吞空客路遠，到岸爭聲語亂譁，日腳明邊看策蹇。

風弄柔條柳欲折，狂花飛作江天雪，三川秀色掩糢糊，灞水沆漭聲決決。撲地成團吹作堆，行看客騎共徘徊，忽然捲盡青山出，紫燕翩翻掠徑來。

春水年年綠滿地，遊人口日鬥花枝，酣觴側側搖波影，翻手探囊索賦詩。翠輦不來春已老，陌上殘紅空自好，為囑封家十八姨，殷勤點綴池邊草。

露下客衾寒氣重，鐘聲何處驚殘夢？隱隱城南半徹天，星沒銀河光欲動。鄰雞聲亂隔垣啼，曙色微茫日漸曦，款段欲騎出門去，滿地炊煙竹院述。

鐘磬訇訇度雲水，塔尖隱隱露山麓，炊煙散作霧滿川，樓閣微茫隔村屋。板橋橫接竹問扉，數疄紫芋黃精肥，十萬紅塵飛不到，樹裏時見一僧歸。

殘日林光潑翠巘，鴛瓦鱗鱗砌宮殿，繡嶺春殘花事稀，溫湯香逼浮金韉。麗姬烽火聞自周，華清宮漏說唐留，遊人博醉橫山麓，臥看紅紫眩峰頭。

蓬心無日不西州，憶別經年又復秋，鄉國幸同居錦水，詩懷喜共話林丘。延平道在誰知己？倚馬才雄自少儔，欲寄魚書清渭遠，蒹葭極目思悠悠。

宿雨今方霽，閒愁得暫寬，苔荒多屐齒，溜盡少風湍。村落斜陽裏，岡巒夕照殘，穀登完歲歉，殊覺有餘安。

臨風倚杖立黃昏，畏虎人家早閉門，蔓草離披山下寺，炊煙歷亂水邊村。峰敲磬落飄空度，谷唱樵歸宿霧屯，遙望五臺天色暮，瀑花濺石動雲根。

青陽舒節候，拄杖亦幽尋，春色花包藥，泉聲石漱琴。傍村連竹塢，夾徑落槐陰，意念樊川久，沿溪不厭深。

金風初振絡緯啼，申甫維靈又降西，仙馭青來鸞作使，關門紫映氣為霓。百城屏翰瞻寮寀，五褲歡歌聽庶黎，此日九如申祝頌，徵書乘傳有沙堤。

牛頭岩寺古，見說好林間，松老龍鱗集，雲深鶴夢閒。道心生寂歷，塵世絕追攀，往往投焛客，將金欲買山。

詞客名花兩會難，新詩貽勝九還丹，禪心已逐孤雲靜，色相空空孰解看？

晴和晷運喜初陽，嶽降春城此日良，杏吐紅霞方水，蘭苞紫砌正吹香。民謠已驗關中化，帝齎還瞻魏闕光，方外久知容借座，向妨介壽一稱觴。𣇍

柴門一望煙橫，雲樹蒼茫隔近城，新竹乍看青玉出，榴花偏照碧窗明。翰香忽起龍蛇潤，藻句俄傳燕雀驚，欲就趨庭陪鯉對，不堪懶性許誰爭？𥌓

春去郊園蝶粉輕，深林古寺尚寒生，花英檻外飛無影，燕語梁間聽有聲。霧倦千山朝旭靜，村連萬樹晚霞晴，共將茗碗消凡福，來往香臺不厭頻。

咫尺青華未可通，上方臺殿碧雲籠，樵歸山徑莓苔滑，鳥啄村園柿子紅。澗底聲喧連日雨，簷前鐸報一天風，明朝拄杖憑虛上，萬井千畦眺眼中。

鳥道盤空上，紆迴石磴斜，探奇踰翠嶺，乘興過青華。樹杪危峰墮，雲根宿莽賒，香清芝浥露，澗響瀑飛花。薜荔巖多隱，莓苔徑半遮，林翻猿振嘯，石迸竹抽芽。遠岫排為障，細流匯作洼，名山真可樂，塵世寂無譁。髮素憐渠瘦，心灰愛爾佳，數椽堪偃息，共此老煙霞。

暫借峰頭一宿眠，身輕猶在史多天，欲知現業無岐徑，已料前因有勝緣。夜靜風來號古木，山深雨過響流泉，幽情自是清人骨，好待開池種白蓮。

龍命分符出御墀，奚囊琴鶴更清奇？供需直駕蕭何術，強富寧誇劉晏儀？勵節一壺冰玉映，憲邦百度豸輪樊，新秋喜接新遷報，願偕滇南寇一時。

山寺倏然到宰官，蕭條門徑不生寒，言中透脫機先峻，句裏藏鋒道覺寬。色映翠蘿朝雨過，聲傳嬌語暮鶯歡，宦情肯覓消閑地，滿目雲松不厭看。

當年形勝說玄都，觀裏千桃樹已無，不見星官占斗極，惟看村舍起田廬。狐穿土穴藏高塚，鶴去仙壇盡宿鳥，紫氣銷沉蹤跡杳，長空夜夜月輪孤。

名稱四得壽居先，弧矢重看此日懸，寶瑟聲聞仙子駐，瑤華香度海桃鮮。功超大禹齊前聖，績懋平江裕後賢，咫尺三台咸屬望，萬年歡奏樂鈞天。

聲光赫奕仰天童，崛起皋亭道獨雄，三尺青萍全殺活，一條白棒打虛空。山花映水生紅浪，野鳥呼人下翠叢，應是祖翁家法在，佇看寰海振宗風。

萬里長江水，扁舟渡去輕，金山看有寺，鐵甕擬無城。浪拍鼉聲震，波翻日色明，從來湖海志，更欲釣鯤鯨。

鴛水湖邊煙雨樓，高城日上涌江流，憑欄俯瞰千門曉，觸目豪吟萬里秋。方外乾坤輪野衲，閒中日月讓輕鷗，蒹葭極盡滄波外，應有羊裘在釣舟。
