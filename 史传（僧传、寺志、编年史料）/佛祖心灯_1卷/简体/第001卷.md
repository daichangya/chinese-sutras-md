# 佛祖心灯 · 第一卷

---

身从无相中受生，犹如幻出诸形像， /
幻人心识本来无，罪福皆空无所住。 /

起诸善法本是幻，造诸恶业亦是幻， /
身如聚沫心如风，幻出无根无实性。 /

假借四大以为身，心本无生因境有。 /
前境若无心亦无，罪福如幻起亦灭。 /

见身无实是佛身，了心如幻是佛幻， /
了得身心本性空，斯人与佛何殊别？ /

佛不见身知是佛，若是有知别无佛。 /
智者能知罪性空，坦然不怖于生死。 /

一切众生心清净，从本无生无可灭， /
即此身心是幻生，幻化之中无罪福。 /

法本法无法，无法法亦法，今付无法时。 /
法法何曾法。

法法本来法，无法无非法，何于一法中， /
有法有非法。

本来付有法，付了言无法，各各须自悟。 /
悟了无无法。

非法亦非心，无心亦无法，说是心法时， /
是法非心法。

心自本来心。本心非有法，有法有本心。 /
非心非本法。

通达本心法，无法无非法，悟了同未悟。 /
无心亦无法。

无心无可得，说得不名法。若了心非心， /
始了心心法。

心同虚空界，示等虚空法，证得虚空时， /
无是无非法。

虚空无内外，心法亦如此。若了虚空故， /
是达真如理。

真理不无名，因名显真理，受得真实法。 /
非真亦非伪。

真体自然真，因真说有理，领得真真法。 /
无行亦无止。

迷悟如隐显，明暗不相离。今付隐显法。 /
非一亦非二。

隐显即本法，明暗元不二。今付悟了法。 /
非取亦非离。

非隐非显法，说是真实际。悟此隐显法， /
非愚亦非智。

为明隐显法，方说解脱理。于法心不证， /
无瞋亦无喜。

本对传法人，为说解脱理，于法实无证。 /
无终亦无始。

于法实无证，不取亦不离，法非有无相。 /
内外云何起？

心地本无生，因地从缘起，缘种不相妨。 /
华果亦复尔。

有种有心地，因缘能发萌，于缘不相碍。 /
当生生不生。

性上本无生，为对求人说。于法既无得， /
何怀决不决？

言下合无生，同于法界性。若能如是解， /
通达事理境。

泡幻同无碍，如何不了悟？达法在其中。 /
非今亦非古。

心随万境转。转处实能幽。随流认得性。 /
无喜复无忧。

认得心性时，可说不思议，了了无可得。 /
得时不说知。

正说知见时，知见俱是心，当心即知见。 /
知见即于今。

圣人说知见，当境无是非。我今悟真性。 /
无道亦无理。

真性心地藏，无头亦无尾，应缘而化物。 /
方便呼为智。

心地生诸种，因事复生理，果满菩提圆。 /
华开世界起。

吾本来兹土。传法救迷情。一华开五叶。 /
结果自然成。

本来缘有地，因地种华生，本来无有种， /
华亦不曾生。

华种虽因地，从地种华生，若无人下种， /
华地尽无生。

华种有生性，因地华生生，大缘与信合。 /
当生生不生。

有情来下种，因地果还生。无情既无种， /
无性亦无生。

心地含诸种，普雨悉皆生。顿悟华情已， /
菩提果自成。

迦文迦叶阿难商，优波毱多与提多， /
弥迦婆须佛伏，脇富马鸣迦毗摩，䭾 /
龙树迦那于罗睺，僧伽伽耶鸠摩罗， /
阇夜婆修摩拏鶴，师子婆舍不如般， /
达磨传于东土后，慧僧道弘慧之他。 /
