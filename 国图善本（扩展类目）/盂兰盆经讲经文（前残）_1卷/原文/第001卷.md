# 盂蘭盆經講經文（前殘） · 第一卷

---

目連依教便脩行 /
供養三尊及大眾福利遐超鬼趣 /
願我慈親領受之因茲息苦得停酸 /
免受倒懸三道離却鬼前休趣𢙣𢙣 /
得向園礼世尊因此厥号蘭盆󷑜𥁄 /
接引眾生交離苦不獨當初為目連 /
兼為今朝座下人故知大聖不思議 /
流向浮化羣生為救世間諸苦難𨶒 /
名曰蘭清淨經念觀世音菩𥁄󴅽 /

上来即如斯略与門徒分別 / 󵘸
向下依經次苐陳不知道理復如何 /
大眾須生敬重心道此經孝行 /
各各心合掌着經文次苐唱將来𣫍 /

覺行周圎号世尊於中三覺不思議 /
別日与門徒廣分別今且略明妙法 / 󲮬
願聞障消除

国王太子兼長者諸佛如来住彼中 /
給孤長者湏達多聞佛功徳心中喜 /
火急来造精舎便買陁太子園㱕󷑜 /
四十里地布黃金建造如来說法處 /
殿宇樓臺徦日月池華菓用嚴 / 󲊷㽵
仏當日在彼中這蘭清淨教 / 󵘸𥁄
為救目連慈母罪免交受苦生天 /
上来多叚義不同經文成就義 / 𢝰󵘸
従此下反是別序目連得道復如何 /
大眾生敬重心六通之名當解釋 /
各各虔茶合掌着目連得道唱將来 /

恰似世間慈母身養得子時登官位 /
威勢人間皆怕自出分憂佐大唐𢝰 /
忽然憶着我耶孃取向本州專侍奉 /
所得財物買珠瑱將来奉獻我尊親 /
百味羞皆給恭日夜將心親侍奉󳏃 /
若也悶来交合曲音聲歌儛不曾 / 𠇲
朝朝甘脆父母前晝夜尋常居左右 /
所要之間皆有意徒孝行遣人傳 /
今此目連亦復然得道恰似為官位 /
憶得先亡念慈親堕落三塗阿郍邊 /
遂將天眼更遙觀欲覓尊親擬供養 /
直為亡来年嵗久不知神識落何方 /
乃知證得六神通根本還因求父母 /
羅漢六通為苐一願報當初養育 / 㤙
今此向下一唱經欲度父母報受 / 㤙
大眾好生合掌着經文次第唱將来 /

自得既圎應合救物懷其孝行欲報重 / 㤙

目連自得既周圎理合救其親父母 /
心裏為懷行孝行報従来養育 / 󷤨㤙
人生在世合如斯父母深湏報荅 / 㤙
想得當初養育我受苦懷不可論 /
除其孝順在眼前供給所湏不闕少 /
假使砕身千万刼不能報得母深 / 㤙
將知徳大難酬我佛如来再三㤙󵘸 /
奉勸座下佛弟子大湏孝順莫因循 /

適来雖列十名㤙
義理差殊都未解門徒若要細分別 /
先生敬重後依行苐一懷擔守護 / 㤙
十月胎中常負重慈母將心憂姟子 /
怕胎中不得安生時受苦命如斯𢙢 /
赤血滂沲魂魄散時向之間却命 / 󷘌
由怕姟兒有殤生了心中便喜歡󰡷 /
忘却憂愁如快樂眷属親情皆喜 / 𢝰
慶賀今朝母子安漸漸姟兒長大時 /
乾處唯留與子眠濕處迴將母自臥 /
洗濯之時無懈惓乳脯養育不辝勞 /
寒熱都来為怜念由如掌上珠 /
年登十五母由憂怕造諸不善業 / 𢙢
走去心中常憶念仏前發願早来 / 㱕
四時八莭不前頭不覺目中雙淚下 /
時向之間不得見恛惶惆悵似湯 / 𤋎

他家孝順由憂耶孃不孝之男廣造 / 業𢙣
他州外鄉逐樂不父母此間肝膓寸断㱕 /

他家若是孝順之兒解向家中親侍奉 /
若是心中不孝順逃走他鄉不 / 𢝰㱕
囙脩向外嵗年間逐樂何曾憶父母 /
所得錢財別受用肯解將来獻二親 /
將知世界眾生罪過愚膚不可𨒫󵘸 /
不報其不孝順堕向三塗道中㤙𢙣 /
奉勸門徒諸信心莫作如斯不孝人 /
斈取目連心裏命終必見慈尊 / 㝎

上来道理轉殷勤聞道還湏行孝行 /
不但自家心裏了也令眾罪速消除 /
