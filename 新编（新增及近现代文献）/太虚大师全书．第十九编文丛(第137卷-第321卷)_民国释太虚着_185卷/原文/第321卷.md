# 太虛大師全書．第十九編　文叢(第137卷-第321卷) · 第321卷

> 民國 釋太虛著

---

發揚大乘佛法真義，
應導現代人心正思。

靈慧光如，真惟法善，德圓智深，理順性健。 /
悟澈心源，言契經典，禪續祖燈，旨超玄辯。 /

真覺平等業形本空無始迷蔽或扶或攻 /
悟理達幻冰釋水融供養如佛一塔普同 /

戶樞南北筦鑰西東四民超敏物阜德豐 /
道聲一樹天下響風覺濟今世唯佛大雄 /
慧日破暗法雷振聾建佛教會拯災恤窘 /
書報刊布經像流通亦修淨業亦習禪功 /
增高繼長歲有不同爰發文采煥爛虛空雲蒸霞蔚垂之無窮！ /

十九出家三十成道說法四十一年普潤二木三草乘鷲山之夙願其智者之再來縱玉泉之可竭必斯塔之無頹。 /

此非汝躲跟處亦非汝捨命場直須身奉塵剎洞然海印發光。 /

妥師之骨于磨鏡台摧邪扶正師其再來 /

此土緣深彌陀觀音長老承化善淨其心 /
母慈子孝資賢師明信願行備極樂永生 /

有大龍象崛起湘衡空所依傍特立獨行 /
因禮南海遂留甬東機輻緣湊中興天封 /
為法為眾任勞任怨大廋嶺上真風卓然 /

懿惟法師佛門神駿雉水鍾靈誕玆賢俊 /
德慧天然雄偉和慎智探覺源悲垂濟振 /
應化適機法雨周潤釋難析疑辯雷迅震 /
荷擔如來作育後進眾望方隆無常忽順 /
哀我僧伽喪此重鎮歸骨光孝塔聳千仞 /
式仰高風泰山俱峻 /

天生哲人好善成性一生善舉屈指罔盡 /
滔滔江漢南國之紀賴公版築方便行李 /
維桑與梓必恭敬止弦誦聲聞濟濟髦士 /
為善最樂慷慨揮金至公自奉辭甘就辛 /
晚崇淨業兆徵生蓮妥茲靈宅億萬斯年 /

八字打開，
一塵不立，
四明第一山，
中道從容入。

攝化閻浮，
應居兜率，
時時示時人，
時人自不識。

戡天縮地逢今日，
護法安僧仗將軍！

巍巍堂堂，
眾聖中王，
現身雪竇，
不離華藏。

禪門艷稱雪竇頌，
海外猶傅碧巖集，
今日當場拈出時，
清風匝地起何極。

諸法剎那生，諸法剎那滅， /
剎那生滅中，無生亦無滅。 /

依有力慧，運即慧力，十五年前，頓入佛律； /
十五年來，廣布法益。正信長留，江漢無竭！ /

方冀藥師延留東方，何期彌陀已接西方！ /
唵、啞、吽、慧力！願無往而不吉羊！ /

嶽嶽居士江漢之英家敦孝友商著賢聲 /
在群在國義勇成名及其皈佛既智且仁 /
慧樹正信三寶昌明力拯災難普度眾生 /
勤奮精進菩薩之行一十五載契以至誠 /
化緣方永何忽捨身追念功誼實慟余情 /
虛空有盡悲願長存覺靈不昧應同此心 /

其生也直其逝也善直性不生善德常湛 /
常湛不生何去何住不生之生無逝而逝 /
逝八七餘佛聲相續今日起龕功行滿足 /

五蘊非有四大本空通身般若法界常融 /
般若火聚腦後神光四邊莫觸一性圓常 /
一性無性中邊絕待大火聚中得大解脫 /

如來設教方便多門莊嚴梵剎淨土淨心 /
水月道場空華佛事智悲交融所行無滯 /
建勝幢於處處映帝網於重重量同法界壽等虛空 /

弘誓持正法，護世濟民生，茲值災難劇，捨眾忽歸真。
敬修釋尊教，願見速轉生，德化敷遐邇，國泰天下甯。
