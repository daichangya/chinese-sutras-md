# 如来广孝十种报恩道场仪 · 第八卷

> 南宋 思觉集　赵文焕．侯冲整理

---

天地生人原以恩，人有父母两称尊。 /
割肉代医酬罔极，出棺说法启晨昏。 /
无身谁作三才主？有孝方开百行门。 /
奉劝世人须自醒，释宗儒训古今存。 /

孝子首重是彜伦，孝有所祖规范真。 /
昊天广大恩难报，藏教分明语最亲。 /
侍读欧阳皆奉旨，圭峰慈觉再来人。 /
留将录论非胸臆，知念劬劳福自申。 /

从来仪式有规程，须以三时作证盟。 /
欲知出世并入世，更揣单行与双行。 /
作观谨严思济度，诵经心口要真诚。 /
放生未了财施去，难报高堂顾复情。 /

道场左右把香焚，两向从来各有分。 /
五趣四边情更切，老聃孔子告犹勤。 /
圣凡合处忘人我，名姓陈来检疏文。 /
安置为何知不二？如来圣训总难闻。 /

熏沐投诚建法坛，婉若在世日承欢。 /
放生以数佛有训，布施将钱人所难。 /
须信悬幡亡脱化，不然衣掷火摧残。 /
儿孙若把悭来破，过去亲心永得安。 /

警策原从一念生，香灯掩映法坛清。 /
钦尊三宝神偏凛，悖逆双亲报不轻。 /
阇世悔心消积苦，圭峰诫语释无明。 /
会须猛勇为佛事，福禄来临万事亨。 /

欲垂劝勉仗诸天，为想高堂结佛缘。 /
三老化身皆助释，一乘妙理定宗禅。 /
指迷始破众生惑，笃孝当为明教先。 /
遵奉大师应有戒，是非消却道场圆。 /

报恩胜会启坛场，密咒醍醐甘露浆。 /
安息飞烟云雾卷，兰膏发焰慧灯光。 /
缁流济济皆精洁，贤圣巍巍尽赞扬。 /
法雨满空甘露洒，道场何处不清凉？ /

法身报身及化身，经律论藏甚深文。 /
开迷化导阿罗汉，参礼南无佛法僧。 /

波罗蜜满足，净性觉智慧， /
胜心得成就，故号名为佛。 /

无染性清净，永离于世间， /
不观世五阴，常住名为法。 /

身心常无为，远离四种食， /
为世良福田，故称和合僧。 /

身口意业本来同，一念才迷失本宗。 /
喝散障云无点翳，一轮杲日照当空。 /

五分法身真妙香，人人具足露堂堂。 /
无根树下亲拈出，供养如来大法王。 /

八功德水自天真，善洗众生业垢尘。 /
流入毗卢华藏界，个中无处不超伦。 /

聚沙成塔亘青天，举止分明在目前。 /
法界道场潇洒处，自然涌出一枝莲。 /

荆棘林中业火生，经由大地任纵横。 /
金刚结出摩诃力，直向如来行处行。 /

一花五叶祖师传，浅白深红有万般。 /
晏座岩前无法说，纷纷坠落紫云端。 /

如来妙色身，世间无与等。 /
无比不思议，是故今赞礼。 /
愿共诸众生，一心头面礼。 /
如来色无尽，智慧亦复然。 /
一切法常住，是故今赞礼。 /

如来智慧灯，同叹一切僧。 /
能生三世佛，是故我皈依。 /

百亿刹中号大雄，四王捧足诞皇宫。 /
游城知苦观假幻，入骑雪山了悟空。 /
阿耨乳恣金色相，菩提树下玉毫容。 /
独尊十号天人主，开教源流刹海中。 /

稽首三界主，大孝释迦尊。 /
累劫报亲恩，积因成正觉。 /
将永锡众类，应请演斯经。 /
欲使报恩人，咸能酬罔极。 /

礼拜能除我慢障，礼拜能感尊贵身， /
礼拜能灭七支愆，礼拜能生三业善。 /

南无佛智慧清净，那罗延力骨锁身。 /
波罗蜜多六度行，大慈悲父常为人。 /

陀罗尼力信无边，普召含灵在佛前。 /
由恐四生中漏落，更祈六道外招筵。 /
净坛坐遣香云去，阴界遥闻宝铎传。 /
愿自会中生乐国，不辞佛敕为重宣。 /

菩萨遍观于六道，莫非皆是宿亲缘。 /
普伸召集赴香坛，愿奉旨甘并法施。 /

我以大悲佛神力，召请冥阳诸有情。 /
旷劫饥虚饿鬼等，不违佛勅来降临。 /

一切有为法，如梦幻泡影， /
如露亦如电，应作如是观。 /

假使百千劫，所造业不忘， /
因缘会遇时，果报还自受。 /

若人欲了知，三世一切佛， /
应观法界性，一切惟心造。 /

诸行无常，是生灭法。 /
生灭灭已，寂灭为乐。 /

如来证涅槃，永断于生死。 /
若能志心听，常得无量乐。 /

我今灌沐诸如来，净智庄严功德聚。 /
愿五浊人今离垢，同证如来净法身。 /

大孝瞿昙道最尊，都缘累劫报亲恩。 /
三牲日奉非真养，万德身严乃本根。 /
返拜不妨惊梵释，初行已解指乾坤。 /
堪嗟我辈相违背，虚负劬劳血一盆。 /

我闻佛语孝为宗，孝行原来佛行同。 /
内蕴佛心遵雅训，外行孝行绍宗风。 /
母胎集会真身露，父臆扪摸妄业空。 /
多少知恩菩萨子，古今尽入此门中。 /

如来孝行有何因？一一如经为指陈。 /
喜见婆罗供母氏，空惊梵志毁能仁。 /
后薨王哭情虽隔，光遶莲花道最尊。 /
若论我师非孝敬，谁于五趣现多身？ /

又复重念作鹦鹉，取人稻谷养二亲。 /
稻主执我生瞋恚，云何盗我熟苗稼？ /
我即报言汝种时，愿与一切众生共。 /
我今取以养父母，是故不名为偷盗。 /
稻主即时生欢喜，我是禽兽汝是人。 /
善哉鹦鹉有智慧，能怀孝养供父母。 /
我从今去以稻施，任汝供养于二亲。 /
如是过去无量事，无有苦行而不作。 /
未曾有怀疲厌意，以求无上清净道。 /

正明苦行报恩时，谛听令人重怆凄。 /
割肉阇提原是我，舍身忍辱更求谁？ /
剪翊竟免西天鸟，脱网曾为鹦鹉儿。 /
净饭摩耶今日看，方知有子大慈悲。 /

回身三界孝慈深，悲救还生慰劳心。 /
赕子更生天遗药，盲亲再见主倾金。 /
采珠归国方饶益，饲虎生天解访寻。 /
笑彼法华穷子意，舍身逃逝不归钦。 /

世尊相好绝无伦，只为从前孝二亲。 /
美馔名衣常奉给，慈心软语每咨询。 /
托胎福母功难继，为子捐王道转新。 /
罪垢众生俱荷负，如何只么毁能仁？ /

大王昔来于我所，实自初无信敬心。 /
欲以轮王令我作，以四天下生恋惜。 /
譬如本昔有神龟，随海水潮至陆地。 /
其海潮水回还去，龟便坠堕深井中。 /
井中旧鼈问神龟：汝本何处今至此？
广智海龟答井鼈：我遇海潮堕此井。
其海潮水回原时，我行迟迟遂不及。 /
以斯我今失时节，坠此小井共汝住。 /
井鼈复问海龟言：其海多少井中水。
岂复宽广于斯耶？为大为小愿速说。 /
广智海龟答井鼈：无智住人穿凿处。
我于大海水中居，在彼经历多年载， /
犹尚不知海处中，况复了达其彼岸。 /
如是大王都不知，我之神通威德力。 /
欲以轮王四天下，世间势力恋惜我。 /
我今现作法轮王，统领三千大千界。 /
如法正治离刀杖，得于八部最胜供。 /

释迦大仙师，成就一切智。 /
在于阎浮提，犹如千眼天。 /
慇懃情渴仰，久欲奉慈颜。 /
本昔王宫中，生我七日已。 /
神升受天福，姨母长乳我。 /
致得成正觉，应供度众生。 /
今故至于此，说法报往恩。 /
愿母与眷属，屈来到此处。 /
敬礼佛法众，并受真净法。 /

汝从无量劫，当饮我乳汁。 /
故离生老死，得成无上道。 /
宜应报恩养，断我三毒本。 /
唯愿施慈悲，速令成妙果。 /
孜孜觅便与寻方，见善双亲反激昂。 /
膝屈父王离禁殿，乳流母氏在天堂。 /
万般神变蒙天卫，千叶莲花向日芳。 /
戏彩凡间老莱子，回心学佛道尤光。 /

有子超凡岂偶然？法轮为转化人天。 /
如如法界原非动，念念攀缘徒自缠。 /
颠倒见亡登实际，须陀洹证破烟然。 /
同归寂灭餐甘露，后世忘恩未是贤。 /

为法酬恩屡启端，方知究竟奉亲难。 /
别离世数谁能免？悲智家风切好看。 /
净饭一心呈玉偈，摩耶十匝遶金棺。 /
此身坚密何曾碍？笑倒云门赤肉团。 /

毗卢本是一凡夫，旷劫修行作楷模。 /
今日因之成道已，诸人还有所生无。 /
轮回路上安能舍？解脱门中正好趋。 /
世出世间须两立，休于苦海更盘盓。 /

武帝龙飞大业成，尊临天下不为荣。 /
浮云富贵知如幻，逝水光阴念所生。 /
愿用发肤酬至德，甘为奴仆委鸿名。 /
我今为报为人子，父母非轻四海轻。 /

佛面犹如净满月，亦如千日放光明。 /
圆光普照于十方，喜舍慈悲皆具足。 /

兜率宫中降母胎，胎中廓尔总兼该。 /
能容法界如来孕，不碍尘沙佛子来。 /
伤叹子萦三障业，缠绵母受一年灾。 /
愿亲无复怀躭苦，永托莲台上品开。 /

摩耶树下欲攀枝，正值如来降诞时。 /
妙体莹然生右胁，慈亲宛尔展双眉。 /
子生迫窄牛遭剥，母苦昏迷鬼欲持。 /
临产片时恩力重，愿亲早得证无为。 /

悉达才生目四方，各行七步表殊常。 /
父因返拜情尤悦，母得生天喜不忘。 /
懒顾自身春渐老，笑观儿子日偏长。 /
至公不宰真端的，报德须依大法王。 /

往省归宁笑不休，养亲法乳古无俦。 /
饱吞必到菩提岸，烂嚼终乘般若舟。 /
为子吐甘滋舌本，忍心咽苦皱眉头。 /
我今愿托如来力，随侍亲归法性游。 /

紫摩金身色可夸，冰清玉洁了无瑕。 /
面如秋夜团团月，足步红莲朵朵花。 /
就湿投身甘秽浊，回干任子卧横斜。 /
愿亲迥出尘埃表，无复情云四面遮。 /

欢喜园中兴味浓，母恩求报意偏工。 /
慈风乍扇恩波举，法雨才施业火空。 /
血乳养儿宁起念，齿牙嚼饭肯欺功。 /
雪山真味何曾失？会得宜将日日供。 /

太子初生道力余，九龙吐水浴金躯。 /
不须俗子频揩拭，端为众生作范模。 /
颇恨形躯多垢秽，徒劳父母几勤劬。 /
泥莲河畔垂千古，效学如来得也无。 /

导化人天戒力强，坚持世嗣即繁昌。 /
故抛禁苑为人子，终证菩提号法王。 /
情爱有些缠子女，冤仇无限恼爷娘。 /
如何截断从前事，不见金牛刃落霜。 /

故国天宫任往还，喜将禅悦奉慈颜。 /
父王意地澄如水，慈母情田静若山。 /
有子已行千里远，劳亲注想百年间。 /
劝君且学如来行，莫似莱衣只戏斑。 /

父母俱抛亦自安，净居忉利去何难？ /
尘刹互遍曾无碍，根境相含切好看。 /
老死路途虽隔绝，发肤情念没遮栏。 /
人间甘旨难呈献，愿侍双亲般涅槃。 /

长空象驾日轮红，命生迦罗净梵宫。 /
富落雪山修万行，贵荣鹿苑阐宗风。 /
金光照处天人集，玉辇行时释梵宗。 /
满月慈容黄金相，堂堂具足法王雄。 /

妙宝莲花清净座，法空空寂妙难思。 /
空中妙有普庄严，此是如来法空座。 /

庄严清净金刚座，我佛跏趺转法轮。 /
一千诸佛证菩提，次第现身登宝座。 /

武帝至尊仁孝念，甘为奴仆报劬劳。 /
着仪动地雨天花，父母非轻四海轻。 /

我今奉献甘露食，量等须弥无过上。 /
色香美味遍十方，合会圣贤哀纳受。 /

一报天地盖载恩，二报日月照临恩， /
三报国王水土恩，四报父母养育恩。 /
现在双亲增福寿，过去父母早超升。 /

长把一心礼佛天，命延巩固自悠然。 /
富因广积来生福，贵为深根宿世缘。 /
金磬声中吟风韵，玉龙顶上袅龙涎。 /
满门俱是俊才子，堂上恭钦二老仙。 /

斗转星移在碧霄，香烟寥落白云飘。 /
如来暂宿那伽定，明日精虔再叩朝。 /

戒定慧解知见香，遍十方刹常芬馥。 /
愿此香云亦如是，回作自他五分身。 /

敬礼金色相，面净如满月。 /
敬礼智无比，离垢三界尊。 /
发净光润泽，顶高如须弥。 /
观者无厌足，眉间白毫相。 /
为众宣微妙，度脱无量众， /
我赞功德聚，无垢清净福。 /

若人狭劣者，虽多行布施， /
受者不清净，故今果报少。 /
若行慧施时，福田虽不净， /
能生广大心，果报亦不净。 /

儒释皆宗道贯通，星分爪剖赖圭峰。 /
放生作福恩堪报，改祭为斋善可从。 /
施戒更当资福业，岁时休但想音容。 /
先王古佛相弘济，类我螟蛉可指踪。 /

卖薪行孝见慈童，顺逆皆由一念中。 /
玉女承颜花报谢，火轮堕地业因空。 /
经标十种排功过，道被三根品异同。 /
火急修行勤奉养，背恩何日出樊笼？ /

敬事双亲问起居，归宁色养日无亏。 /
晨昏定省看承我，冬夏温凉点检渠。 /
泣竹冬月天生笋，扣冰渊跃雪天鱼。 /
踊身高七多罗树，方信如来道有余。 /

养须致乐善看承，和意怡颜侍寝兴。 /
捧檄经年伸悦怿，戏斑终日笑凭陵。 /
陆郎甘旨忻怀橘，朱隽宁亲喜贩缯。 /
争似如来全道力，净居忉利等闲升。 /

亲病当知子负忧，求医问药莫知休。 /
卖身破产终无吝，设拜肩舆不用羞。 /
代死要为潜耀辈，吮痈当作士岩俦。 /
更能仰叩真慈父，天理争教疾弗瘳。 /

一切人归死，无有不死者。 /
随行种祸福，自获善恶业。 /
地狱为恶行，善者必生天。 /
明慧能分别，唯福能遏祸。 /

临丧孝子具真哀，擗踊号咷五内摧。 /
呕血数升悲在膂，忘餐七日泪横腮。 /
目连大叫真贤者，调御舁棺信善哉。 /
不向真乘消爱见，从前感动总痴孩。 /

当思祭则致其严，礿禘蒸尝礼法兼。 /
明法唯忻陈簠簋，克诚配享奉虀盐。 /
休将大辩斋蔬弃，须信青提钵饭甜。 /
人哭鬼歌无用怪，来昆善恶佛能占。 /

淳风远被化浇漓，本固须知叶不衰。 /
三世同财财愈盛，积年合爨爨常炊。 /
马牛相乳和如此，鸦鹊同巢义可知。 /
祸乱不生灾害殄，君臣父子太平时。 /

孝感如前验颇详，神明造物卫行藏。 /
白鸠标瑞栖其宇，芝草呈祥挺在堂。 /
陈氏梦尼生净土，李公刺血发天香。 /
隆兴丞相心词妙，天下人心好忖量。 /

君看五母哭弥罗，忧海无风强起波。 /
定果色堕痴爱网，金刚杵碎死生魔。 /
伤嗟弃本甘缠缚，黾勉知恩好切蹉。 /
念念回光酬罔极，流光催老急如梭。 /

众罪皆忏悔，诸佛尽随喜。 /
及诸佛功德，愿成无上智。 /
去来现在佛，于众生最胜。 /
无量功德海，我今皈命礼。 /

一念迷真失故乡，迷头认影只颠狂。 /
前程不睹心花发，日用唯耑业识忙。 /
已陷罗网遭困厄，忽蒙香火作津梁。 /
掉头展翅何来去？佛影弥纶自在翔。 /

争似如来全道力，净居忉利等闲升。 /

七旬无寝寐，百药治何休？ /

董永卖身殡葬父，乌鸦助土筑坟台。 /

临丧孝子具真哀，擗踊号咷五内摧。 /

孟宗因祭笋，竹内哭苍天。 /

若荐苹蘩修福供，释迦老子更无言。 /

化风远被众皆知，爱敬由来合爨居。 /
鸦鹊同巢真罕有，马牛相乳实希奇。 /

淳风远被化浇漓，本固须知叶不衰。 /
三世同财财愈盛，积年合爨爨常炊。 /

白鸠标瑞栖其宇，芝草呈祥挺在堂。 /
陈氏梦尼生净土，李公刺血发奇香。 /
隆兴丞相心词妙，天下人心好忖量。 /

弥罗八岁入山修，五母号咷哭未休。 /
世出世间行孝道，扬名空向后人留。 /

君看五母哭弥罗，忧海无风强起波。 /
定果色堕痴爱纲，金刚杵碎死生魔。 /

过海浮囊无缺漏，先天妙物出陶甄。 /

四生证果根机利，百劫成功观智融。 /
鹿母当年因供养，后生一子法王雄。 /

一乘为养妙严都，尘刹众生父母躯。 /
长子全身周沙界，小男无处不文殊。 /
摩耶生佛原来幻，太子宁亲忒煞迂。 /
三世十方相涉入，人牛不见月轮孤。 /

雪山教主号能仁，演说三乘报二亲。 /
圆满一乘为究竟，至真至孝绝无伦。 /

天伦佛性自圆常，今日方知孝道昌。 /

已知有父如无等，宁可无儿似月光。 /
自利利他俱满足，更无一物献尊堂。 /

愿轮广博孝隆昌，究竟超登正觉场。 /
五戒三皈资苦本，三宗四法答恩光。 /

昼宵闻见好因缘，箭急将身出爱缠。 /
早是四生花报谢，那堪三界火轮旋。 /
法身独露胞胎外，慧命生成𫄶褓前。 /
万劫亲恩俱解脱，人间天上月团圆。 /

马鸣愿力何其多？吐出玄机锦绣罗。 /
亦似当年亲奉献，报恩会上沐恩波。 /
咦，满门贵眷呈祥瑞，万古光辉献佛陀。 /

天厨妙供是酥酡，老母曾将献维摩。 /
六味馨香充法界，缤纷遍满于娑婆。 /
咦，施主虔诚献三宝，人天三界供餐和。 /

天地储精，琥珀金银， /
玫瑰玛瑙，玳瑁珠珍。 /
无垢界中龙女献，杨子江心居士倾。 /

咦，从此翻身归圣域，祗随鹦鹉伴圆通。 /

佛告善住天子及天帝释：十恶业缘，恶口尤最。当知恶骂甚于猛火，猛火但烧七珍之财；恶口猛火，能烧七圣之财。一切功德，如汝善住。一言恨母，一骂众僧，受天报尽，复入地狱。天地父母众生，不应轻毁。三界慈爱，唯有父母；三世福田，不过众僧。父母生养，劬劳辛苦。十月妊娠，三年乳哺。长养教诲，难忧备尽。冀其成立，才艺过人，又望出家度脱生死。以是恩念，昊天难报。是故我语阿难言：左肩担父，右肩担母，绕须弥山百千万匝，血流没踝，尚不能报一日乳哺之恩，岂应恶骂，轻生恚语？佛告帝释善住天子：今见我故得五眼净，忏悔彻故罪亦除灭。又告善住言：汝止勿泣，我有法门，名为最胜佛顶尊胜陀罗尼。此咒乃是百千万亿俱胝诸佛所说，我今说之，若有受持者，以是功德，百千万劫十恶五逆悉皆消灭，即得阿耨多罗三藐三菩提，不转此身获宿命智。尔时帝释闻佛称赞，一心渴仰，即白佛言：唯愿如来愍我等辈，亦为未来末法众生说此陀罗尼。我当修行，令诸众生永离八难之苦。尔时世尊为受请故，即说咒曰：

稽首光明大佛顶，如来万行首楞严。 /
光中化佛演微言，念诵普令祛宿业。 /

妄情扰扰风飘絮，障垢昏昏镜受尘。 /
虚空诸佛已哀怜，教主由斯宣咒力。 /

自造自招无间歇，个中谁识本来心？ /
为宣密咒力加持，一念回光俱寂静。 /

真如佛性无修短，煞业滋繁致夭伤。 /
善门护念力祛除，须信人天无量寿。 /

万行因华相涉入，重重无尽遍庄严。 /
芬芳秀丽与馨香，由此陀罗尼咒力。 /

三宝三乘亲父母，背恩衣食不丰饶。 /
猛风沙聚总飘飏，受用自然如意足。 /

净居天上亲宣说，受请今时再举扬。 /
见闻带佩与瞻依，五逆罪根俱寂静。 /

杀父及害母，罗汉众圣贤， /
破和合真僧，出佛身血罪， /
萨遮尼干教，五逆众罪愆。 /
愿诵秘密言，定业悉消灭。 /

迷真逐妄甘沦转，水陆飞沉被网罗。 /
我今释放仗真言，永劫更无笼罩难。 /

无始以来诸罪垢，尽虚空界不能容。 /
我今悔过愿消除，念诵密言悉清净。 /

释迦印咒难思议，普与众生灭罪愆。 /
我今忏悔愿垂慈，洗涤无明诸垢染。 /

圣人本自心中现，情见难忘着相求。 /
即心即色两无妨，一念才兴知见了。 /

无始劫来生我慢，恰如山岳耸千寻。 /
我今投地礼如来，愿使慢山俱破碎。 /

万德庄严莲出水，三空智照日开敷。 /
巍巍端坐紫金容，印咒功能果如是。 /

玉斧削成山势耸，金炉𦶟起瑞烟浓。 /
撩天鼻孔悉遥闻，戒定慧香熏法界。 /

五叶心花开此土，一枝优钵产西天。 /
世尊拈起示诸人，迦叶破颜曾一笑。 /

照破昏衢消黑暗，增辉佛日转分明。 /
灯灯续焰到于今，祖祖传芳光不灭。 /

吸尽西江难下口，遍为甘露润群生。 /
九龙吐水浴金身，万古曹溪无尽缘。 /

功德园林勤种植，胸襟造化为栽培。 /
拈来本自善根生，献处圆成无漏果。 /

赵老吃茶何直截？文殊拈盏忒分明。 /
欲知此味贯鸦山，须是舌头亲具眼。 /

大地遍为香积饭，珍馐一味世间无。 /
通身是口为沾尝，万劫千生常饱满。 /

红炉矿熟上钳锤，打就金毛狮子儿。 /
休鉴卞和空泣玉，于中还有老胡知。 /

二龙争斗觅不休，却使胡僧笑点头。 /
还知海藏亲收得，莫向牟尼镜外求。 /

九条无相紫襕衣，传自黄梅夜半时。 /
庾岭石边持不起，重楼永镇在曹溪。 /

香花灯涂珍果等，供养海会众圣贤。 /
惟希纳受鉴丹诚，满我檀那广大愿。 /

我以功德力，如来加持力， /
及以法界力，普供养而住。 /

三身觉海圆明众，此界他方大导师。 /
愿开禅定举扬时，令此道场得成就。 /

欲灭众生三世业，当持佛母七俱胝。 /
尘消障尽绝遮拦，无量法门从此得。 /

佛法僧宝无能胜，五趣三乘总敬崇。 /
归依一念愿冥加，直到菩提究竟岸。 /

风恬浪息江湖静，万像森罗映现中。 /
本来心印亦如斯，身世无非皆净妙。 /

一切人天龙鬼等，能仁等视展深恩。 /
各随彼语震雷音，使离尘缘获法眼。 /

十十互资无有尽，人人境界普贤知。 /
一涓一滴到天池，总得天池一咸味。 /

恶口火焚功德聚，愿凭秘咒力消磨。 /
微尘诸佛总宣扬，诵念必成无上道。 /

爱水欲泥净染污，瞋心见火怎焚烧？ /
本来清净了无瑕，好向今时同显发。 /

六根寂静无余想，心月孤圆朗十方。 /
尘沙父母许重重，尽向此时俱转了。 /

心地无尘境界宽，了明真性悟玄机。 /
单空月轮照法筵，一一普令皆圆满。 /

圣凡一体何来去？隐显同时绝送迎。 /
专诚奉送表丹衷，母子历生难舍离。 /

历劫亲缘蒙降赴，仰瞻金相听圆音。 /
未成佛果已前来，随愿往生佛净土。 /

鬼神承佛天仙力，面百由旬尽护持。 /
如来示现微微笑，各愿深恩归本土。 /
