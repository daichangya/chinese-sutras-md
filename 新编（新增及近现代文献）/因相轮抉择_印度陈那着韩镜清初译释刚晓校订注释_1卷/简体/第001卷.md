# 因相轮抉择 · 第一卷

> 印度 陈那着　韩镜清初译　释刚晓校订注释

---

## 因相轮抉择

〔题解〕

《因相轮抉择》（Gtan-tshigs-kyihkhor-logtan-ladbab-pa），印度因明著作。一卷。印度陈那论师着，为著名的陈那八论之一。

陈那论师本文主要是介绍因明论式中因法与喻的九种格式，并分析九式的正误，以图例形式说明，最终揭示陈那论师新因明的核心理论「因三相」之来源。

此《因相轮抉择》梵本久佚，在藏传佛教丹珠尔中存有一卷，卷尾题为「萨霍堪布菩提萨埵及法无忧翻译、校正及刊定」。原着为十颂，加上皈敬颂共十一颂，附有一图，总共二纸。

吕澂先生曾译此《因相轮抉择》，名为《因轮论图解》，发表于1928年12月《内学》第四辑，其后收入《吕澂佛学论着选集》第一卷（山东齐鲁书社，1991年7月）。韩镜清先生于1980年6月24日再次翻译此文，但为未定草稿，故未发表。2003年韩老去世，释刚晓从吕新国居士处得到韩老手稿，校订后刊登于《灵山海会》2007年春季号（总第二十三期）。

《因相轮抉择》颂文简略，不易理解，且藏文原文颇有不合因明义理处。故由释刚晓略作简注，用脚注形式附之于后。

需要说明的是，现知《因相轮抉择》的藏文原本共有三个：德格本，93页上下；北京本，189页上下；卓尼本，92页上下。韩镜清先生翻译时所依据的是北京本。与德格本相比，北京本末尾多出六首偈颂。韩镜清先生将这六首偈颂也翻译出来，今作为附录一并附在文末。

## 〔正文〕

敬礼童相曼殊室利

敬礼一切智，能破错乱网。 /
因相三相轮，当说彼抉择。 /

于所比知中，有、无及俱二， /
有中为正确，无、俱不成就。 /

二疑为不成，随应不成是， /
同品中为有、无及如是俱， /
异品中如是，三中各三相。 /
上下二中实，四角共不定， /
于中间非共。所量、作、无常、 /
所作、闻、勤生、无常、勤、无体。 /
常、无常、勤生、恒、常及坚牢、 /
非勤、迁、不变。安排能立此。 /

随应边异品，为二正因相。 /
随边异上下，为二相违因。 /
随四角交叉，四种共不定。 /
随应对二边，为不共不定 /

九幻轮因相，喻行相如是， /
如空、瓶；瓶、空；如瓶、电、虚空； /
如虚空、瓶、电；如电、虚空、瓶； /
如瓶、电、虚空；如空、微、业、瓶。 /

乃约义决定，于怀疑理中， /
有及无、有无，皆随应一分。 /

中间常无常勤生中间三种常 /
非勤无常常此九所立法 /
所量作无常所作闻勤生 /
无常勤非触此九为因相 /

初三同品中作有依异中 /
绝无能徧二中三同品中 /
作无依异中能徧二异品 /
下三同品中作为俱之依 /
异品中能徧及绝无俱有 /

如次当了悟四角不决定 /
二边相违因中之中不共 /
中之首末正慧当缩慧域 /
