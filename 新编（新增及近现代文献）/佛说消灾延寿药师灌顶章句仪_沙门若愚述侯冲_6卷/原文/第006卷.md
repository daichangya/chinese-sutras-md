# 佛說消災延壽藥師灌頂章句儀 · 第六卷

> 沙門若愚述　侯沖整理

浩浩難思真法界，藥師海會眾聖賢。 /
我今教誡演儀文，望聖慈悲垂加護。 /

皈命十方及三際，塵剎圓明調御師。 /
法界功德大悲雲，毗盧遮那大智海。 /

所住甚深真法性，所流圓滿修多羅。 /
一一塵方佛會中，文殊普賢諸大士。 /

我今欲以一毫智，測量無邊法界玄。 /
願承三寶同體慈，句句冥符諸佛意。 /

身三口四意貪瞋，千惡門開散本真。 /
喝散障雲無點翳，性天孤月月輪孤。 /

爐焚五分寶香請，一縷煙起徹幽明。 /
遍作十方諸神聖，諸佛聞召悉來臨。 /

彌摩羅界秫提吽，一默澄潭萬古明。 /
理事道場今潔滌，自然風月一時新。 /

聚沙成塔亙青天，舉止分明在目前。 /
理事道場今潔滌，自然湧出一枝蓮。 /

荊棘林中業火生，經由大地任縱橫。 /
金剛突出摩訶力，直向如來行處行。 /

此花初舉在靈山，唯有頭陀獨破顏。 /
續燄聯芳傳此世，一花五葉任君板。 /

諸經寶讚妙伽陀，普散奇花福力多。 /
誠以此花供佛聖，散花行道見彌陀。 /

佛遊廣嚴城中位，曼殊室利請經題。 /
世尊上願慈悲主，無邊琅度群迷。 / 𪻱
解脫菩薩消九橫，藥叉大將除災危。 /
焚香燃燈依科範，集福延祥壽天齊。 /

願此香花雲，遍滿十方界， /
供養一切佛，尊法諸菩薩， /
無邊聲聞眾，及一切天仙。 /
以起光明臺，過於無邊界， /
無邊佛土中，受用作佛事， /
普薰諸眾生，皆發菩提心。 /

如來妙色身，世間無與等。 /
無比不思議，是故皈命禮。 /
如來色無盡，智慧亦復然。 /
一切法常住，是故我讚禮。 /
如來智慧燈，同嘆一切僧。 /
能生三世佛，是故應頂禮。 /

清淨法身遍法界，凝然湛寂號毗盧。 /
出纏離垢本非增，背覺合塵原不染。 /
若聖若凡名縱別，無生無滅理寧差？ /
絕諸戲論離思量，早願有情同證悟。 /

圓滿報身居報土，光明遍照普含容。 /
三祗劫內煉磨來，萬行門中修證去。 /
解脫道中除劣法，華王座上啟酬恩。 /
塵沙相好廣無邊，我等虔誠皈命禮。 /

百億化身所化境，隨機隨類接群生。 /
迦維降迹出王宮，雪嶺修行成佛果。 /
會啟三百五十度，法開八萬四千門。 /
雖然鶴樹示韜光，常在鷲峰諸住處。 /

海減波瀾最淺日，人增壽命極長時。 /
上辭兜率下閻浮，朝見出家暮成道。 /
雷震八音宣妙法，雲臻三會度人天。 /
我於今日誓皈依，願向當來蒙攝受。 /

世界立名為極樂，莊嚴殊勝最難遇。 /
西天梵語阿彌陀，東土唐言無量壽。 /
紺目澄清四大海，白毫宛轉五須彌。 /
十聲尊號若專心，一念便能生淨土。 /

藥與眾生為救療，師能三界作皈依。 /
琉璃瑩淨喻真如，內外光明同佛性。 /
法界無名名假立，聖人無相相權成。 /
不依名相接群生，爭得群生圓覺道？ /

稽首虔誠皈命禮，十方常住佛陀耶。 /
真如體上啟千身，般若光中含萬像。 /
離相絕言雖有說，應機赴感豈曾虧？ /
眾生性水若澄清，佛月此時皆得見。 /

稽首虔誠皈命禮，十方常住達磨耶。 /
龍宮鷲嶺演來時，白馬鴻臚翻出後。 /
一味醍醐平等潤，三般根器應機成。 /
至於八萬四千門，皆是如來方便用。 /

稽首虔誠皈命禮，十方常住僧伽耶。 /
三應四向有修人，五眼六通無漏眾。 /
大隱塵寰凡聖混，深棲嵒洞水雲幽。 /
慈悲長成福田山，添助眾生功德海。 /

稽首虔誠請三寶，三寶慈悲降道場。 /
青螺肉髻拂塵雲，紫磨金容光日月。 /
白毫照徹三千界，紅珠輝映十三天。 /
梵王天上散香花，帝釋宮中鳴鼓樂。 /
文殊大士先來引，手捧維耶《灌頂經》。 /
紅條玉軸日增光，金字青輪星彩現。 /
救脫真人持寶燭，神幡五色亦相現。 /
八員大士擁蓮臺，十德高賢攢月殿。 /
三千國土諸聖賢，十二章中願力王。 /
輕煙細雨拂青天，妙果祥光敷碧落。 /
金鈴萬種空中響，玉磬千般像外敲。 /
香煙颯颯遶雲飛，直至閻浮塵世界。 /
如來尊重超三界，慈悲不越六塵中。 /
但能發願散香花，便降人間霑供養。 /
今霄燈主殷勤重，此日如來降道場。 /
精修香燭展心誠，整頓安祥從佛後。 /

仰白道場諸大眾，幸逢法會悉攀緣。 /
當時我佛釋迦尊，曾在維耶音藥樹。 /
讚彼東方滿月王，有其正覺藥師尊。 /
因中積聚行門深，果內莊嚴佛度盡。 /

金作殿堂仍峭麗，銀為峙堞復聯環。 /
園林四序每精華，池沼七珍含晃耀。 /
雲色光明籠藻井，水聲柔軟遶琉渠。 /
藥音天際響叮噹，花雨空中飛散漫。 /

禽語揄揚八聖道，樹枝掁觸六波羅。 /
琉璃池影瀉樓臺，菡萏香風薰宇宙。 /
路不失遺行正法，人無三毒稟真修。 /
寶幔翠網似煙霞，大貝明珠如瓦礫。 /

無漏感通功莫測，有為心識說難窮。 /
若論此佛利群生，向下依經隨願讚。 /

東方有佛名滿月，佛號琉璃光皎潔。 /
頂上璇螺青繫髻，眉間臺相珂入雪。 /
十二大願度眾生，一片慈心無暫歇。 /
眾生有難若稱名，禮念琉璃罪消滅。 /

佛開八萬四千門，天上人間佛獨尊。 /
莫道滿天星耿耿，猶如孤月照乾坤。 /

長以心田種善根，命延壽筭祝賢人。 /
富因積德光後裔，貴是陰功啟芳聲。 /
金作良田惟至寶，玉聯奎壁即為珍。 /
滿座聖賢呈瑞彩，堂前供樂太平春。 /

能向法門深悟入，自然罪性等虛空。 /
菩提實相倘圓明，生死妄心俱解脫。 /
若不隨宜開經路，何名應病說方書？ /
拔除無始蓋纏根，是故此經名得度。 /

光向維耶城裏放，花從音樂樹間飛。 /
六通上士雨奔騰，十地高真雲靉靆。 /
帝釋梵王頭地禮，人王天眾掌膠來。 /
逡巡圍遶紫金容，未審誰能先發問。 /

輕首已暗時寂靜，如來猶未露機鋒。 /
愍嗟三界未來人，請問十方往昔事。 /
何處世尊深濟度？何方國土最莊嚴？ /
大圓鏡智照無私，願向今霄聞法要。 /

金口忽聞斯讚嘆，文殊決問此因緣。 /
眾生業垢既無邊，諸佛慈悲亦不盡。 /
有一法門深秘密，再三為汝廣宣揚。 /
敕令諦聽善思惟，時眾默然生愛樂。 /

東去有城名滿月，彼中覺皇號琉璃。 /
三祗功業不思議，十號名稱無等匹。 /
二六願門因地發，百千相好果中圓。 /
我今依願讚琉璃，伏願人神歡喜聽。 /

我今誓發菩提願，求證三摩登彼岸。 /
功德莊嚴妙相尊，法界眾生同滿願。 /
一種行願一種智，一種菩提一種理。 /
日光菩薩大慈悲，能與眾生消災罪。 /

我今誓發菩提願，身如琉璃光燦爛。 /
神光照透鐵圍山，黑暗眾生離苦難。 /
二種行願二種智，二種菩提二種理。 /
月光菩薩大慈悲，能與眾生消災罪。 /

人今朝繫洪名，三世冤業皆消滅。某 /

諸佛慈悲常愍念，但令求者啟心源。 /
今時燈主發精誠，一一依憑諸佛願。 /

第一願心心廣大，便期超證證菩提。 /
光明普照大千中，威德遍聞三界外。 /
妙相顓顓身挺特，威容肅肅相端嚴。 /
令他蠢動眾群生，與我此身無一異。 /

第二願身身瑩淨，光明皎潔似琉璃。 /
四生品類盡含容，萬象森羅無障礙。 /
寂爾無為常應念，湛然不動若虛空。 /
幽冥癡暗眾群生，皆願發蒙令曉悟。 /

第三願成無上覺，覺他自覺覺圓明。 /
常將智海潤焦枯，永使慧燈消黑暗。 /
國土更無饑渴想，人民不有怨嗟聲。 /
誓將美饈濟孤貧，普使眾生令飽滿。 /

第四願當來成佛道，巍巍微妙相堂堂。 /
星中皓月獨晶瑩，水裏紅蓮常瑩淨。 /
生死雲開無垢翳，識心浪靜絕痕瑕。 /
令諸熱惱得清涼，情與無情同一體。 /

第五願當來精進力，奉持佛勅止譏嫌。 /
常令戒地有馨香，勿使情塵生染汙。 /
萬劫千生寧毀犯，三十七證轉分明。 /
便令三界眾群生，同至菩提無缺漏。 /

第六願當來我國中，身根具足相端嚴。 /
盲聾喑啞不曾聞，跛躄癊殘何況見？ /
彼若業緣生惡果，我憑佛力為消除。 /
人民相視勿冤憎，禮義謙恭相敬奉。 /

第七願十方諸國土，三途六道眾含生。 /
無皈依處作梯航，遭苦難時為救護。 /
法藥調和多種病，善言誘諭小乘心。 /
咸令勇猛大根機，直至菩提無退轉。 /

第八願愚冥拋我見，六根昏塞執他宗。 /
講說大道發蒙來，開曉疑情通徹去。 /
智慧門深須究竟，菩提路遠莫因循。 /
靜思我師正真言，如救頭然無懈怠。 /

第九願當來成佛果，魔王眷屬自皈依。 /
惟將定力自嚴持，祗用慈心相攝受。 /
六十二般顛倒見，百千萬劫轉輪身。 /
顯揚指示正真源，共趣圓常入正路。 /

第十願當來我國中，更無王事苦煎煩。 /
殘刑虐法不偏加，薄賦輕徭修正道。 /
枷鎖鞭笞不曾見，冤讎枉濫未嘗聞。 /
人民相視勿憂愁，王道昇平歌政化。 /

十一願當來我國中，常令飲食得豐饒。 /
休將物命列雕盤，靡使腥膻薰覺性。 /
畿火豈焚無想念？靈臺寧貯不享餐。 /
天廚美饈種多般，應念隨心皆施與。 /

普濟眾生十二願，願茲福慧遍莊嚴。 /
若逢裸露與孤貧，施與衣資並庫藏。 /
絲竹管絃長在耳，貴榮歡樂每隨心。 /
和顏悅色相莊嚴，無有一人生惡念。 /

我佛因中十二願，善心先覺大千緣。 /
一願身相放光明，普照塵沙無障礙。 /
二願破除諸愛結，自然寶體似琉璃。 /
三願發心等滄溟，流注眾生令飽滿。 /
四願圓光如寶月，照開生死業浮雲。 /
五願戒定自然成，不失威儀三寶行。 /
六願眾生根具足，我今身相俱諸緣。 /
七願閻浮疾苦人，我法便為諸妙藥。 /
八願眾生愚癡者，吾能說法為開通。 /
九願諸魔妒惑心，使人正真祛疑惑。 /
十願橫遭王難苦，我將身命代臨刑。 /
十一願當來發身財，施與眾生為飲食。 /
十二願果圓成正覺，不教國土有饑寒。 /
和顏悅色樂昇平，共等伊圓慈慧力。 /
如是真空十二願，一一金口標題名。 /
今時演讚不思議，萬劫千生資福壽。 /

各於一切音聲海，普出無盡妙言詞。 /
盡於未來一切劫，讚佛甚深功德海。 /

長久皈依大法王，命童晨夕炷心香。 /
富將經藏看千卷，貴列幡花蔙兩行。 /

## 〔附〕
放生儀文

蓋聞稟元氣而生，孰分物我？資陶甄而孕，蓋有濁清。而含靈受質之有殊，乃惡死貪生之則一。是故成湯治化，設開籠釋網之文；梁武施仁，注戒殺放生之典。弋不射宿，是孔聖之存心；釣用直鈎，乃太公之懷德。

蓋為人民徂詐，世態能浮。東震獻禽，簡子見機於上客；祖庭具飲，田文感放陬生。學屠龍射虎之能，效繳鳳穿鱗之藝。所以巢居絕迹，穴處無蹤。麒麟隱遁於海隅，鳳凰翱翔於天末。乃是人心巧詐，恐罹網捕之機關。是以禽魚雖逃於險阻。

△學佛知見，依法奉行，特捐清淨之財，將贖林源之命。胎、卵、濕、化，謂之四生；鱗、甲、羽、毛，名為四種。莫不樂資茂育，跳躑效同。盡承天地之委和，異屬陰陽之造化。附其冀者失其足，與其角者離其牙。縱恣翻飛，任情馳騁。一飲一啄，知全身遠害之心；自飛自遊，有惡死貪生之念。孰謂禽魚無識？亦能樂聚悲離。有子母之情，慈鳥反哺；若兄弟之義，鴻雁成行。群禽集於鳳凰，君臣義重；雙燕語於梁上，夫婦恩深。鮒魚祈水於莊周，江使求生於宋伯。莫不貪遊貪食，豈知身墮於楚囚？戲走戲飛，不意體逄於網罟。任悲鳴於苦甚，故處於潛藏；徒宛轉於千遭，實難逃於陷穽。

但△誠不忍於觳觫，意故遠於庖廚。庶冀出水者任游泳於江河，棲山者恣翱集於林埜。故我世尊昔行菩薩道時，以水濟十千之魚，以藥治一切之病。得名流水，是號醫王。又為諸魚提唱寶勝王如來，並稱三乘四諦十二行法輪。

諸佛子，四諦法者，說是苦苦，是苦集，是苦滅，是苦滅道。十二因緣法者，所謂無明緣行，行緣識，識緣名色，名色緣六入，六入緣觸，觸緣受，受緣愛，愛緣取，取緣有，有緣生，生緣老死憂悲苦惱。無明滅則行滅，行滅則識滅，識滅則名色滅，名色滅則六入滅，六入滅則觸滅，觸滅則受滅，受滅則愛滅，愛滅則取滅，取滅則有滅，有滅則生滅，生滅則老死憂悲苦惱滅。諸佛子，三乘、四諦、十二因緣，願諸佛子一歷耳根，各各皆得三明六通，具八解脫，如意自在，作如是果，受如是因，證十千天子之身，獲八萬珍珠之報。又慮汝等自從曠劫至於今日，得到法筵，夙業愆重，未能解釋。我佛如來有普懺滅罪真言，各斂毛骨，聽吾宣說：

唵。娑縛披播。悉普吒。曩賀曩。嚩日囉耶。娑訶。

皈依佛、法、僧竟

諸佛子，等真等正覺是汝等大師，應當作禮。作禮已竟，諦觀能滅百千萬劫生死之罪，誓不皈依邪魔外道。慈愍故，悲愍故，大慈悲愍故。

諸佛子，茲者因禍成福，捨邪歸正，三禮至尊，一心信敬。我今更為汝等持誦三寶普懺罪真言，即說咒曰：

南無佛陀。達磨。僧伽。曩謨窣都帝。

諸佛子既聞密語，罪咎消除。猶慮汝等歷劫已來不能淨身口意，是故沈淪。今有淨三業真言，一心諦聽，當為宣說：

唵。娑婆嚩秫度。薩哩嚩。達哩麼。娑婆嚩。秫度憾。

諸佛子，苦、集、滅、道是聲聞乘，無明、老死是緣覺乘，戒、定、慧是最上乘。三乘妙法，一心受持。

我今更為汝等稱揚七佛如來名號，汝當諦聽：

南無寶勝王如來、廣博身如來、多寶如來、妙色身如來、阿彌陀如來、甘露王如來、離怖畏如來

上來所說戒相，悉已周完。知從前所作之非，悟爾後漸修之理。翱翔雲路，更無繒繳之憂；游泳海門，長獲波濤之樂。若脫鱗毛之報，免滯輪迴；早聞佛法之緣，速親正覺。冥司報德，慎勿辜恩。禎祥須薦於珍環，顯順特來於日月。釋迦出世，同為聽法之人；彌勒下生，齊受菩提之記。上窮有頂，傍及無邊，俱沭良因，盡成正覺。
