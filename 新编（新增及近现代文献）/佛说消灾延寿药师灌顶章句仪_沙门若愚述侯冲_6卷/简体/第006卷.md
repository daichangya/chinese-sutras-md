# 佛说消灾延寿药师灌顶章句仪 · 第六卷

> 沙门若愚述　侯冲整理

浩浩难思真法界，药师海会众圣贤。 /
我今教诫演仪文，望圣慈悲垂加护。 /

皈命十方及三际，尘刹圆明调御师。 /
法界功德大悲云，毗卢遮那大智海。 /

所住甚深真法性，所流圆满修多罗。 /
一一尘方佛会中，文殊普贤诸大士。 /

我今欲以一毫智，测量无边法界玄。 /
愿承三宝同体慈，句句冥符诸佛意。 /

身三口四意贪瞋，千恶门开散本真。 /
喝散障云无点翳，性天孤月月轮孤。 /

炉焚五分宝香请，一缕烟起彻幽明。 /
遍作十方诸神圣，诸佛闻召悉来临。 /

弥摩罗界秫提吽，一默澄潭万古明。 /
理事道场今洁涤，自然风月一时新。 /

聚沙成塔亘青天，举止分明在目前。 /
理事道场今洁涤，自然涌出一枝莲。 /

荆棘林中业火生，经由大地任纵横。 /
金刚突出摩诃力，直向如来行处行。 /

此花初举在灵山，唯有头陀独破颜。 /
续燄联芳传此世，一花五叶任君板。 /

诸经宝赞妙伽陀，普散奇花福力多。 /
诚以此花供佛圣，散花行道见弥陀。 /

佛游广严城中位，曼殊室利请经题。 /
世尊上愿慈悲主，无边琅度群迷。 / 𪻱
解脱菩萨消九横，药叉大将除灾危。 /
焚香燃灯依科范，集福延祥寿天齐。 /

愿此香花云，遍满十方界， /
供养一切佛，尊法诸菩萨， /
无边声闻众，及一切天仙。 /
以起光明台，过于无边界， /
无边佛土中，受用作佛事， /
普薰诸众生，皆发菩提心。 /

如来妙色身，世间无与等。 /
无比不思议，是故皈命礼。 /
如来色无尽，智慧亦复然。 /
一切法常住，是故我赞礼。 /
如来智慧灯，同叹一切僧。 /
能生三世佛，是故应顶礼。 /

清净法身遍法界，凝然湛寂号毗卢。 /
出缠离垢本非增，背觉合尘原不染。 /
若圣若凡名纵别，无生无灭理宁差？ /
绝诸戏论离思量，早愿有情同证悟。 /

圆满报身居报土，光明遍照普含容。 /
三祗劫内炼磨来，万行门中修证去。 /
解脱道中除劣法，华王座上启酬恩。 /
尘沙相好广无边，我等虔诚皈命礼。 /

百亿化身所化境，随机随类接群生。 /
迦维降迹出王宫，雪岭修行成佛果。 /
会启三百五十度，法开八万四千门。 /
虽然鹤树示韬光，常在鹫峰诸住处。 /

海减波澜最浅日，人增寿命极长时。 /
上辞兜率下阎浮，朝见出家暮成道。 /
雷震八音宣妙法，云臻三会度人天。 /
我于今日誓皈依，愿向当来蒙摄受。 /

世界立名为极乐，庄严殊胜最难遇。 /
西天梵语阿弥陀，东土唐言无量寿。 /
绀目澄清四大海，白毫宛转五须弥。 /
十声尊号若专心，一念便能生净土。 /

药与众生为救疗，师能三界作皈依。 /
琉璃莹净喻真如，内外光明同佛性。 /
法界无名名假立，圣人无相相权成。 /
不依名相接群生，争得群生圆觉道？ /

稽首虔诚皈命礼，十方常住佛陀耶。 /
真如体上启千身，般若光中含万像。 /
离相绝言虽有说，应机赴感岂曾亏？ /
众生性水若澄清，佛月此时皆得见。 /

稽首虔诚皈命礼，十方常住达磨耶。 /
龙宫鹫岭演来时，白马鸿胪翻出后。 /
一味醍醐平等润，三般根器应机成。 /
至于八万四千门，皆是如来方便用。 /

稽首虔诚皈命礼，十方常住僧伽耶。 /
三应四向有修人，五眼六通无漏众。 /
大隐尘寰凡圣混，深栖嵒洞水云幽。 /
慈悲长成福田山，添助众生功德海。 /

稽首虔诚请三宝，三宝慈悲降道场。 /
青螺肉髻拂尘云，紫磨金容光日月。 /
白毫照彻三千界，红珠辉映十三天。 /
梵王天上散香花，帝释宫中鸣鼓乐。 /
文殊大士先来引，手捧维耶《灌顶经》。 /
红条玉轴日增光，金字青轮星彩现。 /
救脱真人持宝烛，神幡五色亦相现。 /
八员大士拥莲台，十德高贤攒月殿。 /
三千国土诸圣贤，十二章中愿力王。 /
轻烟细雨拂青天，妙果祥光敷碧落。 /
金铃万种空中响，玉磬千般像外敲。 /
香烟飒飒遶云飞，直至阎浮尘世界。 /
如来尊重超三界，慈悲不越六尘中。 /
但能发愿散香花，便降人间沾供养。 /
今霄灯主殷勤重，此日如来降道场。 /
精修香烛展心诚，整顿安祥从佛后。 /

仰白道场诸大众，幸逢法会悉攀缘。 /
当时我佛释迦尊，曾在维耶音药树。 /
赞彼东方满月王，有其正觉药师尊。 /
因中积聚行门深，果内庄严佛度尽。 /

金作殿堂仍峭丽，银为峙堞复联环。 /
园林四序每精华，池沼七珍含晃耀。 /
云色光明笼藻井，水声柔软遶琉渠。 /
药音天际响叮当，花雨空中飞散漫。 /

禽语揄扬八圣道，树枝掁触六波罗。 /
琉璃池影泻楼台，菡萏香风薰宇宙。 /
路不失遗行正法，人无三毒禀真修。 /
宝幔翠网似烟霞，大贝明珠如瓦砾。 /

无漏感通功莫测，有为心识说难穷。 /
若论此佛利群生，向下依经随愿赞。 /

东方有佛名满月，佛号琉璃光皎洁。 /
顶上璇螺青系髻，眉间台相珂入雪。 /
十二大愿度众生，一片慈心无暂歇。 /
众生有难若称名，礼念琉璃罪消灭。 /

佛开八万四千门，天上人间佛独尊。 /
莫道满天星耿耿，犹如孤月照乾坤。 /

长以心田种善根，命延寿筭祝贤人。 /
富因积德光后裔，贵是阴功启芳声。 /
金作良田惟至宝，玉联奎壁即为珍。 /
满座圣贤呈瑞彩，堂前供乐太平春。 /

能向法门深悟入，自然罪性等虚空。 /
菩提实相倘圆明，生死妄心俱解脱。 /
若不随宜开经路，何名应病说方书？ /
拔除无始盖缠根，是故此经名得度。 /

光向维耶城里放，花从音乐树间飞。 /
六通上士雨奔腾，十地高真云叆叇。 /
帝释梵王头地礼，人王天众掌胶来。 /
逡巡围遶紫金容，未审谁能先发问。 /

轻首已暗时寂静，如来犹未露机锋。 /
愍嗟三界未来人，请问十方往昔事。 /
何处世尊深济度？何方国土最庄严？ /
大圆镜智照无私，愿向今霄闻法要。 /

金口忽闻斯赞叹，文殊决问此因缘。 /
众生业垢既无边，诸佛慈悲亦不尽。 /
有一法门深秘密，再三为汝广宣扬。 /
敕令谛听善思惟，时众默然生爱乐。 /

东去有城名满月，彼中觉皇号琉璃。 /
三祗功业不思议，十号名称无等匹。 /
二六愿门因地发，百千相好果中圆。 /
我今依愿赞琉璃，伏愿人神欢喜听。 /

我今誓发菩提愿，求证三摩登彼岸。 /
功德庄严妙相尊，法界众生同满愿。 /
一种行愿一种智，一种菩提一种理。 /
日光菩萨大慈悲，能与众生消灾罪。 /

我今誓发菩提愿，身如琉璃光灿烂。 /
神光照透铁围山，黑暗众生离苦难。 /
二种行愿二种智，二种菩提二种理。 /
月光菩萨大慈悲，能与众生消灾罪。 /

和耆罗大将威猛烈，能与众生解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，贫苦众生无饮膳， /
志心称念药师尊，种种随心皆满愿。 /
三种行愿三种智，三种菩提三种理。 /
文殊菩萨大慈悲，能与众生消灾罪。 /

弥伽罗大将威猛烈，能与众生解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，外道众生无正见。 /
尽化廻心向大乘，同驾白牛登彼岸。 /
四种行愿四种智，四种菩提四种理。 /
观音菩萨大慈悲，能与众生消灾罪。 /

安陀罗大将威猛烈，能与施主解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，无戒众生多散乱。 /
志心称念药师名，清净尸罗同满愿。 /
五种行愿五种智，五种菩提五种理。 /
势至菩萨大慈悲，能与众生消灾罪。 /

摩尼罗大将威猛烈，能与众生解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，下方众生根缺离。 /
专心称念药师名，身相端严皆敬爱。 /
六种行愿六种智，六种菩提六种理。 /
无尽意菩萨大慈悲，能与众生消灾罪。 /

宋林罗大将威猛烈，能与施主解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，病苦众生多障难。 /
无救无依无护持，闻举佛名离苦难。 /
七种行愿七种智，七种菩提七种理。 /
宝昙花菩萨大慈悲，能与众生消灾罪。 /

因陀罗大将威猛烈，能与施主解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，众生修行多障难。 /
志心称念药师名，转女成男皆满愿。 /
八种行愿八种智，八种菩提八种理。 /
药王菩萨大慈悲，能与众生消灾罪。 /

波耶罗大将威猛烈，能与众生解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，绝念众生无错乱。 /
专心称念药师名，摧破邪心皈正道。 /
九种行愿九种智，九种菩提九种理。 /
药上菩萨大慈悲，能与众生消灾罪。 /

摩休罗大将威猛烈，能与施主解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，王法枷锁刑囚难。 /
志心称念药师尊，枷锁解脱离苦难。 /
十种行愿十种智，十种菩提十种理。 /
弥勒菩萨大慈悲，能与众生消灾罪。 /

真陀罗大将威猛烈，能与施主解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，贫苦众生无饮膳。 /
志心称念药师尊，法力资财身勇健。 /
十一种行愿十一种智，十一种菩提十一种理。 /
救脱菩萨大慈悲，能与众生消灾罪。 /

照头罗大将威猛烈，能与施主解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

我今誓发菩提愿，寒热咬虫多唧难。 /
志心称念药师名，上妙衣服严身遍。 /
十二种行愿十二种智，十二种菩提十二种理。 /
解冤结菩萨大慈悲，能与众生消灾罪。 /

毗伽罗大将威猛烈，能与众生解冤结。 /
人今朝系洪名，三世冤业皆消灭。某 /

诸佛慈悲常愍念，但令求者启心源。 /
今时灯主发精诚，一一依凭诸佛愿。 /

第一愿心心广大，便期超证证菩提。 /
光明普照大千中，威德遍闻三界外。 /
妙相颛颛身挺特，威容肃肃相端严。 /
令他蠢动众群生，与我此身无一异。 /

第二愿身身莹净，光明皎洁似琉璃。 /
四生品类尽含容，万象森罗无障碍。 /
寂尔无为常应念，湛然不动若虚空。 /
幽冥痴暗众群生，皆愿发蒙令晓悟。 /

第三愿成无上觉，觉他自觉觉圆明。 /
常将智海润焦枯，永使慧灯消黑暗。 /
国土更无饥渴想，人民不有怨嗟声。 /
誓将美馐济孤贫，普使众生令饱满。 /

第四愿当来成佛道，巍巍微妙相堂堂。 /
星中皓月独晶莹，水里红莲常莹净。 /
生死云开无垢翳，识心浪静绝痕瑕。 /
令诸热恼得清凉，情与无情同一体。 /

第五愿当来精进力，奉持佛勅止讥嫌。 /
常令戒地有馨香，勿使情尘生染污。 /
万劫千生宁毁犯，三十七证转分明。 /
便令三界众群生，同至菩提无缺漏。 /

第六愿当来我国中，身根具足相端严。 /
盲聋喑哑不曾闻，跛躄癊残何况见？ /
彼若业缘生恶果，我凭佛力为消除。 /
人民相视勿冤憎，礼义谦恭相敬奉。 /

第七愿十方诸国土，三途六道众含生。 /
无皈依处作梯航，遭苦难时为救护。 /
法药调和多种病，善言诱谕小乘心。 /
咸令勇猛大根机，直至菩提无退转。 /

第八愿愚冥抛我见，六根昏塞执他宗。 /
讲说大道发蒙来，开晓疑情通彻去。 /
智慧门深须究竟，菩提路远莫因循。 /
静思我师正真言，如救头然无懈怠。 /

第九愿当来成佛果，魔王眷属自皈依。 /
惟将定力自严持，祗用慈心相摄受。 /
六十二般颠倒见，百千万劫转轮身。 /
显扬指示正真源，共趣圆常入正路。 /

第十愿当来我国中，更无王事苦煎烦。 /
残刑虐法不偏加，薄赋轻徭修正道。 /
枷锁鞭笞不曾见，冤仇枉滥未尝闻。 /
人民相视勿忧愁，王道升平歌政化。 /

十一愿当来我国中，常令饮食得丰饶。 /
休将物命列雕盘，靡使腥膻薰觉性。 /
畿火岂焚无想念？灵台宁贮不享餐。 /
天厨美馐种多般，应念随心皆施与。 /

普济众生十二愿，愿兹福慧遍庄严。 /
若逢裸露与孤贫，施与衣资并库藏。 /
丝竹管弦长在耳，贵荣欢乐每随心。 /
和颜悦色相庄严，无有一人生恶念。 /

我佛因中十二愿，善心先觉大千缘。 /
一愿身相放光明，普照尘沙无障碍。 /
二愿破除诸爱结，自然宝体似琉璃。 /
三愿发心等沧溟，流注众生令饱满。 /
四愿圆光如宝月，照开生死业浮云。 /
五愿戒定自然成，不失威仪三宝行。 /
六愿众生根具足，我今身相俱诸缘。 /
七愿阎浮疾苦人，我法便为诸妙药。 /
八愿众生愚痴者，吾能说法为开通。 /
九愿诸魔妒惑心，使人正真祛疑惑。 /
十愿横遭王难苦，我将身命代临刑。 /
十一愿当来发身财，施与众生为饮食。 /
十二愿果圆成正觉，不教国土有饥寒。 /
和颜悦色乐升平，共等伊圆慈慧力。 /
如是真空十二愿，一一金口标题名。 /
今时演赞不思议，万劫千生资福寿。 /

各于一切音声海，普出无尽妙言词。 /
尽于未来一切劫，赞佛甚深功德海。 /

长久皈依大法王，命童晨夕炷心香。 /
富将经藏看千卷，贵列幡花蔙两行。 /
金相慈悲抒我愿，玉毫宛转现威光。 /
满门和乐芝兰瑞，堂上如来步彩霞。 /

汝已得闻佛愿行，我今略说国庄严。 /
琉璃地上七重林，玛瑙池中八德水。 /
金殿银城光隐映，琼楼珠网影玲珑。 /
欲尘意垢悉皆无，还似弥陀佛国土。 /

日曜光明如月净，梵音清彻海潮音。 /
久磨智刃越三祗，已驾慈舟超六度。 /
堪与药师为长子，正当补处作医王。 /
善男信女发心专，尽愿得生彼佛土。 /

佛子文殊重启问，琉璃光佛不思议。 /

放生仪文

盖闻禀元气而生，孰分物我？资陶甄而孕，盖有浊清。而含灵受质之有殊，乃恶死贪生之则一。是故成汤治化，设开笼释网之文；梁武施仁，注戒杀放生之典。弋不射宿，是孔圣之存心；钓用直钩，乃太公之怀德。

盖为人民徂诈，世态能浮。东震献禽，简子见机于上客；祖庭具饮，田文感放陬生。学屠龙射虎之能，效缴凤穿鳞之艺。所以巢居绝迹，穴处无踪。麒麟隐遁于海隅，凤凰翱翔于天末。乃是人心巧诈，恐罹网捕之机关。是以禽鱼虽逃于险阻。

△学佛知见，依法奉行，特捐清净之财，将赎林源之命。胎、卵、湿、化，谓之四生；鳞、甲、羽、毛，名为四种。莫不乐资茂育，跳踯效同。尽承天地之委和，异属阴阳之造化。附其冀者失其足，与其角者离其牙。纵恣翻飞，任情驰骋。一饮一啄，知全身远害之心；自飞自游，有恶死贪生之念。孰谓禽鱼无识？亦能乐聚悲离。有子母之情，慈鸟反哺；若兄弟之义，鸿雁成行。群禽集于凤凰，君臣义重；双燕语于梁上，夫妇恩深。鲋鱼祈水于庄周，江使求生于宋伯。莫不贪游贪食，岂知身堕于楚囚？戏走戏飞，不意体逄于网罟。任悲鸣于苦甚，故处於潜藏；徒宛转于千遭，实难逃于陷穽。

但△诚不忍于觳觫，意故远于庖厨。庶冀出水者任游泳于江河，栖山者恣翱集于林埜。故我世尊昔行菩萨道时，以水济十千之鱼，以药治一切之病。得名流水，是号医王。又为诸鱼提唱宝胜王如来，并称三乘四谛十二行法轮。

诸佛子，四谛法者，说是苦苦，是苦集，是苦灭，是苦灭道。十二因缘法者，所谓无明缘行，行缘识，识缘名色，名色缘六入，六入缘触，触缘受，受缘爱，爱缘取，取缘有，有缘生，生缘老死忧悲苦恼。无明灭则行灭，行灭则识灭，识灭则名色灭，名色灭则六入灭，六入灭则触灭，触灭则受灭，受灭则爱灭，爱灭则取灭，取灭则有灭，有灭则生灭，生灭则老死忧悲苦恼灭。诸佛子，三乘、四谛、十二因缘，愿诸佛子一历耳根，各各皆得三明六通，具八解脱，如意自在，作如是果，受如是因，证十千天子之身，获八万珍珠之报。又虑汝等自从旷劫至于今日，得到法筵，夙业愆重，未能解释。我佛如来有普忏灭罪真言，各敛毛骨，听吾宣说：

唵。娑缚披播。悉普咤。囊贺囊。婆日啰耶。娑诃。
