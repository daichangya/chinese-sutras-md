觀音勝會啟壇場，密咒柴油水米香。 /
安息飛煙雲霧捲，蘭膏發熖慧燈光。 /
緇流濟濟皆精潔，賢聖巍巍盡讚揚。 /
法雨滿空甘露灑，道場無處不清涼。 /

觀音感驗難思議，能與眾生作福緣。 /
柴油淨水誦真言，所冀吉蠲無觸穢。 /

壓油縱有傷生悮，破暗寧無利物心。 /
更凴秘密作加持，爍破群昏無限量。 /

妙湛靈源常混混，真空性水自淵淵。 /
眾生無始妄情昏，普願霑濡心垢淨。 /

佛世比丘燒沉水，香嚴聞已悟圓通。 /
檀那敬請聖觀音，拙具羅香凴此咒。 /

心地清涼由法力，色身安快仗資糧。 /
我今稱讚此密言，菩薩天人常賜我。 /

身口意業本來同，一念迷真失本宗。 /
喝散障雲無點翳，一輪杲日照長空。 /

聞法歡喜讚，乃至發一言， /
則為已供養，一切三世佛。 /

八功德水自天真，善洗眾生業垢塵。 /
流入毘盧華藏界，箇中無處不超倫。 /

聚沙成塔亘青天，舉指分明在目前。 /
法界蕩無塵一點，自然涌出一枝蓮。 /

五分法身真妙香，人人具足露堂堂。 /
無根樹下親拈出，供養圓通大法王。 /

荊棘林中業火生，經由大地任縱橫。 /
金剛界出摩訶力，直向如來行處行。 /

揭諦揭諦四天王，統領鬼兵降道場。 /
守護東西南北去，邪魔外道悉逃亡。 /

一花五葉祖師傳，淺白深紅有萬般。 /
宴座巖前無說處，紛紛墜落紫雲端。 /

頂螺青紺雲盤翠，肉髻珠紅果豔分。 /
照曜朦朧五彩明，當空宛轉千花秀。 /

菩薩修行願力深，光明山上運悲心。 /
雲鋪碧落興慈意，潮震滄溟吐梵音。 /
千貝輻輪文紫玉，萬題胸字色黃金。 /
耳通眼慧希昭鑒，此日香壇佇降臨。 /

水澄秋月現，懇禱福田僧。 /
惟有佛菩薩，是真歸仗處。 /

道場清淨眾，各各當至心。 /
至心勤皈依，至心勤禮拜。 /

惟有觀世音，能延人壽命。 /
惟有觀世音，能延人福祿。 /
是故我等眾，今日須控告。 /
惟願聖慈悲，開受我等請。 /
令我壽命長，永修一切善。 /
令我福祿盛，厚結一切緣。 /
今日已往去，永不復退轉。 / 二說

惟有觀世音，誓度諸有情。 /
是故我等眾，今日須控告。 /
唯願聖慈悲，開受我等請。 /
令我所薦嚴，承此妙善力。 /
往生光明山，親禮紫金容。 /
日聞微妙法，超證最上乘。 /
今日已往去，永不復退轉。 /

警策諸人切至誠，制心一處善芽生。 /
凡夫境界塵埋沒，佛法門庭路坦平。 /
速捨魔王煩惱窟，求登大覺涅槃城。 /
齊稱偈讚，合掌聽宣治路明。祈延壽伸追薦 /

山號光明小白花，石階舍利產靈芽。 /
八功德水清堪翫，五色祥雲翠可誇。 /
瑪瑙階前排寶樹，琉璃池畔映金沙。 /
天香間發鳴仙樂，菩薩毫光散彩霞。 /

觀音住在補陀山，自在逍遙日月閑。 /
自把數珠還自念，慈觀諸趣復慈顏。 /
神通遊戲諸三昧，相好端嚴四八般。 /
大眾返聞聞自性，相逢衹在剎那間。 /

觀音古佛大慈悲，權現菩提薩埵儀。 /
足下黃金千輻相，頂門心月一雙眉。 /
初回啟請蒙垂降，合掌虔誠再禱祈。 /
欲請上乘獅子座，先持啟白陀羅尼。 /

《楞嚴經》說聖觀音，能接眾生入覺林。 /
真觀既同清淨觀，梵音無異海潮音。 /
鐵輪磨頂情非捨，金鑒為懷誓不成。 /
世出世間如意事，專誠啟祝定隨心。 /

開壇寶誦妙通玄，地湧聲雷鎮上天。 /
綿綿福果善修來，湛湛心如明鏡臺。 /
臺鏡明如心湛湛，來修善果福綿綿。 /
天上鎮雷聲湧地，玄通妙誦寶壇開。 /

稽首光明大佛頂，如來萬行首楞嚴。 /
光中化佛演微言，誦念溥令祛宿業。 /

滿目旃檀紫竹林，頭頭顯露聖觀音。 /
初時已證圓通會，先發菩提四善心。 /

三慧門高絕品題，而今識與辯端猊。 /
含靈識本從頭悟，淨聖垂慈為獎提。 /
超果超因離勝迹，假名假相示筌第。 /
福田壽域無涯際，携手相從闊步躋。 /

四善心惟正性強，慈悲恭謹是壇場。 /
但能念念無生滅，自證空空絕忖量。 /
佛法地平堪履翫，是非門險莫談揚。 /
更能猛勱除人我，覺悟修行見法王。 /

人天虔潔共歸依，召請方嚴第一時。 /
上聖赴緣臨垢濁，眾生翹首仰慈悲。 /
飄颻瓔珞清音間，芬馥旃檀瑞氣隨。 /
欲仗密言成勝事，輒堅精意為加持。 /

云何為供養，無上兩足尊？ /
願說其義趣，聞者當奉行。 /
香花眾伎樂，衣服藥臥具。 /
如是等供養，云何為最勝？ /

當發菩提心，廣濟諸群品。 /
是則供正覺，三十二相明。 /
設滿恒沙剎，珍妙莊嚴具。 /
奉獻諸如來，及懽喜頂戴。 /
不如以慈心，回向於菩提。 /
是福為最勝，無量無有邊。 /
餘供無過者，超踰不可計。 /
如是菩提心，必成等正覺。 /

諸天龍鬼神，聽我師子吼。 /
今於如來前，弘誓發菩提。 /
生死無量劫，本際不可知。 /
為一眾生故，爾數劫行道。 /
況此諸劫中，度脫無量眾。 /
修行菩提道，而生疲倦心。 /
我欲從今始，起於貪欲心。 /
是則為欺誑，十方一切佛。 /
瞋恚愚癡垢，慳嫉亦復然。 /
我今說實語，遠離於虛妄。 /
我若於今始，起於聲聞心。 /
不樂修菩提，是則歎世尊。 /
亦不求緣覺，自濟利己身。 /
當於萬億劫，大悲度眾生。 /
如今日佛土，清淨妙莊嚴。 /
令我得道時，超踰億百千。 /
國無聲聞眾，亦無緣覺乘。 /
淳有諸菩薩，其數無限量。 /
眾生淨無垢，悉具上妙藥。 /
出生於正覺，總持諸法藏。 /
此誓若誠實，當動大千界。 /

觀音修證出悲華，觀見眾生行業差。 /
無量淨王元古佛，不眴太子選其家。 /
師資身現三王子，左右蓮開二朵花。 /
以大音聲勸回向，菩提心發遍河沙。 /

釋名攝化理幽深，梵語華言仔細尋。 /
濕伐羅耶稱自在，婆盧枳底即觀音。 /
生生善解無窮難，劫劫能除有漏心。 /
三業歸依頭面禮，聞聲救苦便垂臨。 /

存念觀音各不同，五門八法互含融。 /
是心是佛如如理，無我無人念念空。 /
興福疏標慈普應，世親論載數何窮？ /
稱名歸依修三昧，一法通時萬法通。 /

觀音儀相實無邊，金色熒煌映紫檀。 /
白褻花裝為胳膊，毘楞伽寶作天冠。 /
頂中化佛無邊億，項上分輝有萬般。 /
作是觀時為正觀，若他觀者被渠謾。 /

我等自從無始劫，因迷覺海性沉圓。 /
無明妄動能所生，境風鼓擊波浪起。 /
由緣妄見體昏昧，外感頑空相現前。 /
空分四大互相淩，見起六根常融別。 /
妄將心境分成二，故使一真性相殊。 /
由茲生死苦無窮，如旋火輪無休息。 /
幸逢最後佛垂範，因悟從前萬苦辛。 /
今投聖眾懺前愆，應念化成無上道。 /

我昔枉受輪迴苦，皆由心境妄緣攀。 /
而今循省已知非，力行斷惑常無倦。 /
法門無盡常修學，苦海彌天駕法船。 /
我今妄習頓能除，願我真心常不昧。 /
願我直入三摩地，願我對境悟圓通。 /
願我得果成寶王，還度如是恒沙眾。 /

空有多聞迷實相，於無漏業不能修。 /
當來苦果竟難逃，直向聖門求解脫。 /

會上因緣三世佛，圓通海會佛菩薩。 /
聲聞羅漢賢聖僧，摩訶般若般羅密。 /

菡萏紅蓮凝舌相，蘋婆丹果豔唇端。 /
威儀相若象王行，說法音同獅子吼。 /

道場清淨眾，各各當志心。 /
志心勤歸依，志心勤禮拜。 /
大聖大慈悲，觀世音菩薩。 /
唯有觀世音，能拔眾生苦。 /
唯有觀世音，能滅眾生罪。 /
凡我等愚迷，令我延壽命令我所薦嚴。 /
自無始劫來，深造諸黑業。 /
皆由身口意，及我諸先代。 /
內外諸眷屬，或已生人天。 /
而未登聖地，或以業緣牽。 /
未得受快樂，是故我等眾。 /
今日須控告，唯願聖慈悲。 /
開受我等請，令我諸罪苦。 /
無有不消滅，諸罪苦滅已。 /
各發菩提心，諸惡不復作。 /
眾善力奉行，今日已往去。 /
永不復退轉。三說

再伸警策禮觀音，黑業消除白業深。 /
隨喜盡超三有海，見聞俱出八邪林。 /
如如理悟無生理，了了心通大覺心。 /
眾善奉行不退轉，聖凡一體古猶今。 /

啟請今當第二回，五輪投地業山摧。 /
心心洗懺千生罪，念念消除萬劫災。 /
返本還源求解脫，背塵合覺免輪迴。 /
凝然珍重將伸禮，須仗真言震法雷。 /

禮拜能除我慢障，禮拜能除我慢愆， /
禮拜能感尊貴身，禮拜能生三善道。 /

丈六金身現碧空，蓮池海會紫霞紅。 /
自從西域垂明教，輟起恒河化日中。 /

圓通何處不圓通，那箇圓通在海東？ /
三拜起來開豁眼，一枝楊柳笑春風。 /

分明勢至露堂堂，昔日曾修日月光。 /
不離彌陀常左右，手持如意異奇香。 /

願救我苦厄，大悲覆一切。 /
普放淨光明，滅除癡暗冥。 /
為免殺害苦，煩惱及眾病， /
必來至我所，施我大安樂。 /
我今稽首禮，聞名救厄者。 /
我今自歸依，世間慈悲父。 /
唯願必定來，免我三毒苦， /
施我今世樂，及與大涅槃。 / 三說

三回伏地轉懃翹，觀想觀音路匪遙。 /
再禱再祈災網斷，一心一意障雲消。 /
隨聲發響洪鐘叩，說法當機大海潮。 /
菩薩慈悲來赴感，種瓜不是豆生苗。 /

沒溺四生拘溷濁，循環五道恣纏綿。 /
若非慈悲聖觀音，孰與垂哀為救護？ /

此咒名為甘露藥，能救一切諸有情。 /
無量眾苦悉消除，是故名為施無畏。 /

救拔無邊罪苦時，惟憑大士運慈悲。 /
迷途困厄多邪見，聖智哀憐出苦危。 /
盡與滅除煩惱障，普令永斷世間癡。 /
善財親見為良友，攝取眾生應病醫。 /

凡夫三業不清涼，歷劫塵埋在苦鄉。 /
自作教他何覺悟？故為誤犯少籌量。 /
了知本性元無性，頓悟身光自有光。 /
今日懺除何所喻？琉璃瓶內佇朝陽。 /

觀音垂願化娑婆，接引眾生出愛河。 /
靈驗昭彰難可述，神通變化孰能過？ /
自知悟道方成佛，益已安禪便利他。 /
念念念成無相念，分明具足六波羅。 /

大悲大名稱，吉祥安樂人。 /
常說吉祥句，濟度極苦者。 /
眾生若聞名，離苦得解脫。 /
亦遊戲地獄，大悲代受苦。 /
或處畜生中，化作畜生形。 /
教以大智慧，令發無上心。 /
或處阿修羅，軟言調伏心。 /
令除憍慢習，疾至無為岸。 /
現身作餓鬼，手出香色乳。 /
饑渴逼切者，施食得飽滿。 /
大慈大悲心，遊戲於五道。 /
常以善集會，無上勝方便， /
普救一切眾，令離生死海。 /
當得安樂處，到大涅槃岸。 /

觀音化現幾多身，六道三途出苦輪。 /
普願超凡兼入聖，盡令捨妄悉歸真。 /
隨緣在欲元無欲，離相居塵不染塵。 /
定慧慈悲皆攝受，新成舊佛佛成新。 /

我昔所造諸惡業，皆由無始貪嗔癡。 /
不悟自性本來真，枉入四生並六趣。 /
一念迴光而返照，譬如雲散月當空。 /
不歷僧祗獲法身，自利利他悉圓滿。 /

願身口意常清淨，一切罪業悉消除。 /
願我心同如意珠，一切所願悉成就。 /
一一消除微細惑，背塵合覺獲真常。 /
舜若多性可銷亡，爍迦羅心無動轉。 /

三界悠悠如夢幻，四生擾擾但奔馳。 /
歸依無上佛菩提，便是當來堅固藏。 /

會上因緣三世佛，圓通海會佛菩薩。 /
聲聞羅漢賢聖僧，摩訶般若波羅密。 /

胸藏黃金題卍字，足輪碧玉間千花。 /
三十二相遍莊嚴，千百億身常救苦。 /

道場清淨眾，各各當志心。 /
至心勤歸依，至心勤禮拜。 /
大聖大慈悲，觀世音菩薩。 /
唯有觀世音，開示我修道。 /
唯有觀世音，速令我修真。 /
自悟性本空，圓明同太虛。 /
不垢忘不淨，不生亦不滅。 /
是故我等眾，今日須控告。 /
唯願聖慈悲，開受我等請。 /
令我所追薦，精修大乘行。 /

三回警策證圓通，心識圓明意氣雄。 /
有作因緣俱是幻，無為行業等虛空。 /
傍生餓鬼如來用，地獄天堂善逝功。 /
直截根源歸佛地，人人盡識主人翁。 /

菩薩隨緣化有情，四生能化百千形。 /
春來處處花盈谷，秋到家家月滿庭。 /
省覺到頭俱是幻，悟迷畢究了無因。 /
圓融行布皆無礙，收拾歸來在一塵。 /

觀音菩薩運慈悲，妙覺隨緣顯相形。 /
趙璧連城三大棄，眾生是佛幾人知。 /
梁皇不契西來意，達麼潛回北魏時。 /
明覺覺來無所覺，有為同悟悟無為。 /

稽首難思真法界，圓通海會眾聖賢。 /
我今陞座演鴻儀，惟願慈悲垂加護。 /

解脫修心道可攀，證真如理出塵寰。 /
昔年未悟金藏鑛，今日方知玉在山。 /
般若智明登彼岸，菩提心發遍人間。 /
陀羅尼藏誰能識？識得元來不等閑。 /

六波羅蜜遍熏修，便得超凡入聖流。 /
萬行圓融天地闊，三輪清淨鬼神愁。 /
岩前已絕啣花鳥，石畔長閑獻果猴。 /
今古堂堂觀自在，何須馳騁四方求？ /

修行地位強區分，悟則元來本一門。 /
背境觀心心已寂，悟心無境境何存？ /
月沉巨海真無玷，雲散長空豈有痕？ /
一則為多多即一，五般香爇遍乾坤。 /

眾生迷到入邪林，妄念攀緣水火侵。 /
有我有人煩惱宅，非真非妄涅槃心。 /
執情難悟塵埋鏡，離相方知鑛出金。 /
實狀元來無一物，迷雲散盡見觀音。 /

隔垣聽音響，遐邇俱可聞。 /
五根所不齊，是則通真實。 /
音聲性動靜，聞中為有無。 /
無聲號無聞，非實聞無性。 /
聲無既無滅，聲有亦非生。 /
生滅二圓離，是則常真實。 /
