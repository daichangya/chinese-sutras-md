归命满分净法身，毘卢遮那遍照智！ /
开敷妙觉光明眼，修广犹若青莲叶。 /
我今依经要略说，自利利他悉地法， /
真言次第方便行，发起信解胜妙门。 /
先令自心离尘垢，思惟诸佛现于前， /
谛想自身在其所，虔诚布散妙香华， /
种种胜妙庄严具，瞻仰本尊明印法， /
一心恭敬而作礼。

由此作礼真实言，即能遍礼十方佛！ /
右膝着地合爪掌，思惟说悔先罪业。 /
我由无明所积集，身口意业造众罪， /
贪欲恚痴覆心故，于佛、正法、贤圣僧， /
父母二师善知识，及以无量众生所， /
无始生死流转中，具造极重无尽罪； /
亲对十方现在佛！悉皆忏悔不复作。 /

南无十方三世佛！三种常身正法藏， /
胜愿菩提大心众，我今皆悉正归依。 /

我净此身离诸垢，及与三世身口意， /
过于大海刹尘数，奉献一切诸如来！ /

净菩提心胜愿宝，我今起发济群生， /
生苦等集所缠身，及与无知所害身， /
救摄归依令解脱，常当利益诸含识。 /

十方无量世界中，诸正遍知大海众！ /
种种善巧方便力，及诸佛子为群生， /
诸有所修福业等，我今一切尽随喜。 /

我今劝请诸如来、菩提大心救世者！ /
唯愿普于十方界，常以大云降法雨。 /

愿令凡夫所住处，速舍众苦所集身， /
当得至于无垢处，安住清净法界身。 /

所修一切众善业，利益一切众生故， /
我今尽皆正回向，除生死苦至菩提。 /

身随所应以安坐，分明谛观初字门， /
次当结三昧耶印，所谓净除三业道。 /

才结此密印，能净如来地， /
地波罗蜜满，成三法界道。 /
次结法界生，密慧之幖帜， /
净身口意故，遍转于身分。 /

如法界自性，而观于自身， /
为令彼坚固，观自执金刚！ /
结金刚轮印。亦名转法轮印

谛观我此身，即是执金刚！ /
次擐金刚甲，当观所被服， /
遍体生焰光。

「啰」字色鲜白，空点以严之， /
如彼髻明珠，置之于顶上。 /
所积众罪垢，由是悉除灭， /
福慧皆圆满。一切触秽处， /
当加此字门，赤色具威光， /
焰鬘遍围绕。
次为降伏魔，制诸大障者， /
当念大护者！无能堪忍明。 /

由才忆念故，诸毘那夜迦、 /
恶形罗刹等，彼一切驰散。 /
警发于地神！应说如是偈。 /
。双膝长跪，定手持杵当心，慧手舒五指平掌按地

诸佛慈愍有情者，唯愿存念于我等， /
我今请白诸贤圣、坚牢地天并眷属、 /
一切如来及佛子！不舍悲愿悉降临， /
我受此地求成就，为作证明加护我。 /

大毘卢遮那成就仪轨二卷，法全阿阇梨住玄法寺而所撰集。故呼曰：「玄法寺仪轨」，此慈觉大师之请来也。旧本五言偈颂，一行四句，是古来调，经本之通法也。然今所梓行则一行三句，是由间有脚注其句难分而已。又其所讐正皆以冠注之，庶乎后贤为再正之旹。
