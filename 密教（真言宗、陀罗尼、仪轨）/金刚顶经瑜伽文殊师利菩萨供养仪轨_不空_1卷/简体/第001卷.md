# 金刚顶经瑜伽文殊师利菩萨供养仪轨 · 第一卷

> 唐 不空译

---

归命童真妙吉祥，我依瑜伽说念诵， /
身口意业金刚念，如来甚深三密门。 /
行者应发普贤心，从师应受金刚戒， /
不顾身命起慈悲，方可堪入解脱轮。 /
应从师受三么耶，契印密语如经说， /
敬阿阇梨如佛想，于同学所殷重心。 /
或于山间阿兰若，流泉浴池悦意树， /
山峰石窟逈树边，建立坛场如本法。 /
庄严精室置本尊，随力供养一心住， /
遍观十方诸佛海，供养礼诸如来足。 /
为成三业金刚故，当于二手舌心中， /
应想五智金刚杵，犹此加持皆悉地。 /
次应结契名警觉，二手皆作金刚拳， /
檀慧相钩竖进力，二度侧拄成觉悟。 /

敬礼东方阿閦尊，舍身求请不退转， /
全身着地以心礼，金刚合掌舒顶上。 /

次当敬礼宝生尊，舍身求请灌顶位， /
金刚合掌当于心，以额着地虔诚礼。 /

次礼观自在王尊，舍身求请三么地， /
金刚合掌置顶上，以口着地虔诚礼。 /

金刚合掌安于心，舍身求请善巧智， /
金刚合掌安于心，以顶着地稽首礼。 /

次复敬礼十方佛，想身遍在诸佛前， /
观想五轮着地礼，常结金刚三么耶。 /

次诵成就妙真言，所有众生求胜事， /
愿诸如来悉加持，速令成就无上道。 /

次当结跏端身坐，净除三业令清净， /
诸法本性清净故，令我此身净无垢。 /

次结文殊三么耶，十度相叉成满月， /
直伸忍愿金刚剑，想身同等妙吉祥。 /

次当开心入佛智，当于两乳想二字， /
怛啰咤字皆白色，其字想为二户扇，二合 /
二手当结金刚缚，三拍当心开户门。 /

当观妙莲阿字门，以印召入于心殿， /
定慧为月金刚缚，禅智在掌想字入。 /

次当结门心户印，如前入印之幖帜， /
进力屈在禅智上，即得坚固不退转。 /

次结普贤三昧耶，体同萨埵金刚故， /
定慧和合金刚缚，忍愿二度建如幢， /
才诵本誓印真言，身处月轮同萨埵。 /

次结极喜三昧耶，定慧为月坚固缚， /
忍辱愿度中交合，檀慧禅智竖相着。 /

次结金刚降三世，想身同彼无差别。 /
止观二羽金刚拳，檀慧相钩竖进力， /
右转辟除右结界，悲心示现威怒形。 /

次结莲华三么耶，为令观行成就故。 /
十度相叉作为月，禅智檀慧竖相着。 /

次结召集诸罗印，定慧二羽金刚缚， /
忍愿二度建如峰，进力如钩三召集。 /

次结金刚摧罪印，三羽和合内相叉， /
忍愿二度竖如幢，一诵真言一摧拍。 /
自想无始诸罪业，众多裸黑如鬼形， /
诵彼摧罪妙真言，以印摧拍令销灭。 /

行者欲入金刚定，先住妙观察智印， /
定慧二羽仰相叉，进禅力智各相柱。 /
以此妙印修等引，即得如来不动智。 /

次结金刚智剑印，止观相叉作满月， /
忍愿皆竖如剑形，印心及额喉顶上。 /

次结文殊五髻印，止观二羽外相叉， /
檀方慧戒合如峰，进愿忍智头相捻， /
禅力三度头相合，当诵根本妙真言。 /

行者次结一髻印，定慧二羽内相叉， /
忍愿二度合如幢，相拄令圆如髻相。 /

行者次结三髻印，止观十度当心合， /
进力戒方屈入掌，令其中节各相拄。 /

次合定慧虚心掌，火轮交结持水轮， /
二风环屈如大空，其相如钩成密印， /
而用遍置自支分，尔乃修行众事业。 /

次当灌顶结宝印，二手相叉作为月， /
进力反屈如宝形，禅智二度下相捻， /
置于额上分两边，便结智拳如系帛， /
两手向前徐徐散，当知已系无垢缯。 /

次结宝剑自灌顶，二手合掌屈进力， /
禅智皆屈入掌中，置于额上分两边。 /

次复结于甲胄印，二手皆作金刚拳， /
置于心前竖进力，左右二度想唵砧， /
想流青光为绿色，心前三转遶背后， /
复至脐下及两膝，又转至脐遶腰后， /
从腰到心转两膊，从膊至喉向颈后， /
复从颈后至额前，从额至脑结智拳， /
徐徐散下如垂带，止观旋转如舞势， /
二手相叉成满月。

二羽齐拍三相拍，由陈拍印真言并， /
能令圣众发欢喜，速获本尊欢喜体。 /

次结大海印，二羽内相叉， /
仰掌当于脐，禅智微相拄。 /

定慧十度内相叉，双建二臂肘相合， /
当心直竖诵真言，此名妙高宝山印。 /

次结金刚轮大印，二羽各作金刚拳， /
进力檀慧互相钩，如彼坛场身四处。 /

次结四摄印，当诵四字明： /

又结金刚遍人印，止观和合外相叉， /
禅智屈入于掌中，呈印能令大圣现。 /

不解前印诵真言，能令行者分明见。 /

又结三昧耶，金刚剑大印， /
称诵后真言，我与本尊等。 /

次结四秋密，诵此金刚句： /

次以四字明，如前如四处。 /

次当行者座前观，八叶莲花具须蘂， /
止观师子妙高座，座上复有七宝楼。 /
中想七宝莲花王，上想昙字具威光， /
遍照法界靡不周，其字变为金刚利。 /
了了谛观如本形，召请菩萨入想身， /
二手作月进如钩，想身同于彼菩萨。 /
次结金刚钩大印，一切如来请召智， /
定慧和合外相叉，进度如钩独三屈。 /

次结金刚索大印，引入尊身成智体， /
前印禅度入定掌，力智相捻如环势。 /
次当结索入尊身，结月禅神智入掌， /
由此密印加持故，变为一体无有差。 /

次结金刚钩锁印，能令本尊坚固住， /
禅智进力相钩结，是名金刚能止印。 /
次当锁印令坚固，作月四度犹如环， /
由此密印威力故，悉令坚固而不变。 /

次结金刚妙声印，能令诸圣皆欢喜， /
禅智屈入金刚缚，是名金刚欢喜印。 /
次结铃印令欢喜，禅智入掌如铃铎， /
令尊及众皆欢喜，加持令速妙成就。 /

次结文殊羯磨印，二手各作金刚拳， /
定羽置于自心上，慧羽犹如执剑势。 /
由此羯磨妙印力，身与本尊等无异。 /

次结金刚利剑印，缚印忍愿伸如剑。 /
由此妙印加持故，当获般若甚深智。 /

次结青莲花妙印，戒方檀慧合妙幢， /
忍愿各缴戒方背，进力各屈捻禅智。 /

次结孔雀王座印，定慧二羽内相叉， /
檀慧并竖如尾形，禅智相合犹如首。 /

次结嬉戏内供养，外缚禅智并捻进。 /
由此印力加持，速满檀那波罗蜜。 /

次结金刚鬘供养，依前嬉戏直申臂。 /
由结此印加持故，当满净戒波罗蜜。 /

次结金刚歌咏印，鬘至脐口垂下散。 /
由结金刚歌咏印，速获安忍波罗蜜。 /

次结金刚舞供养，二手拳旋如舞势。 /
由结舞印加持力，速满精进波罗蜜。 /

次结金刚外供养，缚印当心向下散。 /
由结烧香印力故，当证静虑波罗蜜。 /

次结金刚散花印，缚印仰解如散花。 /
由结散花印加持，速证般若波罗蜜。 /

次结金刚灯明印，外缚禅智合如幢。 /
由结金刚灯明印，当得方便波罗蜜。 /

次结金刚涂香印，月当胸散如涂香。 /
由结涂香印加持，速满誓愿波罗蜜。 /

般若大品乃二字，昼夜四时精进修， /
现世证得欢喜地，后十六生成正觉。 /

当愿众生遇此教，文殊常为善知识， /
速证般若善巧智，疾成无上两足尊。 /
