初入道场，面向于佛，坐想此身， /
碎如微尘，返收摄身，如金刚体。 /

三业清净已，运心六道中， /
一切诸众生。

而诵此真言，应当一七遍。 /

小光明不动，想身旋复去， /
而念此真言，亦应一七遍。 /

复想身而来，念真言七遍。 /

复想身而入，将成大觉身， /
念此秘密言，加持一七遍。 /

想小光明住，如同大觉身， /
诵此陀罗尼，复应一七遍。 /

复自谛思惟，仰启诸如来： /
「我运心供养，或有错误者， /
愿佛哀愍我，再降甘露水， /
洗涤一切罪，悉皆令消灭。」 /
奉送真言曰：

金刚阿阇黎，与弟子灌顶， /
如上先想坛，亦应诵密语， /
所谓四明王：

而烧白芥子，熏授法之者。 /
一切诸烦恼，咤枳啰惹王， /
加持于净水，以洒弟子身， /
而除诸罪垢。播多攞真言， /
用加持生饭，供养于诸天， /
龙神八部等。此法甚秘密， /
不得妄宣传，除逢智慧人， /
乃可为宣说。
